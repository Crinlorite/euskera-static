Голяма част от обществения живот в Euskal Herria минава през **таверната** (бара). Ако знаеш основните напитки и храни на баски, веднага ще ти се отворят врати: компания от приятели, посещение в ново село, един *poteo* (обикаляне по барове). Започваме с речника.

## Кафето и неговите разновидности

Кафето е може би това, което ще поръчваш най-често. То има няколко форми:

| Euskera | Български |
|---|---|
| *kafea* | кафето (общо) |
| *kafe hutsa* | черно кафе (буквално: "чисто/празно кафе") |
| *kafesnea* | кафе с мляко (от *kafe* + *esne*) |
| *kafe ebakia* | кафе с малко мляко (*ebaki* = "срязан") |
| *kafe deskafeinatua* | безкофеиново кафе |
| *infusioa* | билков чай |
| *tea* | чай |

> *Kafesne* буквално означава "кафе-мляко". Баският образува така много сложни думи, без тире и с основната дума накрая.

## Други напитки

| Euskera | Български |
|---|---|
| *ura* | водата |
| *zumoa* | сок |
| *esnea* | млякото |
| *ardoa* | вино |
| *ardo gorria* | червено вино |
| *ardo zuria* | бяло вино |
| *garagardoa* | бира |
| *zuritoa* | малка бира (типична) |
| *sagardoa* | сидър |
| *txakolina* | чаколи (баско бяло вино) |
| *patxarana* | пачаран (ликьор от трънки) |

> Три любопитни думи: **sagardo** (сидър) = *sagar* (ябълка) + *ardo* (вино); **garagardo** (бира) = *garagar* (ечемик) + *ardo*; **txakolina** е младо и леко бяло вино, запазена марка на Euskadi.

## Основни храни в бара

За към напитката:

| Euskera | Български |
|---|---|
| *ogia* | хлябът |
| *gazta* | сирене |
| *urdaiazpikoa* | шунка |
| *tortilla* | тортия (картофен омлет) |
| *patata frijituak* | пържени картофи |
| *gozokia* | сладкиш (общо) |
| *txokolatea* | шоколад |

## Членът `-a`

Почти всички тези думи получават **`-a`** накрая, когато се появяват "неутрално" в изречение: това е членът.

- *Ardoa gustatzen zait.* — Харесвам виното.
- *Ura nahi dut.* — Искам вода.

Когато поръчваш "едно", `-a` изчезва и се появява **bat** ("един/една/едно"):

- *Kafe **bat**, mesedez.* — Едно кафе, моля.
- *Garagardo **bat**.* — Една бира.

> В урок 3 ще видиш това подробно. Засега запомни формите с `-a`, за да ги разпознаваш в менюто на бара.
