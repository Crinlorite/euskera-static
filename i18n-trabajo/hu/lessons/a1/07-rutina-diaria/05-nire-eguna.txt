Ez a lecke összekapcsolja az egység minden elemét: az időt, a napszakokat, a napi rutin igéit és a gyakoriságot. A cél az, hogy elejétől a végéig baszkul el tudd mesélni a teljes napodat.

## A kulcskérdés: "Zer ordutan…?"

| Kérdés | Magyar |
|---|---|
| *Zer ordutan esnatzen zara?* | Hány órakor ébredsz? |
| *Zer ordutan jaikitzen zara?* | Hány órakor kelsz fel? |
| *Zer ordutan gosaltzen duzu?* | Hány órakor reggelizel? |
| *Zer ordutan bazkaltzen duzu?* | Hány órakor ebédelsz? |
| *Zer ordutan ateratzen zara etxetik?* | Hány órakor indulsz el otthonról? |
| *Zer ordutan afaltzen duzu?* | Hány órakor vacsorázol? |
| *Zer ordutan oheratzen zara?* | Hány órakor fekszel le? |

> Figyelj a segédige váltására: *esnatzen **zara*** (NOR), de *gosaltzen **duzu*** (NOR-NORK). Egyre jobban észre kell venned az ige + segédige párokat.

## "X órakor" — hogyan mondd

Az "X órakor" válaszhoz vedd a többes számú órát, és cseréld az *-ak* végződést **-etan** végződésre (közbeékelt `-e-` hanggal, kivéve, ha eleve magánhangzóra végződik):

| Óra | "…órakor" |
|---|---|
| zazpiak (hét óra) | **zazpietan** |
| zortziak | **zortzietan** |
| hamarrak | **hamarretan** |
| hamabiak | **hamabietan** |
| ordu bata (egy óra) | **ordu batean** (egyes szám, megtartja az alakját) |
| ordu biak | **ordu bietan** |
| bost eta erdiak | **bost eta erdietan** (fél hatkor) |
| zortziak laurden gutxi | **zortziak laurden gutxitan** (háromnegyed nyolckor) |

## Egy teljes nap — minta

Olvasd el ezt a példaszöveget, és figyeld meg, hogyan kapcsolódnak egymáshoz az elemek:

> *Ni goizeko zazpietan esnatzen naiz. Poliki-poliki altxatzen naiz eta komunera joaten naiz. Dutxa bat hartzen dut, arropa janzten dut eta sukaldera joaten naiz. Sukaldean gosaria prestatzen dut eta lasai-lasai gosaltzen dut. Ondoren, etxetik ateratzen naiz eta lanera joaten naiz. Eguerdiko ordu bietan bazkaltzen dut. Arratsaldean batzuetan zinemara joaten naiz, beste batzuetan lagunekin egoten naiz. Gauean, etxean afaltzen dut, telebista ikusten dut eta hamaiketan oheratzen naiz.*

Hozzávetőleges fordítás:
> *Reggel hétkor ébredek. Lassan felkelek, és kimegyek a fürdőszobába. Lezuhanyozom, felöltözöm, és kimegyek a konyhába. A konyhában elkészítem a reggelit, és nyugodtan megreggelizem. Aztán elindulok otthonról, és munkába megyek. Délben kettőkor ebédelek. Délután néha moziba megyek, máskor a barátaimmal vagyok. Este otthon vacsorázom, tévét nézek, és tizenegykor lefekszem.*

## Állítsd össze a sajátodat

Kövesd ezt a sablont a saját valódi adataiddal. Ez a legjobb módja a tanultak rögzítésének:

1. **Hány órakor ébredsz:** *Goizeko ___etan esnatzen naiz.*
2. **Mit csinálsz felkelés után:** *... dutxatzen naiz / gosaltzen dut / ...*
3. **Hogyan jutsz el a munkába vagy az iskolába:** *... oinez / autoz / autobusez joaten naiz.*
4. **Mit csinálsz délután:** *Arratsaldean ...*
5. **Hány órakor vacsorázol és fekszel le:** *Gaueko ___etan afaltzen dut eta ___etan oheratzen naiz.*

## Hasznos kötőszavak

- *Lehenengo* — először
- *Gero / Ondoren* — aztán, utána
- *Eta gero* — és aztán
- *Azkenik* — végül
- *Egunero* — minden nap
- *Batzuetan / Beste batzuetan* — néha / máskor
- *Beti* — mindig
- *Inoiz ez* — soha
