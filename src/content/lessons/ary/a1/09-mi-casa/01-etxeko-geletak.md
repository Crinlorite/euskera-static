غادي نبداو بالحاجة الأساسية ف أي دار: **البيوت**. الكلمة العامة ديال "بيت / قاعة" هي **gela**، وأغلب السميات ديال البيوت كيتصاوبو بلصق جذر مع `-gela`.

## المفردات الأساسية

| الباسكية | الدارجة |
|---|---|
| *etxea* | الدار |
| *pisua* | الأپارتمان (سكنى ف عمارة) |
| *gela* | بيت / قاعة |
| *sukaldea* | الكوزينة |
| *logela* | بيت النعاس |
| *komuna* | الحمام / بيت الما |
| *egongela* | الصالون |
| *sarrera* | المدخل |
| *korridorea* / *pasabidea* | الكولوار |
| *balkoia* | البالكون |
| *terraza* | التيراس |

## كيفاش كيتصاوبو شي سميات

الباسكية واضحة بزاف ف هاد الكلمات. إلا شفتي كيفاش مركبين، غادي تعقل عليهم مزيان:

- **logela** → *lo* (النعاس) + *gela* (بيت) = "بيت النعاس" → بيت النعاس
- **egongela** → *egon* (يكون / يقعد) + *gela* = "بيت القعدة" → الصالون
- **sukaldea** → *su* (العافية) + *aldea* (جهة) = "جهة العافية" → الكوزينة

> **Komuna** و **bainugela** عندهم نفس المعنى: *komuna* هي الكلمة اليومية، و *bainugela* (حرفيا "بيت الدوش") شوية رسمية.

## العمارة: الطابق والأسانسور

| الباسكية | الدارجة |
|---|---|
| *solairua* | الطابق (1، 2…) |
| *igogailua* | الأسانسور |
| *eskailera* | الدروج |
| *ataria* | باب العمارة |

باش تقول ف أشمن طابق ساكن:

- *Hirugarren solairuan bizi naiz.* — ساكن ف الطابق التالت.
- *Etxeak igogailua du.* — الدار فيها الأسانسور.

## أسئلة نافعة

- **Zenbat gela ditu zure etxeak?** — شحال فيها من بيت الدار ديالك؟
- **Zenbat logela ditu?** — شحال فيها من بيت النعاس؟
- **Non dago sukaldea?** — فين جات الكوزينة؟
- **Etxeak badu balkoirik?** — واش الدار فيها البالكون؟

> **ملاحظة ثقافية:** ف ناڤارا والمنطقة اللي بين الباسك وقشتالة، الناس كيقولو عادة *pisua* للسكنى ف المدينة و *etxea* لدار العائلة / دار البلاد. ف الحياة اليومية كيخلطوهم بلا مشكل.
