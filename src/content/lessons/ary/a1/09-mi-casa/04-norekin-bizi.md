واحد من الأسئلة الأساسية باش تتعرف على شي حد هو **Norekin bizi zara?** — "مع منين ساكن؟". الجواب كيستعمل اللاحقة **`-(r)ekin`**، اللي كتسمى **ديال المصاحبة**، وهي "مع" ديال الصحبة فالباسكية.

## اللاحقة `-rekin`

كتزاد للاسم، مع أداة التعريف ديالو:

| الاسم | + -(r)ekin | المعنى |
|---|---|---|
| laguna (الصاحب/الصاحبة) | **lagunarekin** | مع الصاحب/الصاحبة |
| ama (الأم) | **amarekin** | مع الأم |
| anaia (الخو) | **anaiarekin** | مع الخو |
| txakurra (الكلب) | **txakurrarekin** | مع الكلب |
| bikotekidea (الشريك) | **bikotekidearekin** | مع الشريك |

> مع الأسماء العلم ومع *bat* كتزاد **-(e)kin** نيشان، بلا أداة التعريف: *Miren + ekin → Mirenekin* (مع Miren)، *lagun batekin* (مع واحد صاحبي).

## الجمع

| الجمع | + -ekin | المعنى |
|---|---|---|
| gurasoak (الوالدين) | **gurasoekin** | مع الوالدين |
| lagunak (الصحاب) | **lagunekin** | مع الصحاب |
| pisukideak (اللي شاركين الشقة) | **pisukideekin** | مع اللي شاركين الشقة |
| seme-alabak (الولاد) | **seme-alabekin** | مع الولاد |

## تسكن بوحدك

إلا كنتي ساكن بلا حتى واحد، ما محتاجش `-rekin`:

- **Bakarrik bizi naiz.** — ساكن بوحدي.
- **Bakarrik bizi naiz, baina katu batekin.** — ساكن بوحدي، ولكن مع واحد المش.

## أكثر أنواع السكنى

| الحالة | كيفاش كتقال |
|---|---|
| بوحدي | *Bakarrik bizi naiz.* |
| مع الوالدين | *Gurasoekin bizi naiz.* |
| مع الشريك | *Bikotekidearekin bizi naiz.* |
| مع الراجل / المرا | *Senarrarekin / Emaztearekin bizi naiz.* |
| مع اللي شاركين الشقة | *Pisukideekin bizi naiz.* |
| مع الولاد | *Seme-alabekin bizi naiz.* |
| مع صاحب / صحاب | *Lagun batekin / Lagunekin bizi naiz.* |

## الكرا ولا الملك

- **Alokairuan bizi naiz.** — ساكن بالكرا.
- **Nire pisua da.** — الشقة ديالي (ملك).
- **Errenta gora doa.** — الكرا كيطلع. *(عامية)*

## محادثة نموذجية

> — *Kaixo Maialen! Norekin bizi zara?*
>
> — *Bi pisukiderekin bizi naiz Iruñean. Eta zu?*
>
> — *Ni bakarrik, baina txakur batekin. Etxea handia da?*
>
> — *Ez, txikia. Hiru logela ditu.*

> **ملاحظة:** *bikotekide* كلمة جديدة ومحايدة، كتصلح للمزوجين وغير المزوجين، كيفما كان النوع. أما "الراجل" و"المرا" (الزوج والزوجة) باقي كيستعملو **senarra** و **emaztea**.
