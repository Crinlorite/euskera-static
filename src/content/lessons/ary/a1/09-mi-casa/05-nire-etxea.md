هاد الدرس كيجمع كلشي ديال الموضوع 9: البيوت، الأثاث، شغل الدار ومع من ساكن. الهدف هو تقدر **توصف الدار ديالك** بجمل ساهلة، بحال يلا كانو كيسولوك فالقسم ولا فشي هضرة عادية.

## الأسئلة الأساسية

| السؤال | الدارجة |
|---|---|
| *Non dago zure etxea?* | فين كاينة الدار ديالك؟ |
| *Nolakoa da?* | كيفاش دايرة؟ |
| *Zenbat gela ditu?* | شحال من بيت فيها؟ |
| *Norekin bizi zara?* | مع من ساكن؟ |
| *Zenbatgarren solairuan bizi zara?* | فأشمن طابق ساكن؟ |
| *Etxeak badu igogailua / balkoia / terraza?* | واش الدار فيها السانسور / البالكون / التيراس؟ |

## صفات نافعة باش توصف الدار

| الباسكية | الدارجة |
|---|---|
| *handia* | كبيرة |
| *txikia* | صغيرة |
| *argitsua* | فيها الضو |
| *iluna* | مظلمة |
| *berria* | جديدة |
| *zaharra* | قديمة |
| *lasaia* | هادية |
| *zaratatsua* | فيها الصداع |
| *erosoa* | مريحة |
| *garestia* | غالية |
| *merkea* | رخيصة |

> عقل على النمط **NOLAKOA da?** اللي شفنا فوحدات أخرين: الجواب فيه الصفة + `-a` فالتالي + الفعل *izan*. مثال: *Nire etxea **handia da**.* — الدار ديالي كبيرة.

## فقرة نموذجية

ها نص ساهل كيوصف دار. قراه بصوت عالي ورد البال للأنماط.

> *Ni Iruñean bizi naiz, auzo lasai batean. Nire etxea ez da oso handia: hiru gela ditu — bi logela eta egongela bat — sukaldea eta komuna. Egongela argitsua da, eta balkoi bat dauka. Hirugarren solairuan dago, eta etxeak igogailua du.*
>
> *Bikotekidearekin bizi naiz. Berak bazkaria prestatzen du, eta nik ontziak garbitzen ditut. Asteburuetan biok elkarrekin egiten dugu erosketa.*

## دورك: وصف الدار ديالك

بني الفقرة ديالك وجاوب بهاد الترتيب:

1. **Non bizi zara?** (فين ساكن؟) → *X-(e)an bizi naiz.*
2. **Nolakoa da etxea?** (كيفاش دايرة؟) → *Nire etxea handia / argitsua / lasaia da.*
3. **Zenbat gela ditu?** (شحال من بيت؟) → *Bi / Hiru / Lau gela ditu.*
4. **Zer dago etxean?** (شنو كاين؟) → *Sukaldea, egongela, bi logela eta komun bat ditu.*
5. **Norekin bizi zara?** → *Bakarrik / Gurasoekin / Lagunekin bizi naiz.*
6. **Etxeko lanak nork egiten ditu?** → *Nik egunero garbitzen dut* / *Pisukideen artean banatzen ditugu.*

## مفردات الختام

| الباسكية | الدارجة |
|---|---|
| *etxebizitza* | السكن |
| *etxejabea* | مول الدار |
| *alokairua* | الكرا |
| *errenta* | الكرا ديال الشهر |
| *auzoa* | الحومة |
| *erdigunea* | وسط المدينة |
| *aldiriak* | الضواحي / برا المدينة |

> **نصيحة:** ملي تهضر على الدار ديالك فالقسم، ما تحاولش تترجم كل تفصيلة. خلي جمل قصيرة ومزيانة. *"Bi logela ditut, sukalde txiki bat eta egongela handia"* وصف حسن من جملة طويلة عامرة بالغلطات.
