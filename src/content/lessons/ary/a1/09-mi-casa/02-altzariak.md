كل بيت عندو الأثاث ديالو. الكلمة العامة ديال "أثاث" هي **altzaria** (فالجمع *altzariak*). يالله نداورو فالدار بيت ببيت.

## Egongelan — فالصالون

| الباسكية | الدارجة |
|---|---|
| *sofa* | كنبة |
| *besaulkia* | فوطوي |
| *mahaia* | طبلة |
| *aulkia* | كرسي |
| *kuxina* | مخدة |
| *lanpara* | لامبة |
| *telebista* | تلفازة |
| *apalategia* | رفوف |

## Logelan — فبيت النعاس

| الباسكية | الدارجة |
|---|---|
| *ohea* | ناموسية |
| *gau-mahaia* | طبلة حدا الناموسية |
| *armairua* | دولاب |
| *iratzargailua* | منبه |
| *ordenagailua* | بيسي / حاسوب |
| *posterra* | بوسطير |

| الباسكية | الدارجة |
|---|---|
| *hozkailua* | فريجيدير |
| *labea* | فران |

| الباسكية | الدارجة |
|---|---|
| *dutxa* | دوش |
| *bainuontzia* | بانيو |
| *konketa* | لافابو |
| *ispilua* | مراية |
| *eskuoihala* | فوطة |
| *komuneko papera* | كاغط ديال الطواليط |

## كيفاش تجمعهم فجملة

عقل على داكشي اللي كتعرف على **ukan** (عندو) وطبقو:

- *Sukaldean hozkailu bat dut.* — فالكوزينة عندي فريجيدير.
- *Egongelan bi besaulki ditugu.* — فالصالون عندنا جوج فوطويات.
- *Logelan ez dut posterrik.* — فبيت النعاس ما عنديش بوسطيرات. *(النفي ب `-rik`)*

> **ملاحظة:** *garbigailua* (مكينة التصبين) و *ontzi-garbigailua* (مكينة المواعن) فيهم نفس الجذر *garbi-* (نقي / نضف). هادا مثال مزيان على كيفاش الباسكية كتبني كلمات مركبة واضحة بزاف.
