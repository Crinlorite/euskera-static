فهاد الدرس غادي تتعلم الأفعال الأساسية باش تهضر على **etxeko lanak** (خدمة الدار). فالباسكية، الأفعال غالباً كتجي فشكل **participio** (`-tu`، `-i`، `-n`)، وهو الشكل ديال "القاموس": *garbitu*، *prestatu*، *jaso*…

## الأفعال المهمين

| الباسكية (Euskera) | الدارجة |
|---|---|
| *garbitu* | نقّى |
| *prestatu* | وجّد |
| *jaso* | جمع / رتّب |
| *jantzi* | لبس / حطّ |
| *atera* | خرّج |
| *zabaldu* | نشر / حلّ |
| *lisatu* | دوّز الحديدة |
| *paseatu* | سارا |
| *erosi* | شرا |

## الخدمات المعروفين

| الخدمة | كيفاش كتقال |
|---|---|
| وجّد الناموسية | *ohea jantzi* |
| غسل الماعن | *ontziak garbitu* / *harrikoa egin* |
| دوّز الأسبيراتور | *xurgagailua pasa* |
| نشر الحوايج | *arropa zabaldu* |
| دوّز الحديدة على الحوايج | *arropa lisatu* |
| نقّى الطواليط | *komuna garbitu* |
| خرّج الزبل | *zaborra atera* |
| وجّد الماكلة | *bazkaria prestatu* |
| تقضّى | *erosketak egin* |
| خرّج الكلب يتسارا | *txakurra paseatu* |

## من شكل القاموس للحاضر ديال العادة

ملي كتكون شي حاجة كتعاود ديما (كل نهار، كل سيمانة…)، الفعل كيتبدل للشكل بـ `-tzen` + المساعد **dut/duzu/du…** (اللي عارفو من *ukan*):

| الضمير | مثال | الدارجة |
|---|---|---|
| Nik | *Nik etxea **garbitzen dut**.* | أنا كننقّي الدار. |
| Zuk | *Zuk arropa **lisatzen duzu**.* | نتا كتدوّز الحديدة على الحوايج. |
| Berak | *Aitak bazkaria **prestatzen du**.* | بابا كيوجّد الماكلة. |
| Guk | *Guk erosketak **egiten ditugu**.* | حنا كنتقضّاو. |

> فهاد الدرس ماشي ضروري تحفظ التصريف كامل. شد غير القاعدة **`-tzen` + dut/du** باش تهضر على الروتين.

## شحال من مرة

باش تقول شحال من مرة كدير شي خدمة:

- **egunero** — كل نهار
- **astean behin** — مرة فالسيمانة
- **astean bitan / hirutan** — جوج / تلاتة ديال المرات فالسيمانة
- **noizean behin** — مرة مرة
- **inoiz ez** — عمرّ

> *Nire etxean nik **astean behin** lisatzen dut, baina **egunero** garbitzen dut sukaldea.* — فدارنا كندوّز الحديدة مرة فالسيمانة، ولكن كننقّي الكوزينة كل نهار.

## تسوّل شكون كيدير شنو

- **Nork garbitzen ditu ontziak?** — شكون كيغسل الماعن؟
- **Nor arduratzen da arropaz?** — شكون اللي متكلف بالحوايج؟
- **Zuri gustatzen zaizu sukaldatzea?** — واش كيعجبك تطيّب؟

> **ملاحظة ثقافية:** الاستطلاعات على تقسيم خدمة الدار حاجة معروفة بزاف فكتب الـ euskaltegi — وعندها السبب ديالها. هادي مفردات نافعة بزاف فالهضرة الحقيقية مع الصحاب والعائلة.
