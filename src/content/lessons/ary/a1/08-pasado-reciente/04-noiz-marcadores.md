باش تحكي مزيان شنو وقع، خاصك تقول **إمتا**. هاد الدرس كيعطيك الكلمات اللي كيتجمعو مع الماضي القريب باش تحدد الأفعال فالوقت.

## الكلمات الأساسية

| الباسكية | الدارجة |
|---|---|
| *gaur* | اليوم |
| *atzo* | البارح |
| *bihar* | غدا |
| *etzi* | بعد غدا |
| *orain* | دابا |
| *oraintxe* | دابا نيت |
| *lehen* | قبل |
| *gero* | من بعد |

> إلا ردّيتي البال، *atzo* (البارح) و *bihar* (غدا) كلمات قصار بزاف كيتحفظو دغيا. *Etzi* (بعد غدا) كلمة وحدة، بحال "بعد غدا" فالدارجة ولكن غير فكلمة وحدة — هدية صغيرة من الباسكية.

## التجميع مع أوقات النهار

هاد الكلمات كيتجمعو مع *goizean*، *arratsaldean*، *gauean* وصحابهم من الوحدة اللي فاتت. القاعدة هي: **كلمة الوقت + جزء من النهار**.

| الباسكية | الدارجة |
|---|---|
| *gaur goizean* | هاد الصباح / اليوم فالصباح |
| *gaur eguerdian* | اليوم فالقيلولة (نص النهار) |
| *gaur arratsaldean* | هاد العشية |
| *gaur gauean* | هاد الليلة |
| *atzo goizean* | البارح فالصباح |
| *atzo arratsaldean* | البارح فالعشية |
| *atzo gauean* | البارح فالليل |
| *bihar goizean* | غدا فالصباح |

> **رد البال:** *gaur gauean* هي "هاد الليلة" (الليلة اللي جاية ولا اللي نتا فيها)؛ *atzo gauean* هي "البارح فالليل". الباسكية كتفرّق مزيان.

## التكرار والمرات

| الباسكية | الدارجة |
|---|---|
| *behin* | مرة وحدة |
| *bi aldiz* | جوج مرات |
| *hiru aldiz* | تلاتة ديال المرات |
| *askotan* | بزاف ديال المرات، غالبا |
| *batzuetan* | شي مرات |
| *inoiz ez* | عمرو |
| *gaur goizetik* | من هاد الصباح |
| *aste honetan* | هاد السيمانة |
| *hilabete honetan* | هاد الشهر |

## جمل بالماضي القريب والكلمات ديال الوقت

> *Gaur goizean lanera joan naiz autoz.* — هاد الصباح مشيت للخدمة فالطوموبيل.
>
> *Gaur arratsaldean Mikelekin egon naiz.* — هاد العشية كنت مع Mikel.
>
> *Gaur oso berandu esnatu naiz.* — اليوم فقت معطل بزاف.
>
> *Gaur eguerdian etxean bazkaldu dut.* — اليوم فالقيلولة تغديت فالدار.
>
> *Aste honetan bi aldiz egon naiz zinean.* — هاد السيمانة مشيت للسينما جوج مرات.

## الترتيب ديال الجملة

فالباسكية الترتيب العادي ديال جملة فيها كلمة ديال الوقت هو:

> **إمتا + فين + شنو + الفعل**

> **Gaur goizean** + **euskaltegian** + **euskara** + **ikasi dut**. — هاد الصباح قريت الباسكية فالـeuskaltegi.

ماشي هادي هي الطريقة الوحيدة — الباسكية كتخليك تحرك العناصر باش تأكد على شي حاجة — ولكن إلا تبعتي هاد الترتيب ما غاديش تغلط.

## حوار صغير

> *— Eta gaur zer egin duzu, Maialen?*
>
> *— **Gaur goizean** lanera joan naiz oinez. **Eguerdian** lagunekin bazkaldu dut tabernan. **Arratsaldean** etxera bueltatu naiz eta liburua irakurri dut. **Gauean** ez dut afaldu, asko jan baitut bazkarian.*

> **ملاحظة:** *gaur* كتشمل النهار كامل ديال اليوم. إلا بغيتي تدقق، زيد الوقت (*gaur goizean*، *gaur arratsaldean*). فالهضرة العادية، *Zer egin duzu gaur?* كتفهم بحال "شنو درتي اليوم بصفة عامة؟".
