**الأفعال المتعدية** هوما اللي عندهم مفعول: شي واحد كياكل *شي حاجة*، كيشوف *شي حاجة*، كيقرا *شي حاجة*. فالباسكية هاد الأفعال كتستعمل المساعد **ukan** (dut, duzu, du…). فالماضي القريب، القاعدة هي:

> **partizipioa + dut/duzu/du/dugu/duzue/dute**

## الأفعال المتعدية الأساسية

| Partizipioa | أنا (…ت) | الدارجة |
|---|---|---|
| *jan* | **jan dut** | كليت |
| *edan* | **edan dut** | شربت |
| *ikusi* | **ikusi dut** | شفت |
| *irakurri* | **irakurri dut** | قريت |
| *entzun* | **entzun dut** | سمعت |
| *erosi* | **erosi dut** | شريت |
| *egin* | **egin dut** | درت |
| *hartu* | **hartu dut** | شديت / خديت |
| *ekarri* | **ekarri dut** | جبت |
| *eraman* | **eraman dut** | ديت |
| *ikasi* | **ikasi dut** | تعلمت / قريت |
| *eskatu* | **eskatu dut** | طلبت |
| *ordaindu* | **ordaindu dut** | خلصت |
| *idatzi* | **idatzi dut** | كتبت |
| *prestatu* | **prestatu dut** | وجدت |
| *garbitu* | **garbitu dut** | نقيت |
| *gosaldu* | **gosaldu dut** | فطرت |
| *bazkaldu* | **bazkaldu dut** | تغديت |
| *afaldu* | **afaldu dut** | تعشيت |
| *lan egin* | **lan egin dut** | خدمت |

## التصريف الكامل مع فعل واحد

ناخدو *ikusi* (شاف) كمثال:

| الضمير + الفاعل | الشكل | الدارجة |
|---|---|---|
| Nik | **ikusi dut** | شفت |
| Zuk | **ikusi duzu** | شفتي |
| Hark | **ikusi du** | شاف (هو/هي) |
| Guk | **ikusi dugu** | شفنا |
| Zuek | **ikusi duzue** | شفتو |
| Haiek | **ikusi dute** | شافو |

> الفاعل ديال الأفعال المتعدية كياخد العلامة **NORK** (-k): *nik, zuk, hark, guk, zuek, haiek*. غادي تشوفها بزاف، خصوصا ملي يكون الفاعل اسم: *Mikelek* (ميكيل…)، *Maialenek* (مايالين…). إلا تلفتي، فـ A1 تقدر تحيد الضمير وتخلي غير الفعل: السياق كافي.

## جمل معروفة

- *Gaur goizean egunkaria irakurri dut.* — هاد الصباح قريت الجريدة.
- *Bazkaltzeko arraina jan dut.* — فالغدا كليت الحوت.
- *Lagunekin kafea hartu dut.* — شربت القهوة مع صحابي.
- *Mikelek ardoa erosi du.* — ميكيل شرا الشراب.
- *Guk pelikula bat ikusi dugu.* — شفنا واحد الفيلم.
- *Haiek euskara ikasi dute gaur.* — قراو الباسكية اليوم.

## النفي

باش تقول "ما درتش X"، **ez** كتجي قبل المساعد:

> *Ez dut bazkaldu.* — ما تغديتش.
>
> *Ez du egunkaria irakurri.* — ما قراش الجريدة.
>
> *Ez dugu ardorik edan.* — ما شربناش الشراب. (رد البال لـ *ardorik*: مع النفي، المفعول غالبا كياخد **-rik** التجزيئية.)

## حوار صغير

> *— Zer afaldu duzu gaur, Maialen?*
>
> *— Entsalada eta arraina jan dut, eta postrerako jogurta hartu dut. Eta zuk?*
>
> *— Nik tortilla egin dut, baina ez dut postrerik jan.*

> **ملخص:** إلا كان الفعل عندو مفعول ظاهر ولا ضمني (كلا شي حاجة، شاف شي حاجة، دار شي حاجة)، المساعد هو **dut** (ومشتقاتو). حفظ هاد الأزواج فعل-مساعد والباقي غادي يجي بوحدو.
