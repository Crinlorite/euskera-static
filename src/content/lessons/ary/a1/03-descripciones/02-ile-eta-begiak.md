باش توصف الشعر والعينين بالباسكية، ما كنستعملوش **izan** ("كون")، ولكن كنستعملو **ukan** ("عند")، بحال فالدارجة: *عندي شعر كحل*، *عندي عينين زرقين*.

## الشعر: ile

الكلمة ديال "الشعر" هي **ile** (مع الأداة: *ilea*). الصفات كتجي من بعد، وغير الصفة الأخيرة اللي كتاخد العلامة `-a`:

| الباسكية | الدارجة |
|---|---|
| *ile beltza* | شعر كحل |
| *ile horia* | شعر أشقر |
| *ile zuria* | شعر بيض / شايب |
| *ile gorria* | شعر حمر |
| *ile urdina* | شعر رمادي |
| *ile motza* | شعر قصير |
| *ile luzea* | شعر طويل |
| *ile lisoa* | شعر سبيبي (ناعم) |
| *ile kizkurra* | شعر مكرد |

> الشعر فالباسكية كيتعامل معاه بحال **المفرد**، بحال فالدارجة. على هاد الشي كنستعملو *dut* / *du* (ماشي *ditut* / *ditu*).

- *Ile beltza eta luzea **dut**.* — عندي شعر كحل وطويل.
- *Maialenek ile kizkurra **du**.* — Maialen عندها شعر مكرد.

## العينين: begiak

ماشي بحال الشعر، "العينين" فالجمع **plural** (*begiak*). إذن الصفات حتى هي كتكون فالجمع (`-ak`) وكنستعملو **ditut / ditu**:

| الباسكية | الدارجة |
|---|---|
| *begi urdinak* | عينين زرقين |
| *begi marroiak* | عينين قهويين |
| *begi berdeak* | عينين خضرين |
| *begi beltzak* | عينين كحلين |
| *begi argiak* | عينين فاتحين |
| *begi ilunak* | عينين غامقين |

- *Begi urdinak **ditut**.* — عندي عينين زرقين.
- *Mikelek begi marroiak **ditu**.* — Mikel عندو عينين قهويين.

## صفات أخرى: اللاحقة -dun

باش تقول "اللي لابس X" ولا "ب X"، الباسكية عندها لاحقة كتستعمل بزاف: **-duna** (المفرد) / **-dunak** (الجمع). كتزاد للاسم والشخص كيولي "مول النظاضر"، "مول اللحية"...

| الباسكية | الدارجة |
|---|---|
| *betaurrekoduna* | بنظاضر / مول النظاضر |
| *bizarduna* | بلحية |
| *biboteduna* | بشلاغم |
| *burusoila* | صلع (حرفيا "راس مقشر") |

هادو كيمشيو مع **izan**، حيت كيوصفو صفة بحال النعت:

- *Hura biboteduna da.* — هو عندو الشلاغم.
- *Nire aitona burusoila da.* — جدي صلع.

## نجمعو كلشي

الوصف العادي كيخلط بزاف ديال التراكيب:

> *Maialen txikia eta argala da. Ile gorria eta kizkurra du. Begi berdeak ditu. Betaurrekoduna da.*
>
> Maialen قصيرة ورقيقة. عندها شعر حمر ومكرد. عندها عينين خضرين. لابسة نظاضر.

شوف كيفاش كيتقسم: **izan** للصفات العامة (*txikia da*)، **ukan** للشعر والعينين (*ile … du*، *begi … ditu*)، و *-dun*-a عاوتاني مع **izan** للإكسسوارات.
