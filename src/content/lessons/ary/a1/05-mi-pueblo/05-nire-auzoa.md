هاد الدرس كيجمع كلشي ديال الوحدة: مفردات البلايص، اللاحقة ديال المكان `-(e)an`، المواقع (*aurrean*، *ondoan*…)، والفرق بين **كاين / فين كاين** (*badago* / *dago*). ملي تكمل، غادي تقدر توصف الحومة ولا الدوار ديالك بجمل حقيقية.

## الترتيب ديال الوصف

الوصف العادي ديال حومة ولا دوار كيمشي بهاد الترتيب:

1. **كيف داير** المكان (الحجم، الطابع): *Nire auzoa txikia eta polita da.*
2. **شنو كاين** وشنو ما كاينش: *Auzoan badago liburutegia, baina ez dago zinemarik.*
3. **فين كاينة** كل حاجة مهمة: *Liburutegia plazaren ondoan dago.*
4. **فين ساكن نتا** ومع من: *Ni Maialenen ondoan bizi naiz, etxe txiki batean.*

## مفردات الوصف

| الباسكية | الدارجة |
|---|---|
| *handi* | كبير |
| *txiki* | صغير |
| *ertain* | متوسط |
| *polit* | زوين |
| *itsusi* | خايب |
| *zaharra* | قديم |
| *berria* | جديد |
| *lasai* | هادي |
| *jendetsu* | عامر بالناس |
| *modernoa* | عصري (moderno) |
| *erdigunean* | فوسط المدينة |
| *kanpoaldean* | فالأطراف |

> عقل: الصفات فالباسكية كيجيو **من مور الاسم** وكيزادلهم أداة التعريف `-a`. *Auzo + handi + a* → *auzo handia* ("الحومة الكبيرة")؛ *auzo + txiki + a* → *auzo txikia*.

## نجمعو كلشي: مثال نموذجي

> *Ni Iruñean bizi naiz, Txantrea auzoan. Auzoa ez da oso handia, baina lasaia eta polita da. Auzoan badago supermerkatu txiki bat, bi taberna eta okindegi bat. Eskola plazaren ondoan dago, eta liburutegia eskolaren atzean. Parkea handia da, eta umeentzat oso ona. Auzoan ez dago zinemarik, baina hori ez da arazoa: zinema erdigunean dago, eta gertu dago. Nire etxea bigarren solairuan dago, kale lasai batean.*

ترجمة حرة:

> ساكن فبامبلونا، فحومة Txantrea. الحومة ماشي كبيرة بزاف، ولكن هادية وزوينة. فالحومة كاين سوبرمارشي صغير، جوج بارات ومخبزة. المدرسة حدا الساحة، والمكتبة مور المدرسة. الجردة كبيرة، ومزيانة بزاف للدراري. فالحومة ما كاينش سينما، ولكن هادشي ماشي مشكل: السينما فوسط المدينة، وقريبة. الدار ديالي فالطابق الثاني، فزنقة هادية.

## الأسئلة اللي غادي يطرحو عليك

| السؤال | نوع الجواب |
|---|---|
| ***Non bizi zara?*** | مكان + لاحقة المكان: *X-(e)an bizi naiz.* |
| ***Nolakoa da zure auzoa?*** | صفات: *Polita da, txikia da…* |
| ***Zer dago zure auzoan?*** | الوجود: *Badago…, badaude…* |
| ***Ba al dago tabernarik?*** | إيه/لا: *Bai, badago / Ez, ez dago tabernarik.* |
| ***Non dago liburutegia?*** | الموقع: *Plazaren ondoan dago.* |

## دابا دورك

تخيل بلي صاحبك ما كيعرفش الحومة ديالك. وصف:

1. شنو سميتها وفين كاينة.
2. واش كبيرة ولا صغيرة، قديمة ولا عصرية.
3. شنو هوما تلاتة ديال البلايص اللي **كاينين** (بـ *badago / badaude*).
4. شنو هوما تلاتة ديال الحوايج اللي **ما كاينينش** (بـ *ez dago … rik*).
5. فين كاينة الدار ديالك بالضبط (الزنقة، الطابق، حدا شنو).

> **ملاحظة ثقافية:** بزاف ديال الحومات والدواوير الباسكية عندهم كمرجع **frontoia** (ملعب البيلوطا) و**eliza** (الكنيسة)، غالبا واحد حدا الآخر وقراب من الساحة الكبيرة. إلا كانت فالحومة ديالك ساحة، frontón ولا كنيسة، راه أحسن مرجع باش توجه شي واحد.
