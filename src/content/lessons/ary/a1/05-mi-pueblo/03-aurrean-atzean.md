منين كتعرف تقول "راه ف X"، الخطوة الجاية هي تقول **فين بالضبط**: فوق، تحت، حدا، ور… فالباسكية هاد البلايص ديما كيتبناو بهاد الشكل: **البلاصة المرجعية + البلاصة**.

## البلايص الأساسية

| الباسكية | الدارجة |
|---|---|
| *aurrean* | قدام |
| *atzean* | ور |
| *ondoan* | حدا |
| *gainean* | فوق، على |
| *azpian* | تحت |
| *artean* | بين |
| *ezkerrean* | على اليسار |
| *eskuinean* | على اليمين |
| *barruan* | لداخل |
| *kanpoan* | برا |
| *erdian* | فالوسط |

## كيفاش تبنيهم: -(r)en + البلاصة

القاعدة الأساسية هي **(المرجع)-(r)en + البلاصة**. المرجع كياخد الإضافة `-(r)en` (اللي كتقابل "ديال" فالدارجة):

| الباسكية | الدارجة (حرفيا) |
|---|---|
| **mahaiaren gainean** | فوق الطبلة (حرفيا "ديال الطبلة، فوق") |
| **etxearen aurrean** | قدام الدار |
| **elizaren atzean** | ور الكنيسة |
| **parkearen ondoan** | حدا الجردة |
| **kutxaren barruan** | لداخل الصندوق |
| **bi mendien artean** | بين جوج جبال |

القاعدة: المرجع كيجي هو الأول، **من بعد** البلاصة. يعني بالمقلوب على الدارجة.

## أمثلة كاملة

- **Liburua mahaiaren gainean dago.** — الكتاب فوق الطبلة.
- **Katua aulkiaren azpian dago.** — المش تحت الكرسي.
- **Eliza plazaren erdian dago.** — الكنيسة فوسط الساحة.
- **Botika eskolaren ondoan dago.** — الفارماسيان حدا المدرسة.
- **Ni Maiteren eta Anaren artean nago.** — أنا بين Maite و Ana.

## ظروف المكان: hemen / hor / han

باش تشير بالزربة كاينين تلاتة ظروف — ورد البال، هوما **تلاتة ديال المسافات**، ماشي غير جوج:

| الباسكية | الدارجة | فوقاش |
|---|---|---|
| *hemen* | هنا | قريب للي كيهضر |
| *hor* | تما (حداك) | قريب للي كيسمع |
| *han* | لهيه | بعيد على بجوج |

> هاد الظروف التلاتة كيتقابلو مع أسماء الإشارة *hau / hori / hura* ومع الأشكال الطويلة ديالهم ديال المكان *honetan / horretan / hartan* ("فهادا / فداك / فداك البعيد").

أمثلة سريعة:

- **Hemen** taberna bat dago. — هنا كاين واحد البار.
- **Hor** parkea dago. — تما كاينة الجردة.
- **Han** dago euskaltegia. — الـeuskaltegi (مدرسة الباسكية) لهيه.

## حوار صغير: لعبة التخبية

> — *Pilota mahaiaren azpian dago?* — واش الكورة تحت الطبلة؟
>
> — *Ez, pilota ez dago mahaiaren azpian.* — لا، الكورة ماشي تحت الطبلة.
>
> — *Aulkiaren atzean dago?* — واش هي ور الكرسي؟
>
> — *Bai, hor dago!* — إيه، ها هي تما!

> **حيلة:** كاع البلايص فيهم ديجا اللاحقة `-an` (*aurr-ean*، *atz-ean*، *azp-ian*…). ماخصك تزيد والو.
