من غير الوالدين والخوت والولاد، العائلة كتكبر بالعمام والخوال، ولاد العم، ولاد الخوت والنسابة. هنا عندك الكلمات اللي كتستعمل بزاف.

## العمام والخوال وولادهم

| الباسكية | الدارجة |
|---|---|
| *osaba* | عمّ / خال |
| *izeba* | عمّة / خالة |
| *lehengusu* | ولد العم / ولد الخال |
| *lehengusina* | بنت العم / بنت الخال |
| *iloba* | ولد أو بنت الخو/الخت (وفشي لهجات حتى "الحفيد/الحفيدة" — السياق هو اللي كيحدد) |

## النسابة

| الباسكية | الدارجة |
|---|---|
| *aitaginarreba* | الحمو |
| *amaginarreba* | الحماة |
| *koinatu* | النسيب |
| *koinata* | النسيبة |
| *errain* | الكنّة (مرات الولد) |
| *suhi* | النسيب (راجل البنت) |

## أمثلة د الاستعمال

- *Nire osaba Bilbon bizi da.* — عمّي ساكن ف Bilbao.
- *Bere lehengusinak hamabi urte ditu.* — بنت عمّو عندها 12 عام.
- *Zure koinata euskalduna da?* — واش النسيبة ديالك باسكية؟

> الكلمات ديال النسابة بزاف د المرات كيتكوّنو بجمع كلمات موجودة (*aita-* + *ginarreba*). ماشي ضروري تحفظ المنطق ديالها؛ بالاستعمال غادي يتبتو عندك.
