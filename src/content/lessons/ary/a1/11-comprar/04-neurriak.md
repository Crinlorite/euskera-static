إلا عرفتي تطلب كميات محددة، غادي تفرق بين "تفاحة" و"كيلو ديال التفاح". القاعدة فالباسكية منظمة بزاف وديما هي هي.

## القاعدة الأساسية

> **الكمية + السلعة (بلا أداة التعريف)**

| الباسكية | الدارجة |
|---|---|
| *kilo bat sagar* | كيلو ديال التفاح |
| *bi kilo tomate* | جوج كيلو ديال الطماطم |
| *kilo erdi piper* | نص كيلو ديال الفلفل |
| *200 g txorizo* | 200 غرام ديال الشوريسو |
| *litro bat ur* | لتر ديال الما |
| *litro erdi esne* | نص لتر ديال الحليب |
| *dozena bat arrautza* | دزينة ديال البيض |
| *pakete bat makarroi* | باكية ديال المقرونة |
| *botila bat ardo* | قرعة ديال الشراب |
| *lata bat tomate* | علبة ديال الطماطم |

> **رد البال:** السلعة كاتجي **بلا أداة التعريف** (*sagar*، ماشي *sagarra*). هادشي كايتعلم بالتمرين.

## الرقم اللول، السلعة من موراه

الترتيب مهم:

- *Bi kilo sagar* — جوج كيلو ديال التفاح (صحيح)
- ~~Sagar bi kilo~~ — ما كاتقالش هكا

## كميات تقريبية

| الباسكية | الدارجة |
|---|---|
| *gehiago* | كثر |
| *gutxiago* | قل |
| *pixka bat* | شوية |
| *asko* | بزاف |
| *gutxi* | قليل |
| *nahikoa* | كافي |

أمثلة عادية عند مول الفواكه:

- *Gehiago, mesedez.* — زيد شوية، عافاك.
- *Hori da, nahikoa da.* — هادي هي، صافي كافي.
- *Gutxiago, mesedez.* — نقص، عافاك.

## جمل نموذجية

- *Eman kilo bat sagar eta dozena bat arrautza, mesedez.* — عطيني كيلو ديال التفاح ودزينة ديال البيض، عافاك.
- *Litro bat esne hartuko dut.* — غادي ناخد لتر ديال الحليب.
- *Bi botila ur, mesedez.* — جوج قراعي ديال الما، عافاك.

> **ملاحظة ثقافية:** فالأسواق (azoka) والساحات التقليدية مازال كايوزنو كلشي "بالعين": كاتطلب *kilo bat sagar* والبياع كايزيد ولا ينقص حتى يجي الميزان مضبوط. عادي تسمع *pixka bat gehiago, mesedez* والميزان طالع.
