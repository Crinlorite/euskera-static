قبل ما نهضرو على البرامج والأجندة، غادي نراجعو أيام السيمانة ونتعلمو نربطوهم بالأنشطة ديال كل نهار.

## السبع أيام

| الباسكية | الدارجة | تلميح |
|---|---|---|
| *astelehena* | الاثنين | aste + lehen = "أول نهار فالسيمانة" |
| *asteartea* | الثلاثاء | aste + arte = "وسط السيمانة" |
| *asteazkena* | الأربعاء | aste + azken = "آخر نهار فسيمانة الخدمة" (تاريخيا) |
| *osteguna* | الخميس | egun = نهار |
| *ostirala* | الجمعة | فيه نفس الجذر *ortzi/osti-* (السما) بحال *osteguna* |
| *larunbata* | السبت | larun + bata |
| *igandea* | الحد | نهار عطلة من زمان |

> **تلميح للحفظ:** الكلمة **aste** (سيمانة) كتبان فالبداية ديال أيام الخدمة. *Astelehen-, astear-, asteazken-* تقريبا كيحسبو بصوت عالي البداية والوسط والآخر ديال السيمانة.

## كيفاش تقول "نهار الاثنين" — اللاحقة `-(e)an`

باش تحدد إمتى وقع شي حدث، كتزيد `-(e)an` للنهار:

| النهار | "نهار + اليوم" |
|---|---|
| astelehena | astelehen**ean** |
| asteartea | astearte**an** |
| asteazkena | asteazken**ean** |
| osteguna | ostegun**ean** |
| ostirala | ostirale**an** |
| larunbata | larunbat**ean** |
| igandea | igande**an** |

- *Astelehenean lan egiten dut.* — كنخدم نهار الاثنين.
- *Larunbatean afaltzera joango gara.* — نهار السبت غادي نمشيو نتعشاو.

## كيفاش تقول "كل X" — اللاحقة `-ero`

للتكرار المنتظم:

- *astelehenero* — كل اثنين
- *larunbatero* — كل سبت
- *egunero* — كل نهار
- *astero* — كل سيمانة
- *astebururo* — كل ويكاند

## النهار + النشاط: أمثلة

| الباسكية | الدارجة |
|---|---|
| *Astelehenean kiroldegira noa.* | نهار الاثنين كنمشي للجيم. |
| *Asteartean euskara klasea dut.* | نهار الثلاثاء عندي درس ديال الباسكية. |
| *Ostiralean parranda egiten dugu.* | نهار الجمعة كنخرجو نتنشطو. |
| *Larunbatean familiaren etxera joango naiz.* | نهار السبت غادي نمشي لدار العائلة. |
| *Igandean lasai gelditzen naiz etxean.* | نهار الحد كنبقى مرتاح فالدار. |

## Asteburua — الويكاند

`Asteburua` (الويكاند) كلمة نافعة بزاف:

- *Asteburuan zer egingo duzu?* — شنو غادي دير فالويكاند؟
- *Asteburu honetan mendira joango naiz.* — هاد الويكاند غادي نمشي للجبل.
- *Asteburu pasa egitea gustatzen zait.* — كيعجبني نخرج نتسارا فالويكاند.

> **ملاحظة ثقافية:** حدا *igandea* غادي تشوف بزاف *jaieguna* (نهار العطلة): العبارة *igandeak eta jaiegunak* معروفة فمواعيد الطوبيسات، والحوانت، واللوحات ديال الجماعة.
