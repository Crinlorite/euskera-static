الدرس الأخير ديال الوحدة: غادي نبنيو **سيمانة كاملة** ونجمعو فيها كلشي اللي تعلمنا. الأيام، المستقبل، المواعيد، الكلمات اللي كتقول إمتى... اللغة ديال التخطيط.

## سؤال مفتوح

> *Zer egingo duzu aste honetan?* — شنو غادي دير هاد السيمانة؟

جواب طبيعي غادي يستعمل النهار + المستقبل:

> *Astelehenean kiroldegira joango naiz. Asteartean euskara klasea dut. Asteazkenean bilera bat izango dut. Ostegunean lasai egongo naiz. Ostiralean lagunekin afaltzera joango gara. Asteburuan mendira joango gara.*
>
> نهار الاثنين غادي نمشي للصالة ديال الرياضة. نهار الثلاثاء عندي درس ديال الباسكية. نهار الأربعاء غادي يكون عندي اجتماع. نهار الخميس غادي نكون مرتاح. نهار الجمعة غادي نمشيو نتعشاو مع صحابنا. فالويكاند غادي نطلعو للجبل.

## القالب الأساسي

> **النهار + النشاط + المستقبل**

| النهار | مثال ديال النشاط |
|---|---|
| *Astelehenean...* | *...kiroldegira joango naiz* |
| *Asteartean...* | *...lan egingo dut* |
| *Asteazkenean...* | *...amarekin geratuko naiz* |
| *Ostegunean...* | *...filma bat ikusiko dut* |
| *Ostiralean...* | *...lagunekin aterako naiz* |
| *Larunbatean...* | *...mendira joango gara* |
| *Igandean...* | *...etxean lasai egongo naiz* |

## أفعال مفيدة للأجندة

| الفعل | صيغة المستقبل | الدارجة |
|---|---|---|
| joan | joango naiz/da | غادي نمشي، غادي يمشي |
| etorri | etorriko naiz/da | غادي نجي، غادي يجي |
| egon | egongo naiz | غادي نكون |
| izan | izango da | غادي يكون / غادي يكون كاين |
| ikusi | ikusiko dut | غادي نشوف(و) |
| egin | egingo dut | غادي ندير(و) |
| jan | jango dut | غادي ناكل(و) |
| lan egin | lan egingo dut | غادي نخدم |
| atera | aterako naiz | غادي نخرج |
| eraman | eramango dut | غادي نهز(و) |
| erosi | erosiko dut | غادي نشري(ه) |

## قصة صغيرة: السيمانة ديال Iratxe

قرا هاد الأجندة المخترعة ورد البال للكلمات ديال الوقت:

> *Astelehenean lana dut goizean, eta arratsaldean kiroldegira joango naiz. Asteartean medikuarekin daukat hitzordua, hamabietan. Asteazkenean ez dut ezer berezirik, etxean afalduko dut lasai. Ostegunean Maialenekin geratuko naiz kafe bat hartzeko, sei eta erdietan. Ostiralean afari bat dugu lankideekin. Larunbatean asteburu pasa: Bilbora joango gara nire bikotekidearekin. Igandean buelta etxera, eta arratsaldean lasai-lasai filma bat ikusiko dut.*

## دورك: ثلاثة ديال الأجوبة نموذجية

**السؤال:** *Bihar zer egingo duzu?*

> *Bihar lanera joango naiz goizean. Arratsaldean kafea hartuko dut lagun batekin, eta gauean etxean afalduko dut.*

**السؤال:** *Datorren astean zer plan duzu?*

> *Datorren astean azterketa bat izango dut. Asko ikasiko dut. Larunbatean lasai gelditu nahi dut.*

**السؤال:** *Asteburu honetan zer egingo duzu?*

> *Asteburu honetan mendira joango gara lagunekin. Larunbatean Aralarrera joango gara, eta igandean lasai geldituko gara etxean.*

## جمل مهمة باش تنظم السيمانة

- **Libre zaude X-(e)an?** — واش نتا فاضي نهار X؟
- **Hamarretan ondo?** — مع العشرة مزيان؟
- **Beste egun batean izan beharko du.** — خاصها تكون نهار آخر.
- **Konforme, X-(e)an geratuko gara.** — واخا، نتلاقاو نهار X.

## مراجعة بصرية

```
Pasado    →  Presente  →  Futuro
atzo         gaur          bihar — etzi — datorren astean
joan zen     doa            joango da
ikusi dut    ikusten dut    ikusiko dut
```

> **ملاحظة ثقافية:** فبزاف ديال البلايص غادي تشوف لافتات بحال *"Asteburu honetan jaiak"* ولا *"Datorren ostiralean kontzertua"*. الكلمات ديال الوقت بحال *datorren* و *asteburu honetan* كتبان فالهضرة وحتى فأي لوحة ديال الإعلانات فالحومة. ملي كتولّي الودن كتعرفهم، القراية ديال الزنقة كتولّي ساهلة بزاف.
