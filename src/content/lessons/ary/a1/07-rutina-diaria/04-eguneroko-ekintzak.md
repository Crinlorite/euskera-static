باش تقول شنو كدير كل نهار، الباسكية كتستعمل **الصيغة ديال العادة**: كتاخد الفعل (partizipio) وكتزيد ليه **-tzen** ولا **-ten**، ومن بعد كتجمعو مع الفعل المساعد **izan** (naiz, zara, da…) ولا **ukan** (dut, duzu, du…).

## القاعدة

| آخر الفعل | اللاحقة ديال العادة | مثال |
|---|---|---|
| حرف ساكن ولا `-tu` / `-du` | **-tzen** | *esnatu* → *esnatzen* |
| `-n` | **-ten** | *jan* → *jaten*; *egin* → *egiten* |
| `-i` (شاذ) | **-tzen** ولا **-ten** | *etorri* → *etortzen*; *ikusi* → *ikusten* |

> الفعل *jan* (كلا) **no** كيولي *janten*، كيولي *jaten* — الـ"n" اللي فالآخر كتطيح. نفس الشي مع *edan* → *edaten*، *egon* → *egoten*.

## أفعال الحياة اليومية

### NOR (المساعد **izan**: naiz, zara, da…)

هادو كيمشيو **مع izan** حيت لازمين — الفاعل كيعيش الفعل بلا مفعول به:

| Partizipioa | صيغة العادة | المعنى |
|---|---|---|
| *esnatu* | *esnatzen naiz* | كنفيق |
| *jaiki* | *jaikitzen naiz* | كننوض |
| *altxatu* | *altxatzen naiz* | كننوض (بديل ديال *jaiki*) |
| *dutxatu* | *dutxatzen naiz* | كندوّش |
| *jantzi* | *janzten naiz* | كنلبس |
| *joan* | *joaten naiz* | كنمشي |
| *etorri* | *etortzen naiz* | كنجي |
| *oheratu* | *oheratzen naiz* | كنتكّا |
| *lokartu* | *lokartzen naiz* | كيدّيني النعاس |

### NOR-NORK (المساعد **ukan**: dut, duzu, du…)

هادو كيمشيو **مع ukan** حيت عندهم فاعل ومفعول به:

| Partizipioa | صيغة العادة | المعنى |
|---|---|---|
| *gosaldu* | *gosaltzen dut* | كنفطر |
| *bazkaldu* | *bazkaltzen dut* | كنتغدّا |
| *afaldu* | *afaltzen dut* | كنتعشّا |
| *jan* | *jaten dut* | كناكل |
| *edan* | *edaten dut* | كنشرب |
| *lan egin* | *lan egiten dut* | كنخدم |
| *lo egin* | *lo egiten dut* | كننعس |
| *ikusi* | *ikusten dut* | كنشوف |
| *irakurri* | *irakurtzen dut* | كنقرا |
| *erosi* | *erosten dut* | كنشري |

> **علاش شي وحدين كيمشيو مع NAIZ وشي وحدين مع DUT؟** هادي هي الفرق الأساسي فالباسكية. *Esnatzen naiz* (كنفيق) حاجة كتوقع ليا أنا: ما كاينش مفعول به. *Jaten dut* (كناكل) فيه مفعول به: *ogia jaten dut* (كناكل الخبز). غادي نشوفو هادشي مزيان فالوحدة الجاية — دابا حفظ غير الأزواج ديال الفعل + المساعد.

## أمثلة مترابطة

> *Egunero zazpietan esnatzen naiz eta dutxatzen naiz.* — كل نهار كنفيق مع السبعة وكندوّش.
>
> *Goizean kafea hartzen dut.* — فالصباح كنشرب القهوة.
>
> *Askotan lagunekin afaltzen dut.* — بزاف د المرات كنتعشّا مع صحابي.
>
> *Batzuetan lo-kuluxka egiten dut bazkalostean.* — شي مرات كندير تعسيلة من بعد الغدا.

> **ملاحظة:** *bazkalostean* = "من بعد الغدا" (حرفيًا: "ورا الماكلة"). الثقافة الباسكية عندها كلمات قصيرة لحوايج يومية بحال هاد النعسة الصغيرة — *lo-kuluxka* هي هادي بالضبط.
