هاد الدرس كيجمع كلشي ديال الوحدة: الساعة، أوقات النهار، أفعال الروتين والتكرار. الهدف هو تقدر تعاود نهارك كامل بالباسكية من الأول حتى للخر.

## السؤال الأساسي: "Zer ordutan…?"

| السؤال | الدارجة |
|---|---|
| *Zer ordutan esnatzen zara?* | فوقاش كتفيق؟ |
| *Zer ordutan jaikitzen zara?* | فوقاش كتناض؟ |
| *Zer ordutan gosaltzen duzu?* | فوقاش كتفطر؟ |
| *Zer ordutan bazkaltzen duzu?* | فوقاش كتغدا؟ |
| *Zer ordutan ateratzen zara etxetik?* | فوقاش كتخرج من الدار؟ |
| *Zer ordutan afaltzen duzu?* | فوقاش كتعشا؟ |
| *Zer ordutan oheratzen zara?* | فوقاش كتنعس؟ |

> رد البال لتبدال الفعل المساعد: *esnatzen **zara*** (NOR)، ولكن *gosaltzen **duzu*** (NOR-NORK). خصك تبدا تلاحظ الجوج: فعل + مساعد.

## "مع الساعة X" — كيفاش تقولها

باش تجاوب "مع (الساعة)"، خود الساعة فالجمع وبدّل *-ak* بـ **-etan** (مع `-e-` فالوسط من غير اللي ديجا كيساليو بحرف علة):

| الساعة | "مع…" |
|---|---|
| zazpiak (السبعة) | **zazpietan** |
| zortziak | **zortzietan** |
| hamarrak | **hamarretan** |
| hamabiak | **hamabietan** |
| ordu bata (الوحدة) | **ordu batean** (مفرد، كيحافظ على الشكل ديالو) |
| ordu biak | **ordu bietan** |
| bost eta erdiak | **bost eta erdietan** (مع الخمسة ونص) |
| zortziak laurden gutxi | **zortziak laurden gutxitan** (مع التمنية قل ربع) |

## نهار كامل — نموذج

قرا هاد النص وشوف كيفاش كيتربطو الطرفات كاملين:

> *Ni goizeko zazpietan esnatzen naiz. Poliki-poliki altxatzen naiz eta komunera joaten naiz. Dutxa bat hartzen dut, arropa janzten dut eta sukaldera joaten naiz. Sukaldean gosaria prestatzen dut eta lasai-lasai gosaltzen dut. Ondoren, etxetik ateratzen naiz eta lanera joaten naiz. Eguerdiko ordu bietan bazkaltzen dut. Arratsaldean batzuetan zinemara joaten naiz, beste batzuetan lagunekin egoten naiz. Gauean, etxean afaltzen dut, telebista ikusten dut eta hamaiketan oheratzen naiz.*

الترجمة تقريبا:
> *أنا كنفيق مع السبعة دالصباح. كنناض بشوية وكنمشي لبيت الما. كندوش، كنلبس حوايجي وكنمشي للكوزينة. فالكوزينة كنوجد الفطور وكنفطر على خاطري. من بعد كنخرج من الدار وكنمشي للخدمة. مع الجوج دالزوال كنتغدا. فالعشية مرة مرة كنمشي للسينما، ومرات كنكون مع صحابي. فالليل كنتعشا فالدار، كنتفرج فالتلفزة وكننعس مع الحداش.*

## دير ديالك

تبّع هاد النموذج بالمعلومات ديالك الحقيقية. هادي أحسن طريقة باش تثبت داكشي اللي تعلمتي:

1. **فوقاش كتفيق:** *Goizeko ___etan esnatzen naiz.*
2. **شنو كدير ملي كتناض:** *... dutxatzen naiz / gosaltzen dut / ...*
3. **كيفاش كتمشي للخدمة ولا للقراية:** *... oinez / autoz / autobusez joaten naiz.*
4. **شنو كدير فالعشية:** *Arratsaldean ...*
5. **فوقاش كتعشا وكتنعس:** *Gaueko ___etan afaltzen dut eta ___etan oheratzen naiz.*

## جمل مفيدة للربط

- *Lehenengo* — اللول
- *Gero / Ondoren* — من بعد
- *Eta gero* — ومن بعد
- *Azkenik* — فالأخير
- *Egunero* — كل نهار
- *Batzuetan / Beste batzuetan* — مرة مرة / مرات خرين
- *Beti* — ديما
- *Inoiz ez* — عمرو
