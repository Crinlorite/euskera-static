الثقافة الكبيرة ديال البار الباسكي كدور على تلاتة ديال الأشكال: **pintxo** (صغير، ديال الكونطوار)، **ogitarteko** (ساندويتش) و **plater konbinatua** (طبسيل مخلط). إلا عرفتي كيفاش تطلب الأنواع، تقدر تاكل فأي بلاصة.

## الأشكال التلاتة

| الباسكية | الدارجة | الحجم |
|---|---|---|
| *pintxoa* | pintxo / طابا | صغير، ديال الكونطوار |
| *ogitartekoa* | ساندويتش | متوسط، فالخبز |
| *plater konbinatua* | طبسيل مخلط | ماكلة كاملة |
| *razioa* | حصة | باش تقسمها |

> **Ogitarteko** حرفيا معناها "داكشي اللي بين الخبز": *ogi* (الخبز) + *arte* (بين) + *-ko*. هو الساندويتش العادي، ولكن بخبز باسكي مزيان وحشوة عامرة.

## الحشوات المعروفة

هادو هوما الحشوات اللي غادي تشوف بزاف فالسبورة ديال البار:

| الباسكية | الدارجة |
|---|---|
| *tortilla* | تورتيا (ديال البطاطا) |
| *txistorra* | txistorra (صوصيص رقيق) |
| *txorizoa* | شوريسو |
| *gazta* | فرماج |
| *urdaiazpikoa* | جامبون |
| *antxoa* | أنشوبة |
| *atuna* | طون |
| *gilda* | gilda (أنشوبة + فلفلة حارة + زيتونة) |

## كيفاش تجمع باش تطلب

القاعدة هي: **الوصف + الشكل + bat (mesedez)**. الوصف (شنو فيه) كيجي اللول.

- *Tortilla **pintxo bat**, mesedez.* — واحد pintxo ديال التورتيا، عافاك.
- *Gazta **ogitartekoa**, mesedez.* — واحد الساندويتش ديال الفرماج، عافاك.
- *Txistorra **razio bat** hartuko dugu.* — غادي ناخدو حصة ديال txistorra.
- *Ogitarteko **mistoa**, mesedez.* — ساندويتش مخلط، عافاك.

> ملي كتطلب باش تقسمو، كتستعمل **dugu** ("عندنا / كناخدو حنا") ولا **hartuko dugu** ("غادي ناخدو"). فالجماعة عادي بزاف يطلبو بزاف ديال الحصص للكل.

## الأنواع والتفاصيل

- **handia** — كبير / **txikia** — صغير:
  - *Garagardo handia* — بيرة كبيرة
  - *Kafe txikia* — قهوة صغيرة (كاس صغير)
- **hotza** — بارد / **beroa** — سخون:
  - *Ogitarteko beroa* — ساندويتش سخون (فالبلانشا)
- **eta...** — و... (باش تزيد):
  - *Tortilla pintxoa **eta** ardo gorri bat* — pintxo ديال التورتيا وكاس ديال الشراب الحمر

## طابلة ديال الصحاب

> — *Zer hartuko dugu?* — شنو غادي ناخدو؟
>
> — *Niretzat tortilla pintxoa eta zurito bat.* — ليا أنا pintxo ديال التورتيا وكاس صغير ديال البيرة.
>
> — *Eta zuretzat?* — ونتا؟
>
> — *Nik gazta razio bat eta ardo gorri bat hartuko ditut.* — أنا غادي ناخد حصة ديال الفرماج وكاس ديال الشراب الحمر.
>
> — *Nik plater konbinatu bat: arrautzak, txorizoa eta patata frijituak.* — أنا، طبسيل مخلط: بيض، شوريسو وفريت.
>
> — *Bale, hiru eskaera dira.* — واخا، هادو تلاتة ديال الطلبات.

## الخلاص

- **Pagatzera!** — يالله نخلصو!
- **Niri tokatzen zait.** — دوري أنا.
- **Nik gonbidatzen zaitut.** — أنا اللي عارض عليك.
- **Erdibana.** — بالنص، كل واحد النص ديالو. (تقسيم)

> **ملاحظة ثقافية:** الـpintxos تقليد قوي بزاف فـDonostia وBilbao وIruñea. كل بار عادة عندو الطبسيل الخاص بيه. العادة ديال **poteo** هي تدور من بار لبار وتاخد pintxo وشي مشروب فكل واحد — تقليد اجتماعي بزاف وباسكي (euskaldun) بزاف.
