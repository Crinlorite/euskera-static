جزء كبير من الحياة الاجتماعية فـ Euskal Herria كيدوز فـ **الطابيرنا** (البار). إلا عرفتي المشروبات والماكلة الأساسية بالباسكية، غادي تتحل ليك بيبان بزاف: شلة ديال الصحاب، زيارة لشي قرية جديدة، ولا *poteo* (الدورة على البارات). نبداو بالمفردات.

## القهوة وأنواعها

القهوة هي غالباً أكثر حاجة غادي تطلب. عندها بزاف ديال الأشكال:

| الباسكية | الدارجة |
|---|---|
| *kafea* | القهوة (بشكل عام) |
| *kafe hutsa* | قهوة كحلة (حرفياً: "قهوة صافية/خاوية") |
| *kafesnea* | قهوة بالحليب (من *kafe* + *esne*) |
| *kafe ebakia* | قهوة مهرسة (*ebaki* = "مقطوعة") |
| *kafe deskafeinatua* | قهوة بلا كافيين |
| *infusioa* | منقوع أعشاب (تيزان) |
| *tea* | أتاي |

> *Kafesne* حرفياً معناها "قهوة-حليب". الباسكية كتكوّن بزاف ديال الكلمات المركبة بهاد الطريقة، بلا خط وسط، والكلمة الرئيسية فالآخر.

## مشروبات أخرى

| الباسكية | الدارجة |
|---|---|
| *ura* | الما |
| *zumoa* | عصير |
| *esnea* | الحليب |
| *ardoa* | نبيذ |
| *ardo gorria* | نبيذ أحمر |
| *ardo zuria* | نبيذ أبيض |
| *garagardoa* | بيرة |
| *zuritoa* | بيرة صغيرة (معروفة بزاف) |
| *sagardoa* | سيدر (نبيذ التفاح) |
| *txakolina* | تشاكولي (نبيذ أبيض باسكي) |
| *patxarana* | باتشاران (مشروب باسكي بالبرقوق) |

> ثلاث كلمات غريبة: **sagardo** (سيدر) = *sagar* (تفاحة) + *ardo* (نبيذ)؛ **garagardo** (بيرة) = *garagar* (شعير) + *ardo*؛ **txakolina** نبيذ أبيض جديد وخفيف، ماركة ديال الدار فـ Euskadi.

## الماكلة الأساسية فالبار

باش ترافق داكشي اللي كتشرب:

| الباسكية | الدارجة |
|---|---|
| *ogia* | الخبز |
| *gazta* | فرماج |
| *urdaiazpikoa* | جامبون |
| *tortilla* | طورطية (أومليت بالبطاطا) |
| *patata frijituak* | بطاطا مقلية |
| *gozokia* | حلوة (بشكل عام) |
| *txokolatea* | شوكولا |

## أداة التعريف `-a`

تقريباً كاع هاد الكلمات كتاخد **`-a`** فالآخر ملي كتجي "عادية" فالجملة: هي أداة التعريف "الـ".

- *Ardoa gustatzen zait.* — كيعجبني النبيذ.
- *Ura nahi dut.* — بغيت الما.

ملي كتطلب "واحد"، كتختفي `-a` وكتدخل **bat** ("واحد/واحدة"):

- *Kafe **bat**, mesedez.* — واحد القهوة، عافاك.
- *Garagardo **bat**.* — واحد البيرة.

> فالدرس 3 غادي تشوف هادشي بالتفصيل. دابا حفظ الأشكال اللي فيها `-a` باش تعرفها فلائحة البار.
