**الحالة NORA** (كيسميوها حتى *adlativo*) كتبيّن **الوجهة** ديال الحركة: فين غادي. فالدارجة كتقابلها عادةً **"لـ"** ("غادي *لـ*لدار"، "*لـ*بلباو"، "*لـ*لجردة")، بحال *à* و *al* فالفرنسية والإسبانية.

## السؤال: Nora?

| السؤال | الدارجة |
|---|---|
| ***Nora* zoaz?** | فين غادي؟ |
| ***Nora* doa?** | فين غادي هو؟ |
| ***Nora* goaz?** | فين غاديين؟ |
| ***Nora* doaz?** | فين غاديين هوما؟ |

## اللاحقة: -ra

باش تجاوب، كنزيدو **`-ra`** للبلاصة اللي غادي ليها. الطريقة كتبدّل على حساب كيفاش كتسالي الكلمة:

| آخر الكلمة | الطريقة | مثال |
|---|---|---|
| -a (أصلية، *eskola*) | + ra | eskola → **eskolara** |
| حرف علة بلا -a فالآخر (*Bilbo*، *etxe*) | + ra | etxe → **etxera**, Bilbo → **Bilbora** |
| حرف ساكن (*Madril*، *Gasteiz*) | + era | Madril → **Madrilera**, Gasteiz → **Gasteizera** |

## جدول ديال الأمثلة

| البلاصة | الشكل -ra | جملة نموذج |
|---|---|---|
| etxe (دار) | **etxera** | *Etxera noa.* — غادي للدار. |
| eskola | **eskolara** | *Eskolara doaz.* — غاديين للمدرسة. |
| euskaltegi | **euskaltegira** | *Euskaltegira goaz.* — غاديين للeuskaltegi. |
| taberna | **tabernara** | *Tabernara zoaz?* — واش غادي للبار؟ |
| lan (خدمة) | **lanera** | *Lanera nator.* — جاي للخدمة. (حتى هنا -era من بعد حرف ساكن) |
| Bilbo | **Bilbora** | *Bilbora doa.* — غادي لبلباو. |
| Donostia | **Donostiara** | *Donostiara goaz asteburuan.* — غاديين لدونوستيا فالويكاند. |
| Madril | **Madrilera** | *Madrilera doaz.* — غاديين لمدريد. |
| mendi (جبل) | **mendira** | *Mendira goaz larunbatean.* — غاديين للجبل نهار السبت. |

> **حيلة صغيرة:** *non* → *nora* كيتبعو نفس الطريقة ديال *kale-an* → *kale-ra*. إلا كتعرف تكوّن *Bilbon* (فبلباو)، راك كتعرف تكوّن *Bilbora* (لبلباو): بدّل *-n* بـ *-ra*. وإلا كتعرف *Madrilen*، كتعرف *Madrilera*.

## Zertara? — "علاش؟"

باش تسول **علاش** غادي (شنو الهدف)، كنستعملو **Zertara zoaz?** وكنجاوبو بفعل + اللاحقة **`-tzera`**:

| السؤال | الجواب |
|---|---|
| *Zertara zoaz tabernara?* | *Kafea hartzera.* — باش نشرب قهوة. |
| *Zertara doa Kepa supermerkatura?* | *Erostera.* — باش يتقضّى. |
| *Zertara goaz mendira?* | *Ibiltzera.* — باش نتمشاو. |
| *Zertara doaz hondartzara?* | *Igeri egitera.* — باش يعومو. |

> **الطريقة:** *(الفعل فصيغة participio) + -t(z)era*: *erosi → erostera*, *jan → jatera*, *ikasi → ikastera*, *ikusi → ikustera*, *bisitatu → bisitatzera*. هي تقريباً "باش + فعل" فالدارجة.

## حوار صغير

> — *Nora zoaz, Maialen?* — فين غادية، مايالين؟
>
> — *Euskaltegira noa.* — غادية للeuskaltegi.
>
> — *Eta zertara?* — وعلاش؟
>
> — *Klasera, noski! Euskara ikastera.* — للقسم، طبعاً! باش نتعلم الباسكية.
>
> — *Eta gero?* — ومن بعد؟
>
> — *Tabernara goaz lagunekin pote bat hartzera.* — غاديين للبار مع الصحاب نشربو شي حاجة.

## ظروف الاتجاه

أسماء الإشارة حتى هوما عندهم الشكل ديال NORA:

| NON (المكان) | NORA (الاتجاه) | المعنى |
|---|---|---|
| hemen | **hona** | لهنا |
| hor | **horra** | لتما (قريب) |
| han | **hara** | لهيه (بعيد) |

- **Hona zatoz?** — واش جاي لهنا؟
- **Hara doaz.** — غاديين لهيه.

> **تذكير مهم:** بزاف ديال الناس كيتلفو فالأول: *etxean* (فالدار) ≠ *etxera* (للدار) ≠ *etxetik* (من الدار، الدرس 04). بجوج كيتشابهو حيت كلهم كيهضرو على "الدار"، ولكن المعلومة مختالفة تماماً. حفظ فراسك: **NON = -an (كاين)**، **NORA = -ra (مشى)**، **NONDIK = -tik (جا، الدرس 4)**.
