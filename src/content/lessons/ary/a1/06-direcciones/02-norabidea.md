ملي شي واحد كيسولك كيفاش يوصل لشي بلاصة — ولا ملي كتتلف وكتسول نتا — كتحتاج شوية ديال أفعال الأمر وظروف الاتجاه. فهاد الدرس جمعنا الأساسي.

## الأمر الأساسي

فالباسكية، الأمر ديال أفعال الحركة ساهل ومباشر:

| الشكل | الفعل الأصلي | المعنى |
|---|---|---|
| **Jo** | jo | ضرب / توجه (jo ezkerrera = دور على ليسر) |
| **Segi** / **Jarraitu** | segitu / jarraitu | تبع، كمل |
| **Hartu** | hartu | شد (hartu kale hau = شد هاد الزنقة) |
| **Igo** | igo | طلع |
| **Jaitsi** | jaitsi | هبط |
| **Sartu** | sartu | دخل |
| **Irten** | irten | خرج |
| **Zeharkatu** | zeharkatu | قطع |
| **Iritsi** / **heldu** | iritsi / heldu | وصل (… arte = "حتى لـ…") |

> *Jo* معناها الحرفي "ضرب"، ولكن كتستعمل بمعنى "توجه لـ": **jo ezkerrera** = "جبد على ليسر".

## الظروف والإشارات ديال الاتجاه

| الباسكية | الدارجة |
|---|---|
| *ezkerra* | ليسر |
| *eskuina* | ليمن |
| *aurrera* | لقدام |
| *atzera* | لور |
| *zuzen* | نيشان، ديريكت |
| *gora* | للفوق |
| *behera* | للتحت |

> رد البال: باش تعبر على **الاتجاه لـ** كتستعمل اللاحقة `-ra` (غادي تشوفها مزيان فالدرس 03): *ezkerre-ra* (على ليسر)، *aurre-ra* (لقدام)، *atze-ra* (لور). نفس الشي لـ *gora*، *behera*.

## بلايص معروفين كمرجع

| الباسكية | الدارجة |
|---|---|
| *semaforoa* | الضو الأحمر |
| *bidegurutzea* | الكروازما، ملتقى الطرق |
| *zebrabidea* | ممر الراجلين |
| *biribilgunea* / *errotonda* | rotonda (الرومبوان) |
| *aldapa* | العقبة |
| *eskailerak* | الدروج |
| *zubia* | القنطرة |
| *errepidea* | الطريق |
| *kalea* | الزنقة |

## جمل نموذجية

- **Jo ezkerrera bidegurutzean.** — دور على ليسر فالكروازما.
- **Segi aurrera semaforora arte.** — سير نيشان حتى للضو الأحمر.
- **Zeharkatu zebrabidea.** — قطع ممر الراجلين.
- **Igo eskailerak eta sartu eraikinean.** — طلع الدروج ودخل للعمارة.
- **Jaitsi aldapa, eta gero jo eskuinera.** — هبط العقبة، ومن بعد دور على ليمن.
- **Egin atzera; gehiegi joan zara.** — رجع لور؛ فتي البلاصة.

## تسول وتعطي الطريق

> — *Barkatu, **non dago** udaletxea?* — سمح ليا، فين كاينة البلدية؟
>
> — ***Segi aurrera** semaforora arte. Han **jo eskuinera** eta **zeharkatu** plaza. Udaletxea elizaren ondoan dago.* — سير نيشان حتى للضو الأحمر. تما دور على ليمن وقطع الساحة. البلدية حدا الكنيسة.
>
> — *Eta gertu **dago**?* — وواش قريبة؟
>
> — *Bai, oso gertu. Bost minutu oinez.* — إيه، قريبة بزاف. خمس دقايق على رجليك.

> **نصيحة:** بزاف ديال الإرشادات كتبع نفس القالب: الأمر (*jo*، *segi*، *zeharkatu*) + البلاصة باللاحقة (*ezkerrera*، *semaforora*، *zebrabidea*). إلا حفظتي القالب، تقدر تركب تعليمات طوال وتجمع القطع مع بعضياتهم.
