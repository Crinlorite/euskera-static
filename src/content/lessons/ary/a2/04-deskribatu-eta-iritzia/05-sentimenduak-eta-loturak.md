هاد الدرس كيجمع جوج ديال البلوكات ديال A2 مفيدين بزاف:

1. **المشاعر** والحالات النفسية (الأساسيات عرفتيهم ف A1؛ هنا غادي تزيد).
2. **أدوات الربط** باش تقدم حجج وتدقق كلامك: *gainera, hala ere, beraz, alde batetik...*

بهادشي كتسالي الوحدة وكتاخد أدوات باش تعبر على آراء مفصلة كثر.

## المشاعر: القاعدة مع *egon* + حالة

أغلب المشاعر المؤقتة كتجي مع *egon* + صفة ولا ظرف ديال الحالة:

| الدارجة | الباسكية |
|---|---|
| فرحان | *Pozik nago* |
| حزين | *Triste nago* |
| معصب | *Haserre nago* |
| متوتر | *Urduri nago* |
| هاني | *Lasai nago* |
| مقلق بالملل | *Aspertuta nago* |
| عيان | *Nekatuta nago* |
| حشمان | *Lotsatuta nago* |
| مغرم | *Maitemindurik nago* |

> هو نفس النموذج ديال A1 (*pozik, triste, lasai*) زدنا عليه *aspertuta, nekatuta, lotsatuta, maitemindurik*.

## المشاعر مع *izan*: *beldur naiz*

شي مشاعر عميقة كتجي مع *izan*:

| الدارجة | الباسكية |
|---|---|
| أنا خايف | *Beldur naiz* |
| عندك الحق | *Arrazoia duzu* |
| بغيت نعرف (فضول) | *Jakin-mina dut* |
| عندي الخاطر | *Gogoa dut* / *Gogoz nago* |
| ما عنديش الخاطر | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — كنخاف نمشي فالطوموبيل.

## المشاعر مع *NOR-NORI*: *lotsa ematen dit*

طريقة باسكية بزاف: الشعور "كيعطيك":

| الدارجة | الباسكية |
|---|---|
| كنحشم | *Lotsa ematen dit* |
| كيحزني / كنشفق | *Pena ematen dit* |
| كيعصبني | *Amorrua ematen dit* |
| كيخوفني | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — كنحشم نقولها.
>
> *Albiste horrek **pena handia ematen dit**.* — داك الخبر حزني بزاف.

## *Jartzen naiz / jarri naiz*

باش تعبر على **تبدل الحالة** ("توتر، فرح، حزن"):

| الدارجة | الباسكية |
|---|---|
| كنتوتر | *Urduri **jartzen naiz*** |
| تحزن | *Triste **jarri zen*** |
| فرحنا | *Pozik **jarri ginen*** |
| كيتعصب على والو | *Edozergatik haserretzen da* |

## أفعال نفسية كتستعمل بزاف

| الفعل | المعنى |
|---|---|
| *gustatu* | عجب |
| *maite izan* | بغا / حب |
| *gorrotatu* / *higuindu* | كره |
| *beldurtu* | تخلع |
| *aspertu* | تقلق (بالملل) |
| *haserretu* | تعصب |
| *lasaitu* | تهنى |
| *poztu* | فرح |
| *triste jarri* / *atsekabetu* | تحزن |
| *kezkatu* | تشغل بالو |

> *Asko **maite ditut** nire gurasoak.* — كنبغي والديا بزاف.
>
> *Ez **kezkatu**, dena ondo aterako da.* — ما تشغلش بالك، كلشي غادي يدوز مزيان.

## أدوات الربط

باش تربط الآراء والحجج:

### الإضافة

| الدارجة | الباسكية |
|---|---|
| وزيد على هادشي | *gainera* |
| وحتى | *eta baita ere* / *...ere* |
| وخصوصا | *batez ere* |

> *Gainera, prezioa ere ona da.* — وزيد، حتى الثمن مزيان.

### السبب / النتيجة

| الدارجة | الباسكية |
|---|---|
| إذن | *beraz* |
| داكشي علاش | *horregatik* |
| لهاد السبب | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — تعطلات؛ إذن، غادي نمشي.

### التناقض / المعارضة

| الدارجة | الباسكية |
|---|---|
| ومع ذلك | *hala ere* |
| ولكن | *baina* |
| من جهة أخرى | *bestetik* |
| بالعكس | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — تعطلات؛ ومع ذلك، غادي نجي.

### تنظيم الكلام

| الدارجة | الباسكية |
|---|---|
| من جهة… من جهة أخرى | *Alde batetik... bestetik...* |
| الأول… من بعد… | *Lehenengo... gero...* |
| فالأخير | *Azkenik* |
| باختصار | *Laburbilduz* |

## تراكيب العطف ف A2

هادو تراكيب كيبانو فأي امتحان A2:

| الدارجة | الباسكية |
|---|---|
| لا... لا... | *Ez... ez...* |
| بجوج... و... | *Bai... bai...* / *Hala... nola...* |
| ماشي غير... ولكن حتى | *Ez bakarrik..., baita ere...* |
| ...حتى هو | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — لا Anboto لا Olatz ما جاو.
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — خاصني نخدم الصباح والعشية بجوج.

## نص صغير ديال الرأي

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## حيلة ل A2: "الهيكل ديال الرأي"

ملي يطلبو منك تعطي رأيك ف A2، تبع هاد النموذج:

> **1. Nire ustez** + الموضوع + **-(e)la**.
>
> **2. Alde batetik**, + السبب 1 + **-lako**.
>
> **3. Bestetik**, + السبب 2.
>
> **4. Hala ere**, + تدقيق.
>
> **5. Beraz**, + الخلاصة.

بهادشي كتبني فقرة كاملة ديال A2.

> **ملاحظة ثقافية:** بزاف ديال النصوص الرسمية ديال A2 (رسالة للجريدة، منتدى، تعبير فالامتحان) كيطلبو هاد البنية ديال الحجاج. تمرن عليها بمواضيع يومية: الرياضة، الماكلة، مواقع التواصل، الخدمة، الأعياد ديال القرية.
