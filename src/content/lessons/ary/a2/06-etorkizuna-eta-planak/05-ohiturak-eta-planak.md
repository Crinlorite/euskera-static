آخر درس فالوحدة — وسدّان ديال مرحلة كبيرة: دابا مع المستقبل فجيبك، **ولّيتي متحكم فالأزمنة التلاتة**. هاد الدرس كيزيد الحبة اللي فوق الحلوى (*ohi*، "التعوّد" بالباسكية) وكيخليك تحرّك نفس الفكرة بين الماضي، الحاضر-العادة والمستقبل. وهادشي بالضبط اللي بغات تسمع لجنة ديال A2.

## "Ohi" — التعوّد بالباسكية

> **participe + ohi + مساعد**

| الدارجة | الباسكية |
|---|---|
| عادةً كنمشي للخدمة بالبشكليط | *Lanera bizikletaz joan **ohi** naiz* |
| عادةً كناكلو عند جدّة | *Amonaren etxean bazkaldu **ohi** dugu* |
| عادةً كيجي معطّل | *Berandu etorri **ohi** da* |
| كنت كنكمي (دابا لا) | *Erre **ohi** nuen* |

جوج ملاحظات:

1. **البلاصة ثابتة**: بين الـparticipe والمساعد. *Joan ohi naiz* ✓ — عمّرك *ohi joan naiz*.
2. مع **المساعد فالماضي** كتخرج "كنت متعوّد": *joan ohi nintzen* (كنت كنمشي عادةً). قريبة بزاف للماضي المستمر اللي عارف (*joaten nintzen*) — *ohi* كتأكد على العادة.

> **وبلا "ohi"؟** الحاضر ديال العادة (*joaten naiz*) ديجا كيعبّر على العادة. *Ohi* زيادة أنيقة، بزاف فالكتابة وفالامتحان. استعملها ملي بغيتي تبان مزيان: *Igandeetan hondartzara joan ohi gara.*

## الظروف اللي كيمشيو مع العادة

| الدارجة | الباسكية |
|---|---|
| عادةً | *normalean* |
| أغلب المرات | *gehienetan* |
| تقريبا ديما | *ia beti* |
| مرات | *batzuetan* |
| تقريبا عمّر | *ia inoiz ez* |
| كل صباح / كل عام | *goizero / urtero* |
| نهار الحد | *igandeetan* |

## الخريطة الكاملة ديال الأزمنة (الورقة ديالك النهائية)

| الفكرة | الباسكية | الزمن |
|---|---|---|
| كنمشي (عادة) | *joaten naiz* / *joan ohi naiz* | الحاضر ديال العادة |
| راني ماشي | *joaten ari naiz* | الحاضر المستمر |
| مشيت (اليوم) | *joan naiz* | الماضي القريب |
| مشيت (واحد النهار) | *joan nintzen* | الماضي (مرة وحدة) |
| كنت كنمشي / كنت متعوّد نمشي | *joaten nintzen* / *joan ohi nintzen* | الماضي ديال العادة |
| غادي نمشي | ***joango naiz*** | **المستقبل** |

ستة خانات. فعل واحد. **كاملين ديالك.**

## نص صغير: قبل، دابا وغدا

> *Lehen, lanera autoz joan **ohi nintzen**: ordu erdi trafikoan, egunero. Orain bizikletaz **joaten naiz** — hamar minutu, eta gainera kirola **egiten dut**. Datorren urtean etxetik gertuago **biziko naiz**, eta orduan oinez **joango naiz**. Nire medikua pozik **egongo da**!* 😄

## حوار ديال المراجعة (الأزمنة التلاتة خدامين)

> *— Zer egin **ohi duzu** igandeetan?*
>
> *— Normalean berandu jaiki eta familiarekin bazkaldu **ohi dut**. Baina datorren igandean ezberdina **izango da**: Behobia-Donostia lasterketa **korrituko dut**!*
>
> *— Ederki! Entrenatu **ohi zara**?*
>
> *— Bai, gaztetan asko korritzen **nuen**, gero utzi **egin nion**… eta aurten berriro **hasi naiz**. Bihar azken entrenamendua **egingo dut**.*
>
> *— Ba, zorte on! Helmugan **egongo naiz**, animatzen.* 💪
