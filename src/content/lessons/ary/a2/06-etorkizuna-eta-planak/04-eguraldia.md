فبلاد فين يقدر يكون الشمس، تشتا وترجع الشمس فنفس الصباح، **الهضرة على الجو رياضة وطنية**. وفيها جوج فوايد: المفردات ديال *eguraldia* هي أحسن بلاصة باش تتمرن على المستقبل اللي عاد تعلمتي، حيت التوقعات ديما كاتقال بـ *geroaldia*.

## المفردات الأساسية

| الدارجة | الباسكية |
|---|---|
| الجو | *eguraldia* |
| الشمس | *eguzkia* |
| الشتا | *euria* |
| الثلج | *elurra* |
| الريح | *haizea* |
| الضباب | *lainoa* |
| السحاب | *hodeiak* |
| التبروري | *zaparrada* |
| درجة الحرارة | *tenperatura* |
| الدرجات | *graduak* |
| التوقعات | *iragarpena* |

## التلاتة ديال التركيبات اللي كايحركو كلشي

| الوقت | التركيب | مثال |
|---|---|---|
| **دابا بالضبط** | الظاهرة + ***ari du*** | *Euria **ari du**.* — كاتشتا. |
| **بشكل عام / اليوم** | الظاهرة + ***egiten du*** | *Hotz handia **egiten du**.* — كاين برد بزاف. |
| **التوقعات (المستقبل)** | الظاهرة + ***egingo du*** | *Bihar euria **egingo du**.* — غدا غادي تشتا. |

قطع أخرى عندها الفعل ديالها:

> *Eguzkia **atera da** / **aterako da**.* — خرجات / غادي تخرج الشمس.
>
> *Haizea **dabil**.* — كاين الريح (الريح "كايتمشى").
>
> ***Hodeitsu / eguzkitsu dago**.* — الجو مغيّم / مشمّس.

> **رد البال:** فالباسكية الجو "**كايدير**" الحوايج بـ *egin* والمساعد **du** (بلا فاعل باين): *euria egingo du*، *bero handia egiten du*. بحال فالفرنسية «il fait chaud» — غير هنا حتى الشتا كا«تدار».

## كيفاش كانسولو

> ***Zer eguraldi egiten du** zure herrian?* — كيداير الجو فبلادك؟
>
> ***Zer dio iragarpenak** biharko?* — شنو كاتقول النشرة على غدا؟
>
> ***Zenbat gradu daude** kanpoan?* — شحال من درجة كاينة برا؟

## نشرة جوية بصح (بحال فالتلفزة)

> *«Gaur, goizean **lainoa** izango dugu kostaldean, baina eguerdirako **eguzkia aterako da**. Arratsaldean **hodeiak** iritsiko dira mendebaldetik eta gauean **euria egingo du**, batez ere Bizkaian. Tenperaturak **behera egingo du**: 22 gradutik 16ra. Bihar, **haizea ibiliko da** eta **zaparradak** izango ditugu han-hemenka.»*

(ضباب فالصباح فالساحل، الشمس فالنهار، سحاب جاي من الغرب، شتا فالليل، الحرارة كاتنقص، وغدا ريح وتبروري هنا وهنا — المنيو الأطلسي الكلاسيكي. 😄)

## حوار: البرنامج مربوط بالسما

> *— Bihar mendira **joango gara**?*
>
> *— Ez dakit… **zer dio iragarpenak**?*
>
> *— Goizean **eguzkitsu**, baina arratsaldean **euria egingo du**.*
>
> *— Orduan goiz **aterako gara**. **Zaparrada** harrapatzen bagaitu, hurrengoan ez naiz zurekin inora joango!* 😄
