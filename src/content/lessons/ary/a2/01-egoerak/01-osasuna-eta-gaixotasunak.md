فـ A2 غادي تقدر تهضر على كيفاش كتحس بصحتك: ملي تكون مريض، شنو كيضرك، وشنو عطاك الطبيب. التركيب الأساسي اللي عارفو من A1 (*mina daukat*) غادي يتوسع بمفردات خاصة، المهنيين ديال الصحة وحوارات عند الطبيب.

## كيفاش تقول "أنا مريض"

فالباسكية عندك جوج طرق معروفين:

- **Gaixorik nago.** — أنا مريض/مريضة. (حالة مؤقتة، مع *egon*)
- **Ez nago ondo.** — ما مزيانش.
- **Min hartu dut.** — تضرّيت.
- **Gaixotu egin naiz.** — مرضت (فعل لازم، *naiz*).

> **ملاحظة نحوية:** *gaixorik* فيه اللاحقة -**rik** (حالة)، بحال *pozik* (فرحان)، *nekatuta*، *triste*. عقل: الحالة = *egon*.

## الأعراض — القاعدة العامة X **daukat**

بحال فـ A1، الأعراض كتبنى بـ *eduki* (عندو):

| الدارجة | الباسكية |
|---|---|
| فيا السخانة | *Sukarra **daukat*** |
| فيا الكحة | *Eztula **daukat*** |
| فيا الرواح | *Katarroa **daukat*** |
| فيا الگريپ | *Gripea **daukat*** |
| دايخ/دايخة | *Zorabiatuta nago* |
| بغيت نرجّع | *Goragalea **daukat*** |

## الوجع: *mina*

**الوجع** فالباسكية اسم (*mina*) وكيتجمع مع عضو الجسم فـ **NONGO (-ko)**، اللي كيبيّن "شمن نوع ديال الوجع":

> **عضو الجسم + -ko + mina + daukat**

| الدارجة | الباسكية |
|---|---|
| كيضرني راسي | *Buruko mina daukat* |
| كيضرني حلقي | *Eztarriko mina daukat* |
| كتضرني كرشي | *Sabeleko mina daukat* |
| كيضروني ضراسي | *Hortzeko mina daukat* |
| كيضرني ظهري | *Bizkarreko mina daukat* |
| كيضروني رجليا | *Oinetako mina daukat* |

طريقة أخرى معروفة بزاف، خصوصا ملي شي حاجة كتضرك "دابا نيت":

- *Buruak min ematen dit.* — راسي كيعطيني الوجع.

## عند الطبيب

| الدارجة | الباسكية |
|---|---|
| شنو بيك؟ / شنو عندك؟ | *Zer duzu?* / *Zer gertatzen zaizu?* |
| من إمتى؟ | *Noiztik?* |
| واش كيضرك؟ | *Min ematen dizu?* |
| شرب حبة كل تمن سوايع | *Hartu pilula bat zortzi orduro* |
| ريّح | *Hartu atseden* |
| رجع من هنا سيمانة | *Itzuli astebete barru* |

## المهنيين والبلايص

| البلاصة / الشخص | الباسكية |
|---|---|
| المستوصف | *anbulatorioa* |
| السبيطار | *ospitalea* |
| المستعجلات | *larrialdiak* |
| طبيب العائلة | *familia-medikua* |
| الفرملية | *erizaina* |
| مول الفارماسيان | *botikaria* |
| الفارماسيان | *botika* / *farmazia* |
| الموعد المسبق | *aurretiazko hitzordua* |

## حوار صغير

> *— Egun on. **Zer duzu**?*
>
> *— **Sukarra daukat** atzotik, eta **buruko mina** ere bai.*
>
> *— Eztulik?*
>
> *— Bai, baina ez asko.*
>
> *— Ondo. **Hartu** pilula hauek **zortzi orduro**, eta **edan** ur asko. Hobeto ez bazaude, bihar etorri berriro.*

> **ملاحظة ثقافية:** فـ Euskal Herria، *"botikaria"* (مول الفارماسيان) باقي فبزاف ديال القرى الصغار هو أول واحد كيمشيو ليه للمشاكل الخفيفة: الرواح، القرص ديال الحشرات، الدوخة. الفارماسيان كتخدم بحال مصفاة قبل طبيب العائلة.
