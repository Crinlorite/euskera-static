الهضرة على **نمط الحياة** و**البيئة** موضوع كلاسيكي فـ A2: كيتخلط فيه مفردات جداد مع جمل ديال الوجوب والنصيحة (*behar dugu*، *komeni da*، *garrantzitsua da*) اللي كتعرفها من A1.

## العادات الصحية

| الدارجة | الباسكية |
|---|---|
| دير الرياضة | *kirola egin* |
| تمشى / تسارا | *paseatu* / *ibili* |
| جري | *korrika egin* |
| سير بالبيكالة | *bizikletaz ibili* |
| كول الفاكية والخضرة | *fruta eta barazkiak jan* |
| شرب الما | *ura edan* |
| نعس مزيان | *ondo lo egin* |
| كمي | *erre* |
| شرب الكحول | *alkohola edan* |
| ما تكترش من الملحة | *gatzaz ez abusatu* |

> جمل معروفة:
>
> - *Kirola egiten dut astean hiru aldiz.* — كندير الرياضة تلت مرات فالسيمانة.
> - *Erretzeari utzi diot.* — حبست الكارو.
> - *Ez dut alkoholik edaten astegunetan.* — ما كنشربش الكحول فوسط السيمانة.

## شحال من مرة: *X aldiz*

باش تقول "X دالمرات" كتستعمل **العدد + aldiz**:

| الدارجة | الباسكية |
|---|---|
| مرة فالنهار | *Egunean behin* |
| جوج مرات فالسيمانة | *Astean bi aldiz* / *birritan* |
| تلت مرات فالشهر | *Hilean hiru aldiz* |
| بزاف دالمرات | *Askotan* |
| مرة مرة | *Batzuetan* |
| قليل | *Gutxitan* |
| عمر | *Inoiz ez* |

| اللون العادي | الباسكية | لاش |
|---|---|---|
| زرق | *edukiontzi urdina* | papera / الكاغيط |

## جمل مفيدة باش تعطي رأيك

- *Garrantzitsua da birziklatzea.* — مهم نعاودو التدوير.
- *Komeni da kirola egitea.* — مزيان دير الرياضة.
- *Beharrezkoa da kutsadura gutxitzea.* — ضروري ننقصو التلوث.
- *Ez dut uste plastikoa ona denik.* — ما كنظنش البلاستيك مزيان.

> هاد التراكيب (*-tzea + صفة + da*) هي الطريقة ديال A2 باش تقول "مهم / مزيان / ضروري دير X". غادي نخدموها مزيان فالوحدة 4.

## الحياة فالحومة

| الدارجة | الباسكية |
|---|---|
| الحومة | *auzoa* |
| الجار / الجارة | *bizilaguna* |
| جمعية | *elkartea* |
| العمل التطوعي | *boluntariotza* |
| حفلات الحومة | *auzoko jaiak* |
| شارك | *parte hartu* |
| اجتماع | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## نص صغير نموذجي

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **ملاحظة ثقافية:** الـ *auzo-elkarteak* (جمعيات الحومة) حاجة أساسية فالحياة الاجتماعية فبزاف ديال القرى ف Euskal Herria. كينظمو الحفلات، ورشات ديال الباسكية، خرجات للجبل وحملات على البيئة. المشاركة فيهم من أحسن الطرق باش تمارس اللغة فالحياة الحقيقية.
