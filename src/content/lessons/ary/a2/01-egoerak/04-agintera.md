**صيغة الأمر** (*agintera*) كتستعمل باش تعطي تعليمات، تطلب حوايج، ولا تعطي نصائح. فالباسكية هي **ساهلة بزاف كتر من داكشي اللي كيبان**: الصيغة اللي كتستعمل بزاف تقريبا ديما هي نفس **الـparticipe** ديال الفعل.

## القاعدة الأساسية: استعمل الـparticipe

فبزاف ديال الأوامر اليومية، الفعل كيجي فصيغة الـparticipe بلا فعل مساعد:

| الدارجة | الباسكية |
|---|---|
| خود | *Hartu* |
| گلس | *Eseri* |
| نوض | *Jaiki* |
| كتب | *Idatzi* |
| قرا | *Irakurri* |
| سمع | *Entzun* |
| عاود | *Errepikatu* |
| تسنى | *Itxoin* |
| سد الباب | *Itxi atea* |
| حل الشرجم | *Ireki leihoa* |

> هادي هي **الصيغة اللي كتستعمل بزاف** فالقسم، فالزنقة، وفالتعليمات المكتوبة. كتصلح لـ*zu* ولـ*zuek*.

## الصيغ التركيبية (trinkoak): *zatoz*، *zoaz*

شي أفعال كتستعمل بزاف عندها صيغ تركيبية خاصة بالأمر. هادو هوما اللي خاصك تحفظ:

| الفعل | نتا (zu) | نتوما (zuek) |
|---|---|---|
| *etorri* (جا) | **Zatoz** | **Zatozte** |
| *joan* (مشى) | **Zoaz** | **Zoazte** |
| *ekarri* (جاب) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (دّا) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (بقا/كان) | **Egon** / **Lasai** (هدن!) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## الأمر NOR-NORI-NORK: *emadazu*، *esadazu*

ملي كتعطي أمر فيه جوج مفعولات ("عطيني هادي"، "گولها ليه")، الباسكية عندها صيغ مجموعة نافعة بزاف:

| الدارجة | الباسكية |
|---|---|
| عطيني | *Emadazu* / *Eman iezadazu* |
| گولي | *Esadazu* / *Esan iezadazu* |
| عطيه | *Emaiozu* / *Eman iezaiozu* |
| گولو | *Esaiozu* / *Esan iezaiozu* |
| عطينا | *Emaguzu* |
| عطيوني | *Emadazue* |

هاد الصيغ طوال فالحفظ؛ فمستوى A2 كافي تعرف **emadazu / esadazu / emaiozu / esaiozu** وتفهم بلي جايين من الفعل *eman* / *esan*.

## "عافاك" والكلمات اللي كتلطف

الأمر فالباسكية **ما كيبانش قاصح** إلا زدتي شي كلمة ديال الأدب:

- *Mesedez* — عافاك
- *Ahal baduzu* — إلا قدرتي
- *Faborez* (صيغة عامية)
- *Eskerrik asko aldez aurretik* — شكرا مسبقا

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## التعليمات (وصفات، إعلانات، القسم)

الأمر هو الصيغة العادية ف:

- **الوصفات:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **اللوحات:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **القسم:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **الطبيب:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## نص صغير

> *Sukaldari eskolan, irakasleak esaten du:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **ملاحظة ثقافية:** فالباسكية، النبرة **الآمرة** ديال الأمر كتخف بطريقة الكلام والسياق، ماشي ديما بعبارات بحال ("واش تقدر..."). إلا زدتي *mesedez* ولا تبسيمة مع الأمر، غالبا كافي. وإلا بغيتي تكون مؤدب كتر، گول *eman ahal didazu...?* (واش تقدر تعطيني...؟).
