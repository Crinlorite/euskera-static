شنو كدير ملي ما كديرش والو؟ هاد الدرس على **الهوايات** — وعلى القاعدة اللي كتحكمهم: الفعل اللي كيولّي اسم ب **-tzea** (*irakurtzea* = "القراية").

## القطعة: -t(z)ea

من A1 كتعرف *gustatzen zait* مع الحوايج (*kafea gustatzen zait*). باش يعجبك **نشاط**، الفعل كيولّي اسم:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| الدارجة | الباسكية |
|---|---|
| كتعجبني القراية | *Irakurtzea gustatzen zait* |
| كتعجبني الطيابة بزاف | *Asko gustatzen zait sukaldatzea* |
| كيعجبو الغنا | *Abestea gustatzen zaio* |
| كيعجبنا السفر | *Bidaiatzea gustatzen zaigu* |
| ما كيعجبني تا شوية نفيق بكري | *Ez zait batere gustatzen goiz jaikitzea* |

كاع NOR-NORI اللي كتعرف (*zait, zaio, zaigu…*) باقي خدام؛ غير "شنو" اللي كيتبدل.

## لائحة الهوايات

| الدارجة | الباسكية |
|---|---|
| القراية / الكتابة | *irakurtzea / idaztea* |
| تسمع الموسيقى | *musika entzutea* |
| الغنا / الشطيح | *abestea / dantzatzea* |
| الطيابة | *sukaldatzea* |
| التصوير | *argazkiak ateratzea* |
| الصباغة / الرسم | *margotzea / marraztea* |
| السفر | *bidaiatzea* |
| تعتني بالجنان | *baratzea zaintzea* |
| ألعاب الفيديو | *bideo-jokoak* |
| الخياطة / التريكو | *jostea / puntua egitea* |

## تسوّل وتفتاخر

> ***Zer egitea gustatzen zaizu** denbora librean?* — شنو كيعجبك دير فالوقت الفارغ ديالك؟
>
> ***Zein da zure zaletasunik gogokoena**?* — شنو هي الهواية المفضلة ديالك؟
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — الهواية المفضلة ديالي هي الطيابة: كل ويكاند كنجرب وصفة جديدة.

## تلاتة ديال التراكيب، تلاتة ديال المعاني (مراجعة دقيقة)

| التركيب | مثال | المعنى |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | كيعجبني (هواية) |
| **-tzen dakit** | *Margotzen dakit* | كنعرف ندير (مهارة) |
| **-tzen ari naiz** | *Margotzen ari naiz* | راني كندير (دابا) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — ما كنعرفش التريكو، ولكن كنتمنى نتعلمو. (هاد *gustatuko litzaidake* الزوين غادي تتقنو ف B1 — خليناه ليك هنا غير باش تذوقو.)

## حوار

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*
>
> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
>
> *— **Sukaldatzea** eta gero… **jatea**, noski.*
>
> *— Hori ere zaletasuna da?*
>
> *— Nire etxean, **kirola**.* 😄
