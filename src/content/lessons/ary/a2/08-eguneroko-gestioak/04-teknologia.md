من الورقة للبيكسيل: درس **التكنولوجيا ديال كل نهار**. كلمات كتستعملها مية مرة فالنهار — دابا بالباسكية، اللي عندها كلمات واضحين ومبنيين مزيان (*pasahitza* = كلمة الدوزان؛ *sakelakoa* = "ديال الجيب").

## الأجهزة

| الدارجة | الباسكية |
|---|---|
| البيسي | *ordenagailua* |
| البيسي البورطابل | *eramangarria* |
| التيليفون | *mugikorra / sakelakoa* |
| الطابليط | *tableta* |
| الشاشة | *pantaila* |
| الكلافيي | *teklatua* |
| الفأرة (السوري) | *sagua* (إيه، بحال الحيوان!) |
| الكيتمان | *entzungailuak* |

## الشبكة والحسابات

| الدارجة | الباسكية |
|---|---|
| الشبكة / الأنترنيت | *sarea / internet* |
| الويفي | *wifia* |
| الإيميل | *posta elektronikoa* |
| المستخدم | *erabiltzailea* |
| كلمة السر | *pasahitza* |
| التطبيق | *aplikazioa* |
| السيت ويب | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — شنو هو كود الويفي؟
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — نسيت كلمة السر ودابا خاصني ندير وحدة جديدة. عاوتاني.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — باش تدير الحساب خاصك إيميل وكلمة السر.

## الأفعال الرقمية

| الدارجة | الباسكية |
|---|---|
| شعل / طفي | *piztu / itzali* |
| تيليشارجا | *deskargatu / jaitsi* |
| أنسطالا | *instalatu* |
| سجّل | *gorde* |
| مسح | *ezabatu* |
| صيفط / بارطاجا | *bidali / partekatu* |
| قلّب (فالأنترنيت) | *bilatu* |
| خدم (الجهاز) | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — البيسي ما خدامش مزيان؛ طفيه وشعلو — الحل ديال ديما.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — واش سجلتي التصاور؟ ما تمسح والو!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — كتيليشارجي التطبيق، كدير الحساب وصافي.

## حوار: الدعم التقني ديال العائلة

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **ملاحظة:** الباسكية الرقمية حية بزاف: اللوجيسيال الحر والويكيبيديا بالباسكية قويين، وتيليفونك كامل يقدر يكون بالباسكية (*Ezarpenak → Hizkuntza*). وإلا درتيها، راه حيلة واعرة للقراية: تغطيس يومي فابور.
