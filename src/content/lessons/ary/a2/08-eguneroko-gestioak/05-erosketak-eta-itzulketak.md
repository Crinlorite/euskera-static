الشرا راك عارفو من A1. هاد الدرس هو **المستوى 2 ديال الحانوت**: تقيس الحوايج، تتعارك مع القياسات و — الباطرون الأخير — **تبدل ولا ترجع** بلا ما تعرق. مع جوج صحاب قدام خدامين: *-egi* (بزاف) و NOR-NORI (*geratzen zait*).

## فبلاصة القياس

| الدارجة | الباسكية |
|---|---|
| واش نقدر نقيسو؟ | *Probatu dezaket?* |
| بلاصة القياس | *probalekua* |
| القياس | *neurria / talla* |
| شمن قياس كتلبس؟ | *Zein neurri erabiltzen duzu?* |
| جاني مزيان / ما جانيش | *Ondo / gaizki geratzen zait* |
| كبير / صغير بزاف | *Handiegia / txikiegia* |
| واش عندكم بلون آخر؟ | *Beste kolore batean baduzue?* |
| وبقياس كبر شوية؟ | *Eta neurri bat handiagoan?* |

> *— Praka hauek **probatu ditzaket**?*
>
> *— Noski, **probalekua** hor atzean dago.*
>
> *(bost minutu geroago)* *— Zer, **ondo geratzen zaizkizu**?*
>
> *— Ez… **txikiegiak dira**. **42an baduzue**?*

*Geratzen zait / zaizkizu* — NOR-NORI صافي: الحاجة (NOR) جات لـيّا أنا (NORI). فالجمع: *geratzen zaizkit* (جاوني).

## التبديل والرجوع

| الدارجة | الباسكية |
|---|---|
| بغيت نبدلو | *Aldatu nahi dut* |
| بغيت نرجعو | *Itzuli nahi dut* |
| واش غادي ترجعو ليا الفلوس؟ | *Dirua itzuliko didazue?* |
| التيكي | *tiketa* |
| فيه عيب | *Akats bat dauka* |
| جديد ما تلبسش | *Erabili gabe dago* |
| المدة ديال الرجوع | *Itzultzeko epea* |

> *— Egun on. Jertse hau **itzuli nahi nuke**. **Akats bat dauka** hemen, ikusten?*
>
> *— Egia da. **Tiketa badaukazu**?*
>
> *— Bai, hemen. **Dirua itzuliko didazue** ala aldatu behar dut?*
>
> *— Nahi duzun bezala. Dirua **txartelera itzuliko dizugu**, bi-hiru egunetan.*
>
> *— Primeran, eskerrik asko.*

شوف NOR-NORI-NORK مربوطين: *itzuliko didazue* (غادي ترجعوه ليا)، *itzuliko dizugu* (غادي نرجعوه ليك). الوحدة 03 خدامة فالحياة الحقيقية.

## الصولد والأثمنة (مراجعة بنكهة)

> ***Merkealdiak** daude: dena **%50ean**!* — كاين الصولد: كلشي بـ 50 %!
>
> *Deskontuarekin, **19,95 euro** bakarrik.* — مع التخفيض، غير 19,95 €.
>
> *Bi erosita, **hirugarrena doan**.* — شريتي جوج، التالت فابور.

## الخلاصة ديال الجيب

1. **القياس**: *Probatu dezaket? → Ondo/gaizki geratzen zait → -egi* للقياسات.
2. **التبديل**: *Aldatu nahi dut* (+ *beste neurri/kolore batean*).
3. **الرجوع**: *Itzuli nahi dut* + *tiketa* + *dirua itzuliko didazue?*
