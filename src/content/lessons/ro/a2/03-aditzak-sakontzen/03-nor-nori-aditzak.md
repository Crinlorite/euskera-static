Verbele **NOR-NORI** sunt acelea în care ceva (NOR) "i se întâmplă cuiva" (NORI). Subiectul gramatical este **lucrul**, nu persoana — exact ca verbul *a plăcea* în română: *îmi place filmul* (mie îmi place el, filmul).

La A1 ai văzut deja *gustatzen zait*. La A2, extinzi acest model la alte verbe foarte utile.

## Formele auxiliarului NOR-NORI la prezent

Pentru NOR singular:

| NORI | Formă | Română |
|---|---|---|
| niri | **zait** | îmi |
| zuri | **zaizu** | îți |
| hari | **zaio** | îi |
| guri | **zaigu** | ne |
| zuei | **zaizue** | vă |
| haiei | **zaie** | le |

Pentru NOR **plural**:

| NORI | Formă plural | Română |
|---|---|---|
| niri | **zaizkit** | îmi (lucruri) |
| zuri | **zaizkizu** | îți |
| hari | **zaizkio** | îi |
| guri | **zaizkigu** | ne |
| zuei | **zaizkizue** | vă |
| haiei | **zaizkie** | le |

## Trecut: *zitzaidan, zitzaion*

| NORI | Trecut sing. | Trecut pl. |
|---|---|---|
| niri | **zitzaidan** | **zitzaizkidan** |
| zuri | **zitzaizun** | **zitzaizkizun** |
| hari | **zitzaion** | **zitzaizkion** |
| guri | **zitzaigun** | **zitzaizkigun** |
| haiei | **zitzaien** | **zitzaizkien** |

## Verbe cu acest model

| Verb | Semnificație | Exemplu |
|---|---|---|
| *gustatu* | a plăcea | *Filmak gustatzen zaizkit* (îmi plac filmele) |
| *iruditu* | a părea | *Ondo iruditzen zait* (mi se pare bine) |
| *ahaztu* | a uita | *Ahaztu zait izena* (am uitat numele) |
| *erori* | a cădea | *Erori zaizu boligrafoa* (ți-a căzut pixul) |
| *gertatu* | a i se întâmpla | *Zer gertatu zaizu?* (ce ți s-a întâmplat?) |
| *interesatu* | a interesa | *Politika interesatzen zait* (mă interesează politica) |
| *axola izan* | a-i păsa | *Ez zait axola* (nu-mi pasă) |

## Structura: subiectul este lucrul

> **NORI + NOR + verb + auxiliar NOR-NORI**

| Română | Bască | Notație |
|---|---|---|
| Îmi place filmul | *Niri zinea **gustatzen zait*** | NORI + NOR sing + zait |
| Îmi plac filmele | *Niri filmak **gustatzen zaizkit*** | NORI + NOR pl + zaizkit |
| Ți se pare bine | *Zuri ondo **iruditzen zaizu*** | NORI + NOR + zaizu |
| I-a căzut o carte | *Hari liburu bat **erori zaio*** | NORI + NOR sing + zaio |
| Am uitat cheile | *Niri giltzak **ahaztu zaizkit*** | NORI + NOR pl + zaizkit |

> **Sfat:** persoana afectată este în cazul NORI (-ari/-ei) și de obicei apare la început. Lucrul este subiectul gramatical, iar verbul se acordă cu acesta.

## *Gustatzen zait* la trecut — *gustatu zitzaidan*

Pentru a vorbi despre gusturi la trecut:

> *Filma asko **gustatu zitzaidan**.* — Filmul mi-a plăcut mult.
>
> *Ez zitzaion gustatu opari hori.* — Nu i-a plăcut acel cadou.

> Atenție: *gustatu zitzaidan* (= mi-a plăcut, acțiune încheiată) vs *gustatzen zitzaidan* (= îmi plăcea, obișnuință).

## *Iruditu* (a părea) — opinie personală

Una dintre cele mai utile formule pentru A2:

| Română | Bască |
|---|---|
| Mi se pare bine | *Ondo iruditzen zait* |
| Mi se pare interesant | *Interesgarria iruditzen zait* |
| Cum ți se pare? | *Zer iruditzen zaizu?* |
| Mi se pare ciudat | *Bitxia iruditzen zait* |
| Mi se pare că da | *Baietz iruditzen zait* |

## *Ahaztu zait* — am uitat

| Română | Bască |
|---|---|
| Am uitat | *Ahaztu zait* |
| Am uitat cheile | *Giltzak ahaztu zaizkit* |
| Uită tot | *Dena ahazten zaio* |
| Să nu uiți! | *Ez zaizula ahaztu!* |

## Mini-dialog

> *— Olatz, **zer iruditzen zaizu** Bilboko jatetxe berria?*
>
> *— Asko **gustatu zait**. Bereziki bigarren platerak: **interesgarriak iruditu zaizkit**.*
>
> *— Eta, jakin nahi nuen, **ahaztu zaizu** zer eskatu zenuen?*
>
> *— Bai, izenak ez **zaizkit gogoratzen**, baina arraina zen, ziur.*

## Capcane frecvente

1. **Subiectul ergativ NU există aici.** Nu spune *\*Nik gustatzen dut* (este o greșeală foarte comună): corect este *Niri gustatzen zait*. Persoana nu este cea care acționează.
2. **Acordul NOR.** Dacă lucrul este la plural, auxiliarul este la plural: *zaizkit, zaizkio, zaizkigu...*
3. **Unele regiuni folosesc alte variante** (*zaidak, zaidan* în hitano), dar în *batua* formele standard sunt cele din tabel.

> **Notă culturală:** vorbitorii de limba bască tind să abuzeze (cu afecțiune) de *iruditzen zait* pentru a-și exprima opinia cu o oarecare prudență: *interesgarria iruditzen zait*, *bitxia iruditzen zait*, *ez zait ondo iruditzen*. Este versiunea bască a expresiei nuanțate "mi se pare că...".
