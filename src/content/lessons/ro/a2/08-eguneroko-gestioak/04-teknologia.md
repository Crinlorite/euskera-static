De la hârtie la pixel: lecția de **tehnologie cotidiană**. Vocabular pe care îl folosești de o sută de ori pe zi — acum în bască, care se mândrește și cu cuvinte transparente și bine construite (*pasahitza* = cuvânt de trecere; *sakelakoa* = „cel de buzunar”).

## Aparatele

| Română | Bască |
|---|---|
| Calculatorul | *ordenagailua* |
| Laptopul | *eramangarria* |
| Mobilul | *mugikorra / sakelakoa* |
| Tableta | *tableta* |
| Ecranul | *pantaila* |
| Tastatura | *teklatua* |
| Mouse-ul | *sagua* (da, animalul!) |
| Căștile | *entzungailuak* |

## Rețeaua și conturile

| Română | Bască |
|---|---|
| Rețeaua / internetul | *sarea / internet* |
| Wi-Fi-ul | *wifia* |
| E-mailul / poșta electronică | *posta elektronikoa* |
| Utilizatorul | *erabiltzailea* |
| Parola | *pasahitza* |
| Aplicația | *aplikazioa* |
| Pagina web | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Care este parola de la Wi-Fi?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — Am uitat parola și acum trebuie să creez una nouă. Iar.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Pentru a crea contul ai nevoie de e-mail și parolă.

## Verbele digitale

| Română | Bască |
|---|---|
| A porni / a opri | *piztu / itzali* |
| A descărca | *deskargatu / jaitsi* |
| A instala | *instalatu* |
| A salva | *gorde* |
| A șterge | *ezabatu* |
| A trimite / a partaja | *bidali / partekatu* |
| A căuta (pe internet) | *bilatu* |
| A funcționa / a merge | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — Calculatorul merge prost; oprește-l și pornește-l — soluția dintotdeauna.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Ai salvat pozele? Nu șterge nimic!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Descarci aplicația, creezi contul și gata.

## Dialog: suport tehnic în familie

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Notă:** basca digitală este foarte vie: software-ul liber și Wikipedia în bască sunt puternice, și întregul tău mobil poate fi în bască (*Ezarpenak → Hizkuntza*). Setarea aceasta este, de fapt, un truc de studiu genial: imersiune zilnică gratuită.
