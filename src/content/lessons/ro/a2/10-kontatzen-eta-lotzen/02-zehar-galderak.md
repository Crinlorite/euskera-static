Până azi întrebai direct: *Etorriko da?* Acum vei învăța să întrebi **indirect**: *nu știu **dacă va veni***, *întreabă-l **dacă are timp***. Sunt *zehar-galderak* (întrebări indirecte), iar șiretlicul lor este o singură literă: **-n**.

## Regula: auxiliarul preia -n

| Directă | Indirectă |
|---|---|
| *Etorriko **da**?* | *Ez dakit etorriko **den*** |
| *Nor **da**?* | *Ez dakit nor **den*** |
| *Non **dago**?* | *Ez dakit non **dagoen*** |
| *Zer nahi **du**?* | *Ez dakit zer nahi **duen*** |
| *Denborarik **dauka**?* | *Galdetu ea denborarik **daukan*** |

Cum se lipește **-n**: *da → den* · *dago → dagoen* · *du → duen* · *dauka → daukan* · *gara → garen* · *dute → duten*. (Dacă se termină în vocală, -n; restul, -en. Urechea ta se va obișnui în două zile.)

## "Ea" — cuvântul joker

Pentru întrebările de da/nu, limba bască adaugă ***ea*** (= "să vedem dacă / dacă"):

> *Galdetu diot **ea gurekin bazkalduko duen**.* — L-am întrebat dacă va mânca cu noi.
>
> *Ikusiko dugu **ea eguraldi ona egiten duen**.* — Vom vedea dacă va fi vreme bună.
>
> ***Ea garaiz iristen garen**!* — Să vedem dacă ajungem la timp!

Acest ultim *ea…!* de sine stătător este bască pur vorbită: dorință + suspans într-un singur cuvânt.

## Verbele care le cer

| Română | Bască |
|---|---|
| Nu știu dacă… | *Ez dakit … -(e)n* |
| Știi dacă…? | *Badakizu … -(e)n?* |
| Întreabă-l dacă… | *Galdetu (iezaiozu) ea … -(e)n* |
| Nu-mi amintesc dacă… | *Ez naiz gogoratzen … -(e)n* |
| Nu sunt sigur dacă… | *Ez nago ziur … -(e)n* |

## În acțiune

> *— **Badakizu zer ordutan hasten den** kontzertua?*
>
> *— Ez, baina Aneri **galdetuko diot ea dakien**.*
>
> *— Eta **ea sarrerarik geratzen den** ere galdetu, mesedez!*
>
> *— Lasai. **Ea zorte ona dugun**!*

## Contrastul cu -la (falsul prieten)

Nu confunda întrebarea indirectă cu afirmația indirectă (unitatea 04):

> *Esan dit etorriko **dela**.* — Mi-a spus **că** va veni. (afirmație → **-la**)
>
> *Galdetu dit **ea** etorriko **den**.* — M-a întrebat **dacă** voi veni. (întrebare → **-n**)

**Că = -la · Dacă = (ea) -n.** Cu acest pont, lecția este ca și câștigată.
