A vorbi despre **stil de viață** și **mediu înconjurător** este un bloc clasic de A2: se amestecă vocabular nou cu fraze de obligație și sfat (*behar dugu*, *komeni da*, *garrantzitsua da*) pe care le stăpânești deja de la A1.

## Obiceiuri sănătoase

| Română | Bască |
|---|---|
| A face sport | *kirola egin* |
| A merge pe jos / a se plimba | *paseatu* / *ibili* |
| A alerga | *korrika egin* |
| A merge cu bicicleta | *bizikletaz ibili* |
| A mânca fructe și legume | *fruta eta barazkiak jan* |
| A bea apă | *ura edan* |
| A dormi bine | *ondo lo egin* |
| A fuma | *erre* |
| A bea alcool | *alkohola edan* |
| A nu abuza de sare | *gatzaz ez abusatu* |

> Fraze tipice:
>
> - *Kirola egiten dut astean hiru aldiz.* — Fac sport de trei ori pe săptămână.
> - *Erretzeari utzi diot.* — M-am lăsat de fumat.
> - *Ez dut alkoholik edaten astegunetan.* — Nu beau alcool în timpul săptămânii.

## Frecvența: *X aldiz*

Pentru a spune „de X ori” folosești formula **număr + aldiz**:

| Română | Bască |
|---|---|
| O dată pe zi | *Egunean behin* |
| De două ori pe săptămână | *Astean bi aldiz* / *birritan* |
| De trei ori pe lună | *Hilean hiru aldiz* |
| De multe ori | *Askotan* |
| Uneori | *Batzuetan* |
| De puține ori | *Gutxitan* |
| Niciodată | *Inoiz ez* |

## Mediu înconjurător — *ingurumena*

| Română | Bască |
|---|---|
| Mediu înconjurător | *ingurumena* |
| Natură | *natura* |
| Poluare | *kutsadura* |
| Gunoi | *zaborra* |
| A recicla | *birziklatu* |
| A reduce | *gutxitu* / *murriztu* |

## Containerele

| Culoare obișnuită | Bască | Pentru ce |
|---|---|---|
| Albastru | *edukiontzi urdina* | papera / hârtie |
| Galben | *edukiontzi horia* | plastikoa / plastic |
| Verde | *edukiontzi berdea* | beira / sticlă |
| Maro | *edukiontzi marroia* | organikoa / organic |
| Gri | *edukiontzi grisa* | hondakinak / resturi |

## Fraze utile pentru a-ți exprima opinia

- *Garrantzitsua da birziklatzea.* — Este important să reciclăm.
- *Komeni da kirola egitea.* — Este indicat să facem sport.
- *Beharrezkoa da kutsadura gutxitzea.* — Este necesar să reducem poluarea.
- *Ez dut uste plastikoa ona denik.* — Nu cred că plasticul este bun.

> Aceste structuri (*-tzea + adjectiv + da*) sunt formula de A2 pentru „este important / este indicat / este necesar să faci X”. Le vom aprofunda în unitatea 4.

## Viața de cartier

| Română | Bască |
|---|---|
| Cartier | *auzoa* |
| Vecin/ă | *bizilaguna* |
| Asociație | *elkartea* |
| Voluntariat | *boluntariotza* |
| Sărbătorile cartierului | *auzoko jaiak* |
| A participa | *parte hartu* |
| Ședință | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## Mini-text model

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **Notă culturală:** *auzo-elkarteak* (asociațiile de locatari) sunt o piesă fundamentală a vieții sociale în multe localități din Euskal Herria. Organizează sărbători, ateliere de limba bască, ieșiri la munte și campanii de mediu. Participarea este una dintre cele mai bune modalități de a practica limba în uz real.
