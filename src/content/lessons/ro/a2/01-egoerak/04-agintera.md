**Imperativul** (*agintera*) se folosește pentru a da instrucțiuni, a face cereri și a da sfaturi. În limba bască este **mult mai simplu decât pare**: forma cea mai folosită coincide aproape întotdeauna cu **participiul** verbului.

## Regula de bază: folosește participiul

Pentru multe ordine cotidiene, verbul apare la forma sa de participiu, fără auxiliar:

| Română | Bască |
|---|---|
| Ia | *Hartu* |
| Așază-te | *Eseri* |
| Ridică-te | *Jaiki* |
| Scrie | *Idatzi* |
| Citește | *Irakurri* |
| Ascultă | *Entzun* |
| Repetă | *Errepikatu* |
| Așteaptă | *Itxoin* |
| Închide ușa | *Itxi atea* |
| Deschide fereastra | *Ireki leihoa* |

> Aceasta este **forma cea mai folosită** la cursuri, pe stradă și în instrucțiunile scrise. Servește atât pentru *zu*, cât și pentru *zuek*.

## Forme sintetice (trinkoak): *zatoz*, *zoaz*

Unele verbe foarte frecvente au forme sintetice specifice pentru imperativ. Acestea sunt cele pe care merită să le memorezi:

| Verb | Tu (zu) | Voi (zuek) |
|---|---|---|
| *etorri* (a veni) | **Zatoz** | **Zatozte** |
| *joan* (a merge) | **Zoaz** | **Zoazte** |
| *ekarri* (a aduce) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (a duce) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (a fi / a sta) | **Egon** / **Lasai** (stai liniștit(ă)!) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## Imperativul NOR-NORI-NORK: *emadazu*, *esadazu*

Când dai un ordin cu dublu complement („dă-mi asta”, „spune-i aia”), limba bască are forme compacte foarte utile:

| Română | Bască |
|---|---|
| Dă-mi | *Emadazu* / *Eman iezadazu* |
| Spune-mi | *Esadazu* / *Esan iezadazu* |
| Dă-i | *Emaiozu* / *Eman iezaiozu* |
| Spune-i | *Esaiozu* / *Esan iezaiozu* |
| Dă-ne | *Emaguzu* |
| Dați-mi | *Emadazue* |

Aceste forme sunt lungi de învățat; la nivelul A2 este suficient să știi **emadazu / esadazu / emaiozu / esaiozu** și să înțelegi că provin de la verbele *eman* / *esan*.

## „Te rog” și formule de politețe

Imperativul în limba bască **nu sună brusc** dacă adaugi un cuvânt de politețe:

- *Mesedez* — te rog / vă rog
- *Ahal baduzu* — dacă poți
- *Faborez* (variantă colocvială)
- *Eskerrik asko aldez aurretik* — mulțumesc anticipat

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## Instrucțiuni (rețete, anunțuri, la curs)

Imperativul este forma standard în:

- **Rețete:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **Afișe:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **La curs:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **La medic:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## Mini-text

> *La școala de bucătari, profesorul spune:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **Notă culturală:** în limba bască, tonul **poruncitor** al imperativului este atenuat de intonație și context, nu atât de des prin perifraze („ai putea...”). Însoțirea ordinului cu *mesedez* sau cu un zâmbet este de obicei suficientă. Dacă vrei ceva mai politicos, spune *eman ahal didazu...?* (îmi poți da...?).
