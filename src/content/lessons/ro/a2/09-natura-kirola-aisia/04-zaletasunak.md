Ce faci când nu faci nimic? Această lecție este despre **hobby-uri** — și despre elementul gramatical care le guvernează: verbul transformat în substantiv cu **-tzea** (*irakurtzea* = "cititul").

## Elementul: -t(z)ea

De la A1 cunoști *gustatzen zait* cu lucruri (*kafea gustatzen zait*). Pentru a-ți plăcea o **activitate**, verbul devine substantiv:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| Română | Bască |
|---|---|
| Îmi place să citesc | *Irakurtzea gustatzen zait* |
| Îmi place mult să gătesc | *Asko gustatzen zait sukaldatzea* |
| Îi place să cânte | *Abestea gustatzen zaio* |
| Ne place să călătorim | *Bidaiatzea gustatzen zaigu* |
| Nu-mi place deloc să mă trezesc devreme | *Ez zait batere gustatzen goiz jaikitzea* |

Tot NOR-NORI pe care îl știi deja (*zait, zaio, zaigu…*) continuă să fie la comandă; se schimbă doar "ce".

## Catalogul de hobby-uri

| Română | Bască |
|---|---|
| Citit / scris | *irakurtzea / idaztea* |
| Ascultat muzică | *musika entzutea* |
| Cântat / dansat | *abestea / dantzatzea* |
| Gătit | *sukaldatzea* |
| Făcut fotografii | *argazkiak ateratzea* |
| Pictat / desenat | *margotzea / marraztea* |
| Călătorit | *bidaiatzea* |
| Îngrijit grădina de legume | *baratzea zaintzea* |
| Jocurile video | *bideo-jokoak* |
| Cusut / tricotat | *jostea / puntua egitea* |

## A întreba și a te lăuda

> ***Zer egitea gustatzen zaizu** denbora librean?* — Ce îți place să faci în timpul liber?
>
> ***Zein da zure zaletasunik gogokoena**?* — Care este hobby-ul tău preferat?
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — Hobby-ul meu preferat este gătitul: în fiecare weekend încerc o rețetă nouă.

## Trei structuri, trei nuanțe (recapitulare fină)

| Structură | Exemplu | Înseamnă |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | îmi place (hobby) |
| **-tzen dakit** | *Margotzen dakit* | știu să o fac (abilitate) |
| **-tzen ari naiz** | *Margotzen ari naiz* | o fac (acum) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — Nu știu să tricotez, dar mi-ar plăcea să învăț. (Acest elegant *gustatuko litzaidake* îl vei stăpâni la B1 — ți-l lăsăm aici ca aperitiv.)

## Dialog

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*
>
> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
>
> *— **Sukaldatzea** eta gero… **jatea**, noski.*
>
> *— Hori ere zaletasuna da?*
>
> *— Nire etxean, **kirola**.* 😄
