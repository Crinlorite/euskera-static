Pentru A2, exprimarea opiniei este una dintre **competențele cheie**. Această lecție îți oferă:

1. Formulele pentru a introduce o opinie.
2. Completiva cu **-ela** (că…).
3. Negarea opiniei cu **-enik** (nu cred că…).
4. Exprimarea cauzei cu **-lako** și **zeren** (pentru că…).

## Introducerea unei opinii

| Română | Bască |
|---|---|
| Cred că… | *Uste dut...* |
| Mi se pare că… | *Iruditzen zait...* |
| În opinia mea | *Nire ustez* |
| Pentru mine | *Niretzat* |
| Știu că… | *Badakit...* |
| Sunt de acord | *Ados nago* |
| Nu sunt de acord | *Ez nago ados* |
| Ai dreptate | *Arrazoia duzu* |
| Este adevărat | *Egia da* |

## Completiva cu -**ela**

Când opinia introduce o altă propoziție, verbul subordonat primește sufixul **-(e)la** („că…”). Schimbarea este foarte regulată:

| Fără sufix | Cu -ela | Română |
|---|---|---|
| *da* | *dela* | că este / că se află |
| *naiz* | *naizela* | că (eu) sunt |
| *zara* | *zarela* | că tu ești |
| *du* | *duela* | că îl are |
| *ditu* | *dituela* | că îi are |
| *dut* | *dudala* | că (eu) îl am |
| *zen* | *zela* | că era |
| *nuen* | *nuela* | că (eu) îl aveam |
| *etorriko da* | *etorriko **dela*** | că va veni |

> *Uste dut Anboto pozik **dagoela**.* — Cred că Anboto este fericit.
>
> *Badakit gauza zailak gertatu **direla**.* — Știu că s-au întâmplat lucruri dificile.
>
> *Argi dago euskaraz hobeto hitz egiten **duela**.* — Este clar că vorbește mai bine în bască.

## Negarea opiniei: -**enik**

Când spui „**nu cred că** + verb”, sufixul subordonatei se schimbă în **-enik**:

| Română | Bască |
|---|---|
| Nu cred că este bun | *Ez dut uste ona **denik*** |
| Nu cred că vor veni | *Ez dut uste etorriko **direnik*** |
| Nu mi se pare că este adevărat | *Ez zait iruditzen egia **denik*** |

> Este forma specifică de negație cu verbe de opinie. La afirmativ: *uste dut ona **dela***. La negativ: *ez dut uste ona **denik***.

## Alte structuri pentru exprimarea opiniei

Aceste structuri combină adjectiv + *da* + propoziție cu -ela:

| Română | Bască |
|---|---|
| Este clar că… | *Argi dago + -(e)la* |
| Este important să… | *Garrantzitsua da + -tzea* |
| Este adevărat că… | *Egia da + -(e)la* |
| Este posibil să… | *Posible da + -tzea* |
| Este logic că… | *Logikoa da + -(e)la* |
| Este interesant să… | *Interesgarria da + -tzea* |

> *Argi dago ikasten ari **zarela**.* — Este clar că studiezi.
>
> *Garrantzitsua da euskaraz **hitz egitea**.* — Este important să vorbești în bască.

## Cauzalele: *-lako* și *zeren*

Pentru a exprima **cauza** („pentru că”), ai două opțiuni:

### Sufixul -**lako** (subordonat, cel mai comun)

> **verbo + -lako**

| Română | Bască |
|---|---|
| Pentru că a venit | *Etorri **delako*** |
| Pentru că mi-e foame | *Goseak nagoelako* (o *gose naizelako*) |
| Pentru că este important | *Garrantzitsua **delako*** |
| Pentru că nu-mi place | *Ez zaidalako gustatzen* |

> *Etxean nago **gaixorik nagoelako**.* — Stau acasă pentru că sunt bolnav.
>
> *Bilbora joaten naiz lana **bertan dudalako**.* — Merg la Bilbao pentru că am serviciul acolo.

### Conjuncția *zeren* (la începutul propoziției)

| Română | Bască |
|---|---|
| Pentru că este important | *…, **zeren** garrantzitsua baita* |
| …, deoarece a venit | *…, **zeren** etorri baita* |

> Este forma „romană” de exprimare a cauzei, mai formală sau jurnalistică. În vorbirea curentă se preferă *-lako*.

## Mini-dezbatere

> *— Olatz, **uste dut** Bilbo Donostia baino interesgarriagoa **dela**.*
>
> *— **Ez nago ados**. Donostia askoz politagoa da, **uste dut**, itsasoa **duelako** ondoan.*
>
> *— **Egia da** itsasoa duela, baina Bilbon **museo gehiago daudela ere egia da**.*
>
> *— Bai, baina **iruditzen zait** giroa, kalea, jendea... Donostian goxoagoak **direla**. Eta Donostiako pintxoak Bilbokoak **baino hobeak direla** ere bai!*

## Structuri utile (listă)

| Română | Bască |
|---|---|
| Cred că este important | *Garrantzitsua **dela** uste dut* |
| Știu că are dreptate | *Arrazoia **duela** badakit* |
| Nu cred că vor veni | *Ez dut uste etorriko **direnik*** |
| Este clar că are probleme | *Argi dago arazoak **dituela*** |
| Pentru că este bolnav | *Gaixorik **dagoelako*** |
| Pentru că este frig | *Hotz **egiten duelako*** |

## Capcane frecvente

1. **Nu uita de dubla față: -ela la afirmativ, -enik la negativul de opinie.**
2. **Sufixul -ela se atașează verbului conjugat**, nu participiului: *etorriko da → etorriko **dela***.
3. **Dacă opinia este foarte puternică, în spaniolă folosești conjunctivul**, în bască nu există o diferență clară: *uste dut ondo dagoela* (cred că este bine) și *zalantza dut ondo dagoenik* (mă îndoiesc că este bine) folosesc forme diferite, dar nu un „conjunctiv” formal.

> **Notă pedagogică:** formula *Nire ustez + propoziție + -lako + propoziție* este probabil cel mai eficient instrument de nivel A2 pentru a exprima opinii și a argumenta. Exemplu model:
>
> *Nire ustez **euskara ikastea garrantzitsua da** **gure herriaren hizkuntza delako**.*
> („În opinia mea, a învăța basca este important pentru că este limba poporului nostru”.)
