Această lecție completează comparațiile cu încă două elemente:

1. **Exces și lipsă** (-egi, gehiegi, gutxiegi).
2. **Comparativul progresiv** (din ce în ce mai mult / mai puțin: *gero eta...*).

Plus câțiva modificatori utili pentru a nuanța (*pixka bat, askoz, dezente*).

## Sufixul -**egi** — "prea"

Pentru a spune că ceva este **excesiv**, adaugi **-egi** la adjectiv (și apoi **-a** final dacă este însoțit de un substantiv determinat):

| Adjectiv | Excesiv |
|---|---|
| *handia* (mare) | *handi**egia*** (prea mare) |
| *txikia* (mic) | *txiki**egia*** |
| *garestia* (scump) | *garesti**egia*** |
| *beroa* (fierbinte) | *bero**egia*** |
| *hotza* (frig) | *hotz**egia*** |
| *zaila* (dificil) | *zail**egia*** |
| *azkarra* (rapid) | *azkarr**egia*** |

> *Alkandora hau **handiegia** da niretzat.* — Această cămașă este prea mare pentru mine.
>
> *Kafea **beroegi** dago.* — Cafeaua este prea fierbinte.
>
> *Ikastaroa **zailegia** zen guretzat.* — Cursul era prea dificil pentru noi.

## *Gehiegi* și *gutxiegi*

Ca adverbe independente:

| Română | Euskera |
|---|---|
| Prea mult | *gehiegi* |
| Prea puțin / insuficient | *gutxiegi* |
| Prea mulți oameni | *jende **gehiegi*** |
| Prea puțină apă | *ur **gutxiegi*** |

> *Gehiegi jan dut.* — Am mâncat prea mult.
>
> *Gutxiegi lo egiten duzu.* — Dormi (prea) puțin.
>
> *Hori **gehiegi** da niretzat.* — Asta e prea mult pentru mine.

## Comparativul progresiv: *gero eta + -ago*

Pentru "**din ce în ce mai X**" sau "**din ce în ce mai puțin X**", limba bască folosește o formulă foarte expresivă:

> **gero eta + adjetivo/adverbio-ago(a)**

| Română | Euskera |
|---|---|
| Din ce în ce mai scump | *Gero eta **garestiagoa*** |
| Din ce în ce mai frig | *Gero eta **hotzagoa*** |
| Din ce în ce mai bine | *Gero eta **hobea*** |
| Din ce în ce mai rău | *Gero eta **okerragoa*** |
| Din ce în ce mai mult | *Gero eta **gehiago*** |
| Din ce în ce mai puțin | *Gero eta **gutxiago*** |
| Din ce în ce mai repede | *Gero eta **azkarrago*** |
| Din ce în ce mai încet | *Gero eta **polikiago*** |

> *Bilbo gero eta handiagoa da.* — Bilbao este din ce în ce mai mare.
>
> *Eguraldia gero eta okerrago dago.* — Vremea este din ce în ce mai rea.
>
> *Gazteek gero eta gutxiago hitz egiten dute euskaraz.* — Tinerii vorbesc din ce în ce mai puțin în bască.

> **Truc mnemonic:** *gero eta* înseamnă literal "apoi și" — ideea este "apoi, și apoi, și apoi mai mult...". Este modul basc de a exprima progresia.

## *Hain* — "atât de" (cu sau fără negație)

| Română | Euskera |
|---|---|
| Este atât de mare | *Hain handia da* |
| Nu este atât de scump | *Ez da **hain** garestia* |
| Este atât de frumos! | *Hain polita da!* |

> Pentru "nu este atât de... ca..." se folosește *bezain* (lecția anterioară):
>
> *Ez da zuk uste duzun bezain ona.* — Nu este atât de bun pe cât crezi tu.

## Modificatori de cantitate

Pentru a nuanța comparațiile:

| Română | Euskera | Exemplu |
|---|---|---|
| Puțin | *pixka bat* | *Pixka bat handiagoa* (puțin mai mare) |
| Ceva / un pic | *zerbait / zertxobait* | *Zertxobait txikiagoa* (un pic mai mic) |
| Destul de | *dezente* | *Dezente hobea* (considerabil mai bun) |
| Mult | *askoz* | *Askoz hobea* (mult mai bun) |
| Foarte mult | *askoz hobea / askoz garestiagoa* | |

> *Etxe hau zurea **baino askoz** handiagoa da.* — Această casă este mult mai mare decât a ta.
>
> *Pixka bat goizago etorriko naiz.* — Voi veni puțin mai devreme.

## *Hain... ezen* / *hainbeste...* (registru elevat)

Dincolo de nivelul A2 strict, este util să recunoașteți:

- *Hain* + adjectiv + *non/ezen* — atât de... încât: *Hain pozik zegoen, non kantatzen hasi zen* (era atât de fericit încât a început să cânte).
- *Hainbeste* — atât/atâta (cantitate emfatică): *Hainbeste lan dago!*

## Mini-text

> *Garazi sukaldari ona da, baina kafea **beroegi** ipintzen du beti. Lehengo egunean **hain bero** zegoen, ezen ezin nuen edan! Eta hori ez da dena: pintxo bakoitzean olio **gehiegi** botatzen du. **Pixka bat gutxiago** beharko luke. Hala ere, hura **gero eta hobea** da: orain dela urtebete askoz **okerragoa** zen.*

## Mini-dialog

> *— Olatz, etxe berri hori zer moduz?*
>
> *— Eder askoa, baina **garestiegia** zen guretzat. Eta logelak **txikiegiak** ziren.*
>
> *— Eta orain bilatzen ari zaretena nolakoa da?*
>
> *— **Gero eta zailagoa** da etxebizitza on bat aurkitzea. Prezioak **gero eta altuagoak** dira eta etxebizitza on guztiek dute lehia **gehiegi**.*

> **Notă culturală:** lipsa locuințelor la prețuri accesibile (*etxebizitza*) este un subiect recurent în orice conversație de nivel A2 despre actualitate: *gero eta garestiago, pisu eskuragarri gutxiegi, askoz okerrago lehen baino*. Această lecție îți oferă vocabularul pentru a participa.
