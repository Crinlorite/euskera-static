Comparația este una dintre cele mai cotidiene acțiuni ale limbajului: *acesta este mai mare decât acela*, *eu sunt mai scund decât tine*, *omleta este mai bună decât ieri*. În bască, formula este foarte regulată și, odată ce o stăpânești, deschide o mulțime de fraze noi.

## Formula

> **X baino Y-AGO(A)**

- **baino** se plasează între cei doi termeni comparați — echivalează cu "decât".
- **-ago** se adaugă adjectivului sau adverbului (precum "-er" din engleză sau marca de comparativ din română).
- Dacă este însoțit de un substantiv articulat, adjectivul poartă **-a** sa obișnuită: *altuago**a***.

| Română | Bască |
|---|---|
| Mai mare | *handi**agoa*** |
| Mai mic | *txiki**agoa*** |
| Mai scump | *garesti**agoa*** |
| Mai frumos | *polit**agoa*** |
| Mai rapid | *azkar**agoa*** |

## Fraze tipice

| Română | Bască |
|---|---|
| Lander este mai înalt decât Olatz | *Lander Olatz **baino** altu**agoa** da* |
| Această casă este mai mare decât aceea | *Etxe hau hura **baino** handi**agoa** da* |
| Bilbao este mai mare decât Donosti | *Bilbo Donostia **baino** handi**agoa** da* |
| Cafeaua este mai scumpă decât ceaiul | *Kafea tea **baino** garesti**ago** dago* |
| Garazi aleargă mai repede decât mine | *Garazik nik **baino** azkarrago **egiten du korrika*** |

> **Ordine:** în bască, "decât" (*baino*) se plasează între cele două lucruri comparate, nu după adjectiv. **X baino Y-agoa** înseamnă literal "X decât Y-mai".

## Adjective neregulate

Unele adjective nu urmează regula generală și este bine să le memorați:

| Română | Bască |
|---|---|
| Bun → mai bun | *ona → **hobea*** |
| Rău → mai rău | *txarra → **okerragoa*** |
| Mult → mai mult | *asko → **gehiago*** |
| Puțin → mai puțin | *gutxi → **gutxiago*** |

> *Liburu hau hura **baino hobea** da.* — Această carte este mai bună decât aceea.
>
> *Garazik nik **baino gehiago** ikasten du.* — Garazi învață mai mult decât mine.

## Comparativul cu verbe

Când compari **acțiuni** sau **cantități**, *gehiago / gutxiago* funcționează ca adverb:

| Română | Bască |
|---|---|
| Muncesc mai mult decât tine | *Zuk **baino gehiago** lan egiten dut* |
| Învață mai puțin decât înainte | *Lehen **baino gutxiago** ikasten du* |
| Mănânc mai multe fructe decât legume | *Barazkiak **baino fruta gehiago** jaten dut* |

> *Gehiago* și *gutxiago* se plasează **înainte** de verb sau de substantivul modificat, iar *baino* își păstrează locul între cei doi termeni.

## Comparativul cu adverbe

| Adverb | Comparativ |
|---|---|
| *azkar* (rapid) | *azkarrago* |
| *poliki* (încet) | *polikiago* |
| *ondo* (bine) | *hobeto* (neregulat) |
| *gaizki* (rău) | *okerrago* |
| *berandu* (târziu) | *beranduago* |
| *goiz* (devreme) | *goizago* |

> *Hobeto egiten duzu lan.* — Lucrezi mai bine.
>
> *Goizago etorriko naiz bihar.* — Voi veni mai devreme mâine.

## Negația: "mai puțin decât"

Pentru "mai puțin decât", formula naturală este **gutxiago + baino**:

> *Lander nik baino **gutxiago** lan egiten du.* — Lander muncește mai puțin decât mine.

Sau cu comparativul inversat:

> *Olatz Lander baino **txikiagoa** da.* (= Lander este mai înalt decât Olatz, formulat invers.)

## Negații cu *hain* — "nu atât de"

O formulă foarte productivă:

| Română | Bască |
|---|---|
| Nu este atât de scump | *Ez da **hain** garestia* |
| Nu atât de repede | *Ez **hain** azkar* |
| Nu este atât de mare pe cât credeai | *Ez da uste zenuen **bezain** handia* |

> *Hain* se folosește pentru "atât de". Combinat cu *ez*, funcționează pentru a atenua comparațiile.

## Mini-dialog

> *— Anboto, etxe berria zer moduz?*
>
> *— Aurrekoa **baino handiagoa** da, eta argia ere **askoz argiagoa** da. Baina logelak **txikiagoak** dira.*
>
> *— Eta kalea?*
>
> *— Lehen baino **lasaiagoa**: ez dago **hainbeste** autorik.*

## Truc mnemonic

Memorează formula ca pe un bloc:

> **X baino Y-agoa da.**

Iar pentru cele neregulate: **hobea, okerragoa, gehiago, gutxiago**. Cu acestea acoperi 95% din comparațiile de superioritate de nivel A2.

> **Notă culturală:** în vorbirea de zi cu zi vei auzi și expresii întărite: *askoz handiagoa* (mult mai mare), *pixka bat handiagoa* (un pic mai mare), *dezente handiagoa* (considerabil mai mare). Sunt nuanțe care, deși nu sunt strict de nivel A2, apar în orice conversație.
