În această lecție, completezi familia comparațiilor cu două piese:

1. **Egalitate** ("la fel de... ca", "la fel de mult ca"): *bezain*, *adina*, *beste*.
2. **Superlativ** ("cel mai..."): *-en + a*.

## Egalitate: *bezain*

Pentru "la fel de... ca" cu adjectiv sau adverb:

> **X bezain Y**

| Română | Bască |
|---|---|
| La fel de înalt ca tine | *Zu **bezain** altua* |
| La fel de frumoasă ca Donostia | *Donostia **bezain** polita* |
| La fel de bun ca tatăl său | *Aita **bezain** ona* |
| Nu la fel de rapid cum credeam | *Uste nuen **bezain** azkarra ez da* |

> Propoziție completă: *Lander **zu bezain altua** da.* — Lander este la fel de înalt ca tine.

## Egalitate de cantitate: *adina / beste*

Pentru "la fel de mult ca" cu substantiv sau cantitate:

| Română | Bască |
|---|---|
| La fel de mult ca tine | *Zuk **adina*** / *Zuk **beste*** |
| La fel de mulți bani ca mine | *Nik **adina** diru* |
| La fel de mulți ani ca Anboto | *Anbotok **adina** urte* |

> *Zuk adina urte ditut.* — Am la fel de mulți ani ca tine.
>
> *Garazik nik beste irakurtzen du.* — Garazi citește la fel de mult ca mine.

> **Diferența:** *bezain* se folosește cu calități (adjective/adverbe). *Adina/beste* se folosește cu cantități (substantive numărabile sau de cantitate). Uneori se fac greșeli — regula practică: dacă cuvântul care urmează este **adjectiv** → *bezain*; dacă este **substantiv sau număr** → *adina/beste*.

## Comparația de mod: *bezala / moduan*

O altă formă de egalitate, de data aceasta de **mod** sau **manieră**:

| Română | Bască |
|---|---|
| Ca tine | *Zu **bezala*** / *Zure **moduan*** |
| Fac ca tine | *Zuk egin duzun **moduan** egiten dut* |
| O casă ca a ta | *Zurea **bezalako** etxea* |
| Vorbește ca mama sa | *Amaren **moduan** hitz egiten du* |

> Compară:
>
> - *Zu **bezain** altua* — la fel de înalt ca tine (calitate)
> - *Zu **bezala** hitz egiten du* — vorbește ca tine (mod)
> - *Zuk **adina** ikasten du* — studiază la fel de mult ca tine (cantitate)

## Superlativ: *-en + a*

Pentru "cel mai..." adaugi **-en** la adjectiv sau adverb + articolul **-a**:

| Adjectiv | Superlativ |
|---|---|
| *handia* (mare) | *handi**ena*** (cel mai mare) |
| *txikia* (mic) | *txiki**ena*** |
| *polita* (frumos) | *polit**ena*** |
| *zaharra* (bătrân) | *zaharr**ena*** |
| *azkarra* (rapid) | *azkarr**ena*** |
| *garestia* (scump) | *garesti**ena*** |
| *ona* (bun) | **onena** / **hoberena** (neregulat) |
| *txarra* (rău) | **txarrena** / **okerrena** |

> *Liburu hau **politena** da.* — Această carte este cea mai frumoasă.
>
> *Donostia Euskal Herriko hiri **politena** da, askoren ustez.* — Donostia este cel mai frumos oraș din Euskal Herria, în opinia multora.

## Superlativ + grup: *-etan / -etako*

Când indici **în interiorul cărui grup**, folosești cazul locativ sau genitiv:

| Română | Bască |
|---|---|
| Cel mai înalt din clasă | *Klaseko **altuena*** |
| Cea mai rapidă din lume | *Munduko **azkarrena*** |
| Cel mai bun dintre toți | *Denetan **onena*** / *Guztietan **onena*** |
| Cea mai rea dintre zile | *Egunetan **txarrena*** |

> *Klaseko ikasle **azkarrena** da.* — Este cel mai rapid elev din clasă.
>
> *Euskal Herriko mendi **altuena** Hiru Errege Mahaia da.* — Cel mai înalt munte din Euskal Herria este Hiru Errege Mahaia (Masa celor Trei Regi).

## *Gehien / gutxien* — cel care cel mai mult / cel care cel mai puțin

Echivalente superlative de cantitate sau frecvență:

| Română | Bască |
|---|---|
| Ceea ce îmi place cel mai mult | *Gehien gustatzen zaidana* |
| Ceea ce fac cel mai puțin | *Gutxien egiten dudana* |
| Cine studiază cel mai mult | *Gehien ikasten duena* |

## Mini-comparație culturală

Expresii tipice:

- *Hiru Errege Mahaia Euskal Herriko mendi **altuena** da.* — Hiru Errege Mahaia (Masa celor Trei Regi) este cel mai înalt munte din Euskal Herria.
- *Korrika euskararen aldeko ekintza **handiena** da.* — Korrika este cea mai mare acțiune în favoarea limbii basce.
- *San Fermin festa famatuena da.* — San Fermín este cea mai faimoasă sărbătoare.

## Truc pentru memorare

| Formă | Exemplu |
|---|---|
| Comparativ (mai X decât…) | *X baino Y-**agoa*** |
| Egalitate (la fel de X ca…) | *Y bezain X* |
| Egalitate de cantitate (la fel de mult ca) | *Yk adina X* |
| Superlativ (cel mai X) | *X-**ena*** |
| Superlativ în grup | *Z-ko / Z-etan + X-**ena*** |

## Mini-dialog

> *— Anboto, hau bai pintxoa! Sekula jan dudan **goxoena**.*
>
> *— Bai, **zure ustez** Bilboko **onenak** non daude?*
>
> *— Plaza Berrian. Han pintxoak **garestienak** dira, baina **goxoenak** ere bai. Donostiakoak ere ez dira **gutxiago**: ia **maila berekoak** dira.*

> **Notă culturală:** în dezbaterile tipice din *Euskal Herria*, *Donostiako pintxoak Bilbokoak baino hobeak dira* este un subiect clasic de discuție amicală. Realitatea: fiecare zonă își apără produsele, și toate sunt delicioase.
