Această lecție integrează două blocuri A2 foarte productive:

1. **Sentimente** și stări de spirit (pe cele de bază le cunoști de la A1; aici le extinzi).
2. **Conectori discursivi** pentru a argumenta și a nuanța: *gainera, hala ere, beraz, alde batetik...*

Cu aceasta închei unitatea și obții instrumente pentru opinii mai elaborate.

## Sentimente: formula cu *egon* + stare

Majoritatea sentimentelor trecătoare se formează cu *egon* + adjectiv sau adverb de stare:

| Română | Bască |
|---|---|
| Bucuros | *Pozik nago* |
| Trist | *Triste nago* |
| Supărat | *Haserre nago* |
| Nervos | *Urduri nago* |
| Liniștit | *Lasai nago* |
| Plictisit | *Aspertuta nago* |
| Obosit | *Nekatuta nago* |
| Rușinat | *Lotsatuta nago* |
| Îndrăgostit | *Maitemindurik nago* |

> Este același model de la A1 (*pozik, triste, lasai*) extins cu *aspertuta, nekatuta, lotsatuta, maitemindurik*.

## Sentimente cu *izan*: *beldur naiz*

Unele sentimente profunde se formează cu *izan*:

| Română | Bască |
|---|---|
| Mi-e frică | *Beldur naiz* |
| Ai dreptate | *Arrazoia duzu* |
| Sunt curios | *Jakin-mina dut* |
| Am chef | *Gogoa dut* / *Gogoz nago* |
| Nu am chef | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — Mi-e frică să merg cu mașina.

## Sentimente cu *NOR-NORI*: *lotsa ematen dit*

O formulă foarte specifică limbii basce: sentimentul „îți dă”:

| Română | Bască |
|---|---|
| Mi-e rușine | *Lotsa ematen dit* |
| Îmi pare rău | *Pena ematen dit* |
| Mă enervează | *Amorrua ematen dit* |
| Îmi dă frică | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — Mi-e rușine să spun asta.
>
> *Albiste horrek **pena handia ematen dit**.* — Vestea aceea îmi provoacă multă tristețe.

## *Jartzen naiz / jarri naiz*

Pentru a exprima **schimbarea stării** („a deveni nervos, bucuros, trist”):

| Română | Bască |
|---|---|
| Devin nervos | *Urduri **jartzen naiz*** |
| A devenit trist | *Triste **jarri zen*** |
| Am devenit bucuroși | *Pozik **jarri ginen*** |
| Se supără din orice | *Edozergatik haserretzen da* |

## Verbe psihologice frecvente

| Verb | Semnificație |
|---|---|
| *gustatu* | a plăcea |
| *maite izan* | a iubi / a îndrăgi |
| *gorrotatu* / *higuindu* | a urî |
| *beldurtu* | a se speria |
| *aspertu* | a se plictisi |
| *haserretu* | a se supăra |
| *lasaitu* | a se calma |
| *poztu* | a se bucura |
| *triste jarri* / *atsekabetu* | a se întrista |
| *kezkatu* | a se îngrijora |

> *Asko **maite ditut** nire gurasoak.* — Îmi iubesc mult părinții.
>
> *Ez **kezkatu**, dena ondo aterako da.* — Nu te îngrijora, totul va fi bine.

## Conectori discursivi

Pentru a lega opinii și argumente:

### Adăugare

| Română | Bască |
|---|---|
| În plus | *gainera* |
| Și de asemenea | *eta baita ere* / *...ere* |
| Mai ales | *batez ere* |

> *Gainera, prezioa ere ona da.* — În plus, și prețul este bun.

### Cauză / consecință

| Română | Bască |
|---|---|
| Prin urmare | *beraz* |
| De aceea | *horregatik* |
| Din acest motiv | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — E târziu; prin urmare, plec.

### Contrast / opoziție

| Română | Bască |
|---|---|
| Cu toate acestea | *hala ere* |
| Dar | *baina* |
| Pe de altă parte | *bestetik* |
| În schimb | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — E târziu; cu toate acestea, voi veni.

### Organizarea discursului

| Română | Bască |
|---|---|
| Pe de o parte… pe de altă parte | *Alde batetik... bestetik...* |
| Mai întâi… apoi… | *Lehenengo... gero...* |
| În final | *Azkenik* |
| În rezumat | *Laburbilduz* |

## Structuri coordonate A2

Acestea sunt construcții care apar în orice examen A2:

| Română | Bască |
|---|---|
| Nici... nici... | *Ez... ez...* |
| Atât... cât și... | *Bai... bai...* / *Hala... nola...* |
| Nu numai... ci și... | *Ez bakarrik..., baita ere...* |
| ...de asemenea (inclusiv) | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — Nici Anboto, nici Olatz nu au venit.
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — Atât dimineața, cât și după-amiaza, trebuie să lucrez.

## Mini-text de opinie

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## Sfat pentru A2: „scheletul opiniei”

Când ți se cere să-ți exprimi opinia la A2, urmează acest șablon:

> **1. Nire ustez** + tema + **-(e)la**.
>
> **2. Alde batetik**, + razón1 + **-lako**.
>
> **3. Bestetik**, + razón2.
>
> **4. Hala ere**, + matización.
>
> **5. Beraz**, + conclusión.

Cu asta construiești un paragraf complet de A2.

> **Notă culturală:** multe texte oficiale de A2 (scrisoare către editor, forum, compunere de examen) cer această structură argumentativă. Exerseaz-o cu teme cotidiene: sportul, mâncarea, rețelele sociale, munca, sărbătorile locale.
