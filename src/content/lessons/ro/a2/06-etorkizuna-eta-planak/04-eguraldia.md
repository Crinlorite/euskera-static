Într-o țară unde poate fi soare, poate ploua și poate ieși din nou soarele în aceeași dimineață, **a vorbi despre vreme este un sport național**. Și are un premiu dublu: vocabularul despre *eguraldia* este terenul perfect pentru a exersa viitorul proaspăt învățat, deoarece prognoza se exprimă întotdeauna la *geroaldia*.

## Vocabularul de bază

| Română | Bască |
|---|---|
| Vremea | *eguraldia* |
| Soarele | *eguzkia* |
| Ploaia | *euria* |
| Zăpada | *elurra* |
| Vântul | *haizea* |
| Ceața | *lainoa* |
| Norii | *hodeiak* |
| Aversa | *zaparrada* |
| Temperatura | *tenperatura* |
| Gradele | *graduak* |
| Prognoza | *iragarpena* |

## Cele trei construcții care stau la baza tuturor

| Moment | Construcție | Exemplu |
|---|---|---|
| **Chiar acum** | fenomen + ***ari du*** | *Euria **ari du**.* — Plouă. |
| **În general / azi** | fenomen + ***egiten du*** | *Hotz handia **egiten du**.* — Este foarte frig. |
| **Prognoză (viitor)** | fenomen + ***egingo du*** | *Bihar euria **egingo du**.* — Mâine va ploua. |

Alte piese cu verbul lor propriu:

> *Eguzkia **atera da** / **aterako da**.* — A ieșit / va ieși soarele.
>
> *Haizea **dabil**.* — Bate vântul (vântul „umblă”).
>
> ***Hodeitsu / eguzkitsu dago**.* — Este înnorat / însorit.

> **Observă:** în limba bască, vremea „**face**” lucruri cu verbul *egin* și auxiliarul **du** (fără subiect vizibil): *euria egingo du*, *bero handia egiten du*. Este o copie fidelă a expresiei din spaniolă «hace calor» (face căldură) — doar că și ploaia se „face”.

## Cum se întreabă

> ***Zer eguraldi egiten du** zure herrian?* — Ce vreme este în satul tău?
>
> ***Zer dio iragarpenak** biharko?* — Ce spune prognoza pentru mâine?
>
> ***Zenbat gradu daude** kanpoan?* — Câte grade sunt afară?

## O prognoză reală (ca la televizor)

> *«Gaur, goizean **lainoa** izango dugu kostaldean, baina eguerdirako **eguzkia aterako da**. Arratsaldean **hodeiak** iritsiko dira mendebaldetik eta gauean **euria egingo du**, batez ere Bizkaian. Tenperaturak **behera egingo du**: 22 gradutik 16ra. Bihar, **haizea ibiliko da** eta **zaparradak** izango ditugu han-hemenka.»*

(Ceață dimineața pe coastă, soare la prânz, nori dinspre vest, ploaie noaptea, scăderea temperaturii, mâine vânt și averse izolate — meniul clasic atlantic. 😄)

## Dialog: planul depinde de cer

> *— Bihar mendira **joango gara**?*
>
> *— Ez dakit… **zer dio iragarpenak**?*
>
> *— Goizean **eguzkitsu**, baina arratsaldean **euria egingo du**.*
>
> *— Orduan goiz **aterako gara**. **Zaparrada** harrapatzen bagaitu, hurrengoan ez naiz zurekin inora joango!* 😄
