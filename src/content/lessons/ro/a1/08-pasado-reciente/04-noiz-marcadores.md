Pentru a povesti bine ce s-a întâmplat, trebuie să spui **când**. Această lecție îți oferă marcatorii care se combină cu trecutul recent pentru a ancora acțiunile în timp.

## Marcatorii de bază

| Bască | Română |
|---|---|
| *gaur* | azi |
| *atzo* | ieri |
| *bihar* | mâine |
| *etzi* | poimâine |
| *orain* | acum |
| *oraintxe* | chiar acum |
| *lehen* | înainte |
| *gero* | apoi, după aceea |

> Dacă ai observat, *atzo* (ieri) și *bihar* (mâine) sunt două cuvinte atât de scurte încât se învață dintr-o dată. *Etzi* (poimâine) este un cuvânt pe care spaniola nu îl are într-o singură bucată — un mic cadou din partea limbii basce.

## Combinarea cu momentele zilei

Marcatorii se combină cu *goizean*, *arratsaldean*, *gauean* și altele asemenea din unitatea anterioară. Formula este: **marcator + parte a zilei**.

| Bască | Română |
|---|---|
| *gaur goizean* | în această dimineață / azi dimineață |
| *gaur eguerdian* | azi la prânz |
| *gaur arratsaldean* | în această după-amiază / azi după-amiază |
| *gaur gauean* | în această seară / diseară |
| *atzo goizean* | ieri dimineață |
| *atzo arratsaldean* | ieri după-amiază |
| *atzo gauean* | aseară |
| *bihar goizean* | mâine dimineață |

> **Atenție:** *gaur gauean* înseamnă "în această seară" (seara care urmează sau pe care o trăiești); *atzo gauean* înseamnă "aseară". Limba bască face o distincție foarte clară.

## Frecvență și repetări

| Bască | Română |
|---|---|
| *behin* | o dată |
| *bi aldiz* | de două ori |
| *hiru aldiz* | de trei ori |
| *askotan* | deseori, de multe ori |
| *batzuetan* | uneori |
| *inoiz ez* | niciodată |
| *gaur goizetik* | de azi dimineață |
| *aste honetan* | săptămâna aceasta |
| *hilabete honetan* | luna aceasta |

## Propoziții cu trecutul recent și marcatori

> *Gaur goizean lanera joan naiz autoz.* — Azi dimineață am mers la muncă cu mașina.
>
> *Gaur arratsaldean Mikelekin egon naiz.* — Azi după-amiază am fost cu Mikel.
>
> *Gaur oso berandu esnatu naiz.* — Azi m-am trezit foarte târziu.
>
> *Gaur eguerdian etxean bazkaldu dut.* — Azi la prânz am mâncat acasă.
>
> *Aste honetan bi aldiz egon naiz zinean.* — Săptămâna aceasta am fost de două ori la cinema.

## Ordinea în propoziție

În limba bască, ordinea tipică a unei propoziții cu marcator temporal este:

> **CÂND + UNDE + CE + VERB**

> **Gaur goizean** + **euskaltegian** + **euskara** + **ikasi dut**. — Azi dimineață am învățat bască la euskaltegi.

Nu este singura posibilitate — limba bască permite mutarea elementelor pentru a le accentua — dar dacă urmezi această ordine, nu vei greși.

## Mini-conversație

> *— Eta gaur zer egin duzu, Maialen?*
>
> *— **Gaur goizean** lanera joan naiz oinez. **Eguerdian** lagunekin bazkaldu dut tabernan. **Arratsaldean** etxera bueltatu naiz eta liburua irakurri dut. **Gauean** ez dut afaldu, asko jan baitut bazkarian.*

> **Notă:** *gaur* acoperă întreaga zi curentă. Dacă vrei să specifici, adaugă momentul (*gaur goizean*, *gaur arratsaldean*). În conversațiile obișnuite, *Zer egin duzu gaur?* se înțelege ca "ce ai făcut azi în general?".
