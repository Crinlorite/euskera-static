Această lecție reunește totul din unitate: vocabularul locurilor, locativul `-(e)an`, poziții spațiale (*aurrean*, *ondoan*…), și distincția **a exista / a se afla** (*badago* / *dago*). Când vei termina, vei putea descrie cartierul sau satul tău cu propoziții reale.

## Schema unei descrieri

O descriere tipică a unui cartier sau sat urmează această ordine:

1. **Cum este** locul (mărime, caracter): *Nire auzoa txikia eta polita da.*
2. **Ce se află** și ce nu se află: *Auzoan badago liburutegia, baina ez dago zinemarik.*
3. **Unde este** fiecare lucru important: *Liburutegia plazaren ondoan dago.*
4. **Unde locuiești tu** și cu cine: *Ni Maialenen ondoan bizi naiz, etxe txiki batean.*

## Vocabular pentru descriere

| Euskera | Română |
|---|---|
| *handi* | mare |
| *txiki* | mic |
| *ertain* | mediu |
| *polit* | frumos |
| *itsusi* | urât |
| *zaharra* | vechi |
| *berria* | nou |
| *lasai* | liniștit |
| *jendetsu* | aglomerat |
| *modernoa* | modern |
| *erdigunean* | în centru |
| *kanpoaldean* | la periferie |

> Amintește-ți: adjectivele în limba bască se pun **după substantiv** și li se adaugă articolul `-a`. *Auzo + handi + a* → *auzo handia* ("cartierul mare"); *auzo + txiki + a* → *auzo txikia*.

## Combinarea tuturor elementelor: exemplu model

> *Ni Iruñean bizi naiz, Txantrea auzoan. Auzoa ez da oso handia, baina lasaia eta polita da. Auzoan badago supermerkatu txiki bat, bi taberna eta okindegi bat. Eskola plazaren ondoan dago, eta liburutegia eskolaren atzean. Parkea handia da, eta umeentzat oso ona. Auzoan ez dago zinemarik, baina hori ez da arazoa: zinema erdigunean dago, eta gertu dago. Nire etxea bigarren solairuan dago, kale lasai batean.*

Traducere liberă:

> Locuiesc în Pamplona, în cartierul Txantrea. Cartierul nu este foarte mare, dar este liniștit și frumos. În cartier există un supermarket mic, două baruri și o brutărie. Școala este lângă piață, iar biblioteca în spatele școlii. Parcul este mare și foarte bun pentru copii. În cartier nu există cinematograf, dar asta nu este o problemă: cinematograful este în centru și este aproape. Casa mea este la etajul doi, pe o stradă liniștită.

## Întrebări care ți se vor pune

| Întrebare | Tip de răspuns |
|---|---|
| ***Non bizi zara?*** | Loc + locativ: *X-(e)an bizi naiz.* |
| ***Nolakoa da zure auzoa?*** | Adjective: *Polita da, txikia da…* |
| ***Zer dago zure auzoan?*** | Existență: *Badago…, badaude…* |
| ***Ba al dago tabernarik?*** | Da/nu: *Bai, badago / Ez, ez dago tabernarik.* |
| ***Non dago liburutegia?*** | Poziție: *Plazaren ondoan dago.* |

## Rândul tău

Imaginează-ți că colegul/colega ta nu îți cunoaște cartierul. Descrie:

1. Cum se numește și unde se află.
2. Dacă este mare sau mic, vechi sau modern.
3. Ce trei locuri **există** (cu *badago / badaude*).
4. Ce trei lucruri **nu există** (cu *ez dago … rik*).
5. Unde se află casa ta în mod concret (stradă, etaj, lângă ce).

> **Notă culturală:** multe cartiere și sate basce au ca referință **frontoia** (frontonul) și **eliza** (biserica), de obicei unul lângă celălalt și aproape de piața principală. Dacă cartierul tău are piață, fronton sau biserică, aceasta este cea mai bună referință pentru a orienta pe cineva.
