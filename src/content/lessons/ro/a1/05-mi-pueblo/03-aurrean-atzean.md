Odată ce știi să spui „este în X”, următorul pas este să spui **unde anume**: deasupra, dedesubt, alături, în spate… În limba bască, aceste poziții se construiesc mereu cu modelul **loc de referință + poziție**.

## Pozițiile de bază

| Euskera | Română |
|---|---|
| *aurrean* | în față |
| *atzean* | în spate |
| *ondoan* | alături |
| *gainean* | deasupra, pe |
| *azpian* | dedesubt |
| *artean* | între |
| *ezkerrean* | la stânga |
| *eskuinean* | la dreapta |
| *barruan* | înăuntru |
| *kanpoan* | afară |
| *erdian* | în mijloc, în centru |

## Cum se construiesc: -(r)en + poziție

Formula de bază este **(referință)-(r)en + poziție**. Referința preia genitivul `-(r)en` (ceea ce corespunde cazului genitiv în română):

| Euskera | Română (literal) |
|---|---|
| **mahaiaren gainean** | deasupra mesei (lit. „a mesei, deasupra”) |
| **etxearen aurrean** | în fața casei |
| **elizaren atzean** | în spatele bisericii |
| **parkearen ondoan** | alături de parc |
| **kutxaren barruan** | înăuntrul cutiei |
| **bi mendien artean** | între doi munți |

Model: referința este prima, **apoi** poziția. Este exact invers față de română.

## Exemple complete

- **Liburua mahaiaren gainean dago.** — Cartea este pe masă.
- **Katua aulkiaren azpian dago.** — Pisica este sub scaun.
- **Eliza plazaren erdian dago.** — Biserica este în centrul pieței.
- **Botika eskolaren ondoan dago.** — Farmacia este lângă școală.
- **Ni Maiteren eta Anaren artean nago.** — Eu sunt între Maite și Ana.

## Adverbe de loc: hemen / hor / han

Pentru a indica rapid, există trei adverbe — și, atenție, sunt **trei distanțe**, nu două ca în română:

| Euskera | Română | Când |
|---|---|---|
| *hemen* | aici | aproape de vorbitor |
| *hor* | acolo | aproape de ascultător |
| *han* | acolo (departe) | departe de amândoi |

> Aceste trei adverbe corespund demonstrativelor *hau / hori / hura* și cu formele lor locative lungi *honetan / horretan / hartan* („în acesta / în acela / în acela de departe”).

Exemple rapide:

- **Hemen** taberna bat dago. — Aici este un bar.
- **Hor** parkea dago. — Acolo este parcul.
- **Han** dago euskaltegia. — Euskaltegi-ul este acolo (departe).

## Mini-conversație: de-a v-ați ascunselea

> — *Pilota mahaiaren azpian dago?* — Mingea este sub masă?
>
> — *Ez, pilota ez dago mahaiaren azpian.* — Nu, mingea nu este sub masă.
>
> — *Aulkiaren atzean dago?* — Este în spatele scaunului?
>
> — *Bai, hor dago!* — Da, este acolo!

> **Pont:** toate pozițiile au deja sufixul `-an` încorporat (*aurr-ean*, *atz-ean*, *azp-ian*…). Nu trebuie să mai adaugi nimic.
