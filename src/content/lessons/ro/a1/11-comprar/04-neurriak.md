A ști să ceri cantități concrete este diferența dintre "un măr" și "un kilogram de mere". Tiparul în euskera este foarte regulat și mereu același.

## Tiparul de bază

> **CANTITATE + PRODUS (fără articol)**

| Euskera | Română |
|---|---|
| *kilo bat sagar* | un kilogram de mere |
| *bi kilo tomate* | două kilograme de roșii |
| *kilo erdi piper* | jumătate de kilogram de ardei |
| *200 g txorizo* | 200 de grame de chorizo |
| *litro bat ur* | un litru de apă |
| *litro erdi esne* | jumătate de litru de lapte |
| *dozena bat arrautza* | o duzină de ouă |
| *pakete bat makarroi* | un pachet de macaroane |
| *botila bat ardo* | o sticlă de vin |
| *lata bat tomate* | o conservă de roșii |

> **Atenție:** produsul este **fără articol** (*sagar*, nu *sagarra*). Acest lucru este diferit față de limba română și se învață prin practică.

## Numărul înainte, produsul după

Ordinea este importantă:

- *Bi kilo sagar* — două kilograme de mere (CORECT)
- ~~Sagar bi kilo~~ — nu se spune așa

## Cantități aproximative

| Euskera | Română |
|---|---|
| *gehiago* | mai mult |
| *gutxiago* | mai puțin |
| *pixka bat* | un pic |
| *asko* | mult |
| *gutxi* | puțin |
| *nahikoa* | suficient |

Exemple tipice la aprozar:

- *Gehiago, mesedez.* — Un pic mai mult, vă rog.
- *Hori da, nahikoa da.* — Asta e, e de ajuns.
- *Gutxiago, mesedez.* — Mai puțin, vă rog.

## Fraze tip

- *Eman kilo bat sagar eta dozena bat arrautza, mesedez.* — Dați-mi un kilogram de mere și o duzină de ouă, vă rog.
- *Litro bat esne hartuko dut.* — O să iau un litru de lapte.
- *Bi botila ur, mesedez.* — Două sticle de apă, vă rog.

> **Notă culturală:** în piețe (*azoka*) și în piețele tradiționale se cântărește în continuare totul "din ochi": ceri *kilo bat sagar*, iar vânzătorul ajustează până dă greutatea exactă. Este obișnuit să auzi *pixka bat gehiago, mesedez* pe măsură ce se adaugă pe cântar.
