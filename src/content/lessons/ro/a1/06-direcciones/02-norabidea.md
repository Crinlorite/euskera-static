Când cineva te întreabă cum să ajungi într-un loc — sau când te rătăcești și întrebi tu — ai nevoie de o mână de verbe la imperativ și de adverbe de direcție. În această lecție am adunat esențialul.

## Imperative de bază

În bască, imperativul afirmativ al verbelor de mișcare este foarte direct:

| Forma | Verb de bază | Sens |
|---|---|---|
| **Jo** | jo | lovește / îndreaptă-te (jo ezkerrera = fă la stânga) |
| **Segi** / **Jarraitu** | segitu / jarraitu | continuă |
| **Hartu** | hartu | ia (hartu kale hau = ia această stradă) |
| **Igo** | igo | urcă |
| **Jaitsi** | jaitsi | coboară |
| **Sartu** | sartu | intră |
| **Irten** | irten | ieși |
| **Zeharkatu** | zeharkatu | traversează |
| **Iritsi** / **heldu** | iritsi / heldu | ajungi (… arte = "până la…") |

> *Jo* înseamnă literalmente "a lovi", dar se folosește metaforic ca "a te îndrepta spre": **jo ezkerrera** = "fă la stânga".

## Adverbe și referințe direcționale

| Bască | Română |
|---|---|
| *ezkerra* | stânga |
| *eskuina* | dreapta |
| *aurrera* | înainte |
| *atzera* | înapoi |
| *zuzen* | drept |
| *gora* | în sus |
| *behera* | în jos |

> Fii atent: pentru a indica **direcția spre** se folosește sufixul `-ra` (pe care îl vei vedea în detaliu în lecția 03): *ezkerre-ra* (la stânga), *aurre-ra* (înainte), *atze-ra* (înapoi). La fel și pentru *gora*, *behera*.

## Locuri de referință tipice

| Bască | Română |
|---|---|
| *semaforoa* | semafor |
| *bidegurutzea* | intersecție |
| *zebrabidea* | trecere de pietoni |
| *biribilgunea* / *errotonda* | sens giratoriu |
| *aldapa* | pantă |
| *eskailerak* | scări |
| *zubia* | pod |
| *errepidea* | șosea |
| *kalea* | stradă |

## Fraze tipice

- **Jo ezkerrera bidegurutzean.** — Fă la stânga în intersecție.
- **Segi aurrera semaforora arte.** — Mergi drept înainte până la semafor.
- **Zeharkatu zebrabidea.** — Traversează trecerea de pietoni.
- **Igo eskailerak eta sartu eraikinean.** — Urcă scările și intră în clădire.
- **Jaitsi aldapa, eta gero jo eskuinera.** — Coboară panta, și apoi fă la dreapta.
- **Egin atzera; gehiegi joan zara.** — Mergi înapoi; ai trecut de locul respectiv.

## A cere și a oferi indicații

> — *Barkatu, **non dago** udaletxea?* — Scuză-mă, unde este primăria?
>
> — ***Segi aurrera** semaforora arte. Han **jo eskuinera** eta **zeharkatu** plaza. Udaletxea elizaren ondoan dago.* — Mergi drept înainte până la semafor. Acolo fă la dreapta și traversează piața. Primăria este lângă biserică.
>
> — *Eta gertu **dago**?* — Și este aproape?
>
> — *Bai, oso gertu. Bost minutu oinez.* — Da, foarte aproape. Cinci minute pe jos.

> **Sfat:** multe indicații urmează un model fix: imperativ (*jo*, *segi*, *zeharkatu*) + loc cu sufix (*ezkerrera*, *semaforora*, *zebrabidea*). Dacă memorezi modelul, poți înlănțui instrucțiuni lungi combinând piese.
