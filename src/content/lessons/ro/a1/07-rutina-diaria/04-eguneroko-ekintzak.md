Pentru a spune ce faci în fiecare zi, limba bască folosește **aspectul habitual**: iei verbul (partizipio) și îi adaugi **-tzen** sau **-ten**, apoi combini cu verbul auxiliar **izan** (naiz, zara, da…) sau **ukan** (dut, duzu, du…).

## Regula

| Terminația verbului | Sufixul habitual | Exemplu |
|---|---|---|
| consoană sau `-tu` / `-du` | **-tzen** | *esnatu* → *esnatzen* |
| `-n` | **-ten** | *jan* → *jaten*; *egin* → *egiten* |
| `-i` (neregulat) | **-tzen** sau **-ten** | *etorri* → *etortzen*; *ikusi* → *ikusten* |

> Verbul *jan* (a mânca) **nu** devine *janten*, ci *jaten* — „n”-ul final dispare. La fel și cu *edan* → *edaten*, *egon* → *egoten*.

## Verbe de zi cu zi

### NOR (auxiliar **izan**: naiz, zara, da…)

Acestea merg **cu izan** pentru că sunt intranzitive — subiectul experimentează acțiunea fără un obiect:

| Partizipioa | Aspect habitual | Semnificație |
|---|---|---|
| *esnatu* | *esnatzen naiz* | mă trezesc |
| *jaiki* | *jaikitzen naiz* | mă scol |
| *altxatu* | *altxatzen naiz* | mă scol (variantă a lui *jaiki*) |
| *dutxatu* | *dutxatzen naiz* | fac duș |
| *jantzi* | *janzten naiz* | mă îmbrac |
| *joan* | *joaten naiz* | merg |
| *etorri* | *etortzen naiz* | vin |
| *oheratu* | *oheratzen naiz* | mă culc |
| *lokartu* | *lokartzen naiz* | adorm |

### NOR-NORK (auxiliar **ukan**: dut, duzu, du…)

Acestea merg **cu ukan** pentru că au subiect și obiect:

| Partizipioa | Aspect habitual | Semnificație |
|---|---|---|
| *gosaldu* | *gosaltzen dut* | iau micul dejun |
| *bazkaldu* | *bazkaltzen dut* | mănânc (prânzul) |
| *afaldu* | *afaltzen dut* | iau cina |
| *jan* | *jaten dut* | mănânc |
| *edan* | *edaten dut* | beau |
| *lan egin* | *lan egiten dut* | lucrez |
| *lo egin* | *lo egiten dut* | dorm |
| *ikusi* | *ikusten dut* | văd |
| *irakurri* | *irakurtzen dut* | citesc |
| *erosi* | *erosten dut* | cumpăr |

> **De ce unele merg cu NAIZ și altele cu DUT?** Este distincția cheie a limbii basce. *Esnatzen naiz* (mă trezesc) este ceva ce mi se întâmplă mie: nu există un obiect. *Jaten dut* (mănânc) are obiect: *ogia jaten dut* (mănânc pâine). Acest lucru se va aprofunda în unitatea următoare — deocamdată memorează perechile verb + auxiliar.

## Marcatori de frecvență

| Bască | Română |
|---|---|
| *egunero* | în fiecare zi / zilnic |
| *beti* | întotdeauna |
| *askotan* | adesea |
| *batzuetan* | uneori |
| *normalean* | în mod normal |
| *gehienetan* | de cele mai multe ori |
| *gutxitan* | rareori |
| *inoiz ez* | niciodată |
| *astero* | săptămânal / în fiecare săptămână |
| *hilero* | lunar / în fiecare lună |

## Exemple în context

> *Egunero zazpietan esnatzen naiz eta dutxatzen naiz.* — În fiecare zi mă trezesc la șapte și fac duș.
>
> *Goizean kafea hartzen dut.* — Dimineața beau cafea.
>
> *Askotan lagunekin afaltzen dut.* — Adesea iau cina cu prietenii.
>
> *Batzuetan lo-kuluxka egiten dut bazkalostean.* — Uneori trag un pui de somn după prânz.

> **Notă:** *bazkalostean* = „după prânz” (literal: „după masă”). Cultura bască are cuvinte compacte pentru concepte cotidiene precum acest somn scurt — *lo-kuluxka* este exact asta.
