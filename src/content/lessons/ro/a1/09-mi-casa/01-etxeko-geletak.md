Începem cu cel mai de bază element al oricărei locuințe: **încăperile**. Cuvântul general pentru "cameră / încăpere" este **gela**, iar majoritatea numelor de încăperi se construiesc combinând o rădăcină cu `-gela`.

## Vocabular de bază

| Bască | Română |
|---|---|
| *etxea* | casa |
| *pisua* | apartamentul (locuință într-o clădire) |
| *gela* | încăpere / cameră |
| *sukaldea* | bucătărie |
| *logela* | dormitor |
| *komuna* | baie |
| *egongela* | sufragerie |
| *sarrera* | intrare |
| *korridorea* / *pasabidea* | coridor |
| *balkoia* | balcon |
| *terraza* | terasă |

## Cum se formează unele nume

Limba bască este foarte transparentă cu aceste cuvinte. Dacă te uiți cum sunt compuse, le reții mai bine:

- **logela** → *lo* (somn) + *gela* (cameră) = "camera somnului" → dormitor
- **egongela** → *egon* (a sta) + *gela* = "camera de stat" → sufragerie
- **sukaldea** → *su* (foc) + *aldea* (zonă) = "zona focului" → bucătărie

> **Komuna** și **bainugela** sunt sinonime: *komuna* este cuvântul de zi cu zi, în timp ce *bainugela* (literalmente "camera de baie") este puțin mai formal.

## Clădire: etaj și lift

| Bască | Română |
|---|---|
| *solairua* | etaj (etajul 1, 2...) |
| *igogailua* | lift |
| *eskailera* | scară |
| *ataria* | intrare (în clădire) |

Pentru a spune la ce etaj locuiești:

- *Hirugarren solairuan bizi naiz.* — Locuiesc la etajul trei.
- *Etxeak igogailua du.* — Casa are lift.

## Întrebări utile

- **Zenbat gela ditu zure etxeak?** — Câte camere are casa ta?
- **Zenbat logela ditu?** — Câte dormitoare are?
- **Non dago sukaldea?** — Unde este bucătăria?
- **Etxeak badu balkoirik?** — Are casa balcon?

> **Notă culturală:** în Navarra și în zona basco-castiliană se obișnuiește să se spună *pisua* pentru locuința urbană și *etxea* pentru casa de familie/de la țară. În viața de zi cu zi se amestecă fără probleme.
