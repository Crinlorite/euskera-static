Del papel al píxel: la lección de **tecnología cotidiana**. Vocabulario que usas cien veces al día — ahora en euskera, que además presume de palabras transparentes y bien construidas (*pasahitza* = palabra de paso; *sakelakoa* = "el de bolsillo").

## Los aparatos

| Castellano | Euskera |
|---|---|
| El ordenador | *ordenagailua* |
| El (ordenador) portátil | *eramangarria* |
| El móvil | *mugikorra / sakelakoa* |
| La tableta | *tableta* |
| La pantalla | *pantaila* |
| El teclado | *teklatua* |
| El ratón | *sagua* (¡sí, el animal!) |
| Los auriculares | *entzungailuak* |

## La red y las cuentas

| Castellano | Euskera |
|---|---|
| La red / internet | *sarea / internet* |
| El wifi | *wifia* |
| El correo electrónico | *posta elektronikoa* |
| El usuario | *erabiltzailea* |
| La contraseña | *pasahitza* |
| La aplicación | *aplikazioa* |
| La página web | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — ¿Cuál es la contraseña del wifi?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — He olvidado la contraseña y ahora tengo que crear una nueva. Otra vez.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Para crear la cuenta necesitas correo y contraseña.

## Los verbos digitales

| Castellano | Euskera |
|---|---|
| Encender / apagar | *piztu / itzali* |
| Descargar | *deskargatu / jaitsi* |
| Instalar | *instalatu* |
| Guardar | *gorde* |
| Borrar | *ezabatu* |
| Enviar / compartir | *bidali / partekatu* |
| Buscar (en la red) | *bilatu* |
| Funcionar | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — El ordenador va mal; apágalo y enciéndelo — la solución de siempre.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — ¿Has guardado las fotos? ¡No borres nada!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Descargas la app, creas la cuenta y listo.

## Diálogo: soporte técnico familiar

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Nota:** el euskera digital está muy vivo: el software libre y la Wikipedia en euskera son potentes, y tu móvil entero puede ir en euskera (*Ezarpenak → Hizkuntza*). Ponerlo es, de hecho, un truco de estudio brutal: inmersión diaria gratis.
