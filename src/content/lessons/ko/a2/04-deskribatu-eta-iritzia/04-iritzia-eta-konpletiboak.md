A2 레벨에서 의견을 표현하는 것은 **핵심 역량** 중 하나입니다. 이 강의에서는 다음을 배웁니다:

1. 의견을 시작하는 공식.
2. **-ela**를 사용한 보문 (~라는 것…).
3. **-enik**을 사용한 의견 부정 (~라고 생각하지 않아…).
4. **-lako**와 **zeren**을 사용한 이유 표현 (왜냐하면…).

## 의견 시작하기

| 스페인어 | 바스크어 |
|---|---|
| …라고 생각해 | *Uste dut...* |
| …인 것 같아 | *Iruditzen zait...* |
| 내 생각에는 | *Nire ustez* |
| 나에게는 | *Niretzat* |
| …라는 걸 알아 | *Badakit...* |
| 동의해 | *Ados nago* |
| 동의하지 않아 | *Ez nago ados* |
| 네 말이 맞아 | *Arrazoia duzu* |
| 사실이야 | *Egia da* |

## -**ela** 보문

의견이 다른 문장을 이끌 때, 종속절의 동사에는 **-(e)la** 접미사('~라는 것')가 붙습니다. 변화는 매우 규칙적입니다:

| 접미사 없음 | -ela 사용 | 스페인어 |
|---|---|---|
| *da* | *dela* | 이다/있다 라는 것 |
| *naiz* | *naizela* | (내가) 이다 라는 것 |
| *zara* | *zarela* | (네가) 이다 라는 것 |
| *du* | *duela* | 그것을 가지고 있다 라는 것 |
| *ditu* | *dituela* | 그것들을 가지고 있다 라는 것 |
| *dut* | *dudala* | (내가) 그것을 가지고 있다 라는 것 |
| *zen* | *zela* | 이었다 라는 것 |
| *nuen* | *nuela* | (내가) 그것을 가지고 있었다 라는 것 |
| *etorriko da* | *etorriko **dela*** | 올 것이라는 것 |

> *Uste dut Anboto pozik **dagoela**.* — Anboto가 행복하다고 생각해.
>
> *Badakit gauza zailak gertatu **direla**.* — 어려운 일들이 일어났다는 걸 알아.
>
> *Argi dago euskaraz hobeto hitz egiten **duela**.* — 그가 바스크어를 더 잘한다는 것은 분명해.

## 의견 부정: -**enik**

'**~라고 생각하지 않아** + 동사'라고 말할 때, 종속절의 접미사는 **-enik**으로 바뀝니다:

| 스페인어 | 바스크어 |
|---|---|
| 좋다고 생각하지 않아 | *Ez dut uste ona **denik*** |
| 그들이 올 거라고 생각하지 않아 | *Ez dut uste etorriko **direnik*** |
| 사실인 것 같지 않아 | *Ez zait iruditzen egia **denik*** |

> 이것은 의견 동사와 함께 쓰이는 특정한 부정 형태입니다. 긍정문에서는 *uste dut ona **dela***. 부정문에서는 *ez dut uste ona **denik***.

## 기타 의견 표현 구조

이 구조들은 형용사 + *da* + -ela가 붙은 절을 결합합니다:

| 스페인어 | 바스크어 |
|---|---|
| …라는 것이 분명해 | *Argi dago + -(e)la* |
| …하는 것이 중요해 | *Garrantzitsua da + -tzea* |
| …라는 것은 사실이야 | *Egia da + -(e)la* |
| …하는 것이 가능해 | *Posible da + -tzea* |
| …라는 것이 논리적이야 | *Logikoa da + -(e)la* |
| …하는 것은 흥미로워 | *Interesgarria da + -tzea* |

> *Argi dago ikasten ari **zarela**.* — 네가 공부하고 있다는 것은 분명해.
>
> *Garrantzitsua da euskaraz **hitz egitea**.* — 바스크어로 말하는 것은 중요해.

## 이유 표현: *-lako*와 *zeren*

**이유**('왜냐하면')를 표현하는 데는 두 가지 방법이 있습니다:

### -**lako** 접미사 (종속절, 가장 일반적임)

> **동사 + -lako**

| 스페인어 | 바스크어 |
|---|---|
| 그가 왔기 때문에 | *Etorri **delako*** |
| 내가 배고프기 때문에 | *Goseak nagoelako* (또는 *gose naizelako*) |
| 중요하기 때문에 | *Garrantzitsua **delako*** |
| 내가 좋아하지 않기 때문에 | *Ez zaidalako gustatzen* |

> *Etxean nago **gaixorik nagoelako**.* — 아파서 집에 있어.
>
> *Bilbora joaten naiz lana **bertan dudalako**.* — 직장이 거기에 있어서 빌바오에 가.

### 접속사 *zeren* (문장 시작 부분)

| 스페인어 | 바스크어 |
|---|---|
| 왜냐하면 중요하기 때문에 | *…, **zeren** garrantzitsua baita* |
| …, 그가 왔기 때문에 | *…, **zeren** etorri baita* |

> 이것은 이유를 나타내는 '라틴식' 표현으로, 더 격식적이거나 저널리즘적인 방식입니다. 구어체에서는 *-lako*가 선호됩니다.

## 미니 토론

> *— Olatz, **uste dut** Bilbo Donostia baino interesgarriagoa **dela**.*
>
> *— **Ez nago ados**. Donostia askoz politagoa da, **uste dut**, itsasoa **duelako** ondoan.*
>
> *— **Egia da** itsasoa duela, baina Bilbon **museo gehiago daudela ere egia da**.*
>
> *— Bai, baina **iruditzen zait** giroa, kalea, jendea... Donostian goxoagoak **direla**. Eta Donostiako pintxoak Bilbokoak **baino hobeak direla** ere bai!*

## 유용한 구조 목록

| 스페인어 | 바스크어 |
|---|---|
| 중요하다고 생각해 | *Garrantzitsua **dela** uste dut* |
| 그가 옳다는 걸 알아 | *Arrazoia **duela** badakit* |
| 그들이 올 거라고 생각하지 않아 | *Ez dut uste etorriko **direnik*** |
| 그에게 문제가 있다는 것이 분명해 | *Argi dago arazoak **dituela*** |
| 그가 아프기 때문에 | *Gaixorik **dagoelako*** |
| 춥기 때문에 | *Hotz **egiten duelako*** |

## 자주 하는 실수

1. **두 가지 형태를 잊지 마세요: 긍정문에서는 -ela, 의견 부정문에서는 -enik.**
2. **-ela 접미사는 분사가 아닌 활용된 동사**에 붙습니다: *etorriko da → etorriko **dela***.
3. **스페인어에서는 의견이 매우 강할 때 접속법을 사용하지만**, 바스크어에는 뚜렷한 차이가 없습니다: *uste dut ondo dagoela* (괜찮다고 생각해)와 *zalantza dut ondo dagoenik* (괜찮은지 의심스러워)는 다른 형태를 사용하지만 공식적인 '접속법'은 없습니다.

> **교육적 참고:** *Nire ustez + 문장 + -lako + 문장* 공식은 아마도 A2 레벨에서 의견을 말하고 논거를 제시하는 가장 유용한 도구일 것입니다. 모델 예시:
>
> *Nire ustez **euskara ikastea garrantzitsua da** **gure herriaren hizkuntza delako**.*
> ('내 생각에, 바스크어를 배우는 것은 우리 민족의 언어이기 때문에 중요해.')
