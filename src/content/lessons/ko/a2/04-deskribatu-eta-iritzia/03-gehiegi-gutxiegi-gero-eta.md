이번 과에서는 비교급에 두 가지 요소를 더해 완성해 보겠습니다:

1. **과잉과 부족** (-egi, gehiegi, gutxiegi).
2. **진행 비교급** (점점 더 / 덜: *gero eta...*).

그리고 뉘앙스를 더해주는 유용한 수식어(*pixka bat, askoz, dezente*)도 배웁니다.

## 접미사 -**egi** — "너무"

무언가가 **과도하다**고 말하려면 형용사에 **-egi**를 붙입니다 (그리고 한정 명사와 함께 쓰일 경우 마지막에 **-a**를 붙입니다):

| 형용사 | 과도함 |
|---|---|
| *handia* (큰) | *handi**egia*** (너무 큰) |
| *txikia* (작은) | *txiki**egia*** |
| *garestia* (비싼) | *garesti**egia*** |
| *beroa* (뜨거운) | *bero**egia*** |
| *hotza* (추운) | *hotz**egia*** |
| *zaila* (어려운) | *zail**egia*** |
| *azkarra* (빠른) | *azkarr**egia*** |

> *Alkandora hau **handiegia** da niretzat.* — 이 셔츠는 저에게 너무 큽니다.
>
> *Kafea **beroegi** dago.* — 커피가 너무 뜨겁습니다.
>
> *Ikastaroa **zailegia** zen guretzat.* — 그 강좌는 우리에게 너무 어려웠습니다.

## *Gehiegi*와 *gutxiegi*

독립적인 부사로 쓰일 때:

| 한국어 | 바스크어 |
|---|---|
| 너무 많이 | *gehiegi* |
| 너무 적게 / 불충분하게 | *gutxiegi* |
| 너무 많은 사람 | *jende **gehiegi*** |
| 너무 적은 물 | *ur **gutxiegi*** |

> *Gehiegi jan dut.* — 너무 많이 먹었습니다.
>
> *Gutxiegi lo egiten duzu.* — 잠을 너무 적게 잡니다.
>
> *Hori **gehiegi** da niretzat.* — 그건 저에게 너무 과합니다.

## 진행 비교급: *gero eta + -ago*

'**점점 더 X한**' 또는 '**점점 덜 X한**'을 표현하기 위해 바스크어는 매우 표현력이 풍부한 공식을 사용합니다:

> **gero eta + adjetivo/adverbio-ago(a)**

| 한국어 | 바스크어 |
|---|---|
| 점점 더 비싼 | *Gero eta **garestiagoa*** |
| 점점 더 추운 | *Gero eta **hotzagoa*** |
| 점점 더 좋은 | *Gero eta **hobea*** |
| 점점 더 나쁜 | *Gero eta **okerragoa*** |
| 점점 더 많이 | *Gero eta **gehiago*** |
| 점점 더 적게 | *Gero eta **gutxiago*** |
| 점점 더 빨리 | *Gero eta **azkarrago*** |
| 점점 더 느리게 | *Gero eta **polikiago*** |

> *Bilbo gero eta handiagoa da.* — 빌바오는 점점 더 커지고 있습니다.
>
> *Eguraldia gero eta okerrago dago.* — 날씨가 점점 더 나빠지고 있습니다.
>
> *Gazteek gero eta gutxiago hitz egiten dute euskaraz.* — 젊은이들은 바스크어로 점점 더 적게 말합니다.

> **암기 팁:** *gero eta*는 글자 그대로 '그리고 나서 그리고'라는 뜻으로, '그리고 나서, 그리고 나서, 그리고 나서 더...'라는 개념입니다. 진행을 표현하는 바스크어 방식입니다.

## *Hain* — "그렇게", "그토록" (긍정문/부정문 모두 사용)

| 한국어 | 바스크어 |
|---|---|
| 그렇게 큽니다 | *Hain handia da* |
| 그렇게 비싸지 않습니다 | *Ez da **hain** garestia* |
| 정말 예쁘네요! | *Hain polita da!* |

> '...만큼 ...하지 않다'를 표현할 때는 *bezain*을 사용합니다 (이전 과 참고):
>
> *Ez da zuk uste duzun bezain ona.* — 당신이 생각하는 것만큼 좋지는 않습니다.

## 양을 나타내는 수식어

비교의 뉘앙스를 더하기 위해:

| 한국어 | 바스크어 | 예시 |
|---|---|---|
| 조금 | *pixka bat* | *Pixka bat handiagoa* (조금 더 큰) |
| 약간 | *zerbait / zertxobait* | *Zertxobait txikiagoa* (약간 더 작은) |
| 꽤, 상당히 | *dezente* | *Dezente hobea* (꽤 더 좋은) |
| 훨씬 | *askoz* | *Askoz hobea* (훨씬 더 좋은) |
| 훨씬 더 | *askoz hobea / askoz garestiagoa* | |

> *Etxe hau zurea **baino askoz** handiagoa da.* — 이 집은 당신 집보다 훨씬 더 큽니다.
>
> *Pixka bat goizago etorriko naiz.* — 조금 더 일찍 오겠습니다.

## *Hain... ezen* / *hainbeste...* (격식체)

엄격한 A2 수준을 넘어서지만, 알아두면 좋습니다:

- *Hain* + 형용사 + *non/ezen* — 너무 ...해서 ...하다: *Hain pozik zegoen, non kantatzen hasi zen* (그는 너무 기뻐서 노래를 부르기 시작했습니다).
- *Hainbeste* — 그렇게 많은 (양 강조): *Hainbeste lan dago!*

## 짧은 글

> *Garazi sukaldari ona da, baina kafea **beroegi** ipintzen du beti. Lehengo egunean **hain bero** zegoen, ezen ezin nuen edan! Eta hori ez da dena: pintxo bakoitzean olio **gehiegi** botatzen du. **Pixka bat gutxiago** beharko luke. Hala ere, hura **gero eta hobea** da: orain dela urtebete askoz **okerragoa** zen.*

## 짧은 대화

> *— Olatz, etxe berri hori zer moduz?*
>
> *— Eder askoa, baina **garestiegia** zen guretzat. Eta logelak **txikiegiak** ziren.*
>
> *— Eta orain bilatzen ari zaretena nolakoa da?*
>
> *— **Gero eta zailagoa** da etxebizitza on bat aurkitzea. Prezioak **gero eta altuagoak** dira eta etxebizitza on guztiek dute lehia **gehiegi**.*

> **문화 노트:** 저렴한 주택(*etxebizitza*) 부족은 시사에 관한 A2 수준의 대화에서 반복적으로 나오는 주제입니다: *gero eta garestiago, pisu eskuragarri gutxiegi, askoz okerrago lehen baino*. 이번 과에서 배운 어휘를 활용해 대화에 참여할 수 있습니다.
