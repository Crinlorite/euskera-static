이 강의에서는 매우 유용한 A2 레벨의 두 가지 주제를 다룹니다:

1. **감정**과 기분 상태 (기본적인 내용은 A1에서 배웠고, 여기서는 더 확장합니다).
2. 주장하고 뉘앙스를 더할 때 사용하는 **담화 연결어**: *gainera, hala ere, beraz, alde batetik...*

이것으로 이번 단원을 마무리하고, 더 정교한 의견을 표현하는 도구를 얻게 됩니다.

## 감정: *egon* + 상태 공식

대부분의 일시적인 감정은 *egon* + 형용사 또는 부사 형태로 표현합니다:

| 스페인어 | 바스크어 |
|---|---|
| 기쁜 | *Pozik nago* |
| 슬픈 | *Triste nago* |
| 화난 | *Haserre nago* |
| 초조한 | *Urduri nago* |
| 차분한 | *Lasai nago* |
| 지루한 | *Aspertuta nago* |
| 피곤한 | *Nekatuta nago* |
| 부끄러운 | *Lotsatuta nago* |
| 사랑에 빠진 | *Maitemindurik nago* |

> A1에서 배운 (*pozik, triste, lasai*) 패턴에 *aspertuta, nekatuta, lotsatuta, maitemindurik*를 더해 확장한 것입니다.

## *izan* 동사와 함께 쓰는 감정: *beldur naiz*

일부 깊은 감정은 *izan* 동사와 함께 사용합니다:

| 스페인어 | 바스크어 |
|---|---|
| 무서워요 | *Beldur naiz* |
| 당신 말이 맞아요 | *Arrazoia duzu* |
| 궁금해요 | *Jakin-mina dut* |
| 하고 싶어요 | *Gogoa dut* / *Gogoz nago* |
| 하고 싶지 않아요 | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — 차로 가는 것이 무서워요.

## *NOR-NORI*와 함께 쓰는 감정: *lotsa ematen dit*

매우 바스크어다운 표현 방식입니다: 감정이 당신에게 '주어지는' 형태입니다:

| 스페인어 | 바스크어 |
|---|---|
| 부끄러워요 | *Lotsa ematen dit* |
| 안타까워요 | *Pena ematen dit* |
| 화가 나요 | *Amorrua ematen dit* |
| 무서워요 | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — 그렇게 말하기 부끄러워요.
>
> *Albiste horrek **pena handia ematen dit**.* — 그 소식은 정말 안타까워요.

## *Jartzen naiz / jarri naiz*

**상태의 변화**('초조해지다, 기뻐지다, 슬퍼지다')를 표현할 때 사용합니다:

| 스페인어 | 바스크어 |
|---|---|
| 초조해져요 | *Urduri **jartzen naiz*** |
| 그는 슬퍼졌어요 | *Triste **jarri zen*** |
| 우리는 기뻐졌어요 | *Pozik **jarri ginen*** |
| 그는 별것 아닌 일에 화를 내요 | *Edozergatik haserretzen da* |

## 자주 쓰이는 심리 동사

| 동사 | 의미 |
|---|---|
| *gustatu* | 좋아하다 |
| *maite izan* | 사랑하다 |
| *gorrotatu* / *higuindu* | 미워하다 |
| *beldurtu* | 놀라다/무서워하다 |
| *aspertu* | 지루해하다 |
| *haserretu* | 화내다 |
| *lasaitu* | 진정하다 |
| *poztu* | 기뻐하다 |
| *triste jarri* / *atsekabetu* | 슬퍼지다 |
| *kezkatu* | 걱정하다 |

> *Asko **maite ditut** nire gurasoak.* — 저는 부모님을 아주 많이 사랑해요.
>
> *Ez **kezkatu**, dena ondo aterako da.* — 걱정하지 마세요, 다 잘 될 거예요.

## 담화 연결어

의견과 주장을 연결할 때 사용합니다:

### 추가

| 스페인어 | 바스크어 |
|---|---|
| 게다가 | *gainera* |
| 그리고 또한 | *eta baita ere* / *...ere* |
| 특히 | *batez ere* |

> *Gainera, prezioa ere ona da.* — 게다가, 가격도 좋아요.

### 원인 / 결과

| 스페인어 | 바스크어 |
|---|---|
| 그러므로 | *beraz* |
| 그래서 | *horregatik* |
| 그런 이유로 | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — 늦었어요. 그러므로 저는 갈게요.

### 대조 / 반대

| 스페인어 | 바스크어 |
|---|---|
| 하지만, 그럼에도 불구하고 | *hala ere* |
| 하지만 | *baina* |
| 다른 한편으로는 | *bestetik* |
| 반면에 | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — 늦었어요. 그럼에도 불구하고 올게요.

### 담화 구성하기

| 스페인어 | 바스크어 |
|---|---|
| 한편으로는... 다른 한편으로는... | *Alde batetik... bestetik...* |
| 먼저... 그 다음에... | *Lehenengo... gero...* |
| 마지막으로 | *Azkenik* |
| 요약하자면 | *Laburbilduz* |

## A2 레벨 상관 접속사 구조

이 구문들은 모든 A2 시험에 등장합니다:

| 스페인어 | 바스크어 |
|---|---|
| ...도 ...도 아니다 | *Ez... ez...* |
| ...와 ... 둘 다 | *Bai... bai...* / *Hala... nola...* |
| ...뿐만 아니라 ...도 | *Ez bakarrik..., baita ere...* |
| ...도 또한 (포함) | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — Anboto도 Olatz도 오지 않았어요.
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — 오전에도 오후에도 일해야 해요.

## 의견 말하기 미니 텍스트

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## A2 팁: '의견 제시 틀'

A2 레벨에서 의견을 말하라는 요청을 받으면 이 템플릿을 따르세요:

> **1. Nire ustez** + 주제 + **-(e)la**.
>
> **2. Alde batetik**, + 이유1 + **-lako**.
>
> **3. Bestetik**, + 이유2.
>
> **4. Hala ere**, + 뉘앙스/부연 설명.
>
> **5. Beraz**, + 결론.

이것으로 완전한 A2 수준의 문단을 만들 수 있습니다.

> **문화 노트:** 많은 공식 A2 텍스트(독자 투고, 포럼, 작문 시험)에서 이러한 논증 구조를 요구합니다. 일상적인 주제로 연습해 보세요: 스포츠, 음식, 소셜 미디어, 일, 마을 축제 등.
