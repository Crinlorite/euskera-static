이번 단원의 두 번째 파트: **스포츠** — 직접 하는 스포츠와 관람하는 스포츠. 그리고 Euskal Herria에는 세계 다른 곳에서는 볼 수 없는 스포츠들이 있습니다.

## 늘 즐기는 스포츠

| 한국어 | 바스크어 |
|---|---|
| 스포츠 | *kirola* |
| 축구 | *futbola* |
| 농구 | *saskibaloia* |
| 수영 | *igeriketa* |
| 사이클링 | *txirrindularitza* |
| 달리기 | *korrika egin* |
| 하이킹 | *mendi-ibilia* |
| 헬스장 | *gimnasioa* |

## 이곳의 스포츠

| 스포츠 | 설명 |
|---|---|
| *pilota* | 바스크 전통 구기 종목, *frontoia*에서 함 |
| *arrauna* | 조정 — *traineras*와 라 콘차 깃발 대회 |
| *herri kirolak* | 전통 시골 스포츠: *aizkora* (도끼), *harri-jasotzea* (돌), *soka-tira* |

> *Herriko frontoian **pilota partida** dago larunbatean.* — 토요일에 마을 프론톤에서 펠로타 경기가 있어요.
>
> *Irailean **estropadak** ikusten ditugu: gure herriko traineroa animatzera!* — 9월에는 조정 경기를 봐요. 우리 마을 조정팀을 응원하러 가요!

## 연습하기: 동사

> *Kirola **egiten dut**: astean bitan **entrenatzen naiz** eta igandeetan **korrika egiten dut**.* — 저는 운동을 해요. 일주일에 두 번 훈련하고 일요일에는 달리기를 해요.
>
> ***Igeri badakizu**?* — 수영할 줄 알아요? (*jakin* 동사를 사용한 능력 표현: *igeri dakit*, *dantzan dakit*…)
>
> *Gaztetan futbolean **jokatzen nuen**; orain **ikusi** bakarrik.* 😄 — 어릴 때는 축구를 했는데, 지금은 보기만 해요.

## 경기

| 한국어 | 바스크어 |
|---|---|
| 팀 | *taldea* |
| 경기 | *partida* |
| 이기다 / 지다 / 비기다 | *irabazi / galdu / berdindu* |
| 결과 | *emaitza* |
| 골을 넣다 | *gola sartu* |
| 경기장 | *zelaia* |

> *— Ikusi zenuen atzoko partida? **Zenbat** bukatu zen?*
>
> *— **2 eta 1 irabazi genuen**! Azken minutuan **gola sartu** zuten.*
>
> *— Aupa! Eta hurrengo astean **etxean jokatuko dute**?*
>
> *— Bai, igandean. **Zelaira joango gara**? Sarrera nire kontu!*

## 대화: 무언가에 등록하기

> *— Kirol pixka bat egin nahi dut, baina gimnasioa **aspergarria** iruditzen zait.*
>
> *— **Zergatik ez zara** herriko igerilekura **apuntatzen**? Goizeko ordutegia oso ona da.*
>
> *— Ez dakit ba… **igeri badakit**, baina gaizki.*
>
> *— Horretarako dira ikastaroak! Ni **astean bitan** joaten naiz. **Elkarrekin joango gara**?*
>
> *— Beno, ados. Baina gero **hamaiketakoa** ere elkarrekin, e?* 😄
