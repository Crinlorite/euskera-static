아무것도 안 할 때 무엇을 하나요? 이번 과에서는 **취미**에 대해 배웁니다 — 그리고 취미를 표현하는 데 사용되는 문법 요소인, 동사를 **-tzea**를 붙여 명사로 만드는 것에 대해서도요 (*irakurtzea* = "읽는 것").

## 문법 요소: -t(z)ea

A1 과정에서 사물과 함께 *gustatzen zait*를 사용하는 법을 배웠습니다 (*kafea gustatzen zait*). **활동**을 좋아한다고 말하려면, 동사를 명사로 만들어야 합니다:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| 스페인어 | 바스크어 |
|---|---|
| 저는 읽는 것을 좋아해요 | *Irakurtzea gustatzen zait* |
| 저는 요리하는 것을 정말 좋아해요 | *Asko gustatzen zait sukaldatzea* |
| 그는/그녀는 노래하는 것을 좋아해요 | *Abestea gustatzen zaio* |
| 우리는 여행하는 것을 좋아해요 | *Bidaiatzea gustatzen zaigu* |
| 저는 일찍 일어나는 것을 전혀 좋아하지 않아요 | *Ez zait batere gustatzen goiz jaikitzea* |

이미 알고 있는 모든 NOR-NORI 동사(*zait, zaio, zaigu…*)는 그대로 사용됩니다. '무엇을'에 해당하는 부분만 바뀝니다.

## 취미 목록

| 스페인어 | 바스크어 |
|---|---|
| 읽기 / 쓰기 | *irakurtzea / idaztea* |
| 음악 듣기 | *musika entzutea* |
| 노래하기 / 춤추기 | *abestea / dantzatzea* |
| 요리하기 | *sukaldatzea* |
| 사진 찍기 | *argazkiak ateratzea* |
| 페인팅하기 / 그림 그리기 | *margotzea / marraztea* |
| 여행하기 | *bidaiatzea* |
| 텃밭 가꾸기 | *baratzea zaintzea* |
| 비디오 게임 | *bideo-jokoak* |
| 바느질하기 / 뜨개질하기 | *jostea / puntua egitea* |

## 묻고 자랑하기

> ***Zer egitea gustatzen zaizu** denbora librean?* — 자유 시간에 무엇을 하는 것을 좋아하세요?
>
> ***Zein da zure zaletasunik gogokoena**?* — 가장 좋아하는 취미는 무엇인가요?
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — 제가 가장 좋아하는 취미는 요리입니다. 주말마다 새로운 레시피를 시도해 봐요.

## 세 가지 구조, 세 가지 뉘앙스 (심화 복습)

| 구조 | 예시 | 의미 |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | 좋아한다 (취미) |
| **-tzen dakit** | *Margotzen dakit* | 할 줄 안다 (능력) |
| **-tzen ari naiz** | *Margotzen ari naiz* | 하고 있다 (지금) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — 저는 뜨개질은 할 줄 모르지만, 배우고 싶어요. (이 멋진 표현 *gustatuko litzaidake*는 B1 과정에서 마스터하게 될 거예요. 맛보기로 살짝 보여드립니다.)
