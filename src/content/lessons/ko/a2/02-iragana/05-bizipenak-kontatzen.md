이번 과는 **통합** 과입니다. 완료 과거, 불완료 과거, 진행상을 결합하여 바스크어에서 사용하는 시제의 조화를 통해 **경험을 이야기하는 법**을 배웁니다.

이미 배운 내용:

- *Iragan burutua* (1과, 2과): 특정 시점의 사건.
- *Iragan ez burutua* (4과): 습관 또는 묘사.
- 과거형 종합 동사 (3과): 진행 중인 장면을 묘사합니다.
- 과거 시간 표현 (atzo, joan den astean, duela...).

이제 이것들을 **연결하는 법**을 배웁니다.

## 이야기의 시제 조화

일반적인 과거 이야기는 기능에 따라 시제를 혼합합니다:

| 기능 | 시제 | 예시 |
|---|---|---|
| 시간적, 공간적 배경 | 불완료 과거 | *Garai hartan Bilbon **bizi ginen*** |
| 어땠는지 / 어떤 상태였는지 | 불완료 과거 | *Iluna **zen** kalea* |
| 무슨 일이 일어났는지 (특정 시점) | burutua | *Bat-batean atea **jo zuten*** |
| 진행 중인 행동 | ari nintzen / 종합 동사 | *Afaria **prestatzen ari nintzen*** |
| 결과 | burutua | *Eta gauza guztiak **gertatu ziren*** |

## 시간 연결어

일어난 일을 연결하기 위해:

| 스페인어 | 바스크어 |
|---|---|
| 처음에 / 맨 처음에 | *Lehenengo* / *Hasieran* |
| 그 다음에 | *Ondoren* |
| 그리고 나서 | *Gero* |
| 그 후에 | *Geroago* |
| 나중에 | *Beranduago* |
| 그러는 동안 | *Bitartean* |
| 갑자기 | *Bat-batean* |
| 그때 | *Orduan* |
| 마지막으로 / 결국 | *Azkenean* |

이 구조들은 모든 전기나 개인적인 이야기에서 나타납니다:

| 스페인어 | 바스크어 |

## 예문: 짧은 전기

> *Garazi 1992an Iruñean **jaio zen**. Txikitan auzo lasai batean **bizi zen**, eta bere familia oso handia **zen**: lau anai-arreba **zituen** eta amona ondoan **zegoen**. Eskolan euskaraz **ikasten zuen**, eta hamabost urterekin musika tresnak **ikasten hasi zen**.*
>
> *Hemezortzi urterekin Donostiara **joan zen** unibertsitatera. Han Lander **ezagutu zuen**, kafetegi batean **lan egiten** **zuen** **bitartean**. **Maitemindu ziren** azkar, eta urtebete geroago **bizitzen hasi ziren** elkarrekin.*
>
> *Duela bost urte, **erabaki zuten** Bilbora itzultzea. Han etxe txiki bat **erosi zuten**, eta orain bertan **bizi dira** alaba batekin.*

시제의 조화를 살펴보세요:

- *jaio zen, joan zen, ezagutu zuen, maitemindu ziren, hasi ziren, erabaki zuten, erosi zuten* → **burutua** (특정 시점의 행동).
- *bizi zen, zituen, zegoen, ikasten zuen, lan egiten zuen* → **ez burutua** (장면, 배경, 습관).

## 나만의 이야기 만들기

A2 레벨을 위한 실용적인 방법:

1. **시간적 배경**: 시간 표현(*Duela X urte... / X-ean...*)으로 시작하세요.
2. **장면**: 불완료 과거로 모든 것이 어땠는지 묘사하세요 (*bizi nintzen, lan egiten nuen, urruti nengoen...*).
3. **핵심 사건**: 이야기의 핵심 사건들을 burutua로 연결하세요 (*ezagutu nuen, joan ginen, hasi nintzen...*).
4. **연결어**: *lehenengo, gero, ondoren, bitartean, azkenean* 등을 사용하여 흐름을 자연스럽게 만드세요.
5. **마무리**: 현재 시제로 끝내서 지금과 연결하세요 (*eta orain... bizi naiz / ari naiz / nago*).

## 누군가를 인터뷰하기 위한 질문

| 스페인어 | 바스크어 |
|---|---|
| 어디서 태어났나요? | *Non jaio zinen?* |
| 언제부터 일을 시작했나요? | *Noiz hasi zinen lanean?* |
| 어렸을 때 무엇을 했나요? | *Zer egiten zenuen txikitan?* |
| Lander와 Anboto 중 누구를 먼저 만났나요? | *Lehenengo nor ezagutu zenuen, Lander ala Anboto?* |
| 당신의 고향은 어땠나요? | *Nolakoa zen zure herria?* |
| 왜 이사했나요? | *Zergatik aldatu zinen etxez?* |

> **A2 도전 과제:** burutua와 ez burutua를 섞어서 다섯 문장으로 자신만의 짧은 전기를 써보세요. *jaio nintzen*으로 시작해서, 어린 시절의 장면(*bizi ginen, etxean...*)을 묘사하고, 세 가지 핵심 사건을 연결한 후 현재 시제로 마무리하세요.

> **문화 노트:** 전기와 *bizipen-kontaketak*(경험담)은 성인 바스크어 학습에서 매우 흔한 장르입니다. 거의 모든 A2 교재에는 노인, 작가, 운동선수와의 인터뷰가 포함되어 있습니다. 이는 과거 시제를 다지고, 더불어 Bernardo Atxaga, Itziar Ituño 또는 Mikel Erentxun과 같은 문화적 인물들을 발견하는 가장 좋은 방법입니다.
