A2 레벨에서는 자신의 신체 상태에 대해 이야기하는 법을 배웁니다. 언제 아픈지, 어디가 아픈지, 의사가 무엇을 처방했는지 말이죠. A1에서 이미 배운 기본 구조(*mina daukat*)에 특정 어휘, 의료 전문가, 진료실 대화가 더해져 확장됩니다.

## "아프다"라고 말하는 법

바스크어에는 두 가지 흔한 표현이 있습니다:

- **Gaixorik nago.** — 아픕니다. (일시적인 상태, *egon* 동사 사용)
- **Ez nago ondo.** — 몸이 좋지 않습니다.
- **Min hartu dut.** — 다쳤습니다.
- **Gaixotu egin naiz.** — 아프게 되었습니다 (자동사, *naiz*).

> **문법 노트:** *gaixorik*은 *pozik*(기쁜), *nekatuta*, *triste*와 마찬가지로 상태를 나타내는 접미사 -**rik**을 사용합니다. 기억하세요: 상태 = *egon*.

## 증상 — 만능 공식 X **daukat**

A1에서처럼, 증상은 *eduki*(가지다) 동사로 표현합니다:

| 한국어 | 바스크어 |
|---|---|
| 열이 있어요 | *Sukarra **daukat*** |
| 기침이 나요 | *Eztula **daukat*** |
| 감기에 걸렸어요 | *Katarroa **daukat*** |
| 독감에 걸렸어요 | *Gripea **daukat*** |
| 어지러워요 | *Zorabiatuta nago* |
| 메스꺼워요 | *Goragalea **daukat*** |

## 통증: *mina*

**통증**은 바스크어에서 명사(*mina*)이며, **NONGO (-ko)** 형태의 신체 부위와 결합하여 "어떤 종류의 통증"인지를 설명하는 보어 역할을 합니다:

> **신체 부위 + -ko + mina + daukat**

| 한국어 | 바스크어 |
|---|---|
| 머리가 아파요 | *Buruko mina daukat* |
| 목이 아파요 | *Eztarriko mina daukat* |
| 배가 아파요 | *Sabeleko mina daukat* |
| 이가 아파요 | *Hortzeko mina daukat* |
| 등이 아파요 | *Bizkarreko mina daukat* |
| 발이 아파요 | *Oinetako mina daukat* |

특히 "지금 당장" 어딘가 아플 때 매우 자주 쓰이는 다른 표현입니다:

- *Buruak min ematen dit.* — 머리가 아프게 해요 (직역: 머리가 나에게 통증을 줘요).

## 진료실에서

| 한국어 | 바스크어 |
|---|---|
| 어디가 안 좋으세요? / 무슨 일 있으세요? | *Zer duzu?* / *Zer gertatzen zaizu?* |
| 언제부터요? | *Noiztik?* |
| 아프세요? | *Min ematen dizu?* |
| 8시간마다 알약 하나씩 드세요 | *Hartu pilula bat zortzi orduro* |
| 쉬세요 | *Hartu atseden* |
| 일주일 후에 다시 오세요 | *Itzuli astebete barru* |

|---|---|

## 짧은 대화

> *— Egun on. **Zer duzu**?*
>
> *— **Sukarra daukat** atzotik, eta **buruko mina** ere bai.*
>
> *— Eztulik?*
>
> *— Bai, baina ez asko.*
>
> *— Ondo. **Hartu** pilula hauek **zortzi orduro**, eta **edan** ur asko. Hobeto ez bazaude, bihar etorri berriro.*

> **문화 노트:** 바스크 지방(Euskal Herria)의 많은 작은 마을에서는 가벼운 문제(감기, 벌레 물림, 어지럼증)가 있을 때 *"botikaria"*(약사)를 가장 먼저 찾아가는 경우가 많습니다. 약국이 주치의를 만나기 전 필터 역할을 하는 셈입니다.
