**명령법**(*agintera*)은 지시, 요청, 조언을 할 때 사용됩니다. 바스크어에서는 **생각보다 훨씬 간단합니다**: 가장 많이 쓰이는 형태가 거의 항상 동사의 **분사** 형태와 일치하기 때문입니다.

## 기본 규칙: 분사 형태 사용하기

많은 일상적인 명령에서 동사는 조동사 없이 분사 형태로 나타납니다:

| 스페인어 | 바스크어 |
|---|---|
| 잡으세요 | *Hartu* |
| 앉으세요 | *Eseri* |
| 일어나세요 | *Jaiki* |
| 쓰세요 | *Idatzi* |
| 읽으세요 | *Irakurri* |
| 들으세요 | *Entzun* |
| 반복하세요 | *Errepikatu* |
| 기다리세요 | *Itxoin* |
| 문을 닫으세요 | *Itxi atea* |
| 창문을 여세요 | *Ireki leihoa* |

> 이것이 교실, 길거리, 그리고 설명서에서 **가장 많이 사용되는 형태**입니다. *zu*와 *zuek* 모두에게 사용할 수 있습니다.

## 통합형(trinkoak): *zatoz*, *zoaz*

일부 매우 흔한 동사들은 명령법을 위한 특정 통합형을 가지고 있습니다. 다음은 암기해두면 좋은 형태들입니다:

| 동사 | 너 (zu) | 너희 (zuek) |
|---|---|---|
| *etorri* (오다) | **Zatoz** | **Zatozte** |
| *joan* (가다) | **Zoaz** | **Zoazte** |
| *ekarri* (가져오다) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (가져가다) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (있다/머무르다) | **Egon** / **Lasai** (진정해!) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## NOR-NORI-NORK 명령법: *emadazu*, *esadazu*

이중 목적어("이것을 나에게 줘", "저것을 그에게 말해")를 사용하여 명령할 때, 바스크어에는 매우 유용한 축약형이 있습니다:

| 스페인어 | 바스크어 |
|---|---|
| 나에게 줘 | *Emadazu* / *Eman iezadazu* |
| 나에게 말해줘 | *Esadazu* / *Esan iezadazu* |
| 그에게 줘 | *Emaiozu* / *Eman iezaiozu* |
| 그에게 말해줘 | *Esaiozu* / *Esan iezaiozu* |
| 우리에게 줘 | *Emaguzu* |
| (너희가) 나에게 줘 | *Emadazue* |

이 형태들은 배우기 어렵습니다. A2 수준에서는 **emadazu / esadazu / emaiozu / esaiozu**를 알고 이들이 *eman* / *esan* 동사에서 왔다는 것을 이해하는 것으로 충분합니다.

## "부탁합니다"와 완곡 표현

바스크어 명령법은 정중한 표현을 덧붙이면 **무례하게 들리지 않습니다**:

- *Mesedez* — 부탁합니다
- *Ahal baduzu* — 가능하다면
- *Faborez* (구어체 변형)
- *Eskerrik asko aldez aurretik* — 미리 감사합니다

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## 지시문 (요리법, 공지, 교실)

명령법은 다음과 같은 상황에서 표준적으로 사용됩니다:

- **요리법:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **표지판:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **교실:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **병원:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## 짧은 글

> *Sukaldari eskolan, irakasleak esaten du:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **문화 노트:** 바스크어에서 명령법의 **명령조** 어감은 완곡한 표현("~해줄 수 있니...?")보다는 억양과 문맥으로 완화됩니다. 명령에 *mesedez*를 덧붙이거나 미소를 짓는 것만으로도 충분한 경우가 많습니다. 더 정중한 표현을 원한다면 *eman ahal didazu...?*(나에게 줄 수 있니...?)라고 말하세요.
