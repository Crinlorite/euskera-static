**생활 방식**과 **환경**에 대해 이야기하는 것은 A2 레벨의 대표적인 주제입니다. A1에서 이미 배운 의무 및 조언 표현(*behar dugu*, *komeni da*, *garrantzitsua da*)과 새로운 어휘가 함께 사용됩니다.

## 건강한 습관

| 스페인어 | 바스크어 |
|---|---|
| 운동하기 | *kirola egin* |
| 걷기 / 산책하기 | *paseatu* / *ibili* |
| 달리기 | *korrika egin* |
| 자전거 타기 | *bizikletaz ibili* |
| 과일과 채소 먹기 | *fruta eta barazkiak jan* |
| 물 마시기 | *ura edan* |
| 잘 자기 | *ondo lo egin* |
| 흡연하기 | *erre* |
| 음주하기 | *alkohola edan* |
| 소금 과다 섭취하지 않기 | *gatzaz ez abusatu* |

> 대표적인 문장:
>
> - *Kirola egiten dut astean hiru aldiz.* — 일주일에 세 번 운동해요.
> - *Erretzeari utzi diot.* — 담배를 끊었어요.
> - *Ez dut alkoholik edaten astegunetan.* — 평일에는 술을 마시지 않아요.

## 빈도: *X aldiz*

'X번'이라고 말하려면 **숫자 + aldiz** 공식을 사용합니다:

| 스페인어 | 바스크어 |
|---|---|
| 하루에 한 번 | *Egunean behin* |
| 일주일에 두 번 | *Astean bi aldiz* / *birritan* |
| 한 달에 세 번 | *Hilean hiru aldiz* |
| 자주 | *Askotan* |
| 가끔 | *Batzuetan* |
| 거의 ~않다 | *Gutxitan* |
| 절대 ~않다 | *Inoiz ez* |

## 환경 — *ingurumena*

| 스페인어 | 바스크어 |
|---|---|
| 환경 | *ingurumena* |
| 자연 | *natura* |
| 오염 | *kutsadura* |
| 쓰레기 | *zaborra* |
| 재활용하다 | *birziklatu* |
| 줄이다 | *gutxitu* / *murriztu* |
| 재사용하다 | *berrerabili* |
| 재생 에너지 | *energia berriztagarria* |
| 기후 변화 | *klima-aldaketa* |
| 지구 온난화 | *berotze globala* |

## 분리수거함

| 일반적인 색 | 바스크어 | 용도 |
|---|---|---|
| 파란색 | *edukiontzi urdina* | papera / 종이 |
| 노란색 | *edukiontzi horia* | plastikoa / 플라스틱 |
| 초록색 | *edukiontzi berdea* | beira / 유리 |
| 갈색 | *edukiontzi marroia* | organikoa / 유기물 |
| 회색 | *edukiontzi grisa* | hondakinak / 일반 쓰레기 |

## 의견을 말할 때 유용한 표현

- *Garrantzitsua da birziklatzea.* — 재활용하는 것은 중요해요.
- *Komeni da kirola egitea.* — 운동하는 것이 좋아요.
- *Beharrezkoa da kutsadura gutxitzea.* — 오염을 줄이는 것이 필요해요.
- *Ez dut uste plastikoa ona denik.* — 플라스틱이 좋다고 생각하지 않아요.

> 이 구조들(*-tzea + 형용사 + da*)은 A2 레벨에서 'X하는 것은 중요하다 / 좋다 / 필요하다'를 표현하는 공식입니다. 4단원에서 더 자세히 다룰 것입니다.

## 동네 생활

| 스페인어 | 바스크어 |
|---|---|
| 동네 | *auzoa* |
| 이웃 | *bizilaguna* |
| 협회, 모임 | *elkartea* |
| 자원봉사 | *boluntariotza* |
| 동네 축제 | *auzoko jaiak* |
| 참여하다 | *parte hartu* |
| 회의 | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## 모델 미니 텍스트

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **문화 노트:** *auzo-elkarteak*(주민 협회)는 에우스칼 헤리아(Euskal Herria)의 많은 마을에서 사회 생활의 핵심적인 부분입니다. 축제, 바스크어 워크숍, 등산, 환경 캠페인 등을 조직합니다. 참여하는 것은 실제 상황에서 언어를 연습할 수 있는 가장 좋은 방법 중 하나입니다.
