이 단원의 마지막 강의이자, 한 큰 주기의 마무리입니다. 미래 시제를 손에 넣었으니, 이제 **세 시제를 모두 마스터**하게 됩니다. 이번 강의에서는 화룡점정 격인 (*ohi*, 바스크어의 "~하곤 하다")를 추가하고, 하나의 아이디어를 과거, 현재-습관, 미래 시제로 옮겨보는 연습을 합니다. 이것이 바로 A2 시험관이 듣고 싶어 하는 것입니다.

## "Ohi" — 바스크어의 "~하곤 하다"

> **분사 + ohi + 조동사**

| 스페인어 | 바스크어 |
|---|---|
| 저는 보통 자전거를 타고 출근해요 | *Lanera bizikletaz joan **ohi** naiz* |
| 우리는 보통 할머니 댁에서 점심을 먹어요 | *Amonaren etxean bazkaldu **ohi** dugu* |
| 그는 보통 늦게 와요 | *Berandu etorri **ohi** da* |
| 예전에는 담배를 피우곤 했어요 (지금은 안 피워요) | *Erre **ohi** nuen* |

두 가지 참고사항:

1. **위치는 고정되어 있습니다**: 분사와 조동사 사이입니다. *Joan ohi naiz* ✓ — 절대 *ohi joan naiz*가 아닙니다.
2. **과거형 조동사**와 함께 쓰면 "~하곤 했다"가 됩니다: *joan ohi nintzen* (~가곤 했다). 이미 알고 있는 불완료과거(*joaten nintzen*)와 아주 비슷하지만, *ohi*는 습관을 더 강조합니다.

> **"ohi"가 없으면요?** 습관 현재형(*joaten naiz*) 자체로 이미 습관을 나타냅니다. *Ohi*는 이를 강조하는 세련된 표현으로, 주로 글이나 시험에서 사용됩니다. 멋지게 표현하고 싶을 때 사용해 보세요: *Igandeetan hondartzara joan ohi gara.*

## 습관을 나타내는 부사

| 스페인어 | 바스크어 |
|---|---|
| 보통, 일반적으로 | *normalean* |
| 대부분 | *gehienetan* |
| 거의 항상 | *ia beti* |
| 가끔, 때때로 | *batzuetan* |
| 거의 ~않다 | *ia inoiz ez* |
| 매일 아침 / 매년 | *goizero / urtero* |
| 일요일마다 | *igandeetan* |

## 시제 총정리 맵 (최종 요약 노트)

| 개념 | 바스크어 | 시제 |
|---|---|---|
| 간다 (습관) | *joaten naiz* / *joan ohi naiz* | 습관 현재 |
| 가고 있다 | *joaten ari naiz* | 현재 진행 |
| (오늘) 갔다 | *joan naiz* | 근과거 |
| (어느 날) 갔다 | *joan nintzen* | 특정 과거 |
| 가곤 했다 | *joaten nintzen* / *joan ohi nintzen* | 습관 과거 |
| 갈 것이다 | ***joango naiz*** | **미래** |

여섯 개의 칸. 하나의 동사. **이제 모두 당신 것입니다.**

## 짧은 글: 예전, 지금, 그리고 내일

> *Lehen, lanera autoz joan **ohi nintzen**: ordu erdi trafikoan, egunero. Orain bizikletaz **joaten naiz** — hamar minutu, eta gainera kirola **egiten dut**. Datorren urtean etxetik gertuago **biziko naiz**, eta orduan oinez **joango naiz**. Nire medikua pozik **egongo da**!* 😄
