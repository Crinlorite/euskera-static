한나절 아침에 해가 떴다가, 비가 오고, 다시 해가 뜰 수 있는 나라에서는 **날씨에 대해 이야기하는 것이 국민 스포츠입니다**. 그리고 두 배의 보상이 따릅니다: *eguraldia* 관련 어휘는 갓 배운 미래 시제를 연습하기에 완벽한 무대입니다. 일기 예보는 항상 *geroaldia*로 말하기 때문이죠.

## 기본 어휘

| 한국어 | 바스크어 |
|---|---|
| 날씨 | *eguraldia* |
| 해 | *eguzkia* |
| 비 | *euria* |
| 눈 | *elurra* |
| 바람 | *haizea* |
| 안개 | *lainoa* |
| 구름 | *hodeiak* |
| 소나기 | *zaparrada* |
| 기온 | *tenperatura* |
| 도 (온도) | *graduak* |
| 일기 예보 | *iragarpena* |

## 모든 것을 움직이는 세 가지 구문

| 시점 | 구문 | 예시 |
|---|---|---|
| **바로 지금** | 현상 + ***ari du*** | *Euria **ari du**.* — 비가 오고 있어요. |
| **일반적으로 / 오늘** | 현상 + ***egiten du*** | *Hotz handia **egiten du**.* — 매우 추워요. |
| **예보 (미래)** | 현상 + ***egingo du*** | *Bihar euria **egingo du**.* — 내일 비가 올 거예요. |

자체 동사를 가진 다른 표현들:

> *Eguzkia **atera da** / **aterako da**.* — 해가 떴어요 / 뜰 거예요.
>
> *Haizea **dabil**.* — 바람이 불어요 (바람이 "걷는다"는 의미).
>
> ***Hodeitsu / eguzkitsu dago**.* — 흐려요 / 화창해요.

> **주목하세요:** 바스크어에서 날씨는 *egin* 동사와 보조 동사 **du**를 사용하여 (가시적인 주어 없이) 무언가를 "**합니다**": *euria egingo du*, *bero handia egiten du*. 스페인어의 «hace calor»(더워요)와 똑같은 구조입니다. 다만 비도 '한다'고 표현한다는 점이 다릅니다.

## 질문하는 법

> ***Zer eguraldi egiten du** zure herrian?* — 당신의 마을은 날씨가 어때요?
>
> ***Zer dio iragarpenak** biharko?* — 내일 예보가 어떻게 돼요?
>
> ***Zenbat gradu daude** kanpoan?* — 밖은 몇 도예요?

## 실제 일기 예보 (TV에서처럼)

> *«Gaur, goizean **lainoa** izango dugu kostaldean, baina eguerdirako **eguzkia aterako da**. Arratsaldean **hodeiak** iritsiko dira mendebaldetik eta gauean **euria egingo du**, batez ere Bizkaian. Tenperaturak **behera egingo du**: 22 gradutik 16ra. Bihar, **haizea ibiliko da** eta **zaparradak** izango ditugu han-hemenka.»*

(아침 해안가에는 안개, 정오에는 맑음, 서쪽에서 구름 유입, 밤에는 비, 기온 하강, 내일은 바람과 간헐적인 소나기 — 전형적인 대서양 날씨죠. 😄)

## 대화: 계획은 하늘에 달렸다

> *— Bihar mendira **joango gara**?*
>
> *— Ez dakit… **zer dio iragarpenak**?*
>
> *— Goizean **eguzkitsu**, baina arratsaldean **euria egingo du**.*
>
> *— Orduan goiz **aterako gara**. **Zaparrada** harrapatzen bagaitu, hurrengoan ez naiz zurekin inora joango!* 😄
