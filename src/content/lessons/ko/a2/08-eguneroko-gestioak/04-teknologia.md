종이에서 픽셀까지: **일상 기술**에 대한 수업입니다. 하루에 백 번은 사용하는 어휘를 이제 바스크어로 배워보세요. 바스크어는 투명하고 잘 만들어진 단어들을 자랑합니다(*pasahitza* = 통과 단어; *sakelakoa* = '주머니 속의 것').

## 기기들

| 스페인어 | 바스크어 |
|---|---|
| 컴퓨터 | *ordenagailua* |
| 노트북 (컴퓨터) | *eramangarria* |
| 휴대폰 | *mugikorra / sakelakoa* |
| 태블릿 | *tableta* |
| 화면 | *pantaila* |
| 키보드 | *teklatua* |
| 마우스 | *sagua* (네, 그 동물 맞아요!) |
| 헤드폰 / 이어폰 | *entzungailuak* |

## 네트워크와 계정

| 스페인어 | 바스크어 |
|---|---|
| 네트워크 / 인터넷 | *sarea / internet* |
| 와이파이 | *wifia* |
| 이메일 | *posta elektronikoa* |
| 사용자 | *erabiltzailea* |
| 비밀번호 | *pasahitza* |
| 애플리케이션 / 앱 | *aplikazioa* |
| 웹사이트 | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — 와이파이 비밀번호가 뭐예요?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — 비밀번호를 잊어버려서 새로 만들어야 해요. 또다시.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — 계정을 만들려면 이메일과 비밀번호가 필요합니다.

## 디지털 동사

| 스페인어 | 바스크어 |
|---|---|
| 켜다 / 끄다 | *piztu / itzali* |
| 다운로드하다 | *deskargatu / jaitsi* |
| 설치하다 | *instalatu* |
| 저장하다 | *gorde* |
| 삭제하다 | *ezabatu* |
| 보내다 / 공유하다 | *bidali / partekatu* |
| 검색하다 (인터넷에서) | *bilatu* |
| 작동하다 | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — 컴퓨터가 잘 안 돼요. 껐다가 켜세요. 언제나 통하는 해결책이죠.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — 사진 저장했어요? 아무것도 지우지 마세요!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — 앱을 다운로드하고, 계정을 만들면 끝.

## 대화: 가족 기술 지원

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **참고:** 디지털 세상의 바스크어는 매우 활발합니다. 오픈 소스 소프트웨어와 바스크어 위키백과는 강력하며, 휴대폰 전체 언어를 바스크어로 설정할 수도 있습니다 (*Ezarpenak → Hizkuntza*). 이렇게 설정하는 것은 사실 엄청난 공부 꿀팁입니다. 매일 무료로 몰입 학습을 할 수 있죠.
