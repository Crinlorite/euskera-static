성인 생활의 최종 보스: **서류 작업**. 숨을 고르세요. 잘 선택한 열 개의 단어(*agiria, hitzordua, bete, epea…*)만 있으면 어떤 창구에서도 살아남을 수 있습니다 — 게다가 바스크어로 말하면, 공무원의 미소는 덤으로 얻을 수 있죠.

## 서류 작업 관련 어휘

| 스페인어 | 바스크어 |
|---|---|
| 시청 | *udaletxea* |
| 주민 등록 / 전입 신고하다 | *errolda / erroldatu* |
| 주민등록증명서 | *errolda-agiria* |
| 문서 / 증명서 | *agiria* |
| 신분증 (DNI) | *NANa* |
| 운전면허증 | *gidabaimena* |
| 신청서 | *eskabidea* |
| 작성하다 | *bete* |
| 예약 / 차례 | *hitzordua / txanda* |
| 기한 | *epea* |
| 창구 | *leihatila* |

## 예약하기 (현대의 의식)

> ***Hitzordua eskatu behar da** aurretik, webgunean edo telefonoz.* — 웹사이트나 전화로 미리 예약해야 합니다.
>
> *Hitzordua daukat **gaurko, hamaiketan**, erroldarako.* — 오늘 11시에 주민 등록 때문에 예약이 있습니다.

## 창구에서

> *— Egun on. **Errolda-agiri bat behar dut**, banketxerako.*
>
> *— **NANa**, mesedez… Momentu bat… Tori, hemen duzu. **Doan da**.*
>
> *— Eskerrik asko! Eta beste kontu bat: etxez aldatu naiz. **Erroldatzeko**, zer egin behar dut?*
>
> *— **Eskabide hau bete** eta etxebizitzaren kontratua ekarri. **Fotokopiarik ez** da behar; guk egiten dugu.*
>
> *— Bikain. **Eperik badago**?*
>
> *— Ez, lasai, edonoiz etor zaitezke. Baina **hitzordua eskatu** lehenago, e!*

## 생존을 위한 세 문장

> ***Zer agiri ekarri behar ditut**?* — 어떤 서류를 가져와야 하나요?
>
> ***Noiz arte** daukat epea?* — 기한이 언제까지인가요?
>
> ***Nork sinatu behar du**?* — 누가 서명해야 하나요?

> **참고:** *hitzordua*는 글자 그대로 "말의 시간"(*hitza* + *ordua*)이라는 뜻입니다 — 병원 예약, 관공서 예약, 데이트 약속 모두 같은 단어를 씁니다. 나머지는 문맥(과 당신의 표정)에 달려있죠. 😄
