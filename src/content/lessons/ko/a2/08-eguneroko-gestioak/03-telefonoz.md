다른 언어로 전화 통화하는 건 부담스럽죠 — 얼굴도 안 보이고, 제스처도 없으니까요. 그래서 이번 과는 **바로 쓸 수 있는 공식**들로 가득합니다: 격식 있는 전화 통화부터 WhatsApp 음성 메시지까지, 언제나 통하는 고정 표현들이죠.

## 전화 받고 묻기

| 스페인어 | 바스크어 |
|---|---|
| 여보세요? | *Bai, esan?* |
| 누구세요? | *Nor da?* |
| Ane 있나요? | *Ane dago?* |
| Mikel입니다 | *Mikel naiz* |
| 잠시만요, 바꿔 드릴게요 | *Une batez, orain jarriko da* |
| 지금 안 계세요 | *Orain ez dago* |

## 전화를 받을 수 없을 때

> *— Kaixo, **Ane dago**?*
>
> *— Ez, **orain ez dago**. Zerbait **esan behar diot**?*
>
> *— Bai, mesedez: bilera **bihar dela**, ez gaur. Edo hobeto: **deituko didala**, libre dagoenean.*
>
> *— Ederki, **esango diot**. Nor zarela esango diot?*
>
> *— **Mikel naiz**, lanekoa. Eskerrik asko!*

주목하세요: *esan behar diot*(그에게 말해야 해요), *esango diot*(그에게 말할 거예요), *deituko didala*(나에게 전화하라고) — 03과에서 배운 NOR-NORI-NORK 용법이 전화 통화에서 핵심적인 역할을 합니다. 전화하다는 *deitu* + NORI입니다: *deitu diot*(그에게 전화했어요), *deituko dizut*(너에게 전화할게).

## 기술적인 문제 (단골 문제들)

| 스페인어 | 바스크어 |
|---|---|
| 통화 중입니다 | *Komunikatzen ari da* |
| 수신이 안 돼요 | *Estaldurarik ez dago* |
| 배터리가 나갔어요 | *Bateria gabe geratu naiz* |
| 잘 안 들려요 | *Gaizki entzuten da* |
| 끊겼어요 | *Deia moztu da* |
| 잘못된 번호 | *Okerreko zenbakia* |

> *Barkatu, **gaizki entzuten da**. Igogailuan nago — **gero deituko dizut**!* — 미안, 잘 안 들려. 엘리베이터 안이라서 — 나중에 전화할게!

## 메시지 (gaur egungo bizitza)

> ***Mezu bat bidali dizut** WhatsAppez.* — WhatsApp으로 메시지 보냈어.
>
> ***Audioa entzun duzu**?* — 음성 메시지 들었어?
>
> *Deitu beharrean, **idatzi**, mesedez: bileran nago.* — 전화 말고 문자로 부탁해. 회의 중이야.

## 자동 응답기 / 안내 메시지

> *«Kaixo! Orain ezin dut telefonoa hartu. **Utzi mezua** seinalearen ondoren, eta **lehenbailehen deituko dizut**. Eskerrik asko!»* — 안녕하세요! 지금은 전화를 받을 수 없습니다. 신호음이 울리면 메시지를 남겨주세요. 확인하는 대로 바로 전화드리겠습니다. 감사합니다!

*Lehenbailehen* = 가능한 한 빨리. 여러분의 바스크어 실력을 두 단계는 올려줄 것 같은 우아한 단어죠. 😄
