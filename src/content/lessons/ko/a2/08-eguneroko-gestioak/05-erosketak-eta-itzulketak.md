A1 레벨에서 쇼핑하는 법은 이미 배웠습니다. 이번 과는 **상점 레벨 2**입니다: 옷 입어보기, 사이즈와 씨름하기, 그리고 최종 보스인 땀 흘리지 않고 **교환 또는 환불하기**를 배울 거예요. 오랜 친구 두 명도 함께합니다. 바로 *-egi*(너무)와 NOR-NORI(*geratzen zait*)입니다.

## 탈의실에서

| 스페인어 | 바스크어 |
|---|---|
| 입어봐도 될까요? | *Probatu dezaket?* |
| 탈의실 | *probalekua* |
| 사이즈 | *neurria / talla* |
| 사이즈가 어떻게 되세요? | *Zein neurri erabiltzen duzu?* |
| 잘 맞아요 / 안 맞아요 | *Ondo / gaizki geratzen zait* |
| 너무 커요 / 작아요 | *Handiegia / txikiegia* |
| 다른 색상도 있나요? | *Beste kolore batean baduzue?* |
| 한 사이즈 더 큰 건요? | *Eta neurri bat handiagoan?* |

> *— Praka hauek **probatu ditzaket**?*
>
> *— Noski, **probalekua** hor atzean dago.*
>
> *(bost minutu geroago)* *— Zer, **ondo geratzen zaizkizu**?*
>
> *— Ez… **txikiegiak dira**. **42an baduzue**?*

*Geratzen zait / zaizkizu* — 순수한 NOR-NORI 구문입니다: 옷(NOR)이 나에게(NORI) 맞다. 복수형은 *geratzen zaizkit*(내게 맞는다)입니다.

## 교환 및 환불

| 스페인어 | 바스크어 |
|---|---|
| 교환하고 싶어요 | *Aldatu nahi dut* |
| 환불하고 싶어요 | *Itzuli nahi dut* |
| 돈으로 환불해 주시나요? | *Dirua itzuliko didazue?* |
| 영수증 | *tiketa* |
| 결함이 있어요 | *Akats bat dauka* |
| 사용하지 않았어요 | *Erabili gabe dago* |
| 환불 기간 | *Itzultzeko epea* |

> *— Egun on. Jertse hau **itzuli nahi nuke**. **Akats bat dauka** hemen, ikusten?*
>
> *— Egia da. **Tiketa badaukazu**?*
>
> *— Bai, hemen. **Dirua itzuliko didazue** ala aldatu behar dut?*
>
> *— Nahi duzun bezala. Dirua **txartelera itzuliko dizugu**, bi-hiru egunetan.*
>
> *— Primeran, eskerrik asko.*

연결된 NOR-NORI-NORK 구문에 주목하세요: *itzuliko didazue*(당신들이 나에게 그것을 돌려줄 것이다), *itzuliko dizugu*(우리가 당신에게 그것을 돌려줄 것이다). 03과가 실생활에서 이렇게 쓰입니다.

## 포켓 요약

1. **입어보기**: *Probatu dezaket? → Ondo/gaizki geratzen zait →* 사이즈에는 *-egi* 사용.
2. **교환하기**: *Aldatu nahi dut* (+ *beste neurri/kolore batean*).
3. **환불하기**: *Itzuli nahi dut* + *tiketa* + *dirua itzuliko didazue?*
