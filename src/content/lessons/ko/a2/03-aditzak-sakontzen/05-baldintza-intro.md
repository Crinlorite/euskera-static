바스크어의 **조건법**(*baldintza*)은 여러 형태가 있습니다. A2 레벨에서는 **가장 유용한 두 가지** 형태를 배웁니다:

1. **실현 가능한 조건 (일어날 법한 미래):** *만약 내일 비가 온다면, 가지 않을 거야*.
2. **비현실적 조건 (가정):** *만약 돈이 있다면, 집을 살 텐데*.

이번 과는 **입문** 과정입니다. 형태를 알아보고 간단한 문장을 만들 수 있으면 충분합니다. B1 유닛에서 더 깊이 다룹니다.

## 유형 1: 실현 가능한 조건 — *ba-* + 현재형

**일어날 법한 미래**나 현재에 대한 가정을 할 때, 바스크어에서는 현재형 조동사 앞에 접두사 **ba-**를 붙입니다.

> **ba- + 조동사 현재형, ... + 미래형**

| 한국어 | 바스크어 |
|---|---|
| 비가 오면, 가지 않을 거야 | *Euria egiten **badu**, ez naiz joango* |
| 시간 있으면, 와 | *Astia **baduzu**, etorri* |
| 원하면, 나에게 전화해 | *Nahi **baduzu**, deitu niri* |
| 언젠가 부자가 된다면… | *Aberatsa **banaiz** noizbait...* |

### *ba-* 형태 (현재형)

| 동사 | ba- 없음 | ba- 있음 |
|---|---|---|
| *naiz* | 나는 ~이다 | **banaiz** (만약 내가 ~라면) |
| *zara* | 너는 ~이다 | **bazara** (만약 네가 ~라면) |
| *da* | ~이다 | **bada** (만약 ~라면) |
| *gara* | 우리는 ~이다 | **bagara** (만약 우리가 ~라면) |
| *dut* | 나는 그것을 가지고 있다 | **badut** (만약 내가 그것을 가지고 있다면) |
| *du* | 그가 그것을 가지고 있다 | **badu** (만약 그가 그것을 가지고 있다면) |
| *dute* | 그들이 그것을 가지고 있다 | **badute** (만약 그들이 그것을 가지고 있다면) |

> **¡주의!** *Ba-*는 긍정의 의미로도 사용됩니다: *bai, badator* = "네, 오고 있어요". 문맥을 통해 구분할 수 있습니다. 만약 문장에 두 번째 부분("...그러면...")이 있다면, 조건문입니다.

## 유형 2: 비현실적 조건 — *banintz / banu*

비현실적이거나 가능성이 매우 낮은 가정을 할 때("만약 내가 ~라면...", "만약 내가 ~을 가졌다면..."), 바스크어에서는 전용 형태를 사용합니다:

### 비현실적 조건에서의 *izan* 동사 형태

| 대명사 | 형태 | 한국어 |
|---|---|---|
| ni | **banintz** | 만약 내가 ~라면/~있다면 |
| zu | **bazina** | 만약 네가 ~라면 |
| hura | **balitz** | 만약 ~라면/~있다면 |
| gu | **bagina** | 만약 우리가 ~라면 |
| zuek | **bazinete** | 만약 너희가 ~라면 |
| haiek | **balira** | 만약 그들이 ~라면 |

### 비현실적 조건에서의 *ukan* 동사 형태

| 대명사 | 형태 | 한국어 |
|---|---|---|
| nik | **banu** | 만약 내가 그것을 가졌다면 |
| zuk | **bazenu** | 만약 네가 그것을 가졌다면 |
| hark | **balu** | 만약 그/그녀가 그것을 가졌다면 |
| guk | **bagenu** | 만약 우리가 그것을 가졌다면 |
| haiek | **balute** | 만약 그들이 그것을 가졌다면 |

> **이 여섯 가지를 먼저 외우세요**: *banintz, balitz, banu, balu, bagenu, balute*. 이 형태들은 모든 비현실적 조건문에 나타납니다.

## 결과절: *-ko/-go + nuke / nintzateke*

"살 **텐데** / 갈 텐데 / 일 텐데"와 같은 표현은 미래형과 동일한 표시인 **-ko/-go**와 특별한 조동사를 결합하여 만듭니다:

### NOR-NORK 조건법 ("나는 그것을 ~할 텐데")

| 대명사 | 형태 | 한국어 |
|---|---|---|
| nik | **nuke** | 나는 그것을 —할 텐데 |
| zuk | **zenuke** | 너는 그것을 —할 텐데 |
| hark | **luke** | 그는 그것을 —할 텐데 |
| guk | **genuke** | 우리는 그것을 —할 텐데 |
| haiek | **lukete** | 그들은 그것을 —할 텐데 |

### NOR 조건법 ("나는 —할 텐데", 자동사)

| 대명사 | 형태 | 한국어 |
|---|---|---|
| ni | **nintzateke** | 나는 —할 텐데 |
| zu | **zinateke** | 너는 —할 텐데 |
| hura | **litzateke** | 그는 —할 텐데 / 일 텐데 |
| gu | **ginateke** | 우리는 —할 텐데 |
| haiek | **lirateke** | 그들은 —할 텐데 |

## 예문

> **baldintza + ondorioa**

> *Diru asko **banu**, etxe bat **erosiko nuke**.* — 만약 돈이 많다면, 집을 한 채 살 텐데.
>
> *Lurralde berri batean **bizi banintz**, beste hizkuntza bat **ikasiko nuke**.* — 만약 새로운 나라에 산다면, 다른 언어를 배울 텐데.
>
> *Anboto hemen **balitz**, lasaiago **egongo ginateke**.* — 만약 Anboto가 여기 있다면, 우리는 더 편안할 텐데.
>
> *Aberatsak **balira**, mundu osoa **bisitatuko lukete**.* — 만약 그들이 부자라면, 전 세계를 여행할 텐데.

## 두 유형 비교

| 유형 | "만약" | "그러면" |
|---|---|---|
| 실현 가능 (일어날 법한 미래) | *ba-* + 현재형: *baduzu, bada* | 미래형: *-ko/-go + naiz/dut* (joango naiz, erosiko dut) |
| 비현실적 (가정) | *ba-* + 조건법: *banu, balitz* | 조건법: *-ko/-go + nuke/nintzateke* |

## 대조 예문

- **실현 가능:** *Astia **baduzu**, lagunduko **dizut**.* — 시간 있으면, 도와줄게.
- **비현실적:** *Astia **bazenu**, lagunduko **zenidake**.* — 시간이 있다면, 나를 도와줄 텐데.

## 아주 유용한 관용 표현

| 한국어 | 바스크어 |
|---|---|
| ~하시겠어요…? | *Nahi **zenuke**…?* |
| ~하고 싶어요… | *Gustatuko **litzaidake**…* |
| 좋을 텐데요… | *Polita **litzateke**…* |
| 기꺼이 갈 텐데요 | *Gustura **joango nintzateke*** |
| 생각해 볼 텐데요 | *Pentsatuko **nuke*** |

## 미니 대화

> *— Olatz, **nahi zenuke** zinemara joan?*
>
> *— Bai, **gustatuko litzaidake**, baina astia **banu**... Lan asko daukat astean.*
>
> *— Lasai. Bihar **etortzen bazara**, sarrera bat **erosiko dizut**.*

> **교육적 참고:** *baldintza*는 A2에서 B1으로 넘어가는 관문 중 하나입니다. 공식 A2 과정에서는 *banintz... -ko nuke*와 같은 간단한 문장을 **알아보고** 만들 수 있는 수준이면 충분합니다. 조건법의 전체 동사 변화는 B1에서 다룹니다.
