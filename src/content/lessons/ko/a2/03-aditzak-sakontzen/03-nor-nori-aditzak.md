**NOR-NORI** 동사는 어떤 것(NOR)이 "누군가에게(NORI) 일어나는" 경우에 사용됩니다. 문법적 주어는 사람이 아니라 **사물**입니다 — 스페인어의 *gustar* 동사와 똑같습니다: *me gusta el cine* (나는 영화를 좋아한다).

A1 레벨에서 *gustatzen zait*을 이미 배웠습니다. A2에서는 이 패턴을 다른 유용한 동사들로 확장합니다.

## 현재 시제 NOR-NORI 조동사 형태

NOR 단수일 때:

| NORI | 형태 | 한국어 |
|---|---|---|
| niri | **zait** | 나에게 |
| zuri | **zaizu** | 너에게 |
| hari | **zaio** | 그/그녀에게 |
| guri | **zaigu** | 우리에게 |
| zuei | **zaizue** | 너희에게 |
| haiei | **zaie** | 그들에게 |

NOR **복수**일 때:

| NORI | 복수 형태 | 한국어 |
|---|---|---|
| niri | **zaizkit** | 나에게 (복수) |
| zuri | **zaizkizu** | 너에게 |
| hari | **zaizkio** | 그/그녀에게 |
| guri | **zaizkigu** | 우리에게 |
| zuei | **zaizkizue** | 너희에게 |
| haiei | **zaizkie** | 그들에게 |

## 과거: *zitzaidan, zitzaion*

| NORI | 과거 단수 | 과거 복수 |
|---|---|---|
| niri | **zitzaidan** | **zitzaizkidan** |
| zuri | **zitzaizun** | **zitzaizkizun** |
| hari | **zitzaion** | **zitzaizkion** |
| guri | **zitzaigun** | **zitzaizkigun** |
| haiei | **zitzaien** | **zitzaizkien** |

## 이 패턴을 사용하는 동사

| 동사 | 의미 | 예시 |
|---|---|---|
| *gustatu* | 좋아하다 | *Filmak gustatzen zaizkit* (나는 영화들을 좋아한다) |
| *iruditu* | ~인 것 같다, ~라고 생각되다 | *Ondo iruditzen zait* (괜찮다고 생각한다) |
| *ahaztu* | 잊어버리다 | *Ahaztu zait izena* (이름을 잊어버렸다) |
| *erori* | 떨어지다 | *Erori zaizu boligrafoa* (네 볼펜이 떨어졌다) |
| *gertatu* | (누군가에게) 일어나다 | *Zer gertatu zaizu?* (무슨 일이야?) |
| *interesatu* | 관심 있다 | *Politika interesatzen zait* (나는 정치에 관심이 있다) |
| *axola izan* | 상관있다 | *Ez zait axola* (상관없다) |

## 구조: 주어는 사물

> **NORI + NOR + 동사 + NOR-NORI 조동사**

| 한국어 | 바스크어 | 표기 |
|---|---|---|
| 나는 영화를 좋아한다 | *Niri zinea **gustatzen zait*** | NORI + NOR 단수 + zait |
| 나는 영화들을 좋아한다 | *Niri filmak **gustatzen zaizkit*** | NORI + NOR 복수 + zaizkit |
| 너는 괜찮다고 생각한다 | *Zuri ondo **iruditzen zaizu*** | NORI + NOR + zaizu |
| 그가 책 한 권을 떨어뜨렸다 | *Hari liburu bat **erori zaio*** | NORI + NOR 단수 + zaio |
| 나는 열쇠들을 잊어버렸다 | *Niri giltzak **ahaztu zaizkit*** | NORI + NOR 복수 + zaizkit |

> **팁:** 영향을 받는 사람은 NORI (-ari/-ei) 형태로 문장 맨 앞에 오는 경향이 있습니다. 사물이 문법적 주어이며, 동사는 이 사물에 일치시킵니다.

## 과거형 *Gustatzen zait* — *gustatu zitzaidan*

과거의 취향에 대해 말할 때:

> *Filma asko **gustatu zitzaidan**.* — 그 영화 정말 좋았어요.
>
> *Ez zitzaion gustatu opari hori.* — 그는 그 선물을 좋아하지 않았어요.

> 주의: *gustatu zitzaidan* (= 좋았다, 완료된 행동) vs *gustatzen zitzaidan* (= 좋아했었다, 습관).

## *Iruditu* (~인 것 같다) — 개인적인 의견

A2 레벨에서 가장 유용한 표현 중 하나입니다:

| 한국어 | 바스크어 |
|---|---|
| 좋은 것 같아요 | *Ondo iruditzen zait* |
| 흥미로운 것 같아요 | *Interesgarria iruditzen zait* |
| 어떻게 생각해요? | *Zer iruditzen zaizu?* |
| 이상한 것 같아요 | *Bitxia iruditzen zait* |
| 그런 것 같아요 | *Baietz iruditzen zait* |

## *Ahaztu zait* — 잊어버렸어요

| 한국어 | 바스크어 |
|---|---|
| 잊어버렸어요 | *Ahaztu zait* |
| 열쇠들을 잊어버렸어요 | *Giltzak ahaztu zaizkit* |
| 그는 모든 것을 잊어버려요 | *Dena ahazten zaio* |
| 잊지 마세요! | *Ez zaizula ahaztu!* |

## 짧은 대화

> *— Olatz, **zer iruditzen zaizu** Bilboko jatetxe berria?*
>
> *— Asko **gustatu zait**. Bereziki bigarren platerak: **interesgarriak iruditu zaizkit**.*
>
> *— Eta, jakin nahi nuen, **ahaztu zaizu** zer eskatu zenuen?*
>
> *— Bai, izenak ez **zaizkit gogoratzen**, baina arraina zen, ziur.*

## 자주 하는 실수

1. **여기서는 능격 주어가 사용되지 않습니다.** *\*Nik gustatzen dut*이라고 말하지 마세요 (아주 흔한 실수입니다). *Niri gustatzen zait*이 맞습니다. 사람이 행동의 주체가 아닙니다.
2. **NOR 일치.** 사물이 복수이면 조동사도 복수형을 씁니다: *zaizkit, zaizkio, zaizkigu...*
3. **일부 지역에서는 다른 변형을 사용하지만** (*hitano*의 *zaidak, zaidan* 등), *batua* (표준 바스크어)에서는 표에 나온 형태가 표준입니다.

> **문화 노트:** 바스크어 화자들은 조심스럽게 의견을 표현하기 위해 *iruditzen zait*을 (애정을 담아) 남용하는 경향이 있습니다: *interesgarria iruditzen zait*, *bitxia iruditzen zait*, *ez zait ondo iruditzen*. 이는 뉘앙스를 더한 "내 생각에는..."의 바스크어 버전입니다.
