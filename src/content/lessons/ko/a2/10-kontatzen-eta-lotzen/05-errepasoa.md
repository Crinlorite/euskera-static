A2의 마지막 수업입니다. **새로운 문법은 없습니다** — 대신 더 좋은 것이 있죠. 바로 지금까지 배운 모든 것이 함께 어떻게 작용하는지 증명하는 시간입니다. 시험 형식: 읽고, 바스크어로 마음속의 목소리를 듣고, 답하세요. *Ea zer moduz!*

## 이제 당신의 것이 된 지식 지도

**A1에서 가져온 것**: 현재 시제, NOR-NORK, 격, 시간, 쇼핑, 취향.

**A2에서 얻은 것:**

| Bloque | La estrella |
|---|---|
| 건강과 명령법 | *Hartu pilula hau!* |
| 과거 시제 (3가지) | *joan nintzen · joaten nintzen · joan ohi nintzen* |
| NOR-NORI-NORK | *eman dizkiot* |
| 비교 | *handiagoa, handiena, handiegia* |
| 의견과 종속절 | *uste dut … -la* |
| **미래와 계획** | *joango naiz · asmoa dut* |
| **여행** | *joan-etorria, erreserba* |
| **업무 처리** | *hitzordua, transferentzia* |
| **여가와 취향** | *irakurtzea gustatzen zait* |
| **연결하기** | *-nean · aurretik/ondoren · -tzeko/-tzera · ea -n* |

## 마지막 텍스트 (한 단락으로 보는 전체 레벨)

> *Iaz euskara **ikasten hasi nintzen**. Hasieran dena **zaila iruditzen zitzaidan**: aditzak, kasuak, hitz luzeak… Egunero apur bat **ikasi ohi nuen**, autobusean **nindoanean** edo afaldu **ondoren**. Orain, urtebete **geroago**, gauza asko **esan ditzaket**: nire bizitza **konta dezaket**, planak **egin ditzaket** eta lagunei mezuak euskaraz **bidaltzen dizkiet**. Ez dakit **noiz arte iritsiko naizen**, baina gauza bat **ziur dakit**: datorren urtean **B1 maila egingo dut**. Eta zuk? **Ea elkarrekin ikasten dugun**!*

전부 이해하셨나요? 바로 그것이 A2 레벨을 갖췄다는 의미입니다.

## 솔직한 자가 평가

보지 않고 다음을 할 수 있다면 A2를 마스터했다고 할 수 있습니다:

1. ✅ **지난 주말에 무엇을 했는지** 말하기 (과거 시제 3문장).
2. ✅ **다음 주말에 무엇을 할 것인지** 말하기 (미래 시제 3문장).
3. ✅ 가게에서 물건을 사고 다음 날 **반품하기**.
4. ✅ **전화 메시지** 남기기: 누구인지, 무엇을 원하는지, 전화해 달라고 요청하기.
5. ✅ **자신의 인생**을 여섯 문장으로 이야기하기 (과거 → 현재 → 계획).
6. ✅ 근거를 들어 **날씨**에 대해 불평하기. ☔

## Zorionak!
