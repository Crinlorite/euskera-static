**타동사**는 목적어를 갖는 동사입니다: 누군가 *무엇을* 먹고, *무엇을* 보고, *무엇을* 읽습니다. 바스크어에서 이 동사들은 **ukan** (dut, duzu, du…) 조동사를 사용합니다. 최근 과거 시제에서의 공식은 다음과 같습니다:

> **partizipioa + dut/duzu/du/dugu/duzue/dute**

## 기본 타동사

| Partizipioa | 나 (…했다) | 한국어 |
|---|---|---|
| *jan* | **jan dut** | 먹었다 |
| *edan* | **edan dut** | 마셨다 |
| *ikusi* | **ikusi dut** | 봤다 |
| *irakurri* | **irakurri dut** | 읽었다 |
| *entzun* | **entzun dut** | 들었다 |
| *erosi* | **erosi dut** | 샀다 |
| *egin* | **egin dut** | 했다 |
| *hartu* | **hartu dut** | 잡았다 / 가졌다 |
| *ekarri* | **ekarri dut** | 가져왔다 |
| *eraman* | **eraman dut** | 가져갔다 |
| *ikasi* | **ikasi dut** | 배웠다 / 공부했다 |
| *eskatu* | **eskatu dut** | 요청했다 / 주문했다 |
| *ordaindu* | **ordaindu dut** | 지불했다 |
| *idatzi* | **idatzi dut** | 썼다 |
| *prestatu* | **prestatu dut** | 준비했다 |
| *garbitu* | **garbitu dut** | 청소했다 |
| *gosaldu* | **gosaldu dut** | 아침을 먹었다 |
| *bazkaldu* | **bazkaldu dut** | 점심을 먹었다 |
| *afaldu* | **afaldu dut** | 저녁을 먹었다 |
| *lan egin* | **lan egin dut** | 일했다 |

## 동사 하나로 전체 활용 보기

*ikusi* (보다)를 예로 들어보겠습니다:

| 대명사 + 주어 | 형태 | 한국어 |
|---|---|---|
| Nik | **ikusi dut** | 제가 봤습니다 |
| Zuk | **ikusi duzu** | 당신이 봤습니다 |
| Hark | **ikusi du** | 그/그녀가 봤습니다 |
| Guk | **ikusi dugu** | 저희가 봤습니다 |
| Zuek | **ikusi duzue** | 당신들이 봤습니다 |
| Haiek | **ikusi dute** | 그들이 봤습니다 |

> 타동사의 주어는 **NORK** 표시(-k)를 가집니다: *nik, zuk, hark, guk, zuek, haiek*. 특히 주어가 이름일 때 자주 보게 될 것입니다: *Mikelek* (미켈이…), *Maialenek* (마이알렌이…). 헷갈린다면, A1 단계에서는 대명사를 생략하고 동사만 사용해도 됩니다. 문맥으로 충분합니다.

## 대표적인 문장들

- *Gaur goizean egunkaria irakurri dut.* — 오늘 아침에 신문을 읽었어요.
- *Bazkaltzeko arraina jan dut.* — 점심으로 생선을 먹었어요.
- *Lagunekin kafea hartu dut.* — 친구들과 커피를 마셨어요.
- *Mikelek ardoa erosi du.* — 미켈이 와인을 샀어요.
- *Guk pelikula bat ikusi dugu.* — 우리는 영화 한 편을 봤어요.
- *Haiek euskara ikasi dute gaur.* — 그들은 오늘 바스크어를 공부했어요.

## 부정문

"X를 하지 않았다"라고 말하려면, **ez**를 조동사 앞에 놓습니다:

> *Ez dut bazkaldu.* — 점심을 먹지 않았어요.
>
> *Ez du egunkaria irakurri.* — 그는 신문을 읽지 않았어요.
>
> *Ez dugu ardorik edan.* — 우리는 와인을 마시지 않았어요. (*ardorik*에 주목하세요: 부정문에서는 목적어에 보통 부분격 **-rik**이 붙습니다.)

## 짧은 대화

> *— Zer afaldu duzu gaur, Maialen?*
>
> *— Entsalada eta arraina jan dut, eta postrerako jogurta hartu dut. Eta zuk?*
>
> *— Nik tortilla egin dut, baina ez dut postrerik jan.*

> **요약:** 행동에 명시적이거나 암시적인 목적어(무언가를 먹다, 무언가를 보다, 무언가를 하다)가 있다면, 조동사는 **dut** (및 그 활용형)입니다. 이 동사-조동사 쌍을 외우면 나머지는 저절로 해결됩니다.
