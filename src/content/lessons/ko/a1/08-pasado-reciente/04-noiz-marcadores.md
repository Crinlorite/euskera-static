무슨 일이 있었는지 잘 이야기하려면 **언제** 일어났는지 말해야 합니다. 이번 과에서는 최근 과거 시제와 함께 쓰여 행동이 일어난 시점을 명확히 해주는 시간 표현들을 배웁니다.

## 기본 시간 표현

| 바스크어 | 한국어 |
|---|---|
| *gaur* | 오늘 |
| *atzo* | 어제 |
| *bihar* | 내일 |
| *etzi* | 모레 |
| *orain* | 지금 |
| *oraintxe* | 바로 지금 |
| *lehen* | 전에 |
| *gero* | 나중에, 후에 |

> 눈치채셨겠지만, *atzo*(어제)와 *bihar*(내일)는 매우 짧은 단어라 한 번에 외울 수 있습니다. *Etzi*(모레)는 스페인어에는 없는 한 단어 표현입니다. 바스크어가 주는 작은 선물이죠.

## 하루의 시간대와 결합하기

시간 표현은 이전 단원에서 배운 *goizean*, *arratsaldean*, *gauean* 등과 결합할 수 있습니다. 공식은 다음과 같습니다: **시간 표현 + 하루의 시간대**.

| 바스크어 | 한국어 |
|---|---|
| *gaur goizean* | 오늘 아침에 |
| *gaur eguerdian* | 오늘 정오에 |
| *gaur arratsaldean* | 오늘 오후에 |
| *gaur gauean* | 오늘 밤에 |
| *atzo goizean* | 어제 아침에 |
| *atzo arratsaldean* | 어제 오후에 |
| *atzo gauean* | 어젯밤에 |
| *bihar goizean* | 내일 아침에 |

> **주의:** *gaur gauean*은 '오늘 밤'(다가올 밤 또는 현재의 밤)이고, *atzo gauean*은 '어젯밤'입니다. 바스크어는 이 둘을 매우 명확하게 구분합니다.

## 빈도와 횟수

| 바스크어 | 한국어 |
|---|---|
| *behin* | 한 번 |
| *bi aldiz* | 두 번 |
| *hiru aldiz* | 세 번 |
| *askotan* | 자주, 여러 번 |
| *batzuetan* | 가끔, 때때로 |
| *inoiz ez* | 절대 ~않다, 결코 |
| *gaur goizetik* | 오늘 아침부터 |
| *aste honetan* | 이번 주에 |
| *hilabete honetan* | 이번 달에 |

## 최근 과거 시제와 시간 표현을 사용한 문장

> *Gaur goizean lanera joan naiz autoz.* — 오늘 아침에 차로 출근했어요.
>
> *Gaur arratsaldean Mikelekin egon naiz.* — 오늘 오후에 Mikel과 함께 있었어요.
>
> *Gaur oso berandu esnatu naiz.* — 오늘 아주 늦게 일어났어요.
>
> *Gaur eguerdian etxean bazkaldu dut.* — 오늘 정오에 집에서 점심을 먹었어요.
>
> *Aste honetan bi aldiz egon naiz zinean.* — 이번 주에 영화관에 두 번 갔어요.

## 문장 순서

바스크어에서 시간 표현이 있는 문장의 일반적인 어순은 다음과 같습니다:

> **언제 + 어디서 + 무엇을 + 동사**

> **Gaur goizean** + **euskaltegian** + **euskara** + **ikasi dut**. — 오늘 아침에 euskaltegi에서 바스크어를 공부했어요.

이것이 유일한 순서는 아닙니다. 바스크어에서는 강조하고 싶은 요소를 앞으로 옮길 수 있습니다. 하지만 이 순서를 따르면 틀릴 일이 없습니다.

## 짧은 대화

> *— Eta gaur zer egin duzu, Maialen?*
>
> *— **Gaur goizean** lanera joan naiz oinez. **Eguerdian** lagunekin bazkaldu dut tabernan. **Arratsaldean** etxera bueltatu naiz eta liburua irakurri dut. **Gauean** ez dut afaldu, asko jan baitut bazkarian.*

> **참고:** *gaur*는 오늘 하루 전체를 의미합니다. 더 구체적으로 말하고 싶다면 시간대(*gaur goizean*, *gaur arratsaldean*)를 덧붙이세요. 일상 대화에서 *Zer egin duzu gaur?*는 '오늘 대체로 뭘 했니?'라는 의미로 이해됩니다.
