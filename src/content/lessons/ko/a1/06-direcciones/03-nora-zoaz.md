**NORA 격**(*향격*이라고도 함)은 움직임의 **목적지**, 즉 어디로 가는지를 나타냅니다. 스페인어에서는 보통 전치사 **"a"**로 번역됩니다("voy *a* casa", "*a* Bilbao", "*al* parque").

## 질문: Nora?

| 질문 | 스페인어 |
|---|---|
| ***Nora* zoaz?** | 어디로 가세요? |
| ***Nora* doa?** | 어디로 가요? |
| ***Nora* goaz?** | 우리 어디로 가요? |
| ***Nora* doaz?** | 어디로 가나요? |

## 접미사: -ra

답변하려면 목적지 장소에 **`-ra`**를 붙입니다. 패턴은 단어가 어떻게 끝나는지에 따라 달라집니다:

| 장소의 어미 | 패턴 | 예시 |
|---|---|---|
| -a (고유어, *eskola*) | + ra | eskola → **eskolara** |
| 마지막 -a가 아닌 모음 (*Bilbo*, *etxe*) | + ra | etxe → **etxera**, Bilbo → **Bilbora** |
| 자음 (*Madril*, *Gasteiz*) | + era | Madril → **Madrilera**, Gasteiz → **Gasteizera** |

## 예시 표

| 장소 | -ra 형태 | 예문 |
|---|---|---|
| etxe (집) | **etxera** | *Etxera noa.* — 집에 갑니다. |
| eskola | **eskolara** | *Eskolara doaz.* — 학교에 갑니다. |
| euskaltegi | **euskaltegira** | *Euskaltegira goaz.* — euskaltegi에 갑니다. |
| taberna | **tabernara** | *Tabernara zoaz?* — 술집에 가세요? |
| lan (일) | **lanera** | *Lanera nator.* — 일하러 옵니다. (자음 뒤에는 마찬가지로 -era) |
| Bilbo | **Bilbora** | *Bilbora doa.* — 빌바오에 갑니다. |
| Donostia | **Donostiara** | *Donostiara goaz asteburuan.* — 주말에 도노스티아에 갑니다. |
| Madril | **Madrilera** | *Madrilera doaz.* — 마드리드에 갑니다. |
| mendi (산) | **mendira** | *Mendira goaz larunbatean.* — 토요일에 산에 갑니다. |

> **미니 팁:** *non* → *nora*는 *kale-an* → *kale-ra*와 같은 패턴을 따릅니다. *Bilbon*(빌바오에서)을 만들 줄 안다면, *Bilbora*(빌바오로)도 만들 수 있습니다: *-n*을 *-ra*로 바꾸면 됩니다. *Madrilen*을 만들 줄 안다면, *Madrilera*도 만들 수 있습니다.

## Zertara? — "무엇을 하러?"

**무엇을** (어떤 목적으로) 하러 가는지 물어볼 때는 **Zertara zoaz?**를 사용하고, 동사 + 접미사 **`-tzera`**로 대답합니다:

| 질문 | 답변 |
|---|---|
| *Zertara zoaz tabernara?* | *Kafea hartzera.* — 커피 마시러. |
| *Zertara doa Kepa supermerkatura?* | *Erostera.* — 사러. |
| *Zertara goaz mendira?* | *Ibiltzera.* — 걸으러. |
| *Zertara doaz hondartzara?* | *Igeri egitera.* — 수영하러. |

> **패턴:** *(동사 분사형) + -t(z)era*: *erosi → erostera*, *jan → jatera*, *ikasi → ikastera*, *ikusi → ikustera*, *bisitatu → bisitatzera*. 기본적으로 스페인어의 "a + 동사원형"과 같습니다.

## 짧은 대화

> — *Nora zoaz, Maialen?* — 마이알렌, 어디 가니?
>
> — *Euskaltegira noa.* — euskaltegi에 가.
>
> — *Eta zertara?* — 뭐 하러?
>
> — *Klasera, noski! Euskara ikastera.* — 수업 들으러, 당연하지! 바스크어 배우러.
>
> — *Eta gero?* — 그러고 나서는?
>
> — *Tabernara goaz lagunekin pote bat hartzera.* — 친구들이랑 뭐 마시러 술집에 가.

## 방향 부사

지시사도 NORA 형태가 있습니다:

| NON (처격) | NORA (방향) | 의미 |
|---|---|---|
| hemen | **hona** | 이쪽으로 |
| hor | **horra** | 그쪽으로 |
| han | **hara** | 저쪽으로 |

- **Hona zatoz?** — 이쪽으로 오니?
- **Hara doaz.** — 저쪽으로 갑니다.

> **중요한 점:** 처음에는 많은 사람들이 헷갈려 합니다: *etxean*(집에서) ≠ *etxera*(집으로) ≠ *etxetik*(집에서부터, 04과). 세 단어 모두 "집"에 대해 이야기하기 때문에 비슷해 보이지만, 정보는 완전히 다릅니다. 기억해 두세요: **NON = -an (있다)**, **NORA = -ra (가다)**, **NONDIK = -tik (오다, 4과)**.
