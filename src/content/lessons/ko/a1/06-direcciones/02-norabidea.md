누군가 길을 묻거나, 혹은 길을 잃어 직접 물어봐야 할 때 필요한 몇 가지 명령형 동사와 방향 부사들이 있습니다. 이번 과에서는 필수 표현들을 모아 보았습니다.

## 기본 명령형

바스크어에서 이동 동사의 긍정 명령형은 매우 직설적입니다:

| 형태 | 기본 동사 | 의미 |
|---|---|---|
| **Jo** | jo | 치다 / 향하다 (jo ezkerrera = 왼쪽으로 돌다) |
| **Segi** / **Jarraitu** | segitu / jarraitu | 계속 가다, 계속하다 |
| **Hartu** | hartu | 가다, 잡다 (hartu kale hau = 이 길로 가다) |
| **Igo** | igo | 올라가다 |
| **Jaitsi** | jaitsi | 내려가다 |
| **Sartu** | sartu | 들어가다 |
| **Irten** | irten | 나가다 |
| **Zeharkatu** | zeharkatu | 건너다 |
| **Iritsi** / **heldu** | iritsi / heldu | 도착하다 (… arte = "...까지") |

> *Jo*는 문자적으로 '치다'를 의미하지만, '...쪽으로 향하다'라는 비유적인 의미로 사용됩니다: **jo ezkerrera** = "왼쪽으로 가다".

## 방향 부사 및 관련 표현

| 바스크어 | 한국어 |
|---|---|
| *ezkerra* | 왼쪽 |
| *eskuina* | 오른쪽 |
| *aurrera* | 앞으로 |
| *atzera* | 뒤로 |
| *zuzen* | 똑바로, 직진 |
| *gora* | 위로 |
| *behera* | 아래로 |

> 참고: **...쪽으로의 방향**을 나타낼 때는 접미사 `-ra`를 사용합니다 (03과에서 자세히 배울 예정입니다): *ezkerre-ra* (왼쪽으로), *aurre-ra* (앞으로), *atze-ra* (뒤로). *gora*, *behera*도 마찬가지입니다.

## 대표적인 장소/지형지물

| 바스크어 | 한국어 |
|---|---|
| *semaforoa* | 신호등 |
| *bidegurutzea* | 교차로, 사거리 |
| *zebrabidea* | 횡단보도 |
| *biribilgunea* / *errotonda* | 로터리 |
| *aldapa* | 언덕길 |
| *eskailerak* | 계단 |
| *zubia* | 다리 |
| *errepidea* | 도로 |
| *kalea* | 길, 거리 |

## 예문

- **Jo ezkerrera bidegurutzean.** — 교차로에서 좌회전하세요.
- **Segi aurrera semaforora arte.** — 신호등까지 직진하세요.
- **Zeharkatu zebrabidea.** — 횡단보도를 건너세요.
- **Igo eskailerak eta sartu eraikinean.** — 계단을 올라가서 건물로 들어가세요.
- **Jaitsi aldapa, eta gero jo eskuinera.** — 언덕길을 내려가서 오른쪽으로 도세요.
- **Egin atzera; gehiegi joan zara.** — 뒤로 돌아가세요. 너무 많이 오셨어요.

## 길 묻고 답하기

> — *Barkatu, **non dago** udaletxea?* — 실례합니다, 시청이 어디에 있나요?
>
> — ***Segi aurrera** semaforora arte. Han **jo eskuinera** eta **zeharkatu** plaza. Udaletxea elizaren ondoan dago.* — 신호등까지 직진하세요. 거기서 우회전해서 광장을 건너세요. 시청은 교회 옆에 있습니다.
>
> — *Eta gertu **dago**?* — 가까운가요?
>
> — *Bai, oso gertu. Bost minutu oinez.* — 네, 아주 가까워요. 걸어서 5분 거리입니다.

> **팁:** 많은 길 안내 표현은 명령형 (*jo*, *segi*, *zeharkatu*) + 접미사가 붙은 장소 (*ezkerrera*, *semaforora*, *zebrabidea*)의 고정된 패턴을 따릅니다. 이 패턴을 기억하면 여러 조각을 조합하여 긴 안내문을 만들 수 있습니다.
