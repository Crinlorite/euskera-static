이번 단원을 마무리하기 위해 마지막 한 조각이 남았습니다: **어떻게 이동하는지**에 대한 표현입니다. 스페인어에서는 "en + 교통수단"("en coche", "en autobús")을 사용합니다. 바스크어에서는 **`-z`** 접미사(*도구격*)를 사용하는데, 교통수단에 붙이며 놀랍게도 "발"을 의미하는 단어에도 붙습니다.

## 질문

| 질문 | 스페인어 |
|---|---|
| ***Nola* zoaz?** | 어떻게 가니? |
| ***Zerez* zoaz?** | 무엇을 타고 가니? |
| ***Nola* doa Iruñera?** | 팜플로나에 어떻게 가나요? |

*Nola*와 *Zerez* 두 가지 형태 모두 유효하며 자주 쓰입니다. *Nola*는 더 일반적이고, *zerez*는 "무슨 수단으로"라는 의미를 직접적으로 내포합니다.

## 교통수단

| 수단 | -z 형태 | 스페인어 |
|---|---|---|
| oin (발) | **oinez** | 걸어서 |
| kotxe / auto | **kotxez** / **autoz** | 차로 |
| autobus | **autobusez** | 버스로 |
| tren | **trenez** | 기차로 |
| metro | **metroz** | 지하철로 |
| taxi | **taxiz** | 택시로 |
| bizikleta | **bizikletaz** | 자전거로 |
| motor | **motorrez** | 오토바이로 |
| hegazkin | **hegazkinez** | 비행기로 |
| itsasontzi | **itsasontziz** | 배로 |
| furgoneta | **furgonetaz** | 승합차로 |
| zaldi (말) | **zaldiz** | 말을 타고 |

> 접미사는 모음 뒤에서는 **`-z`**, 자음 뒤에서는 **`-ez`**입니다 (*autobus → autobusez*). 실제로는 거의 모든 교통수단 명칭이 모음으로 끝나므로, 기본 공식은 **교통수단 + z**입니다.

## 전체 예문

- **Oinez noa lanera.** — 직장에 걸어서 갑니다.
- **Iruñera trenez goaz.** — 팜플로나에 기차로 갑니다.
- **Bilbora hegazkinez doaz.** — 빌바오에 비행기로 갑니다.
- **Eskolara bizikletaz dator alaba.** — 딸이 학교에 자전거를 타고 옵니다.
- **Mendira oinez igotzen gara.** — 산에 걸어서 올라갑니다.

## NONDIK + NORA + NOLA 조합하기

일반적인 여행 문장은 보통 **어디에서 + 어디로 + 어떻게**라는 세 부분으로 구성됩니다.

- **Iruñetik Donostiara autobusez doa.** — 팜플로나에서 도노스티아까지 버스로 갑니다.
- **Bilbotik Madrilera trenez gatoz.** — 빌바오에서 마드리드까지 기차로 옵니다.
- **Etxetik euskaltegira oinez noa.** — 집에서 바스크어 학원까지 걸어서 갑니다.

## 짧은 대화

> — *Aupa! Bihar Bilbora **noa**.* — 안녕! 내일 빌바오에 가.
>
> — *Eta **nola** zoaz?* — 그럼 어떻게 가?
>
> — *Trenez. Oso erosoa da.* — 기차로. 아주 편해.
>
> — *Ni autoz noa beti, baina garestia da gasolina.* — 나는 항상 차로 가는데, 휘발유가 비싸.

## "oinez"에 대하여

언뜻 보기에 *oinez*는 별개의 경우("발로")처럼 보이지만, 실제로는 나머지 단어들과 정확히 같은 패턴입니다: *oin*(발) + *ez*(도구격 접미사). 바스크어에서는 "걸어서 가다"를 다른 교통수단과 똑같이 취급합니다. 즉, 이동시켜주는 수단을 사용하는 것이죠.

## NORA / NONDIK / NOLA 블록 최종 복습

| 질문 | 접미사 | 대표 질문 | 대표 답변 |
|---|---|---|---|
| **Nora?** | -ra | 어디로? | *Bilbo**ra** noa.* |
| **Nondik?** | -tik | 어디에서? | *Bilbo**tik** nator.* |
| **Nola? / Zerez?** | -z | 어떻게? / 무엇으로? | *Tren**ez** noa.* |

> **팁:** 이 세 접미사를 함께 사용하면 거의 모든 여행 문장을 만들 수 있습니다. 예를 들어, *Bilbotik Donostiara autobusez goaz, lagun bat bisitatzera*. — "우리는 친구를 만나러 빌바오에서 도노스티아까지 버스로 갑니다." 이 세 접미사와 *joan*, *etorri*의 통합형 동사를 마스터하면 일상생활의 모든 이동에 대해 이야기할 수 있습니다.
