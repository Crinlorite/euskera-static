이번 과에서는 **etxeko lanak**(집안일)에 대해 말할 때 필요한 기본 동사들을 배웁니다. 바스크어에서 동사는 보통 **분사형**(`-tu`, `-i`, `-n`)으로 제시되는데, 이것이 '사전형'입니다: *garbitu*, *prestatu*, *jaso*…

## 주요 동사

| 바스크어 | 한국어 |
|---|---|
| *garbitu* | 청소하다 |
| *prestatu* | 준비하다 |
| *jaso* | 정리하다 |
| *jantzi* | 입다 / 놓다 |
| *atera* | 꺼내다 |
| *zabaldu* | 널다 / 열다 |
| *lisatu* | 다림질하다 |
| *paseatu* | 산책시키다 |
| *erosi* | 사다 |

## 일반적인 집안일

| 집안일 | 표현 |
|---|---|
| 침대 정리하기 | *ohea jantzi* |
| 설거지하기 | *ontziak garbitu* / *harrikoa egin* |
| 진공청소기 돌리기 | *xurgagailua pasa* |
| 빨래 널기 | *arropa zabaldu* |
| 옷 다림질하기 | *arropa lisatu* |
| 화장실 청소하기 | *komuna garbitu* |
| 쓰레기 버리기 | *zaborra atera* |
| 음식 준비하기 | *bazkaria prestatu* |
| 장보기 | *erosketak egin* |
| 개 산책시키기 | *txakurra paseatu* |

## 사전형에서 현재 습관형으로

어떤 행동이 습관적으로(매일, 매주 등) 반복될 때, 동사는 `-tzen` 형태에 *ukan*에서 이미 배운 조동사 **dut/duzu/du…**를 더한 형태로 바뀝니다:

| 인칭 | 예시 | 한국어 |
|---|---|---|
| Nik | *Nik etxea **garbitzen dut**.* | 나는 집을 청소해요. |
| Zuk | *Zuk arropa **lisatzen duzu**.* | 너는 옷을 다림질해. |
| Berak | *Aitak bazkaria **prestatzen du**.* | 아버지는 음식을 준비해요. |
| Guk | *Guk erosketak **egiten ditugu**.* | 우리는 장을 봐요. |

> 이번 과에서는 동사 변화를 완벽히 익힐 필요는 없습니다. 일과에 대해 말할 때는 **`-tzen` + dut/du** 패턴만 기억하세요.

## 빈도

어떤 일을 얼마나 자주 하는지 말하려면:

- **egunero** — 매일
- **astean behin** — 일주일에 한 번
- **astean bitan / hirutan** — 일주일에 두 번 / 세 번
- **noizean behin** — 가끔
- **inoiz ez** — 절대 안 함

> *Nire etxean nik **astean behin** lisatzen dut, baina **egunero** garbitzen dut sukaldea.* — 우리 집에서 나는 일주일에 한 번 다림질하지만, 부엌은 매일 청소해요.

## 누가 무엇을 하는지 묻기

- **Nork garbitzen ditu ontziak?** — 누가 설거지를 하나요?
- **Nor arduratzen da arropaz?** — 누가 빨래를 담당하나요?
- **Zuri gustatzen zaizu sukaldatzea?** — 요리하는 것을 좋아하나요?

> **문화 노트:** 가정 내 가사 분담에 대한 설문조사는 바스크어 학원(euskaltegi) 교재의 단골 주제입니다. 그럴 만한 이유가 있죠. 친구나 가족과의 실제 대화에서 매우 유용한 어휘이기 때문입니다.
