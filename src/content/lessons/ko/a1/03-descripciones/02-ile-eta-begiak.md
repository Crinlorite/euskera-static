바스크어에서 머리카락과 눈을 묘사할 때는 스페인어("soy moreno")에서처럼 **izan**("~이다")을 사용하지 않고, **ukan**("가지다")을 사용합니다: *나는 검은 머리카락을 가졌어*, *나는 파란 눈을 가졌어*.

## 머리카락: ile

"머리카락"을 뜻하는 단어는 **ile**입니다 (관사가 붙으면: *ilea*). 형용사는 뒤에 오며, 마지막 형용사에만 `-a` 표시가 붙습니다:

| Euskera | 한국어 |
|---|---|
| *ile beltza* | 검은 머리 |
| *ile horia* | 금발 머리 |
| *ile zuria* | 흰 머리 / 백발 |
| *ile gorria* | 빨간 머리 |
| *ile urdina* | 회색 머리 |
| *ile motza* | 짧은 머리 |
| *ile luzea* | 긴 머리 |
| *ile lisoa* | 직모 |
| *ile kizkurra* | 곱슬머리 |

> 바스크어에서 머리카락은 스페인어에서처럼 **단수**로 취급됩니다. 그래서 (*ditut* / *ditu*가 아닌) *dut* / *du*를 사용합니다.

- *Ile beltza eta luzea **dut**.* — 저는 검고 긴 머리카락을 가졌어요.
- *Maialenek ile kizkurra **du**.* — Maialen은 곱슬머리를 가졌어요.

## 눈: begiak

머리카락과 달리, "눈"은 **복수**(*begiak*)입니다. 따라서 형용사도 복수형(`-ak`)을 사용하고 **ditut / ditu**를 사용합니다:

| Euskera | 한국어 |
|---|---|
| *begi urdinak* | 파란 눈 |
| *begi marroiak* | 갈색 눈 |
| *begi berdeak* | 녹색 눈 |
| *begi beltzak* | 검은 눈 |
| *begi argiak* | 밝은 색 눈 |
| *begi ilunak* | 어두운 색 눈 |

- *Begi urdinak **ditut**.* — 저는 파란 눈을 가졌어요.
- *Mikelek begi marroiak **ditu**.* — Mikel은 갈색 눈을 가졌어요.

## 기타 특징: 접미사 -dun

"X를 가진" 또는 "X와 함께"라고 말하기 위해, 바스크어에는 매우 생산적인 접미사인 **-duna**(단수) / **-dunak**(복수)가 있습니다. 명사에 붙이면 그 사람은 "안경 쓴 사람", "수염 난 사람" 등이 됩니다...

| Euskera | 한국어 |
|---|---|
| *betaurrekoduna* | 안경을 쓴 / 안경 쓴 사람 |
| *bizarduna* | 수염이 있는 |
| *biboteduna* | 콧수염이 있는 |
| *burusoila* | 대머리 (글자 그대로는 "벗겨진 머리") |

이것들은 형용사처럼 특성을 묘사하기 때문에 **izan**과 함께 사용됩니다:

- *Hura biboteduna da.* — 그는 콧수염이 있어요.
- *Nire aitona burusoila da.* — 제 할아버지는 대머리예요.

## 모두 합치기

일반적인 인물 묘사는 여러 구조를 혼합합니다:

> *Maialen txikia eta argala da. Ile gorria eta kizkurra du. Begi berdeak ditu. Betaurrekoduna da.*
>
> Maialen은 키가 작고 말랐어요. 빨간 곱슬머리를 가졌어요. 녹색 눈을 가졌어요. 안경을 썼어요.

어떻게 나뉘는지 보세요: 일반적인 특성에는 **izan** (*txikia da*), 머리카락/눈에는 **ukan** (*ile … du*, *begi … ditu*), 그리고 액세서리에는 다시 **izan**과 함께 *-dun*-a를 사용합니다.
