이번 과에서는 이 단원의 모든 내용을 종합합니다: 장소 어휘, 처격 `-(e)an`, 공간 위치(*aurrean*, *ondoan*…), 그리고 **존재 / 위치**(*badago* / *dago*)의 구분을 배웁니다. 이 과를 마치면 실제 문장으로 여러분의 동네나 마을을 묘사할 수 있게 될 것입니다.

## 묘사의 구조

동네나 마을을 묘사할 때는 보통 다음 순서를 따릅니다:

1. 장소가 **어떤지** (크기, 특징): *Nire auzoa txikia eta polita da.*
2. **무엇이 있고** 없는지: *Auzoan badago liburutegia, baina ez dago zinemarik.*
3. 중요한 장소들이 **어디에 있는지**: *Liburutegia plazaren ondoan dago.*
4. **당신이 어디에** 누구와 사는지: *Ni Maialenen ondoan bizi naiz, etxe txiki batean.*

## 묘사 어휘

| 바스크어 | 한국어 |
|---|---|
| *handi* | 큰 |
| *txiki* | 작은 |
| *ertain* | 중간 크기의 |
| *polit* | 예쁜 |
| *itsusi* | 못생긴 |
| *zaharra* | 오래된 |
| *berria* | 새로운 |
| *lasai* | 조용한 |
| *jendetsu* | 사람이 많은 |
| *modernoa* | 현대적인 |
| *erdigunean* | 중심가에 |
| *kanpoaldean* | 외곽에 |

> 기억하세요: 바스크어에서 형용사는 **명사 뒤에** 오고 정관사 `-a`가 붙습니다. *Auzo + handi + a* → *auzo handia* ("큰 동네"); *auzo + txiki + a* → *auzo txikia*.

## 모두 합치기: 모범 예시

> *Ni Iruñean bizi naiz, Txantrea auzoan. Auzoa ez da oso handia, baina lasaia eta polita da. Auzoan badago supermerkatu txiki bat, bi taberna eta okindegi bat. Eskola plazaren ondoan dago, eta liburutegia eskolaren atzean. Parkea handia da, eta umeentzat oso ona. Auzoan ez dago zinemarik, baina hori ez da arazoa: zinema erdigunean dago, eta gertu dago. Nire etxea bigarren solairuan dago, kale lasai batean.*

자유 번역:

> 저는 팜플로나의 Txantrea 동네에 삽니다. 동네는 아주 크지는 않지만, 조용하고 예쁩니다. 동네에는 작은 슈퍼마켓 하나, 술집 두 곳, 빵집 한 곳이 있습니다. 학교는 광장 옆에 있고, 도서관은 학교 뒤에 있습니다. 공원은 크고, 아이들에게 아주 좋습니다. 동네에는 영화관이 없지만 문제없습니다. 영화관은 중심가에 있고 가깝기 때문입니다. 저희 집은 조용한 거리에 있는 건물의 2층입니다.

## 받게 될 질문들

| 질문 | 답변 유형 |
|---|---|
| ***Non bizi zara?*** | 장소 + 처격: *X-(e)an bizi naiz.* |
| ***Nolakoa da zure auzoa?*** | 형용사: *Polita da, txikia da…* |
| ***Zer dago zure auzoan?*** | 존재: *Badago…, badaude…* |
| ***Ba al dago tabernarik?*** | 예/아니요: *Bai, badago / Ez, ez dago tabernarik.* |
| ***Non dago liburutegia?*** | 위치: *Plazaren ondoan dago.* |

## 여러분 차례

친구/파트너가 여러분의 동네를 모른다고 상상하고 묘사해 보세요:

1. 이름이 무엇이고 어디에 있는지.
2. 큰지 작은지, 오래되었는지 현대적인지.
3. **있는** 장소 세 곳 (*badago / badaude* 사용).
4. **없는** 것 세 가지 (*ez dago … rik* 사용).
5. 집이 구체적으로 어디에 있는지 (거리, 층, 무엇의 옆).

> **문화 노트:** 많은 바스크 동네와 마을에서는 **frontoia**(프론톤 경기장)와 **eliza**(교회)를 기준으로 삼습니다. 이 둘은 보통 서로 옆에 있으며 중심 광장 근처에 있습니다. 여러분의 동네에 광장, 프론톤 경기장 또는 교회가 있다면, 누군가에게 길을 알려줄 때 가장 좋은 기준점이 될 것입니다.
