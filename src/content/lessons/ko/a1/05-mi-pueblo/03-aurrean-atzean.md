"X에 있다"라고 말하는 법을 배웠으니, 다음 단계는 **정확히 어디에** 있는지, 즉 위, 아래, 옆, 뒤 등을 표현하는 것입니다. 바스크어에서는 이러한 위치를 항상 **기준 장소 + 위치** 패턴으로 만듭니다.

## 기본 위치 표현

| 바스크어 | 한국어 |
|---|---|
| *aurrean* | 앞에 |
| *atzean* | 뒤에 |
| *ondoan* | 옆에 |
| *gainean* | 위에 |
| *azpian* | 아래에 |
| *artean* | 사이에 |
| *ezkerrean* | 왼쪽에 |
| *eskuinean* | 오른쪽에 |
| *barruan* | 안에 |
| *kanpoan* | 밖에 |
| *erdian* | 가운데에, 중앙에 |

## 만드는 법: -(r)en + 위치

기본 공식은 **(기준)-(r)en + 위치**입니다. 기준이 되는 명사에는 소유격 `-(r)en`이 붙습니다 (한국어의 "~의"에 해당합니다):

| 바스크어 | 한국어 (직역) |
|---|---|
| **mahaiaren gainean** | 책상 위에 (직역: "책상의, 위에") |
| **etxearen aurrean** | 집 앞에 |
| **elizaren atzean** | 교회 뒤에 |
| **parkearen ondoan** | 공원 옆에 |
| **kutxaren barruan** | 상자 안에 |
| **bi mendien artean** | 두 산 사이에 |

패턴: 기준이 먼저 오고, **그 다음** 위치가 옵니다. 스페인어와는 어순이 정반대입니다.

## 전체 문장 예시

- **Liburua mahaiaren gainean dago.** — 책이 책상 위에 있습니다.
- **Katua aulkiaren azpian dago.** — 고양이가 의자 아래에 있습니다.
- **Eliza plazaren erdian dago.** — 교회가 광장 중앙에 있습니다.
- **Botika eskolaren ondoan dago.** — 약국이 학교 옆에 있습니다.
- **Ni Maiteren eta Anaren artean nago.** — 저는 Maite와 Ana 사이에 있습니다.

## 장소 부사: hemen / hor / han

장소를 간단히 가리키는 세 가지 부사가 있습니다 — 스페인어와 달리 **세 단계의 거리**를 구분하니 주의하세요:

| 바스크어 | 한국어 | 언제 사용하나요? |
|---|---|---|
| *hemen* | 여기 | 화자에게 가까울 때 |
| *hor* | 거기 | 청자에게 가까울 때 |
| *han* | 저기 | 두 사람 모두에게서 멀 때 |

> 이 세 부사는 지시사 *hau / hori / hura* 및 장소 격 형태인 *honetan / horretan / hartan*("이것에 / 그것에 / 저것에")과 관련이 있습니다.

간단한 예시:

- **Hemen** taberna bat dago. — 여기에 술집이 하나 있습니다.
- **Hor** parkea dago. — 거기에 공원이 있습니다.
- **Han** dago euskaltegia. — 바스크어 학교(*euskaltegi*)는 저기에 있습니다.

## 짧은 대화: 숨바꼭질

> — *Pilota mahaiaren azpian dago?* — 공이 책상 아래에 있니?
>
> — *Ez, pilota ez dago mahaiaren azpian.* — 아니, 공은 책상 아래에 없어.
>
> — *Aulkiaren atzean dago?* — 의자 뒤에 있니?
>
> — *Bai, hor dago!* — 응, 거기 있어!

> **팁:** 모든 위치 표현 단어에는 이미 접미사 `-an`이 포함되어 있습니다(*aurr-ean*, *atz-ean*, *azp-ian*...). 따라서 다른 것을 추가할 필요가 없습니다.
