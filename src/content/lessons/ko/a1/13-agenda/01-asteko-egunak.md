계획과 일정에 대해 이야기하기 전에, 요일을 복습하고 일상 활동과 연관 짓는 법을 배워봅시다.

## 일곱 요일

| 바스크어 | 스페인어 | 힌트 |
|---|---|---|
| *astelehena* | 월요일 | aste + lehen = "주의 첫 번째 날" |
| *asteartea* | 화요일 | aste + arte = "주중" |
| *asteazkena* | 수요일 | aste + azken = "(역사적으로) 주중의 마지막 날" |
| *osteguna* | 목요일 | egun = 날 |
| *ostirala* | 금요일 | *osteguna*와 함께 *ortzi/osti-* (하늘)라는 어근을 공유합니다 |
| *larunbata* | 토요일 | larun + bata |
| *igandea* | 일요일 | 역사적인 공휴일 |

> **암기 팁:** **aste**(주)라는 단어는 평일의 시작 부분에 나타납니다. *Astelehen-, astear-, asteazken-*은 거의 주의 시작, 중간, 끝을 소리 내어 세는 것과 같습니다.

## "월요일에"라고 말하기 — 접미사 `-(e)an`

어떤 날에 일이 일어나는 것을 나타내려면 요일에 `-(e)an`을 붙입니다:

| 요일 | "~요일에" |
|---|---|
| astelehena | astelehen**ean** |
| asteartea | astearte**an** |
| asteazkena | asteazken**ean** |
| osteguna | ostegun**ean** |
| ostirala | ostirale**an** |
| larunbata | larunbat**ean** |
| igandea | igande**an** |

- *Astelehenean lan egiten dut.* — 월요일에 일해요.
- *Larunbatean afaltzera joango gara.* — 토요일에 저녁 먹으러 갈 거예요.

## "매주 ~요일에"라고 말하기 — 접미사 `-ero`

규칙적인 빈도를 나타낼 때:

- *astelehenero* — 매주 월요일
- *larunbatero* — 매주 토요일
- *egunero* — 매일
- *astero* — 매주
- *astebururo* — 매 주말

## 요일 + 활동: 예시

| 바스크어 | 한국어 |
|---|---|
| *Astelehenean kiroldegira noa.* | 월요일에 체육관에 가요. |
| *Asteartean euskara klasea dut.* | 화요일에 바스크어 수업이 있어요. |
| *Ostiralean parranda egiten dugu.* | 금요일에 파티하러 나가요. |
| *Larunbatean familiaren etxera joango naiz.* | 토요일에 가족 집에 갈 거예요. |
| *Igandean lasai gelditzen naiz etxean.* | 일요일에 집에서 조용히 쉬어요. |

## Asteburua — 주말

`Asteburua`(주말)는 아주 유용한 단어입니다:

- *Asteburuan zer egingo duzu?* — 주말에 뭐 할 거예요?
- *Asteburu honetan mendira joango naiz.* — 이번 주말에 등산 갈 거예요.
- *Asteburu pasa egitea gustatzen zait.* — 주말에 짧은 여행 가는 것을 좋아해요.

> **문화 노트:** *igandea*와 함께 *jaieguna*(공휴일)라는 단어도 자주 보게 될 겁니다: *igandeak eta jaiegunak*이라는 표현은 버스 시간표, 상점, 시청 게시판 등에서 흔히 볼 수 있습니다.
