이번 과에서는 자주 헷갈리는 두 가지 질문, 즉 **어디 출신인지**(출신)와 **어디에 사는지**(현재 거주지)를 다룹니다. 바스크어에서는 이 두 질문을 서로 다른 접미사를 사용해 만듭니다.

## 출신: Nongoa zara? → ...koa naiz

출신을 물을 때는 **Nongoa zara?**를 사용하고, 장소 + 접미사 **`-(e)ko`**로 답합니다 (관사와 함께: `-koa`):

| 장소 | 출신 |
|---|---|
| Bilbo | Bilbo**koa** naiz (저는 빌바오 출신입니다) |
| Donostia | Donostia**koa** naiz (저는 도노스티아 출신입니다) |
| Iruñea | Iruñe**koa** naiz (저는 팜플로나 출신입니다) |
| Madril | Madril**goa** naiz |
| Espainia | Espainia**koa** naiz |
| Argentina | Argentina**koa** naiz |

> 자음 뒤에서는 접미사가 철자법에 맞게 변형됩니다 (*Madril* → *Madrilgoa*). 연습하다 보면 자연스러워질 거예요.

## 거주지: Non bizi zara? → ...n bizi naiz

지금 어디에 사는지 물을 때는 **Non bizi zara?** ("어디에 사니?")를 사용하고, 장소에 장소격 접미사 **`-(e)n`**을 붙여 답합니다:

| 장소 | 거주지 |
|---|---|
| Bilbo | Bilbo**n** bizi naiz |
| Donostia | Donostia**n** bizi naiz |
| Iruñea | Iruñea**n** bizi naiz |
| Madril | Madril**en** bizi naiz |

> 고유의 `-a`로 끝나는 단어(Donostia)는 `a`를 유지합니다. 자음으로 끝나는 단어(Madril)는 `-e-`를 삽입합니다.

## 대화에서 두 가지 모두 사용하기

> — *Kaixo! Zein da zure izena?* — 안녕하세요, 이름이 뭐예요?
>
> — *Ni Maialen naiz. Eta zu?* — 저는 Maialen이에요. 당신은요?
>
> — *Egoitz naiz. **Nongoa zara?*** — 저는 Egoitz예요. 어디 출신이세요?
>
> — ***Iruñekoa naiz**, baina **Bilbon bizi naiz** orain.* — 저는 팜플로나 출신이지만, 지금은 빌바오에 살아요.

## 유용한 어휘

- **herri** — 마을
- **hiri** — 도시
- **herrialde** — 지역 / 주
- **estatu** — 국가 / 나라
- **norekin bizi zara?** — 누구와 사나요? → *Bakarrik bizi naiz* (혼자 살아요) / *Gurasoekin bizi naiz* (부모님과 함께 살아요)
