바스크어로 가격을 묻고 계산할 때 상대방의 말을 이해하려면 두 가지가 필요합니다: **Zenbat balio du?** 공식과 100까지의 숫자입니다. 바스크어의 숫자 체계는 **20진법**(20 단위로 묶음)이므로 약간의 적응이 필요합니다.

## 핵심 질문

| 바스크어 | 한국어 |
|---|---|
| *Zenbat balio du?* | 얼마예요? |
| *Zenbat da?* | 얼마예요? |
| *Zenbat dira denera?* | 전부 얼마예요? |
| *Pagatu daiteke?* | 계산할 수 있을까요? (계산서 요청) |

> **Zenbat**은 '얼마 / 몇'이라는 뜻입니다. *Zenbat urte dituzu?*('몇 살이에요?')에서 이미 보셨죠. **Balio** = '가치가 있다 / 비용이 들다'입니다.

## 20까지의 숫자 (복습)

가족 단원에서 1부터 10까지의 숫자는 이미 배웠습니다. 여기 11부터 20까지의 숫자입니다:

| 숫자 | 바스크어 |
|---|---|
| 11 | *hamaika* |
| 12 | *hamabi* (hamar + bi) |
| 13 | *hamahiru* |
| 14 | *hamalau* |
| 15 | *hamabost* |
| 16 | *hamasei* |
| 17 | *hamazazpi* |
| 18 | *hemezortzi* |
| 19 | *hemeretzi* |
| 20 | *hogei* |

> 12부터 17까지는 *hamar*('십') + 숫자로 이루어져 있습니다: *hamabi* = '십-이' = 12. *Hamaika*(11)와 *hemezortzi*/*hemeretzi*(18, 19)는 불규칙입니다.

## 십 단위: 20진법 체계

여기에 바스크어의 놀라운 점이 있습니다. 십 단위는 **20 단위로** 셉니다:

| 숫자 | 바스크어 | 논리 |
|---|---|---|
| 20 | *hogei* | 기본 |
| 30 | *hogeita hamar* | '20과 10' |
| 40 | *berrogei* | '20의 두 배' (*ber-* = 두 배) |
| 50 | *berrogeita hamar* | '20의 두 배와 10' |
| 60 | *hirurogei* | '20의 세 배' (*hiru* = 셋) |
| 70 | *hirurogeita hamar* | '20의 세 배와 10' |
| 80 | *laurogei* | '20의 네 배' |
| 90 | *laurogeita hamar* | '20의 네 배와 10' |
| 100 | *ehun* | 기본 |

> 중간 숫자들도 같은 논리를 따릅니다: 25 = *hogeita bost*('20과 5'), 67 = *hirurogeita zazpi*('20의 세 배와 7'). 처음에는 어렵지만, 바(bar)에서 가격을 보며 연습하다 보면 자연스러워질 겁니다.

## 가격 말하기

| 가격 | 바스크어 |
|---|---|
| 1 € | *euro bat* |
| 2 € | *bi euro* |
| 1,50 € | *euro bat eta berrogeita hamar* / *euro eta erdi* |
| 3 € | *hiru euro* |
| 25 € | *hogeita bost euro* |

> 숫자 뒤에 올 때 **euro**에는 `-a`가 붙지 않는다는 점에 유의하세요(*bi anaia*, '두 형제'에서처럼요). 센트 단위의 정확한 금액은 스페인어에서처럼 말합니다: *hiru euro eta berrogeita hamar zentimo*(3.50유로).

## 여러 개 구매하기

한 개 이상을 주문할 때는 *dut*/*dugu* 대신 **ditut**이나 **ditugu**를 사용해야 한다는 것을 기억하세요:

- *Bi kafe hartuko ditut.* — 커피 두 잔 마실게요.
- *Hiru ogitarteko hartuko ditugu.* — 샌드위치 세 개 먹을게요.

## 가격에 대해 말할 때 쓰는 형용사

- **garesti** — 비싼 (관사와 함께 *garestia*로도 사용)
- **merke** — 싼 (*merkea*로도 사용)
- **doan** — 무료

> *Hau oso garestia da!* — 이거 정말 비싸네요!
> *Bilbon kafea merkea da.* — 빌바오에서는 커피가 싸요.
