Euskal Herria 사회생활의 상당 부분은 **taberna**(바)에서 이루어집니다. 바스크어로 된 기본 음료와 음식을 알면 친구들과 어울리거나, 새로운 마을을 방문하거나, *poteo*를 즐기는 등 즉시 새로운 문이 열릴 것입니다. 어휘부터 시작하겠습니다.

## 커피와 그 종류

커피는 아마 가장 많이 주문하게 될 음료일 겁니다. 여러 종류가 있습니다:

| 바스크어 | 한국어 |
|---|---|
| *kafea* | 커피 (일반) |
| *kafe hutsa* | 블랙 커피 (직역: "순수한/빈 커피") |
| *kafesnea* | 카페라테 (*kafe* + *esne*에서 유래) |
| *kafe ebakia* | 코르타도 커피 (*ebaki* = "자른") |
| *kafe deskafeinatua* | 디카페인 커피 |
| *infusioa* | 인퓨전 (허브차 등) |
| *tea* | 차 (홍차, 녹차 등) |

> *Kafesne*는 글자 그대로 "커피-우유"를 의미합니다. 바스크어는 이렇게 하이픈 없이 주요 단어를 뒤에 붙여 많은 합성어를 만듭니다.

## 기타 음료

| 바스크어 | 한국어 |
|---|---|
| *ura* | 물 |
| *zumoa* | 주스 |
| *esnea* | 우유 |
| *ardoa* | 와인 |
| *ardo gorria* | 레드 와인 |
| *ardo zuria* | 화이트 와인 |
| *garagardoa* | 맥주 |
| *zuritoa* | 작은 잔 맥주 (전형적) |
| *sagardoa* | 사과주 |
| *txakolina* | 차콜리 (바스크 화이트 와인) |
| *patxarana* | 파차란 |

> 흥미로운 세 단어: **sagardo**(사과주) = *sagar*(사과) + *ardo*(와인); **garagardo**(맥주) = *garagar*(보리) + *ardo*; **txakolina**는 바스크 지방의 대표적인 가볍고 어린 화이트 와인입니다.

## 바의 기본 음식

음료와 함께 곁들일 음식입니다:

| 바스크어 | 한국어 |
|---|---|
| *ogia* | 빵 |
| *gazta* | 치즈 |
| *urdaiazpikoa* | 하몽 |
| *tortilla* | 토르티야 (감자 오믈렛) |
| *patata frijituak* | 감자튀김 |
| *gozokia* | 단 것 (일반) |
| *txokolatea* | 초콜릿 |

## 정관사 `-a`

이 단어들은 대부분 문장에서 "중립적"으로 나타날 때 끝에 **`-a`**가 붙습니다. 이는 영어의 "the"와 같은 정관사입니다.

- *Ardoa gustatzen zait.* — 나는 와인을 좋아해.
- *Ura nahi dut.* — 나는 물을 원해.

"하나"를 주문할 때는 `-a`가 사라지고 **bat**("하나")이 붙습니다:

- *Kafe **bat**, mesedez.* — 커피 한 잔 주세요.
- *Garagardo **bat**.* — 맥주 한 잔이요.

> 3과에서 이에 대해 자세히 배울 것입니다. 지금은 바 메뉴판에서 단어를 알아볼 수 있도록 `-a`가 붙은 형태를 외워두세요.
