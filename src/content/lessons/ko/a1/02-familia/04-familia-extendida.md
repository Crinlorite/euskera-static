부모, 형제, 자녀를 넘어 가족은 삼촌, 사촌, 조카, 그리고 배우자의 가족으로 확장됩니다. 여기에 가장 많이 사용되는 어휘가 있습니다.

## 삼촌과 사촌

| 바스크어 | 한국어 |
|---|---|
| *osaba* | 삼촌 |
| *izeba* | 이모/고모 |
| *lehengusu* | 사촌 (남자) |
| *lehengusina* | 사촌 (여자) |
| *iloba* | 조카 (일부 방언에서는 "손주"라는 뜻도 있음 — 문맥에 따라 결정됨) |

## 배우자의 가족

| 바스크어 | 한국어 |
|---|---|
| *aitaginarreba* | 시아버지/장인 |
| *amaginarreba* | 시어머니/장모 |
| *koinatu* | 처남/매형/시동생 |
| *koinata* | 처제/시누이/형수 |
| *errain* | 며느리 |
| *suhi* | 사위 |

## 사용 패턴

- *Nire osaba Bilbon bizi da.* — 제 삼촌은 빌바오에 살아요.
- *Bere lehengusinak hamabi urte ditu.* — 그의/그녀의 사촌(여자)은 열두 살이에요.
- *Zure koinata euskalduna da?* — 당신의 처제/시누이/형수는 바스크 사람인가요?

> 배우자의 가족을 나타내는 단어들은 종종 기존 단어들(*aita-* + *ginarreba*)을 조합하여 만들어집니다. 내부적인 논리를 외울 필요는 없으며, 사용하다 보면 자연스럽게 익숙해질 거예요.
