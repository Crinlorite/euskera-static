바스크어로 분을 말할 때는 거의 모든 상황에 쓰이는 세 가지 표현이 있습니다: **eta erdiak**(30분), **eta laurden**(15분), 그리고 **gutxi**(...분 전). 핵심은 각 요소를 어디에 놓는지 아는 것입니다.

## '...시 30분' — 특별한 경우

다른 표현들과 달리, '...시 30분'이라고 말할 때는 시간도 복수형으로 말하고, '반'을 뜻하는 단어(*erdi*) 또한 복수형(*erdiak*)으로 씁니다.

| 시간 | 바스크어 |
|---|---|
| 1:30 | **Ordu bat eta erdiak dira** |
| 2:30 | **Ordu bi eta erdiak dira** |
| 3:30 | **Hiru eta erdiak dira** |
| 4:30 | **Lau eta erdiak dira** |
| 5:30 | **Bost eta erdiak dira** |
| 7:30 | **Zazpi eta erdiak dira** |

> 주의: *eta erdiak*을 쓸 때는 시간 숫자 뒤에 **-ak를 붙이지 않습니다**(*bostak*이 아니라 *bost*). 복수 의미가 이미 *erdiak*에 들어있기 때문입니다.

## '...시 15분'과 정각이 지난 분

정각에서 몇 분이 지났을 때는 **시간-ak eta 분** 공식을 사용합니다:

| 시간 | 바스크어 |
|---|---|
| 3:05 | **Hirurak eta bost dira** |
| 4:10 | **Laurak eta hamar dira** |
| 5:15 | **Bostak eta laurden dira** |
| 6:20 | **Seiak eta hogei dira** |
| 7:25 | **Zazpiak eta hogeita bost dira** |

**Laurden**은 '4분의 1'을 의미하므로, **eta laurden**은 '그리고 15분'이라는 뜻입니다.

## '...분 전' — gutxi는 뒤에 옵니다

30분부터는 다음 정시를 기준으로 **gutxi**('...분 전')라는 단어를 써서 말합니다. 순서는 **(다음 시간)-ak + (남은 분) + gutxi**입니다.

| 시간 | 바스크어 |
|---|---|
| 6:35 | **Zazpiak hogeita bost gutxi dira** |
| 7:40 | **Zortziak hogei gutxi dira** |
| 8:45 | **Bederatziak laurden gutxi dira** |
| 9:50 | **Hamarrak hamar gutxi dira** |
| 10:55 | **Hamaikak bost gutxi dira** |

> 스페인어와 달리 바스크어에서는 **gutxi**가 분(숫자) **뒤에** 온다는 점이 흥미롭습니다. *Bederatziak laurden gutxi*는 직역하면 '아홉 시들 15분 전'이라는 의미입니다.

## 요약 표

| 개념 | 핵심 단어 | 위치 |
|---|---|---|
| '...시 30분' | *eta erdiak* | 시간 뒤; 숫자는 -ak 없이 옴 |
| '...시 15분' | *eta laurden* | -ak가 붙은 시간 뒤 |
| '...시 X분' | *eta + 숫자* | -ak가 붙은 시간 뒤 |
| '...시 15분 전' | *laurden gutxi* | -ak가 붙은 다음 시간 뒤 |
| '...시 X분 전' | *숫자 + gutxi* | -ak가 붙은 다음 시간 뒤 |

## 대화 예시

> *— Zer ordu da?*
>
> *— **Zazpiak eta laurden dira.*** (7시 15분입니다.)
>
> *— Eta orain?*
>
> *— **Zortziak laurden gutxi dira.*** (8시 15분 전입니다.)

> **문화 노트:** 많은 바스크 마을에서는 지금도 교회 종이 정각과 15분마다 시간을 알려줍니다. 잠시 멈춰서 종소리에 귀를 기울여 보세요. 말이 입에 붙기 전에 귀가 먼저 그 패턴에 익숙해질 거예요.
