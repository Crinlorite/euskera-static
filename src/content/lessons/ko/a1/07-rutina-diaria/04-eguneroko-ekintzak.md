매일 하는 일을 말하기 위해 바스크어에서는 **습관상**을 사용합니다. 동사(분사형)에 **-tzen** 또는 **-ten**을 붙이고, 그 다음에 조동사 **izan**(naiz, zara, da…) 또는 **ukan**(dut, duzu, du…)과 결합합니다.

## 규칙

| 동사 어미 | 습관상 접미사 | 예시 |
|---|---|---|
| 자음 또는 `-tu` / `-du` | **-tzen** | *esnatu* → *esnatzen* |
| `-n` | **-ten** | *jan* → *jaten*; *egin* → *egiten* |
| `-i` (불규칙) | **-tzen** 또는 **-ten** | *etorri* → *etortzen*; *ikusi* → *ikusten* |

> 동사 *jan*(먹다)은 *janten*이 아니라 *jaten*으로 바뀝니다 — 마지막 "n"이 사라집니다. *edan* → *edaten*, *egon* → *egoten*의 경우도 마찬가지입니다.

## 일상생활 동사

### NOR (조동사 **izan**: naiz, zara, da…)

이 동사들은 자동사이기 때문에 **izan**과 함께 쓰입니다 — 주어가 목적어 없이 행동을 경험합니다:

| Partizipioa | 습관상 | 의미 |
|---|---|---|
| *esnatu* | *esnatzen naiz* | 일어나다 (잠에서 깨다) |
| *jaiki* | *jaikitzen naiz* | 일어나다 (몸을 일으키다) |
| *altxatu* | *altxatzen naiz* | 일어나다 (*jaiki*의 변형) |
| *dutxatu* | *dutxatzen naiz* | 샤워하다 |
| *jantzi* | *janzten naiz* | 옷을 입다 |
| *joan* | *joaten naiz* | 가다 |
| *etorri* | *etortzen naiz* | 오다 |
| *oheratu* | *oheratzen naiz* | 잠자리에 들다 |
| *lokartu* | *lokartzen naiz* | 잠들다 |

### NOR-NORK (조동사 **ukan**: dut, duzu, du…)

이 동사들은 주어와 목적어를 가지므로 **ukan**과 함께 쓰입니다:

| Partizipioa | 습관상 | 의미 |
|---|---|---|
| *gosaldu* | *gosaltzen dut* | 아침을 먹다 |
| *bazkaldu* | *bazkaltzen dut* | 점심을 먹다 |
| *afaldu* | *afaltzen dut* | 저녁을 먹다 |
| *jan* | *jaten dut* | 먹다 |
| *edan* | *edaten dut* | 마시다 |
| *lan egin* | *lan egiten dut* | 일하다 |
| *lo egin* | *lo egiten dut* | 자다 |
| *ikusi* | *ikusten dut* | 보다 |
| *irakurri* | *irakurtzen dut* | 읽다 |
| *erosi* | *erosten dut* | 사다 |

> **왜 어떤 동사는 NAIZ와, 다른 동사는 DUT과 함께 쓰일까요?** 이것이 바스크어의 핵심적인 구분입니다. *Esnatzen naiz*(일어나다)는 나에게 일어나는 일입니다. 목적어가 없습니다. *Jaten dut*(먹다)는 목적어가 있습니다: *ogia jaten dut*(빵을 먹다). 이 내용은 다음 단원에서 더 자세히 다룰 것입니다 — 지금은 동사 + 조동사 쌍을 외워두세요.

## 연결된 예문

> *Egunero zazpietan esnatzen naiz eta dutxatzen naiz.* — 매일 7시에 일어나서 샤워합니다.
>
> *Goizean kafea hartzen dut.* — 아침에 커피를 마십니다.
>
> *Askotan lagunekin afaltzen dut.* — 자주 친구들과 저녁을 먹습니다.
>
> *Batzuetan lo-kuluxka egiten dut bazkalostean.* — 가끔 점심 식사 후에 낮잠을 잡니다.

> **참고:** *bazkalostean* = "점심 식사 후" (직역: "식사 뒤에"). 바스크 문화에는 짧은 낮잠과 같은 일상적인 개념을 위한 간결한 단어들이 있습니다 — *lo-kuluxka*가 바로 그것입니다.
