바스크어에서 하루의 시간대를 나타내는 말은 용도에 따라 두 가지 핵심 접미사, 즉 **`-(e)an`** ('~에')과 **`-(e)ko`** ('~의')를 사용합니다. 좋은 점은 모든 단어와 규칙적으로 결합한다는 것입니다.

## 기본 단어

| 바스크어 | 한국어 |
|---|---|
| *goiza* | 아침 |
| *eguerdia* | 정오 |
| *arratsaldea* | 오후 |
| *iluntzea* | 해질녘 |
| *gaua* | 밤 |

## '아침에 / 오후에' — 장소격 `-(e)an`

언제(하루 중 어느 때) 어떤 일이 일어나는지 말하려면 어근에 **-(e)an**을 붙입니다:

| 언제 | 바스크어 |
|---|---|
| 아침에 | **goizean** |
| 정오에 | **eguerdian** |
| 오후에 | **arratsaldean** |
| 해질녘에 | **iluntzean** |
| 밤에 | **gauean** |

> *Goizean kafea hartzen dut.* — 아침에 커피를 마셔요.
>
> *Arratsaldean lagunekin egoten naiz.* — 오후에 친구들과 함께 있어요.
>
> *Gauean lo egiten dut.* — 밤에 잠을 자요.

## '아침의 / 오후의' — 접미사 `-ko`

**하루 중 몇 시**인지 구체적으로 말하려면 시간 앞에 **-ko**를 붙인 단어를 놓습니다:

| 정확한 시간 | 바스크어 |
|---|---|
| 아침 8시 | **goizeko zortziak** |
| 정오 12시 | **eguerdiko hamabiak** |
| 오후 5시 | **arratsaldeko bostak** |
| 밤 9시 | **gaueko bederatziak** |

> *Goizeko zazpietan esnatzen naiz.* — 저는 아침 7시에 일어나요.
>
> *Arratsaldeko hirurak dira.* — 오후 3시입니다.

## 기본적인 시간 표현

이 표현들은 매일 사용하게 될 거예요:

| 바스크어 | 한국어 |
|---|---|
| *gaur* | 오늘 |
| *atzo* | 어제 |
| *bihar* | 내일 (다음 날) |
| *etzi* | 모레 |
| *orain* | 지금 |
| *gero* | 나중에, 후에 |
| *lehen* | 전에 |

> 주의: **bihar**(다음 날, '내일')와 **goiza**(정오까지의 '아침')를 혼동하지 않도록 조심하세요. 스페인어에서는 같은 단어를 사용하지만 바스크어에서는 다릅니다.

## 모두 조합하기

> *Bihar goizean lanera joango naiz.* — 내일 아침에 일하러 갈 거예요.
>
> *Atzo arratsaldean zinemara joan ginen.* — 어제 오후에 영화 보러 갔어요.
>
> *Gaur gaueko hamarretan afalduko dut.* — 오늘 밤 10시에 저녁을 먹을 거예요.

> **문화 노트:** 바스크 지방은 *iluntze*로 유명합니다. — 친구들이 *poteo*(가벼운 술자리를 돌며 마시는 것)를 하러 나가는 해질녘 시간입니다. 오후도 아니고 밤도 아닌, 그 자체로 고유한 정체성을 가진 시간대입니다.
