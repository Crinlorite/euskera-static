Esta lição integradora revisa **quatro novas declinações** que o nível A2 adiciona ao repertório do A1 (NOR, NORK, NORI, NON, NOREN, NORA, NONDIK, NOREKIN). São as que aparecem em qualquer prova do nível A2 e completam a "rosa" do basco.

## NORENTZAT — para quem (destinativo)

> **-(r)entzat** sobre o substantivo determinado

| Substantivo | Forma | Português |
|---|---|---|
| niretzat | *niretzat* | para mim |
| zuretzat | *zuretzat* | para você |
| beretzat / harentzat | *beretzat* | para ele/ela |
| guretzat | *guretzat* | para nós |
| zuentzat | *zuentzat* | para vocês |
| haientzat | *haientzat* | para eles/elas |
| Lander | *Landerrentzat* | para Lander |
| a mãe | *amarentzat* | para a mãe |
| os amigos | *lagunentzat* | para os amigos |

> *Hau **zuretzat** da.* — Isto é para você.
>
> *Opari bat erosi dut **Garazirentzat**.* — Comprei um presente para Garazi.
>
> *Liburu hau **gazte ikasleentzat** da.* — Este livro é para os jovens estudantes.

> **Variante:** existe também a forma **-(r)endako**, sinônima em muitos dialetos: *Garazirendako, niretzako/niretako*. A forma padrão é *-rentzat*.

## NORAINO — até (limite)

> **-(r)aino** sobre o substantivo (segue a regra do NORA: vogal → +raino, consoante → +eraino)

| Português | Basco |
|---|---|
| Até o monte | *mendi**raino*** |
| Até Bilbao | *Bilbo**raino*** |
| Até aqui | *hona**ino*** |
| Até onde | *nora**ino*** |
| Até o cume | *tontorr**eraino*** |

> *Korrika egin dugu **plazaraino**.* — Corremos até a praça.
>
> *Bilbo**raino** etorri zen eta gero itzuli.* — Veio até Bilbao e depois voltou.

## NORANTZ — em direção a (direção)

> **-(r)antz** sobre o substantivo (mesmo padrão que o NORA)

| Português | Basco |
|---|---|
| Em direção ao monte | *mendi**rantz*** |
| Em direção a casa | *etxe**rantz*** |
| Em direção ao sul | *hego**rantz*** |
| Em sua direção | *zu**rantz*** |

> *Etxe**rantz** abiatu nintzen.* — Fui em direção a casa.
>
> *Itsaso**rantz** dago etxea.* — A casa está voltada para o mar.

> **Diferença em relação a NORA (-ra):** *NORA* indica um destino concreto ("vou para Bilbao"); *NORANTZ* indica uma direção aproximada ("vou em direção a Bilbao", sem garantia de chegar).

## ZERGATIK / NORENGATIK — por causa de (motivo)

Para perguntar o motivo: **zergatik?** (por quê?). Para responder com um substantivo: **-engatik**.

| Substantivo | Forma | Português |
|---|---|---|
| nigatik | *nigatik* | por mim (causa) |
| zugatik | *zugatik* | por você |
| beragatik / harengatik | *beragatik* | por ele/ela |
| Lander | *Landerrengatik* | por Lander |
| a mãe | *amarengatik* | pela mãe |
| o amor | *maitasunarengatik* | pelo amor |
| a chuva | *euriagatik* | pela chuva |

> *Eskerrik asko **etorri zarelako, niregatik**!* — Obrigado(a) por vir, por mim!
>
> *Berandu iritsi nintzen **trafikoarengatik**.* — Cheguei tarde por causa do trânsito.
>
> *Zergatik egin duzu hori? — **Zugatik**.* — Por que você fez isso? — Por você.

> **Nota:** diferencie *-engatik* (causa: "por causa de") de *-rentzat* (destinatário: "para"). Em espanhol, "por" cobre os dois sentidos, mas em basco são distintos.

## NONGO / NOIZKO — de que lugar / momento

Você já viu *NON* (-an: em) no A1. **NONGO** e **NOIZKO** transformam um lugar ou um tempo em um **modificador** (atributo):

| Português | Basco |
|---|---|
| As pessoas **de** Bilbao | *Bilbo**ko** jendea* |
| O museu **de** Donosti | *Donostia**ko** museoa* |
| O jornal **de** hoje | *Gaur**ko** egunkaria* |
| A prova **de** amanhã | *Bihar**ko** azterketa* |
| A festa **de** julho | *Uztaileko jaia* |

> É o caso **NONGO/NOIZKO** (-ko / -tako após consoante): "de onde" / "de quando" em sentido atributivo.

| Forma | Para que |
|---|---|
| **-ko** singular | *Bilboko, etxeko, gaurko* |
| **-etako** plural | *etxe**etako**, mendi**etako**, urte**etako*** |

> *Atzo**ko** afari**a** ona zen.* — O jantar de ontem estava bom.
>
> *Bilbo**ko** etxebizitzak garestiak dira.* — As moradias de Bilbao são caras.
>
> *Mendi**etako** loreak ederrak dira.* — As flores das montanhas são bonitas.

## Mini-texto integrador

> *Joan den astean **Bilboraino** joan ginen autobusez. Helmuga: hiriko **museorako** sarrera bana erostea. **Bilboko jendea** oso jatorra izan zen. Buelta hartzeko, taxi bat hartu genuen **etxerantz**: euri-jasa hain handia zen, ezen autoa **euriagatik** hondatu zen. Azkenean, ordu bat **beranduago** iritsi ginen **Donostiako geltokira**. Hori bai, etxean opari bat zegoen zain: **niretzat**, ama maitearen partez.*

Agora você já domina todos os casos básicos:

|---|---|---|---|

| NORK | quem faz? | -ak | *etxeak* (sujeito) |
| NORI | a quem? | -ari | *etxeari* |
| NON | onde? | -an | *etxean* |
| NORA | para onde? | -ra | *etxera* |
| NONDIK | de onde? | -tik | *etxetik* |
| NOREKIN | com quem? | -arekin | *etxearekin* |
| NOREN | de quem? | -aren | *etxearen* |
| NONGO | de onde (at.)? | -ko | *etxeko* |
| NORENTZAT | para quem? | -arentzat | *etxearentzat* |
| NORAINO | até onde? | -raino | *etxeraino* |
| NORANTZ | em direção a onde? | -rantz | *etxerantz* |
| NORENGATIK | por quem? | -arengatik | *etxearengatik* |
| -ZAZ / -Z | instrumental | -z | *etxez* |
| -RIK | partitivo (negação) | -rik | *etxerik (ez dago)* |

> **Desafio A2:** escreva uma frase com cada caso usando o substantivo *Garazi*. Você verá como toda a engrenagem do basco funciona em uma única pessoa.

> **Nota pedagógica:** estas declinações são a "porta para o B1": se você as dominar, já poderá construir frases ricas em informação (destino, motivo, atributo, direção). No B1, os usos abstratos são aprofundados e mais alguns são adicionados (instrumental com valor causal, partitivo estendido).
