Esta lição expande o passado para os verbos **NOR-NORK** (transitivos: eu o, você o, ele o). É a base para narrar todas as ações que têm um objeto: *comi, vi, fiz, disse, comprei, chamei...*

## A fórmula

> **partizipioa + nuen / zenuen / zuen / genuen / zenuten / zuten**

| Pronome | Passado de *dut* | Português |
|---|---|---|
| nik | **nuen** | eu o |
| zuk | **zenuen** | você o |
| hark | **zuen** | ele/ela o |
| guk | **genuen** | nós o |
| zuek | **zenuten** | vocês o |
| haiek | **zuten** | eles/elas o |

> As formas terminam **sempre em -n**, e a primeira letra é a marca da pessoa: **n-** (eu), **z-** (você/vocês/eles), **g-** (nós).

## Objeto plural — *nituen*

Se o objeto for **plural** (os livros, os ingressos, as cervejas), o auxiliar muda para a série em **-itu-**:

| Pronome | Auxiliar plural | Português |
|---|---|---|
| nik | **nituen** | eu os |
| zuk | **zenituen** | você os |
| hark | **zituen** | ele/ela os |
| guk | **genituen** | nós os |
| zuek | **zenituzten** | vocês os |
| haiek | **zituzten** | eles/elas os |

## Exemplos

| Português | Basco |
|---|---|
| Comi pintxos | *Pintxoak jan **nituen*** |
| Vi um filme | *Film bat ikusi **nuen*** |
| Fizeram o jantar | *Afaria egin **zuten*** |
| O que ele/ela disse? | *Zer esan **zuen**?* |
| Compramos pão | *Ogia erosi **genuen*** |
| Vendeu as duas motos | *Bi motoak saldu **zituen*** |

## Verbos sintéticos: *eduki* e *jakin*

Dois verbos muito frequentes mantêm a forma **sintética** no passado, assim como no presente (*daukat, dakit*):

### *Eduki* (ter, posse)

| Pronome | Forma | Português |
|---|---|---|
| ni | **neukan** | eu tinha |
| zu | **zeneukan** | você tinha |
| hura | **zeukan** | ele/ela tinha |
| gu | **geneukan** | nós tínhamos |
| zuek | **zeneukaten** | vocês tinham |
| haiek | **zeukaten** | eles/elas tinham |

### *Jakin* (saber)

| Pronome | Forma | Português |
|---|---|---|
| ni | **nekien** | eu sabia |
| zu | **zenekien** | você sabia |
| hura | **zekien** | ele/ela sabia |
| gu | **genekien** | nós sabíamos |
| zuek | **zenekiten** | vocês sabiam |
| haiek | **zekiten** | eles/elas sabiam |

> *Anbotok bizikleta gorri bat **zeukan** umetan.* — Anboto tinha uma bicicleta vermelha quando era criança.
>
> *Ez **zekien** non bizi ginen.* — Não sabia onde morávamos.

## Dois detalhes-chave do NOR-NORK no passado

**1. A marca -k no sujeito.** Assim como no presente, o sujeito que realiza a ação leva o caso ergativo:

> *Garazi**k** afaria egin **zuen**.* — Garazi fez o jantar.
>
> *Lander**rek** sarrerak erosi **zituen**.* — Lander comprou os ingressos.

**2. Concordância com o objeto.** Se o objeto for singular → *nuen / zuen*; se for plural → *nituen / zituen*. É a mesma regra do presente.

## Negação

> *Atzo ez nuen filmik ikusi.* — Ontem não vi nenhum filme.
>
> *Ainarak ez zuen ezer esan.* — Ainara não disse nada.
>
> *Ez genituen sarrerak erosi.* — Não compramos os ingressos.

> Quando o objeto é negado, ele geralmente aparece no partitivo: *filmik, ezer, txikirik*. É o mesmo *-rik* que você viu no A1.

## Mini-narrativa

> *Aurreko larunbatean Olatz eta Lander itsasora **joan ziren** (NOR). Hondartzan egun osoa **eman zuten**: igeri **egin zuten**, eguzkitan etzanda **egon ziren** eta liburu bat **irakurri zuten**. Iluntzean afari bat **prestatu zuten** eta lagunekin **afaldu zuten**.*

Note como se misturam as formas NOR (*joan ziren, egon ziren*) e NOR-NORK (*eman zuten, irakurri zuten, prestatu zuten*). As duas lições se combinam para narrar.

> **Nota:** na próxima lição, você verá os **verbos sintéticos no passado** (*nindoan, nentorren, nenbilen*) que completam o passado NOR.
