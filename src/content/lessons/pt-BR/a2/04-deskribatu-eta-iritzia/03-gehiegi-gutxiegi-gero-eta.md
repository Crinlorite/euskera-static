Esta lição completa as comparações com mais duas peças:

1. **Excesso e insuficiência** (-egi, gehiegi, gutxiegi).
2. **Comparativo progressivo** (cada vez mais / menos: *gero eta...*).

Mais alguns modificadores úteis para matizar (*pixka bat, askoz, dezente*).

## O sufixo -**egi** — "demais"

Para dizer que algo é **excessivo**, você adiciona **-egi** ao adjetivo (e depois o **-a** final se for com um substantivo determinado):

| Adjetivo | Excessivo |
|---|---|
| *handia* (grande) | *handi**egia*** (grande demais) |
| *txikia* (pequeno) | *txiki**egia*** |
| *garestia* (caro) | *garesti**egia*** |
| *beroa* (quente) | *bero**egia*** |
| *hotza* (frio) | *hotz**egia*** |
| *zaila* (difícil) | *zail**egia*** |
| *azkarra* (rápido) | *azkarr**egia*** |

> *Alkandora hau **handiegia** da niretzat.* — Esta camisa é grande demais para mim.
>
> *Kafea **beroegi** dago.* — O café está quente demais.
>
> *Ikastaroa **zailegia** zen guretzat.* — O curso era difícil demais para nós.

## *Gehiegi* e *gutxiegi*

Como advérbios independentes:

| Português | Basco |
|---|---|
| Demais | *gehiegi* |
| Pouco demais / insuficiente | *gutxiegi* |
| Gente demais | *jende **gehiegi*** |
| Pouca água demais | *ur **gutxiegi*** |

> *Gehiegi jan dut.* — Eu comi demais.
>
> *Gutxiegi lo egiten duzu.* — Você dorme pouco (demais).
>
> *Hori **gehiegi** da niretzat.* — Isso é demais para mim.

## O comparativo progressivo: *gero eta + -ago*

Para "**cada vez mais X**" ou "**cada vez menos X**", o basco usa uma fórmula muito expressiva:

> **gero eta + adjetivo/advérbio-ago(a)**

| Português | Basco |
|---|---|
| Cada vez mais caro | *Gero eta **garestiagoa*** |
| Cada vez mais frio | *Gero eta **hotzagoa*** |
| Cada vez melhor | *Gero eta **hobea*** |
| Cada vez pior | *Gero eta **okerragoa*** |
| Cada vez mais | *Gero eta **gehiago*** |
| Cada vez menos | *Gero eta **gutxiago*** |
| Cada vez mais rápido | *Gero eta **azkarrago*** |
| Cada vez mais devagar | *Gero eta **polikiago*** |

> *Bilbo gero eta handiagoa da.* — Bilbao está cada vez maior.
>
> *Eguraldia gero eta okerrago dago.* — O tempo está cada vez pior.
>
> *Gazteek gero eta gutxiago hitz egiten dute euskaraz.* — Os jovens falam cada vez menos em basco.

> **Dica mnemônica:** *gero eta* literalmente "depois e" — a ideia é "depois, e depois, e depois mais...". É a forma basca de expressar progressão.

## *Hain* — "tão" (com ou sem negação)

| Português | Basco |
|---|---|
| É tão grande | *Hain handia da* |
| Não é tão caro | *Ez da **hain** garestia* |
| É tão bonito! | *Hain polita da!* |

> Para "não é tão... como..." se usa *bezain* (lição anterior):
>
> *Ez da zuk uste duzun bezain ona.* — Não é tão bom como você pensa.

## Modificadores de quantidade

Para matizar as comparações:

| Português | Basco | Exemplo |
|---|---|---|
| Um pouco | *pixka bat* | *Pixka bat handiagoa* (um pouco maior) |
| Algo | *zerbait / zertxobait* | *Zertxobait txikiagoa* (algo menor) |
| Bastante | *dezente* | *Dezente hobea* (bastante melhor) |
| Muito | *askoz* | *Askoz hobea* (muito melhor) |
| Muitíssimo | *askoz hobea / askoz garestiagoa* | |

> *Etxe hau zurea **baino askoz** handiagoa da.* — Esta casa é muito maior que a sua.
>
> *Pixka bat goizago etorriko naiz.* — Virei um pouco mais cedo.

## *Hain... ezen* / *hainbeste...* (registro formal)

Além do A2 estrito, convém reconhecer:

- *Hain* + adjetivo + *non/ezen* — tão... que: *Hain pozik zegoen, non kantatzen hasi zen* (estava tão contente que começou a cantar).
- *Hainbeste* — tanto/a (quantidade enfática): *Hainbeste lan dago!*

## Mini-texto

> *Garazi sukaldari ona da, baina kafea **beroegi** ipintzen du beti. Lehengo egunean **hain bero** zegoen, ezen ezin nuen edan! Eta hori ez da dena: pintxo bakoitzean olio **gehiegi** botatzen du. **Pixka bat gutxiago** beharko luke. Hala ere, hura **gero eta hobea** da: orain dela urtebete askoz **okerragoa** zen.*

## Mini-diálogo

> *— Olatz, etxe berri hori zer moduz?*
>
> *— Eder askoa, baina **garestiegia** zen guretzat. Eta logelak **txikiegiak** ziren.*
>
> *— Eta orain bilatzen ari zaretena nolakoa da?*
>
> *— **Gero eta zailagoa** da etxebizitza on bat aurkitzea. Prezioak **gero eta altuagoak** dira eta etxebizitza on guztiek dute lehia **gehiegi**.*

> **Nota cultural:** a escassez de moradia acessível (*etxebizitza*) é um tema recorrente em qualquer conversa de nível A2 sobre a atualidade: *gero eta garestiago, pisu eskuragarri gutxiegi, askoz okerrago lehen baino*. Esta lição te dá o vocabulário para participar.
