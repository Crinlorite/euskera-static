Do papel ao pixel: a lição de **tecnologia cotidiana**. Vocabulário que você usa cem vezes por dia — agora em basco, que, aliás, se orgulha de suas palavras transparentes e bem construídas (*pasahitza* = palavra de passagem; *sakelakoa* = "o de bolso").

## Os aparelhos

| Português | Euskera |
|---|---|
| O computador | *ordenagailua* |
| O notebook | *eramangarria* |
| O celular | *mugikorra / sakelakoa* |
| O tablet | *tableta* |
| A tela | *pantaila* |
| O teclado | *teklatua* |
| O mouse | *sagua* (sim, o animal!) |
| Os fones de ouvido | *entzungailuak* |

## A rede e as contas

| Português | Euskera |
|---|---|
| A rede / a internet | *sarea / internet* |
| O wi-fi | *wifia* |
| O e-mail | *posta elektronikoa* |
| O usuário | *erabiltzailea* |
| A senha | *pasahitza* |
| O aplicativo | *aplikazioa* |
| O site | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Qual é a senha do wi-fi?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — Esqueci a senha e agora tenho que criar uma nova. De novo.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Para criar a conta, você precisa de e-mail e senha.

## Os verbos digitais

| Português | Euskera |
|---|---|
| Ligar / desligar | *piztu / itzali* |
| Baixar / fazer download | *deskargatu / jaitsi* |
| Instalar | *instalatu* |
| Salvar | *gorde* |
| Apagar / deletar | *ezabatu* |
| Enviar / compartilhar | *bidali / partekatu* |
| Procurar / buscar (na rede) | *bilatu* |
| Funcionar | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — O computador não está funcionando bem; desligue e ligue — a solução de sempre.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Você salvou as fotos? Não apague nada!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Baixe o app, crie a conta e pronto.

## Diálogo: suporte técnico familiar

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Nota:** o basco digital está muito vivo: o software livre e a Wikipédia em basco são potentes, e seu celular inteiro pode ficar em basco (*Ezarpenak → Hizkuntza*). Configurá-lo assim é, na verdade, um truque de estudo incrível: imersão diária e gratuita.
