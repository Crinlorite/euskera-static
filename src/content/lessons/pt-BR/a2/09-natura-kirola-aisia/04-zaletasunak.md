O que você faz quando não faz nada? Esta lição é sobre **hobbies** — e sobre a peça gramatical que os rege: o verbo transformado em substantivo com **-tzea** (*irakurtzea* = "o ler").

## A peça: -t(z)ea

Do A1 você conhece *gustatzen zait* com coisas (*kafea gustatzen zait*). Para gostar de uma **atividade**, o verbo se torna um substantivo:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| Português | Basco |
|---|---|
| Gosto de ler | *Irakurtzea gustatzen zait* |
| Adoro cozinhar | *Asko gustatzen zait sukaldatzea* |
| Ele/ela gosta de cantar | *Abestea gustatzen zaio* |
| Gostamos de viajar | *Bidaiatzea gustatzen zaigu* |
| Não gosto nem um pouco de acordar cedo | *Ez zait batere gustatzen goiz jaikitzea* |

Todo o NOR-NORI que você já sabe (*zait, zaio, zaigu…*) continua no comando; só muda o "quê".

## O catálogo de hobbies

| Português | Basco |
|---|---|
| Ler / escrever | *irakurtzea / idaztea* |
| Ouvir música | *musika entzutea* |
| Cantar / dançar | *abestea / dantzatzea* |
| Cozinhar | *sukaldatzea* |
| Tirar fotos | *argazkiak ateratzea* |
| Pintar / desenhar | *margotzea / marraztea* |
| Viajar | *bidaiatzea* |
| Cuidar da horta | *baratzea zaintzea* |
| Videogames | *bideo-jokoak* |
| Costurar / tricotar | *jostea / puntua egitea* |

## Perguntar e exibir

> ***Zer egitea gustatzen zaizu** denbora librean?* — O que você gosta de fazer no seu tempo livre?
>
> ***Zein da zure zaletasunik gogokoena**?* — Qual é o seu hobby favorito?
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — Meu hobby favorito é cozinhar: todo fim de semana eu provo uma receita nova.

## Três estruturas, três nuances (revisão refinada)

| Estrutura | Exemplo | Significa |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | eu gosto (hobby) |
| **-tzen dakit** | *Margotzen dakit* | sei fazer (habilidade) |
| **-tzen ari naiz** | *Margotzen ari naiz* | estou fazendo (agora) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — Não sei tricotar, mas gostaria de aprender. (Esse *gustatuko litzaidake* elegante você dominará no B1 — deixamos aqui como um aperitivo.)
