Os verbos **NOR-NORI** são aqueles em que algo (NOR) "acontece a alguém" (NORI). O sujeito gramatical é **a coisa**, não a pessoa — exatamente como o verbo *gostar* em espanhol: *me gusta el cine* (para mim, ele, o cinema, me agrada).

No A1 você já viu *gustatzen zait*. No A2 você expande o padrão para outros verbos muito úteis.

## As formas do auxiliar NOR-NORI no presente

Para NOR singular:

| NORI | Forma | Português |
|---|---|---|
| niri | **zait** | me |
| zuri | **zaizu** | te |
| hari | **zaio** | lhe |
| guri | **zaigu** | nos |
| zuei | **zaizue** | vos |
| haiei | **zaie** | lhes |

Para NOR **plural**:

| NORI | Forma plural | Português |
|---|---|---|
| niri | **zaizkit** | me (coisas) |
| zuri | **zaizkizu** | te |
| hari | **zaizkio** | lhe |
| guri | **zaizkigu** | nos |
| zuei | **zaizkizue** | vos |
| haiei | **zaizkie** | lhes |

## Passado: *zitzaidan, zitzaion*

| NORI | Passado sing. | Passado pl. |
|---|---|---|
| niri | **zitzaidan** | **zitzaizkidan** |
| zuri | **zitzaizun** | **zitzaizkizun** |
| hari | **zitzaion** | **zitzaizkion** |
| guri | **zitzaigun** | **zitzaizkigun** |
| haiei | **zitzaien** | **zitzaizkien** |

## Verbos com este padrão

| Verbo | Significado | Exemplo |
|---|---|---|
| *gustatu* | gostar | *Filmak gustatzen zaizkit* (gosto dos filmes) |
| *iruditu* | parecer | *Ondo iruditzen zait* (me parece bom) |
| *ahaztu* | esquecer-se | *Ahaztu zait izena* (esqueci o nome) |
| *erori* | cair | *Erori zaizu boligrafoa* (sua caneta caiu) |
| *gertatu* | acontecer a | *Zer gertatu zaizu?* (o que te aconteceu?) |
| *interesatu* | interessar | *Politika interesatzen zait* (a política me interessa) |
| *axola izan* | importar | *Ez zait axola* (não me importa) |

## Estrutura: o sujeito é a coisa

> **NORI + NOR + verbo + auxiliar NOR-NORI**

| Português | Basco | Notação |
|---|---|---|
| Gosto de cinema | *Niri zinea **gustatzen zait*** | NORI + NOR sing + zait |
| Gosto de filmes | *Niri filmak **gustatzen zaizkit*** | NORI + NOR pl + zaizkit |
| Te parece bom | *Zuri ondo **iruditzen zaizu*** | NORI + NOR + zaizu |
| Um livro caiu dele/dela | *Hari liburu bat **erori zaio*** | NORI + NOR sing + zaio |
| Esqueci as chaves | *Niri giltzak **ahaztu zaizkit*** | NORI + NOR pl + zaizkit |

> **Dica:** a pessoa afetada vai em NORI (-ari/-ei) e geralmente aparece no início. A coisa é o sujeito gramatical, e o verbo concorda com ela.

## *Gustatzen zait* no passado — *gustatu zitzaidan*

Para falar de gostos no passado:

> *Filma asko **gustatu zitzaidan**.* — Gostei muito do filme.
>
> *Ez zitzaion gustatu opari hori.* — Ele/ela não gostou daquele presente.

> Cuidado: *gustatu zitzaidan* (= gostei, ação concluída) vs *gustatzen zitzaidan* (= gostava, hábito).

## *Iruditu* (parecer) — opinião pessoal

Uma das fórmulas mais úteis para o A2:

| Português | Basco |
|---|---|
| Me parece bom | *Ondo iruditzen zait* |
| Me parece interessante | *Interesgarria iruditzen zait* |
| O que você acha? | *Zer iruditzen zaizu?* |
| Me parece estranho | *Bitxia iruditzen zait* |
| Acho que sim | *Baietz iruditzen zait* |

## *Ahaztu zait* — esqueci

| Português | Basco |
|---|---|
| Esqueci | *Ahaztu zait* |
| Esqueci as chaves | *Giltzak ahaztu zaizkit* |
| Ele/ela esquece tudo | *Dena ahazten zaio* |
| Não se esqueça! | *Ez zaizula ahaztu!* |

## Minidiálogo

> *— Olatz, **zer iruditzen zaizu** Bilboko jatetxe berria?*
>
> *— Asko **gustatu zait**. Bereziki bigarren platerak: **interesgarriak iruditu zaizkit**.*
>
> *— Eta, jakin nahi nuen, **ahaztu zaizu** zer eskatu zenuen?*
>
> *— Bai, izenak ez **zaizkit gogoratzen**, baina arraina zen, ziur.*

## Armadilhas frequentes

1. **O sujeito ergativo NÃO existe aqui.** Não diga *\*Nik gustatzen dut* (é um erro muito comum): o correto é *Niri gustatzen zait*. A pessoa não é quem age.
2. **Concordância NOR.** Se a coisa for plural, o auxiliar é plural: *zaizkit, zaizkio, zaizkigu...*
3. **Algumas regiões usam outras variantes** (*zaidak, zaidan* em hitano), mas em *batua* as formas padrão são as da tabela.

> **Nota cultural:** os falantes de basco costumam usar muito (de forma carinhosa) *iruditzen zait* para opinar com uma certa cautela: *interesgarria iruditzen zait*, *bitxia iruditzen zait*, *ez zait ondo iruditzen*. É a versão basca do "eu acho que..." com ressalvas.
