O **imperativo** (*agintera*) serve para dar instruções, fazer pedidos e dar conselhos. Em basco, é **muito mais simples do que parece**: a forma mais usada quase sempre coincide com o **particípio** do verbo.

## A regra básica: use o particípio

Para muitas ordens cotidianas, o verbo aparece em sua forma de particípio, sem auxiliar:

| Português | Basco |
|---|---|
| Pegue / Tome | *Hartu* |
| Sente-se | *Eseri* |
| Levante-se | *Jaiki* |
| Escreva | *Idatzi* |
| Leia | *Irakurri* |
| Escute | *Entzun* |
| Repita | *Errepikatu* |
| Espere | *Itxoin* |
| Feche a porta | *Itxi atea* |
| Abra a janela | *Ireki leihoa* |

> Esta é a **forma mais usada** em sala de aula, na rua e em instruções escritas. Serve tanto para *zu* quanto para *zuek*.

## Formas sintéticas (trinkoak): *zatoz*, *zoaz*

Alguns verbos muito frequentes têm formas sintéticas específicas para o imperativo. Estas são as que convém memorizar:

| Verbo | Você (zu) | Vocês (zuek) |
|---|---|---|
| *etorri* (vir) | **Zatoz** | **Zatozte** |
| *joan* (ir) | **Zoaz** | **Zoazte** |
| *ekarri* (trazer) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (levar) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (estar) | **Egon** / **Lasai** (calma!) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## Imperativo NOR-NORI-NORK: *emadazu*, *esadazu*

Quando você dá uma ordem com objeto duplo ("dê-me isto", "diga-lhe aquilo"), o basco tem formas compactas muito úteis:

| Português | Basco |
|---|---|
| Dê-me | *Emadazu* / *Eman iezadazu* |
| Diga-me | *Esadazu* / *Esan iezadazu* |
| Dê-lhe | *Emaiozu* / *Eman iezaiozu* |
| Diga-lhe | *Esaiozu* / *Esan iezaiozu* |
| Dê-nos | *Emaguzu* |
| Deem-me | *Emadazue* |

Estas formas são longas para aprender; no nível A2, basta saber **emadazu / esadazu / emaiozu / esaiozu** e entender que vêm do verbo *eman* / *esan*.

## "Por favor" e suavizadores

O imperativo em basco **não soa rude** se você adicionar alguma palavra de cortesia:

- *Mesedez* — por favor
- *Ahal baduzu* — se você puder
- *Faborez* (variante coloquial)
- *Eskerrik asko aldez aurretik* — obrigado(a) de antemão

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## Instruções (receitas, avisos, sala de aula)

O imperativo é a forma padrão em:

- **Receitas:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **Cartazes:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **Sala de aula:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **Médico:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## Mini-texto

> *Sukaldari eskolan, irakasleak esaten du:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **Nota cultural:** em basco, o tom **mandão** do imperativo é atenuado com a entonação e o contexto, não tantas vezes com perífrases ("você poderia..."). Acompanhar a ordem com *mesedez* ou com um sorriso costuma ser suficiente. Se quiser algo mais cortês, diga *eman ahal didazu...?* (você pode me dar...?).
