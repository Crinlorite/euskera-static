Falar sobre **estilo de vida** e **meio ambiente** é um bloco clássico do A2: mistura-se vocabulário novo com frases de obrigação e conselho (*behar dugu*, *komeni da*, *garrantzitsua da*) que você já domina desde o A1.

## Hábitos saudáveis

| Português | Basco |
|---|---|
| Praticar esporte | *kirola egin* |
| Caminhar / passear | *paseatu* / *ibili* |
| Correr | *korrika egin* |
| Andar de bicicleta | *bizikletaz ibili* |
| Comer frutas e verduras | *fruta eta barazkiak jan* |
| Beber água | *ura edan* |
| Dormir bem | *ondo lo egin* |
| Fumar | *erre* |
| Beber álcool | *alkohola edan* |
| Não abusar do sal | *gatzaz ez abusatu* |

> Frases típicas:
>
> - *Kirola egiten dut astean hiru aldiz.* — Pratico esporte três vezes por semana.
> - *Erretzeari utzi diot.* — Parei de fumar.
> - *Ez dut alkoholik edaten astegunetan.* — Não bebo álcool durante a semana.

## Frequência: *X aldiz*

Para dizer "X vezes" você usa a fórmula **número + aldiz**:

| Português | Basco |
|---|---|
| Uma vez por dia | *Egunean behin* |
| Duas vezes por semana | *Astean bi aldiz* / *birritan* |
| Três vezes por mês | *Hilean hiru aldiz* |
| Muitas vezes | *Askotan* |
| Às vezes | *Batzuetan* |
| Poucas vezes | *Gutxitan* |
| Nunca | *Inoiz ez* |

## Frases úteis para opinar

- *Garrantzitsua da birziklatzea.* — É importante reciclar.
- *Komeni da kirola egitea.* — Convém praticar esporte.
- *Beharrezkoa da kutsadura gutxitzea.* — É necessário reduzir a poluição.
- *Ez dut uste plastikoa ona denik.* — Não acho que o plástico seja bom.

> Essas estruturas (*-tzea + adjetivo + da*) são a fórmula do A2 para "é importante / convém / é necessário fazer X". Vamos trabalhá-las a fundo na unidade 4.

## Vida do bairro

| Português | Basco |
|---|---|
| Bairro | *auzoa* |
| Vizinho/a | *bizilaguna* |
| Associação | *elkartea* |
| Voluntariado | *boluntariotza* |
| Festas do bairro | *auzoko jaiak* |
| Participar | *parte hartu* |
| Reunião | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## Mini-texto modelo

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **Nota cultural:** as *auzo-elkarteak* (associações de bairro) são uma peça fundamental da vida social em muitos povoados de Euskal Herria. Elas organizam festas, oficinas de basco, passeios à montanha e campanhas ambientais. Participar é uma das melhores formas de praticar a língua em uso real.
