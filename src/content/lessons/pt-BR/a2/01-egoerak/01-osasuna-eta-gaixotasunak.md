O A2 abre a porta para você falar sobre como se sente fisicamente: quando está doente, o que dói e o que o médico receitou. A estrutura básica que você já conhece do A1 (*mina daukat*) é ampliada com vocabulário específico, profissionais de saúde e diálogos de consulta.

## Como dizer "estou doente"

Em basco, você tem duas formas comuns:

- **Gaixorik nago.** — Estou doente. (estado pontual, com *egon*)
- **Ez nago ondo.** — Não estou bem.
- **Min hartu dut.** — Eu me machuquei.
- **Gaixotu egin naiz.** — Fiquei doente (verbo intransitivo, *naiz*).

> **Nota gramatical:** *gaixorik* leva o sufixo -**rik** (estado), assim como *pozik* (contente), *nekatuta*, *triste*. Lembre-se: estado = *egon*.

## Sintomas — fórmula universal X **daukat**

Como no A1, os sintomas são construídos com *eduki* (ter):

| Português | Basco |
|---|---|
| Estou com febre | *Sukarra **daukat*** |
| Estou com tosse | *Eztula **daukat*** |
| Estou resfriado/a | *Katarroa **daukat*** |
| Estou com gripe | *Gripea **daukat*** |
| Estou tonto/a | *Zorabiatuta nago* |
| Estou com náuseas | *Goragalea **daukat*** |

## Dor: *mina*

A **dor** é um substantivo em basco (*mina*) e se combina com a parte do corpo em **NONGO (-ko)**, que atua como um complemento de "que tipo de dor":

> **parte do corpo + -ko + mina + daukat**

| Português | Basco |
|---|---|
| Estou com dor de cabeça | *Buruko mina daukat* |
| Estou com dor de garganta | *Eztarriko mina daukat* |
| Estou com dor de barriga | *Sabeleko mina daukat* |
| Estou com dor de dente | *Hortzeko mina daukat* |
| Estou com dor nas costas | *Bizkarreko mina daukat* |
| Estou com dor nos pés | *Oinetako mina daukat* |

Outra forma muito comum, especialmente quando algo dói "agora mesmo":

- *Buruak min ematen dit.* — A cabeça me dói.

## Na consulta

| Português | Basco |
|---|---|
| O que você tem? / O que está acontecendo com você? | *Zer duzu?* / *Zer gertatzen zaizu?* |
| Desde quando? | *Noiztik?* |
| Está doendo? | *Min ematen dizu?* |
| Tome um comprimido a cada oito horas | *Hartu pilula bat zortzi orduro* |
| Descanse | *Hartu atseden* |
| Volte dentro de uma semana | *Itzuli astebete barru* |

## Profissionais e lugares

| Lugar / Pessoa | Basco |
|---|---|
| O posto de saúde | *anbulatorioa* |
| O hospital | *ospitalea* |
| Emergência | *larrialdiak* |
| O médico de família | *familia-medikua* |
| A enfermeira | *erizaina* |
| O farmacêutico | *botikaria* |
| A farmácia | *botika* / *farmazia* |
| Consulta marcada / agendada | *aurretiazko hitzordua* |

## Minidiálogo

> *— Egun on. **Zer duzu**?*
>
> *— **Sukarra daukat** atzotik, eta **buruko mina** ere bai.*
>
> *— Eztulik?*
>
> *— Bai, baina ez asko.*
>
> *— Ondo. **Hartu** pilula hauek **zortzi orduro**, eta **edan** ur asko. Hobeto ez bazaude, bihar etorri berriro.*

> **Nota cultural:** em Euskal Herria, o *"botikaria"* (farmacêutico/a) continua sendo, em muitas cidades pequenas, a primeira consulta para problemas leves: resfriados, picadas, tonturas. A farmácia funciona como um filtro antes do médico de família.
