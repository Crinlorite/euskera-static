O **caso NORA** (também chamado de *adlativo*) marca **o destino** de um movimento: para onde você vai. Em português, traduz-se normalmente com a preposição **"a"** ou **"para"** ("vou *para* casa", "*para* Bilbao", "*ao* parque").

## A pergunta: Nora?

| Pergunta | Português |
|---|---|
| ***Nora* zoaz?** | Aonde você vai? |
| ***Nora* doa?** | Aonde ele/ela vai? |
| ***Nora* goaz?** | Aonde nós vamos? |
| ***Nora* doaz?** | Aonde eles/elas vão? |

## O sufixo: -ra

Para responder, adicionamos **`-ra`** ao lugar de destino. O padrão se adapta dependendo de como a palavra termina:

| Final do lugar | Padrão | Exemplo |
|---|---|---|
| -a (orgânico, *eskola*) | + ra | eskola → **eskolara** |
| Vogal sem -a final (*Bilbo*, *etxe*) | + ra | etxe → **etxera**, Bilbo → **Bilbora** |
| Consoante (*Madril*, *Gasteiz*) | + era | Madril → **Madrilera**, Gasteiz → **Gasteizera** |

## Tabela de exemplos

| Lugar | Forma -ra | Frase modelo |
|---|---|---|
| etxe (casa) | **etxera** | *Etxera noa.* — Vou para casa. |
| eskola | **eskolara** | *Eskolara doaz.* — Vão para a escola. |
| euskaltegi | **euskaltegira** | *Euskaltegira goaz.* — Vamos ao euskaltegi. |
| taberna | **tabernara** | *Tabernara zoaz?* — Você vai ao bar? |
| lan (trabalho) | **lanera** | *Lanera nator.* — Venho para o trabalho. (igualmente -era após consoante) |
| Bilbo | **Bilbora** | *Bilbora doa.* — Ele/ela vai para Bilbao. |
| Donostia | **Donostiara** | *Donostiara goaz asteburuan.* — Vamos para Donostia no fim de semana. |
| Madril | **Madrilera** | *Madrilera doaz.* — Eles/elas vão para Madri. |
| mendi (monte) | **mendira** | *Mendira goaz larunbatean.* — Vamos ao monte no sábado. |

> **Minidica:** *non* → *nora* seguem o mesmo padrão que *kale-an* → *kale-ra*. Se você sabe formar *Bilbon* (em Bilbao), já sabe formar *Bilbora* (para Bilbao): troque *-n* por *-ra*. Se você sabe formar *Madrilen*, sabe formar *Madrilera*.

## Zertara? — "Para quê?"

Para perguntar **o que** você vai fazer (com que objetivo), usa-se **Zertara zoaz?** e se responde com um verbo + sufixo **`-tzera`**:

| Pergunta | Resposta |
|---|---|
| *Zertara zoaz tabernara?* | *Kafea hartzera.* — Tomar um café. |
| *Zertara doa Kepa supermerkatura?* | *Erostera.* — Fazer compras. |
| *Zertara goaz mendira?* | *Ibiltzera.* — Caminhar. |
| *Zertara doaz hondartzara?* | *Igeri egitera.* — Nadar. |

> **Padrão:** *(verbo no particípio) + -t(z)era*: *erosi → erostera*, *jan → jatera*, *ikasi → ikastera*, *ikusi → ikustera*, *bisitatu → bisitatzera*. É basicamente o "para + infinitivo" do português.

## Miniconversa

> — *Nora zoaz, Maialen?* — Aonde você vai, Maialen?
>
> — *Euskaltegira noa.* — Vou ao euskaltegi.
>
> — *Eta zertara?* — E fazer o quê?
>
> — *Klasera, noski! Euskara ikastera.* — Para a aula, claro! Aprender basco.
>
> — *Eta gero?* — E depois?
>
> — *Tabernara goaz lagunekin pote bat hartzera.* — Vamos ao bar com os amigos para tomar algo.

## Advérbios de direção

Os demonstrativos também têm sua forma NORA:

| NON (locativo) | NORA (direção) | Significado |
|---|---|---|
| hemen | **hona** | para cá |
| hor | **horra** | para aí |
| han | **hara** | para lá |

- **Hona zatoz?** — Você vem para cá?
- **Hara doaz.** — Eles/elas vão para lá.

> **Lembrete importante:** confunde muita gente no início: *etxean* (em casa) ≠ *etxera* (para casa) ≠ *etxetik* (de casa, lição 04). As três se parecem porque todas falam de "casa", mas a informação é totalmente diferente. Marque mentalmente: **NON = -an (estar)**, **NORA = -ra (ir)**, **NONDIK = -tik (vir, lição 4)**.
