Para encerrar a unidade, nos falta uma peça: **como você se move**. Em português, usamos "de + transporte" ("de carro", "de ônibus"). No basco, usa-se o sufixo **`-z`** (caso *instrumental*), que é adicionado ao meio de transporte e, surpreendentemente, também à palavra para "pé".

## A pergunta

| Pergunta | Português |
|---|---|
| ***Nola* zoaz?** | Como você vai? |
| ***Zerez* zoaz?** | Com que (meio) você vai? |
| ***Nola* doa Iruñera?** | Como ele/ela vai para Pamplona? |

As duas formas (*Nola* e *Zerez*) são válidas e frequentes. *Nola* é mais geral; *zerez* implica diretamente "com que meio".

## Os meios de transporte

| Meio | Forma com -z | Português |
|---|---|---|
| oin (pé) | **oinez** | a pé |
| kotxe / auto | **kotxez** / **autoz** | de carro |
| autobus | **autobusez** | de ônibus |
| tren | **trenez** | de trem |
| metro | **metroz** | de metrô |
| taxi | **taxiz** | de táxi |
| bizikleta | **bizikletaz** | de bicicleta |
| motor | **motorrez** | de moto |
| hegazkin | **hegazkinez** | de avião |
| itsasontzi | **itsasontziz** | de barco |
| furgoneta | **furgonetaz** | de van |
| zaldi (cavalo) | **zaldiz** | a cavalo |

> O sufixo é **`-z`** depois de vogal e **`-ez`** depois de consoante (*autobus → autobusez*). Na prática, quase todos os nomes de transporte terminam em vogal, então a fórmula básica é: **meio + z**.

## Exemplos completos

- **Oinez noa lanera.** — Vou a pé para o trabalho.
- **Iruñera trenez goaz.** — Vamos para Pamplona de trem.
- **Bilbora hegazkinez doaz.** — Eles/Elas vão para Bilbao de avião.
- **Eskolara bizikletaz dator alaba.** — A filha vem para a escola de bicicleta.
- **Mendira oinez igotzen gara.** — Subimos a pé ao monte.

## Combinando NONDIK + NORA + NOLA

Uma frase típica de viagem costuma ter três partes: **de onde + para onde + como**.

- **Iruñetik Donostiara autobusez doa.** — Ele/Ela vai de Pamplona a Donostia de ônibus.
- **Bilbotik Madrilera trenez gatoz.** — Viemos de Bilbao a Madri de trem.
- **Etxetik euskaltegira oinez noa.** — Vou de casa para o euskaltegi a pé.

## Miniconversa

> — *Aupa! Bihar Bilbora **noa**.* — Olá! Amanhã vou para Bilbao.
>
> — *Eta **nola** zoaz?* — E como você vai?
>
> — *Trenez. Oso erosoa da.* — De trem. É muito confortável.
>
> — *Ni autoz noa beti, baina garestia da gasolina.* — Eu vou sempre de carro, mas a gasolina está cara.

## Sobre "oinez"

À primeira vista, *oinez* parece um caso à parte ("com o pé"), mas na verdade é exatamente o mesmo padrão do resto: *oin* (pé) + *ez* (sufixo instrumental). O basco trata "ir a pé" como qualquer outro meio de transporte: usando o meio que te leva.

## Revisão final do bloco NORA / NONDIK / NOLA

| Pergunta | Sufixo | Pergunta-tipo | Resposta-tipo |
|---|---|---|---|
| **Nora?** | -ra | Para onde? | *Bilbo**ra** noa.* |
| **Nondik?** | -tik | De onde? | *Bilbo**tik** nator.* |
| **Nola? / Zerez?** | -z | Como? / Com quê? | *Tren**ez** noa.* |

> **Dica:** os três sufixos juntos formam quase qualquer frase de viagem. Por exemplo: *Bilbotik Donostiara autobusez goaz, lagun bat bisitatzera*. — "Vamos de Bilbao a Donostia de ônibus, para visitar um amigo." Se você dominar esses três sufixos + as formas sintéticas de *joan* e *etorri*, poderá falar sobre qualquer deslocamento do seu dia a dia.
