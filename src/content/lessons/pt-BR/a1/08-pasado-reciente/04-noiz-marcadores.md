Para contar bem o que aconteceu, você precisa dizer **quando**. Esta lição te dá os marcadores que se combinam com o passado recente para situar as ações no tempo.

## Os marcadores básicos

| Basco | Português |
|---|---|
| *gaur* | hoje |
| *atzo* | ontem |
| *bihar* | amanhã |
| *etzi* | depois de amanhã |
| *orain* | agora |
| *oraintxe* | agora mesmo |
| *lehen* | antes |
| *gero* | logo, depois |

> Se você reparou, *atzo* (ontem) e *bihar* (amanhã) são duas palavras tão curtas que se aprende de uma vez só. *Etzi* (depois de amanhã) é uma palavra que o português não tem em uma só peça — um pequeno presente do basco.

## Combinando com momentos do dia

Os marcadores se combinam com *goizean*, *arratsaldean*, *gauean* e companhia da unidade anterior. A fórmula é: **marcador + parte do dia**.

| Basco | Português |
|---|---|
| *gaur goizean* | esta manhã / hoje de manhã |
| *gaur eguerdian* | hoje ao meio-dia |
| *gaur arratsaldean* | esta tarde / hoje à tarde |
| *gaur gauean* | esta noite / hoje à noite |
| *atzo goizean* | ontem de manhã |
| *atzo arratsaldean* | ontem à tarde |
| *atzo gauean* | ontem à noite |
| *bihar goizean* | amanhã de manhã |

> **Atenção:** *gaur gauean* é "esta noite" (a noite que você tem pela frente ou a que está vivendo); *atzo gauean* é "ontem à noite". O basco distingue muito claramente.

## Frequência e vezes

| Basco | Português |
|---|---|
| *behin* | uma vez |
| *bi aldiz* | duas vezes |
| *hiru aldiz* | três vezes |
| *askotan* | frequentemente, muitas vezes |
| *batzuetan* | às vezes |
| *inoiz ez* | nunca |
| *gaur goizetik* | desde esta manhã |
| *aste honetan* | esta semana |
| *hilabete honetan* | este mês |

## Frases com passado recente e marcadores

> *Gaur goizean lanera joan naiz autoz.* — Esta manhã fui ao trabalho de carro.
>
> *Gaur arratsaldean Mikelekin egon naiz.* — Esta tarde estive com Mikel.
>
> *Gaur oso berandu esnatu naiz.* — Hoje acordei muito tarde.
>
> *Gaur eguerdian etxean bazkaldu dut.* — Hoje ao meio-dia almocei em casa.
>
> *Aste honetan bi aldiz egon naiz zinean.* — Esta semana estive duas vezes no cinema.

## A ordem da frase

Em basco, a ordem típica de uma frase com marcador de tempo é:

> **QUANDO + ONDE + O QUÊ + VERBO**

> **Gaur goizean** + **euskaltegian** + **euskara** + **ikasi dut**. — Esta manhã estudei basco no euskaltegi.

Não é a única possibilidade — o basco permite mover os elementos para enfatizar — mas se você seguir esta ordem, não tem erro.

## Miniconversa

> *— Eta gaur zer egin duzu, Maialen?*
>
> *— **Gaur goizean** lanera joan naiz oinez. **Eguerdian** lagunekin bazkaldu dut tabernan. **Arratsaldean** etxera bueltatu naiz eta liburua irakurri dut. **Gauean** ez dut afaldu, asko jan baitut bazkarian.*

> **Nota:** *gaur* abrange todo o dia atual. Se quiser especificar, adicione o momento (*gaur goizean*, *gaur arratsaldean*). Em conversas comuns, *Zer egin duzu gaur?* é entendido como "o que você fez hoje em geral?".
