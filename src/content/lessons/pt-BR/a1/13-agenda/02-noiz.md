Para falar sobre planos, é preciso dominar os marcadores temporais. Aqui estão os do eixo passado-presente-futuro e os mais usados para o futuro próximo.

## O eixo básico

| Euskera | Português |
|---|---|
| *atzo* | ontem |
| *gaur* | hoje |
| *bihar* | amanhã |
| *etzi* | depois de amanhã |
| *etziluma / etzidamu* | "depois de depois de amanhã" (pouco usado) |

Três palavras curtas (*atzo, gaur, bihar*) e *etzi* — com isso você resolve quase qualquer conversa cotidiana sobre datas.

## `Datorren` (que vem)

Para falar sobre "a próxima semana", "o próximo mês", usa-se **datorren** + substantivo:

| Euskera | Português |
|---|---|
| *datorren astean* | na semana que vem |
| *datorren astelehenean* | na segunda-feira que vem |
| *datorren hilean* | no mês que vem |
| *datorren urtean* | no ano que vem |

`Datorren` significa "que vem" (é a forma relativa do verbo *etorri*, vir). O importante é aprendê-lo como um bloco.

## "Este/esta" — `hau` / `honetan`

Para "esta semana", "este fim de semana":

- *aste honetan* — esta semana
- *asteburu honetan* — este fim de semana
- *hilabete honetan* — este mês

## Outros marcadores-chave

| Euskera | Português |
|---|---|
| *orain* | agora |
| *gero* | logo, depois |
| *lehen* | antes |
| *gaur goizean* | hoje de manhã |
| *gaur arratsaldean* | hoje à tarde |
| *gaur gauean* | hoje à noite |
| *bihar goizean* | amanhã de manhã |

> *Goiza* = manhã (parte do dia). *Bihar* = amanhã (dia seguinte). São duas palavras diferentes, não as confunda!

## Fazer perguntas sobre o tempo

- **Noiz?** — Quando?
- **Noiz etorriko zara?** — Quando você virá?
- **Noiz egingo dugu afaria?** — Quando faremos o jantar?

## Exemplos em contexto

- *Bihar mendira joango naiz.* — Amanhã irei ao monte.
- *Etzi euskara klasea dut.* — Depois de amanhã tenho aula de basco.
- *Datorren astean lan asko izango dut.* — Na semana que vem terei muito trabalho.
- *Asteburu honetan ez dut planik.* — Neste fim de semana não tenho planos.

> **Nota cultural:** em basco, "manhã" como parte do dia é *goiza* e "amanhã" como o dia seguinte é *bihar*. A frase *bihar goizean* ("amanhã de manhã") junta as duas. Nas primeiras conversas, é muito comum errar essa nuance, então convém fixá-la desde o início.
