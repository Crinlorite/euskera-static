Eth patron finau dera vida adulta: **era papièra**. Respira: damb dètz paraules ben triades (*agiria, hitzordua, bete, epea…*) sobreviues a quinsevolh finestrèla — en basc, ath delà, damb un sorríder deth foncionari de regal.

## Eth vocabulari dera papièra

| Castelhan | Basc |
|---|---|
| Er ajuntament | *udaletxea* |
| Eth padron / empadronar-se | *errolda / erroldatu* |
| Eth certificat d'empadronament | *errolda-agiria* |
| Eth document / certificat | *agiria* |
| Eth DNI | *NANa* |
| Eth permés de condusir | *gidabaimena* |
| Era sollicitud | *eskabidea* |
| Emplenar | *bete* |
| Eth rendètz-vos / eth torn | *hitzordua / txanda* |
| Eth termini | *epea* |
| Era finestrèla | *leihatila* |

## Demanar un rendètz-vos (eth rituau modèrne)

> ***Hitzordua eskatu behar da** aurretik, webgunean edo telefonoz.* — Cau demanar un rendètz-vos abans, ena web o per telefòn.
>
> *Hitzordua daukat **gaurko, hamaiketan**, erroldarako.* — È un rendètz-vos entà aué, a onze ores, entad eth padron.

## Ena finestrèla

> *— Egun on. **Errolda-agiri bat behar dut**, banketxerako.*
>
> *— **NANa**, mesedez… Momentu bat… Tori, hemen duzu. **Doan da**.*
>
> *— Eskerrik asko! Eta beste kontu bat: etxez aldatu naiz. **Erroldatzeko**, zer egin behar dut?*
>
> *— **Eskabide hau bete** eta etxebizitzaren kontratua ekarri. **Fotokopiarik ez** da behar; guk egiten dugu.*
>
> *— Bikain. **Eperik badago**?*
>
> *— Ez, lasai, edonoiz etor zaitezke. Baina **hitzordua eskatu** lehenago, e!*

## Tres frases de supervivéncia

> ***Zer agiri ekarri behar ditut**?* — Quini documents è de portar?
>
> ***Noiz arte** daukat epea?* — D'ençà quan è de termini?
>
> ***Nork sinatu behar du**?* — Qui a de signar?

> **Nòta:** *hitzordua* ei literaument "ora dera paraula" (*hitza* + *ordua*) — eth rendètz-vos deth metge, der ajuntament o romantic: era madeisha paraula. Eth contèxte (e era cara que hès) hè era rèsta. 😄
