A2レベルでは、意見を述べることが**重要な能力**の一つです。このレッスンでは、以下を学びます：

1. 意見を切り出すための表現。
2. **-ela** を使った補文（〜ということ）。
3. **-enik** を使った意見の否定（〜とは思わない）。
4. **-lako** と **zeren** を使った原因・理由（なぜなら〜）。

## 意見を切り出す

| スペイン語 | バスク語 |
|---|---|
| 〜と思います | *Uste dut...* |
| 〜のように思えます | *Iruditzen zait...* |
| 私の意見では | *Nire ustez* |
| 私にとっては | *Niretzat* |
| 〜と知っています | *Badakit...* |
| 賛成です | *Ados nago* |
| 賛成ではありません | *Ez nago ados* |
| その通りです | *Arrazoia duzu* |
| 本当です | *Egia da* |

## -**ela** を使った補文

意見が別の文を導く場合、従属節の動詞には接尾辞 **-(e)la**（「〜ということ」）が付きます。変化は非常に規則的です：

| 接尾辞なし | -ela 付き | スペイン語 |
|---|---|---|
| *da* | *dela* | 〜であるということ / 〜いるということ |
| *naiz* | *naizela* | （私が）〜であるということ |
| *zara* | *zarela* | （君が）〜であるということ |
| *du* | *duela* | それを持っているということ |
| *ditu* | *dituela* | それらを持っているということ |
| *dut* | *dudala* | （私が）それを持っているということ |
| *zen* | *zela* | 〜だったということ |
| *nuen* | *nuela* | （私が）それを持っていたということ |
| *etorriko da* | *etorriko **dela*** | 来るだろうということ |

> *Uste dut Anboto pozik **dagoela**.* — Anbotoは喜んでいると思います。
>
> *Badakit gauza zailak gertatu **direla**.* — 難しいことが起こったと知っています。
>
> *Argi dago euskaraz hobeto hitz egiten **duela**.* — 彼がバスク語をより上手に話すことは明らかです。

## 意見の否定：-**enik**

「**〜とは思わない** + 動詞」と言う場合、従属節の接尾辞は **-enik** に変わります：

| スペイン語 | バスク語 |
|---|---|
| 良いとは思いません | *Ez dut uste ona **denik*** |
| 彼らが来るとは思いません | *Ez dut uste etorriko **direnik*** |
| 本当だとは思えません | *Ez zait iruditzen egia **denik*** |

> これは意見を表す動詞での否定の特定の形です。肯定文では *uste dut ona **dela***、否定文では *ez dut uste ona **denik*** となります。

## その他の意見表明の構文

これらの構文は、形容詞 + *da* + -ela を伴う文を組み合わせます：

| スペイン語 | バスク語 |
|---|---|
| 〜は明らかです | *Argi dago + -(e)la* |
| 〜は重要です | *Garrantzitsua da + -tzea* |
| 〜は本当です | *Egia da + -(e)la* |
| 〜は可能です | *Posible da + -tzea* |
| 〜は論理的です | *Logikoa da + -(e)la* |
| 〜は興味深いです | *Interesgarria da + -tzea* |

> *Argi dago ikasten ari **zarela**.* — あなたが勉強していることは明らかです。
>
> *Garrantzitsua da euskaraz **hitz egitea**.* — バスク語で話すことは重要です。

## 原因・理由：*-lako* と *zeren*

**原因**（「なぜなら」）を表すには、2つの方法があります：

### 接尾辞 -**lako**（従属節、最も一般的）

> **動詞 + -lako**

| スペイン語 | バスク語 |
|---|---|
| 来たので | *Etorri **delako*** |
| お腹が空いているので | *Goseak nagoelako* (o *gose naizelako*) |
| 重要なので | *Garrantzitsua **delako*** |
| 好きではないので | *Ez zaidalako gustatzen* |

> *Etxean nago **gaixorik nagoelako**.* — 病気なので家にいます。
>
> *Bilbora joaten naiz lana **bertan dudalako**.* — 仕事がそこにあるので、ビルバオに行きます。

### 接続詞 *zeren*（文頭で）

| スペイン語 | バスク語 |
|---|---|
| なぜなら重要だからです | *…, **zeren** garrantzitsua baita* |
| …、というのも彼が来たからです | *…, **zeren** etorri baita* |

> これはよりフォーマルまたは報道で使われる原因の表現方法です。話し言葉では *-lako* の方が好まれます。

## ミニディベート

> *— Olatz, **uste dut** Bilbo Donostia baino interesgarriagoa **dela**.*
>
> *— **Ez nago ados**. Donostia askoz politagoa da, **uste dut**, itsasoa **duelako** ondoan.*
>
> *— **Egia da** itsasoa duela, baina Bilbon **museo gehiago daudela ere egia da**.*
>
> *— Bai, baina **iruditzen zait** giroa, kalea, jendea... Donostian goxoagoak **direla**. Eta Donostiako pintxoak Bilbokoak **baino hobeak direla** ere bai!*

## 便利な構文リスト

| スペイン語 | バスク語 |
|---|---|
| 重要だと思います | *Garrantzitsua **dela** uste dut* |
| 彼が正しいと知っています | *Arrazoia **duela** badakit* |
| 彼らが来るとは思いません | *Ez dut uste etorriko **direnik*** |
| 彼が問題を抱えているのは明らかです | *Argi dago arazoak **dituela*** |
| 病気なので | *Gaixorik **dagoelako*** |
| 寒いので | *Hotz **egiten duelako*** |

## よくある間違い

1. **肯定文での -ela、意見の否定文での -enik という二つの側面を忘れないでください。**
2. **接尾辞 -ela は分詞ではなく、活用した動詞に付きます**：*etorriko da → etorriko **dela***。
3. **スペイン語では意見が非常に強い場合、接続法を使いますが**、バスク語には明確な区別がありません：*uste dut ondo dagoela*（良いと思う）と *zalantza dut ondo dagoenik*（良いかどうか疑わしい）は異なる形を使いますが、正式な「接続法」ではありません。

> **教育上の注意点：** *Nire ustez + 文 + -lako + 文* という形式は、A2レベルで意見を述べ、論じる上で最も効果的なツールでしょう。模範例：
>
> *Nire ustez **euskara ikastea garrantzitsua da** **gure herriaren hizkuntza delako**.*
> （「私の意見では、バスク語を学ぶことは重要です。なぜなら、それは私たちの民族の言語だからです」）
