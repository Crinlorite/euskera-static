このレッスンでは、A2レベルで非常に役立つ2つのブロックを学びます。

1. **感情**と心の状態（基本的なものはA1で学びました。ここではさらに広げます）。
2. 議論やニュアンスを加えるための**談話接続詞**：*gainera, hala ere, beraz, alde batetik...*

これでこのユニットは終わりです。より手の込んだ意見を述べるためのツールが身につきます。

## 感情：*egon* + 状態の形

一時的な感情のほとんどは、*egon* + 状態を表す形容詞または副詞で表現します。

| スペイン語 | バスク語 |
|---|---|
| 嬉しい | *Pozik nago* |
| 悲しい | *Triste nago* |
| 怒っている | *Haserre nago* |
| 緊張している | *Urduri nago* |
| 落ち着いている | *Lasai nago* |
| 退屈している | *Aspertuta nago* |
| 疲れている | *Nekatuta nago* |
| 恥ずかしい | *Lotsatuta nago* |
| 恋をしている | *Maitemindurik nago* |

> これはA1で学んだパターン（*pozik, triste, lasai*）に、*aspertuta, nekatuta, lotsatuta, maitemindurik* を加えたものです。

## *izan* を使う感情：*beldur naiz*

より深い感情の中には *izan* を使うものがあります。

| スペイン語 | バスク語 |
|---|---|
| 怖い | *Beldur naiz* |
| あなたは正しい | *Arrazoia duzu* |
| 好奇心がある | *Jakin-mina dut* |
| やる気がある | *Gogoa dut* / *Gogoz nago* |
| やる気がない | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — 車で行くのが怖いです。

## *NOR-NORI* を使う感情：*lotsa ematen dit*

バスク語らしい表現方法：感情が「あなたに与える」という形です。

| スペイン語 | バスク語 |
|---|---|
| 恥ずかしいです | *Lotsa ematen dit* |
| 残念です・かわいそうです | *Pena ematen dit* |
| 腹が立ちます | *Amorrua ematen dit* |
| 怖いです | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — それを言うのは恥ずかしいです。
>
> *Albiste horrek **pena handia ematen dit**.* — そのニュースはとても残念です。

## *Jartzen naiz / jarri naiz*

**状態の変化**（「緊張する、嬉しくなる、悲しくなる」）を表すには：

| スペイン語 | バスク語 |
|---|---|
| 私は緊張します | *Urduri **jartzen naiz*** |
| 彼は悲しくなりました | *Triste **jarri zen*** |
| 私たちは嬉しくなりました | *Pozik **jarri ginen*** |
| 彼はささいなことで怒ります | *Edozergatik haserretzen da* |

## よく使われる心理動詞

| 動詞 | 意味 |
|---|---|
| *gustatu* | 好きである |
| *maite izan* | 愛する |
| *gorrotatu* / *higuindu* | 憎む |
| *beldurtu* | 怖がる |
| *aspertu* | 退屈する |
| *haserretu* | 怒る |
| *lasaitu* | 落ち着く |
| *poztu* | 喜ぶ |
| *triste jarri* / *atsekabetu* | 悲しむ |
| *kezkatu* | 心配する |

> *Asko **maite ditut** nire gurasoak.* — 私は両親をとても愛しています。
>
> *Ez **kezkatu**, dena ondo aterako da.* — 心配しないで、すべてうまくいきます。

## 談話接続詞

意見や議論を組み立てるために：

### 追加

| スペイン語 | バスク語 |
|---|---|
| さらに | *gainera* |
| そして〜も | *eta baita ere* / *...ere* |
| 特に | *batez ere* |

> *Gainera, prezioa ere ona da.* — さらに、値段も良いです。

### 原因・結果

| スペイン語 | バスク語 |
|---|---|
| したがって | *beraz* |
| だから | *horregatik* |
| その理由で | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — 遅いので、行きます。

### 対比・反対

| スペイン語 | バスク語 |
|---|---|
| しかしながら | *hala ere* |
| しかし | *baina* |
| 一方で | *bestetik* |
| その代わりに | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — 遅いですが、それでも来ます。

### 談話の構成

| スペイン語 | バスク語 |
|---|---|
| 一方では…他方では… | *Alde batetik... bestetik...* |
| まず…次に… | *Lehenengo... gero...* |
| 最後に | *Azkenik* |
| 要約すると | *Laburbilduz* |

## A2レベルの並列構造

これらはA2レベルの試験によく出てくる構文です。

| スペイン語 | バスク語 |
|---|---|
| 〜も〜もない | *Ez... ez...* |
| 〜も〜も両方 | *Bai... bai...* / *Hala... nola...* |
| 〜だけでなく〜も | *Ez bakarrik..., baita ere...* |
| 〜もまた（含めて） | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — AnbotoもOlatzも来ませんでした。
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — 午前も午後も働かなければなりません。

## 意見文のミニテキスト

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## A2レベルのコツ：「意見の骨格」

A2レベルで意見を求められたら、このテンプレートに従ってください。

> **1. Nire ustez** + テーマ + **-(e)la**.
>
> **2. Alde batetik**, + 理由1 + **-lako**.
>
> **3. Bestetik**, + 理由2.
>
> **4. Hala ere**, + ニュアンス.
>
> **5. Beraz**, + 結論.

これでA2レベルの完全な段落が作れます。

> **文化メモ：**多くの公式A2テキスト（編集者への手紙、フォーラム、試験の作文）では、この議論の構成が求められます。日常的なテーマで練習しましょう：スポーツ、食事、SNS、仕事、村祭りなど。
