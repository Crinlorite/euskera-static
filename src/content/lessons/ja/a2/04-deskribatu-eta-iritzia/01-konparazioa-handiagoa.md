何かを比べることは、言葉を使う上で最も日常的な行為の一つです。『*これはあれより大きい*』、『*私はあなたより背が低い*』、『*トルティーヤは昨日よりおいしい*』など。バスク語では、この形式は非常に規則的で、一度マスターすれば、たくさんの新しい文が作れるようになります。

## 基本の形

> **X baino Y-AGO(A)**

- **baino** は比較される2つのものの間に置かれます。これは「〜より」に相当します。
- **-ago** は形容詞や副詞に付きます（英語の "-er" のようなものです）。
- 定冠詞の付いた名詞と使われる場合、形容詞には通常の **-a** が付きます。例：*altuago**a***。

| スペイン語 | バスク語 |
|---|---|
| より大きい | *handi**agoa*** |
| より小さい | *txiki**agoa*** |
| より高い（値段が） | *garesti**agoa*** |
| よりきれいな | *polit**agoa*** |
| より速い | *azkar**agoa*** |

## 例文

| スペイン語 | バスク語 |
|---|---|
| LanderはOlatzより背が高い | *Lander Olatz **baino** altu**agoa** da* |
| この家はあの家より大きい | *Etxe hau hura **baino** handi**agoa** da* |
| ビルバオはドノスティアより大きい | *Bilbo Donostia **baino** handi**agoa** da* |
| コーヒーは紅茶より高い | *Kafea tea **baino** garesti**ago** dago* |
| Garaziは私より速く走る | *Garazik nik **baino** azkarrago **egiten du korrika*** |

> **語順：** バスク語では、「〜より」にあたる *baino* は、形容詞の後ではなく、比較される2つのものの間に来ます。**X baino Y-agoa** は文字通りには「X より Y-もっと」となります。

## 不規則な形容詞

いくつかの形容詞は規則通りに変化しないため、覚える必要があります。

| スペイン語 | バスク語 |
|---|---|
| 良い → より良い | *ona → **hobea*** |
| 悪い → より悪い | *txarra → **okerragoa*** |
| たくさん → もっと多く | *asko → **gehiago*** |
| 少し → もっと少なく | *gutxi → **gutxiago*** |

> *Liburu hau hura **baino hobea** da.* — この本はあの本より良いです。
>
> *Garazik nik **baino gehiago** ikasten du.* — Garaziは私よりもっと勉強します。

## 動詞との比較

**行動**や**量**を比較する場合、*gehiago / gutxiago* は副詞として機能します。

| スペイン語 | バスク語 |
|---|---|
| 私はあなたより多く働く | *Zuk **baino gehiago** lan egiten dut* |
| 彼は以前より勉強しない | *Lehen **baino gutxiago** ikasten du* |
| 私は野菜より果物を多く食べる | *Barazkiak **baino fruta gehiago** jaten dut* |

> *Gehiago* と *gutxiago* は動詞や修飾される名詞の**前**に置かれ、*baino* は変わらず比較される2つのものの間に来ます。

## 副詞との比較

| 副詞 | 比較級 |
|---|---|
| *azkar* (速く) | *azkarrago* |
| *poliki* (ゆっくり) | *polikiago* |
| *ondo* (良く) | *hobeto* (不規則) |
| *gaizki* (悪く) | *okerrago* |
| *berandu* (遅く) | *beranduago* |
| *goiz* (早く) | *goizago* |

> *Hobeto egiten duzu lan.* — あなたはもっと上手に仕事をしますね。
>
> *Goizago etorriko naiz bihar.* — 明日はもっと早く来ます。

## 否定：「〜より少なく」

「〜より少なく」を表すには、**gutxiago + baino** という形が自然です。

> *Lander nik baino **gutxiago** lan egiten du.* — Landerは私より働きません。

または、比較を逆にして表現することもできます。

> *Olatz Lander baino **txikiagoa** da.* （= LanderはOlatzより背が高い、を逆の形で表現したもの。）

## *hain* を使った否定 — 「〜ほど〜ない」

これは非常によく使われる形です。

| スペイン語 | バスク語 |
|---|---|
| それほど高くない | *Ez da **hain** garestia* |
| それほど速くない | *Ez **hain** azkar* |
| あなたが思っていたほど大きくない | *Ez da uste zenuen **bezain** handia* |

> *Hain* は「それほど」（= このくらい）という意味で使われます。*ez* と組み合わせることで、比較の表現を和らげることができます。

## ミニ会話

> *— Anboto, etxe berria zer moduz?*
>
> *— Aurrekoa **baino handiagoa** da, eta argia ere **askoz argiagoa** da. Baina logelak **txikiagoak** dira.*
>
> *— Eta kalea?*
>
> *— Lehen baino **lasaiagoa**: ez dago **hainbeste** autorik.*

## 記憶のコツ

この形をひとつの塊として覚えましょう。

> **X baino Y-agoa da.**

そして不規則形は **hobea, okerragoa, gehiago, gutxiago**。これだけでA2レベルの優等比較の95%はカバーできます。

> **文化メモ：** 日常会話では、*askoz handiagoa*（ずっと大きい）、*pixka bat handiagoa*（少し大きい）、*dezente handiagoa*（かなり大きい）のように、比較を強調する表現も耳にします。これらは厳密にはA2レベルではありませんが、あらゆる会話で使われるニュアンスです。
