このレッスンでは、比較の仲間を2つの要素で完成させます：

1. **同等** (「〜と同じくらい…」): *bezain*, *adina*, *beste*。
2. **最上級** (「最も…」): *-en + a*。

## 同等: *bezain*

形容詞や副詞を使った「〜と同じくらい…」の場合：

> **X bezain Y**

| 日本語 | バスク語 |
|---|---|
| 君と同じくらい背が高い | *Zu **bezain** altua* |
| ドノスティアと同じくらい美しい | *Donostia **bezain** polita* |
| 彼の父親と同じくらい良い | *Aita **bezain** ona* |
| 思っていたほど速くない | *Uste nuen **bezain** azkarra ez da* |

> 文全体: *Lander **zu bezain altua** da.* — ランデルは君と同じくらい背が高いです。

## 量の同等: *adina / beste*

名詞や量を使った「〜と同じくらい」の場合：

| 日本語 | バスク語 |
|---|---|
| 君と同じくらい | *Zuk **adina*** / *Zuk **beste*** |
| 私と同じくらいのお金 | *Nik **adina** diru* |
| アンボトと同じくらいの年月 | *Anbotok **adina** urte* |

> *Zuk adina urte ditut.* — 私は君と同じくらいの年齢です。
>
> *Garazik nik beste irakurtzen du.* — ガラシは私と同じくらい読みます。

> **違い:** *bezain* は性質（形容詞/副詞）と共に使います。*Adina/beste* は量（数えられる名詞や量）と共に使います。時々間違えられますが、実践的なルールは次の通りです：続く単語が**形容詞**なら → *bezain*、**名詞や数**なら → *adina/beste*。

## 様態の比較: *bezala / moduan*

もう一つの同等の形、今回は**様態**や**方法**です：

| 日本語 | バスク語 |
|---|---|
| 君のように | *Zu **bezala*** / *Zure **moduan*** |
| 君がしたようにする | *Zuk egin duzun **moduan** egiten dut* |
| 君の家のような家 | *Zurea **bezalako** etxea* |
| 母親のように話す | *Amaren **moduan** hitz egiten du* |

> 比較してみましょう：
>
> - *Zu **bezain** altua* — 君と同じくらい背が高い (性質)
> - *Zu **bezala** hitz egiten du* — 君のように話す (様態)
> - *Zuk **adina** ikasten du* — 君と同じくらい勉強する (量)

## 最上級: *-en + a*

「最も…」を表すには、形容詞や副詞に **-en** を付け、定冠詞 **-a** を加えます：

| 形容詞 | 最上級 |
|---|---|
| *handia* (大きい) | *handi**ena*** (最も大きい) |
| *txikia* (小さい) | *txiki**ena*** |
| *polita* (美しい) | *polit**ena*** |
| *zaharra* (古い) | *zaharr**ena*** |
| *azkarra* (速い) | *azkarr**ena*** |
| *garestia* (高価な) | *garesti**ena*** |
| *ona* (良い) | **onena** / **hoberena** (不規則) |
| *txarra* (悪い) | **txarrena** / **okerrena** |

> *Liburu hau **politena** da.* — この本は最も美しいです。
>
> *Donostia Euskal Herriko hiri **politena** da, askoren ustez.* — ドノスティアは多くの人によれば、バスク地方で最も美しい都市です。

## 最上級 + グループ: *-etan / -etako*

**どのグループの中で**かを示す場合、場所格または属格を使います：

| 日本語 | バスク語 |
|---|---|
| クラスで一番背が高い | *Klaseko **altuena*** |
| 世界で一番速い | *Munduko **azkarrena*** |
| すべての中で一番良い | *Denetan **onena*** / *Guztietan **onena*** |
| 日々の中で最悪の | *Egunetan **txarrena*** |

> *Klaseko ikasle **azkarrena** da.* — 彼はクラスで一番速い生徒です。
>
> *Euskal Herriko mendi **altuena** Hiru Errege Mahaia da.* — バスク地方で最も高い山はイル・エレーゲ・マハイア（三王のテーブル）です。

## *Gehien / gutxien* — 最も多く / 最も少なく

量や頻度の最上級に相当します：

| 日本語 | バスク語 |
|---|---|
| 私が一番好きなこと | *Gehien gustatzen zaidana* |
| 私が一番しないこと | *Gutxien egiten dudana* |
| 一番勉強する人 | *Gehien ikasten duena* |

## 文化のミニ比較

典型的なフレーズ：

- *Hiru Errege Mahaia Euskal Herriko mendi **altuena** da.* — イル・エレーゲ・マハイア（三王のテーブル）はバスク地方で最も高い山です。
- *Korrika euskararen aldeko ekintza **handiena** da.* — コリカはバスク語を支持する最大の活動です。
- *San Fermin festa famatuena da.* — サン・フェルミンは最も有名なお祭りです。

## 覚えるためのヒント

| 形 | 例 |
|---|---|
| 比較級 (…よりX) | *X baino Y-**agoa*** |
| 同等 (…と同じくらいX) | *Y bezain X* |
| 量の同等 (…と同じくらい) | *Yk adina X* |
| 最上級 (最もX) | *X-**ena*** |
| グループ内での最上級 | *Z-ko / Z-etan + X-**ena*** |

## ミニ会話

> *— Anboto, hau bai pintxoa! Sekula jan dudan **goxoena**.*
>
> *— Bai, **zure ustez** Bilboko **onenak** non daude?*
>
> *— Plaza Berrian. Han pintxoak **garestienak** dira, baina **goxoenak** ere bai. Donostiakoak ere ez dira **gutxiago**: ia **maila berekoak** dira.*

> **文化メモ:** *Euskal Herri*（バスク地方）の典型的な議論では、「ドノスティアのピンチョスはビルバオのものより美味しい」(*Donostiako pintxoak Bilbokoak baino hobeak dira*) は、お決まりの和やかな話題です。実際には、各地域が自分たちのものを擁護し、どれも非常に美味しいです。
