新しいユニット：**実用的な生活**。毎日旅行する人はいなくても、銀行や郵便局には誰でも行くものです。そこから始めましょう。A1レベルで学んだ数字や値段、*nahi dut*、*behar dut*などを、どれだけ再利用できるか見ていきましょう…

## 銀行で (banketxea)

| スペイン語 | バスク語 |
|---|---|
| 口座 | *kontua* |
| 口座を開設する | *kontua ireki / zabaldu* |
| お金を引き出す | *dirua atera* |
| お金を入金する | *dirua sartu* |
| 振込 | *transferentzia* |
| カード | *txartela* |
| ATM | *kutxazaina* |
| 手数料 | *komisioa* |

> *Egun on, **kontu bat ireki nahi nuke**.* — おはようございます、口座を開設したいのですが。
>
> ***Transferentzia bat egin behar dut** Alemaniara. **Komisiorik badago**?* — ドイツに送金する必要があります。手数料はかかりますか？
>
> *Kutxazaina **hondatuta dago**; barruan atera dezakezu dirua.* — ATMは故障しています。中で現金を引き出せますよ。

*Hondatuta dago* = 故障している。ATMや券売機、ビルバオの傘などに使える便利な言葉です。

## 郵便局で (postetxea)

| スペイン語 | バスク語 |
|---|---|
| 手紙 | *gutuna* |
| 小包 | *paketea* |
| 切手 | *zigilua* |
| 送る／受け取る | *bidali / jaso* |
| 書留 | *ziurtagiriarekin* |
| 郵便ポスト | *postontzia* |

> *Pakete hau **bidali nahi dut** Iruñera. **Zenbat balio du**?* — この小包をパンプローナに送りたいです。いくらですか？
>
> *— **Arrunta ala ziurtagiriarekin**?* — 普通郵便ですか、それとも書留にしますか？
>
> *— Ziurtagiriarekin, mesedez. Garrantzitsua da.*
>
> *— Ederki. **Hemen sinatu**, mesedez.* — 結構です。ここに署名をお願いします。

## 小包の通知 (あの不在票のことです)

> *«Zure paketea **postetxean jaso dezakezu**, astelehenetik ostiralera, 8:30etik 14:30era. **NANa ekarri**, mesedez.»* — 小包は郵便局で受け取れます。月曜日から金曜日の8:30から14:30までです。身分証明書（DNI）をお持ちください。

そう、午前中だけです。どの言語でも同じことがありますね。😄

## 会話全体

> *— Egun on! Pakete bat **jasotzeko** etorri naiz. Hau da abisua.*
>
> *— Egun on. **NANa**, mesedez… Bai, hemen dago. **Hemen sinatu**.*
>
> *— Bide batez, **hiru zigilu** ere nahi ditut, gutun batzuk bidaltzeko.*
>
> *— Noski. **Guztira, 5,20 euro**. Txartelaz ala eskudirutan?*
>
> *— **Txartelaz**, mesedez.*
