紙からピクセルへ：**日常のテクノロジー**のレッスンです。一日に何度も使う単語を、今度はバスク語で学びましょう。バスク語には、分かりやすく巧みに作られた単語がたくさんあります（*pasahitza* = 通るための言葉; *sakelakoa* = 「ポケットのもの」）。

## 機器

| スペイン語 | バスク語 |
|---|---|
| パソコン | *ordenagailua* |
| ノートパソコン | *eramangarria* |
| 携帯電話 / スマホ | *mugikorra / sakelakoa* |
| タブレット | *tableta* |
| 画面 | *pantaila* |
| キーボード | *teklatua* |
| マウス | *sagua* （そう、動物のネズミです！） |
| イヤホン / ヘッドホン | *entzungailuak* |

## ネットとアカウント

| スペイン語 | バスク語 |
|---|---|
| ネット / インターネット | *sarea / internet* |
| Wi-Fi | *wifia* |
| メール / Eメール | *posta elektronikoa* |
| ユーザー | *erabiltzailea* |
| パスワード | *pasahitza* |
| アプリ | *aplikazioa* |
| ウェブサイト | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Wi-Fiのパスワードは何ですか？
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — パスワードを忘れてしまったので、新しいものを作らなければなりません。またです。
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — アカウントを作成するには、メールアドレスとパスワードが必要です。

## デジタル関連の動詞

| スペイン語 | バスク語 |
|---|---|
| 電源を入れる / 切る | *piztu / itzali* |
| ダウンロードする | *deskargatu / jaitsi* |
| インストールする | *instalatu* |
| 保存する | *gorde* |
| 削除する | *ezabatu* |
| 送信する / 共有する | *bidali / partekatu* |
| （ネットで）検索する | *bilatu* |
| 動く / 機能する | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — パソコンの調子が悪いです。電源を切ってからまた入れてみてください。いつもの解決策です。
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — 写真は保存しましたか？何も削除しないでください！
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — アプリをダウンロードして、アカウントを作成すれば、それで完了です。

## 会話：家族のテクニカルサポート

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **注：**デジタルの世界でもバスク語は活発です。フリーソフトやバスク語版ウィキペディアは非常に充実しており、お使いのスマホ全体をバスク語表示にすることもできます（*Ezarpenak → Hizkuntza*）。実際に設定してみるのは、毎日無料で言語に浸れる、非常に効果的な学習法です。
