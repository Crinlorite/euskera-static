大人社会のラスボス、それは**書類手続き**。深呼吸してください。いくつかの重要な単語 (*agiria, hitzordua, bete, epea…*) さえ覚えておけば、どんな窓口でも乗り切れます — しかもバスク語で話せば、窓口の担当者が笑顔のおまけまで付けてくれるかもしれません。

## 書類手続きのボキャブラリー

| 日本語 | バスク語 |
|---|---|
| 市役所 | *udaletxea* |
| 住民登録 / 住民登録する | *errolda / erroldatu* |
| 住民登録証明書 | *errolda-agiria* |
| 書類 / 証明書 | *agiria* |
| 身分証明書 (DNI) | *NANa* |
| 運転免許証 | *gidabaimena* |
| 申請書 | *eskabidea* |
| 記入する | *bete* |
| 予約 / 順番 | *hitzordua / txanda* |
| 期限 | *epea* |
| 窓口 | *leihatila* |

## 予約を取る（現代の儀式）

> ***Hitzordua eskatu behar da** aurretik, webgunean edo telefonoz.* — 事前に、ウェブサイトか電話で予約を取る必要があります。
>
> *Hitzordua daukat **gaurko, hamaiketan**, erroldarako.* — 今日の11時に、住民登録の予約をしています。

## 窓口にて

> *— Egun on. **Errolda-agiri bat behar dut**, banketxerako.*
>
> *— **NANa**, mesedez… Momentu bat… Tori, hemen duzu. **Doan da**.*
>
> *— Eskerrik asko! Eta beste kontu bat: etxez aldatu naiz. **Erroldatzeko**, zer egin behar dut?*
>
> *— **Eskabide hau bete** eta etxebizitzaren kontratua ekarri. **Fotokopiarik ez** da behar; guk egiten dugu.*
>
> *— Bikain. **Eperik badago**?*
>
> *— Ez, lasai, edonoiz etor zaitezke. Baina **hitzordua eskatu** lehenago, e!*

## 生き残るための3フレーズ

> ***Zer agiri ekarri behar ditut**?* — どの書類を持ってくる必要がありますか？
>
> ***Noiz arte** daukat epea?* — 期限はいつまでですか？
>
> ***Nork sinatu behar du**?* — 誰が署名する必要がありますか？

> **注：** *hitzordua* は文字通り「言葉の時間」(*hitza* + *ordua*) という意味です。病院の予約、市役所の予約、デートの約束など、すべて同じ単語で表現します。文脈（とあなたの表情）が意味を決定します。😄
