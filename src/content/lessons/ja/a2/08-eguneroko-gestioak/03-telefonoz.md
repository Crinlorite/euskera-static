他の言語で電話で話すのは緊張しますよね — 顔が見えず、ジェスチャーもありませんから。だからこそ、このレッスンは**決まり文句のオンパレード**です。フォーマルな電話からWhatsAppの音声メッセージまで、いつでも使える定番フレーズを学びましょう。

## 電話に出て、尋ねる

| スペイン語 | バスク語 |
|---|---|
| もしもし？ | *Bai, esan?* |
| どなたですか？ | *Nor da?* |
| Aneはいますか？ | *Ane dago?* |
| Mikelです | *Mikel naiz* |
| 少々お待ちください、今代わります | *Une batez, orain jarriko da* |
| 今はいません | *Orain ez dago* |

## 電話に出られないとき

> *— Kaixo, **Ane dago**?*
>
> *— Ez, **orain ez dago**. Zerbait **esan behar diot**?*
>
> *— Bai, mesedez: bilera **bihar dela**, ez gaur. Edo hobeto: **deituko didala**, libre dagoenean.*
>
> *— Ederki, **esango diot**. Nor zarela esango diot?*
>
> *— **Mikel naiz**, lanekoa. Eskerrik asko!*

見てみましょう。*esan behar diot* (彼/彼女に言わなければならない)、*esango diot* (彼/彼女に言うつもりだ)、*deituko didala* (私に電話してくれるように) — ユニット03で学んだNOR-NORI-NORKが電話の会話で大活躍です。「電話をかける」は *deitu* + NORIです。*deitu diot* (彼/彼女に電話した)、*deituko dizut* (君に電話するよ)。

## 技術的な問題（よくあるやつ）

| スペイン語 | バスク語 |
|---|---|
| 話し中です | *Komunikatzen ari da* |
| 電波がありません | *Estaldurarik ez dago* |
| バッテリーが切れました | *Bateria gabe geratu naiz* |
| よく聞こえません | *Gaizki entzuten da* |
| 電話が切れました | *Deia moztu da* |
| 番号間違いです | *Okerreko zenbakia* |

> *Barkatu, **gaizki entzuten da**. Igogailuan nago — **gero deituko dizut**!* — すみません、よく聞こえません。エレベーターの中にいるので、後でかけ直します！

## メッセージ（現代の暮らし）

> ***Mezu bat bidali dizut** WhatsAppez.* — WhatsAppでメッセージを送りました。
>
> ***Audioa entzun duzu**?* — 音声メッセージは聞きましたか？
>
> *Deitu beharrean, **idatzi**, mesedez: bileran nago.* — 電話ではなく、メッセージをください。会議中なので。

## 留守番電話 / アナウンス

> *«Kaixo! Orain ezin dut telefonoa hartu. **Utzi mezua** seinalearen ondoren, eta **lehenbailehen deituko dizut**. Eskerrik asko!»* — もしもし！ただ今電話に出ることができません。発信音の後にメッセージを残してください。折り返し、できるだけ早くお電話します。ありがとうございます！

*Lehenbailehen* = できるだけ早く。あなたのバスク語レベルが2ポイントアップする、エレガントな単語です。😄
