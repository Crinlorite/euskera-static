今までは、*Etorriko da?* のように直接的に質問していました。これからは、*no sé **si vendrá***（**来るかどうか**わからない）、*pregúntale **si tiene tiempo***（**時間があるかどうか**尋ねて）のように、**間接的に**質問する方法を学びます。これらが *zehar-galderak*（間接疑問）で、コツはたった一文字の **-n** です。

## ルール：助動詞に -n をつける

| 直接 | 間接 |
|---|---|
| *Etorriko **da**?* | *Ez dakit etorriko **den*** |
| *Nor **da**?* | *Ez dakit nor **den*** |
| *Non **dago**?* | *Ez dakit non **dagoen*** |
| *Zer nahi **du**?* | *Ez dakit zer nahi **duen*** |
| *Denborarik **dauka**?* | *Galdetu ea denborarik **daukan*** |

**-n** の付け方：*da → den* · *dago → dagoen* · *du → duen* · *dauka → daukan* · *gara → garen* · *dute → duten*。（母音で終わる場合は -n、その他は -en を付けます。2日もすれば耳が慣れて自然にできるようになりますよ。）

## "Ea" — 万能な単語

はい/いいえで答える質問の場合、バスク語では ***ea***（〜かどうか）を加えます：

> *Galdetu diot **ea gurekin bazkalduko duen**.* — 彼が私たちと一緒に昼食を食べるかどうか尋ねました。
>
> *Ikusiko dugu **ea eguraldi ona egiten duen**.* — 天気が良くなるかどうか見てみましょう。
>
> ***Ea garaiz iristen garen**!* — 間に合うといいな！

最後の *ea…!* だけの表現は、まさにバスク語の話し言葉です。願望と期待がこの一言に込められています。

## 間接疑問を必要とする動詞

| スペイン語 | バスク語 |
|---|---|
| 〜かどうかわからない | *Ez dakit … -(e)n* |
| 〜かどうかわかる？ | *Badakizu … -(e)n?* |
| 〜かどうか尋ねて | *Galdetu (iezaiozu) ea … -(e)n* |
| 〜かどうか覚えていない | *Ez naiz gogoratzen … -(e)n* |
| 〜かどうか確信がない | *Ez nago ziur … -(e)n* |

## 実践編

> *— **Badakizu zer ordutan hasten den** kontzertua?*
>
> *— Ez, baina Aneri **galdetuko diot ea dakien**.*
>
> *— Eta **ea sarrerarik geratzen den** ere galdetu, mesedez!*
>
> *— Lasai. **Ea zorte ona dugun**!*

## -la との比較（紛らわしい表現）

間接疑問と間接話法（ユニット04）を混同しないようにしましょう：

> *Esan dit etorriko **dela**.* — 彼は来ると言いました。（肯定 → **-la**）
>
> *Galdetu dit **ea** etorriko **den**.* — 彼は来るか**どうか**私に尋ねました。（疑問 → **-n**）

**Que = -la · Si = (ea) -n.** この早見表があれば、このレッスンはマスターしたも同然です。
