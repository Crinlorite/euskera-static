このレベル最後のユニット、**まとめ**の課です。あなたの過去に関する最重要課題、**人生全体を語る**ことから始めましょう。自分のでも、他の誰かのでも構いません。これはA2試験の典型的な課題であり、誰かを知るための最良の方法でもあります。

## 人生の節目

| スペイン語 | バスク語 |
|---|---|
| 生まれる | *jaio* (jaio nintzen/zen) |
| 育つ | *hazi* |
| 学校へ行く | *eskolara joan* |
| （学業を）修める | *ikasketak egin* |
| 仕事を始める | *lanean hasi* |
| 結婚する | *ezkondu* |
| 子供を持つ | *seme-alabak izan* |
| 引っ越す | *bizitzera joan / etxez aldatu* |
| 退職する | *erretiroa hartu* |
| 亡くなる | *hil* |

## 日付と時代

> *1990**ean** jaio nintzen.* — 私は1990年に生まれました。（年 + -ean）
>
> ***Gaztaroan** Iruñean bizi izan zen.* — 若い頃、彼はパンプローナに住んでいました。
>
> ***Garai hartan** ez zegoen internetik.* — その時代、インターネットはありませんでした。
>
> ***Urte askoan** irakasle ibili zen.* — 長年、彼女は教師として働いていました。

## まとまった伝記（試験モデル）

> *Elbira Zipitria **1906an jaio zen**, Zumaian, eta Donostian **hazi zen**. Gaztetan **irakasle-ikasketak egin zituen**. Gerra ostean, euskarazko eskolak **debekatuta zeuden**, baina Elbirak umeei euskaraz **irakasten zien** bere etxean, isilpean. **Urte askoan** aritu zen lan horretan, eta gaur egun euskal eskolaren **aitzindaritzat** hartzen dugu. **1982an hil zen**, baina bere lana gure ikastoletan **bizi da** oraindik.*

全ての要素に注目してください：*jaio zen / hazi zen* (NOR)、*egin zituen / irakasten zien* (NORK と NORI)、*zeuden / zegoen* (描写)… **A2レベルの過去形がすべてこの一段落に詰まっています。**

## あなたの番：骨組み

> *Ni **[urtea]n jaio nintzen**, **[herria]n**. **[Herria]n hazi nintzen** eta **[ikasketak] egin nituen**. **[Urtea]n [lana]n hasi nintzen**. Orain **[herria]n bizi naiz** eta **[zaletasuna] gustatzen zait**. Etorkizunean **[plana egingo dut]**.*

過去 → 現在 → 未来。3つの時制で1つの人生を語る：「あなたのことを話してください」に対する完璧な答えです。

## 相手の人生について尋ねる

> ***Non jaio zinen**?* — どこで生まれましたか？
>
> ***Non hazi zinen**?* — どこで育ちましたか？
>
> ***Zer ikasi zenuen**?* — 何を勉強しましたか？
>
> ***Noiz hasi zinen** lanean?* — いつ仕事を始めましたか？
>
> ***Nolakoa zen** zure herria garai hartan?* — その頃、あなたの故郷はどんな町でしたか？
