**命令形** (*agintera*) は、指示を出したり、お願いをしたり、アドバイスをしたりするのに使います。バスク語では、**見た目よりもずっとシンプルです**。最もよく使われる形は、ほとんどの場合、動詞の**分詞**と同じです。

## 基本ルール：分詞を使う

日常的な多くの命令では、動詞は助動詞なしで分詞の形で現れます。

| スペイン語 | バスク語 |
|---|---|
| 取って | *Hartu* |
| 座って | *Eseri* |
| 立って | *Jaiki* |
| 書いて | *Idatzi* |
| 読んで | *Irakurri* |
| 聞いて | *Entzun* |
| 繰り返して | *Errepikatu* |
| 待って | *Itxoin* |
| ドアを閉めて | *Itxi atea* |
| 窓を開けて | *Ireki leihoa* |

> これは教室や街中、書き言葉の指示で**最もよく使われる形**です。*zu* と *zuek* の両方に使えます。

## 総合形 (trinkoak): *zatoz*, *zoaz*

非常によく使われるいくつかの動詞には、命令形に特有の総合形があります。これらは覚えておくと便利です。

| 動詞 | 君 (zu) | 君たち (zuek) |
|---|---|---|
| *etorri* (来る) | **Zatoz** | **Zatozte** |
| *joan* (行く) | **Zoaz** | **Zoazte** |
| *ekarri* (持ってくる) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (持って行く) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (いる、ある) | **Egon** / **Lasai** (落ち着いて！) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## NOR-NORI-NORK の命令形: *emadazu*, *esadazu*

二重目的語（「これを私にくれ」「あれを彼に言え」）を持つ命令を出すとき、バスク語には非常に便利な短い形があります。

| スペイン語 | バスク語 |
|---|---|
| 私にちょうだい | *Emadazu* / *Eman iezadazu* |
| 私に言って | *Esadazu* / *Esan iezadazu* |
| 彼/彼女にちょうだい | *Emaiozu* / *Eman iezaiozu* |
| 彼/彼女に言って | *Esaiozu* / *Esan iezaiozu* |
| 私たちにちょうだい | *Emaguzu* |
| (君たちが)私にちょうだい | *Emadazue* |

これらの形は覚えるのが大変です。A2レベルでは、**emadazu / esadazu / emaiozu / esaiozu** を覚え、これらが動詞 *eman* / *esan* から来ていることを理解すれば十分です。

## 「お願いします」と表現を和らげる言葉

バスク語の命令形は、丁寧な言葉を付け加えれば**きつく聞こえません**。

- *Mesedez* — お願いします
- *Ahal baduzu* — もしできれば
- *Faborez* (口語的な言い方)
- *Eskerrik asko aldez aurretik* — 前もってお礼を言います

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## 指示（レシピ、掲示、教室）

命令形は次のような場面で標準的に使われます。

- **レシピ:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **掲示:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **教室:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **医者:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## ミニテキスト

> *Sukaldari eskolan, irakasleak esaten du:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **文化メモ:** バスク語では、命令形の**命令的な響き**は、イントネーションや文脈によって和らぎ、（「〜していただけますか？」のような）回りくどい言い方はあまり使いません。命令に *mesedez* を付け加えたり、笑顔を添えたりするだけで十分な場合が多いです。もっと丁寧に言いたい場合は、*eman ahal didazu...?*（私に〜をくれますか？）と言います。
