「**ライフスタイル**」と「**環境**」について話すのは、A2レベルの定番テーマです。新しい単語と、A1レベルからすでに習得している義務やアドバイスを表すフレーズ（*behar dugu*、*komeni da*、*garrantzitsua da*）が混ざっています。

## 健康的な習慣

| スペイン語 | バスク語 |
|---|---|
| スポーツをする | *kirola egin* |
| 歩く / 散歩する | *paseatu* / *ibili* |
| 走る | *korrika egin* |
| 自転車に乗る | *bizikletaz ibili* |
| 果物と野菜を食べる | *fruta eta barazkiak jan* |
| 水を飲む | *ura edan* |
| よく寝る | *ondo lo egin* |
| タバコを吸う | *erre* |
| お酒を飲む | *alkohola edan* |
| 塩分を摂りすぎない | *gatzaz ez abusatu* |

> 代表的なフレーズ：
>
> - *Kirola egiten dut astean hiru aldiz.* — 週に3回スポーツをします。
> - *Erretzeari utzi diot.* — タバコをやめました。
> - *Ez dut alkoholik edaten astegunetan.* — 平日はお酒を飲みません。

## 頻度：*X aldiz*

「X回」と言うには、**数字 + aldiz** という形を使います：

| スペイン語 | バスク語 |
|---|---|
| 1日に1回 | *Egunean behin* |
| 週に2回 | *Astean bi aldiz* / *birritan* |
| 月に3回 | *Hilean hiru aldiz* |
| よく、何度も | *Askotan* |
| 時々 | *Batzuetan* |
| めったに～ない | *Gutxitan* |
| 決して～ない | *Inoiz ez* |

## 環境 — *ingurumena*

| スペイン語 | バスク語 |
|---|---|
| 環境 | *ingurumena* |
| 自然 | *natura* |
| 汚染 | *kutsadura* |
| ゴミ | *zaborra* |
| リサイクルする | *birziklatu* |
| 減らす | *gutxitu* / *murriztu* |
| 再利用する | *berrerabili* |
| 再生可能エネルギー | *energia berriztagarria* |
| 気候変動 | *klima-aldaketa* |
| 地球温暖化 | *berotze globala* |

## ゴミ箱

| 一般的な色 | バスク語 | 用途 |
|---|---|---|
| 青 | *edukiontzi urdina* | papera / 紙 |
| 黄 | *edukiontzi horia* | plastikoa / プラスチック |
| 緑 | *edukiontzi berdea* | beira / ガラス |
| 茶 | *edukiontzi marroia* | organikoa / 生ゴミ |
| 灰 | *edukiontzi grisa* | hondakinak / その他 |

## 意見を言うのに便利なフレーズ

- *Garrantzitsua da birziklatzea.* — リサイクルすることは重要です。
- *Komeni da kirola egitea.* — スポーツをすると良いです。
- *Beharrezkoa da kutsadura gutxitzea.* — 汚染を減らす必要があります。
- *Ez dut uste plastikoa ona denik.* — プラスチックが良いとは思いません。

> これらの構文（*-tzea + 形容詞 + da*）は、「Xすることは重要だ／良い／必要だ」と言うためのA2レベルの公式です。ユニット4で詳しく学習します。

## 地域での生活

| スペイン語 | バスク語 |
|---|---|
| 地域、地区 | *auzoa* |
| 隣人、住民 | *bizilaguna* |
| 協会、団体 | *elkartea* |
| ボランティア活動 | *boluntariotza* |
| 地域のお祭り | *auzoko jaiak* |
| 参加する | *parte hartu* |
| 会議、集会 | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## 短いモデル文

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **文化メモ：***auzo-elkarteak*（住民協会）は、バスク地方の多くの町で社会生活の基本的な要素です。お祭り、バスク語のワークショップ、山へのハイキング、環境キャンペーンなどを企画します。参加することは、実際に使われている言語を練習する最良の方法の一つです。
