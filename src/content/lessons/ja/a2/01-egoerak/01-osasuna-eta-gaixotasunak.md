A2レベルでは、体の調子について話せるようになります。いつ体調が悪いか、どこが痛いか、医者に何を処方されたか、などです。A1で学んだ基本的な構造 (*mina daukat*) に、専門用語や医療関係者、診察での会話が加わります。

## 「体調が悪い」の言い方

バスク語では、主に2つの言い方があります。

- **Gaixorik nago.** — 病気です。(一時的な状態、*egon* を使います)
- **Ez nago ondo.** — 元気ではありません。／調子が悪いです。
- **Min hartu dut.** — けがをしました。
- **Gaixotu egin naiz.** — 病気になりました。(自動詞、*naiz* を使います)

> **文法メモ：** *gaixorik* には状態を表す接尾辞 -**rik** が付いています。これは *pozik* (嬉しい)、*nekatuta* (疲れている)、*triste* (悲しい) と同じです。覚えておきましょう：状態 = *egon*。

## 症状 — 万能な言い方 X **daukat**

A1と同様、症状は *eduki* (持つ) を使って表現します。

| 日本語 | バスク語 |
|---|---|
| 熱があります | *Sukarra **daukat*** |
| 咳が出ます | *Eztula **daukat*** |
| 風邪をひいています | *Katarroa **daukat*** |
| インフルエンザです | *Gripea **daukat*** |
| めまいがします | *Zorabiatuta nago* |
| 吐き気がします | *Goragalea **daukat*** |

## 痛み: *mina*

バスク語で **痛み** は名詞 (*mina*) で、「どんな痛みか」を補足するために、体の部位を **NONGO (-ko)** の形で組み合わせます。

> **体の部位 + -ko + mina + daukat**

| 日本語 | バスク語 |
|---|---|
| 頭が痛いです | *Buruko mina daukat* |
| 喉が痛いです | *Eztarriko mina daukat* |
| お腹が痛いです | *Sabeleko mina daukat* |
| 歯が痛いです | *Hortzeko mina daukat* |
| 背中が痛いです | *Bizkarreko mina daukat* |
| 足が痛いです | *Oinetako mina daukat* |

もう一つのよく使われる言い方です。特に「今まさに」痛いときに使います。

- *Buruak min ematen dit.* — 頭が痛いです。(直訳：頭が私に痛みを与える)

## 診察室で

| 日本語 | バスク語 |
|---|---|
| どうしましたか？ | *Zer duzu?* / *Zer gertatzen zaizu?* |
| いつからですか？ | *Noiztik?* |
| 痛みますか？ | *Min ematen dizu?* |
| 8時間ごとに錠剤を1つ飲んでください | *Hartu pilula bat zortzi orduro* |
| 休んでください | *Hartu atseden* |
| 1週間後にまた来てください | *Itzuli astebete barru* |

| 場所・人 | バスク語 |
|---|---|
| 保健センター | *anbulatorioa* |
| 病院 | *ospitalea* |

## ミニ会話

> *— Egun on. **Zer duzu**?*
>
> *— **Sukarra daukat** atzotik, eta **buruko mina** ere bai.*
>
> *— Eztulik?*
>
> *— Bai, baina ez asko.*
>
> *— Ondo. **Hartu** pilula hauek **zortzi orduro**, eta **edan** ur asko. Hobeto ez bazaude, bihar etorri berriro.*

> **文化メモ：** バスク地方では、特に小さな町では、*"botikaria"* (薬剤師) が、風邪、虫刺され、めまいといった軽い症状の最初の相談相手になることが今でもあります。薬局がかかりつけ医の前のフィルターの役割を果たしているのです。
