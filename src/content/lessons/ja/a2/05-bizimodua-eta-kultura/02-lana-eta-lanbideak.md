A2レベルでは、「私は学生です／教師です」という表現を超えて、**仕事**の世界が広がります。これからは、次のようなことについて話せるようになります：

- 仕事の種類と勤務形態。
- 就職の面接。
- 履歴書と職務経験。
- 現在の仕事や希望する**仕事内容の説明**。

## 職業 — 応用復習

A1では基本的な職業（*medikua, ikaslea, irakaslea, sukaldaria*）を学びました。A2では、さらに多くの職業を追加します：

| スペイン語 | バスク語 |
|---|---|
| ジャーナリスト | *kazetaria* |
| プログラマー | *programatzailea* |
| デザイナー | *diseinatzailea* |
| エンジニア | *ingeniaria* |
| 建築家 | *arkitektoa* |
| 弁護士 | *abokatua* |
| 公証人 | *notarioa* |
| 実業家、経営者 | *enpresari* |
| 商人 | *merkataria* |
| 運転手 | *gidaria* |
| 消防士 | *suhiltzailea* |
| 公務員 | *funtzionarioa* |
| アシスタント、補助員 | *laguntzailea* |
| 販売員 | *saltzailea* |
| 左官、建設作業員 | *igeltseroa* |
| 配管工 | *iturgina* |
| 電気技師 | *elektrizista* |

> **ヒント：**多くの職業は **-le**, **-tzaile** o **-ari** で終わります：*saltzaile, irakasle, gidari, sukaldari, kazetari*。これらは生産的な接尾辞です。

## 接尾辞 -**dun** （「〜を持つ／身につけている」）

A1で学んだこの接尾辞を思い出しましょう。職業を表すのによく使われます：

| スペイン語 | バスク語 |
|---|---|
| バスク語話者 | *euskalduna* |
| チャンピオン（*txapela* を持つ人） | *txapelduna* |
| トラック運転手 | *kamioiduna* |

## 仕事について話す

| スペイン語 | バスク語 |
|---|---|
| どんな仕事をしていますか？ | *Zertan egiten duzu lan?* |
| オフィスで働いています | *Bulego batean lan egiten dut* |
| 自営業です | *Autonomoa naiz* / *Autoenplegatua naiz* |
| 失業中です | *Langabezian nago* |
| 休職中です | *Bajan nago* |
| 無期雇用契約です | *Kontratu mugagabea daukat* |
| 有期雇用契約です | *Kontratu mugatua daukat* |
| シフト制で働いています | *Txandaka egiten dut lan* |

| スペイン語 | バスク語 |

## 就職の面接

一般的なステップと語彙：

| スペイン語 | バスク語 |
|---|---|
| 求人 | *lan-eskaintza* |
| 履歴書 | *curriculuma* |
| カバーレター、自己PR書 | *aurkezpen-gutuna* |
| 就職の面接 | *lan-elkarrizketa* |
| 経験 | *esperientzia* |
| 推薦状、照会先 | *erreferentziak* |
| 言語 | *hizkuntzak* |
| スキル | *trebetasunak* |
| 学歴 | *ikasketak* |

## 面接でよく使われるフレーズ

| スペイン語 | バスク語 |
|---|---|
| あなた自身について教えてください | *Konta iezadazu zerbait zuri buruz* |
| なぜこの職に応募したのですか？ | *Zergatik nahi duzu lanpostu hau?* |
| どのような経験がありますか？ | *Zer esperientzia daukazu?* |
| バスク語、スペイン語、英語を話します | *Euskaraz, gaztelaniaz eta ingelesez hitz egiten dut* |
| 6月から勤務可能です | *Ekainetik aurrera nago eskuragarri* |
| 希望給与はいくらですか？ | *Zer **soldata** nahi duzu?* |

## -**(e)n** を使った関係節

より複雑な表現で仕事について説明するには、**関係節**を使うと便利です：

> **動詞の活用形 + -(e)n + 名詞**

| スペイン語 | バスク語 |
|---|---|
| 私が持っている仕事 | *Daukadan lana* |
| 私が働いている会社 | *Lan egiten dudan enpresa* |
| 私が知っている同僚 | *Ezagutzen ditudan lankideak* |
| 私が受け取る給料 | *Jasotzen dudan soldata* |
| 私が受けたコース | *Egin nuen ikastaroa* |

> **作り方：**現在形または過去形の動詞 + 接尾辞 **-(e)n** + 名詞。
>
> *dut → dudan*, *du → duen*, *zen → zen*, *zuen → zuen* （すでに -n で終わっている場合は、何も追加しません）。

> これはA2レベルの重要なポイントで、ユニット5で様々な使い方で登場します：面接（*duzun esperientzia*）や自己紹介（*ezagutzen dudan jendea*）など。B1レベルでさらに詳しく学びます。

## ミニ会話：lan-elkarrizketa

> *— Egun on. Eseri, mesedez. **Konta iezadazu** zertan **lan egin duzun** orain arte.*
>
> *— Bai. Bost urtez **lan egin dut** Bilboko diseinu-enpresa batean. Han **daukadan zeregina** bezeroentzako proiektuak diseinatzea da.*
>
> *— Ondo. Eta zergatik nahi duzu **lanpostu hau**?*
>
> *— **Iruditzen zait** zuen enpresa **interesgarriagoa dela**, eta nire trebetasunak hobeto erabili **ahal izango ditudala**. **Gainera**, **lanaldi erdiko** modalitatea **eskaintzen duzuelako**, hori asko **interesatzen zait**.*

## 短文：仕事の説明

> *Lander **kazetari** lanetan dabil hamar urtetik hona. Bilboko egunkari batean **lan egiten du**, **lanaldi osoan**. Goizeko zortzietan hasten da eta bostetan amaitzen du. Berarentzat **garrantzitsuena** albisteak ondo **kontatzea** da. **Soldata** ez da oso handia, baina **gustatzen zaion lana** dauka, eta **lankide jatorrak** ditu.*

> **文化メモ：**バスク地方では、多くの公務員（保健サービス、バスク自治政府、市役所など）の求人で、バスク語の知識が**「プロフィール」**（PL1, PL2, PL3, PL4）というシステムで評価されます。バスク語を学ぶことは文化的な意味だけでなく、多くの公職において競争力となります。
