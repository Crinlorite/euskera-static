この総合レッスンでは、A1のレパートリー（NOR, NORK, NORI, NON, NOREN, NORA, NONDIK, NOREKIN）にA2で加わる**4つの新しい格変化**を復習します。これらはA2の試験には必ず出題され、バスク語の格変化の「バラ」を完成させます。

## NORENTZAT — 誰のために（為格）

> **-(r)entzat** は定名詞に付きます

| 名詞 | 形 | 日本語 |
|---|---|---|
| niretzat | *niretzat* | 私のために |
| zuretzat | *zuretzat* | 君のために |
| beretzat / harentzat | *beretzat* | 彼/彼女のために |
| guretzat | *guretzat* | 私たちのために |
| zuentzat | *zuentzat* | 君たちのために |
| haientzat | *haientzat* | 彼らのために |
| Lander | *Landerrentzat* | Landerのために |
| la madre | *amarentzat* | 母のために |
| los amigos | *lagunentzat* | 友達のために |

> *Hau **zuretzat** da.* — これは君のためです。
>
> *Opari bat erosi dut **Garazirentzat**.* — Garaziのためにプレゼントを買いました。
>
> *Liburu hau **gazte ikasleentzat** da.* — この本は若い学生たちのためのものです。

> **別形：** **-(r)endako** という形も存在し、多くの方言で同義語です：*Garazirendako, niretzako/niretako*。標準形は *-rentzat* です。

## NORAINO — 〜まで（到達点）

> **-(r)aino** は名詞に付きます（NORAのルールに従います：母音 → +raino, 子音 → +eraino）

| 日本語 | バスク語 |
|---|---|
| 山まで | *mendi**raino*** |
| ビルバオまで | *Bilbo**raino*** |
| ここまで | *hona**ino*** |
| どこまで | *nora**ino*** |
| 頂上まで | *tontorr**eraino*** |

> *Korrika egin dugu **plazaraino**.* — 広場まで走りました。
>
> *Bilbo**raino** etorri zen eta gero itzuli.* — 彼はビルバオまで来て、それから戻りました。

## NORANTZ — 〜の方へ（方向）

> **-(r)antz** は名詞に付きます（NORAと同じパターン）

| 日本語 | バスク語 |
|---|---|
| 山の方へ | *mendi**rantz*** |
| 家の方へ | *etxe**rantz*** |
| 南の方へ | *hego**rantz*** |
| 君の方へ | *zu**rantz*** |

> *Etxe**rantz** abiatu nintzen.* — 家の方へ向かいました。
>
> *Itsaso**rantz** dago etxea.* — その家は海の方を向いています。

> **NORA (-ra)との違い：** *NORA* は具体的な目的地（「ビルバオに行く」）を示しますが、*NORANTZ* はおおよその方向（「ビルバオの方へ行く」、到着の保証なし）を示します。

## ZERGATIK / NORENGATIK — 〜のせいで・〜のために（動機格）

理由を尋ねるには **zergatik?**（なぜ？）を使います。名詞で答えるには **-engatik** を使います。

| 名詞 | 形 | 日本語 |
|---|---|---|
| nigatik | *nigatik* | 私のせいで（原因） |
| zugatik | *zugatik* | 君のせいで |
| beragatik / harengatik | *beragatik* | 彼/彼女のせいで |
| Lander | *Landerrengatik* | Landerのせいで |
| la madre | *amarengatik* | 母のせいで |
| el amor | *maitasunarengatik* | 愛のために |
| la lluvia | *euriagatik* | 雨のせいで |

> *Eskerrik asko **etorri zarelako, niregatik**!* — 来てくれてありがとう、私のために！
>
> *Berandu iritsi nintzen **trafikoarengatik**.* — 交通渋滞のせいで遅れました。
>
> *Zergatik egin duzu hori? — **Zugatik**.* — なぜそれをしたの？ — 君のために。

> **注意：** *-engatik*（原因：「〜のせいで」）と*-rentzat*（受益者：「〜のために」）を区別してください。スペイン語の「por」は両方の意味を持ちますが、バスク語ではこれらは異なります。

## NONGO / NOIZKO — どの場所の / いつの

A1で *NON*（-an：〜で）を学びましたね。**NONGO** と **NOIZKO** は、場所や時を**修飾語**（属性）に変えます：

| 日本語 | バスク語 |
|---|---|
| ビルバオ**の**人々 | *Bilbo**ko** jendea* |
| ドノスティア**の**美術館 | *Donostia**ko** museoa* |
| 今日**の**新聞 | *Gaur**ko** egunkaria* |
| 明日**の**試験 | *Bihar**ko** azterketa* |
| 7月**の**お祭り | *Uztaileko jaia* |

> これは **NONGO/NOIZKO** の格（子音の後では -ko / -tako）で、属性的な意味での「どこの」/「いつの」を表します。

| 形 | 用途 |
|---|---|
| **-ko** 単数 | *Bilboko, etxeko, gaurko* |
| **-etako** 複数 | *etxe**etako**, mendi**etako**, urte**etako*** |

> *Atzo**ko** afari**a** ona zen.* — 昨日**の**夕食は美味しかったです。
>
> *Bilbo**ko** etxebizitzak garestiak dira.* — ビルバオ**の**住宅は高いです。
>
> *Mendi**etako** loreak ederrak dira.* — 山々**の**花は美しいです。

## ミニまとめ表

| 格 | 接尾辞 | 疑問詞 | 例 |
|---|---|---|---|
| NORENTZAT | -rentzat | 誰のために？ | *Garazirentzat* |
| NORAINO | -raino | どこまで？ | *Bilboraino* |
| NORANTZ | -rantz | どの方へ？ | *etxerantz* |
| NORENGATIK | -engatik | 誰/何のせいで？ | *euriagatik* |
| NONGO | -ko | どこの（属性）？ | *Donostiako* |
| NOIZKO | -ko / -tako | いつの？ | *gaurko, atzoko* |

## 総合ミニテキスト

> *Joan den astean **Bilboraino** joan ginen autobusez. Helmuga: hiriko **museorako** sarrera bana erostea. **Bilboko jendea** oso jatorra izan zen. Buelta hartzeko, taxi bat hartu genuen **etxerantz**: euri-jasa hain handia zen, ezen autoa **euriagatik** hondatu zen. Azkenean, ordu bat **beranduago** iritsi ginen **Donostiako geltokira**. Hori bai, etxean opari bat zegoen zain: **niretzat**, ama maitearen partez.*

## ビジュアル復習：A2のバラ

これで、すべての基本的な格を使いこなせるようになりました：

| 格 | 疑問詞 | 接尾辞 | 例 (etxe) |
|---|---|---|---|
| NOR | 誰？ | -a | *etxea* |
| NORK | 誰が（する）？ | -ak | *etxeak* (sujeto) |
| NORI | 誰に？ | -ari | *etxeari* |
| NON | どこで？ | -an | *etxean* |
| NORA | どこへ？ | -ra | *etxera* |
| NONDIK | どこから？ | -tik | *etxetik* |
| NOREKIN | 誰と？ | -arekin | *etxearekin* |
| NOREN | 誰の？ | -aren | *etxearen* |
| NONGO | どこの（属性）？ | -ko | *etxeko* |
| NORENTZAT | 誰のために？ | -arentzat | *etxearentzat* |
| NORAINO | どこまで？ | -raino | *etxeraino* |
| NORANTZ | どの方へ？ | -rantz | *etxerantz* |
| NORENGATIK | 誰のせいで？ | -arengatik | *etxearengatik* |
| -ZAZ / -Z | 具格 | -z | *etxez* |
| -RIK | 分格（否定） | -rik | *etxerik (ez dago)* |

> **A2チャレンジ：** 名詞 *Garazi* を使って、各格で文を一つずつ書いてみましょう。一人の人間を通して、バスク語の仕組み全体がどのように機能するかがわかるでしょう。

> **教育的メモ：** これらの格変化は「B1への扉」です。これらをマスターすれば、情報（目的地、動機、属性、方向）に富んだ豊かな文を組み立てることができるようになります。B1では、より抽象的な用法を深め、さらにいくつか（原因を示す具格、拡張された分格など）が追加されます。
