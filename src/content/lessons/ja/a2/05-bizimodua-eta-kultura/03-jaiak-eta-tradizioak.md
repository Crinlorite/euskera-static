このレッスンでは、**祭りや習慣**について話したり、**時代や場所を比較**したりする（「以前は...今は」、「XでもYでも」）ためのツールを学びます。A2レベルの文化的な会話に欠かせない語彙です。

## バスクの祭り：中心となる語彙

| 日付 | 祭り | 簡単な説明 |
|---|---|---|
| 6月23日 | *San Juan sua* | 聖ヨハネの前夜祭の焚き火 |
| 12月31日 | *Urtezahar* | 大晦日 |
| 12月24日 | *Olentzero* | プレゼントを運んでくる炭焼き職人のキャラクター |
| 2月 / 3月 | *Inauteriak / Aratusteak* | カーニバル |
| 2月5日 | *Santa Ageda* | 家々を回って歌う伝統的な歌 |
| 2年ごと | *Korrika* | バスク語を支援するための市民マラソン |
| 8月 | *Aste Nagusia* | ビルバオのセマナ・グランデ（大週間） |
| 地域ごと（各村） | *Herriko jaiak* | 村祭り |

## バスク文化の人物と要素

| スペイン語 | バスク語 |
|---|---|
| Bertsolari（即興詩人） | *bertsolaria* |
| Trikitilari（アコーディオン奏者） | *trikitilaria* |
| Txistulari（伝統的な笛の奏者） | *txistularia* |
| Dantzari（ダンサー） | *dantzaria* |
| Pelotari（ペロタ選手） | *pilotaria* |
| Aizkolari（丸太切り職人） | *aizkolaria* |
| Harrijasotzaile（石持ち上げ力士） | *harrijasotzaileak* |

> **文化メモ：** *kirol-jaiak*（田舎のスポーツ）は祭りの典型的なものです。石持ち上げ、斧での丸太割り、トライネラ（ボートレース）、*soka-tira*（綱引き）などがあります。これらはバスクのアイデンティティの象徴であり、どんな村の祭りのプログラムにも登場します。

## 昔と今を比較する：*lehen / orain*

文化比較では、この2つの単語が鍵となります。

| スペイン語 | バスク語 |
|---|---|
| 以前は、昔は | *lehen* |
| 今は | *orain* |
| 昔は、かつては | *garai batean* / *aspaldian* |
| 今日では | *gaur egun* |
| 以前は...今は... | *Lehen... orain...* |
| 数年前に | *Duela urte batzuk* |

> *Lehen baserrian **bizi ginen**, orain hirian **bizi gara**.* — 以前は農家に住んでいましたが、今は街に住んでいます。
>
> *Garai batean **dena euskaraz egiten zen**; gaur egun, **erdaraz ere asko** egiten da.* — かつてはすべてがバスク語で行われていましたが、今日ではスペイン語でも多く行われています。

## 場所を比較する：*bai... bai...*、*baita... ere*

| スペイン語 | バスク語 |
|---|---|
| XでもYでも | *Bai X-(e)an, bai Y-(e)an* |
| Xでもまた | *X-(e)an ere bai* |
| XでもYでもない | *Ez X-(e)an, ez Y-(e)an* |
| XだけでなくYも | *Ez **bakarrik** X, **baita** Y **ere*** |

> *San Juan sua **bai** Donostian, **bai** Bilbon ospatzen da.* — 聖ヨハネの前夜祭の焚き火はドノスティアでもビルバオでも祝われます。
>
> *Korrika **bai** Hego Euskal Herrian, **bai** Iparraldean egiten da.* — *Korrika*は南バスク地方でも北バスク地方でも行われます。

## 祭りを説明する方法

便利な構成：

> **祭り + いつ + どこで + 何をするか + なぜ特別か**

> *San Juan sua **ekainaren 23an** ospatzen da. Herri askotan **plaza nagusian** egur pila bat egiten da, eta gauean **sua pizten dute**. Jendeak **suaren gainetik salto egiten du**, eta **dantzan eta kantuan** aritzen da gauerdi arte. Familia eta lagun arteko ospakizuna da, eta **udaren hasiera** ospatzen du.*

## 比較のミニテキスト

> *Lehen, herriko **jaiak** ohikoak ziren udazkenean. Familia osoa elkartzen zen plaza nagusian, **bertsolariak** eta **trikitilariak** entzuten zituen, eta **dantzan** ari zen gauerdi arte. **Gaur egun**, jaiak antolatzea zailagoa da: jendea sakabanatuta dago, gazteek bestelako gustuak dituzte, eta **lehen baino** diru **gutxiago** dago. Hala ere, **tradizioa** mantentzen ahalegintzen dira: **bai herri txikietan, bai hiri handietan**, urtero programa **politak** prestatzen dituzte.*

## 対話：習慣を比較する

> *— Anboto, zer ospatzen da zure herrian?*
>
> *— Ba, klasikoak: **San Juan**, **herriko jaiak** abuztuan, **Olentzero** Eguberrian. **Korrika** ere bai bi urtero, oso garrantzitsua hori.*
>
> *— Eta Olentzero, oraindik etxez etxe ibiltzen da?*
>
> *— **Lehen ohitura zen** etxez etxe ibili eta umeentzako opariak banatzea. **Orain**, herri txikietan oraindik egiten da, baina hirietan ekitaldi nagusi bat plazan egin ohi da, **bertsolariekin eta musikarekin**.*

## 文化を比較するための便利な構文

| スペイン語 | バスク語 |
|---|---|
| 一方、ここでは... | *Hemen, aldiz, ...* |
| Xと同じように | *X-(e)n bezala* |
| Xとは違って | *X ez bezala* |
| ～に似ています | *Antzekoa da* |
| 全く違います | *Oso ezberdina da* |

> **文化メモ：**バスクの祭りは、公式試験や実際の会話で最も頻繁に出題されるA2レベルのテーマの一つです。**あなた自身の好きな祭りについて**、いつ、どこで、何をするか、何が好きか、そして他の祭りと比較して、5つの文で説明文を作成してみましょう。これは完璧な総合演習になります。
