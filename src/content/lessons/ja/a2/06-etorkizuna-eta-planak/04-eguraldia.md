同じ日の朝に晴れたり、雨が降ったり、また晴れたりする国では、**天気の話は国民的スポーツのようなもの**です。しかも、これには一石二鳥の効果があります。*eguraldia*（天気）の語彙は、習いたての未来形を練習するのに最適な分野なのです。なぜなら、天気予報は常に*geroaldia*（未来形）で話されるからです。

## 基本の単語

| 日本語 | バスク語 |
|---|---|
| 天気 | *eguraldia* |
| 太陽 | *eguzkia* |
| 雨 | *euria* |
| 雪 | *elurra* |
| 風 | *haizea* |
| 霧 | *lainoa* |
| 雲 | *hodeiak* |
| にわか雨、夕立 | *zaparrada* |
| 気温 | *tenperatura* |
| 度 | *graduak* |
| 予報 | *iragarpena* |

## すべてを動かす3つの構文

| 時 | 構文 | 例 |
|---|---|---|
| **今、この瞬間** | 現象 + ***ari du*** | *Euria **ari du**.* — 雨が降っています。 |
| **一般的・今日** | 現象 + ***egiten du*** | *Hotz handia **egiten du**.* — とても寒いです。 |
| **予報（未来）** | 現象 + ***egingo du*** | *Bihar euria **egingo du**.* — 明日は雨が降るでしょう。 |

独自の動詞を持つその他の表現：

> *Eguzkia **atera da** / **aterako da**.* — 太陽が出ました／出るでしょう。
>
> *Haizea **dabil**.* — 風が吹いています（直訳：風が「歩いて」います）。
>
> ***Hodeitsu / eguzkitsu dago**.* — 曇っています／晴れています。

> **注目：**バスク語の天気は、*egin* と助動詞 **du** を使って物事を「**する**」と表現します（主語は見えません）：*euria egingo du*、*bero handia egiten du*。これはスペイン語の「hace calor」（暑い、直訳：熱を作る）とそっくりです。違うのは、雨も「作られる」点です。

## 質問の仕方

> ***Zer eguraldi egiten du** zure herrian?* — あなたの町はどんな天気ですか？
>
> ***Zer dio iragarpenak** biharko?* — 明日の天気予報は何と言っていますか？
>
> ***Zenbat gradu daude** kanpoan?* — 外は何度ですか？

## 本物の天気予報（テレビのように）

> *«Gaur, goizean **lainoa** izango dugu kostaldean, baina eguerdirako **eguzkia aterako da**. Arratsaldean **hodeiak** iritsiko dira mendebaldetik eta gauean **euria egingo du**, batez ere Bizkaian. Tenperaturak **behera egingo du**: 22 gradutik 16ra. Bihar, **haizea ibiliko da** eta **zaparradak** izango ditugu han-hemenka.»*

（今朝は沿岸部で霧、正午には晴れ、午後は西から雲が広がり、夜には雨、特にビスカヤ県で。気温は22度から16度に下がります。明日は風が吹き、所によりにわか雨が降るでしょう — 定番の大西洋メニューですね。😄）

## 会話：予定は空模様次第

> *— Bihar mendira **joango gara**?*
>
> *— Ez dakit… **zer dio iragarpenak**?*
>
> *— Goizean **eguzkitsu**, baina arratsaldean **euria egingo du**.*
>
> *— Orduan goiz **aterako gara**. **Zaparrada** harrapatzen bagaitu, hurrengoan ez naiz zurekin inora joango!* 😄
