このユニットの最後のレッスンです。そして、大きなサイクルの締めくくりでもあります。未来時制をマスターした今、あなたは**3つの時制を使いこなせます**。このレッスンでは、それに加えて素晴らしい表現 (*ohi*、バスク語の「〜するのが常だ」) を学び、一つの考えを過去、現在（習慣）、未来の間で動かす練習をします。これこそ、まさにA2レベルの試験官が聞きたいことなのです。

## "Ohi" — バスク語の「〜するのが常だ」

> **分詞 + ohi + 助動詞**

| 日本語 | バスク語 |
|---|---|
| 私は普段、自転車で仕事に行きます | *Lanera bizikletaz joan **ohi** naiz* |
| 私たちは普段、おばあちゃんの家で食事をします | *Amonaren etxean bazkaldu **ohi** dugu* |
| 彼は普段、遅れて来ます | *Berandu etorri **ohi** da* |
| 以前はタバコを吸っていました（今は吸いません） | *Erre **ohi** nuen* |

2つのポイント：

1. **位置は固定です**：分詞と助動詞の間に入ります。*Joan ohi naiz* ✓ — *ohi joan naiz* とは言いません。
2. **助動詞を過去形**にすると「〜するのが常だった」になります：*joan ohi nintzen*（よく行っていた）。これは既知の未完了過去 (*joaten nintzen*) とよく似ていますが、*ohi* は習慣であることを強調します。

> **"ohi" を使わない場合は？** 習慣を表す現在形 (*joaten naiz*) もすでに習慣を表します。*Ohi* は、特に書き言葉や試験で使われる、習慣を強調する洗練された表現です。上品に聞こせたい時に使いましょう：*Igandeetan hondartzara joan ohi gara.*

## 習慣を表す副詞

| 日本語 | バスク語 |
|---|---|
| 普通は、普段は | *normalean* |
| たいてい | *gehienetan* |
| ほとんどいつも | *ia beti* |
| 時々 | *batzuetan* |
| ほとんど〜ない | *ia inoiz ez* |
| 毎朝 / 毎年 | *goizero / urtero* |
| 日曜日は（複数） | *igandeetan* |

## 時制の完全マップ（あなたの決定版カンニングペーパー）

| 意味 | バスク語 | 時制 |
|---|---|---|
| 行く（習慣） | *joaten naiz* / *joan ohi naiz* | 習慣的現在 |
| 行っているところだ | *joaten ari naiz* | 現在進行形 |
| 行った（今日） | *joan naiz* | 最近の過去 |
| 行った（ある日） | *joan nintzen* | 点過去 |
| 行っていた / よく行っていた | *joaten nintzen* / *joan ohi nintzen* | 習慣的過去 |
| 行くだろう | ***joango naiz*** | **未来** |

6つのマス。動詞は1つ。**すべてあなたのものです。**

## ミニテキスト：以前、今、そして明日

> *Lehen, lanera autoz joan **ohi nintzen**: ordu erdi trafikoan, egunero. Orain bizikletaz **joaten naiz** — hamar minutu, eta gainera kirola **egiten dut**. Datorren urtean etxetik gertuago **biziko naiz**, eta orduan oinez **joango naiz**. Nire medikua pozik **egongo da**!* 😄

## 復習ダイアログ（3つの時制を実践）

> *— Zer egin **ohi duzu** igandeetan?*
>
> *— Normalean berandu jaiki eta familiarekin bazkaldu **ohi dut**. Baina datorren igandean ezberdina **izango da**: Behobia-Donostia lasterketa **korrituko dut**!*
>
> *— Ederki! Entrenatu **ohi zara**?*
>
> *— Bai, gaztetan asko korritzen **nuen**, gero utzi **egin nion**… eta aurten berriro **hasi naiz**. Bihar azken entrenamendua **egingo dut**.*
>
> *— Ba, zorte on! Helmugan **egongo naiz**, animatzen.* 💪
