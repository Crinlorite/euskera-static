未来形の作り方はもう知っていますね。今度は、**日常生活で実際に役立つ使い方、つまり予定を立てる**ために使ってみましょう。このレッスンでは、未来を表す時間マーカーと、意図や決定を表現するための構文を学びます。

## 未来を表すマーカー

| スペイン語 | バスク語 |
|---|---|
| 明日 | *bihar* |
| 明後日 | *etzi* |
| 今日の午後 / 今夜 | *gaur arratsaldean / gaur gauean* |
| 週末 | *asteburuan* |
| 来週 | *datorren astean* |
| 来月 | *datorren hilean* |
| 来年 | *datorren urtean* |
| もうすぐ | *laster* |
| 休暇中 | *oporretan* |

> **便利な対称性:** *atzo ↔ bihar* (昨日 ↔ 明日)、*herenegun ↔ etzi* (一昨日 ↔ 明後日)。*Joan den astean* (先週、去った週) ↔ *datorren astean* (来週、来る週)。バスク語では文字通りに表現します: **joan** = 行く、**etorri (dator)** = 来る。

## 定番の質問

> ***Zer egingo duzu** asteburuan?* — 週末は何をしますか？

そして、その典型的な答え方です：

> *Larunbatean mendira **joango naiz**, eta igandean etxean **geratuko naiz**, lasai.* — 土曜日は山へ行き、日曜日は家でゆっくりします。
>
> *Oraindik ez dakit. Agian lagunekin **aterako naiz**.* — まだ分かりません。たぶん友達と出かけるでしょう。

## 意図と決定

| スペイン語 | バスク語 | ニュアンス |
|---|---|---|
| 旅行するつもりです | *Bidaiatzeko **asmoa dut*** | 頭の中の計画 |
| 仕事を変えることに決めました | *Lanez aldatzea **erabaki dut*** | 下された決定 |
| 行きたいです | *Joateko **gogoa daukat*** | 欲求 |
| 行こうと思っています | *Joateko **asmotan nabil*** | その考えでいる |

共通の構造: **動詞 + -t(z)eko + 名詞 (asmoa/gogoa)**。*-tzeko*（目的）についてすでに知っていることと合わせれば、これは自然に理解できるはずです。

## 文脈の中での例

> *Datorren urtean euskara-azterketa bat egiteko **asmoa dut**.* — 来年、バスク語の試験を受けるつもりです。
>
> *Aurten ez dugu oporrik hartuko; dirua aurreztuko dugu eta **datorren udan** Grezia ezagutuko dugu.* — 今年は休暇を取りません。お金を貯めて、来年の夏にギリシャを訪れます。
>
> *Laster **jakingo dugu** emaitza.* — もうすぐ結果が分かります。

## 会話

> *— Aizu, zer **egingo duzu** etzi arratsaldean?* (ねえ、明後日の午後は何をするの？)
>
> *— Etzi… ostirala da, ezta? Lanetik irten eta gimnasiora **joango naiz**. Zergatik?* (明後日…金曜日だよね？仕事が終わったらジムに行くよ。どうして？)
>
> *— Kontzertu bat dago Gasteizen. Sarrerak erosteko **asmoa dut**.* (Gasteizでコンサートがあるんだ。チケットを買おうと思ってるんだけど。)
>
> *— Ederra plana! Ni ere apuntatzen naiz. Gimnasioa **datorren astean** ere hor **egongo da**.* 😄 (いい計画だね！私も参加するよ。ジムは**来週**もそこにあるからね。😄)

## 短文：私の予定

> *Datorren hilean lan berria hasiko dut. Lehenengo astean jende berria ezagutuko dut eta dena ikasi beharko dut. Urduri nago, baina gogotsu: azkenean, benetan gustatzen zaidan zerbait **egingo dut**. Asteburuan lagunekin ospatuko dut — afari eder bat **prestatuko dugu** eta berandu arte **egongo gara** hizketan.*
