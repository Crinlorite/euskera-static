**NOR-NORI**動詞とは、何か（NOR）が「誰かに（NORI）起こる」動詞のことです。文法上の主語は**人ではなく物**です。これはスペイン語の*gustar*と全く同じです：*me gusta el cine*（私に彼、つまり映画が好かれる）。

 A1ではすでに*gustatzen zait*を学びました。A2では、このパターンを他の便利な動詞にも広げていきます。

## NOR-NORI助動詞の現在形

NORが単数形の場合：

| NORI | 形 | スペイン語 |
|---|---|---|
| niri | **zait** | 私に |
| zuri | **zaizu** | 君に |
| hari | **zaio** | 彼/彼女に |
| guri | **zaigu** | 私たちに |
| zuei | **zaizue** | 君たちに |
| haiei | **zaie** | 彼ら/彼女らに |

NORが**複数形**の場合：

| NORI | 複数形 | スペイン語 |
|---|---|---|
| niri | **zaizkit** | 私に（複数の物） |
| zuri | **zaizkizu** | 君に |
| hari | **zaizkio** | 彼/彼女に |
| guri | **zaizkigu** | 私たちに |
| zuei | **zaizkizue** | 君たちに |
| haiei | **zaizkie** | 彼ら/彼女らに |

## 過去形：*zitzaidan, zitzaion*

| NORI | 過去単数 | 過去複数 |
|---|---|---|
| niri | **zitzaidan** | **zitzaizkidan** |
| zuri | **zitzaizun** | **zitzaizkizun** |
| hari | **zitzaion** | **zitzaizkion** |
| guri | **zitzaigun** | **zitzaizkigun** |
| haiei | **zitzaien** | **zitzaizkien** |

## このパターンの動詞

| 動詞 | 意味 | 例 |
|---|---|---|
| *gustatu* | 〜が好きである | *Filmak gustatzen zaizkit*（私は映画が好きです） |
| *iruditu* | 〜と思われる | *Ondo iruditzen zait*（私は良いと思います） |
| *ahaztu* | 〜を忘れる | *Ahaztu zait izena*（名前を忘れてしまいました） |
| *erori* | 落ちる | *Erori zaizu boligrafoa*（君はボールペンを落としました） |
| *gertatu* | （誰かに）起こる | *Zer gertatu zaizu?*（君に何があったの？） |
| *interesatu* | 〜に興味がある | *Politika interesatzen zait*（私は政治に興味があります） |
| *axola izan* | 重要である | *Ez zait axola*（私は気にしません） |

## 構造：主語は物

> **NORI + NOR + 動詞 + NOR-NORI助動詞**

| スペイン語 | バスク語 | 表記 |
|---|---|---|
| 私は映画が好きです | *Niri zinea **gustatzen zait*** | NORI + NOR sing + zait |
| 私は映画（複数）が好きです | *Niri filmak **gustatzen zaizkit*** | NORI + NOR pl + zaizkit |
| 君は良いと思う | *Zuri ondo **iruditzen zaizu*** | NORI + NOR + zaizu |
| 彼/彼女は本を落としました | *Hari liburu bat **erori zaio*** | NORI + NOR sing + zaio |
| 私は鍵を忘れました | *Niri giltzak **ahaztu zaizkit*** | NORI + NOR pl + zaizkit |

> **ヒント：** 影響を受ける人はNORI（-ari/-ei）格で、通常は文頭に来ます。物が文法上の主語となり、動詞はそれに一致します。

## 過去形の*Gustatzen zait* — *gustatu zitzaidan*

過去の好みについて話すには：

> *Filma asko **gustatu zitzaidan**.* — その映画はとても気に入りました。
>
> *Ez zitzaion gustatu opari hori.* — 彼/彼女はそのプレゼントが気に入りませんでした。

> 注意：*gustatu zitzaidan*（＝気に入った、完了した行為） vs *gustatzen zitzaidan*（＝好きだった、習慣）。

## *Iruditu*（〜と思われる）— 個人的な意見

A2で最も役立つ表現の一つです：

| スペイン語 | バスク語 |
|---|---|
| 良いと思います | *Ondo iruditzen zait* |
| 面白いと思います | *Interesgarria iruditzen zait* |
| どう思いますか？ | *Zer iruditzen zaizu?* |
| 奇妙だと思います | *Bitxia iruditzen zait* |
| そうだと思います | *Baietz iruditzen zait* |

## *Ahaztu zait* — 忘れてしまいました

| スペイン語 | バスク語 |
|---|---|
| 忘れてしまいました | *Ahaztu zait* |
| 鍵を忘れてしまいました | *Giltzak ahaztu zaizkit* |
| 彼/彼女は全てを忘れます | *Dena ahazten zaio* |
| 忘れないで！ | *Ez zaizula ahaztu!* |

## ミニ会話

> *— Olatz, **zer iruditzen zaizu** Bilboko jatetxe berria?*
>
> *— Asko **gustatu zait**. Bereziki bigarren platerak: **interesgarriak iruditu zaizkit**.*
>
> *— Eta, jakin nahi nuen, **ahaztu zaizu** zer eskatu zenuen?*
>
> *— Bai, izenak ez **zaizkit gogoratzen**, baina arraina zen, ziur.*

## よくある間違い

1. **ここには能格の主語は存在しません。** *\*Nik gustatzen dut*と言わないでください（これは非常によくある間違いです）。正しくは*Niri gustatzen zait*です。人が行為者ではありません。
2. **NORの一致。** 物が複数形の場合、助動詞も複数形になります：*zaizkit, zaizkio, zaizkigu...*
3. **一部の地域では他の変種が使われます**（*hitano*では*zaidak, zaidan*など）が、標準バスク語（*batua*）では表にある形が標準形です。

> **文化メモ：** バスク語話者は、意見を控えめに述べるために*iruditzen zait*を（愛情を込めて）多用する傾向があります：*interesgarria iruditzen zait*、*bitxia iruditzen zait*、*ez zait ondo iruditzen*。これは、ニュアンスを含んだ「私には〜と思われる…」のバスク語版です。
