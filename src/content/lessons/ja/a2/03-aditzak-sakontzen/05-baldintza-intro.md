バスク語の**条件法** (*baldintza*)にはいくつかの形があります。A2レベルでは、**最も便利な2つの形**を学びます：

1. **現実的条件（起こりうる未来）：** *もし明日雨が降ったら、行きません*。
2. **非現実的条件（仮定）：** *もしお金があったら、家を買うのに*。

このレッスンは**入門編**です。形を認識し、簡単な文を作れるようになれば十分です。B1のユニットでさらに詳しく学びます。

## タイプ1：現実的条件 — *ba-* + 現在形

**起こりうる未来**や現在についての仮定には、バスク語では助動詞の現在形に接頭辞**ba-**を付けます。

> **ba- + 助動詞の現在形, ... + 未来形**

| スペイン語 | バスク語 |
|---|---|
| もし雨が降ったら、行きません | *Euria egiten **badu**, ez naiz joango* |
| もし時間があれば、来てください | *Astia **baduzu**, etorri* |
| もしよかったら、電話してください | *Nahi **baduzu**, deitu niri* |
| もし私がいつか金持ちになったら… | *Aberatsa **banaiz** noizbait...* |

### *ba-* を伴う形（現在形）

| 動詞 | ba- なし | ba- あり |
|---|---|---|
| *naiz* | 私は〜です | **banaiz** (もし私が〜なら) |
| *zara* | 君は〜です | **bazara** (もし君が〜なら) |
| *da* | 〜です | **bada** (もし〜なら) |
| *gara* | 私たちは〜です | **bagara** (もし私たちが〜なら) |
| *dut* | 私はそれを | **badut** (もし私がそれを持っていたら) |
| *du* | 彼がそれを | **badu** (もし彼がそれを持っていたら) |
| *dute* | 彼らがそれを | **badute** (もし彼らがそれを持っていたら) |

> **注意！** *Ba-* には肯定的な用法もあります：*bai, badator* = 「はい、来ます」。文脈によって意味が区別されます。文に後半部分（「…ならば…」）があれば、それは条件法です。

## タイプ2：非現実的条件 — *banintz / banu*

非現実的、または可能性が非常に低い仮定（「もし私が…だったら」、「もし私が…を持っていたら」）には、バスク語では専用の形を使います：

### 非現実的条件における *izan* の形

| 人称 | 形 | スペイン語 |
|---|---|---|
| ni | **banintz** | もし私が〜だったら／〜いたら |
| zu | **bazina** | もし君が〜だったら |
| hura | **balitz** | もし〜だったら／〜いたら |
| gu | **bagina** | もし私たちが〜だったら |
| zuek | **bazinete** | もし君たちが〜だったら |
| haiek | **balira** | もし彼らが〜だったら |

### 非現実的条件における *ukan* の形

| 人称 | 形 | スペイン語 |
|---|---|---|
| nik | **banu** | もし私がそれを持っていたら |
| zuk | **bazenu** | もし君がそれを持っていたら |
| hark | **balu** | もし（彼が）それを持っていたら |
| guk | **bagenu** | もし私たちがそれを持っていたら |
| haiek | **balute** | もし彼らがそれを持っていたら |

> **まずこの6つを覚えてください**：*banintz, balitz, banu, balu, bagenu, balute*。これらは非現実的条件の文では必ず出てきます。

## 帰結節：*-ko/-go + nuke / nintzateke*

「買う**のに**／行くのに／〜であるのに」という部分は、未来形と同じ**-ko/-go** + 特殊な助動詞で形成されます：

### NOR-NORK 条件法（「私はそれを〜するのに」）

| 人称 | 形 | スペイン語 |
|---|---|---|
| nik | **nuke** | 私はそれを〜するのに |
| zuk | **zenuke** | 君はそれを〜するのに |
| hark | **luke** | 彼はそれを〜するのに |
| guk | **genuke** | 私たちはそれを〜するのに |
| haiek | **lukete** | 彼らはそれを〜するのに |

### NOR 条件法（「私は〜するのに」、自動詞）

| 人称 | 形 | スペイン語 |
|---|---|---|
| ni | **nintzateke** | 私は〜するのに |
| zu | **zinateke** | 君は〜するのに |
| hura | **litzateke** | 彼は〜するのに／〜であるのに |
| gu | **ginateke** | 私たちは〜するのに |
| haiek | **lirateke** | 彼らは〜するのに |

## モデル文

> **baldintza + ondorioa**

> *Diru asko **banu**, etxe bat **erosiko nuke**.* — もしお金がたくさんあったら、家を一軒買うのになあ。
>
> *Lurralde berri batean **bizi banintz**, beste hizkuntza bat **ikasiko nuke**.* — もし新しい国に住んでいたら、別の言語を学ぶのになあ。
>
> *Anboto hemen **balitz**, lasaiago **egongo ginateke**.* — もしアンボトがここにいたら、私たちはもっと落ち着いていられるのになあ。
>
> *Aberatsak **balira**, mundu osoa **bisitatuko lukete**.* — もし彼らが金持ちだったら、全世界を旅行するのになあ。

## 2つのタイプの比較

| タイプ | 「もし」節 | 「ならば」節 |
|---|---|---|
| 現実的（起こりうる未来） | *ba-* + 現在形: *baduzu, bada* | 未来形: *-ko/-go + naiz/dut* (*joango naiz, erosiko dut*) |
| 非現実的（仮定） | *ba-* + 条件法: *banu, balitz* | 条件法: *-ko/-go + nuke/nintzateke* |

## 対照的な例

- **現実的：** *Astia **baduzu**, lagunduko **dizut**.* — もし時間があれば、手伝いますよ。
- **非現実的：** *Astia **bazenu**, lagunduko **zenidake**.* — もし時間があれば、手伝ってくれるのに。

## とても便利な決まり文句

| スペイン語 | バスク語 |
|---|---|
| 〜なさいませんか？ | *Nahi **zenuke**…?* |
| 〜したいです。 | *Gustatuko **litzaidake**…* |
| 〜だったら素敵ですね。 | *Polita **litzateke**…* |
| 喜んで行きたいです | *Gustura **joango nintzateke*** |
| 考えておきます。 | *Pentsatuko **nuke*** |

## ミニ会話

> *— Olatz, **nahi zenuke** zinemara joan?*
>
> *— Bai, **gustatuko litzaidake**, baina astia **banu**... Lan asko daukat astean.*
>
> *— Lasai. Bihar **etortzen bazara**, sarrera bat **erosiko dizut**.*

> **学習上の注意：** *baldintza*は、A2からB1への扉を開くポイントの一つです。公式のA2レベルでは、それを**認識**し、*banintz... -ko nuke*のような簡単な文を作れれば十分です。条件法の完全な活用はB1で扱います。
