バスク語で「できる」と言うには、2つの選択肢があります。1つは**フォーマル**な形（特別な助動詞を持つahalera）で、もう1つは**口語**的な形（通常の助動詞を持つ*ahal*）です。A2レベルでは、両方を認識できると便利です。

「できない」については、専用の単語 **ezin** があります。

## 選択肢1：口語的な形 — *ahal*

最も簡単で、最もよく耳にする形です：

> **partizipioa + ahal + auxiliar**

| スペイン語 | バスク語 |
|---|---|
| ¿Puedes venir? | *Etorri **ahal zara**?* |
| ¿Puedo entrar? | *Sartu **ahal naiz**?* |
| ¿Me puedes ayudar? | *Lagundu **ahal didazu**?* |
| ¿Podemos hablar contigo? | *Hitz egin **ahal dugu** zurekin?* |

> 書き言葉やよりフォーマルな場面では **ahal izan** が現れます：*etorri ahal izango da*、*jakin ahal izan dut*。日常会話では *ahal* + 助動詞で機能します。

## 選択肢2：「真の」ahalera — *dezaket / naiteke*

これは可能法（ahalera）の総合形です。動詞が他動詞か自動詞かによって、2つの系列があります。

### 他動詞 (NOR-NORK): *dezaket*

| 人称代名詞 | 形 | スペイン語 |
|---|---|---|
| nik | **dezaket** | 私はそれをできる |
| zuk | **dezakezu** | 君はそれをできる |
| hark | **dezake** | 彼/彼女はそれをできる |
| guk | **dezakegu** | 私たちはそれをできる |
| zuek | **dezakezue** | 君たちはそれをできる |
| haiek | **dezakete** | 彼ら/彼女らはそれをできる |

> **語尾なしの分詞 + dezaket**: *egin → egin dezaket*, *idatzi → idatz dezaket*, *jan → jan dezaket*。

### 自動詞 (NOR): *naiteke*

| 人称代名詞 | 形 | スペイン語 |
|---|---|---|
| ni | **naiteke** | 私はできる |
| zu | **zaitezke** | 君はできる |
| hura | **daiteke** | 彼/彼女はできる |
| gu | **gaitezke** | 私たちはできる |
| zuek | **zaitezkete** | 君たちはできる |
| haiek | **daitezke** | 彼ら/彼女らはできる |

> *Etor naiteke?* — 来てもいいですか？
>
> *Joan zaitezke?* — 行けますか？
>
> *Hori egia izan daiteke.* — それは本当かもしれません。

## 総合形の公式

| タイプ | 構造 | 例 |
|---|---|---|
| 他動詞 | 分詞（典型的な語末なし） + *dezaket* など | *Liburua **irakur dezakezu*** (君はその本を読むことができる) |
| 自動詞 | 分詞 + *naiteke* など | *Etor **zaitezke**?* (来られますか？) |

> **スペリングの詳細：** ahaleraでは、いくつかの動詞で分詞が「短縮」されて現れます：*jan → jan*、*egin → egin*、*irakurri → irakur*、*ikusi → ikus*、*etorri → etor*。最後の-iが脱落します。これは典型的なフォーマルな印です。

## *Ezin* — できない

ahaleraの否定形には専用の単語 **ezin** があります。

> **ezin + partizipioa + auxiliar**

| スペイン語 | バスク語 |
|---|---|
| No puedo venir | *Ezin **dut etorri*** (NOR-NORK) o *Ezin **naiz etorri*** (NOR) |
| No puedo ir | *Ezin naiz joan* |
| No puedes hacer eso | *Ezin duzu hori egin* |
| No podía dormir | *Ezin nuen lo egin* |
| No se puede saber | *Ezin da jakin* |
| No podemos esperar | *Ezin dugu itxaron* |

> *Ezin* は主語の後に続き、分詞 + 助動詞を伴います。非常に多用されます。

## 過去形：*nezakeen / nintekeen / ezin nuen*

| 形 | 意味 |
|---|---|
| **nezakeen** | 私はそれをできた（可能法過去） |
| **zezakeen** | 彼はそれをできた |
| **nintekeen** | 私はできた（NOR 過去） |
| **ezin nintzen** | できなかった（NOR） |
| **ezin nuen** | できなかった（NOR-NORK） |

> *Atzo ezin nintzen joan, gaixorik nengoen.* — 昨日は病気だったので行けませんでした。

## 法助動詞 vs 助動詞：「君はそれをできる」の3つの形

1. **口語：** *Egin ahal duzu.* — 話し言葉で最も自然。
2. **総合形：** *Egin dezakezu.* — よりフォーマル、または書き言葉。
3. **ezinによる否定：** *Ezin duzu egin.* — 「君はそれをできない」の場合。

3つは共存しています。A2レベルでは、最初の2つを使いこなし、すべてを認識できるようにしましょう。

## 他の時制での *Ahal izan*

| スペイン語 | バスク語 |
|---|---|
| He podido ir | *Joan ahal izan naiz* |
| Podré ir | *Joan ahal izango naiz* |
| No he podido | *Ezin izan dut* |

## 日常的な例

- *Lagundu ahal didazu, mesedez?* — 手伝ってもらえますか？
- *Bihar ezin naiz etorri.* — 明日は来られません。
- *Hau uler dezaket.* — これは理解できます。
- *Ezin duzu hori egin.* — 君はそれをすることはできません。
- *Goazen lasai, denbora dugu eta.* — 時間があるから、落ち着いて行こう。
- *Etxea bihar eros daiteke.* — その家は明日買うことができます。

## ミニ会話

> *— Anboto, **etor zaitezke** bihar afaltzera?*
>
> *— Tira, **ezin dut**: lan asko daukat eta berandu arte ezin naiz mugitu. Baina hurrengo astean **etor naiteke**, eta zer ekar **dezaket**?*
>
> *— **Ekar dezakezu** ardo botila bat, hori asko gustatzen zaigu.*

> **学習上の注意：** A2レベルでは、「できない」を表す *ezin dut/naiz* と、質問する際の *ahal duzu?* をうまく使いこなすことが最も役立ちます。総合形（*dezaket, naiteke*）は、読解を通じて徐々に身につけていくでしょう。B1のユニットでさらに詳しく学びます。
