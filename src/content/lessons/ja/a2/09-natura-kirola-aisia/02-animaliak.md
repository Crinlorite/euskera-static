風景からそこに住む生き物へ：**動物** — 家の動物、農家の動物、そして森の動物。物語を語る複合語がたくさんある、覚えやすい単語です（*basurdea* = 「森の豚」）。

## 家で

| スペイン語 | バスク語 |
|---|---|
| 犬 | *txakurra* |
| 猫 | *katua* |
| 鳥 | *txoria* |
| 魚 | *arraina* |

> *Gure **txakurrak** hiru urte ditu eta **katuak** hamaika. Nagusia, katua — noski.* — 私たちの犬は3歳で、猫は11歳です。ボスはもちろん猫です。

## 農家（baserria）で

| スペイン語 | バスク語 |
|---|---|
| 牛 | *behia* |
| 羊 / 子羊 | *ardia / arkumea* |
| 馬 | *zaldia* |
| 豚 | *txerria* |
| 雌鶏 / 雄鶏 | *oiloa / oilarra* |
| ロバ | *astoa* |

> *Baserrian **behiak, ardiak eta oiloak** dituzte. Goizero **esnea eta arrautzak** hartzen dituzte.* — 農家では牛、羊、鶏を飼っています。毎朝、牛乳と卵をとります。

## 森と空で

| スペイン語 | バスク語 |
|---|---|
| イノシシ | *basurdea* |
| キツネ | *azeria* |
| オオカミ | *otsoa* |
| クマ | *hartza* |
| シカ | *oreina* |
| ハゲワシ | *putrea* |
| リス | *urtxintxa* |

> *Mendian **basurde bat ikusi genuen** — eta basurdea guri begira. Denok geldi-geldi!* — 山でイノシシを一頭見ました。そしてイノシシは私たちを見ていました。みんな、動かないで！
>
> *Pirinioetan **hartzak** daude berriro, gutxi baina badaude.* — ピレネー山脈には再びクマが生息しています。数は少ないですが、います。

## あなたの動物について話す

> ***Animaliarik baduzu**?* — 動物を飼っていますか？
>
> *Bai, **txakur bat daukat**. Mendira eramaten dut **egunero**.* — はい、犬を飼っています。毎日山に連れて行きます。
>
> *Katuak **ez du ezer egiten**… eta hala ere, **dena da berea**.* — 猫は何もしません…それでも、すべてが猫のものです。😄

> **注：**動物はバスク語の至る所に登場します：*Otsoa aipatu eta otsoa atari*（オオカミの話をすればオオカミが戸口に現れる＝噂をすれば影がさす）、*azeria baino azkarragoa*（キツネより賢い）など。また、Otxoa（オオカミ）、Artzak（クマ）、Azeri（キツネ）など、多くの姓にもなっています。動物たちは何世紀にもわたって、名前の中にも生き続けているのです。
