このユニットの2つ目のテーマは、**スポーツ** — するスポーツと観るスポーツです。そしてバスク地方には、世界の他のどこにもないスポーツがあります。

## いつものスポーツ

| スペイン語 | バスク語 |
|---|---|
| スポーツ | *kirola* |
| サッカー | *futbola* |
| バスケットボール | *saskibaloia* |
| 水泳 | *igeriketa* |
| サイクリング | *txirrindularitza* |
| ランニング | *korrika egin* |
| ハイキング | *mendi-ibilia* |
| ジム | *gimnasioa* |

## バスク地方のスポーツ

| スポーツ | 内容 |
|---|---|
| *pilota* | バスク・ペロタ、*frontoia*（フロントン）で行われます |
| *arrauna* | ボートレース — *traineras*（トライネラ）とコンチャの旗 |
| *herri kirolak* | 田舎のスポーツ：*aizkora*（斧）、*harri-jasotzea*（石）、*soka-tira*（綱引き） |

> *Herriko frontoian **pilota partida** dago larunbatean.* — 土曜日には村のフロントンでペロタの試合があります。
>
> *Irailean **estropadak** ikusten ditugu: gure herriko traineroa animatzera!* — 9月にはレガッタを見ます。村のトライネラを応援しに！

## 実践：動詞

> *Kirola **egiten dut**: astean bitan **entrenatzen naiz** eta igandeetan **korrika egiten dut**.* — 私はスポーツをします。週に2回トレーニングして、日曜日は走ります。
>
> ***Igeri badakizu**?* — 泳げますか？（*jakin*を使った能力の表現：*igeri dakit*、*dantzan dakit*…）
>
> *Gaztetan futbolean **jokatzen nuen**; orain **ikusi** bakarrik.* 😄 — 若い頃はサッカーをしていましたが、今は観るだけです。

## 試合

| スペイン語 | バスク語 |
|---|---|
| チーム | *taldea* |
| 試合 | *partida* |
| 勝つ / 負ける / 引き分ける | *irabazi / galdu / berdindu* |
| 結果 | *emaitza* |
| ゴールを決める | *gola sartu* |
| フィールド、競技場 | *zelaia* |

> *— Ikusi zenuen atzoko partida? **Zenbat** bukatu zen?* — 昨日の試合見た？スコアはどうだった？
>
> *— **2 eta 1 irabazi genuen**! Azken minutuan **gola sartu** zuten.* — 2対1で勝ったよ！最後の1分でゴールを決めたんだ。
>
> *— Aupa! Eta hurrengo astean **etxean jokatuko dute**?* — すごい！来週はホームで試合するの？
>
> *— Bai, igandean. **Zelaira joango gara**? Sarrera nire kontu!* — うん、日曜日にね。競技場に行こうか？チケットは僕が持つよ！

## 会話：何かに申し込む

> *— Kirol pixka bat egin nahi dut, baina gimnasioa **aspergarria** iruditzen zait.* — ちょっとスポーツをしたいんだけど、ジムは退屈だと思うんだ。
>
> *— **Zergatik ez zara** herriko igerilekura **apuntatzen**? Goizeko ordutegia oso ona da.* — 村のプールに申し込んだらどう？午前の時間帯はすごくいいよ。
>
> *— Ez dakit ba… **igeri badakit**, baina gaizki.* — うーん、どうかな… 泳げるけど、下手なんだ。
>
> *— Horretarako dira ikastaroak! Ni **astean bitan** joaten naiz. **Elkarrekin joango gara**?* — そのためのレッスンがあるじゃない！私は週に2回行ってるよ。一緒に行かない？
>
> *— Beno, ados. Baina gero **hamaiketakoa** ere elkarrekin, e?* 😄 — うん、わかった。でもその後、おやつも一緒にね？ 😄
