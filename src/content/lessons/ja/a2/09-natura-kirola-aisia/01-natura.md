新しい単元：**アウトドア**。まずは舞台となる場所から始めましょう — 山、森、川、そして海 — バスク地方では、これらは単なる背景ではありません。日曜日の計画であり、世俗的な宗教であり、尽きることのない会話のテーマなのです。

## 山

| スペイン語 | バスク語 |
|---|---|
| 山 | *mendia* |
| 山頂 | *gailurra* |
| 山腹 | *magala* |
| 森 | *basoa* |
| 木 | *zuhaitza* |
| 小道 | *bidezidorra* |
| 岩 | *harkaitza* |
| 谷 | *harana* |

> *Bidezidorretik gora, bi ordutan **gailurrera iritsiko gara**.* — 小道を登って、2時間で山頂に着きます。
>
> *Basoan barrena **ibili ginen**, eta ez genuen inor ikusi. Bakea.* — 森の中を歩きましたが、誰にも会いませんでした。静寂。

## 水

| スペイン語 | バスク語 |
|---|---|
| 川 | *ibaia* |
| 貯水池 / ダム | *urtegia* |
| 滝 | *ur-jauzia* |
| 海 | *itsasoa* |
| 浜辺 | *hondartza* |
| 波 | *olatuak* |
| 崖 | *labarra* |

> *Uda honetan ibaian **bainatuko gara**, hondartzan **jende gehiegi** dago eta.* — この夏は川で泳ぎます。浜辺は人が多すぎるので。（接尾辞 *-egi* と理由を示す *eta* が活躍していますね。）

## 風景を描写する

> *Hemendik **bista ikusgarria** dago: harana, basoa eta urrutian **itsasoa**.* — ここからは素晴らしい景色が見えます。谷、森、そして遠くには海。
>
> *Udazkenean basoa **kolore ederrekoa** da: horia, gorria, marroia.* — 秋には森が美しい色になります。
>
> *Zuhaitz hori **oso zaharra da** — ehun urte baino **gehiago** ditu.* — あの木はとても古いです。樹齢100年以上です。（単元04の比較級）

## 会話：日曜日の計画

> *— Igandean **mendira joango gara**? Anbotora, adibidez.*
>
> *— Anboto? Hori **gogorra** da niretzat! **Zerbait errazagoa**, mesedez…*
>
> *— Ados: Urkiolara **igoko gara**, bidezidor lasai batetik. **Gailurrean** hamaiketakoa.*
>
> *— Hamaiketakoarekin **konbentzitu nauzu**.* 😄

> **注：** *mendizaletasuna*（山への情熱）は、純粋なアイデンティティです。それぞれの村には「自分の」山があり、山頂には郵便受けが設置されています。*hamaiketakoa* — 11時のお昼ごはん — という言葉こそが、多くの人が山に登る本当の理由です。あまり大きな声では言わないでくださいね。
