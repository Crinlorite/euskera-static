何もしていない時は何をしますか？このレッスンでは**趣味**について、そして趣味について話す時に使われる文法、動詞を名詞化する **-tzea** (*irakurtzea* = 「読むこと」) について学びます。

## 文法の要素: -t(z)ea

A1レベルで、物に対して *gustatzen zait* を使うことを学びましたね (*kafea gustatzen zait*)。**活動**について「好き」と言うためには、動詞を名詞化します。

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| スペイン語 | バスク語 |
|---|---|
| 読書が好きです | *Irakurtzea gustatzen zait* |
| 料理が大好きです | *Asko gustatzen zait sukaldatzea* |
| 彼/彼女は歌うのが好きです | *Abestea gustatzen zaio* |
| 私たちは旅行が好きです | *Bidaiatzea gustatzen zaigu* |
| 早起きは全く好きではありません | *Ez zait batere gustatzen goiz jaikitzea* |

すでに知っているNOR-NORI (*zait, zaio, zaigu…*) のルールはそのまま適用されます。変わるのは「何が」の部分だけです。

## 趣味のカタログ

| スペイン語 | バスク語 |
|---|---|
| 読書 / 執筆 | *irakurtzea / idaztea* |
| 音楽を聴くこと | *musika entzutea* |
| 歌うこと / 踊ること | *abestea / dantzatzea* |
| 料理すること | *sukaldatzea* |
| 写真を撮ること | *argazkiak ateratzea* |
| 絵を描くこと / デッサンすること | *margotzea / marraztea* |
| 旅行すること | *bidaiatzea* |
| 家庭菜園の手入れ | *baratzea zaintzea* |
| テレビゲーム | *bideo-jokoak* |
| 裁縫 / 編み物 | *jostea / puntua egitea* |

## 質問したり、自分の趣味について話したり

> ***Zer egitea gustatzen zaizu** denbora librean?* — 自由な時間に何をするのが好きですか？
>
> ***Zein da zure zaletasunik gogokoena**?* — 一番好きな趣味は何ですか？
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — 私の一番好きな趣味は料理です。毎週末、新しいレシピを試しています。

## 3つの構造、3つのニュアンス（細かい復習）

| 構造 | 例 | 意味 |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | 〜するのが好きです（趣味） |
| **-tzen dakit** | *Margotzen dakit* | 〜できます（能力） |
| **-tzen ari naiz** | *Margotzen ari naiz* | 〜しています（現在進行形） |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — 編み物はできませんが、習ってみたいです。（この洗練された *gustatuko litzaidake* はB1レベルでマスターします — ここでは前菜として紹介しておきます。）

## 会話

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*
>
> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
>
> *— **Sukaldatzea** eta gero… **jatea**, noski.*
>
> *— Hori ere zaletasuna da?*
>
> *— Nire etxean, **kirola**.* 😄
