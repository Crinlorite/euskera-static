このレッスンは**統合的**な内容です：完了過去、未完了過去、進行形を組み合わせて、バスク語で使われる時制の組み合わせ方で**経験を語る**方法を学びます。

すでに学んだこと：

- *Iragan burutua* (レッスン1、2)：特定の時点での出来事。
- *Iragan ez burutua* (レッスン4)：習慣や描写。
- 過去形の統合動詞 (レッスン3)：進行中の場面を描写します。
- 過去を表す時間マーカー (*atzo*, *joan den astean*, *duela*...）。

今回は、これらを**つなげる**方法を学びます。

## 物語の構成

過去の典型的な物語では、機能に応じて時制を使い分けます：

| 機能 | 時制 | 例 |
|---|---|---|
| 時間的・空間的な設定 | 未完了過去 | *Garai hartan Bilbon **bizi ginen*** |
| どのような様子だったか | 未完了過去 | *Iluna **zen** kalea* |
| 何が起こったか（特定の時点） | burutua | *Bat-batean atea **jo zuten*** |
| 進行中の行動 | ari nintzen / 統合動詞 | *Afaria **prestatzen ari nintzen*** |
| 結果 | burutua | *Eta gauza guztiak **gertatu ziren*** |

## 時間をつなぐ言葉

出来事をつなげるために：

| 日本語 | バスク語 |
|---|---|
| まず / 最初に | *Lehenengo* / *Hasieran* |
| 次に | *Ondoren* |
| それから | *Gero* |
| その後 | *Geroago* |
| もっと後で | *Beranduago* |
| その間 | *Bitartean* |
| 突然 | *Bat-batean* |
| その時 | *Orduan* |
| 最後に / 最終的に | *Azkenean* |

## 経歴に関する重要なフレーズ

これらの構文は、どんな経歴や個人の物語にも登場します：

| 日本語 | バスク語 |
|---|---|
| 1990年に生まれました | *1990ean **jaio nintzen*** |
| Tolosaで育ちました | *Tolosan **hazi nintzen*** |
| バスク語を勉強しました | *Euskara **ikasi nuen*** |
| 22歳で働き始めました | *22 urterekin lanean **hasi nintzen*** |
| Anbotoに出会いました | *Anboto **ezagutu nuen*** |
| 恋に落ちました | *Maitemindu **nintzen*** |
| 2015年に結婚しました | *2015ean **ezkondu ginen*** |
| 娘が一人いました | *Alaba bat **izan genuen*** |
| 仕事を変えました | *Lana **aldatu nuen*** |
| ビルバオに戻りました | *Bilbora **itzuli ginen*** |

## 経歴に関するマーカー

| 日本語 | バスク語 |
|---|---|
| X年前に | *Duela X urte* |
| 1985年に | *1985ean* |
| X歳の時に | *X urterekin* |
| 私がX歳だった時 | *X urte nituenean* |
| その年に | *Urte hartan* |
| その時代に | *Garai hartan* |

## モデルテキスト：短い経歴

> *Garazi 1992an Iruñean **jaio zen**. Txikitan auzo lasai batean **bizi zen**, eta bere familia oso handia **zen**: lau anai-arreba **zituen** eta amona ondoan **zegoen**. Eskolan euskaraz **ikasten zuen**, eta hamabost urterekin musika tresnak **ikasten hasi zen**.*
>
> *Hemezortzi urterekin Donostiara **joan zen** unibertsitatera. Han Lander **ezagutu zuen**, kafetegi batean **lan egiten** **zuen** **bitartean**. **Maitemindu ziren** azkar, eta urtebete geroago **bizitzen hasi ziren** elkarrekin.*
>
> *Duela bost urte, **erabaki zuten** Bilbora itzultzea. Han etxe txiki bat **erosi zuten**, eta orain bertan **bizi dira** alaba batekin.*

構成に注目してください：

- *jaio zen, joan zen, ezagutu zuen, maitemindu ziren, hasi ziren, erabaki zuten, erosi zuten* → **burutua** (特定の時点での行動)。
- *bizi zen, zituen, zegoen, ikasten zuen, lan egiten zuen* → **ez burutua** (場面、背景、習慣)。

## 自分の物語の作り方

A2レベル向けの実践的な手順：

1. **時間設定**：マーカー (*Duela X urte... / X-ean...*) で始めます。
2. **場面**：未完了過去を使って、全体の様子を描写します (*bizi nintzen, lan egiten nuen, urruti nengoen...*)。
3. **重要な出来事**：物語の要点を *burutua* でつなげます (*ezagutu nuen, joan ginen, hasi nintzen...*)。
4. **接続詞**：*lehenengo, gero, ondoren, bitartean, azkenean* を散りばめて、話をスムーズにします。
5. **結び**：現在形で終わり、今とつなげます (*eta orain... bizi naiz / ari naiz / nago*)。

## 誰かにインタビューするための質問

| 日本語 | バスク語 |
|---|---|
| どこで生まれましたか？ | *Non jaio zinen?* |
| いつ働き始めましたか？ | *Noiz hasi zinen lanean?* |
| 子供の頃、何をしていましたか？ | *Zer egiten zenuen txikitan?* |
| LanderとAnboto、どちらに先に会いましたか？ | *Lehenengo nor ezagutu zenuen, Lander ala Anboto?* |
| あなたの町はどんなところでしたか？ | *Nolakoa zen zure herria?* |
| なぜ引っ越したのですか？ | *Zergatik aldatu zinen etxez?* |

> **A2レベルへの挑戦：** *burutua* と *ez burutua* を混ぜて、5文で自分の短い経歴を書いてみましょう。*jaio nintzen* で始め、子供時代の場面 (*bizi ginen, etxean...*) に続け、3つの重要な出来事をつなげ、現在形で締めくくります。

> **文化メモ：** 経歴や *bizipen-kontaketak*（体験談）は、大人のバスク語学習で非常によく使われるジャンルです。ほとんどのA2レベルの教科書には、高齢者、作家、スポーツ選手へのインタビューが含まれています。これは過去形を定着させる最良の方法であり、同時にBernardo Atxaga、Itziar Ituño、Mikel Erentxunのような文化的な著名人を知るきっかけにもなります。
