このレッスンでは、過去形を **NOR-NORK** 動詞（他動詞：私がそれを、君がそれを、彼がそれを）に広げます。これは、目的語を持つすべての行動（*食べた、見た、した、言った、買った、呼んだ...*）を語るための基礎です。

## 形式

> **partizipioa + nuen / zenuen / zuen / genuen / zenuten / zuten**

| 代名詞 | *dut* の過去形 | 日本語訳 |
|---|---|---|
| nik | **nuen** | 私がそれを |
| zuk | **zenuen** | 君がそれを |
| hark | **zuen** | 彼/彼女がそれを |
| guk | **genuen** | 私たちがそれを |
| zuek | **zenuten** | 君たちがそれを |
| haiek | **zuten** | 彼らがそれを |

> 活用形は**常に -n** で終わり、最初の文字が人称の目印です：**n-** (私)、**z-** (君/君たち/彼ら)、**g-** (私たち)。

## 複数目的語 — *nituen*

目的語が**複数**（本、チケット、ビール）の場合、助動詞は **-itu-** のシリーズに変わります：

| 代名詞 | 複数形助動詞 | 日本語訳 |
|---|---|---|
| nik | **nituen** | 私がそれらを |
| zuk | **zenituen** | 君がそれらを |
| hark | **zituen** | 彼/彼女がそれらを |
| guk | **genituen** | 私たちがそれらを |
| zuek | **zenituzten** | 君たちがそれらを |
| haiek | **zituzten** | 彼らがそれらを |

## 例文

| 日本語訳 | バスク語 |
|---|---|
| ピンチョスを食べた | *Pintxoak jan **nituen*** |
| 映画を一本見た | *Film bat ikusi **nuen*** |
| 彼らは夕食を作った | *Afaria egin **zuten*** |
| 彼は何と言った？ | *Zer esan **zuen**?* |
| 私たちはパンを買った | *Ogia erosi **genuen*** |
| 彼はバイクを2台売った | *Bi motoak saldu **zituen*** |

## 統合動詞：*eduki* と *jakin*

非常に頻繁に使われる2つの動詞は、現在形（*daukat, dakit*）と同様に、過去形でも**統合形**を保ちます：

### *Eduki* (持つ、所有)

| 代名詞 | 活用形 | 日本語訳 |
|---|---|---|
| ni | **neukan** | 私は持っていた |
| zu | **zeneukan** | 君は持っていた |
| hura | **zeukan** | 彼/彼女は持っていた |
| gu | **geneukan** | 私たちは持っていた |
| zuek | **zeneukaten** | 君たちは持っていた |
| haiek | **zeukaten** | 彼らは持っていた |

### *Jakin* (知る)

| 代名詞 | 活用形 | 日本語訳 |
|---|---|---|
| ni | **nekien** | 私は知っていた |
| zu | **zenekien** | 君は知っていた |
| hura | **zekien** | 彼/彼女は知っていた |
| gu | **genekien** | 私たちは知っていた |
| zuek | **zenekiten** | 君たちは知っていた |
| haiek | **zekiten** | 彼らは知っていた |

> *Anbotok bizikleta gorri bat **zeukan** umetan.* — アンボトは子供の頃、赤い自転車を持っていました。
>
> *Ez **zekien** non bizi ginen.* — 彼は私たちがどこに住んでいるか知りませんでした。

## NOR-NORK 過去形の2つの重要ポイント

**1. 主語の -k という標識。**現在形と同様に、行為を行う主語は能格を取ります：

> *Garazi**k** afaria egin **zuen**.* — ガラシは夕食を作りました。
>
> *Lander**rek** sarrerak erosi **zituen**.* — ランデルはチケットを買いました。

**2. 目的語との一致。**目的語が単数なら → *nuen / zuen*；複数なら → *nituen / zituen*。これは現在形と同じルールです。

## 否定

> *Atzo ez nuen filmik ikusi.* — 昨日、私は映画を一本も見ませんでした。
>
> *Ainarak ez zuen ezer esan.* — アイナラは何も言いませんでした。
>
> *Ez genituen sarrerak erosi.* — 私たちはチケットを買いませんでした。

> 否定文で目的語が使われる場合、通常は部分格で現れます：*filmik, ezer, txikirik*。これはA1で学んだのと同じ *-rik* です。

## 短い物語

> *Aurreko larunbatean Olatz eta Lander itsasora **joan ziren** (NOR). Hondartzan egun osoa **eman zuten**: igeri **egin zuten**, eguzkitan etzanda **egon ziren** eta liburu bat **irakurri zuten**. Iluntzean afari bat **prestatu zuten** eta lagunekin **afaldu zuten**.*

NOR (*joan ziren, egon ziren*) と NOR-NORK (*eman zuten, irakurri zuten, prestatu zuten*) の形がどのように混ざっているかに注目してください。この2つのレッスンが組み合わさって物語を語ります。

> **注：**次のレッスンでは、NOR の過去形を完成させる**統合動詞の過去形**（*nindoan, nentorren, nenbilen*）を学びます。
