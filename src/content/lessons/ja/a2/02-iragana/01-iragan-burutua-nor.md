A1レベルで**最近の過去**（*joan naiz*、*jan dut*）についてはすでに学びましたね。A2では、決定的な一歩として**完了過去**（*iragan burutua*）を学びます。これは、時間的に完結した、遠い、あるいはすでに隔たりのある出来事を語る際に使う「私は〜だった／いた／した／言った」に相当します。

この最初のレッスンでは、NOR動詞である**izan**と**egon**の過去形に焦点を当てます。

## *izan* (〜である) の過去形

| 人称代名詞 | 過去形 | 日本語 |
|---|---|---|
| ni | **nintzen** | 〜だった |
| zu | **zinen** | 〜だった |
| hura | **zen** | 〜だった |
| gu | **ginen** | 〜だった |
| zuek | **zineten** | 〜だった |
| haiek | **ziren** | 〜だった |

> ヒント：すべての活用形で語尾に**n**が現れます (n**intzen**, zi**nen**, ze**n**, gi**nen**, zi**ne**ten, zir**en**)。これはバスク語の過去形における典型的な目印です。

## *egon* (〜いる、ある) の過去形 — 統合形

*Egon*には、現在形の*nago/zaude/dago...*に対応する統合形の過去形があります：

| 人称代名詞 | 過去形 | 日本語 |
|---|---|---|
| ni | **nengoen** | 〜いた、あった |
| zu | **zeunden** | 〜いた、あった |
| hura | **zegoen** | 〜いた、あった |
| gu | **geunden** | 〜いた、あった |
| zuek | **zeundeten** | 〜いた、あった |
| haiek | **zeuden** | 〜いた、あった |

> 日常会話では、助動詞を使った**egon nintzen / egon zen**などの形も有効です。統合形はより丁寧、あるいは文学的な響きがありますが、非常によく耳にします。

## 使い分け：過去形の*izan* vs *egon*

現在形と同様に、過去形でも以下の使い分けを維持します：

- **性質・本質** → *izan*: *Egoitz medikua zen* (エゴイツは医者でした)。
- **一時的な状態・場所** → *egon*: *Egoitz pozik zegoen* (エゴイツは喜んでいました) / *Egoitz Bilbon zegoen* (エゴイツはビルバオにいました)。

## 完了過去を表す言葉

文が完結した過去を表すように、バスク語では次のような時を表す言葉を使います：

| 日本語 | バスク語 |
|---|---|
| 昨日 | *Atzo* |
| 昨夜 | *Bart* |
| おととい | *Herenegun* |
| 先週 | *Joan den astean* / *Aurreko astean* |
| 先月 | *Joan den hilean* |
| 去年 | *Joan den urtean* / *Iaz* |
| 2年前 | *Duela bi urte* |
| ずっと前 | *Aspaldian* / *Duela urte asko* |
| その時 | *Orduan* |
| 2010年に | *2010ean* |

## 代表的なパターン

> *Atzo ni etxean **nintzen** goiz osoan.* — 昨日、私は午前中ずっと家にいました。
>
> *Joan den urtean Garazi Frantzian **zegoen**.* — 去年、ガラシはフランスにいました。
>
> *Duela hamar urte ikaskideak **ginen**.* — 10年前、私たちはクラスメートでした。
>
> *Bart kalean jende asko **zegoen**.* — 昨夜、通りにはたくさんの人がいました。
>
> *Haurrak gu **ginen**, eta orain helduak gara.* — 子供だったのは私たちで、今は大人です。

## 否定文

現在形と同じく、動詞の前に**ez**を置きます。

> *Atzo ez nintzen lanean egon.* — 昨日、私は仕事場にいませんでした。
>
> *Ainara ez zegoen pozik orduan.* — その時、アイナラは嬉しくありませんでした。
>
> *Gu ez ginen ikaskideak.* — 私たちはクラスメートではありませんでした。

## 短文

> *Duela hamar urte Anboto Bartzelonan **bizi zen**. Han ikaslea **zen** eta unibertsitateko logelan **zegoen**. Pozik **zegoen** baina urruti **zegoen** familiatik. Astebururo telefonoz hitz egiten zuen amarekin.*

> **注：**この一節には、*zen* (〜だった)、*zegoen* (〜いた) と、今後のレッスンで学ぶ他の形が混在しています。これがユニット2の核心です：物語を語るために過去形を紡ぎ合わせること。
