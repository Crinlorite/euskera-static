バスク語の**半過去** (*iragan ez burutua*) は、大まかに言うと、スペイン語の「comía / vivía / iba / trabajaba」（食べていた・住んでいた・行っていた・働いていた）に相当します。次のようなことを語るのに使います：

- **過去の習慣**（習慣的にしていたこと）。
- **描写**（どうだったか、どこに住んでいたか、何を持っていたか）。
- ある特定の行動の背景となる**進行中の行動**。

## 作り方

> **動詞の-tzen / -ten形 + 過去形の助動詞**

現在形と半過去を比べてみましょう：

| 現在形（今日の習慣） | 半過去（過去の習慣） |
|---|---|
| *Lan egiten dut* (働いています) | *Lan egiten **nuen*** (働いていました) |
| *Bilbon bizi naiz* (住んでいます) | *Bilbon bizi **nintzen*** (住んでいました) |
| *Filmak ikusten ditut* (観ます) | *Filmak ikusten **nituen*** (観ていました) |
| *Egunero joaten naiz* (行きます) | *Egunero **joaten nintzen*** (行っていました) |

> 主動詞は**習慣**の形（-tzen / -ten — A1で習ったものと同じ）をとり、助動詞は**過去形**（レッスン1と2の形）になります。

## 助動詞NORとの活用（自動詞）

| 人称代名詞 | 半過去 | 日本語訳 |
|---|---|---|
| ni | *…tzen* **nintzen** | 私は行っていた・だった・住んでいた |
| zu | *…tzen* **zinen** | 君は行っていた |
| hura | *…tzen* **zen** | 行っていた・だった |
| gu | *…tzen* **ginen** | 私たちは行っていた・だった |
| zuek | *…tzen* **zineten** | 君たちは行っていた |
| haiek | *…tzen* **ziren** | 彼らは行っていた |

> *Garai hartan Donostian **bizi nintzen**.* — その頃、私はサン・セバスティアンに住んでいました。

> *Aitak afari berezia **prestatzen zuen** igandero.* — 父は毎週日曜日に特別な夕食を準備していました。

## Burutua vs ez burutua: 重要な対立

| 種類 | 形 | 意味 |
|---|---|---|
| Burutua (完了) | partizipioa + 過去の助動詞 | 一回きりの、完結した出来事 |
| Ez burutua (半過去) | -tzen + 過去の助動詞 | 習慣または進行中の行動 |

比べてみましょう：

| 日本語 | バスク語 |
|---|---|
| 昨日、職場へ行きました | *Atzo lanera **joan nintzen*** |
| 以前は自転車で職場へ行っていました | *Lehen lanera bizikletaz **joaten nintzen*** |
| 土曜日に映画を一本観ました | *Larunbatean film bat **ikusi nuen*** |
| 毎週土曜日に映画を観ていました | *Larunbatero filmak **ikusten nituen*** |

## 進行相: *ari nintzen*

「〜していた」と言うには、**ari** を使った迂言法を用います：

> **-tzen + ari + izan の過去形** (NOR)

| 日本語 | バスク語 |
|---|---|
| 食べていました | *Jaten **ari nintzen*** |
| 働いていました | *Lanean **ari ginen*** |
| 雨が降っていました | *Euria **ari zuen*** |
| 何をしていましたか？ | *Zer **ari zinen** egiten?* |

> 現在形の *ari naiz* と同様に、過去形では *ari nintzen* となります。特定の瞬間にその行動が**進行中**であったことを示すのに使います。

## 半過去を要求するマーカー

これらのマーカーは、文を半過去・習慣の意味合いに導きます：

| 日本語 | バスク語 |
|---|---|
| 子供の頃 | *Txikitan* |
| 若かった頃 | *Gaztea nintzenean* |
| その頃 | *Garai hartan* |
| 以前・昔 | *Lehen* / *Lehenago* |
| いつも | *Beti* |
| 毎日 | *Egunero* |
| しばしば | *Sarri* / *Askotan* |

## 比較ミニテキスト

> **Burutua:** *Atzo Iratiren etxera **joan nintzen**, kafea **hartu nuen**, eta hamabietan **itzuli nintzen**.* — 昨日、イラティの家に行き、コーヒーを飲み、12時に帰りました。
>
> **Ez burutua:** *Lehen Iratiren etxera **joaten nintzen** astero. Han kafea **hartzen genuen** eta luze **hitz egiten genuen**.* — 以前は毎週イラティの家に行っていました。そこでコーヒーを飲み、長く話していました。
>
> **Progresivoa:** *Atzo, kafea **hartzen ari ginela**, telefonoa jo zuen.* — 昨日、私たちがコーヒーを飲んでいると、電話が鳴りました。

## よくある間違い

1. **規則動詞 + -tzen** はほとんどの場合機能します。注意：*jan → jaten* (*jantzen* ではない)、*edan → edaten*、*egin → egiten*。これらはA1で覚えます。
2. **「estaba siendo」を文字通り訳さないでください**：バスク語では、半過去が描写的な過去の用法の多くをカバーしており、*ari* を追加する必要はありません。
3. **助動詞は**分詞 (*partizipio*) と同じです (*nintzen, nuen*)。変わるのは主動詞の形だけです。

> **実践的なまとめ：** 文が「何が起こったか？」という問いに答えるなら → *partizipio + 助動詞* (burutua)。「習慣的に何をしていたか？」または「どうだったか？」に答えるなら → *-tzen + 過去の助動詞* (ez burutua)。「その瞬間、何をしていたか？」に答えるなら → *-tzen ari + izan の過去形* (puntukaria)。
