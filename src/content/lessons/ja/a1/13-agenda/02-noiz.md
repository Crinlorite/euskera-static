予定について話すには、時を表す表現をマスターする必要があります。ここでは、過去・現在・未来の時間軸で使われる表現と、近い未来によく使われる表現を紹介します。

## 基本的な時間軸

| バスク語 | 日本語 |
|---|---|
| *atzo* | 昨日 |
| *gaur* | 今日 |
| *bihar* | 明日 |
| *etzi* | 明後日 |
| *etziluma / etzidamu* | 「明々後日」(あまり使われない) |

*atzo, gaur, bihar* という3つの短い単語と *etzi* — これだけで、日付に関する日常会話のほとんどに対応できます。

## `datorren` (「来る」)

「来週」や「来月」について話すには、**datorren** + 名詞を使います:

| バスク語 | 日本語 |
|---|---|
| *datorren astean* | 来週 |
| *datorren astelehenean* | 次の月曜日 |
| *datorren hilean* | 来月 |
| *datorren urtean* | 来年 |

`datorren` は「来る」という意味です（動詞 *etorri*「来る」の連体形です）。ひとつの塊として覚えることが重要です。

## 「この」 — `hau` / `honetan`

「今週」や「今週末」を表すには:

- *aste honetan* — 今週
- *asteburu honetan* — 今週末
- *hilabete honetan* — 今月

## その他の主要な表現

| バスク語 | 日本語 |
|---|---|
| *orain* | 今 |
| *gero* | 後で、その後 |
| *lehen* | 前に |
| *gaur goizean* | 今朝 |
| *gaur arratsaldean* | 今日の午後 |
| *gaur gauean* | 今夜 |
| *bihar goizean* | 明日の朝 |

> *Goiza* = 朝（一日のうちの時間帯）。*Bihar* = 明日（次の日）。これらは2つの異なる単語です。混同しないようにしましょう！

## 時間について質問する

- **Noiz?** — いつ？
- **Noiz etorriko zara?** — いつ来ますか？
- **Noiz egingo dugu afaria?** — いつ夕食にしますか？

## 文脈の中での例

- *Bihar mendira joango naiz.* — 明日、山に行きます。
- *Etzi euskara klasea dut.* — 明後日、バスク語の授業があります。
- *Datorren astean lan asko izango dut.* — 来週はたくさん仕事があります。
- *Asteburu honetan ez dut planik.* — 今週末は予定がありません。

> **文化メモ:** バスク語では、一日の時間帯としての「朝」は *goiza*、次の日としての「明日」は *bihar* です。*bihar goizean*（「明日の朝」）というフレーズは、この2つを組み合わせたものです。最初のうちはこのニュアンスを間違えやすいので、初めからしっかり覚えておくと良いでしょう。
