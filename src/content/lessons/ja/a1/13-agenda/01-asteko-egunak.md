予定やスケジュールについて話す前に、まず曜日を復習し、日常の活動と関連付けてみましょう。

## 7つの曜日

| バスク語 | 日本語 | ヒント |
|---|---|---|
| *astelehena* | 月曜日 | aste + lehen = 「週の最初の日」 |
| *asteartea* | 火曜日 | aste + arte = 「週の中」 |
| *asteazkena* | 水曜日 | aste + azken = 「労働週の最後の日」（歴史的） |
| *osteguna* | 木曜日 | egun = 日 |
| *ostirala* | 金曜日 | *osteguna* と同じく「空」を意味する語根 *ortzi/osti-* を持つ |
| *larunbata* | 土曜日 | larun + bata |
| *igandea* | 日曜日 | 歴史的な祝日 |

> **覚えるためのヒント：** **aste**（週）という単語は、平日の曜日の一番最初に出てきます。*Astelehen-*、*astear-*、*asteazken-* は、まるで週の初め、真ん中、終わりを声に出して数えているかのようです。

## 「月曜日に」と言うには — 接尾辞 `-(e)an`

ある出来事の日付を言うには、曜日に `-(e)an` を付けます：

| 曜日 | 「～曜日に」 |
|---|---|
| astelehena | astelehen**ean** |
| asteartea | astearte**an** |
| asteazkena | asteazken**ean** |
| osteguna | ostegun**ean** |
| ostirala | ostirale**an** |
| larunbata | larunbat**ean** |
| igandea | igande**an** |

- *Astelehenean lan egiten dut.* — 月曜日に働きます。
- *Larunbatean afaltzera joango gara.* — 土曜日に夕食を食べに行きます。

## 「毎週～曜日に」と言うには — 接尾辞 `-ero`

定期的な頻度を表すには：

- *astelehenero* — 毎週月曜日
- *larunbatero* — 毎週土曜日
- *egunero* — 毎日
- *astero* — 毎週
- *astebururo* — 毎週末

## 曜日 + アクティビティ：例文

| バスク語 | 日本語 |
|---|---|
| *Astelehenean kiroldegira noa.* | 月曜日にジムへ行きます。 |
| *Asteartean euskara klasea dut.* | 火曜日にバスク語の授業があります。 |
| *Ostiralean parranda egiten dugu.* | 金曜日に飲みに出かけます。 |
| *Larunbatean familiaren etxera joango naiz.* | 土曜日に実家（家族の家）へ行きます。 |
| *Igandean lasai gelditzen naiz etxean.* | 日曜日は家でゆっくり過ごします。 |

## Asteburua — 週末

`Asteburua`（週末）はとても便利な言葉です：

- *Asteburuan zer egingo duzu?* — 週末は何をしますか？
- *Asteburu honetan mendira joango naiz.* — 今週末は山へ行きます。
- *Asteburu pasa egitea gustatzen zait.* — 週末に小旅行をするのが好きです。

> **文化メモ：** *igandea* と並んで *jaieguna*（祝日）という言葉もよく目にします。*igandeak eta jaiegunak* という表現は、バスの時刻表、商店、市役所の掲示などでよく使われる決まり文句です。
