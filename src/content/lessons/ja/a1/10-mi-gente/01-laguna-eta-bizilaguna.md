このユニットでは、あなたの周りの人々、つまり**bizilagunak**（隣人）、**lagunak**（友達）、職場やクラスの人々に焦点を当てます。バスク語には、これらの関係性を区別するための的確な言葉があり、その多くが接尾辞**`-kide`**（「仲間／メンバー」）を共有しています。

## キーワード

| バスク語 | 日本語 | どのような関係か |
|---|---|---|
| *laguna* | 友達 | 個人的な信頼関係 |
| *lagun mina* | 親友 | 最大限の信頼関係 |
| *bizilaguna* | 隣人 | 同じ建物／玄関を共有 |
| *auzokidea* | 隣人 | 近所の人 |
| *ikaskidea* | クラスメート | バスク語学校、高校、大学 |
| *lankidea* | 同僚 | オフィスの |
| *ezaguna* | 知り合い | 顔は知っているが、関係は薄い |
| *ezezaguna* | 知らない人 | 面識がない |

## 接尾辞 -kide

バスク語で非常によく使われます。「メンバー／仲間」を意味します：

- **ikaskidea** = *ikas-* (勉強する) + *kide* → 学友
- **lankidea** = *lan* (仕事) + *kide* → 同僚
- **bikotekidea** = *bikote* (カップル) + *kide* → パートナー
- **bizikide** = *bizi* (住む) + *kide* → 同居人
- **pisukidea** = *pisu* (アパート) + *kide* → ルームメイト

> もし具体的な単語を思い出せない場合、*X-kidea* が緊急の解決策として機能します：「Xグループのメンバー／仲間」。

## Bizilaguna vs auzokidea

どちらも「隣人」と訳されますが、ニュアンスの違いがあります：

- **bizilaguna** → 同じ建物／玄関に住んでいる人。エレベーターや階段で会う人。
- **auzokidea** → より広い意味での近所の人。

日常会話では混同されますが、フォーマルな文脈（住民集会、玄関の掲示など）では通常**bizilaguna**が使われます。

## Koadrila — 単なる友達グループ以上のもの

**koadrila**はバスク地方特有の社会的な慣習です。通常、思春期に形成され、何十年も続く親しい友人たちのグループです。

- **Nire koadrilarekin afaltzera noa.** — 私のクアドリリャと夕食に行きます。
- **Bera nire koadrilakidea da.** — 彼は私のクアドリリャのメンバーです。

> **文化メモ：**「友達」と「koadrila」の違いは、クアドリリャは**定期的**に（毎週のように）集まり、独自のお決まりごと（日曜の食事、村の祭り、決まったバルをはしごするなど）があり、しばしば世襲される点です。つまり、子供たちが知り合い、親のクアドリリャに倣って自分たちのクアドリリャを形成するのです。
