誰かを紹介できるようになったら（*Hau X da*）、次の自然なステップは**その人が何をしているかを話すこと**です。どこに住んでいるか、どこで働いているか、何歳か、日々の生活はどんなものか。活用はすべて**三人称**で行うので、ここではそれを練習します。

## 質問

| 質問 | 日本語 |
|---|---|
| *Non bizi da?* | どこに住んでいますか？ |
| *Norekin bizi da?* | 誰と住んでいますか？ |
| *Zenbat urte ditu?* | 何歳ですか？ |
| *Zer da bera?* / *Zer egiten du?* | （職業は）何ですか？ / 何をしていますか？ |
| *Non egiten du lan?* | どこで働いていますか？ |
| *Ezkonduta dago?* | 結婚していますか？ |

## 答えのパターン

学んだことを組み合わせましょう。構造は **主語 + 補語 + 動詞** です。

| テーマ | 例文 |
|---|---|
| 居住 | *Bera **Iruñean bizi da**.* — パンプローナに住んでいます。 |
| 同居者 | *Bera **bikotekidearekin bizi da**.* — パートナーと住んでいます。 |
| 年齢 | *Bera**k hogeita hamar urte ditu**.* — 30歳です。 |
| 職業 | *Bera **medikua da**.* — 医者です。 |
| 仕事 | *Bera**k ospitalean lan egiten du**.* — 病院で働いています。 |

## 仕事場を表す位格 `-(e)an`

接尾辞 **`-(e)an`**（「〜で」）は、地区や住居についての課ですでに学んでいるはずです。ここでは誰かがどこで働いているかを言うために使います。

| 場所 | 例文 |
|---|---|
| ospitala（病院） | *ospitale**an** lan egiten du* |
| eskola（学校） | *eskola**n** lan egiten du* |
| taberna（バル） | *taberna**n** lan egiten du* |
| bulegoa（オフィス） | *bulego**an** lan egiten du* |
| denda（店） | *denda**n** lan egiten du* |
| euskaltegia（バスク語学校） | *euskaltegi**an** lan egiten du* |
| etxean（家で） | *etxean lan egiten du* |

> 覚えておきましょう：単語が本来の `-a`（tabern**a**）で終わる場合はそのまま保たれます → *tabernan*。子音で終わる場合（Madril）は `-e-` を挟みます → *Madrilen*。

## 職業 + 場所 = 完全な人物像

職業と場所を組み合わせることで、よりしっかりとした人物紹介ができます：

> *Bera **erizaina** da, eta **ospitalean lan egiten du**. **Iruñean bizi da, bikotekidearekin**, eta **bi seme-alaba ditu**.*

> *Hau Maialen da. Bera **kazetaria** da, **egunkari batean lan egiten du**. **Bilbokoa da, baina orain Donostian bizi da**.*

## 婚姻状態（役に立つ語彙）

| バスク語 | 日本語 |
|---|---|
| *ezkonduta dago* | 結婚している |
| *ezkongabea da* | 独身である |
| *banatuta dago* | 別居している |
| *dibortziatuta dago* | 離婚している |
| *alargun da* | （夫・妻と）死別している |

## 簡単な日課

誰かが普段していることを説明するには、家事の課ですでに見た **`-tzen` + du** のパターンを復習しましょう：

- *Goizean **lana hasten du** zortzietan.* — 8時に仕事を始めます。
- *Eguerdian **etxean bazkaltzen du**.* — 昼に家で昼食をとります。
- *Arratsaldean **kirola egiten du**.* — 午後にスポーツをします。

> A1レベルでは、単発の文で十分です。一日の行動をすべてつなげて話す必要はありません。誰かについて、はっきりしたことを3つ言えれば、もう立派な紹介になっています。
