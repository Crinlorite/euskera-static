バスク語で髪と目を描写するには、スペイン語のように（「私は黒髪です」のように）**izan**（～である）は使わず、**ukan**（持っている）を使います：*tengo el pelo negro*（私は黒い髪を持っている）、*tengo los ojos azules*（私は青い目を持っている）。

## 髪: ile

「髪」を意味する単語は **ile** です（定冠詞付き：*ilea*）。形容詞は後ろに置かれ、最後の形容詞にのみ接尾辞 `-a` が付きます：

| バスク語 | 日本語 |
|---|---|
| *ile beltza* | 黒い髪 |
| *ile horia* | 金髪 |
| *ile zuria* | 白髪 |
| *ile gorria* | 赤毛 |
| *ile urdina* | グレーの髪 |
| *ile motza* | 短い髪 |
| *ile luzea* | 長い髪 |
| *ile lisoa* | ストレートの髪 |
| *ile kizkurra* | 巻き毛 |

> バスク語では、髪はスペイン語と同様に**単数**として扱われます。そのため、*dut* / *du* を使います（*ditut* / *ditu* ではありません）。

- *Ile beltza eta luzea **dut**.* — 私は黒くて長い髪をしています。
- *Maialenek ile kizkurra **du**.* — Maialenは巻き毛です。

## 目: begiak

髪とは異なり、「目」は**複数形** (*begiak*) です。そのため、形容詞も複数形 (`-ak`) になり、**ditut / ditu** を使います：

| バスク語 | 日本語 |
|---|---|
| *begi urdinak* | 青い目 |
| *begi marroiak* | 茶色い目 |
| *begi berdeak* | 緑の目 |
| *begi beltzak* | 黒い目 |
| *begi argiak* | 明るい色の目 |
| *begi ilunak* | 暗い色の目 |

- *Begi urdinak **ditut**.* — 私は青い目をしています。
- *Mikelek begi marroiak **ditu**.* — Mikelは茶色い目をしています。

## その他の特徴: 接尾辞 -dun

「Xを身につけている」や「X付きの」と言うために、バスク語には非常に生産的な接尾辞 **-duna**（単数）/ **-dunak**（複数）があります。これは名詞に付き、その人は「メガネの人」、「ヒゲの人」のようになります…

| バスク語 | 日本語 |
|---|---|
| *betaurrekoduna* | メガネをかけている / メガネの人 |
| *bizarduna* | ヒゲを生やしている |
| *biboteduna* | 口ヒゲを生やしている |
| *burusoila* | ハゲ（文字通りには「剥げた頭」） |

これらは **izan** と一緒に使われます。なぜなら、形容詞のように性質を表すからです：

- *Hura biboteduna da.* — 彼は口ヒゲを生やしています。
- *Nire aitona burusoila da.* — 私の祖父はハゲています。

## すべてを組み合わせる

典型的な人物描写では、いくつかの構文が混ざります：

> *Maialen txikia eta argala da. Ile gorria eta kizkurra du. Begi berdeak ditu. Betaurrekoduna da.*
>
> Maialenは背が低くて痩せています。彼女は赤毛の巻き毛です。緑の目をしています。メガネをかけています。

どのように使い分けられているか見てみましょう：一般的な性質には **izan**（*txikia da*）、髪や目には **ukan**（*ile … du*, *begi … ditu*）、そして、身につけているものには再び **izan** と共に *-dun*-a を使います。
