誰かの外見を説明した後は、その人の**内面**、つまり性格や人柄について話すのが自然です。バスク語では、これらの性格を表す形容詞も、外見の形容詞と同じように **izan** + 形容詞 + `-a` の形で構成されます。

## 性格に関する基本語彙

形容詞は、ほとんどが反対語のペアで出てきます：

| バスク語 | 日本語 | 反対語 |
|---|---|---|
| *alaia* | 陽気な | *triste* (悲しい — ただし、これは状態を表します) |
| *jatorra* | 感じの良い、親切な | — |
| *atsegina* | 親切な、感じの良い | — |
| *ona* | 良い | *txarra* (悪い) |
| *isila* | 無口な | *berritsua* (おしゃべりな) |
| *lasaia* | 落ち着いた | *urduria* (神経質な) |
| *langilea* | 働き者の | *alferra* (怠け者の) |
| *ausarta* | 勇敢な | *beldurtia* (臆病な) |
| *zintzoa* | 真面目な、誠実な | *bihurria* (いたずら好きな、わんぱくな) |
| *serioa* | 真面目な | — |
| *lotsatia* | 内気な、恥ずかしがり屋の | — |
| *bikaina* | 素晴らしい、優秀な | — |

> これらの形容詞の多くは、名詞 + 接尾辞から作られています。例えば、*langile* は *lan* (「仕事」) から、*beldurti* は *beldur* (「恐怖」) から来ています。A1レベルでこの内部ロジックを学ぶ必要はありませんが、覚える助けにはなるでしょう。

## 構造：外見の形容詞と同じ

- *Maialen oso **alaia** da.* — マイアレンはとても陽気です。
- *Egoitz **isila eta serioa** da.* — エゴイツは無口で真面目です。
- *Gu **langileak** gara.* — 私たちは働き者です。
- *Haiek **bihurriak** dira.* — 彼らはいたずら好きです。
- *Ni ez naiz oso **lotsatia**.* — 私はあまり内気ではありません。

## 複数の形容詞をつなげる

誰かを紹介するとき、3〜4つの特徴を続けて言うのはとても自然な方法です。バスク語では、最後の形容詞の前にだけ接続詞 **eta** (「〜と」) を使います：

> *Nire arreba alaia, jatorra **eta** langilea da.*
>
> 私の姉（妹）は陽気で、感じが良くて、働き者です。

## ニュアンスを加える "oso" と "nahiko"

- **oso** alaia → とても陽気な
- **nahiko** isila → かなり無口な
- **ez** oso urduria → あまり神経質ではない
- **ez** zara batere alferra → 君は全く怠け者ではない (*batere* は否定を強調します)

## 全文例

> *Nire ama oso jatorra eta atsegina da. Lasaia da, baina nire aita urduria da. Anaia bihurri samarra da, baina ni zintzoa naiz!*
>
> 私の母はとても感じが良くて親切です。母は落ち着いていますが、父は神経質です。私の兄（弟）はかなりいたずら好きですが、私は真面目です！
