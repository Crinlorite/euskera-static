誰かと知り合うための基本的な質問の一つは **Norekin bizi zara?** —「誰と住んでいますか？」です。答えには、バスク語で仲間を表す「〜と」にあたる、**共格**と呼ばれる接尾辞 **`-(r)ekin`** を使います。

## 接尾辞 `-rekin`

冠詞の付いた名詞に付け加えます：

| 名詞 | + -(r)ekin | 意味 |
|---|---|---|
| laguna (友達) | **lagunarekin** | 友達と |
| ama (母) | **amarekin** | 母と |
| anaia (兄・弟) | **anaiarekin** | 兄・弟と |
| txakurra (犬) | **txakurrarekin** | 犬と |
| bikotekidea (パートナー) | **bikotekidearekin** | パートナーと |

> 固有名詞や *bat* と一緒に使う場合は、冠詞なしで直接 **-(e)kin** を付けます：*Miren + ekin → Mirenekin* (ミレンと)、*lagun batekin* (一人の友達と)。

## 複数形

| 複数形 | + -ekin | 意味 |
|---|---|---|
| gurasoak (両親) | **gurasoekin** | 両親と |
| lagunak (友達) | **lagunekin** | 友達と |
| pisukideak (ルームメイト) | **pisukideekin** | ルームメイトと |
| seme-alabak (子供たち) | **seme-alabekin** | 子供たちと |

## 一人暮らし

一人で住んでいる場合は、`-rekin` を使う必要はありません：

- **Bakarrik bizi naiz.** — 一人で住んでいます。
- **Bakarrik bizi naiz, baina katu batekin.** — 一人で住んでいますが、猫と一緒です。

## 一般的な同居の形態

| 状況 | 言い方 |
|---|---|
| 一人 | *Bakarrik bizi naiz.* |
| 両親と | *Gurasoekin bizi naiz.* |
| パートナーと | *Bikotekidearekin bizi naiz.* |
| 夫と／妻と | *Senarrarekin / Emaztearekin bizi naiz.* |
| ルームメイトと | *Pisukideekin bizi naiz.* |
| 子供たちと | *Seme-alabekin bizi naiz.* |
| 友達（一人）と／友達（複数）と | *Lagun batekin / Lagunekin bizi naiz.* |

## 賃貸か持ち家か

- **Alokairuan bizi naiz.** — 賃貸に住んでいます。
- **Nire pisua da.** — （これは）私の持ち家（アパート）です。
- **Errenta gora doa.** — 家賃が上がっています。*(口語)*

## 会話例

> — *Kaixo Maialen! Norekin bizi zara?*
>
> — *Bi pisukiderekin bizi naiz Iruñean. Eta zu?*
>
> — *Ni bakarrik, baina txakur batekin. Etxea handia da?*
>
> — *Ez, txikia. Hiru logela ditu.*

> **注：** *bikotekide* は現代的で中立的な言葉で、結婚しているかどうかにかかわらず、異性愛・同性愛のカップル両方に使えます。「夫」と「妻」には、引き続き **senarra** と **emaztea** が使われます。
