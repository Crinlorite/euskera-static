まずは、どんな住居にもある基本的なもの、**部屋**から始めましょう。「部屋」を意味する一般的な単語は **gela** で、ほとんどの部屋の名前は語幹に `-gela` を付けて作られます。

## 基本単語

| バスク語 | 日本語 |
|---|---|
| *etxea* | 家 |
| *pisua* | アパート・マンション（集合住宅） |
| *gela* | 部屋 |
| *sukaldea* | キッチン・台所 |
| *logela* | 寝室 |
| *komuna* | トイレ・浴室 |
| *egongela* | リビング・居間 |
| *sarrera* | 玄関 |
| *korridorea* / *pasabidea* | 廊下 |
| *balkoia* | バルコニー |
| *terraza* | テラス |

## 単語の成り立ち

バスク語のこれらの単語は非常に分かりやすいです。どのように構成されているかを見ると、覚えやすくなります。

- **logela** → *lo* (睡眠) + *gela* (部屋) = 「睡眠の部屋」 → 寝室
- **egongela** → *egon* (いる・ある) + *gela* (部屋) = 「いるための部屋」 → リビング
- **sukaldea** → *su* (火) + *aldea* (場所) = 「火の場所」 → キッチン

> **Komuna** と **bainugela** は同義語です。*komuna* は日常的な言葉で、*bainugela*（文字通り「お風呂の部屋」）は少しフォーマルな言い方です。

## 建物：階とエレベーター

| バスク語 | 日本語 |
|---|---|
| *solairua* | 階（1階、2階…） |
| *igogailua* | エレベーター |
| *eskailera* | 階段 |
| *ataria* | （建物の）玄関ホール |

何階に住んでいるか言うには：

- *Hirugarren solairuan bizi naiz.* — 私は3階に住んでいます。
- *Etxeak igogailua du.* — この家にはエレベーターがあります。

## 便利な質問

- **Zenbat gela ditu zure etxeak?** — あなたの家には部屋がいくつありますか？
- **Zenbat logela ditu?** — 寝室はいくつありますか？
- **Non dago sukaldea?** — キッチンはどこですか？
- **Etxeak badu balkoirik?** — その家にはバルコニーがありますか？

> **文化メモ：** ナバラ州やスペインのバスク地方では、都市部の住居には *pisua*、実家や田舎の家には *etxea* を使うのが一般的です。日常会話では問題なく混同して使われます。
