このレッスンでは、テーマ9で学んだすべて（部屋、家具、家事、誰と住んでいるか）をまとめます。目標は、授業や気軽な会話で質問されたかのように、簡単な文章で**自分の家を説明できる**ようになることです。

## 基本的な質問

| 質問 | 日本語 |
|---|---|
| *Non dago zure etxea?* | あなたの家はどこにありますか？ |
| *Nolakoa da?* | どんな家ですか？ |
| *Zenbat gela ditu?* | 部屋はいくつありますか？ |
| *Norekin bizi zara?* | 誰と住んでいますか？ |
| *Zenbatgarren solairuan bizi zara?* | 何階に住んでいますか？ |
| *Etxeak badu igogailua / balkoia / terraza?* | その家にはエレベーター／バルコニー／テラスがありますか？ |

## 家を説明するのに便利な形容詞

| バスク語 | 日本語 |
|---|---|
| *handia* | 大きい |
| *txikia* | 小さい |
| *argitsua* | 明るい |
| *iluna* | 暗い |
| *berria* | 新しい |
| *zaharra* | 古い |
| *lasaia* | 静かな |
| *zaratatsua* | うるさい |
| *erosoa* | 快適な |
| *garestia* | （値段が）高い |
| *merkea* | 安い |

> 他のユニットで学んだ **NOLAKOA da?** のパターンを思い出しましょう。答えは「形容詞 + 語末の`-a` + 動詞*izan*」という形になります。例：*Nire etxea **handia da**.* — 私の家は大きいです。

## モデル文

ここに家を説明する簡単な文章があります。声に出して読み、パターンに注目しましょう。

> *Ni Iruñean bizi naiz, auzo lasai batean. Nire etxea ez da oso handia: hiru gela ditu — bi logela eta egongela bat — sukaldea eta komuna. Egongela argitsua da, eta balkoi bat dauka. Hirugarren solairuan dago, eta etxeak igogailua du.*
>
> *Bikotekidearekin bizi naiz. Berak bazkaria prestatzen du, eta nik ontziak garbitzen ditut. Asteburuetan biok elkarrekin egiten dugu erosketa.*

## あなたの番です：自分の家を説明してみましょう

この順番で質問に答えて、自分自身の文章を作ってみましょう：

1. **Non bizi zara?** (どこに住んでいますか？) → *X-(e)an bizi naiz.*
2. **Nolakoa da etxea?** (どんな家ですか？) → *Nire etxea handia / argitsua / lasaia da.*
3. **Zenbat gela ditu?** (部屋はいくつありますか？) → *Bi / Hiru / Lau gela ditu.*
4. **Zer dago etxean?** (何がありますか？) → *Sukaldea, egongela, bi logela eta komun bat ditu.*
5. **Norekin bizi zara?** → *Bakarrik / Gurasoekin / Lagunekin bizi naiz.*
6. **Etxeko lanak nork egiten ditu?** → *Nik egunero garbitzen dut* / *Pisukideen artean banatzen ditugu.*

## 締めくくりの語彙

| バスク語 | 日本語 |
|---|---|
| *etxebizitza* | 住居 |
| *etxejabea* | 家主、オーナー |
| *alokairua* | 賃貸 |
| *errenta* | 家賃 / 月々の賃料 |
| *auzoa* | 近所、地区 |
| *erdigunea* | （街の）中心部 |
| *aldiriak* | 郊外 |

> **アドバイス：**授業で自分の家について話すとき、細部まで全てを訳そうとしないでください。短くて正しい文章を使いましょう。間違いだらけの長い文章よりも、*"Bi logela ditut, sukalde txiki bat eta egongela handia"* のような表現の方が良い説明になります。
