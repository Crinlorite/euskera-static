このレッスンでは、**etxeko lanak**（家の仕事、家事）について話すための基本的な動詞を学びます。バスク語では、動詞は通常**分詞**（`-tu`、`-i`、`-n`）の形で示されます。これが「辞書形」です。例：*garbitu*、*prestatu*、*jaso*…

## 主な動詞

| バスク語 | 日本語 |
|---|---|
| *garbitu* | 掃除する |
| *prestatu* | 準備する |
| *jaso* | 片付ける |
| *jantzi* | 着せる / 置く |
| *atera* | 出す |
| *zabaldu* | 干す / 開ける |
| *lisatu* | アイロンをかける |
| *paseatu* | 散歩させる |
| *erosi* | 買う |

## 一般的な家事

| 家事 | 言い方 |
|---|---|
| ベッドを整える | *ohea jantzi* |
| 皿を洗う | *ontziak garbitu* / *harrikoa egin* |
| 掃除機をかける | *xurgagailua pasa* |
| 洗濯物を干す | *arropa zabaldu* |
| 服にアイロンをかける | *arropa lisatu* |
| トイレを掃除する | *komuna garbitu* |
| ゴミを出す | *zaborra atera* |
| 食事を準備する | *bazkaria prestatu* |
| 買い物をする | *erosketak egin* |
| 犬の散歩をする | *txakurra paseatu* |

## 辞書形から現在の習慣へ

ある行動が習慣的に（毎日、毎週など）繰り返される場合、動詞は `-tzen` + 助動詞 **dut/duzu/du…**（*ukan* で学習済み）の形に変わります。

| 人称 | 例文 | 日本語 |
|---|---|---|
| Nik | *Nik etxea **garbitzen dut**.* | 私は家を掃除します。 |
| Zuk | *Zuk arropa **lisatzen duzu**.* | あなたは服にアイロンをかけます。 |
| Berak | *Aitak bazkaria **prestatzen du**.* | 私の父は食事を準備します。 |
| Guk | *Guk erosketak **egiten ditugu**.* | 私たちは買い物をします。 |

> このレッスンでは、活用のすべてをマスターする必要はありません。日常の習慣について話すために、**`-tzen` + dut/du** のパターンを覚えておきましょう。

## 頻度

どのくらいの頻度で家事をするかを言うには：

- **egunero** — 毎日
- **astean behin** — 週に1回
- **astean bitan / hirutan** — 週に2回 / 3回
- **noizean behin** — ときどき
- **inoiz ez** — 決して〜ない

> *Nire etxean nik **astean behin** lisatzen dut, baina **egunero** garbitzen dut sukaldea.* — 私の家では、私は週に1回アイロンをかけますが、キッチンは毎日掃除します。

## 誰が何をするか尋ねる

- **Nork garbitzen ditu ontziak?** — 誰が皿を洗いますか？
- **Nor arduratzen da arropaz?** — 誰が洗濯物の担当ですか？
- **Zuri gustatzen zaizu sukaldatzea?** — 料理は好きですか？

> **文化メモ：** 家庭での家事分担に関するアンケートは、バスク語学校（euskaltegi）の教科書で定番のテーマです。それには理由があります。友人や家族との実際の会話で非常に役立つ語彙だからです。
