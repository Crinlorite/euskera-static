両親、兄弟、子供の他にも、おじ、いとこ、甥・姪、義理の家族など、親戚はたくさんいます。ここでは、よく使われる語彙を紹介します。

## おじ・おばといとこ

| バスク語 | 日本語 |
|---|---|
| *osaba* | おじ |
| *izeba* | おば |
| *lehengusu* | いとこ (男) |
| *lehengusina* | いとこ (女) |
| *iloba* | 甥・姪 (一部の方言では「孫」も意味します — 文脈で判断します) |

## 義理の家族

| バスク語 | 日本語 |
|---|---|
| *aitaginarreba* | 義父 |
| *amaginarreba* | 義母 |
| *koinatu* | 義理の兄弟 |
| *koinata* | 義理の姉妹 |
| *errain* | 嫁 |
| *suhi* | 婿 |

## 使用例

- *Nire osaba Bilbon bizi da.* — 私のおじはビルバオに住んでいます。
- *Bere lehengusinak hamabi urte ditu.* — 彼/彼女のいとこ（女）は12歳です。
- *Zure koinata euskalduna da?* — あなたの義理の姉妹はバスク人ですか？

> 義理の家族を表す言葉は、既存の単語を組み合わせて作られることがよくあります (*aita-* + *ginarreba*)。その内部的な仕組みを覚える必要はありません。使いながら自然に身につきます。
