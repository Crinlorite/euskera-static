「どこに住んでいますか」のレッスンで、接尾辞**`-(e)an`**はもう学びましたね (*Bilbon bizi naiz*)。ここでは、それを近隣の場所に応用して、物がどこにあるかを表現します。

## 質問：Non dago…?

**〜はどこにありますか？**と尋ねるには、次を使います：

- **Non dago …?** — 〜はどこにありますか？（主語が単数）
- **Non daude …?** — 〜はどこにありますか？（主語が複数）
- **Non zaude?** — （あなたは）どこにいますか？
- **Non nago?** — （私は）どこにいますか？

動詞は**egon**（いる、ある）です。挨拶の課で出てきましたね。活用形を復習しましょう：

| 人称 | 活用形 |
|---|---|
| ni | **nago** |
| zu | **zaude** |
| hura | **dago** |
| gu | **gaude** |
| zuek | **zaudete** |
| haiek | **daude** |

## 答え方：場所 + `-(e)an` + dago

何かが**どこにあるか**を言うには、場所に接尾辞**`-(e)an`**を付けます：

| 場所の語末 | パターン | 例 |
|---|---|---|
| -a（*Donostia* のように語幹の一部） | + n | Donostia → **Donostian** |
| -a 以外の母音（*mendi*, *kale-*) | + an | mendi → **mendian** |
| 子音（*Madril*, *lur*） | + en（固有名詞）/ + ean（普通名詞） | Madril → **Madrilen**; lur → **lurrean** |

> *kale*（通り）のような単語についての注意点：定冠詞が付いて *kalea*（その通り）となっている場合、接尾辞を付ける前に、冠詞の`-a`を取り除きます：*kalea* → *kale-an* = **kalean**（通りに）。

## 例文

- **Botika kalean dago.** — 薬局は通りにあります。
- **Liburuak mahaian daude.** — 本はテーブルの上にあります。
- **Ikaslea ikasgelan dago.** — 生徒は教室にいます。
- **Aita tabernan dago.** — お父さんはバルにいます。
- **Ni euskaltegian nago.** — 私はエウスカルテギ（バスク語学校）にいます。
- **Bilbo Bizkaian dago.** — ビルバオはビスカヤにあります。

## ミニ会話

> — *Aupa! **Non dago** liburutegia?* — こんにちは！図書館はどこにありますか？
>
> — *Liburutegia plazan dago, eskolaren ondoan.* — 図書館は広場にあります、学校の隣です。
>
> — *Eskerrik asko!*

> **ヒント：**バスク語の *non* は「どこ」という意味です。*non…?* への答えには、接尾辞`-(e)an`が付いた名詞か、場所の副詞（*hemen*, *hor*, *han* — これらは次のレッスンで学びます）が使われます。
