このレッスンでは、このユニットで学んだすべてをまとめます：場所に関する語彙、場所格 `-(e)an`、空間的な位置（*aurrean*、*ondoan*…）、そして**存在 / 所在**（*badago* / *dago*）の区別です。このレッスンを終えれば、自分の近所や町について、実践的な文章で説明できるようになります。

## 説明の構成

近所や町についての典型的な説明は、次のような順序で進みます：

1. **どんな場所か**（大きさ、特徴）：*Nire auzoa txikia eta polita da.*
2. **何があって**何がないか：*Auzoan badago liburutegia, baina ez dago zinemarik.*
3. **主なものがどこにあるか**：*Liburutegia plazaren ondoan dago.*
4. **自分がどこに**誰と住んでいるか：*Ni Maialenen ondoan bizi naiz, etxe txiki batean.*

## 説明に使う語彙

| バスク語 | 日本語 |
|---|---|
| *handi* | 大きい |
| *txiki* | 小さい |
| *ertain* | 中くらいの |
| *polit* | きれいな |
| *itsusi* | 醜い |
| *zaharra* | 古い |
| *berria* | 新しい |
| *lasai* | 静かな |
| *jendetsu* | 人が多い |
| *modernoa* | モダンな |
| *erdigunean* | 中心部に |
| *kanpoaldean* | 郊外に |

> 覚えておきましょう：バスク語の形容詞は**名詞の後ろに**置かれ、定冠詞`-a`が付きます。*Auzo + handi + a* → *auzo handia*（「その大きな地区」）; *auzo + txiki + a* → *auzo txikia*。

## すべてを組み合わせる：モデル例文

> *Ni Iruñean bizi naiz, Txantrea auzoan. Auzoa ez da oso handia, baina lasaia eta polita da. Auzoan badago supermerkatu txiki bat, bi taberna eta okindegi bat. Eskola plazaren ondoan dago, eta liburutegia eskolaren atzean. Parkea handia da, eta umeentzat oso ona. Auzoan ez dago zinemarik, baina hori ez da arazoa: zinema erdigunean dago, eta gertu dago. Nire etxea bigarren solairuan dago, kale lasai batean.*

訳：

> 私はパンプローナのTxantrea地区に住んでいます。この地区はあまり大きくありませんが、静かで素敵な場所です。地区には小さなスーパーが1軒、バルが2軒、パン屋が1軒あります。学校は広場の隣にあり、図書館は学校の後ろにあります。公園は広く、子供たちにとってとても良い場所です。地区に映画館はありませんが、問題ありません。映画館は中心部にあり、近いです。私の家は静かな通りの2階にあります。

## よくされる質問

| 質問 | 回答のタイプ |
|---|---|
| ***Non bizi zara?*** | 場所 + 場所格: *X-(e)an bizi naiz.* |
| ***Nolakoa da zure auzoa?*** | 形容詞: *Polita da, txikia da…* |
| ***Zer dago zure auzoan?*** | 存在: *Badago…, badaude…* |
| ***Ba al dago tabernarik?*** | はい/いいえ: *Bai, badago / Ez, ez dago tabernarik.* |
| ***Non dago liburutegia?*** | 位置: *Plazaren ondoan dago.* |

## あなたの番です

あなたのパートナーがあなたの近所を知らないと想像して、説明してみましょう：

1. 名前と場所。
2. 大きいか小さいか、古いか新しいか。
3. **ある**場所を3つ（*badago / badaude* を使って）。
4. **ない**ものを3つ（*ez dago … rik* を使って）。
5. あなたの家が具体的にどこにあるか（通り、階数、何かの隣など）。

> **文化メモ：**多くのバスクの地区や町では、**frontoia**（ペロタ競技場）と**eliza**（教会）が目印になります。これらは通常、メインの広場の近くに隣接しています。もしあなたの近所に広場、フロントン、教会があれば、誰かに道を教える際の最高の目印になります。
