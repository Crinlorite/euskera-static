バスクのバル文化は、主に3つの形式を中心に成り立っています。**pintxo**（ピンチョ：カウンターで食べる小さな一品）、**ogitarteko**（オギタルテコ：サンドイッチ）、そして**plater konbinatua**（プラテル・コンビナトゥア：盛り合わせプレート）です。これらのバリエーションの頼み方を知っておけば、どこでも食事を楽しめます。

## 3つの形式

| バスク語 | 日本語 | サイズ |
|---|---|---|
| *pintxoa* | ピンチョ／タパス | 小さい、カウンターで食べる |
| *ogitartekoa* | サンドイッチ | 中くらい、パンに挟んだもの |
| *plater konbinatua* | 盛り合わせプレート | 一食分の食事 |
| *razioa* | ラシオン（大皿料理） | 取り分け用 |

> **Ogitarteko**は文字通り「パンの間のもの」を意味します。*ogi*（パン）+ *arte*（間）+ *-ko* です。昔ながらのサンドイッチですが、上質なバスクのパンとたっぷりの具材で作られています。

## 定番の具材

これらは、バルの黒板でよく見かける、最も一般的な具材です。

| バスク語 | 日本語 |
|---|---|
| *tortilla* | トルティージャ（ジャガイモ入り） |
| *txistorra* | チストラ |
| *txorizoa* | チョリソ |
| *gazta* | チーズ |
| *urdaiazpikoa* | ハム |
| *antxoa* | アンチョビ |
| *atuna* | ツナ |
| *gilda* | ヒルダ（アンチョビ＋青唐辛子＋オリーブ） |

## 注文するための組み合わせ方

注文の仕方は、**内容を表す言葉 + 形式 + bat (mesedez)** です。内容を表す言葉（何が入っているか）を先に言います。

- *Tortilla **pintxo bat**, mesedez.* — トルティージャのピンチョを一つ、お願いします。
- *Gazta **ogitartekoa**, mesedez.* — チーズのサンドイッチをお願いします。
- *Txistorra **razio bat** hartuko dugu.* — チストラのラシオンを一ついただきます。
- *Ogitarteko **mistoa**, mesedez.* — ミックスサンドイッチをお願いします。

> シェアするために注文するときは、**dugu**（「私たちが持ちます／食べます」）や**hartuko dugu**（「（これから）食べます」）を使います。グループでは、みんなでいくつかのラシオン（大皿料理）を頼むのがごく一般的です。

## バリエーションとニュアンス

- **handia** — 大きい ／ **txikia** — 小さい：
  - *Garagardo handia* — 大きいビール
  - *Kafe txikia* — 小さいコーヒー（小さいカップ）
- **hotza** — 冷たい ／ **beroa** — 温かい：
  - *Ogitarteko beroa* — 温かいサンドイッチ（鉄板で温めたもの）
- **eta...** — 〜と…（追加するとき）：
  - *Tortilla pintxoa **eta** ardo gorri bat* — トルティージャのピンチョと赤ワインを一杯

## 仲間とのテーブルで

> — *Zer hartuko dugu?* — 何にする？
>
> — *Niretzat tortilla pintxoa eta zurito bat.* — 僕はトルティージャのピンチョとスリート（小グラスのビール）を一杯。
>
> — *Eta zuretzat?* — 君は？
>
> — *Nik gazta razio bat eta ardo gorri bat hartuko ditut.* — 私はチーズのラシオンを一つと赤ワインを一杯もらうよ。
>
> — *Nik plater konbinatu bat: arrautzak, txorizoa eta patata frijituak.* — 僕は盛り合わせプレートを一つ。卵とチョリソとフライドポテトの。
>
> — *Bale, hiru eskaera dira.* — オーケー、注文は3つだね。

## 支払い

- **Pagatzera!** — お会計！
- **Niri tokatzen zait.** — ここは私が払う番だ。
- **Nik gonbidatzen zaitut.** — 私がおごるよ。
- **Erdibana.** — 割り勘で。（半分ずつ）

> **文化メモ：** ピンチョは、ドノスティア、ビルバオ、イルニャで特に根強い伝統です。どのバルにもたいてい自慢の一品（看板メニュー）があります。**poteo**（ポテオ）という習慣は、バルをはしごして、それぞれのお店でピンチョ一つと飲み物一杯を楽しむというもの。とても社交的で、まさにバスク人（euskaldun）らしい伝統です。
