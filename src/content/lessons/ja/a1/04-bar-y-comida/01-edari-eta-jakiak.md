*Euskal Herria*での社会生活の大部分は、**taberna**（バル）が中心です。バスク語で基本的な飲み物や食べ物を知っていると、友達の輪、新しい村への訪問、*poteo*（バル巡り）など、すぐに様々な扉が開かれます。まずは単語から始めましょう。

## コーヒーとそのバリエーション

コーヒーはおそらく最もよく注文するものでしょう。いくつかの種類があります。

| バスク語 | 日本語 |
|---|---|
| *kafea* | コーヒー（一般的） |
| *kafe hutsa* | ブラックコーヒー（直訳：「純粋な／空のコーヒー」） |
| *kafesnea* | カフェオレ（*kafe* + *esne* より） |
| *kafe ebakia* | コルタード（少量のミルク入りコーヒー）（*ebaki* = 「カットされた」） |
| *kafe deskafeinatua* | カフェインレスコーヒー |
| *infusioa* | ハーブティー |
| *tea* | 紅茶 |

> *Kafesne*は文字通り「コーヒー牛乳」を意味します。バスク語ではこのように、ハイフンなしで主要な単語を最後に置いて多くの複合語が作られます。

## その他の飲み物

| バスク語 | 日本語 |
|---|---|
| *ura* | 水 |
| *zumoa* | ジュース |
| *esnea* | 牛乳 |
| *ardoa* | ワイン |
| *ardo gorria* | 赤ワイン |
| *ardo zuria* | 白ワイン |
| *garagardoa* | ビール |
| *zuritoa* | グラスビール（典型的な小さいサイズのビール） |
| *sagardoa* | シードル |
| *txakolina* | チャコリ（バスクの白ワイン） |
| *patxarana* | パチャラン |

> 興味深い3つの単語：**sagardo**（シードル）= *sagar*（リンゴ）+ *ardo*（ワイン）；**garagardo**（ビール）= *garagar*（大麦）+ *ardo*；**txakolina**は、バスク地方の特産である、若くて軽い白ワインです。

## 定冠詞「`-a`」

これらの単語のほとんどは、文中で「中立的に」現れるとき、語末に**`-a`**がつきます。これはスペイン語の定冠詞「el / la」にあたります。

- *Ardoa gustatzen zait.* — 私はワインが好きです。
- *Ura nahi dut.* — 水が欲しいです。

「ひとつ」を頼むときは、`-a`が消えて**bat**（「ひとつの」）がつきます。

- *Kafe **bat**, mesedez.* — コーヒーをひとつ、お願いします。
- *Garagardo **bat**.* — ビールをひとつ。

> レッスン3でこれを詳しく見ます。今は、バルのメニューで単語がわかるように、`-a`のついた形を覚えておきましょう。
