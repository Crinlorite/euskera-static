バスク地方 (*Euskal Herria*) で買い物に行くとき、特に町や地区では、商品ごとに専門店があるのが一般的です。お店の名前を覚えると、移動しやすくなるだけでなく、看板を理解するのにも役立ちます。

## 食料品店

| バスク語 | スペイン語 | 売られているもの |
|---|---|---|
| *harategia* | 精肉店 | haragia (肉) |
| *okindegia* | パン屋 | ogia (パン) |
| *arrandegia* | 魚屋 | arraina (魚) |
| *fruta-denda* | 青果店 | frutak, barazkiak |
| *supermerkatua* | スーパーマーケット | 何でも |
| *hipermerkatua* | ハイパーマーケット | 大型店舗 |
| *azoka* / *plaza* | 市場 | 様々な屋台 |

## 隠れたヒント：*-degi*

多くのお店は **-degi** という接尾辞で終わります。これは「～がある場所」を意味する古い接尾辞です。

- *ogi* (パン) → **okindegia** (パン屋)
- *haragi* (肉) → **harategia** (精肉店)
- *arrain* (魚) → **arrandegia** (魚屋)
- *gozo* (お菓子) → **gozotegia** (菓子店)

> *-degi* というパターンを見つければ、今まで見たことのないお店でも認識できるようになります。

## その他の便利な場所

| バスク語 | スペイン語 |
|---|---|
| *kutxazain automatikoa* | ATM |
| *banketxea* | 銀行 |
| *postetxea* | 郵便局 |
| *tabako-denda* | タバコ屋 |

## どこへ行くか言う

お店に行くときは、目的地を表す接尾辞 `-ra` を伴う **NORA**（方向格）を使います。

- *Okindegi**ra** noa.* — パン屋に行きます。
- *Harategi**ra** joango naiz.* — 精肉店に行くでしょう。
- *Fruta-denda**ra** joaten naiz astero.* — 毎週青果店に行きます。

> **文化メモ：** 多くの家庭では今でも買い物を分担しています。魚は近所の *arrandegia* で、パンは *okindegia* で、そして残りのものだけをスーパーマーケットで買います。「*okindegira noa*」という表現を日常的な決まり文句として聞くのはよくあることです。
