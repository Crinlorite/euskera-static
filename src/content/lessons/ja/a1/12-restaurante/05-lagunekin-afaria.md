これで全てのピースが揃いました。レストランの種類、メニュー、注文、支払い。これらを友達との夕食で統合してみましょう。約束を決め、注文し、夜を締めくくります。

## 1. 夕食の約束をする

> — *Aizue, ostiralean afaltzera joango gara?* — ねえ、金曜日に夕食に行かない？
>
> — *Bai, ideia ona!* — うん、いいね！
>
> — *Nik ezin dut ostiralean. Larunbatean ondo?* — 僕は金曜日は無理なんだ。土曜日はどう？
>
> — *Ados. Zer ordutan geratuko gara?* — いいよ。何時に会う？
>
> — *Bederatzi eta erdietan, taberna ondoan?* — 9時半に、バーの隣でどう？
>
> — *Ederki!* — 完璧！

都合が悪い時に断るためのフレーズ：

- **Ezin dut, beste plan bat dut.** — 無理なんだ、別の予定があるんだ。
- **Ezin dut, bihar lan egin behar dut.** — 無理なんだ、明日は仕事をしなくちゃいけないんだ。
- **Beste egun batean izan beharko du.** — また別の日にしないとね。

## 2. 予約する

> — *Egun on! "Kutixi" jatetxea al da?*
>
> — *Bai, esan.*
>
> — *Erreserba egin nahi dut, larunbat gauerako.*
>
> — *Zenbat lagunentzat?*
>
> — *Lau lagun izango gara.*
>
> — *Zer ordutan?*
>
> — *Bederatzi eta erdietan.*
>
> — *Noren izenean?*
>
> — *Mikelen izenean.*
>
> — *Oso ondo. Larunbat arte!*

## 3. テーブルで

席に着いたときの挨拶：

- **On egin!** — どうぞ召し上がれ！
- **Topa!** — 乾杯！（杯を交わすとき）

注文する、全てのピースを使って：

> — *Hasteko, niretzat entsalada mistoa, mesedez.*
>
> — *Eta niretzat arrain-zopa.*
>
> — *Bigarrenerako, niretzat legatza saltsan.*
>
> — *Niri, txuleta. Eta edateko, ardo gorria botila bat, mesedez.*

## 4. 食事についてコメントする

| バスク語 | スペイン語 |
|---|---|
| *Oso goxoa zegoen!* | とても美味しかったです！ |
| *Hau betekada!* | お腹いっぱい！ |
| *Beste botila bat ardo, mesedez.* | ワインをもう一本お願いします。 |
| *Postrerako, izozkia hartuko dut.* | デザートに、アイスクリームをいただきます。 |
| *Nik ez dut postrerik nahi.* | 私はデザートはいりません。 |

## 5. 夜を締めくくる

> — *Aizu, kobratuko al diguzu?*
>
> — *Bai, oraintxe. Berrogeita hamabi euro eta hogeita bost zentimo.*
>
> — *Txartelaz ordain dezakegu?*
>
> — *Bai, noski.*
>
> — *Eskerrik asko! Oso ondo zegoen.*
>
> — *Zuri! Hurrengora arte!*

## ビジュアルサマリー

```
1. 約束する:      Etorri nahi duzu afaltzera?  →  Bai, ados!
2. 予約:     Erreserba egin nahi dut...   →  Noren izenean?
3. 注文:       Hasteko... Bigarrenerako...  →  Postrerako...
4. 楽しむ:   On egin! / Topa! / Goxoa zegoen!
5. 支払い:       Kontua, mesedez. / Txartelaz ordain dezaket?
```

> **文化メモ：** *On egin!* という表現は、公共の場所（テラス、果物屋など、どこでも）で食事をしている人々のそばを通りかかるときにも使われます。これは非常に典型的な丁寧なジェスチャーで、耳にして返事をすると良いでしょう。自然な返答は *Eskerrik asko!* です。
