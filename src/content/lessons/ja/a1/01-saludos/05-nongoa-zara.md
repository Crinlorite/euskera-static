このレッスンでは、よく混同される2つの質問、**de dónde eres**（出身）と**dónde vives**（現在の居住地）について学びます。バスク語では、これらは異なる接尾辞を使って表現されます。

## 出身：Nongoa zara? → ...koa naiz

出身地を尋ねるには **Nongoa zara?** を使い、地名に接尾辞 **`-(e)ko`**（定冠詞付き：`-koa`）を付けて答えます：

| 場所 | 出身 |
|---|---|
| Bilbo | Bilbo**koa** naiz（ビルバオ出身です） |
| Donostia | Donostia**koa** naiz（ドノスティア出身です） |
| Iruñea | Iruñe**koa** naiz（パンプローナ出身です） |
| Madril | Madril**goa** naiz |
| Espainia | Espainia**koa** naiz |
| Argentina | Argentina**koa** naiz |

> 子音の後では、接尾辞は正書法に従って変化します（*Madril* → *Madrilgoa*）。練習すれば自然にできるようになります。

## 居住地：Non bizi zara? → ...n bizi naiz

今どこに住んでいるかを尋ねるには **Non bizi zara?**（「どこに住んでいますか？」）を使い、地名に場所を示す **`-(e)n`** を付けます：

| 場所 | 居住地 |
|---|---|
| Bilbo | Bilbo**n** bizi naiz |
| Donostia | Donostia**n** bizi naiz |
| Iruñea | Iruñea**n** bizi naiz |
| Madril | Madril**en** bizi naiz |

> 語幹の `-a` で終わる単語（Donostia）は `a` を保持します。子音で終わる単語（Madril）は `-e-` を挿入します。

## 会話での両方の表現

> — *Kaixo! Zein da zure izena?* — こんにちは！お名前は何ですか？
>
> — *Ni Maialen naiz. Eta zu?* — 私はマイアレンです。あなたは？
>
> — *Egoitz naiz. **Nongoa zara?*** — エゴイツです。出身はどこですか？
>
> — ***Iruñekoa naiz**, baina **Bilbon bizi naiz** orain.* — パンプローナ出身ですが、今はビルバオに住んでいます。

## 便利な語彙

- **herri** — 村、町
- **hiri** — 都市
- **herrialde** — 地方、県
- **estatu** — 国
- **norekin bizi zara?** — 誰と住んでいますか？ → *Bakarrik bizi naiz*（一人で住んでいます） / *Gurasoekin bizi naiz*（両親と住んでいます）
