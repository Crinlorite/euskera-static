バスク語では、時間は動詞 **izan** (〜である) を使って表現します。そして、「1時」の場合を除き、時間は常に**複数形**になります。文字通りには *「5時たちです」*、*「8時たちです」* のようになります。最初は奇妙に聞こえるかもしれませんが、パターンは非常に規則的です。

## 質問の仕方

時間を尋ねるには **Zer ordu da?** (「何時ですか？」) を使います。

> *— Zer ordu da?*
>
> *— Zazpiak dira.* (7時です。)

## ちょうど〜時

| 時刻 | バスク語 |
|---|---|
| 1:00 | **Ordu bata da** |
| 2:00 | **Ordu biak dira** |
| 3:00 | **Hirurak dira** |
| 4:00 | **Laurak dira** |
| 5:00 | **Bostak dira** |
| 6:00 | **Seiak dira** |
| 7:00 | **Zazpiak dira** |
| 8:00 | **Zortziak dira** |
| 9:00 | **Bederatziak dira** |
| 10:00 | **Hamarrak dira** |
| 11:00 | **Hamaikak dira** |
| 12:00 | **Hamabiak dira** |

## 1時と2時が特別な理由

- **Ordu bata** (1時) は**単数**なので、**da** を使って *Ordu bata da* と言います。
- **Ordu biak** (2時) は、前に *ordu* という単語を付けます。なぜなら *biak* だけだと紛らわしい可能性があるからです。はっきりとさせるために多くの人が "ordu" を付け加える唯一の時間です。それ以外 (3時以降) は単独で使われます: *hirurak*, *laurak*, *bostak*…

## 接尾辞 `-ak`

この語末の **-ak** はどこから来たのでしょうか？これはバスク語の複数形です (*gurasoak* や *aiton-amonak* で見ましたね)。ここでも同じです: *bost* (5) → *bostak* (「5時たち」) + *dira* (「です」)。

> **注:** 多くの人は、スペイン語と同様に12時間制で時間を言います。午前か午後かを区別するには、前に *goizeko* (朝の) または *arratsaldeko* (午後の) を付け加えるだけです: *goizeko zortziak* (朝の8時)。これについてはレッスン3で学びます。

## 練習

今すぐ携帯電話の時計を見て、声に出して言ってみましょう。11時なら *hamaikak dira*。1時なら *ordu bata da*。一週間、時計を見るたびにこれをやってみてください — それが自動的に言えるようになる一番の方法です。
