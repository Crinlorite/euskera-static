バスク語の一日の時間帯は、使い方に応じて2つの重要な接尾辞、**`-(e)an`**（〜に、〜で）と**`-(e)ko`**（〜の）を使って表現します。嬉しいことに、これらはすべての単語と規則的に組み合わさります。

## 基本となる単語

| バスク語 | 日本語 |
|---|---|
| *goiza* | 朝 |
| *eguerdia* | 正午 |
| *arratsaldea* | 午後 |
| *iluntzea* | 夕方 |
| *gaua* | 夜 |

## 「朝に・午後に」 — 場所を表す `-(e)an`

いつ（一日のどの時間帯に）何かが起こるかを言うには、語幹に **-(e)an** を付けます：

| いつ | バスク語 |
|---|---|
| 朝に | **goizean** |
| 正午に | **eguerdian** |
| 午後に | **arratsaldean** |
| 夕方に | **iluntzean** |
| 夜に | **gauean** |

> *Goizean kafea hartzen dut.* — 朝にコーヒーを飲みます。
>
> *Arratsaldean lagunekin egoten naiz.* — 午後は友達と過ごします。
>
> *Gauean lo egiten dut.* — 夜は寝ます。

## 「朝の・午後の」 — 接尾辞 `-ko`

**一日のどの時間か**を特定するには、時間の前に **-ko** を付けた単語を置きます：

| 正確な時間 | バスク語 |
|---|---|
| 朝の8時 | **goizeko zortziak** |
| 正午の12時 | **eguerdiko hamabiak** |
| 午後の5時 | **arratsaldeko bostak** |
| 夜の9時 | **gaueko bederatziak** |

> *Goizeko zazpietan esnatzen naiz.* — 私は朝の7時に起きます。
>
> *Arratsaldeko hirurak dira.* — 午後3時です。

## 基本的な時を表す言葉

これらは毎日使うことになるでしょう：

| バスク語 | 日本語 |
|---|---|
| *gaur* | 今日 |
| *atzo* | 昨日 |
| *bihar* | 明日（翌日） |
| *etzi* | 明後日 |
| *orain* | 今 |
| *gero* | 後で、その後 |
| *lehen* | 前に |

> 注意：**bihar**（翌日、「明日」）と **goiza**（午前中、正午までの「朝」）を混同しないようにしましょう。

## すべてを組み合わせる

> *Bihar goizean lanera joango naiz.* — 明日の朝、仕事に行きます。
>
> *Atzo arratsaldean zinemara joan ginen.* — 昨日の午後、映画に行きました。
>
> *Gaur gaueko hamarretan afalduko dut.* — 今夜10時に夕食を食べます。

> **文化メモ：**バスク地方は *iluntze* で有名です。これは、友人グループが *poteo*（バルをはしごして一杯ずつ飲むこと）に出かける夕暮れの時間帯のこと。午後でも夜でもなく、それ自体が独自のアイデンティティを持つ一日の時間帯なのです。
