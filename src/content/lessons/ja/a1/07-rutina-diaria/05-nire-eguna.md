このレッスンでは、このユニットで学んだすべて（時間、一日の時間帯、日常の動詞、頻度）をまとめます。目標は、バスク語であなたの一日を最初から最後まで話せるようになることです。

## キーとなる質問：「Zer ordutan…?」

| 質問 | 日本語 |
|---|---|
| *Zer ordutan esnatzen zara?* | 何時に起きますか？ |
| *Zer ordutan jaikitzen zara?* | 何時にベッドから出ますか？ |
| *Zer ordutan gosaltzen duzu?* | 何時に朝食をとりますか？ |
| *Zer ordutan bazkaltzen duzu?* | 何時に昼食をとりますか？ |
| *Zer ordutan ateratzen zara etxetik?* | 何時に家を出ますか？ |
| *Zer ordutan afaltzen duzu?* | 何時に夕食をとりますか？ |
| *Zer ordutan oheratzen zara?* | 何時に寝ますか？ |

> 助動詞の変化に注意：*esnatzen **zara*** (NOR) ですが、*gosaltzen **duzu*** (NOR-NORK) となります。動詞と助動詞のペアに気づいていくことが大切です。

## 「〜時に」—言い方

「〜時に」と答えるには、複数形の時間に付く *-ak* を **-etan** に変えます（すでに母音で終わる単語を除き、間に `-e-` が入ります）：

| 時間 | 「〜時に」 |
|---|---|
| zazpiak (7時) | **zazpietan** |
| zortziak | **zortzietan** |
| hamarrak | **hamarretan** |
| hamabiak | **hamabietan** |
| ordu bata (1時) | **ordu batean** (単数形、形はそのまま) |
| ordu biak | **ordu bietan** |
| bost eta erdiak | **bost eta erdietan** (5時半に) |
| zortziak laurden gutxi | **zortziak laurden gutxitan** (8時15分前に) |

## ある一日 —モデル文

この例文を読んで、各要素がどのようにつながっているか見てみましょう：

> *Ni goizeko zazpietan esnatzen naiz. Poliki-poliki altxatzen naiz eta komunera joaten naiz. Dutxa bat hartzen dut, arropa janzten dut eta sukaldera joaten naiz. Sukaldean gosaria prestatzen dut eta lasai-lasai gosaltzen dut. Ondoren, etxetik ateratzen naiz eta lanera joaten naiz. Eguerdiko ordu bietan bazkaltzen dut. Arratsaldean batzuetan zinemara joaten naiz, beste batzuetan lagunekin egoten naiz. Gauean, etxean afaltzen dut, telebista ikusten dut eta hamaiketan oheratzen naiz.*

大まかな訳：
> *私は朝7時に目を覚まします。ゆっくりと起きてトイレに行きます。シャワーを浴び、服を着て、台所へ行きます。台所で朝食の準備をして、ゆっくりと朝食をとります。その後、家を出て仕事に行きます。正午2時に昼食をとります。午後は、時々映画に行ったり、友達と過ごしたりします。夜は家で夕食をとり、テレビを見て、11時に寝ます。*

## あなたの文を作ってみよう

このテンプレートにあなたの実際の情報を入れてみましょう。学んだことを定着させる一番の方法です：

1. **何時に起きるか：** *Goizeko ___etan esnatzen naiz.*
2. **起きてから何をするか：** *... dutxatzen naiz / gosaltzen dut / ...*
3. **仕事や学校にどうやって行くか：** *... oinez / autoz / autobusez joaten naiz.*
4. **午後に何をするか：** *Arratsaldean ...*
5. **何時に夕食をとり、寝るか：** *Gaueko ___etan afaltzen dut eta ___etan oheratzen naiz.*

## つなぎに便利なフレーズ

- *Lehenengo* — 最初に
- *Gero / Ondoren* — それから、その後
- *Eta gero* — そして、それから
- *Azkenik* — 最後に
- *Egunero* — 毎日
- *Batzuetan / Beste batzuetan* — 時々 / またある時は
- *Beti* — いつも
- *Inoiz ez* — 決して〜ない

> **文化メモ：** バスク地方では、多くの人が14時から15時の間に昼食（*bazkaldu*）をとり、夕食（*afaldu*）は21時から22時頃とかなり遅めです。*Hamaiketakoa* — 午前11時の軽食で、通常はピンチョスやサンドイッチ — は、なくてはならない習慣です。もし友達グループ（cuadrilla）といて、11時に誰かが *hamaiketakoa egitera goaz* と言ったら、何をするかもうお分かりですね。
