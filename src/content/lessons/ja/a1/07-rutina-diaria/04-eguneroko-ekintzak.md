毎日することについて話すとき、バスク語では**習慣相**を使います。動詞（分詞形）に **-tzen** または **-ten** を付け、その後、助動詞 **izan** (naiz, zara, da…) または **ukan** (dut, duzu, du…) と組み合わせます。

## ルール

| 動詞の語末 | 習慣相の接尾辞 | 例 |
|---|---|---|
| 子音または `-tu` / `-du` | **-tzen** | *esnatu* → *esnatzen* |
| `-n` | **-ten** | *jan* → *jaten*; *egin* → *egiten* |
| `-i` (不規則) | **-tzen** または **-ten** | *etorri* → *etortzen*; *ikusi* → *ikusten* |

> 動詞 *jan* (食べる) は *janten* には**ならず**、*jaten* になります — 語末の "n" が消えます。*edan* → *edaten*、*egon* → *egoten* も同様です。

## 日常で使う動詞

### NOR (助動詞 **izan**: naiz, zara, da…)

これらは自動詞なので **izan** と一緒に使います — 主語は目的語なしで行動を経験します:

| Partizipioa | 習慣相 | 意味 |
|---|---|---|
| *esnatu* | *esnatzen naiz* | 私は目が覚める |
| *jaiki* | *jaikitzen naiz* | 私は起きる |
| *altxatu* | *altxatzen naiz* | 私は起きる (*jaiki* の異形) |
| *dutxatu* | *dutxatzen naiz* | 私はシャワーを浴びる |
| *jantzi* | *janzten naiz* | 私は服を着る |
| *joan* | *joaten naiz* | 私は行く |
| *etorri* | *etortzen naiz* | 私は来る |
| *oheratu* | *oheratzen naiz* | 私は寝る |
| *lokartu* | *lokartzen naiz* | 私は眠りに落ちる |

### NOR-NORK (助動詞 **ukan**: dut, duzu, du…)

これらは主語と目的語を持つので **ukan** と一緒に使います:

| Partizipioa | 習慣相 | 意味 |
|---|---|---|
| *gosaldu* | *gosaltzen dut* | 私は朝食をとる |
| *bazkaldu* | *bazkaltzen dut* | 私は昼食をとる |
| *afaldu* | *afaltzen dut* | 私は夕食をとる |
| *jan* | *jaten dut* | 私は食べる |
| *edan* | *edaten dut* | 私は飲む |
| *lan egin* | *lan egiten dut* | 私は働く |
| *lo egin* | *lo egiten dut* | 私は眠る |
| *ikusi* | *ikusten dut* | 私は見る |
| *irakurri* | *irakurtzen dut* | 私は読む |
| *erosi* | *erosten dut* | 私は買う |

> **なぜ一部は NAIZ を使い、他は DUT を使うのでしょうか？** これはバスク語の重要な区別です。*Esnatzen naiz* (私は目が覚める) は自分自身に起こることです。目的語はありません。*Jaten dut* (私は食べる) には目的語があります: *ogia jaten dut* (私はパンを食べる)。これについては次のユニットで詳しく学びます — 今のところは、動詞と助動詞のペアを覚えてください。

## 例文

> *Egunero zazpietan esnatzen naiz eta dutxatzen naiz.* — 毎日7時に起きてシャワーを浴びます。
>
> *Goizean kafea hartzen dut.* — 朝はコーヒーを飲みます。
>
> *Askotan lagunekin afaltzen dut.* — よく友達と夕食をとります。
>
> *Batzuetan lo-kuluxka egiten dut bazkalostean.* — ときどき昼食後に昼寝をします。

> **注:** *bazkalostean* = 「昼食後」(文字通り：「食事の後」)。バスク語の文化には、短い昼寝のような日常的な概念を表す簡潔な言葉があります — *lo-kuluxka* がまさにそれです。
