起こったことをうまく説明するには、**いつ**起きたのかを言う必要があります。このレッスンでは、最近の過去形と組み合わせて、行動を時間軸に位置付けるための時を表す言葉を学びます。

## 基本的な時を表す言葉

| バスク語 | 日本語 |
|---|---|
| *gaur* | 今日 |
| *atzo* | 昨日 |
| *bihar* | 明日 |
| *etzi* | 明後日 |
| *orain* | 今 |
| *oraintxe* | たった今、今すぐ |
| *lehen* | 前に |
| *gero* | 後で |

> お気づきかもしれませんが、*atzo*（昨日）と *bihar*（明日）はどちらも非常に短い単語なので、すぐに覚えられます。*Etzi*（明後日）は、スペイン語では一言で表せない単語です。バスク語からのちょっとした贈り物ですね。

## 一日の時間帯との組み合わせ

これらの時を表す言葉は、前のユニットで学んだ *goizean*、*arratsaldean*、*gauean* などと組み合わせることができます。形式は次の通りです：**時を表す言葉 + 一日の時間帯**。

| バスク語 | 日本語 |
|---|---|
| *gaur goizean* | 今朝 / 今日の午前中 |
| *gaur eguerdian* | 今日の正午に |
| *gaur arratsaldean* | 今日の午後 |
| *gaur gauean* | 今夜 |
| *atzo goizean* | 昨日の午前中 |
| *atzo arratsaldean* | 昨日の午後 |
| *atzo gauean* | 昨夜 |
| *bihar goizean* | 明日の午前中 |

> **注意：** *gaur gauean* は「今夜」（これから来る夜、または今過ごしている夜）です。*atzo gauean* は「昨夜」です。バスク語ではこの二つを明確に区別します。

## 頻度と回数

| バスク語 | 日本語 |
|---|---|
| *behin* | 一回 |
| *bi aldiz* | 二回 |
| *hiru aldiz* | 三回 |
| *askotan* | しばしば、何度も |
| *batzuetan* | 時々 |
| *inoiz ez* | 決して～ない、一度も～ない |
| *gaur goizetik* | 今朝から |
| *aste honetan* | 今週 |
| *hilabete honetan* | 今月 |

## 最近の過去形と時を表す言葉を使った文

> *Gaur goizean lanera joan naiz autoz.* — 今朝、車で仕事に行きました。
>
> *Gaur arratsaldean Mikelekin egon naiz.* — 今日の午後、ミケルと一緒にいました。
>
> *Gaur oso berandu esnatu naiz.* — 今日、とても遅く起きました。
>
> *Gaur eguerdian etxean bazkaldu dut.* — 今日の正午、家で昼食を食べました。
>
> *Aste honetan bi aldiz egon naiz zinean.* — 今週、二回映画館に行きました。

## 文の語順

バスク語で時を表す言葉を使った文の典型的な語順は次の通りです：

> **いつ + どこで + 何を + 動詞**

> **Gaur goizean** + **euskaltegian** + **euskara** + **ikasi dut**. — 今朝、*euskaltegi*でバスク語を勉強しました。

これが唯一の可能性というわけではありません。バスク語では強調するために要素を移動させることができますが、この語順に従えば間違うことはありません。

## ミニ会話

> *— Eta gaur zer egin duzu, Maialen?*
>
> *— **Gaur goizean** lanera joan naiz oinez. **Eguerdian** lagunekin bazkaldu dut tabernan. **Arratsaldean** etxera bueltatu naiz eta liburua irakurri dut. **Gauean** ez dut afaldu, asko jan baitut bazkarian.*

> **注：** *gaur* は今日一日全体を指します。もっと具体的に言いたい場合は、時間帯（*gaur goizean*、*gaur arratsaldean*）を追加します。日常会話では、*Zer egin duzu gaur?* は「今日は（全体として）何をしましたか？」という意味で理解されます。
