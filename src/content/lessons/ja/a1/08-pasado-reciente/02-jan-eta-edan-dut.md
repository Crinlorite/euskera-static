**他動詞**とは目的語をとる動詞のことです。誰かが*何かを*食べる、*何かを*見る、*何かを*読む、など。バスク語では、これらの動詞は助動詞 **ukan** (dut, duzu, du…) を使います。近過去では、次の形になります：

> **partizipioa + dut/duzu/du/dugu/duzue/dute**

## 基本的な他動詞

| 分詞 | 私 (…した) | 日本語 |
|---|---|---|
| *jan* | **jan dut** | 食べました |
| *edan* | **edan dut** | 飲みました |
| *ikusi* | **ikusi dut** | 見ました |
| *irakurri* | **irakurri dut** | 読みました |
| *entzun* | **entzun dut** | 聞きました |
| *erosi* | **erosi dut** | 買いました |
| *egin* | **egin dut** | しました |
| *hartu* | **hartu dut** | 取りました / 持ちました |
| *ekarri* | **ekarri dut** | 持ってきました |
| *eraman* | **eraman dut** | 持って行きました |
| *ikasi* | **ikasi dut** | 学びました / 勉強しました |
| *eskatu* | **eskatu dut** | 頼みました / 注文しました |
| *ordaindu* | **ordaindu dut** | 支払いました |
| *idatzi* | **idatzi dut** | 書きました |
| *prestatu* | **prestatu dut** | 準備しました |
| *garbitu* | **garbitu dut** | 掃除しました |
| *gosaldu* | **gosaldu dut** | 朝食を食べました |
| *bazkaldu* | **bazkaldu dut** | 昼食を食べました |
| *afaldu* | **afaldu dut** | 夕食を食べました |
| *lan egin* | **lan egin dut** | 働きました |

## ある動詞の完全な活用

例として *ikusi* (見る) を見てみましょう：

| 代名詞 + 主語 | 形 | 日本語 |
|---|---|---|
| Nik | **ikusi dut** | 見ました |
| Zuk | **ikusi duzu** | 見ました |
| Hark | **ikusi du** | 見ました |
| Guk | **ikusi dugu** | 見ました |
| Zuek | **ikusi duzue** | 見ました |
| Haiek | **ikusi dute** | 見ました |

> 他動詞の主語には **NORK** 格 (-k) が付きます：*nik, zuk, hark, guk, zuek, haiek*。特に主語が名前の場合によく見られます：*Mikelek* (ミケルが…した)、*Maialenek* (マイアレンが…した)。混乱するようであれば、A1レベルでは代名詞を省略して動詞だけを使っても構いません。文脈で十分伝わります。

## 代表的なフレーズ

- *Gaur goizean egunkaria irakurri dut.* — 今朝、新聞を読みました。
- *Bazkaltzeko arraina jan dut.* — 昼食に魚を食べました。
- *Lagunekin kafea hartu dut.* — 友達とコーヒーを飲みました。
- *Mikelek ardoa erosi du.* — ミケルはワインを買いました。
- *Guk pelikula bat ikusi dugu.* — 私たちは映画を一本見ました。
- *Haiek euskara ikasi dute gaur.* — 彼らは今日、バスク語を勉強しました。

## 否定

「Xをしなかった」と言うには、助動詞の前に **ez** を置きます：

> *Ez dut bazkaldu.* — 昼食を食べていません。
>
> *Ez du egunkaria irakurri.* — 彼は新聞を読んでいません。
>
> *Ez dugu ardorik edan.* — 私たちはワインを飲んでいません。（*ardorik* に注目：否定文では、目的語に部分格の **-rik** が付くことがよくあります。）

## ミニ会話

> *— Zer afaldu duzu gaur, Maialen?*
>
> *— Entsalada eta arraina jan dut, eta postrerako jogurta hartu dut. Eta zuk?*
>
> *— Nik tortilla egin dut, baina ez dut postrerik jan.*

> **視覚的なまとめ：** 行為に明示的または暗示的な目的語がある場合（何かを食べる、何かを見る、何かをする）、助動詞は **dut**（およびその派生形）になります。これらの動詞と助動詞のペアを覚えれば、あとは自然にできるようになります。
