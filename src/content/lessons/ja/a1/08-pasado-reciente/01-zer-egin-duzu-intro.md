バスク語では、最近したこと、特に今日したことを話すときには、**orainaldi burutua**（文字通りには「現在完了」）が使われます。これはスペイン語の *he comido / he ido*（食べた／行った）に相当します。これは**最近の過去**として知られています。

## 作り方はとてもシンプルです

> **分詞 + 助動詞（izan または ukan）**

前のユニットで学んだ習慣のアスペクトと比べると、唯一の違いは、動詞に **-tzen / -ten** が付かないことです。

| 習慣 | 最近の過去 | スペイン語 |
|---|---|---|
| *gosaltzen dut* | **gosaldu dut** | 朝食をとる → 朝食をとった |
| *jaten dut* | **jan dut** | 食べる → 食べた |
| *joaten naiz* | **joan naiz** | 行く → 行った |
| *etortzen naiz* | **etorri naiz** | 来る → 来た |
| *ikusten dut* | **ikusi dut** | 見る → 見た |

> **これはスペイン語の**習慣的現在形と現在完了形の違いと同じです。
>
> - *Egunero euskaltegira **joaten naiz**.* — 毎日バスク語学校に行きます。
> - *Gaur goizean euskaltegira **joan naiz**.* — 今朝、バスク語学校に行きました。

## 最も自然な質問

> *— **Zer egin duzu gaur?*** — 今日、何をしましたか？
>
> *— Lan egin dut, eta gero zinera joan naiz.* — 仕事をして、それから映画に行きました。

2つの形に注目してください。**lan egin dut**（バスク語で「働く」は目的語をとるので *dut* を使います）と **joan naiz**（「行く」は目的語をとらないので *naiz* を使います）。

## 2つの助動詞 — 簡単なおさらい

### izan (NOR) を使う場合 — naiz / zara / da / gara / zarete / dira

| 代名詞 | 助動詞 | 例 |
|---|---|---|
| ni (私) | naiz | *joan **naiz*** (行きました) |
| zu (君) | zara | *etorri **zara*** (来ました) |
| hura (彼/彼女) | da | *esnatu **da*** (目が覚めました) |
| gu (私たち) | gara | *joan **gara*** (行きました) |
| zuek (君たち) | zarete | *etorri **zarete*** (来ました) |
| haiek (彼ら/彼女ら) | dira | *joan **dira*** (行きました) |

### ukan (NOR-NORK) を使う場合 — dut / duzu / du / dugu / duzue / dute

| 代名詞 | 助動詞 | 例 |
|---|---|---|
| nik (私が) | dut | *jan **dut*** (食べました) |
| zuk (君が) | duzu | *ikusi **duzu*** (見ました) |
| hark (彼/彼女が) | du | *erosi **du*** (買いました) |
| guk (私たちが) | dugu | *egin **dugu*** (しました) |
| zuek (君たちが) | duzue | *jan **duzue*** (食べました) |
| haiek (彼ら/彼女らが) | dute | *ikusi **dute*** (見ました) |

## ミニ会話

> *— Kaixo Maialen! Zer moduz?*
>
> *— Ondo. Eta zu? **Zer egin duzu gaur?***
>
> *— Lan egin dut goizean, eta arratsaldean lagun batekin kafea hartu dut.*
>
> *— Polita. Ni gaur ez naiz lanera joan, gaixo egon naiz.*

> **要点：**コツは、各動詞がどの助動詞を使うかを知ること（これは次の2つのレッスンで学びます）、そして分詞を習慣を表す *-tzen/-ten* を付けない形に保つことです。
