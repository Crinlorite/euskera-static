この単元を終えるにあたり、最後のピースが残っています。それは**移動方法**です。スペイン語では「en + 交通手段」（「en coche」、「en autobús」）を使います。バスク語では、接尾辞**`-z`**（*具格*）を使います。これは交通手段に付け加えられ、驚くべきことに「足」を意味する単語にも付けられます。

## 質問

| 質問 | 日本語訳 |
|---|---|
| ***Nola* zoaz?** | どうやって行きますか？ |
| ***Zerez* zoaz?** | 何（の手段）で行きますか？ |
| ***Nola* doa Iruñera?** | パンプローナへはどうやって行きますか？ |

どちらの形（*Nola* と *Zerez*）も正しく、よく使われます。*Nola* はより一般的で、*zerez* は直接的に「何の手段で」という意味合いを持ちます。

## 交通手段

| 手段 | -z を付けた形 | 日本語訳 |
|---|---|---|
| oin (pie) | **oinez** | 徒歩で |
| kotxe / auto | **kotxez** / **autoz** | 車で |
| autobus | **autobusez** | バスで |
| tren | **trenez** | 電車で |
| metro | **metroz** | 地下鉄で |
| taxi | **taxiz** | タクシーで |
| bizikleta | **bizikletaz** | 自転車で |
| motor | **motorrez** | バイクで |
| hegazkin | **hegazkinez** | 飛行機で |
| itsasontzi | **itsasontziz** | 船で |
| furgoneta | **furgonetaz** | バンで |
| zaldi (caballo) | **zaldiz** | 馬で |

> 接尾辞は、母音の後では**`-z`**、子音の後では**`-ez`**になります（*autobus → autobusez*）。実際には、ほとんどの交通手段の名前は母音で終わるため、基本的な公式は **手段 + z** となります。

## 完全な例文

- **Oinez noa lanera.** — 私は職場へ徒歩で行きます。
- **Iruñera trenez goaz.** — 私たちはパンプローナへ電車で行きます。
- **Bilbora hegazkinez doaz.** — 彼らはビルバオへ飛行機で行きます。
- **Eskolara bizikletaz dator alaba.** — 娘は学校へ自転車で来ます。
- **Mendira oinez igotzen gara.** — 私たちは山へ徒歩で登ります。

## NONDIK + NORA + NOLA の組み合わせ

典型的な移動に関する文は、通常3つの要素で構成されます：**どこから + どこへ + どうやって**。

- **Iruñetik Donostiara autobusez doa.** — 彼はパンプローナからドノスティアへバスで行きます。
- **Bilbotik Madrilera trenez gatoz.** — 私たちはビルバオからマドリードへ電車で来ます。
- **Etxetik euskaltegira oinez noa.** — 私は家からバスク語学校（euskaltegi）へ徒歩で行きます。

## ミニ会話

> — *Aupa! Bihar Bilbora **noa**.* — やあ！明日ビルバオへ行きます。
>
> — *Eta **nola** zoaz?* — それで、どうやって行くの？
>
> — *Trenez. Oso erosoa da.* — 電車で。とても快適だよ。
>
> — *Ni autoz noa beti, baina garestia da gasolina.* — 私はいつも車で行くけど、ガソリンが高いんだ。

## *oinez* について

一見すると *oinez* は特別なケース（「足で」）のように見えますが、実際には他の単語と全く同じパターンです：*oin*（足）+ *ez*（具格接尾辞）。バスク語では、「徒歩で行く」ことを、他の交通手段と同様に、移動させてくれる手段を使う、という形で扱います。

## NORA / NONDIK / NOLA ブロックの最終復習

| 質問 | 接尾辞 | 質問の例 | 答えの例 |
|---|---|---|---|
| **Nora?** | -ra | どこへ？ | *Bilbo**ra** noa.* |
| **Nondik?** | -tik | どこから？ | *Bilbo**tik** nator.* |
| **Nola? / Zerez?** | -z | どうやって？ / 何で？ | *Tren**ez** noa.* |

> **ヒント：** この3つの接尾辞を組み合わせると、ほとんどの移動に関する文を作ることができます。例えば、*Bilbotik Donostiara autobusez goaz, lagun bat bisitatzera*. — 「私たちはビルバオからドノスティアへ、友人を訪ねるためにバスで行きます。」この3つの接尾辞と、*joan* と *etorri* の統合形をマスターすれば、日々のあらゆる移動について話すことができるようになります。
