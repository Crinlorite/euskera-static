誰かに場所への行き方を尋ねられたり、自分が道に迷って尋ねたりするときには、いくつかの命令形の動詞と方向を示す副詞が必要になります。このレッスンでは、その基本をまとめます。

## 基本的な命令形

バスク語では、動きを表す動詞の肯定命令形は非常に直接的です。

| 形 | 基本動詞 | 意味 |
|---|---|---|
| **Jo** | jo | 打て / 向けろ (*jo ezkerrera* = 左に曲がれ) |
| **Segi** / **Jarraitu** | segitu / jarraitu | 進め、続けろ |
| **Hartu** | hartu | 取れ (*hartu kale hau* = この道を行け) |
| **Igo** | igo | 上がれ |
| **Jaitsi** | jaitsi | 下りろ |
| **Sartu** | sartu | 入れ |
| **Irten** | irten | 出ろ |
| **Zeharkatu** | zeharkatu | 渡れ |
| **Iritsi** / **heldu** | iritsi / heldu | 着け (… *arte* = 「〜まで」) |

> *Jo* は文字通りには「打つ」を意味しますが、「〜の方へ向かう」という比喩的な意味で使われます：**jo ezkerrera** = 「左へ進め」。

## 方向を示す副詞と指示

| バスク語 | 日本語 |
|---|---|
| *ezkerra* | 左 |
| *eskuina* | 右 |
| *aurrera* | 前方へ |
| *atzera* | 後方へ |
| *zuzen* | まっすぐ |
| *gora* | 上へ |
| *behera* | 下へ |

> 注意：**〜への方向**を示すには、接尾辞 `-ra` を使います（レッスン03で詳しく学びます）：*ezkerre-ra*（左へ）、*aurre-ra*（前方へ）、*atze-ra*（後方へ）。*gora*、*behera* も同様です。

## 代表的な目印

| バスク語 | 日本語 |
|---|---|
| *semaforoa* | 信号 |
| *bidegurutzea* | 交差点 |
| *zebrabidea* | 横断歩道 |
| *biribilgunea* / *errotonda* | ロータリー、環状交差点 |
| *aldapa* | 坂 |
| *eskailerak* | 階段 |
| *zubia* | 橋 |
| *errepidea* | 道路、車道 |
| *kalea* | 通り |

## 例文

- **Jo ezkerrera bidegurutzean.** — 交差点を左に曲がってください。
- **Segi aurrera semaforora arte.** — 信号までまっすぐ進んでください。
- **Zeharkatu zebrabidea.** — 横断歩道を渡ってください。
- **Igo eskailerak eta sartu eraikinean.** — 階段を上って、建物に入ってください。
- **Jaitsi aldapa, eta gero jo eskuinera.** — 坂を下って、それから右に曲がってください。
- **Egin atzera; gehiegi joan zara.** — 戻ってください。行き過ぎましたよ。

## 道を尋ねる・教える

> — *Barkatu, **non dago** udaletxea?* — すみません、市役所はどこですか？
>
> — ***Segi aurrera** semaforora arte. Han **jo eskuinera** eta **zeharkatu** plaza. Udaletxea elizaren ondoan dago.* — 信号までまっすぐ進んでください。そこで右に曲がって、広場を横切ります。市役所は教会の隣にあります。
>
> — *Eta gertu **dago**?* — それで、近いですか？
>
> — *Bai, oso gertu. Bost minutu oinez.* — はい、とても近いです。歩いて5分です。

> **ヒント：** 多くの道案内は、命令形（*jo*, *segi*, *zeharkatu*）+ 接尾辞付きの場所（*ezkerrera*, *semaforora*, *zebrabidea*）という決まったパターンに従います。このパターンを覚えれば、パーツを組み合わせて長い指示を組み立てることができます。
