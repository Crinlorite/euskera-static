3つの基本的な動詞が常に登場します：**joan** (行く)、**etorri** (来る)、**ibili** (歩く、「あちこち移動する」) です。この3つには、現在形で非常によく使われる**総合形** (助動詞なし) があり、まとめて覚えるのがおすすめです。

## Joan — 行く

| 人称 | 形 | 日本語 |
|---|---|---|
| ni | **noa** | 私が行きます |
| zu | **zoaz** | あなたが行きます |
| hura | **doa** | 彼/彼女が行きます |
| gu | **goaz** | 私たちが行きます |
| zuek | **zoazte** | あなたたちが行きます |
| haiek | **doaz** | 彼ら/彼女らが行きます |

> キーフレーズ：***Nora zoaz?*** — どこへ行きますか？ これはレッスン03で学びます。

## Etorri — 来る

| 人称 | 形 | 日本語 |
|---|---|---|
| ni | **nator** | 私が来ます |
| zu | **zatoz** | あなたが来ます |
| hura | **dator** | 彼/彼女が来ます |
| gu | **gatoz** | 私たちが来ます |
| zuek | **zatozte** | あなたたちが来ます |
| haiek | **datoz** | 彼ら/彼女らが来ます |

> キーフレーズ：***Nondik zatoz?*** — どこから来ますか？ これはレッスン04で学びます。

## Ibili — 歩く、移動する

| 人称 | 形 | 日本語 |
|---|---|---|
| ni | **nabil** | 私が歩いています、移動しています |
| zu | **zabiltza** | あなたが歩いています |
| hura | **dabil** | 彼/彼女が歩いています |
| gu | **gabiltza** | 私たちが歩いています |
| zuek | **zabiltzate** | あなたたちが歩いています |
| haiek | **dabiltza** | 彼ら/彼女らが歩いています |

> *Ibili* は「何をしているの？」と尋ねるのにも使えます：**Zer zabiltza?** — 元気？／何してるの？ 知り合い同士の挨拶として非常によく使われます。

## その他の便利な移動の動詞

| バスク語 | 日本語 | 例文 |
|---|---|---|
| *sartu* | 入る | *Tabernan sartu naiz.* — バルに入りました。 |
| *irten* | 出る | *Etxetik irten naiz.* — 家から出ました。 |
| *igo* | 上がる、登る | *Eskailerak igo ditut.* — 階段を上りました。 |
| *jaitsi* | 下りる、下がる | *Aldapa jaitsi dut.* — 坂を下りました。 |
| *iritsi / heldu* | 着く、到着する | *Iruñera iritsi naiz.* — パンプローナに着きました。 |

## 総合形がなぜ重要か

バスク語では、ほとんどの動詞は**助動詞**を使って活用します：*jan dut* (食べました)、*ikusi dut* (見ました)。しかし、**joan**, **etorri**, **egon**, **ibili**, **eduki**, **jakin** をはじめとする、いくつかの非常に頻繁に使われる動詞は、現在形で使われる独自の「コンパクトな」活用（*総合形*）を持っています。これらは非常によく出てくるので、回りくどい言い方をするよりも、6つの形を覚えてしまう方が簡単です。

## ミニ会話

> — *Aupa, nora zoaz?* — やあ！どこへ行くの？
>
> — *Banketxera **noa**. Eta zu, nondik **zatoz**?* — 銀行へ行くんだ。君はどこから来たの？
>
> — *Lanetik **nator**.* — 仕事帰りだよ。
>
> — *Eta Lide? Zer **dabil**?* — Lideは？何してる？
>
> — *Enkargutan **dabil**, batetik bestera.* — お使いであちこち回ってるよ。

> **注：** 総合形はA1レベルの中心的な要素です。歌ったり、書いたり、繰り返したりして、2つ (*ni*/*zu*) や3つ (*gu*/*zuek*/*haiek*) のブロックで覚えてください。練習すれば自然に身につきます。
