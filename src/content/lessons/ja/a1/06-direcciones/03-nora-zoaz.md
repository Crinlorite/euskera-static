**NORA格**（*adlativo*、向格とも呼ばれます）は、移動の**目的地**、つまりどこへ行くかを示します。スペイン語では通常、前置詞の**"a"**で訳されます（"voy *a* casa"「家へ行く」、"*a* Bilbao"「ビルバオへ」、"*al* parque"「公園へ」など）。

## 質問: Nora?

| 質問 | スペイン語 |
|---|---|
| ***Nora* zoaz?** | どこへ行きますか？ |
| ***Nora* doa?** | （彼/彼女は）どこへ行きますか？ |
| ***Nora* goaz?** | （私たちは）どこへ行きますか？ |
| ***Nora* doaz?** | （彼らは）どこへ行きますか？ |

## 接尾辞: -ra

答えるには、目的地の場所に**`-ra`**を付けます。語末によってパターンが変わります。

| 場所の語末 | パターン | 例 |
|---|---|---|
| -a（語幹の-a、例: *eskola*） | + ra | eskola → **eskolara** |
| -a 以外の母音（例: *Bilbo*, *etxe*） | + ra | etxe → **etxera**, Bilbo → **Bilbora** |
| 子音（例: *Madril*, *Gasteiz*） | + era | Madril → **Madrilera**, Gasteiz → **Gasteizera** |

## 例文

| 場所 | -ra の形 | 例文 |
|---|---|---|
| etxe (家) | **etxera** | *Etxera noa.* — 家へ行きます。 |
| eskola | **eskolara** | *Eskolara doaz.* — 彼らは学校へ行きます。 |
| euskaltegi | **euskaltegira** | *Euskaltegira goaz.* — 私たちはエウスカルテギ（バスク語学校）へ行きます。 |
| taberna | **tabernara** | *Tabernara zoaz?* — バルへ行きますか？ |
| lan (仕事) | **lanera** | *Lanera nator.* — 仕事に来ます。（同様に子音の後ろは -era） |
| Bilbo | **Bilbora** | *Bilbora doa.* — 彼/彼女はビルバオへ行きます。 |
| Donostia | **Donostiara** | *Donostiara goaz asteburuan.* — 週末にドノスティアへ行きます。 |
| Madril | **Madrilera** | *Madrilera doaz.* — 彼らはマドリードへ行きます。 |
| mendi (山) | **mendira** | *Mendira goaz larunbatean.* — 土曜日に山へ行きます。 |

> **ちょっとしたヒント:** *non* → *nora* は *kale-an* → *kale-ra* と同じパターンに従います。*Bilbon*（ビルバオで）の作り方を知っていれば、*Bilbora*（ビルバオへ）の作り方もわかります。*-n* を *-ra* に変えるだけです。*Madrilen* の作り方を知っていれば、*Madrilera* の作り方もわかります。

## Zertara? — 「何をしに？」

**何をしに**（どんな目的で）行くのかを尋ねるには、**Zertara zoaz?** を使い、動詞 + 接尾辞 **`-tzera`** で答えます。

| 質問 | 答え |
|---|---|
| *Zertara zoaz tabernara?* | *Kafea hartzera.* — コーヒーを飲みに。 |
| *Zertara doa Kepa supermerkatura?* | *Erostera.* — 買い物に。 |
| *Zertara goaz mendira?* | *Ibiltzera.* — 歩きに。 |
| *Zertara doaz hondartzara?* | *Igeri egitera.* — 泳ぎに。 |

> **パターン:** *（動詞の分詞形）+ -t(z)era*: *erosi → erostera*, *jan → jatera*, *ikasi → ikastera*, *ikusi → ikustera*, *bisitatu → bisitatzera*。これは基本的にスペイン語の "a + 不定詞" に相当します。

## ミニ会話

> — *Nora zoaz, Maialen?* — マイアレン、どこへ行くの？
>
> — *Euskaltegira noa.* — エウスカルテギ（バスク語学校）へ行くんだ。
>
> — *Eta zertara?* — 何をしに？
>
> — *Klasera, noski! Euskara ikastera.* — 授業にだよ、もちろん！バスク語を習いにね。
>
> — *Eta gero?* — その後は？
>
> — *Tabernara goaz lagunekin pote bat hartzera.* — 友達とバルに一杯飲みに行くんだ。

## 方向の副詞

指示詞にもNORAの形があります。

| NON（場所格） | NORA（方向） | 意味 |
|---|---|---|
| hemen | **hona** | こちらへ |
| hor | **horra** | そちらへ |
| han | **hara** | あちらへ |

- **Hona zatoz?** — こちらへ来ますか？
- **Hara doaz.** — 彼らはあちらへ行きます。

> **重要な注意点:** 最初は多くの人が混乱します: *etxean*（家で）≠ *etxera*（家へ）≠ *etxetik*（家から、レッスン04）。3つとも「家」について話しているので似ていますが、伝えている情報は全く異なります。心に留めておきましょう: **NON = -an (いる)**, **NORA = -ra (行く)**, **NONDIK = -tik (来る、レッスン4)**。
