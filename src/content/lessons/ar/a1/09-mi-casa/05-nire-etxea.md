يدمج هذا الدرس كل شيء من الوحدة 9: الغرف، الأثاث، المهام ومع من تعيش. الهدف هو أن تتمكن من **وصف منزلك** في جمل بسيطة، كما لو كانوا يسألونك في الفصل أو في محادثة غير رسمية.

## الأسئلة الأساسية

| السؤال | الإسبانية |
|---|---|
| *Non dago zure etxea?* | ¿Dónde está tu casa? |
| *Nolakoa da?* | ¿Cómo es? |
| *Zenbat gela ditu?* | ¿Cuántas habitaciones tiene? |
| *Norekin bizi zara?* | ¿Con quién vives? |
| *Zenbatgarren solairuan bizi zara?* | ¿En qué planta vives? |
| *Etxeak badu igogailua / balkoia / terraza?* | ¿La casa tiene ascensor / balcón / terraza? |

## صفات مفيدة لوصف المنزل

| الباسكية | الإسبانية |
|---|---|
| *handia* | grande |
| *txikia* | pequeña |
| *argitsua* | luminosa |
| *iluna* | oscura |
| *berria* | nueva |
| *zaharra* | vieja |
| *lasaia* | tranquila |
| *zaratatsua* | ruidosa |
| *erosoa* | cómoda |
| *garestia* | cara |
| *merkea* | barata |

> تذكر النمط **NOLAKOA da?** الذي رأيته بالفعل في وحدات أخرى: الإجابة تحتوي على الصفة + `-a` في النهاية + الفعل *izan*. مثال: *Nire etxea **handia da**.* — منزلي كبير.

## فقرة نموذجية

إليك نص بسيط يصف منزلاً. اقرأه بصوت عالٍ وانتبه للأنماط.

> *Ni Iruñean bizi naiz, auzo lasai batean. Nire etxea ez da oso handia: hiru gela ditu — bi logela eta egongela bat — sukaldea eta komuna. Egongela argitsua da, eta balkoi bat dauka. Hirugarren solairuan dago, eta etxeak igogailua du.*
>
> *Bikotekidearekin bizi naiz. Berak bazkaria prestatzen du, eta nik ontziak garbitzen ditut. Asteburuetan biok elkarrekin egiten dugu erosketa.*

## دورك: صف منزلك

كوّن فقرتك الخاصة بالإجابة بهذا الترتيب:

1. **Non bizi zara?** (أين تعيش؟) → *X-(e)an bizi naiz.*
2. **Nolakoa da etxea?** (كيف هو المنزل؟) → *Nire etxea handia / argitsua / lasaia da.*
3. **Zenbat gela ditu?** (كم عدد الغرف؟) → *Bi / Hiru / Lau gela ditu.*
4. **Zer dago etxean?** (ماذا يوجد في المنزل؟) → *Sukaldea, egongela, bi logela eta komun bat ditu.*
5. **Norekin bizi zara?** → *Bakarrik / Gurasoekin / Lagunekin bizi naiz.*
6. **Etxeko lanak nork egiten ditu?** → *Nik egunero garbitzen dut* / *Pisukideen artean banatzen ditugu.*

## مفردات ختامية

| الباسكية | الإسبانية |
|---|---|
| *etxebizitza* | vivienda |
| *etxejabea* | propietario |
| *alokairua* | alquiler |
| *errenta* | renta / alquiler mensual |
| *auzoa* | barrio |
| *erdigunea* | centro (de la ciudad) |
| *aldiriak* | extrarradio / afueras |

> **نصيحة:** عندما تتحدث عن منزلك في الفصل، لا تحاول ترجمة كل التفاصيل. التزم بالجمل القصيرة والمتقنة. *"Bi logela ditut, sukalde txiki bat eta egongela handia"* هو وصف أفضل من جملة طويلة مليئة بالأخطاء.
