لوصف الشعر والعيون في لغة الباسك، لا يُستخدم الفعل **izan** (بمعنى "يكون") كما في الإسبانية (مثلاً "soy moreno" أي "أنا أسمر")، بل يُستخدم **ukan** (بمعنى "يملك" أو "لديه"): *tengo el pelo negro* (لدي شعر أسود)، *tengo los ojos azules* (لدي عيون زرقاء).

## الشعر: ile

الكلمة التي تعني "شعر" هي **ile** (مع أداة التعريف: *ilea*). تأتي الصفات بعدها، والصفة الأخيرة فقط هي التي تأخذ العلامة `-a`:

| الباسكية | العربية |
|---|---|
| *ile beltza* | شعر أسود |
| *ile horia* | شعر أشقر |
| *ile zuria* | شعر أبيض / أشيب |
| *ile gorria* | شعر أحمر |
| *ile urdina* | شعر رمادي |
| *ile motza* | شعر قصير |
| *ile luzea* | شعر طويل |
| *ile lisoa* | شعر أملس |
| *ile kizkurra* | شعر مجعد |

> يُعامل الشعر في لغة الباسك كـ**مفرد**، تماماً كما في الإسبانية. لهذا السبب يُستخدم *dut* / *du* (وليس *ditut* / *ditu*).

- *Ile beltza eta luzea **dut**.* — لدي شعر أسود وطويل.
- *Maialenek ile kizkurra **du**.* — لدى Maialen شعر مجعد.

## العيون: begiak

على عكس الشعر، كلمة "العيون" هي **جمع** (*begiak*). لذلك، تأتي الصفات أيضاً في صيغة الجمع (`-ak`) ويُستخدم الفعل **ditut / ditu**:

| الباسكية | العربية |
|---|---|
| *begi urdinak* | عيون زرقاء |
| *begi marroiak* | عيون بنية |
| *begi berdeak* | عيون خضراء |
| *begi beltzak* | عيون سوداء |
| *begi argiak* | عيون فاتحة |
| *begi ilunak* | عيون داكنة |

- *Begi urdinak **ditut**.* — لدي عيون زرقاء.
- *Mikelek begi marroiak **ditu**.* — لدى Mikel عيون بنية.

## سمات أخرى: اللاحقة -dun

للقول "الذي يرتدي X" أو "ذو X"، تملك لغة الباسك لاحقة شائعة الاستخدام: **-duna** (للمفرد) / **-dunak** (للجمع). تُضاف إلى الاسم فيصبح الشخص "صاحب النظارات"، "صاحب اللحية"...

| الباسكية | العربية |
|---|---|
| *betaurrekoduna* | يرتدي نظارات / ذو النظارات |
| *bizarduna* | ذو لحية |
| *biboteduna* | ذو شارب |
| *burusoila* | أصلع (حرفياً "رأس مقشر") |

هذه الكلمات تأتي مع الفعل **izan**، لأنها تصف سمة كأنها صفة:

- *Hura biboteduna da.* — هو ذو شارب.
- *Nire aitona burusoila da.* — جدي أصلع.

## دمج كل شيء

الوصف النموذجي يمزج بين عدة تراكيب:

> *Maialen txikia eta argala da. Ile gorria eta kizkurra du. Begi berdeak ditu. Betaurrekoduna da.*
>
> Maialen قصيرة ونحيفة. لديها شعر أحمر ومجعد. لديها عيون خضراء. ترتدي نظارات.

لاحظ كيف يتم التوزيع: **izan** للصفات العامة (*txikia da*)، **ukan** للشعر/العيون (*ile … du*, *begi … ditu*)، و *-dun*-a مرة أخرى مع **izan** للإكسسوارات.
