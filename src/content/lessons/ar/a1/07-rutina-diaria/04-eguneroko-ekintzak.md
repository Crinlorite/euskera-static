للتعبير عما تفعله كل يوم، تستخدم اللغة الباسكية **الصيغة الاعتيادية**: تأخذ الفعل (partizipio) وتضيف له **-tzen** أو **-ten**، ثم تدمجه مع الفعل المساعد **izan** (naiz, zara, da…) أو **ukan** (dut, duzu, du…).

## القاعدة

| نهاية الفعل | اللاحقة الاعتيادية | مثال |
|---|---|---|
| حرف ساكن أو `-tu` / `-du` | **-tzen** | *esnatu* → *esnatzen* |
| `-n` | **-ten** | *jan* → *jaten*; *egin* → *egiten* |
| `-i` (غير قياسي) | **-tzen** أو **-ten** | *etorri* → *etortzen*; *ikusi* → *ikusten* |

> الفعل *jan* (يأكل) **لا** يتحول إلى *janten* بل إلى *jaten* — حرف "n" الأخير يختفي. نفس الشيء مع *edan* → *edaten*, *egon* → *egoten*.

## أفعال الحياة اليومية

### NOR (الفعل المساعد **izan**: naiz, zara, da…)

هذه الأفعال تأتي **مع izan** لأنها أفعال لازمة — الفاعل يمر بالفعل دون وجود مفعول به:

| Partizipioa | الصيغة الاعتيادية | المعنى |
|---|---|---|
| *esnatu* | *esnatzen naiz* | أستيقظ |
| *jaiki* | *jaikitzen naiz* | أنهض |
| *altxatu* | *altxatzen naiz* | أنهض (صيغة أخرى من *jaiki*) |
| *dutxatu* | *dutxatzen naiz* | أستحم |
| *jantzi* | *janzten naiz* | أرتدي ملابسي |
| *joan* | *joaten naiz* | أذهب |
| *etorri* | *etortzen naiz* | آتي |
| *oheratu* | *oheratzen naiz* | أذهب إلى الفراش |
| *lokartu* | *lokartzen naiz* | أنام |

### NOR-NORK (الفعل المساعد **ukan**: dut, duzu, du…)

هذه الأفعال تأتي **مع ukan** لأن لها فاعل ومفعول به:

| Partizipioa | الصيغة الاعتيادية | المعنى |
|---|---|---|
| *gosaldu* | *gosaltzen dut* | أتناول الفطور |
| *bazkaldu* | *bazkaltzen dut* | آكل (الغداء) |
| *afaldu* | *afaltzen dut* | أتعشى |
| *jan* | *jaten dut* | آكل |
| *edan* | *edaten dut* | أشرب |
| *lan egin* | *lan egiten dut* | أعمل |
| *lo egin* | *lo egiten dut* | أنام |
| *ikusi* | *ikusten dut* | أرى |
| *irakurri* | *irakurtzen dut* | أقرأ |
| *erosi* | *erosten dut* | أشتري |

> **لماذا تأتي بعض الأفعال مع NAIZ وأخرى مع DUT؟** هذا هو التمييز الرئيسي في اللغة الباسكية. *Esnatzen naiz* (أستيقظ) هو شيء يحدث لي: لا يوجد مفعول به. *Jaten dut* (آكل) لها مفعول به: *ogia jaten dut* (آكل الخبز). سنرى هذا بالتفصيل في الوحدة القادمة — في الوقت الحالي، احفظ أزواج الفعل + المساعد.

## أمثلة مترابطة

> *Egunero zazpietan esnatzen naiz eta dutxatzen naiz.* — كل يوم أستيقظ في السابعة وأستحم.
>
> *Goizean kafea hartzen dut.* — في الصباح أشرب القهوة.
>
> *Askotan lagunekin afaltzen dut.* — غالبًا ما أتعشى مع الأصدقاء.
>
> *Batzuetan lo-kuluxka egiten dut bazkalostean.* — أحيانًا آخذ قيلولة بعد الغداء.

> **ملاحظة:** *bazkalostean* = "بعد الغداء" (حرفيًا: "عقب الوجبة"). ثقافة اللغة الباسكية لديها كلمات مدمجة للمفاهيم اليومية مثل تلك القيلولة القصيرة — *lo-kuluxka* هي بالضبط ذلك.
