ماذا تفعل عندما لا تفعل شيئًا؟ هذا الدرس عن **الهوايات** — وعن القاعدة النحوية التي تحكمها: الفعل المحوّل إلى اسم باستخدام **-tzea** (*irakurtzea* = "القراءة").

## القاعدة: -t(z)ea

من المستوى A1، أنت تعرف *gustatzen zait* مع الأشياء (*kafea gustatzen zait*). لكي يعجبك **نشاط** ما، يتحول الفعل إلى اسم:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| الإسبانية | الباسكية |
|---|---|
| أحب القراءة | *Irakurtzea gustatzen zait* |
| أعشق الطبخ | *Asko gustatzen zait sukaldatzea* |
| يحب/تحب الغناء | *Abestea gustatzen zaio* |
| نحب السفر | *Bidaiatzea gustatzen zaigu* |
| لا أحب الاستيقاظ باكرًا على الإطلاق | *Ez zait batere gustatzen goiz jaikitzea* |

كل ما تعرفه عن NOR-NORI (*zait, zaio, zaigu…*) لا يزال هو المتحكم؛ فقط يتغير الـ "ماذا".

## قائمة الهوايات

| الإسبانية | الباسكية |
|---|---|
| القراءة / الكتابة | *irakurtzea / idaztea* |
| الاستماع إلى الموسيقى | *musika entzutea* |
| الغناء / الرقص | *abestea / dantzatzea* |
| الطبخ | *sukaldatzea* |
| التقاط الصور | *argazkiak ateratzea* |
| التلوين / الرسم | *margotzea / marraztea* |
| السفر | *bidaiatzea* |
| العناية بالبستان | *baratzea zaintzea* |
| ألعاب الفيديو | *bideo-jokoak* |
| الخياطة / الحياكة | *jostea / puntua egitea* |

## السؤال والتباهي

> ***Zer egitea gustatzen zaizu** denbora librean?* — ماذا تحب أن تفعل في وقت فراغك؟
>
> ***Zein da zure zaletasunik gogokoena**?* — ما هي هوايتك المفضلة؟
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — هوايتي المفضلة هي الطبخ: في نهاية كل أسبوع أجرب وصفة جديدة.

## ثلاثة تراكيب، ثلاثة فروق دقيقة (مراجعة دقيقة)

| التركيب | مثال | المعنى |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | يعجبني (هواية) |
| **-tzen dakit** | *Margotzen dakit* | أعرف كيف أفعله (مهارة) |
| **-tzen ari naiz** | *Margotzen ari naiz* | أنا أفعله (الآن) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — لا أعرف الحياكة، لكن أود أن أتعلم. (ستتقن هذا التعبير الأنيق *gustatuko litzaidake* في المستوى B1 — نتركه لك هنا كمقبلات.)

## حوار

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*
>
> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
>
> *— **Sukaldatzea** eta gero… **jatea**, noski.*
>
> *— Hori ere zaletasuna da?*
>
> *— Nire etxean, **kirola**.* 😄
