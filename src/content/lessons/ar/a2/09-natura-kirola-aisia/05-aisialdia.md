ختام الوحدة: **الترفيه في المدينة** — حفلات موسيقية، مسرح، متاحف ومعارض. هنا يجتمع كل شيء: الخطط (الوحدة 06)، اللقاء (الوحدة 06)، الأذواق (الدرس السابق) ونقود التذاكر (A1). المستوى A2 بدأ يبدو كالحياة الواقعية.

| العربية | الباسكية |
|---|---|
| الحفل الموسيقي | *kontzertua* |
| المسرح (المبنى) | *antzokia* |
| المسرحية | *antzezlana* |
| السينما | *zinema* |
| المتحف | *museoa* |
| المعرض | *erakusketa* |
| المهرجان | *jaialdia* |
| السوق / المعرض التجاري | *azoka* |
| الحديقة | *parkea* |

## التذاكر

| العربية | الباسكية |
|---|---|
| التذكرة | *sarrera* |
| شراء التذاكر | *sarrerak erosi* |
| مجاني | *doan* |
| نفدت | *agortuta* |
| العرض / الجلسة | *emanaldia* |
| الطابور | *ilara* |

> *Kontzerturako **sarrerak erosi ditut** — azkenak! Ia **agortuta zeuden**.* — لقد اشتريت تذاكر الحفل — إنها الأخيرة! كادت أن تنفد.
>
> *Museoa **doan da** asteazken arratsaldetan.* — المتحف مجاني بعد ظهر كل أربعاء.
>
> ***Zer ordutan hasten da** emanaldia?* — في أي ساعة يبدأ العرض؟

## اقتراح الخطة (كل شيء معًا)

> *— Aizu, **zer egingo dugu** larunbatean?*
>
> *— Bi plan ditut: goizean **azokara** joan — bertako gazta erosi nahi dut — eta arratsaldean **erakusketa berria** ikusi Artiumen.*
>
> *— **Ondo iruditzen zait** goizekoa… baina arratsalderako beste ideia bat: **kontzertua** dago gaztetxean, **doan**!*
>
> *— **Doan**? Ba erakusketa **datorren astean** ikusiko dugu. 😄 **Zer ordutan hasten da**?*
>
> *— Zortzietan. **Zazpietan geratuko gara**, zerbait afaltzeko.*

## الحكي عن كيف كانت (الماضي + الرأي)

> *Kontzertua **izugarria izan zen**: bi ordu eta erdi, jendea **dantzan** hasieratik. **Giro ederra**.* — كان الحفل الموسيقي رائعًا: ساعتان ونصف، والناس يرقصون منذ البداية. جو جميل.
>
> *Antzezlana **polita zen**, baina **luzeegia** — hiru ordu!* — كانت المسرحية جميلة، لكنها طويلة جدًا: ثلاث ساعات! (اللاحقة *-egi*، دائمًا حاضرة.)
>
> *Azokan **gazta, ogia eta sagardoa** erosi genituen. **Merezi izan zuen**.* — في المعرض اشترينا جبنًا وخبزًا وعصير التفاح. كان الأمر يستحق العناء.

> **ملاحظة:** الأجندة الثقافية الباسكية لها كلماتها الخاصة: *gaztetxea* (الـ "txoko" المدار ذاتيًا للحفلات الموسيقية الرخيصة)، *bertso-saioa* (جلسة *bertsolaris*)، *herriko jaiak*… وأكبر *Azoka* على الإطلاق: **Durangoko Azoka**، معرض الكتاب والأسطوانات الباسكية في ديسمبر — الحج السنوي للقارئ الباسكي.
