الحديث عن **نمط الحياة** و**البيئة** هو جزء أساسي في المستوى A2: حيث تمتزج المفردات الجديدة مع عبارات الإلزام والنصيحة (*behar dugu*, *komeni da*, *garrantzitsua da*) التي تتقنها بالفعل منذ المستوى A1.

## عادات صحية

| الإسبانية | الباسكية |
|---|---|
| ممارسة الرياضة | *kirola egin* |
| المشي / التنزه | *paseatu* / *ibili* |
| الجري | *korrika egin* |
| ركوب الدراجة | *bizikletaz ibili* |
| أكل الفاكهة والخضروات | *fruta eta barazkiak jan* |
| شرب الماء | *ura edan* |
| النوم جيدًا | *ondo lo egin* |
| التدخين | *erre* |
| شرب الكحول | *alkohola edan* |
| عدم الإفراط في الملح | *gatzaz ez abusatu* |

> عبارات نموذجية:
>
> - *Kirola egiten dut astean hiru aldiz.* — أمارس الرياضة ثلاث مرات في الأسبوع.
> - *Erretzeari utzi diot.* — لقد أقلعت عن التدخين.
> - *Ez dut alkoholik edaten astegunetan.* — لا أشرب الكحول خلال أيام الأسبوع.

## التكرار: *X aldiz*

لقول "X مرات"، استخدم الصيغة **رقم + aldiz**:

| الإسبانية | الباسكية |
|---|---|
| مرة واحدة في اليوم | *Egunean behin* |
| مرتين في الأسبوع | *Astean bi aldiz* / *birritan* |
| ثلاث مرات في الشهر | *Hilean hiru aldiz* |
| مرات عديدة | *Askotan* |
| أحيانًا | *Batzuetan* |
| مرات قليلة | *Gutxitan* |
| أبدًا | *Inoiz ez* |

## البيئة — *ingurumena*

| الإسبانية | الباسكية |
|---|---|
| البيئة | *ingurumena* |
| الطبيعة | *natura* |
| التلوث | *kutsadura* |
| القمامة | *zaborra* |
| إعادة التدوير | *birziklatu* |
| التقليل | *gutxitu* / *murriztu* |
| إعادة الاستخدام | *berrerabili* |
| الطاقة المتجددة | *energia berriztagarria* |
| تغير المناخ | *klima-aldaketa* |
| الاحتباس الحراري | *berotze globala* |

## حاويات القمامة

| اللون المعتاد | الباسكية | لأي شيء |
|---|---|---|
| أزرق | *edukiontzi urdina* | papera / ورق |
| أصفر | *edukiontzi horia* | plastikoa / بلاستيك |
| أخضر | *edukiontzi berdea* | beira / زجاج |
| بني | *edukiontzi marroia* | organikoa / عضوي |
| رمادي | *edukiontzi grisa* | hondakinak / بقايا |

## عبارات مفيدة لإبداء الرأي

- *Garrantzitsua da birziklatzea.* — من المهم إعادة التدوير.
- *Komeni da kirola egitea.* — من المستحسن ممارسة الرياضة.
- *Beharrezkoa da kutsadura gutxitzea.* — من الضروري تقليل التلوث.
- *Ez dut uste plastikoa ona denik.* — لا أعتقد أن البلاستيك جيد.

> هذه التراكيب (*-tzea + adjetivo + da*) هي صيغة المستوى A2 لقول "من المهم / من المستحسن / من الضروري فعل X". سنتناولها بالتفصيل في الوحدة 4.

## حياة الحي

| الإسبانية | الباسكية |
|---|---|
| الحي | *auzoa* |
| جار/جارة | *bizilaguna* |
| جمعية | *elkartea* |
| العمل التطوعي | *boluntariotza* |
| احتفالات الحي | *auzoko jaiak* |
| المشاركة | *parte hartu* |
| اجتماع | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## نص نموذجي قصير

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **ملاحظة ثقافية:** *auzo-elkarteak* (جمعيات الأحياء) هي جزء أساسي من الحياة الاجتماعية في العديد من قرى بلاد الباسك. تنظم احتفالات، وورش عمل لتعلم اللغة الباسكية، ورحلات إلى الجبال، وحملات بيئية. المشاركة هي واحدة من أفضل الطرق لممارسة اللغة في استخدامها الحقيقي.
