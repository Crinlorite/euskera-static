من الورق إلى البكسل: درس **التكنولوجيا اليومية**. مفردات تستخدمها مئة مرة في اليوم — الآن باللغة الباسكية، التي تتباهى أيضًا بكلمات شفافة ومبنية بشكل جيد (*pasahitza* = كلمة المرور؛ *sakelakoa* = "الذي في الجيب").

## الأجهزة

| الإسبانية | الباسكية |
|---|---|
| الحاسوب | *ordenagailua* |
| الحاسوب المحمول | *eramangarria* |
| الهاتف المحمول | *mugikorra / sakelakoa* |
| الجهاز اللوحي | *tableta* |
| الشاشة | *pantaila* |
| لوحة المفاتيح | *teklatua* |
| الفأرة | *sagua* (نعم، الحيوان!) |
| سماعات الرأس | *entzungailuak* |

## الشبكة والحسابات

| الإسبانية | الباسكية |
|---|---|
| الشبكة / الإنترنت | *sarea / internet* |
| الواي فاي | *wifia* |
| البريد الإلكتروني | *posta elektronikoa* |
| المستخدم | *erabiltzailea* |
| كلمة المرور | *pasahitza* |
| التطبيق | *aplikazioa* |
| صفحة الويب | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — ما هي كلمة مرور الواي فاي؟
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — لقد نسيت كلمة المرور والآن يجب أن أنشئ واحدة جديدة. مرة أخرى.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — لإنشاء الحساب تحتاج إلى بريد إلكتروني وكلمة مرور.

## الأفعال الرقمية

| الإسبانية | الباسكية |
|---|---|
| تشغيل / إطفاء | *piztu / itzali* |
| تنزيل | *deskargatu / jaitsi* |
| تثبيت | *instalatu* |
| حفظ | *gorde* |
| حذف | *ezabatu* |
| إرسال / مشاركة | *bidali / partekatu* |
| بحث (في الشبكة) | *bilatu* |
| يعمل / يشتغل | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — الحاسوب لا يعمل جيدًا؛ أطفئه وشغّله — الحل الدائم.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — هل حفظت الصور؟ لا تحذف شيئًا!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — تنزّل التطبيق، تنشئ الحساب، وهذا كل شيء.

## حوار: الدعم الفني العائلي

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **ملاحظة:** اللغة الباسكية الرقمية حية جدًا: البرمجيات الحرة وويكيبيديا باللغة الباسكية قويتان، ويمكنك ضبط هاتفك المحمول بالكامل على اللغة الباسكية (*Ezarpenak → Hizkuntza*). في الواقع، يعد ضبطه بهذه الطريقة خدعة دراسية رائعة: انغماس يومي مجاني.
