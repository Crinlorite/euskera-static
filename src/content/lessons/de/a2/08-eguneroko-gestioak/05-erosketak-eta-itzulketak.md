Einkaufen kannst du schon seit A1. Diese Lektion ist **Level 2 im Geschäft**: Kleidung anprobieren, mit den Größen kämpfen und – der Endgegner – **umtauschen oder zurückgeben**, ohne ins Schwitzen zu kommen. Dabei helfen uns zwei alte Bekannte: das *-egi* (zu) und das NOR-NORI (*geratzen zait*).

## In der Umkleidekabine

| Deutsch | Baskisch |
|---|---|
| Kann ich das anprobieren? | *Probatu dezaket?* |
| Die Umkleidekabine | *probalekua* |
| Die Größe | *neurria / talla* |
| Welche Größe trägst du? | *Zein neurri erabiltzen duzu?* |
| Es passt mir gut / schlecht | *Ondo / gaizki geratzen zait* |
| Zu groß / klein | *Handiegia / txikiegia* |
| Haben Sie es in einer anderen Farbe? | *Beste kolore batean baduzue?* |
| Und in einer Nummer größer? | *Eta neurri bat handiagoan?* |

> *— Praka hauek **probatu ditzaket**?*
>
> *— Noski, **probalekua** hor atzean dago.*
>
> *(bost minutu geroago)* *— Zer, **ondo geratzen zaizkizu**?*
>
> *— Ez… **txikiegiak dira**. **42an baduzue**?*

*Geratzen zait / zaizkizu* — reines NOR-NORI: das Kleidungsstück (NOR) passt MIR (NORI). Im Plural: *geratzen zaizkit* (sie passen mir).

## Umtauschen und zurückgeben

| Deutsch | Baskisch |
|---|---|
| Ich möchte es umtauschen | *Aldatu nahi dut* |
| Ich möchte es zurückgeben | *Itzuli nahi dut* |
| Bekomme ich das Geld zurück? | *Dirua itzuliko didazue?* |
| Der Kassenbon | *tiketa* |
| Es hat einen Mangel | *Akats bat dauka* |
| Es ist ungetragen | *Erabili gabe dago* |
| Die Rückgabefrist | *Itzultzeko epea* |

> *— Egun on. Jertse hau **itzuli nahi nuke**. **Akats bat dauka** hemen, ikusten?*
>
> *— Egia da. **Tiketa badaukazu**?*
>
> *— Bai, hemen. **Dirua itzuliko didazue** ala aldatu behar dut?*
>
> *— Nahi duzun bezala. Dirua **txartelera itzuliko dizugu**, bi-hiru egunetan.*
>
> *— Primeran, eskerrik asko.*

Achte auf das verkettete NOR-NORI-NORK: *itzuliko didazue* (ihr werdet es mir zurückgeben), *itzuliko dizugu* (wir werden es dir zurückgeben). Lektion 03 im echten Leben.

## Die Zusammenfassung für die Hosentasche

1. **Anprobieren**: *Probatu dezaket? → Ondo/gaizki geratzen zait → -egi* für die Größen.
2. **Umtauschen**: *Aldatu nahi dut* (+ *beste neurri/kolore batean*).
3. **Zurückgeben**: *Itzuli nahi dut* + *tiketa* + *dirua itzuliko didazue?*
