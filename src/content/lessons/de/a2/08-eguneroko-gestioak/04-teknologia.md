Vom Papier zum Pixel: die Lektion über **Alltagstechnologie**. Vokabeln, die du hundertmal am Tag benutzt — jetzt auf Baskisch, das außerdem transparente und gut konstruierte Wörter zu bieten hat (*pasahitza* = Wort zum Passieren; *sakelakoa* = "das für die Tasche").

|---|---|
| Der Computer | *ordenagailua* |
| Der Laptop | *eramangarria* |
| Das Handy | *mugikorra / sakelakoa* |
| Das Tablet | *tableta* |

## Das Netz und die Konten

| Deutsch | Euskera |
|---|---|
| Das Netz / Internet | *sarea / internet* |
| Das WLAN | *wifia* |
| Die E-Mail | *posta elektronikoa* |
| Der Benutzer | *erabiltzailea* |
| Das Passwort | *pasahitza* |
| Die App | *aplikazioa* |
| Die Webseite | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Wie lautet das WLAN-Passwort?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — Ich habe das Passwort vergessen und muss jetzt ein neues erstellen. Schon wieder.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Um das Konto zu erstellen, brauchst du eine E-Mail-Adresse und ein Passwort.

## Digitale Verben

| Deutsch | Euskera |
|---|---|
| Einschalten / ausschalten | *piztu / itzali* |
| Herunterladen | *deskargatu / jaitsi* |
| Installieren | *instalatu* |
| Speichern | *gorde* |
| Löschen | *ezabatu* |
| Senden / teilen | *bidali / partekatu* |
| Suchen (im Netz) | *bilatu* |
| Funktionieren / laufen | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — Der Computer funktioniert schlecht; schalte ihn aus und wieder ein — die übliche Lösung.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Hast du die Fotos gespeichert? Lösche nichts!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Die App herunterladen, das Konto erstellen und fertig.

## Dialog: Technischer Support in der Familie

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Hinweis:** Das digitale Baskisch ist sehr lebendig: Open-Source-Software und die baskische Wikipedia sind stark, und dein ganzes Handy kann auf Baskisch eingestellt werden (*Ezarpenak → Hizkuntza*). Es umzustellen ist tatsächlich ein genialer Lerntrick: tägliche Immersion gratis.
