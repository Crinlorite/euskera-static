Was machst du, wenn du nichts tust? In dieser Lektion geht es um **Hobbys** — und um das Grammatikelement, das sie bestimmt: das Verb, das mit **-tzea** zu einem Substantiv wird (*irakurtzea* = „das Lesen“).

## Das Element: -t(z)ea

Aus A1 kennst du *gustatzen zait* mit Dingen (*kafea gustatzen zait*). Damit dir eine **Tätigkeit** gefällt, wird das Verb substantiviert:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| Deutsch | Baskisch |
|---|---|
| Mir gefällt Lesen | *Irakurtzea gustatzen zait* |
| Ich koche sehr gerne | *Asko gustatzen zait sukaldatzea* |
| Ihm/Ihr gefällt Singen | *Abestea gustatzen zaio* |
| Uns gefällt Reisen | *Bidaiatzea gustatzen zaigu* |
| Früh aufstehen gefällt mir überhaupt nicht | *Ez zait batere gustatzen goiz jaikitzea* |

Das ganze NOR-NORI, das du schon kennst (*zait, zaio, zaigu…*), gilt weiterhin; nur das „Was“ ändert sich.

## Der Hobby-Katalog

| Deutsch | Baskisch |
|---|---|
| Lesen / Schreiben | *irakurtzea / idaztea* |
| Musik hören | *musika entzutea* |
| Singen / Tanzen | *abestea / dantzatzea* |
| Kochen | *sukaldatzea* |
| Fotos machen | *argazkiak ateratzea* |
| Malen / Zeichnen | *margotzea / marraztea* |
| Reisen | *bidaiatzea* |
| Den Gemüsegarten pflegen | *baratzea zaintzea* |
| Videospiele | *bideo-jokoak* |
| Nähen / Stricken | *jostea / puntua egitea* |

## Fragen und Angeben

> ***Zer egitea gustatzen zaizu** denbora librean?* — Was machst du gerne in deiner Freizeit?
>
> ***Zein da zure zaletasunik gogokoena**?* — Was ist dein Lieblingshobby?
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — Mein Lieblingshobby ist Kochen: Jedes Wochenende probiere ich ein neues Rezept aus.

## Drei Strukturen, drei Nuancen (Feinschliff)

| Struktur | Beispiel | Bedeutung |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | es gefällt mir (Hobby) |
| **-tzen dakit** | *Margotzen dakit* | ich kann es (Fähigkeit) |
| **-tzen ari naiz** | *Margotzen ari naiz* | ich tue es gerade (jetzt) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — Ich kann nicht stricken, aber ich würde es gerne lernen. (Dieses elegante *gustatuko litzaidake* wirst du in B1 beherrschen — wir geben es dir hier als kleinen Vorgeschmack.)

## Dialog

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*
>
> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
>
> *— **Sukaldatzea** eta gero… **jatea**, noski.*
>
> *— Hori ere zaletasuna da?*
>
> *— Nire etxean, **kirola**.* 😄
