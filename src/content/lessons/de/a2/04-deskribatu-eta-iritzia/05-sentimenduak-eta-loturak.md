Diese Lektion behandelt zwei sehr produktive A2-Blöcke:

1. **Gefühle** und Gemütszustände (die Grundlagen kennst du aus A1; hier erweiterst du sie).
2. **Diskurskonnektoren** zum Argumentieren und Nuancieren: *gainera, hala ere, beraz, alde batetik...*

Damit schließt du die Einheit ab und erhältst Werkzeuge für differenziertere Meinungsäußerungen.

## Gefühle: die Formel mit *egon* + Zustand

Die meisten vorübergehenden Gefühle werden mit *egon* + Adjektiv oder Adverb im Zustand gebildet:

| Deutsch | Baskisch |
|---|---|
| Zufrieden / Froh | *Pozik nago* |
| Traurig | *Triste nago* |
| Wütend / Verärgert | *Haserre nago* |
| Nervös | *Urduri nago* |
| Ruhig / Gelassen | *Lasai nago* |
| Gelangweilt | *Aspertuta nago* |
| Müde | *Nekatuta nago* |
| Beschämt | *Lotsatuta nago* |
| Verliebt | *Maitemindurik nago* |

> Das ist das gleiche Muster wie in A1 (*pozik, triste, lasai*), erweitert um *aspertuta, nekatuta, lotsatuta, maitemindurik*.

## Gefühle mit *izan*: *beldur naiz*

Einige tiefgreifende Gefühle werden mit *izan* gebildet:

| Deutsch | Baskisch |
|---|---|
| Ich habe Angst | *Beldur naiz* |
| Du hast Recht | *Arrazoia duzu* |
| Ich bin neugierig | *Jakin-mina dut* |
| Ich habe Lust | *Gogoa dut* / *Gogoz nago* |
| Ich habe keine Lust | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — Ich habe Angst, mit dem Auto zu fahren.

## Gefühle mit *NOR-NORI*: *lotsa ematen dit*

Eine sehr baskische Formel: Das Gefühl „gibt dir“:

| Deutsch | Baskisch |
|---|---|
| Es ist mir peinlich | *Lotsa ematen dit* |
| Es tut mir leid | *Pena ematen dit* |
| Es macht mich wütend | *Amorrua ematen dit* |
| Es macht mir Angst | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — Es ist mir peinlich, das zu sagen.
>
> *Albiste horrek **pena handia ematen dit**.* — Diese Nachricht tut mir sehr leid.

## *Jartzen naiz / jarri naiz*

Um den **Zustandswechsel** auszudrücken („nervös/froh/traurig werden“):

| Deutsch | Baskisch |
|---|---|
| Ich werde nervös | *Urduri **jartzen naiz*** |
| Er/Sie/Es wurde traurig | *Triste **jarri zen*** |
| Wir wurden froh | *Pozik **jarri ginen*** |
| Er/Sie/Es wird wegen nichts wütend | *Edozergatik haserretzen da* |

## Häufige psychologische Verben

| Verb | Bedeutung |
|---|---|
| *gustatu* | gefallen / mögen |
| *maite izan* | lieben / mögen |
| *gorrotatu* / *higuindu* | hassen |
| *beldurtu* | sich erschrecken |
| *aspertu* | sich langweilen |
| *haserretu* | wütend werden / sich ärgern |
| *lasaitu* | sich beruhigen |
| *poztu* | sich freuen |
| *triste jarri* / *atsekabetu* | traurig werden |
| *kezkatu* | sich Sorgen machen |

> *Asko **maite ditut** nire gurasoak.* — Ich liebe meine Eltern sehr.
>
> *Ez **kezkatu**, dena ondo aterako da.* — Mach dir keine Sorgen, alles wird gut werden.

## Diskurskonnektoren

Um Meinungen und Argumente zu verknüpfen:

### Hinzufügung

| Deutsch | Baskisch |
|---|---|
| Außerdem | *gainera* |
| Und auch | *eta baita ere* / *...ere* |
| Vor allem | *batez ere* |

> *Gainera, prezioa ere ona da.* — Außerdem ist der Preis auch gut.

### Ursache / Folge

| Deutsch | Baskisch |
|---|---|
| Deshalb / Daher | *beraz* |
| Deswegen | *horregatik* |
| Aus diesem Grund | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — Es ist spät, deshalb gehe ich.

### Kontrast / Gegensatz

| Deutsch | Baskisch |
|---|---|
| Trotzdem / Jedoch | *hala ere* |
| Aber | *baina* |
| Andererseits | *bestetik* |
| Dagegen / Im Gegensatz dazu | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — Es ist spät, trotzdem werde ich kommen.

### Den Diskurs organisieren

| Deutsch | Baskisch |
|---|---|
| Einerseits... andererseits... | *Alde batetik... bestetik...* |
| Zuerst... dann... | *Lehenengo... gero...* |
| Schließlich / Zuletzt | *Azkenik* |
| Zusammenfassend | *Laburbilduz* |

## Koordinierte Strukturen A2

Dies sind Konstruktionen, die in jeder A2-Prüfung vorkommen:

| Deutsch | Baskisch |
|---|---|
| Weder... noch... | *Ez... ez...* |
| Sowohl... als auch... | *Bai... bai...* / *Hala... nola...* |
| Nicht nur..., sondern auch... | *Ez bakarrik..., baita ere...* |
| ...auch (inbegriffen) | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — Weder Anboto noch Olatz sind gekommen.
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — Sowohl morgens als auch nachmittags muss ich arbeiten.

## Mini-Text Meinungsäußerung

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## Trick für A2: das „Meinungs-Grundgerüst“

Wenn du in A2 deine Meinung äußern sollst, folge dieser Vorlage:

> **1. Nire ustez** + tema + **-(e)la**.
>
> **2. Alde batetik**, + razón1 + **-lako**.
>
> **3. Bestetik**, + razón2.
>
> **4. Hala ere**, + matización.
>
> **5. Beraz**, + conclusión.

Damit baust du einen vollständigen A2-Absatz.

> **Kultureller Hinweis:** Viele offizielle A2-Texte (Leserbrief, Forum, Prüfungsaufsatz) verlangen diese argumentative Struktur. Übe sie mit alltäglichen Themen: Sport, Essen, soziale Netzwerke, Arbeit, die Feste im Dorf.
