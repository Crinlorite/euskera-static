Wir beginnen mit dem Grundlegendsten jeder Wohnung: den **Zimmern**. Das allgemeine Wort für „Raum / Zimmer“ ist **gela**, und die meisten Namen für Räume werden gebildet, indem ein Wortstamm mit `-gela` kombiniert wird.

## Grundwortschatz

| Baskisch | Deutsch |
|---|---|
| *etxea* | das Haus |
| *pisua* | die Wohnung (in einem Gebäude) |
| *gela* | Zimmer / Raum |
| *sukaldea* | Küche |
| *logela* | Schlafzimmer |
| *komuna* | Badezimmer |
| *egongela* | Wohnzimmer |
| *sarrera* | Eingang |
| *korridorea* / *pasabidea* | Flur / Korridor |
| *balkoia* | Balkon |
| *terraza* | Terrasse |

## Wie einige Namen gebildet werden

Das Baskische ist bei diesen Wörtern sehr transparent. Wenn du dir ansiehst, wie sie zusammengesetzt sind, kannst du sie dir besser merken:

- **logela** → *lo* (Schlaf) + *gela* (Raum) = „Schlafraum“ → Schlafzimmer
- **egongela** → *egon* (sein/sich aufhalten) + *gela* = „Aufenthaltsraum“ → Wohnzimmer
- **sukaldea** → *su* (Feuer) + *aldea* (Bereich) = „Feuerbereich“ → Küche

> **Komuna** und **bainugela** sind Synonyme: *komuna* ist das alltägliche Wort, während *bainugela* (wörtlich „Bade-Raum“) etwas formeller ist.

## Gebäude: Stockwerk und Aufzug

| Baskisch | Deutsch |
|---|---|
| *solairua* | Stockwerk (1., 2., …) |
| *igogailua* | Aufzug |
| *eskailera* | Treppe |
| *ataria* | Hauseingang / Portal |

Um zu sagen, in welchem Stockwerk du wohnst:

- *Hirugarren solairuan bizi naiz.* — Ich wohne im dritten Stock.
- *Etxeak igogailua du.* — Das Haus hat einen Aufzug.

## Nützliche Fragen

- **Zenbat gela ditu zure etxeak?** — Wie viele Zimmer hat dein Haus?
- **Zenbat logela ditu?** — Wie viele Schlafzimmer hat es?
- **Non dago sukaldea?** — Wo ist die Küche?
- **Etxeak badu balkoirik?** — Hat das Haus einen Balkon?

> **Kultureller Hinweis:** In Navarra und im baskisch-kastilischen Gebiet ist es üblich, *pisua* für eine Stadtwohnung und *etxea* für das Familienhaus/Dorfhaus zu sagen. Im Alltag werden die Begriffe problemlos vermischt.
