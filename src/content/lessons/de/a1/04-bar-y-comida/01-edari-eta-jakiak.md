Ein großer Teil des sozialen Lebens im Baskenland spielt sich in der **taberna** (der Bar) ab. Die grundlegenden Getränke und Speisen auf Baskisch zu kennen, wird dir sofort Türen öffnen: eine Gruppe von Freunden, ein Besuch in einem neuen Dorf, ein *poteo*. Beginnen wir mit dem Vokabular.

## Der Kaffee und seine Varianten

Kaffee ist wahrscheinlich das, was du am häufigsten bestellen wirst. Es gibt ihn in verschiedenen Formen:

| Baskisch | Deutsch |
|---|---|
| *kafea* | der Kaffee (allgemein) |
| *kafe hutsa* | schwarzer Kaffee (wörtlich: „reiner/leerer Kaffee“) |
| *kafesnea* | Milchkaffee (von *kafe* + *esne*) |
| *kafe ebakia* | Cortado (*ebaki* = „geschnitten“) |
| *kafe deskafeinatua* | entkoffeinierter Kaffee |
| *infusioa* | Kräutertee |
| *tea* | Tee |

> *Kafesne* bedeutet wörtlich „Kaffee-Milch“. Das Baskische bildet viele zusammengesetzte Wörter auf diese Weise, ohne Bindestrich und mit dem Hauptwort am Ende.

## Andere Getränke

| Baskisch | Deutsch |
|---|---|
| *ura* | das Wasser |
| *zumoa* | Saft |
| *esnea* | die Milch |
| *ardoa* | Wein |
| *ardo gorria* | Rotwein |
| *ardo zuria* | Weißwein |
| *garagardoa* | Bier |
| *zuritoa* | kleines Bier vom Fass (typisch) |
| *sagardoa* | Apfelwein |
| *txakolina* | Txakoli (baskischer Weißwein) |
| *patxarana* | Patxaran |

> Drei interessante Wörter: **sagardo** (Apfelwein) = *sagar* (Apfel) + *ardo* (Wein); **garagardo** (Bier) = *garagar* (Gerste) + *ardo*; **txakolina** ist ein junger, leichter Weißwein, eine Spezialität des Baskenlandes.

## Einfache Speisen in der Bar

Als Begleitung zu deinem Getränk:

| Baskisch | Deutsch |
|---|---|
| *ogia* | das Brot |
| *gazta* | Käse |
| *urdaiazpikoa* | Schinken |
| *tortilla* | Tortilla (Kartoffelomlett) |
| *patata frijituak* | Pommes frites |
| *gozokia* | Süßigkeit (allgemein) |
| *txokolatea* | Schokolade |

## Der Artikel `-a`

Fast alle diese Wörter haben ein **`-a`** am Ende, wenn sie „neutral“ in einem Satz erscheinen: Das ist der Artikel „der / die / das“.

- *Ardoa gustatzen zait.* — Ich mag den Wein.
- *Ura nahi dut.* — Ich möchte Wasser.

Wenn du „einen/eine/ein“ bestellst, verschwindet das `-a` und **bat** („eins/ein/eine“) tritt hinzu:

- *Kafe **bat**, mesedez.* — Einen Kaffee, bitte.
- *Garagardo **bat**.* — Ein Bier.

> In Lektion 3 wirst du das im Detail sehen. Lerne vorerst die Formen mit `-a`, um sie auf der Speisekarte der Bar wiederzuerkennen.
