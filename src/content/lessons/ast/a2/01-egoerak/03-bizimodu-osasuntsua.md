Falar de **estilu de vida** y **mediu ambiente** ye un bloque clásicu del A2: amiéstase vocabulariu nuevu con frases d'obligación y conseyu (*behar dugu*, *komeni da*, *garrantzitsua da*) que yá remanes dende l'A1.

## Vezos saludables

| Castellán | Eusquera |
|---|---|
| Facer deporte | *kirola egin* |
| Caminar / pasiar | *paseatu* / *ibili* |
| Correr | *korrika egin* |
| Andar en bici | *bizikletaz ibili* |
| Comer fruta y verdura | *fruta eta barazkiak jan* |
| Beber agua | *ura edan* |
| Dormir bien | *ondo lo egin* |
| Fumar | *erre* |
| Beber alcohol | *alkohola edan* |
| Nun abusar del sal | *gatzaz ez abusatu* |

> Frases típiques:
>
> - *Kirola egiten dut astean hiru aldiz.* — Fago deporte tres vegaes a la selmana.
> - *Erretzeari utzi diot.* — Dexé de fumar.
> - *Ez dut alkoholik edaten astegunetan.* — Nun bebo alcohol ente selmana.

## Frecuencia: *X aldiz*

Pa dicir "X vegaes" uses la fórmula **númberu + aldiz**:

| Castellán | Eusquera |
|---|---|
| Una vez al día | *Egunean behin* |
| Dos vegaes a la selmana | *Astean bi aldiz* / *birritan* |
| Tres vegaes al mes | *Hilean hiru aldiz* |
| Munches vegaes | *Askotan* |
| A vegaes | *Batzuetan* |
| Poques vegaes | *Gutxitan* |
| Nunca | *Inoiz ez* |

| Castellán | Eusquera |
|---|---|
| Mediu ambiente | *ingurumena* |
| Naturaleza | *natura* |
| Contaminación | *kutsadura* |
| Basoria | *zaborra* |

| Enerxía anovable | *energia berriztagarria* |

| Calentamientu global | *berotze globala* |

## Los contenedores

| Color habitual | Eusquera | Pa qué |
|---|---|---|
| Azul | *edukiontzi urdina* | papera / papel |
| Mariellu | *edukiontzi horia* | plastikoa / plásticu |
| Verde | *edukiontzi berdea* | beira / vidru |
| Marrón | *edukiontzi marroia* | organikoa / orgánicu |
| Gris | *edukiontzi grisa* | hondakinak / resto |

## Frases útiles pa opinar

- *Garrantzitsua da birziklatzea.* — Ye importante reciclar.
- *Komeni da kirola egitea.* — Convién facer deporte.
- *Beharrezkoa da kutsadura gutxitzea.* — Ye necesario amenorgar la contaminación.
- *Ez dut uste plastikoa ona denik.* — Nun creo que'l plásticu seya bono.

> Estes estructures (*-tzea + axetivu + da*) son la fórmula A2 pa "ye importante / convién / ye necesario facer X". Vamos trabayales a fondu na unidá 4.

## Vida del barriu

| Castellán | Eusquera |
|---|---|
| Barriu | *auzoa* |
| Vecín/a | *bizilaguna* |
| Asociación | *elkartea* |
| Voluntariáu | *boluntariotza* |
| Fiestes del barriu | *auzoko jaiak* |
| Participar | *parte hartu* |
| Xunta | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## Mini-testu modelu

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **Nota cultural:** les *auzo-elkarteak* (asociaciones de vecinos) son una pieza fundamental de la vida social en munchos pueblos d'Euskal Herria. Organicen fiestes, talleres d'eusquera, salíes al monte y campañes medioambientales. Participar ye una de les meyores formes de prauticar la llingua n'usu real.
