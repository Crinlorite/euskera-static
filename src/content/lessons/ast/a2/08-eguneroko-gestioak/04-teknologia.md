Del papel al píxel: la lleición de **teunoloxía cotidiana**. Vocabulariu que uses cien veces al día — agora n'euskera, que perriba presume de pallabres tresparentes y bien construyíes (*pasahitza* = pallabra de pasu; *sakelakoa* = "el de bolsu").

## Los aparatos

| Asturianu | Euskera |
|---|---|
| L'ordenador | *ordenagailua* |
| El (ordenador) portátil | *eramangarria* |
| El móvil | *mugikorra / sakelakoa* |
| La tableta | *tableta* |
| La pantalla | *pantaila* |
| El tecláu | *teklatua* |
| El mur | *sagua* (¡sí, l'animal!) |
| Los auriculares | *entzungailuak* |

## La rede y les cuentes

| Asturianu | Euskera |
|---|---|
| La rede / internet | *sarea / internet* |
| El wifi | *wifia* |
| El corréu electrónicu | *posta elektronikoa* |
| L'usuariu | *erabiltzailea* |
| La contraseña | *pasahitza* |
| L'aplicación | *aplikazioa* |
| La páxina web | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — ¿Cuál ye la contraseña del wifi?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — Escaecí la contraseña y agora tengo que crear una nueva. Otra vez.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Pa crear la cuenta necesites corréu y contraseña.

## Los verbos dixitales

| Asturianu | Euskera |
|---|---|
| Prender / apagar | *piztu / itzali* |
| Descargar / baxar | *deskargatu / jaitsi* |
| Instalar | *instalatu* |
| Guardar | *gorde* |
| Desaniciar | *ezabatu* |
| Unviar / compartir | *bidali / partekatu* |
| Buscar (na rede) | *bilatu* |
| Funcionar / furrular | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — L'ordenador va mal; apágalo y préndilo — la solución de siempre.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — ¿Guardasti les semeyes? ¡Nun desanicies nada!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Descargues l'app, crees la cuenta y listo.

## Diálogu: soporte téunicu familiar

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Nota:** l'euskera dixital ta muy vivu: el software llibre y la Wikipedia n'euskera son potentes, y el to móvil enteru pue dir n'euskera (*Ezarpenak → Hizkuntza*). Ponelo ye, de fechu, un truquín d'estudiu brutal: inmersión diaria gratis.
