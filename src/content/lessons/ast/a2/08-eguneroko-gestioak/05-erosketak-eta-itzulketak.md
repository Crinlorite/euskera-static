Comprar yá lo sabíes dende l'A1. Esta lleición ye'l **nivel 2 de tienda**: probar ropa, engarrase coles talles y — el xefe final — **cambear o devolver** ensin sudar. Con dos vieyos amigos trabayando: el *-egi* (demasiáu) y el NOR-NORI (*geratzen zait*).

## Nel probador

| Asturianu | Eusquera |
|---|---|
| ¿Podo probalo? | *Probatu dezaket?* |
| El probador | *probalekua* |
| La talla | *neurria / talla* |
| ¿Qué talla uses? | *Zein neurri erabiltzen duzu?* |
| Quéda-yme bien / mal | *Ondo / gaizki geratzen zait* |
| Demasiáu grande / pequeñu | *Handiegia / txikiegia* |
| ¿Teníaislo n'otru color? | *Beste kolore batean baduzue?* |
| ¿Y nuna talla más? | *Eta neurri bat handiagoan?* |

> *— Praka hauek **probatu ditzaket**?*
>
> *— Noski, **probalekua** hor atzean dago.*
>
> *(bost minutu geroago)* *— Zer, **ondo geratzen zaizkizu**?*
>
> *— Ez… **txikiegiak dira**. **42an baduzue**?*

*Geratzen zait / zaizkizu* — NOR-NORI puru: la prenda (NOR) quéda-yme A MÍ (NORI). En plural: *geratzen zaizkit* (quédenme).

## Cambear y devolver

| Asturianu | Eusquera |
|---|---|
| Quiero cambealo | *Aldatu nahi dut* |
| Quiero devolvelo | *Itzuli nahi dut* |
| ¿Devuélvenme'l dineru? | *Dirua itzuliko didazue?* |
| El tique | *tiketa* |
| Tien un defectu | *Akats bat dauka* |
| Ta ensin estrenar | *Erabili gabe dago* |
| El plazu de devolución | *Itzultzeko epea* |

> *— Egun on. Jertse hau **itzuli nahi nuke**. **Akats bat dauka** hemen, ikusten?*
>
> *— Egia da. **Tiketa badaukazu**?*
>
> *— Bai, hemen. **Dirua itzuliko didazue** ala aldatu behar dut?*
>
> *— Nahi duzun bezala. Dirua **txartelera itzuliko dizugu**, bi-hiru egunetan.*
>
> *— Primeran, eskerrik asko.*

Fíxate nel NOR-NORI-NORK encadenáu: *itzuliko didazue* (vais devolve-ylo), *itzuliko dizugu* (vamos devolvete-ylo). La unidá 03 trabayando na vida real.

## Rebaixes y precios (repasu con chispa)

>
> *Deskontuarekin, **19,95 euro** bakarrik.* — Col descuentu, solo 19,95 €.
>
> *Bi erosita, **hirugarrena doan**.* — Mercando dos, el terceru gratis.

## El resume de bolsu

1. **Probar**: *Probatu dezaket? → Ondo/gaizki geratzen zait → -egi* pa les talles.
2. **Cambear**: *Aldatu nahi dut* (+ *beste neurri/kolore batean*).
3. **Devolver**: *Itzuli nahi dut* + *tiketa* + *dirua itzuliko didazue?*
