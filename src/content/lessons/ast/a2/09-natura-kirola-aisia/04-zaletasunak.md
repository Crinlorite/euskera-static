¿Qué faes cuando nun faes nada? Esta lleición va d'**aficiones** — y de la pieza de gramática que les gobierna: el verbu convertíu en sustantivu con **-tzea** (*irakurtzea* = "el lleer").

## La pieza: -t(z)ea

Del A1 conoces *gustatzen zait* con coses (*kafea gustatzen zait*). Pa que te preste una **actividá**, el verbu faise sustantivu:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| Castellán | Eusquera |
|---|---|
| Préstame lleer | *Irakurtzea gustatzen zait* |
| Préstame muncho cocinar | *Asko gustatzen zait sukaldatzea* |
| Présta-y cantar | *Abestea gustatzen zaio* |
| Préstanos viaxar | *Bidaiatzea gustatzen zaigu* |
| Nun me presta nada madrugar | *Ez zait batere gustatzen goiz jaikitzea* |

Tolo NOR-NORI que yá sabes (*zait, zaio, zaigu…*) sigue mandando; solo camuda'l "qué".

## El catálogu d'aficiones

| Castellán | Eusquera |
|---|---|
| Lleer / escribir | *irakurtzea / idaztea* |
| Escuchar música | *musika entzutea* |
| Cantar / baillar | *abestea / dantzatzea* |
| Cocinar | *sukaldatzea* |
| Sacar semeyes | *argazkiak ateratzea* |
| Pintar / dibuxar | *margotzea / marraztea* |
| Viaxar | *bidaiatzea* |
| Curiar la güerta | *baratzea zaintzea* |
| Los videoxuegos | *bideo-jokoak* |
| Coser / texer | *jostea / puntua egitea* |

## Preguntar y presumir

> ***Zer egitea gustatzen zaizu** denbora librean?* — ¿Qué te presta facer nel to tiempu llibre?
>
> ***Zein da zure zaletasunik gogokoena**?* — ¿Cuál ye la to afición favorita?

> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — La mio afición favorita ye cocinar: cada finde pruebo una receta nueva.

## Tres estructures, tres matices (repasu finu)

| Estructura | Exemplu | Significa |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | préstame (afición) |
| **-tzen dakit** | *Margotzen dakit* | sé facelo (habilidá) |
| **-tzen ari naiz** | *Margotzen ari naiz* | toi faciéndolo (agora) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — Nun sé texer, pero prestaríame aprender. (Esi *gustatuko litzaidake* elegante vas dominalu en B1 — dexámostelu equí d'aperitivu.)
