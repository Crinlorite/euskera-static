Do papel ao píxel: a lección de **tecnoloxía cotiá**. Vocabulario que usas cen veces ao día — agora en éuscaro, que ademais presume de palabras transparentes e ben construídas (*pasahitza* = palabra de paso; *sakelakoa* = "o de peto").

## Os aparellos

| Galego | Euskera |
|---|---|
| O ordenador | *ordenagailua* |
| O (ordenador) portátil | *eramangarria* |
| O móbil | *mugikorra / sakelakoa* |
| A tableta | *tableta* |
| A pantalla | *pantaila* |
| O teclado | *teklatua* |
| O rato | *sagua* (si, o animal!) |
| Os auriculares | *entzungailuak* |

## A rede e as contas

| Galego | Euskera |
|---|---|
| A rede / internet | *sarea / internet* |
| O wifi | *wifia* |
| O correo electrónico | *posta elektronikoa* |
| O usuario | *erabiltzailea* |
| O contrasinal | *pasahitza* |
| A aplicación | *aplikazioa* |
| A páxina web | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Cal é o contrasinal do wifi?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — Esquecín o contrasinal e agora teño que crear un novo. Outra vez.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Para crear a conta necesitas correo e contrasinal.

## Os verbos dixitais

| Galego | Euskera |
|---|---|
| Acender / apagar | *piztu / itzali* |
| Descargar | *deskargatu / jaitsi* |
| Instalar | *instalatu* |
| Gardar | *gorde* |
| Borrar | *ezabatu* |
| Enviar / compartir | *bidali / partekatu* |
| Buscar (na rede) | *bilatu* |
| Funcionar | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — O ordenador vai mal; apágao e acéndeo — a solución de sempre.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Gardaches as fotos? Non borres nada!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Descargas a app, creas a conta e listo.

## Diálogo: soporte técnico familiar

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄
