O **imperativo** (*agintera*) serve para dar instrucións, facer peticións e dar consellos. En éuscaro é **moito máis sinxelo do que parece**: a forma máis usada coincide case sempre co **participio** do verbo.

## A regra básica: usa o participio

Para moitas ordes cotiás, o verbo aparece na súa forma de participio sen auxiliar:

| Castelán | Éuscaro |
|---|---|
| Toma | *Hartu* |
| Senta | *Eseri* |
| Levántate | *Jaiki* |
| Escribe | *Idatzi* |
| Le | *Irakurri* |
| Escoita | *Entzun* |
| Repite | *Errepikatu* |
| Espera | *Itxoin* |
| Pecha a porta | *Itxi atea* |
| Abre a xanela | *Ireki leihoa* |

> Esta é a **forma máis usada** na aula, na rúa e en instrucións escritas. Serve tanto para *zu* como para *zuek*.

## Formas sintéticas (trinkoak): *zatoz*, *zoaz*

Algúns verbos moi frecuentes teñen formas sintéticas específicas para o imperativo. Estas son as que convén memorizar:

| Verbo | Ti (zu) | Vós (zuek) |
|---|---|---|
| *etorri* (vir) | **Zatoz** | **Zatozte** |
| *joan* (ir) | **Zoaz** | **Zoazte** |
| *ekarri* (traer) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (levar) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (estar) | **Egon** / **Lasai** (tranquilo!) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## Imperativo NOR-NORI-NORK: *emadazu*, *esadazu*

Cando dás unha orde con dobre obxecto ("dáme isto", "dille aquilo"), o éuscaro ten formas compactas moi útiles:

| Castelán | Éuscaro |
|---|---|
| Dáme | *Emadazu* / *Eman iezadazu* |
| Dime | *Esadazu* / *Esan iezadazu* |
| Dálle | *Emaiozu* / *Eman iezaiozu* |
| Dille | *Esaiozu* / *Esan iezaiozu* |
| Dános | *Emaguzu* |
| Dádeme | *Emadazue* |

Estas formas son longas de aprender; en A2 abonda con **emadazu / esadazu / emaiozu / esaiozu** e entender que veñen do verbo *eman* / *esan*.

## "Por favor" e suavizadores

O imperativo en éuscaro **non soa brusco** se engades algunha palabra de cortesía:

- *Mesedez* — por favor
- *Ahal baduzu* — se podes
- *Faborez* (variante coloquial)
- *Eskerrik asko aldez aurretik* — grazas por adiantado

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## Instrucións (receitas, anuncios, aula)

O imperativo é a forma estándar en:

- **Receitas:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **Carteis:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **Aula:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **Médico:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## Mini-texto

> *Sukaldari eskolan, irakasleak esaten du:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **Nota cultural:** en éuscaro o ton **mandón** do imperativo atenúase coa entoación e o contexto, non tantas veces con perífrases ("poderías..."). Acompañar a orde con *mesedez* ou cun sorriso adoita ser suficiente. Se queres algo máis cortés, di *eman ahal didazu...?* (pódesme dar...?).
