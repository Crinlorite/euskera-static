Falar de **estilo de vida** e **medio ambiente** é un bloque clásico do A2: mestúrase vocabulario novo con frases de obriga e consello (*behar dugu*, *komeni da*, *garrantzitsua da*) que xa manexas desde A1.

## Hábitos saudables

| Castelán | Éuscaro |
|---|---|
| Facer deporte | *kirola egin* |
| Camiñar / pasear | *paseatu* / *ibili* |
| Correr | *korrika egin* |
| Andar en bici | *bizikletaz ibili* |
| Comer froita e verdura | *fruta eta barazkiak jan* |
| Beber auga | *ura edan* |
| Durmir ben | *ondo lo egin* |
| Fumar | *erre* |
| Beber alcol | *alkohola edan* |
| Non abusar do sal | *gatzaz ez abusatu* |

> Frases típicas:
>
> - *Kirola egiten dut astean hiru aldiz.* — Fago deporte tres veces á semana.
> - *Erretzeari utzi diot.* — Deixei de fumar.
> - *Ez dut alkoholik edaten astegunetan.* — Non bebo alcol entre semana.

## Frecuencia: *X aldiz*

Para dicir "X veces" usas a fórmula **número + aldiz**:

| Castelán | Éuscaro |
|---|---|
| Unha vez ao día | *Egunean behin* |
| Dúas veces á semana | *Astean bi aldiz* / *birritan* |
| Tres veces ao mes | *Hilean hiru aldiz* |
| Moitas veces | *Askotan* |
| Ás veces | *Batzuetan* |
| Poucas veces | *Gutxitan* |
| Nunca | *Inoiz ez* |

## Os contedores

| Cor habitual | Éuscaro | Para que |
|---|---|---|
| Azul | *edukiontzi urdina* | papera / papel |
| Amarelo | *edukiontzi horia* | plastikoa / plástico |
| Verde | *edukiontzi berdea* | beira / vidro |
| Marrón | *edukiontzi marroia* | organikoa / orgánico |
| Gris | *edukiontzi grisa* | hondakinak / resto |

## Frases útiles para opinar

- *Garrantzitsua da birziklatzea.* — É importante reciclar.
- *Komeni da kirola egitea.* — Convén facer deporte.
- *Beharrezkoa da kutsadura gutxitzea.* — É necesario reducir a contaminación.
- *Ez dut uste plastikoa ona denik.* — Non creo que o plástico sexa bo.

> Estas estruturas (*-tzea + adjetivo + da*) son a fórmula A2 para "é importante / convén / é necesario facer X". Traballarémolas a fondo na unidade 4.

## Vida do barrio

| Castelán | Éuscaro |
|---|---|
| Barrio | *auzoa* |
| Veciño/a | *bizilaguna* |
| Asociación | *elkartea* |
| Voluntariado | *boluntariotza* |
| Festas do barrio | *auzoko jaiak* |
| Participar | *parte hartu* |
| Reunión | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## Mintexto modelo

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **Nota cultural:** as *auzo-elkarteak* (asociacións de veciños) son unha peza fundamental da vida social en moitas vilas de Euskal Herria. Organizan festas, obradoiros de éuscaro, saídas ao monte e campañas medioambientais. Participar é unha das mellores formas de practicar a lingua en uso real.
