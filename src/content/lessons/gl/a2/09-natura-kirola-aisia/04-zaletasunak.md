Que fas cando non fas nada? Esta lección vai de **afeccións** — e da peza de gramática que as goberna: o verbo convertido en substantivo con **-tzea** (*irakurtzea* = "o ler").

## A peza: -t(z)ea

Do A1 coñeces *gustatzen zait* con cousas (*kafea gustatzen zait*). Para que che guste unha **actividade**, o verbo faise substantivo:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| Castelán | Éuscaro |
|---|---|
| Gústame ler | *Irakurtzea gustatzen zait* |
| Gústame moito cociñar | *Asko gustatzen zait sukaldatzea* |
| Gústalle cantar | *Abestea gustatzen zaio* |
| Gústanos viaxar | *Bidaiatzea gustatzen zaigu* |
| Non me gusta nada madrugar | *Ez zait batere gustatzen goiz jaikitzea* |

Todo o NOR-NORI que xa sabes (*zait, zaio, zaigu…*) segue mandando; só cambia o "que".

## O catálogo de afeccións

| Castelán | Éuscaro |
|---|---|
| Ler / escribir | *irakurtzea / idaztea* |
| Escoitar música | *musika entzutea* |
| Cantar / bailar | *abestea / dantzatzea* |
| Cociñar | *sukaldatzea* |
| Sacar fotos | *argazkiak ateratzea* |
| Pintar / debuxar | *margotzea / marraztea* |
| Viaxar | *bidaiatzea* |
| Coidar a horta | *baratzea zaintzea* |
| Os videoxogos | *bideo-jokoak* |
| Coser / tecer | *jostea / puntua egitea* |

## Preguntar e presumir

> ***Zer egitea gustatzen zaizu** denbora librean?* — Que che gusta facer no teu tempo libre?
>
> ***Zein da zure zaletasunik gogokoena**?* — Cal é a túa afección favorita?
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — A miña afección favorita é cociñar: cada fin de semana probo unha receita nova.

## Tres estruturas, tres matices (repaso fino)

| Estrutura | Exemplo | Significa |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | gústame (afección) |
| **-tzen dakit** | *Margotzen dakit* | seino facer (habilidade) |
| **-tzen ari naiz** | *Margotzen ari naiz* | estouno facendo (agora) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — Non sei tecer, pero gustaríame aprender. (Ese *gustatuko litzaidake* elegante dominaralo no B1 — deixámoscho aquí de aperitivo.)

## Diálogo

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*

> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
