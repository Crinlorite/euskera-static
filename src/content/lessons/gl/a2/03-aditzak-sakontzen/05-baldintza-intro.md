O **condicional** (*baldintza*) en éuscaro ten varias formas. En A2 quedamos coas **dúas máis útiles**:

1. **Condición real (futuro probable):** *se chove mañá, non irei*.
2. **Condición irreal (hipótese):** *se tivese diñeiro, compraría unha casa*.

Esta lección é unha **introdución**: abonda con que recoñezas as formas e produzas frases sinxelas. A unidade B1 afonda niso.

## Tipo 1: condición real — *ba-* + presente

Para hipóteses sobre o **futuro probable** ou o presente, o éuscaro usa o prefixo **ba-** sobre o auxiliar en presente.

> **ba- + presente do auxiliar, ... + futuro**

| Galego | Éuscaro |
|---|---|
| Se chove, non irei | *Euria egiten **badu**, ez naiz joango* |
| Se tes tempo, ven | *Astia **baduzu**, etorri* |
| Se queres, chámame | *Nahi **baduzu**, deitu niri* |
| Se son rico algún día… | *Aberatsa **banaiz** noizbait...* |

### Formas con *ba-* (presente)

| Verbo | Sen ba- | Con ba- |
|---|---|---|
| *naiz* | eu son | **banaiz** (se son) |
| *zara* | ti es | **bazara** (se es) |
| *da* | é | **bada** (se é) |
| *gara* | somos | **bagara** (se somos) |
| *dut* | eu o | **badut** (se o teño) |
| *du* | o (el) | **badu** (se o ten) |
| *dute* | o (eles) | **badute** (se o teñen) |

> **Coidado!** *Ba-* ten tamén un uso afirmativo: *bai, badator* = "si, vén". É o contexto o que o desambigua: se a frase ten unha segunda parte ("...entón..."), é condicional.

## Tipo 2: condición irreal — *banintz / banu*

Para hipóteses irreais ou moi pouco probables ("se eu fose...", "se eu tivese..."), o éuscaro usa formas dedicadas:

### Formas de *izan* en condición irreal

| Pronome | Forma | Galego |
|---|---|---|
| ni | **banintz** | se eu fose/estivese |
| zu | **bazina** | se ti foses |
| hura | **balitz** | se fose/estivese |
| gu | **bagina** | se nós fósemos |
| zuek | **bazinete** | se vós fósedes |
| haiek | **balira** | se eles fosen |

### Formas de *ukan* en condición irreal

| Pronome | Forma | Galego |
|---|---|---|
| nik | **banu** | se eu o tivese |
| zuk | **bazenu** | se ti o tiveses |
| hark | **balu** | se el o tivese |
| guk | **bagenu** | se nós o tivésemos |
| haiek | **balute** | se eles o tivesen |

> **Memoriza primeiro estas seis**: *banintz, balitz, banu, balu, bagenu, balute*. Son as que aparecen en calquera frase condicional irreal.

## A consecuencia: *-ko/-go + nuke / nintzateke*

O "comprar**ía** / iría / sería" fórmase con **-ko/-go** (a mesma marca que o futuro) + auxiliar especial:

### NOR-NORK condicional ("eu o + ría")

| Pronome | Forma | Galego |
|---|---|---|
| nik | **nuke** | eu o —ría |
| zuk | **zenuke** | ti o —rías |
| hark | **luke** | el o —ría |
| guk | **genuke** | o —ríamos |
| haiek | **lukete** | o —rían |

### NOR condicional ("eu —ría", intransitivo)

| Pronome | Forma | Galego |
|---|---|---|
| ni | **nintzateke** | eu —ría |
| zu | **zinateke** | ti —rías |
| hura | **litzateke** | el —ría / sería |
| gu | **ginateke** | —ríamos |
| haiek | **lirateke** | —rían |

## Frase modelo

> **baldintza + ondorioa**

> *Diru asko **banu**, etxe bat **erosiko nuke**.* — Se tivese moito diñeiro, compraría unha casa.
>
> *Lurralde berri batean **bizi banintz**, beste hizkuntza bat **ikasiko nuke**.* — Se vivise nun país novo, aprendería outro idioma.
>
> *Anboto hemen **balitz**, lasaiago **egongo ginateke**.* — Se Anboto estivese aquí, estariamos máis tranquilos.
>
> *Aberatsak **balira**, mundu osoa **bisitatuko lukete**.* — Se fosen ricos, visitarían o mundo enteiro.

## Comparación dos dous tipos

| Tipo | "se" | "entón" |
|---|---|---|
| Real (futuro probable) | *ba-* + presente: *baduzu, bada* | futuro: *-ko/-go + naiz/dut* (joango naiz, erosiko dut) |
| Irreal (hipótese) | *ba-* + condicional: *banu, balitz* | condicional: *-ko/-go + nuke/nintzateke* |

## Exemplos en contraste

- **Real:** *Astia **baduzu**, lagunduko **dizut**.* — Se tes tempo, axudareite.
- **Irreal:** *Astia **bazenu**, lagunduko **zenidake**.* — Se tiveses tempo, axudaríasme.

## Frases feitas moi útiles

| Galego | Éuscaro |
|---|---|
| Quererías…? | *Nahi **zenuke**…?* |
| Gustaríame… | *Gustatuko **litzaidake**…* |
| Sería bonito… | *Polita **litzateke**…* |
| Iría con gusto | *Gustura **joango nintzateke*** |
| Pensaríao | *Pentsatuko **nuke*** |

## Minidiálogo

> *— Olatz, **nahi zenuke** zinemara joan?*
>
> *— Si, **gustatuko litzaidake**, pero se tivese tempo... Teño moito traballo na semana.*
>
> *— Tranquila. Se vés mañá, comprareiche unha entrada.*

> **Nota pedagóxica:** a *baldintza* é un dos puntos onde A2 che abre a porta a B1. No A2 oficial abonda con **recoñecela** e producir frases sinxelas do tipo *banintz... -ko nuke*. A conxugación completa do condicional trabállase en B1.
