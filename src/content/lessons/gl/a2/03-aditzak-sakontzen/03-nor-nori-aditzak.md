Os verbos **NOR-NORI** son aqueles nos que algo (NOR) "lle ocorre a alguén" (NORI). O suxeito gramatical é **a cousa**, non a persoa — exactamente como *gustar* en castelán: *me gusta el cine* (a min gústame el, o cine).

En A1 xa viches *gustatzen zait*. En A2 amplías o padrón a outros verbos moi útiles.

## As formas do auxiliar NOR-NORI presente

Para NOR singular:

| NORI | Forma | Castelán |
|---|---|---|
| niri | **zait** | me |
| zuri | **zaizu** | te |
| hari | **zaio** | lle |
| guri | **zaigu** | nos |
| zuei | **zaizue** | vos |
| haiei | **zaie** | lles |

Para NOR **plural**:

| NORI | Forma plural | Castelán |
|---|---|---|
| niri | **zaizkit** | me (cousas) |
| zuri | **zaizkizu** | te |
| hari | **zaizkio** | lle |
| guri | **zaizkigu** | nos |
| zuei | **zaizkizue** | vos |
| haiei | **zaizkie** | lles |

## Pasado: *zitzaidan, zitzaion*

| NORI | Pasado sing. | Pasado pl. |
|---|---|---|
| niri | **zitzaidan** | **zitzaizkidan** |
| zuri | **zitzaizun** | **zitzaizkizun** |
| hari | **zitzaion** | **zitzaizkion** |
| guri | **zitzaigun** | **zitzaizkigun** |
| haiei | **zitzaien** | **zitzaizkien** |

## Verbos con este padrón

| Verbo | Significado | Exemplo |
|---|---|---|
| *gustatu* | gustar | *Filmak gustatzen zaizkit* (gústanme as pelis) |
| *iruditu* | parecer | *Ondo iruditzen zait* (paréceme ben) |
| *ahaztu* | esquecerse | *Ahaztu zait izena* (esquecéuseme o nome) |
| *erori* | caer | *Erori zaizu boligrafoa* (caeuche o bolígrafo) |
| *gertatu* | ocorrerlle | *Zer gertatu zaizu?* (que che pasou?) |
| *interesatu* | interesar | *Politika interesatzen zait* (interésame a política) |
| *axola izan* | importar | *Ez zait axola* (non me importa) |

## Estrutura: o suxeito é a cousa

> **NORI + NOR + verbo + auxiliar NOR-NORI**

| Castelán | Éuscaro | Notación |
|---|---|---|
| Gústame o cine | *Niri zinea **gustatzen zait*** | NORI + NOR sing + zait |
| Gústanme as películas | *Niri filmak **gustatzen zaizkit*** | NORI + NOR pl + zaizkit |
| Paréceche ben | *Zuri ondo **iruditzen zaizu*** | NORI + NOR + zaizu |
| Caeulle un libro | *Hari liburu bat **erori zaio*** | NORI + NOR sing + zaio |
| Esquecéronseme as chaves | *Niri giltzak **ahaztu zaizkit*** | NORI + NOR pl + zaizkit |

> **Truco:** a persoa afectada vai en NORI (-ari/-ei) e adoita aparecer ao principio. A cousa é o suxeito gramatical, e o verbo concorda con ela.

## *Gustatzen zait* en pasado — *gustatu zitzaidan*

Para falar de gustos no pasado:

> *Filma asko **gustatu zitzaidan**.* — A película gustoume moito.
>
> *Ez zitzaion gustatu opari hori.* — Non lle gustou ese agasallo.

> Coidado: *gustatu zitzaidan* (= gustoume, feito pechado) vs *gustatzen zitzaidan* (= gustábame, hábito).

## *Iruditu* (parecer) — opinión persoal

Unha das fórmulas máis útiles para A2:

| Castelán | Éuscaro |
|---|---|
| Paréceme ben | *Ondo iruditzen zait* |
| Paréceme interesante | *Interesgarria iruditzen zait* |
| Que che parece? | *Zer iruditzen zaizu?* |
| Paréceme raro | *Bitxia iruditzen zait* |
| Paréceme que si | *Baietz iruditzen zait* |

## *Ahaztu zait* — esquecéuseme

| Castelán | Éuscaro |
|---|---|
| Esquecéuseme | *Ahaztu zait* |
| Esquecéronseme as chaves | *Giltzak ahaztu zaizkit* |
| Esquéceselle todo | *Dena ahazten zaio* |
| Que non se che esqueza! | *Ez zaizula ahaztu!* |

## Minidiálogo

> *— Olatz, **zer iruditzen zaizu** Bilboko jatetxe berria?*
>
> *— Asko **gustatu zait**. Bereziki bigarren platerak: **interesgarriak iruditu zaizkit**.*
>
> *— Eta, jakin nahi nuen, **ahaztu zaizu** zer eskatu zenuen?*
>
> *— Bai, izenak ez **zaizkit gogoratzen**, baina arraina zen, ziur.*

## Trampas frecuentes

1. **O suxeito ergativo NON existe aquí.** Non digas *\*Nik gustatzen dut* (é un erro moi común): é *Niri gustatzen zait*. A persoa non é a que actúa.
2. **Concordancia NOR.** Se a cousa é plural, o auxiliar é plural: *zaizkit, zaizkio, zaizkigu...*
3. **Algunhas rexións usan outras variantes** (*zaidak, zaidan* en hitano), pero en *batua* as formas estándar son as da táboa.

> **Nota cultural:** os falantes de éuscaro adoitan abusar (con agarimo) de *iruditzen zait* para opinar con certa cautela: *interesgarria iruditzen zait*, *bitxia iruditzen zait*, *ez zait ondo iruditzen*. É a versión vasca do "paréceme que..." matizado.
