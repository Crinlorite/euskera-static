Nesta lección completas a familia das comparacións con dúas pezas:

1. **Igualdade** ("tan... coma", "tanto coma"): *bezain*, *adina*, *beste*.
2. **Superlativo** ("o máis..."): *-en + a*.

## Igualdade: *bezain*

Para "tan... coma" con adxectivo ou adverbio:

> **X bezain Y**

| Galego | Éuscaro |
|---|---|
| Tan alto coma ti | *Zu **bezain** altua* |
| Tan bonita coma Donostia | *Donostia **bezain** polita* |
| Tan bo coma o seu pai | *Aita **bezain** ona* |
| Non tan rápido coma cría | *Uste nuen **bezain** azkarra ez da* |

> Frase completa: *Lander **zu bezain altua** da.* — Lander é tan alto coma ti.

## Igualdade de cantidade: *adina / beste*

Para "tanto coma" con substantivo ou cantidade:

| Galego | Éuscaro |
|---|---|
| Tanto coma ti | *Zuk **adina*** / *Zuk **beste*** |
| Tantos cartos coma min | *Nik **adina** diru* |
| Tantos anos coma Anboto | *Anbotok **adina** urte* |

> *Zuk adina urte ditut.* — Teño tantos anos coma ti.
>
> *Garazik nik beste irakurtzen du.* — Garazi le tanto coma min.

> **Diferenza:** *bezain* vai con calidades (adxectivos/adverbios). *Adina/beste* vai con cantidades (substantivos contables ou de cantidade). Ás veces hai erros — a regra práctica: se a palabra que segue é **adxectivo** → *bezain*; se é **substantivo ou número** → *adina/beste*.

## Comparación de modo: *bezala / moduan*

Outra forma de igualdade, esta vez de **modo** ou **maneira**:

| Galego | Éuscaro |
|---|---|
| Coma ti | *Zu **bezala*** / *Zure **moduan*** |
| Fago coma ti | *Zuk egin duzun **moduan** egiten dut* |
| Unha casa coma a túa | *Zurea **bezalako** etxea* |
| Fala coma a súa nai | *Amaren **moduan** hitz egiten du* |

> Compara:
>
> - *Zu **bezain** altua* — tan alto coma ti (calidade)
> - *Zu **bezala** hitz egiten du* — fala coma ti (modo)
> - *Zuk **adina** ikasten du* — estuda tanto coma ti (cantidade)

## Superlativo: *-en + a*

Para "o máis..." engades **-en** ao adxectivo ou adverbio + o artigo **-a**:

| Adxectivo | Superlativo |
|---|---|
| *handia* (grande) | *handi**ena*** (o máis grande) |
| *txikia* (pequeno) | *txiki**ena*** |
| *polita* (bonito) | *polit**ena*** |
| *zaharra* (vello) | *zaharr**ena*** |
| *azkarra* (rápido) | *azkarr**ena*** |
| *garestia* (caro) | *garesti**ena*** |
| *ona* (bo) | **onena** / **hoberena** (irregular) |
| *txarra* (malo) | **txarrena** / **okerrena** |

> *Liburu hau **politena** da.* — Este libro é o máis bonito.
>
> *Donostia Euskal Herriko hiri **politena** da, askoren ustez.* — Donostia é a cidade máis bonita de Euskal Herria, segundo moitos.

## Superlativo + grupo: *-etan / -etako*

Cando indicas **dentro de que grupo**, usas o caso locativo ou o xenitivo:

| Galego | Éuscaro |
|---|---|
| O máis alto da clase | *Klaseko **altuena*** |
| A máis rápida do mundo | *Munduko **azkarrena*** |
| O mellor de todos | *Denetan **onena*** / *Guztietan **onena*** |
| O peor dos días | *Egunetan **txarrena*** |

> *Klaseko ikasle **azkarrena** da.* — É o alumno máis rápido da clase.
>
> *Euskal Herriko mendi **altuena** Hiru Errege Mahaia da.* — A montaña máis alta de Euskal Herria é Hiru Errege Mahaia (a Mesa dos Tres Reis).

## *Gehien / gutxien* — o que máis / o que menos

Equivalentes superlativos de cantidade ou frecuencia:

| Galego | Éuscaro |
|---|---|
| O que máis me gusta | *Gehien gustatzen zaidana* |
| O que menos fago | *Gutxien egiten dudana* |
| Quen máis estuda | *Gehien ikasten duena* |

## Minicomparación cultural

Frases típicas:

- *Hiru Errege Mahaia Euskal Herriko mendi **altuena** da.* — Hiru Errege Mahaia (a Mesa dos Tres Reis) é o monte máis alto de Euskal Herria.
- *Korrika euskararen aldeko ekintza **handiena** da.* — A Korrika é a maior acción a favor do éuscaro.
- *San Fermin festa famatuena da.* — San Fermín é a festa máis famosa.

## Truco para memorizar

| Forma | Exemplo |
|---|---|
| Comparativo (máis X que…) | *X baino Y-**agoa*** |
| Igualdade (tan X coma…) | *Y bezain X* |
| Igualdade de cantidade (tanto coma) | *Yk adina X* |
| Superlativo (o máis X) | *X-**ena*** |
| Superlativo en grupo | *Z-ko / Z-etan + X-**ena*** |

## Minidiálogo

> *— Anboto, hau bai pintxoa! Sekula jan dudan **goxoena**.*
>
> *— Bai, **zure ustez** Bilboko **onenak** non daude?*
>
> *— Plaza Berrian. Han pintxoak **garestienak** dira, baina **goxoenak** ere bai. Donostiakoak ere ez dira **gutxiago**: ia **maila berekoak** dira.*

> **Nota cultural:** en debates típicos de *Euskal Herri*, *Donostiako pintxoak Bilbokoak baino hobeak dira* é un clásico de discusión amable. A realidade: cada zona defende os seus, e todos están boísimos.
