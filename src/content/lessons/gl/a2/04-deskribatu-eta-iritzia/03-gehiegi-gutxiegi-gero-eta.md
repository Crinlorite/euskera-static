Esta lección completa as comparacións con dúas pezas máis:

1. **Exceso e defecto** (-egi, gehiegi, gutxiegi).
2. **Comparativo progresivo** (cada vez máis / menos: *gero eta...*).

Máis algúns modificadores útiles para matizar (*pixka bat, askoz, dezente*).

## O sufixo -**egi** — "demasiado"

Para dicir que algo é **excesivo**, engádese **-egi** ao adxectivo (e logo o **-a** final se vai cun substantivo determinado):

| Adxectivo | Excesivo |
|---|---|
| *handia* (grande) | *handi**egia*** (demasiado grande) |
| *txikia* (pequeno) | *txiki**egia*** |
| *garestia* (caro) | *garesti**egia*** |
| *beroa* (quente) | *bero**egia*** |
| *hotza* (frío) | *hotz**egia*** |
| *zaila* (difícil) | *zail**egia*** |
| *azkarra* (rápido) | *azkarr**egia*** |

> *Alkandora hau **handiegia** da niretzat.* — Esta camisa é demasiado grande para min.
>
> *Kafea **beroegi** dago.* — O café está demasiado quente.
>
> *Ikastaroa **zailegia** zen guretzat.* — O curso era demasiado difícil para nós.

## *Gehiegi* e *gutxiegi*

Como adverbios independentes:

| Castelán | Éuscaro |
|---|---|
| Demasiado | *gehiegi* |
| Demasiado pouco / insuficiente | *gutxiegi* |
| Demasiada xente | *jende **gehiegi*** |
| Moi pouca auga | *ur **gutxiegi*** |

> *Gehiegi jan dut.* — Comín demasiado.
>
> *Gutxiegi lo egiten duzu.* — Dormes (demasiado) pouco.
>
> *Hori **gehiegi** da niretzat.* — Iso é demasiado para min.

## O comparativo progresivo: *gero eta + -ago*

Para "**cada vez máis X**" ou "**cada vez menos X**", o éuscaro usa unha fórmula moi expresiva:

> **gero eta + adxectivo/adverbio-ago(a)**

| Castelán | Éuscaro |
|---|---|
| Cada vez máis caro | *Gero eta **garestiagoa*** |
| Cada vez máis frío | *Gero eta **hotzagoa*** |
| Cada vez mellor | *Gero eta **hobea*** |
| Cada vez peor | *Gero eta **okerragoa*** |
| Cada vez máis | *Gero eta **gehiago*** |
| Cada vez menos | *Gero eta **gutxiago*** |
| Cada vez máis rápido | *Gero eta **azkarrago*** |
| Cada vez máis amodo | *Gero eta **polikiago*** |

> *Bilbo gero eta handiagoa da.* — Bilbao é cada vez máis grande.
>
> *Eguraldia gero eta okerrago dago.* — O tempo está cada vez peor.
>
> *Gazteek gero eta gutxiago hitz egiten dute euskaraz.* — A xente nova fala cada vez menos en éuscaro.

> **Truco mnemotécnico:** *gero eta* literalmente "logo e" — a idea é "logo, e logo, e logo máis...". É a forma vasca de expresar progresión.

## *Hain* — "tan" (con ou sen negación)

| Castelán | Éuscaro |
|---|---|
| É tan grande | *Hain handia da* |
| Non é tan caro | *Ez da **hain** garestia* |
| É tan bonito! | *Hain polita da!* |

> Para "non é tan... coma..." úsase *bezain* (lección anterior):
>
> *Ez da zuk uste duzun bezain ona.* — Non é tan bo como ti pensas.

## Modificadores de cantidade

Para matizar as comparacións:

| Castelán | Éuscaro | Exemplo |
|---|---|---|
| Un pouco | *pixka bat* | *Pixka bat handiagoa* (un pouco máis grande) |
| Algo | *zerbait / zertxobait* | *Zertxobait txikiagoa* (algo máis pequeno) |
| Bastante | *dezente* | *Dezente hobea* (bastante mellor) |
| Moito | *askoz* | *Askoz hobea* (moito mellor) |
| Moitísimo | *askoz hobea / askoz garestiagoa* | |

> *Etxe hau zurea **baino askoz** handiagoa da.* — Esta casa é moito máis grande ca a túa.
>
> *Pixka bat goizago etorriko naiz.* — Virei un pouco antes.

## *Hain... ezen* / *hainbeste...* (rexistro alto)

Máis alá do A2 estrito, convén recoñecer:

- *Hain* + adxectivo + *non/ezen* — tan... que: *Hain pozik zegoen, non kantatzen hasi zen* (estaba tan contento que se puxo a cantar).
- *Hainbeste* — tanto/a (cantidade enfática): *Hainbeste lan dago!*

## Mini-texto

> *Garazi sukaldari ona da, baina kafea **beroegi** ipintzen du beti. Lehengo egunean **hain bero** zegoen, ezen ezin nuen edan! Eta hori ez da dena: pintxo bakoitzean olio **gehiegi** botatzen du. **Pixka bat gutxiago** beharko luke. Hala ere, hura **gero eta hobea** da: orain dela urtebete askoz **okerragoa** zen.*

## Mini-diálogo

> *— Olatz, etxe berri hori zer moduz?*
>
> *— Eder askoa, baina **garestiegia** zen guretzat. Eta logelak **txikiegiak** ziren.*
>
> *— Eta orain bilatzen ari zaretena nolakoa da?*
>
> *— **Gero eta zailagoa** da etxebizitza on bat aurkitzea. Prezioak **gero eta altuagoak** dira eta etxebizitza on guztiek dute lehia **gehiegi**.*

> **Nota cultural:** a escaseza de vivenda accesible (*etxebizitza*) é un tema recorrente en calquera conversa de A2 sobre a actualidade: *gero eta garestiago, pisu eskuragarri gutxiegi, askoz okerrago lehen baino*. Esta lección dáche o vocabulario para participar.
