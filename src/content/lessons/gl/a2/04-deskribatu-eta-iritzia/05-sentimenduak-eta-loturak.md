Esta lección integra dous bloques A2 moi produtivos:

1. **Sentimentos** e estados de ánimo (os básicos xa os coñeces de A1; aquí amplías).
2. **Conectores discursivos** para argumentar e matizar: *gainera, hala ere, beraz, alde batetik...*

Con isto pechas a unidade e obtés ferramentas para opinións máis elaboradas.

## Sentimentos: a fórmula con *egon* + estado

A maioría de sentimentos pasaxeiros van con *egon* + adxectivo ou adverbio en estado:

| Galego | Éuscaro |
|---|---|
| Contento | *Pozik nago* |
| Triste | *Triste nago* |
| Enfado | *Haserre nago* |
| Nervioso | *Urduri nago* |
| Tranquilo | *Lasai nago* |
| Aborrecido | *Aspertuta nago* |
| Cansado | *Nekatuta nago* |
| Avergoñado | *Lotsatuta nago* |
| Namorado | *Maitemindurik nago* |

> É o mesmo padrón de A1 (*pozik, triste, lasai*) ampliado con *aspertuta, nekatuta, lotsatuta, maitemindurik*.

## Sentimentos con *izan*: *beldur naiz*

Algúns sentimentos profundos van con *izan*:

| Galego | Éuscaro |
|---|---|
| Teño medo | *Beldur naiz* |
| Tes razón | *Arrazoia duzu* |
| Teño curiosidade | *Jakin-mina dut* |
| Teño ganas | *Gogoa dut* / *Gogoz nago* |
| Non teño ganas | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — Teño medo de ir en coche.

## Sentimentos con *NOR-NORI*: *lotsa ematen dit*

Unha fórmula moi do éuscaro: o sentimento "dáche":

| Galego | Éuscaro |
|---|---|
| Dáme vergoña | *Lotsa ematen dit* |
| Dáme pena | *Pena ematen dit* |
| Dáme rabia | *Amorrua ematen dit* |
| Dáme medo | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — Dáme vergoña dicilo.
>
> *Albiste horrek **pena handia ematen dit**.* — Esa noticia dáme moita pena.

## *Jartzen naiz / jarri naiz*

Para expresar o **cambio de estado** ("poñerse nervioso, contento, triste"):

| Galego | Éuscaro |
|---|---|
| Póñome nervioso | *Urduri **jartzen naiz*** |
| Púxose triste | *Triste **jarri zen*** |
| Puxémonos contentos | *Pozik **jarri ginen*** |
| Enfádase por nada | *Edozergatik haserretzen da* |

## Verbos psicolóxicos frecuentes

| Verbo | Significado |
|---|---|
| *gustatu* | gustar |
| *maite izan* | querer / amar |
| *gorrotatu* / *higuindu* | odiar |
| *beldurtu* | asustarse |
| *aspertu* | aborrecerse |
| *haserretu* | enfadarse |
| *lasaitu* | calmarse |
| *poztu* | alegrarse |
| *triste jarri* / *atsekabetu* | entristecerse |
| *kezkatu* | preocuparse |

> *Asko **maite ditut** nire gurasoak.* — Quero moito os meus pais.
>
> *Ez **kezkatu**, dena ondo aterako da.* — Non te preocupes, todo sairá ben.

## Conectores discursivos

Para fiar opinións e argumentos:

### Adición

| Galego | Éuscaro |
|---|---|
| Ademais | *gainera* |
| E tamén | *eta baita ere* / *...ere* |
| Sobre todo | *batez ere* |

> *Gainera, prezioa ere ona da.* — Ademais, o prezo tamén é bo.

### Causa / consecuencia

| Galego | Éuscaro |
|---|---|
| Polo tanto | *beraz* |
| Por iso | *horregatik* |
| Por esa razón | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — É tarde; polo tanto, voume.

### Contraste / oposición

| Galego | Éuscaro |
|---|---|
| Con todo | *hala ere* |
| Pero | *baina* |
| Doutra banda | *bestetik* |
| En troques | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — É tarde; aínda así, virei.

### Organizar o discurso

| Galego | Éuscaro |
|---|---|
| Por unha banda… por outra | *Alde batetik... bestetik...* |
| Primeiro… logo… | *Lehenengo... gero...* |
| Por último | *Azkenik* |
| En resumo | *Laburbilduz* |

## Estruturas coordinadas A2

Estas son construcións que aparecen en calquera exame A2:

| Galego | Éuscaro |
|---|---|
| Nin... nin... | *Ez... ez...* |
| Tanto... como... | *Bai... bai...* / *Hala... nola...* |
| Non só..., senón tamén | *Ez bakarrik..., baita ere...* |
| ...tamén (incluído) | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — Nin Anboto nin Olatz viñeron.
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — Tanto pola mañá como pola tarde teño que traballar.

## Minitexto de opinión

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## Truco para A2: o "esqueleto de opinión"

Cando che pidan opinar en A2, segue este modelo:

> **1. Nire ustez** + tema + **-(e)la**.
>
> **2. Alde batetik**, + razón1 + **-lako**.
>
> **3. Bestetik**, + razón2.
>
> **4. Hala ere**, + matización.
>
> **5. Beraz**, + conclusión.

Con iso constrúes un parágrafo completo de A2.

> **Nota cultural:** moitos textos A2 oficiais (carta ao director, foro, redacción de exame) piden esta estrutura argumentativa. Practícaa con temas cotiáns: o deporte, a comida, as redes sociais, o traballo, as festas da vila.
