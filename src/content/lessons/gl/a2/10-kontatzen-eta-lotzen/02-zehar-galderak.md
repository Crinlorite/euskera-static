Ata hoxe preguntabas de fronte: *Etorriko da?* Agora aprenderás a preguntar **de lado**: *non sei **se virá***, *pregúntalle **se ten tempo***. Son as *zehar-galderak* (preguntas indirectas), e o seu truco é unha soa letra: **-n**.

## A regra: o auxiliar leva -n

| Directa | Indirecta |
|---|---|
| *Etorriko **da**?* | *Ez dakit etorriko **den*** |
| *Nor **da**?* | *Ez dakit nor **den*** |
| *Non **dago**?* | *Ez dakit non **dagoen*** |
| *Zer nahi **du**?* | *Ez dakit zer nahi **duen*** |
| *Denborarik **dauka**?* | *Galdetu ea denborarik **daukan*** |

Como se pega o **-n**: *da → den* · *dago → dagoen* · *du → duen* · *dauka → daukan* · *gara → garen* · *dute → duten*. (Se acaba en vogal, -n; o resto, -en. O teu oído farao só en dous días.)

## "Ea" — a palabra comodín

Para as preguntas de si/non, o éuscaro engade ***ea*** (= "a ver se / se"):

> *Galdetu diot **ea gurekin bazkalduko duen**.* — Pregunteille se comerá connosco.
>
> *Ikusiko dugu **ea eguraldi ona egiten duen**.* — Veremos a ver se fai bo tempo.
>
> ***Ea garaiz iristen garen**!* — A ver se chegamos a tempo!

Ese último *ea…!* solto é éuscaro falado puro: desexo + suspense nunha palabra.

## Os verbos que as piden

| Galego | Euskera |
|---|---|
| Non sei se… | *Ez dakit … -(e)n* |
| Sabes se…? | *Badakizu … -(e)n?* |
| Pregúntalle se… | *Galdetu (iezaiozu) ea … -(e)n* |
| Non recordo se… | *Ez naiz gogoratzen … -(e)n* |
| Non estou seguro de se… | *Ez nago ziur … -(e)n* |

## En acción

> *— **Badakizu zer ordutan hasten den** kontzertua?*
>
> *— Ez, baina Aneri **galdetuko diot ea dakien**.*
>
> *— Eta **ea sarrerarik geratzen den** ere galdetu, mesedez!*
>
> *— Lasai. **Ea zorte ona dugun**!*

## O contraste con -la (o falso amigo)

Non confundas a pregunta indirecta coa afirmación indirecta (unidade 04):

> *Esan dit etorriko **dela**.* — Díxome **que** virá. (afirmación → **-la**)
>
> *Galdetu dit **ea** etorriko **den**.* — Preguntoume **se** virei. (pregunta → **-n**)

**Que = -la · Se = (ea) -n.** Con esa chuleta, esta lección está gañada.
