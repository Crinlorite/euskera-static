Gdy już umiesz powiedzieć "jest w X", kolejnym krokiem jest powiedzenie, **gdzie dokładnie**: na, pod, obok, za… W języku baskijskim te określenia miejsca tworzy się zawsze według wzoru **punkt odniesienia + położenie**.

## Podstawowe określenia miejsca

| Euskera | Polski |
|---|---|
| *aurrean* | przed |
| *atzean* | za |
| *ondoan* | obok |
| *gainean* | na, nad |
| *azpian* | pod |
| *artean* | pomiędzy |
| *ezkerrean* | na lewo |
| *eskuinean* | na prawo |
| *barruan* | w środku |
| *kanpoan* | na zewnątrz |
| *erdian* | pośrodku, w centrum |

## Jak je tworzyć: -(r)en + położenie

Podstawowy wzór to **(punkt odniesienia)-(r)en + położenie**. Punkt odniesienia przyjmuje dopełniacz (genitivus) `-(r)en` (co odpowiada polskiemu dopełniaczowi, np. "stołu", "domu"):

| Euskera | Polski (dosłownie) |
|---|---|
| **mahaiaren gainean** | na stole (dosł. "stołu, na") |
| **etxearen aurrean** | przed domem |
| **elizaren atzean** | za kościołem |
| **parkearen ondoan** | obok parku |
| **kutxaren barruan** | w środku pudełka |
| **bi mendien artean** | pomiędzy dwiema górami |

Schemat: najpierw punkt odniesienia, **potem** położenie. To dokładnie odwrotnie niż w języku polskim.

## Pełne przykłady

- **Liburua mahaiaren gainean dago.** — Książka jest na stole.
- **Katua aulkiaren azpian dago.** — Kot jest pod krzesłem.
- **Eliza plazaren erdian dago.** — Kościół jest na środku placu.
- **Botika eskolaren ondoan dago.** — Apteka jest obok szkoły.
- **Ni Maiteren eta Anaren artean nago.** — Jestem między Maite a Aną.

## Przysłówki miejsca: hemen / hor / han

Do szybkiego wskazywania służą trzy przysłówki — i uwaga, określają one **trzy odległości**, a nie dwie, jak w języku polskim:

| Euskera | Polski | Kiedy |
|---|---|---|
| *hemen* | tutaj | blisko mówiącego |
| *hor* | tam (blisko ciebie) | blisko słuchacza |
| *han* | tam (daleko) | daleko od obojga |

> Te trzy przysłówki odpowiadają zaimkom wskazującym *hau / hori / hura* oraz ich dłuższym formom miejscownika *honetan / horretan / hartan* ("w tym / w tym / w tamtym").

Szybkie przykłady:

- **Hemen** taberna bat dago. — Tutaj jest bar.
- **Hor** parkea dago. — Tam jest park.
- **Han** dago euskaltegia. — Tam jest euskaltegi.

## Minidialog: zabawa w chowanego

> — *Pilota mahaiaren azpian dago?* — Czy piłka jest pod stołem?
>
> — *Ez, pilota ez dago mahaiaren azpian.* — Nie, piłka nie jest pod stołem.
>
> — *Aulkiaren atzean dago?* — Czy jest za krzesłem?
>
> — *Bai, hor dago!* — Tak, tam jest!

> **Wskazówka:** wszystkie określenia miejsca mają już wbudowany sufiks `-an` (*aurr-ean*, *atz-ean*, *azp-ian*…). Nie musisz nic więcej dodawać.
