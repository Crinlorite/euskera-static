Od papieru do piksela: lekcja o **codziennej technologii**. Słownictwo, którego używasz sto razy dziennie — teraz po baskijsku, który dodatkowo szczyci się przejrzystymi i dobrze skonstruowanymi słowami (*pasahitza* = słowo-przepustka; *sakelakoa* = „kieszonkowy”).

## Urządzenia

| Polski | Euskera |
|---|---|
| Komputer | *ordenagailua* |
| Laptop | *eramangarria* |
| Telefon komórkowy / komórka | *mugikorra / sakelakoa* |
| Tablet | *tableta* |
| Ekran | *pantaila* |
| Klawiatura | *teklatua* |
| Myszka | *sagua* (tak, jak zwierzę!) |
| Słuchawki | *entzungailuak* |

## Sieć i konta

| Polski | Euskera |
|---|---|
| Sieć / internet | *sarea / internet* |
| Wi-Fi | *wifia* |
| E-mail / poczta elektroniczna | *posta elektronikoa* |
| Użytkownik | *erabiltzailea* |
| Hasło | *pasahitza* |
| Aplikacja | *aplikazioa* |
| Strona internetowa | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Jakie jest hasło do Wi-Fi?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — Zapomniałem/am hasła i teraz muszę utworzyć nowe. Znowu.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Aby utworzyć konto, potrzebujesz adresu e-mail i hasła.

## Cyfrowe czasowniki

| Polski | Euskera |
|---|---|
| Włączać / wyłączać | *piztu / itzali* |
| Pobierać / ściągać | *deskargatu / jaitsi* |
| Instalować | *instalatu* |
| Zapisywać | *gorde* |
| Usuwać / kasować | *ezabatu* |
| Wysyłać / udostępniać | *bidali / partekatu* |
| Szukać (w sieci) | *bilatu* |
| Działać / funkcjonować | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — Komputer źle działa; wyłącz go i włącz — rozwiązanie wszech czasów.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Zapisałeś/aś zdjęcia? Nic nie usuwaj!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Pobierasz aplikację, tworzysz konto i gotowe.

## Dialog: rodzinne wsparcie techniczne

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Uwaga:** cyfrowy język baskijski jest bardzo żywy: wolne oprogramowanie i Wikipedia w języku baskijskim są bardzo rozwinięte, a cały Twój telefon może być po baskijsku (*Ezarpenak → Hizkuntza*). Ustawienie go to w rzeczywistości genialny trik do nauki: codzienna, darmowa immersja.
