**Tryb rozkazujący** (*agintera*) służy do wydawania poleceń, próśb i udzielania rad. W języku baskijskim jest **znacznie prostszy, niż się wydaje**: najczęściej używana forma jest prawie zawsze taka sama jak **imiesłów bierny** (participio) czasownika.

## Podstawowa zasada: użyj imiesłowu (participio)

W przypadku wielu codziennych poleceń czasownik występuje w formie imiesłowu (participio) bez czasownika posiłkowego:

| Polski | Baskijski |
|---|---|
| Weź | *Hartu* |
| Usiądź | *Eseri* |
| Wstań | *Jaiki* |
| Napisz | *Idatzi* |
| Przeczytaj | *Irakurri* |
| Słuchaj | *Entzun* |
| Powtórz | *Errepikatu* |
| Poczekaj | *Itxoin* |
| Zamknij drzwi | *Itxi atea* |
| Otwórz okno | *Ireki leihoa* |

> To jest **najczęściej używana forma** w klasie, na ulicy i w pisemnych instrukcjach. Służy zarówno dla *zu* (ty), jak i *zuek* (wy).

## Formy syntetyczne (trinkoak): *zatoz*, *zoaz*

Niektóre bardzo częste czasowniki mają specyficzne formy syntetyczne dla trybu rozkazującego. Warto je zapamiętać:

| Czasownik | Ty (zu) | Wy (zuek) |
|---|---|---|
| *etorri* (przychodzić) | **Zatoz** | **Zatozte** |
| *joan* (iść) | **Zoaz** | **Zoazte** |
| *ekarri* (przynosić) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (zanosić/brać ze sobą) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (być) | **Egon** / **Lasai** (spokojnie!) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## Tryb rozkazujący NOR-NORI-NORK: *emadazu*, *esadazu*

Gdy wydajesz polecenie z podwójnym dopełnieniem („daj mi to”, „powiedz mu tamto”), język baskijski ma bardzo użyteczne formy skondensowane:

| Polski | Baskijski |
|---|---|
| Daj mi | *Emadazu* / *Eman iezadazu* |
| Powiedz mi | *Esadazu* / *Esan iezadazu* |
| Daj mu/jej | *Emaiozu* / *Eman iezaiozu* |
| Powiedz mu/jej | *Esaiozu* / *Esan iezaiozu* |
| Daj nam | *Emaguzu* |
| Dajcie mi | *Emadazue* |

Te formy są trudne do nauczenia; na poziomie A2 wystarczy znać **emadazu / esadazu / emaiozu / esaiozu** i rozumieć, że pochodzą od czasowników *eman* / *esan*.

## „Proszę” i zwroty łagodzące

Tryb rozkazujący w języku baskijskim **nie brzmi szorstko**, jeśli dodasz zwrot grzecznościowy:

- *Mesedez* — proszę
- *Ahal baduzu* — jeśli możesz
- *Faborez* (wariant potoczny)
- *Eskerrik asko aldez aurretik* — dziękuję z góry

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## Instrukcje (przepisy, ogłoszenia, sala lekcyjna)

Tryb rozkazujący to standardowa forma w:

- **Przepisy:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **Znaki/plakaty:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **Sala lekcyjna:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **U lekarza:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## Minitekst

> *W szkole gotowania nauczyciel mówi:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **Wskazówka kulturowa:** w języku baskijskim **rozkazujący** ton trybu rozkazującego jest łagodzony przez intonację i kontekst, a nie tak często przez omówienia („czy mógłbyś...”). Zazwyczaj wystarczy dodać do polecenia *mesedez* lub uśmiech. Jeśli chcesz być bardziej uprzejmy, powiedz *eman ahal didazu...?* (czy możesz mi dać...?).
