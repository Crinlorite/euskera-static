Una buona parte della vita sociale in Euskal Herria passa per la **taberna** (il bar). Conoscere le bevande e i cibi di base in basco ti aprirà porte immediate: una comitiva di amici, una visita a un paese nuovo, un *poteo*. Iniziamo dal vocabolario.

## Il caffè e le sue varianti

Il caffè è probabilmente ciò che ordinerai più spesso. Esiste in diverse forme:

| Basco | Italiano |
|---|---|
| *kafea* | il caffè (generico) |
| *kafe hutsa* | caffè liscio (letteralmente: "caffè puro/vuoto") |
| *kafesnea* | caffellatte (da *kafe* + *esne*) |
| *kafe ebakia* | caffè macchiato (*ebaki* = "tagliato") |
| *kafe deskafeinatua* | caffè decaffeinato |
| *infusioa* | infuso |
| *tea* | tè |

> *Kafesne* significa letteralmente "caffè-latte". Il basco forma molte parole composte in questo modo, senza trattino e con la parola principale alla fine.

## Altre bevande

| Basco | Italiano |
|---|---|
| *ura* | l'acqua |
| *zumoa* | succo |
| *esnea* | il latte |
| *ardoa* | vino |
| *ardo gorria* | vino rosso |
| *ardo zuria* | vino bianco |
| *garagardoa* | birra |
| *zuritoa* | birra piccola (alla spina, tipica) |
| *sagardoa* | sidro |
| *txakolina* | txakoli (vino bianco basco) |
| *patxarana* | patxaran |

> Tre parole curiose: **sagardo** (sidro) = *sagar* (mela) + *ardo* (vino); **garagardo** (birra) = *garagar* (orzo) + *ardo*; **txakolina** è un vino bianco giovane e leggero, un marchio di fabbrica nei Paesi Baschi.

## Cibi di base al bar

Per accompagnare ciò che bevi:

| Basco | Italiano |
|---|---|
| *ogia* | il pane |
| *gazta* | formaggio |
| *urdaiazpikoa* | prosciutto |
| *tortilla* | tortilla (di patate) |
| *patata frijituak* | patatine fritte |
| *gozokia* | dolce (generico) |
| *txokolatea* | cioccolato |

## L'articolo `-a`

Quasi tutte queste parole hanno **`-a`** alla fine quando appaiono in forma "neutra" in una frase: è l'articolo determinativo ("il / lo / la").

- *Ardoa gustatzen zait.* — Mi piace il vino.
- *Ura nahi dut.* — Voglio dell'acqua.

Quando chiedi "uno", la `-a` scompare ed entra **bat** ("uno/una"):

- *Kafe **bat**, mesedez.* — Un caffè, per favore.
- *Garagardo **bat**.* — Una birra.

> Nella lezione 3 vedrai questo argomento in dettaglio. Per ora, memorizza le forme con `-a` per riconoscerle sul menù del bar.
