L'**imperativo** (*agintera*) serve per dare istruzioni, fare richieste e dare consigli. In basco è **molto più semplice di quanto sembri**: la forma più usata coincide quasi sempre con il **participio** del verbo.

## La regola di base: usa il participio

Per molti ordini quotidiani, il verbo appare nella sua forma di participio senza ausiliare:

| Italiano | Euskera |
|---|---|
| Prendi | *Hartu* |
| Siediti | *Eseri* |
| Alzati | *Jaiki* |
| Scrivi | *Idatzi* |
| Leggi | *Irakurri* |
| Ascolta | *Entzun* |
| Ripeti | *Errepikatu* |
| Aspetta | *Itxoin* |
| Chiudi la porta | *Itxi atea* |
| Apri la finestra | *Ireki leihoa* |

> Questa è la **forma più usata** in classe, per strada e nelle istruzioni scritte. Serve sia per *zu* che per *zuek*.

## Forme sintetiche (trinkoak): *zatoz*, *zoaz*

Alcuni verbi molto frequenti hanno forme sintetiche specifiche per l'imperativo. Queste sono quelle che conviene memorizzare:

| Verbo | Tu (zu) | Voi (zuek) |
|---|---|---|
| *etorri* (venire) | **Zatoz** | **Zatozte** |
| *joan* (andare) | **Zoaz** | **Zoazte** |
| *ekarri* (portare qui) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (portare via) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (stare) | **Egon** / **Lasai** (stai calmo!) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## Imperativo NOR-NORI-NORK: *emadazu*, *esadazu*

Quando dai un ordine con un doppio oggetto ("dammi questo", "digli quello"), il basco ha forme compatte molto utili:

| Italiano | Euskera |
|---|---|
| Dammi | *Emadazu* / *Eman iezadazu* |
| Dimmi | *Esadazu* / *Esan iezadazu* |
| Dagli / Dalle | *Emaiozu* / *Eman iezaiozu* |
| Digli / Dille | *Esaiozu* / *Esan iezaiozu* |
| Dacci | *Emaguzu* |
| Datemi | *Emadazue* |

Queste forme sono lunghe da imparare; al livello A2 è sufficiente conoscere **emadazu / esadazu / emaiozu / esaiozu** e capire che derivano dai verbi *eman* / *esan*.

## "Per favore" e modi per attenuare

L'imperativo in basco **non suona brusco** se aggiungi qualche parola di cortesia:

- *Mesedez* — per favore
- *Ahal baduzu* — se puoi
- *Faborez* (variante colloquiale)
- *Eskerrik asko aldez aurretik* — grazie in anticipo

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## Istruzioni (ricette, annunci, in classe)

L'imperativo è la forma standard in:

- **Ricette:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **Cartelli:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **In classe:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **Dal medico:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## Mini-testo

> *Sukaldari eskolan, irakasleak esaten du:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **Nota culturale:** in basco il tono **imperioso** dell'imperativo si attenua con l'intonazione e il contesto, non così spesso con parafrasi ("potresti..."). Accompagnare l'ordine con *mesedez* o con un sorriso è di solito sufficiente. Se vuoi essere più cortese, dì *eman ahal didazu...?* (puoi darmi...?).
