Parlare di **stile di vita** e **ambiente** è un blocco classico del livello A2: si mescola nuovo vocabolario con frasi di obbligo e consiglio (*behar dugu*, *komeni da*, *garrantzitsua da*) che già conosci dal livello A1.

## Abitudini sane

| Italiano | Euskera |
|---|---|
| Fare sport | *kirola egin* |
| Camminare / passeggiare | *paseatu* / *ibili* |
| Correre | *korrika egin* |
| Andare in bici | *bizikletaz ibili* |
| Mangiare frutta e verdura | *fruta eta barazkiak jan* |
| Bere acqua | *ura edan* |
| Dormire bene | *ondo lo egin* |
| Fumare | *erre* |
| Bere alcolici | *alkohola edan* |
| Non abusare del sale | *gatzaz ez abusatu* |

> Frasi tipiche:
>
> - *Kirola egiten dut astean hiru aldiz.* — Faccio sport tre volte a settimana.
> - *Erretzeari utzi diot.* — Ho smesso di fumare.
> - *Ez dut alkoholik edaten astegunetan.* — Non bevo alcolici durante la settimana.

## Frequenza: *X aldiz*

Per dire "X volte" si usa la formula **numero + aldiz**:

| Italiano | Euskera |
|---|---|
| Una volta al giorno | *Egunean behin* |
| Due volte a settimana | *Astean bi aldiz* / *birritan* |
| Tre volte al mese | *Hilean hiru aldiz* |
| Spesso | *Askotan* |
| A volte | *Batzuetan* |
| Poche volte | *Gutxitan* |
| Mai | *Inoiz ez* |

## Frasi utili per dare un'opinione

- *Garrantzitsua da birziklatzea.* — È importante riciclare.
- *Komeni da kirola egitea.* — È consigliabile fare sport.
- *Beharrezkoa da kutsadura gutxitzea.* — È necessario ridurre l'inquinamento.
- *Ez dut uste plastikoa ona denik.* — Non credo che la plastica sia un bene.

> Queste strutture (*-tzea + aggettivo + da*) sono la formula del livello A2 per dire "è importante / è consigliabile / è necessario fare X". Le approfondiremo nell'unità 4.

## Vita di quartiere

| Italiano | Euskera |
|---|---|
| Quartiere | *auzoa* |
| Vicino/a | *bizilaguna* |
| Associazione | *elkartea* |
| Volontariato | *boluntariotza* |
| Feste di quartiere | *auzoko jaiak* |
| Partecipare | *parte hartu* |
| Riunione | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## Mini-testo modello

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **Nota culturale:** le *auzo-elkarteak* (associazioni di quartiere) sono un elemento fondamentale della vita sociale in molti paesi di Euskal Herria. Organizzano feste, laboratori di basco, escursioni in montagna e campagne ambientaliste. Partecipare è uno dei modi migliori per praticare la lingua in un contesto reale.
