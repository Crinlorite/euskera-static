За да разкажеш добре какво се е случило, трябва да кажеш **кога**. Този урок ти дава думите за време, които се съчетават с близкото минало, за да поставят действията във времето.

## Основните думи за време

| Euskera | Български |
|---|---|
| *gaur* | днес |
| *atzo* | вчера |
| *bihar* | утре |
| *etzi* | вдругиден |
| *orain* | сега |
| *oraintxe* | точно сега |
| *lehen* | преди, по-рано |
| *gero* | после, по-късно |

> Ако си забелязал, *atzo* (вчера) и *bihar* (утре) са толкова кратки думи, че се научават наведнъж. *Etzi* (вдругиден) е една много кратка дума — малък подарък от баския.

## Съчетание с частите на деня

Думите за време се съчетават с *goizean*, *arratsaldean*, *gauean* и другите от предишния раздел. Формулата е: **дума за време + част от деня**.

| Euskera | Български |
|---|---|
| *gaur goizean* | тази сутрин / днес сутринта |
| *gaur eguerdian* | днес по обяд |
| *gaur arratsaldean* | днес следобед |
| *gaur gauean* | довечера / тази нощ |
| *atzo goizean* | вчера сутринта |
| *atzo arratsaldean* | вчера следобед |
| *atzo gauean* | снощи |
| *bihar goizean* | утре сутринта |

> **Внимание:** *gaur gauean* е "довечера / тази нощ" (нощта, която предстои или която преживяваш); *atzo gauean* е "снощи". Баският ги разграничава много ясно.

## Честота и пъти

| Euskera | Български |
|---|---|
| *behin* | веднъж |
| *bi aldiz* | два пъти |
| *hiru aldiz* | три пъти |
| *askotan* | често, много пъти |
| *batzuetan* | понякога |
| *inoiz ez* | никога |
| *gaur goizetik* | от тази сутрин |
| *aste honetan* | тази седмица |
| *hilabete honetan* | този месец |

## Изречения с близко минало и думи за време

> *Gaur goizean lanera joan naiz autoz.* — Тази сутрин отидох на работа с кола.
>
> *Gaur arratsaldean Mikelekin egon naiz.* — Днес следобед бях с Микел.
>
> *Gaur oso berandu esnatu naiz.* — Днес се събудих много късно.
>
> *Gaur eguerdian etxean bazkaldu dut.* — Днес по обяд обядвах вкъщи.
>
> *Aste honetan bi aldiz egon naiz zinean.* — Тази седмица бях два пъти на кино.

## Словоредът в изречението

На баски типичният ред на изречение с дума за време е:

> **КОГА + КЪДЕ + КАКВО + ГЛАГОЛ**

> **Gaur goizean** + **euskaltegian** + **euskara** + **ikasi dut**. — Тази сутрин учих баски в euskaltegi.

Това не е единствената възможност — баският позволява елементите да се разместват за подчертаване — но ако следваш този ред, няма да сгрешиш.

## Мини разговор

> *— Eta gaur zer egin duzu, Maialen?*
>
> *— **Gaur goizean** lanera joan naiz oinez. **Eguerdian** lagunekin bazkaldu dut tabernan. **Arratsaldean** etxera bueltatu naiz eta liburua irakurri dut. **Gauean** ez dut afaldu, asko jan baitut bazkarian.*

> **Бележка:** *gaur* обхваща целия днешен ден. Ако искаш да уточниш, добави момента (*gaur goizean*, *gaur arratsaldean*). В обикновените разговори *Zer egin duzu gaur?* се разбира като "какво прави днес като цяло?".
