В този урок ще научиш основните глаголи, за да говориш за **etxeko lanak** (домакинската работа). На баски глаголите обикновено се дават във формата на **причастие** (`-tu`, `-i`, `-n`), която е "речниковата" форма: *garbitu*, *prestatu*, *jaso*…

## Ключови глаголи

| Euskera | Български |
|---|---|
| *garbitu* | чистя |
| *prestatu* | приготвям |
| *jaso* | прибирам, вдигам |
| *jantzi* | обличам / слагам |
| *atera* | изнасям, изваждам |
| *zabaldu* | простирам / отварям |
| *lisatu* | гладя |
| *paseatu* | разхождам |
| *erosi* | купувам |

## Типични задачи

| Задача | Как се казва |
|---|---|
| Оправям леглото | *ohea jantzi* |
| Мия чиниите | *ontziak garbitu* / *harrikoa egin* |
| Минавам с прахосмукачката | *xurgagailua pasa* |
| Простирам прането | *arropa zabaldu* |
| Гладя дрехите | *arropa lisatu* |
| Чистя банята | *komuna garbitu* |
| Изнасям боклука | *zaborra atera* |
| Приготвям обяда | *bazkaria prestatu* |
| Пазарувам | *erosketak egin* |
| Разхождам кучето | *txakurra paseatu* |

## От речниковата форма към обичайното сегашно време

Когато едно действие се повтаря редовно (всеки ден, всяка седмица…), глаголът преминава във формата с `-tzen` + спомагателния глагол **dut/duzu/du…** (който вече познаваш от *ukan*):

| Лице | Пример | Български |
|---|---|---|
| Nik | *Nik etxea **garbitzen dut**.* | Аз чистя къщата. |
| Zuk | *Zuk arropa **lisatzen duzu**.* | Ти гладиш дрехите. |
| Berak | *Aitak bazkaria **prestatzen du**.* | Баща ми приготвя обяда. |
| Guk | *Guk erosketak **egiten ditugu**.* | Ние пазаруваме. |

> В този урок не е нужно да владееш спрежението. Запомни модела **`-tzen` + dut/du**, за да говориш за ежедневието си.

## Честота

За да кажеш колко често вършиш нещо:

- **egunero** — всеки ден
- **astean behin** — веднъж седмично
- **astean bitan / hirutan** — два / три пъти седмично
- **noizean behin** — от време на време
- **inoiz ez** — никога

> *Nire etxean nik **astean behin** lisatzen dut, baina **egunero** garbitzen dut sukaldea.* — Вкъщи гладя веднъж седмично, но кухнята я чистя всеки ден.

## Как да попиташ кой какво прави

- **Nork garbitzen ditu ontziak?** — Кой мие чиниите?
- **Nor arduratzen da arropaz?** — Кой се грижи за дрехите?
- **Zuri gustatzen zaizu sukaldatzea?** — Обичаш ли да готвиш?

> **Културна бележка:** анкетите за разпределението на домакинската работа са класика в учебниците на euskaltegi — и не без причина. Това е много полезен речник за истински разговори с приятели и семейство.
