Този урок обединява всичко от тема 9: стаите, мебелите, домакинската работа и с кого живееш. Целта е да можеш да **опишеш дома си** с прости изречения, все едно те питат в клас или в неформален разговор.

## Основните въпроси

| Въпрос | Български |
|---|---|
| *Non dago zure etxea?* | Къде е жилището ти? |
| *Nolakoa da?* | Какво е? |
| *Zenbat gela ditu?* | Колко стаи има? |
| *Norekin bizi zara?* | С кого живееш? |
| *Zenbatgarren solairuan bizi zara?* | На кой етаж живееш? |
| *Etxeak badu igogailua / balkoia / terraza?* | Има ли жилището асансьор / балкон / тераса? |

## Полезни прилагателни за описание на дома

| Euskera | Български |
|---|---|
| *handia* | голямо |
| *txikia* | малко |
| *argitsua* | светло |
| *iluna* | тъмно |
| *berria* | ново |
| *zaharra* | старо |
| *lasaia* | тихо, спокойно |
| *zaratatsua* | шумно |
| *erosoa* | удобно |
| *garestia* | скъпо |
| *merkea* | евтино |

> Припомни си модела **NOLAKOA da?** от други раздели: отговорът съдържа прилагателното + крайно `-a` + глагола *izan*. Напр.: *Nire etxea **handia da**.* — Жилището ми е голямо.

## Примерен абзац

Ето един прост текст, който описва жилище. Прочети го на глас и обърни внимание на моделите.

> *Ni Iruñean bizi naiz, auzo lasai batean. Nire etxea ez da oso handia: hiru gela ditu — bi logela eta egongela bat — sukaldea eta komuna. Egongela argitsua da, eta balkoi bat dauka. Hirugarren solairuan dago, eta etxeak igogailua du.*
>
> *Bikotekidearekin bizi naiz. Berak bazkaria prestatzen du, eta nik ontziak garbitzen ditut. Asteburuetan biok elkarrekin egiten dugu erosketa.*

## Твой ред е: опиши дома си

Състави собствен абзац, като отговаряш в този ред:

1. **Non bizi zara?** (Къде живееш?) → *X-(e)an bizi naiz.*
2. **Nolakoa da etxea?** (Какво е жилището?) → *Nire etxea handia / argitsua / lasaia da.*
3. **Zenbat gela ditu?** (Колко стаи?) → *Bi / Hiru / Lau gela ditu.*
4. **Zer dago etxean?** (Какво има?) → *Sukaldea, egongela, bi logela eta komun bat ditu.*
5. **Norekin bizi zara?** → *Bakarrik / Gurasoekin / Lagunekin bizi naiz.*
6. **Etxeko lanak nork egiten ditu?** → *Nik egunero garbitzen dut* / *Pisukideen artean banatzen ditugu.*

## Заключителен речник

| Euskera | Български |
|---|---|
| *etxebizitza* | жилище |
| *etxejabea* | собственик |
| *alokairua* | наем |
| *errenta* | месечен наем |
| *auzoa* | квартал |
| *erdigunea* | центърът (на града) |
| *aldiriak* | покрайнини |

> **Съвет:** когато говориш за дома си в клас, не се опитвай да превеждаш всяка подробност. Придържай се към кратки и добре построени изречения. *"Bi logela ditut, sukalde txiki bat eta egongela handia"* е по-добро описание от едно дълго изречение, пълно с грешки.
