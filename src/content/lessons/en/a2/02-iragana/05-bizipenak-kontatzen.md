This is an **integrative** lesson: it combines the perfect past, imperfect, and progressive aspect so you can learn to **narrate an experience** with the tense choreography used in Basque.

What you already have:

- *Iragan burutua* (lessons 1 and 2): specific event.
- *Iragan ez burutua* (lesson 4): habit or description.
- Synthetic verbs in the past (lesson 3): describe ongoing scenes.
- Past time markers (atzo, joan den astean, duela...).

Now you'll learn to **link them together**.

## The Narrative Choreography

A typical past narrative mixes tenses depending on their function:

| Function | Tense | Example |
|---|---|---|
| Temporal and spatial setting | imperfect | *Garai hartan Bilbon **bizi ginen*** |
| What it was like / how it was | imperfect | *Iluna **zen** kalea* |
| What happened (specific event) | burutua | *Bat-batean atea **jo zuten*** |
| Ongoing action | ari nintzen / synthetic | *Afaria **prestatzen ari nintzen*** |
| Result | burutua | *Eta gauza guztiak **gertatu ziren*** |

## Temporal Connectors

To link what happened:

| English | Basque |
|---|---|
| First / at the beginning | *Lehenengo* / *Hasieran* |
| Next | *Ondoren* |
| Then | *Gero* |
| Afterwards | *Geroago* |
| Later | *Beranduago* |
| Meanwhile | *Bitartean* |
| Suddenly | *Bat-batean* |
| Then | *Orduan* |
| Finally / in the end | *Azkenean* |

## Key Biographical Phrases

These structures appear in any biography or personal story:

| English | Basque |
|---|---|
| I was born in 1990 | *1990ean **jaio nintzen*** |
| I grew up in Tolosa | *Tolosan **hazi nintzen*** |
| I studied Basque | *Euskara **ikasi nuen*** |
| I started working at age 22 | *22 urterekin lanean **hasi nintzen*** |
| I met Anboto | *Anboto **ezagutu nuen*** |
| I fell in love | *Maitemindu **nintzen*** |
| We got married in 2015 | *2015ean **ezkondu ginen*** |
| We had a daughter | *Alaba bat **izan genuen*** |
| I changed jobs | *Lana **aldatu nuen*** |
| We returned to Bilbao | *Bilbora **itzuli ginen*** |

## Model Text: A Short Biography

> *Garazi 1992an Iruñean **jaio zen**. Txikitan auzo lasai batean **bizi zen**, eta bere familia oso handia **zen**: lau anai-arreba **zituen** eta amona ondoan **zegoen**. Eskolan euskaraz **ikasten zuen**, eta hamabost urterekin musika tresnak **ikasten hasi zen**.*
>
> *Hemezortzi urterekin Donostiara **joan zen** unibertsitatera. Han Lander **ezagutu zuen**, kafetegi batean **lan egiten** **zuen** **bitartean**. **Maitemindu ziren** azkar, eta urtebete geroago **bizitzen hasi ziren** elkarrekin.*
>
> *Duela bost urte, **erabaki zuten** Bilbora itzultzea. Han etxe txiki bat **erosi zuten**, eta orain bertan **bizi dira** alaba batekin.*

Notice the choreography:

- *jaio zen, joan zen, ezagutu zuen, maitemindu ziren, hasi ziren, erabaki zuten, erosi zuten* → **burutua** (specific actions).
- *bizi zen, zituen, zegoen, ikasten zuen, lan egiten zuen* → **ez burutua** (scene, background, habit).

## How to Build Your Own Story

A practical recipe for A2:

1. **Temporal setting**: start with a marker (*Duela X urte... / X-ean...*).
2. **Scene**: describe what everything was like in the imperfect (*bizi nintzen, lan egiten nuen, urruti nengoen...*).
3. **Key events**: link the story's key points using the *burutua* (*ezagutu nuen, joan ginen, hasi nintzen...*).
4. **Connectors**: sprinkle in *lehenengo, gero, ondoren, bitartean, azkenean* to make it flow.
5. **Closing**: end in the present tense to connect to the now (*eta orain... bizi naiz / ari naiz / nago*).

## Questions to Interview Someone

| English | Basque |
|---|---|
| Where were you born? | *Non jaio zinen?* |
| When did you start working? | *Noiz hasi zinen lanean?* |
| What did you do as a child? | *Zer egiten zenuen txikitan?* |
| Who did you meet first, Lander or Anboto? | *Lehenengo nor ezagutu zenuen, Lander ala Anboto?* |
| What was your town like? | *Nolakoa zen zure herria?* |
| Why did you move? | *Zergatik aldatu zinen etxez?* |

> **A2 Challenge:** write your own mini-biography in five sentences mixing *burutua* and *ez burutua*. Start with *jaio nintzen*, continue with the scene of your childhood (*bizi ginen, etxean...*), link three key events, and close in the present tense.

> **Cultural Note:** biographies and *bizipen-kontaketak* are a very common genre in adult Basque learning. Almost all A2 textbooks include interviews with elderly people, writers, and athletes. It's the best way to consolidate the past tense and, in the process, discover cultural figures like Bernardo Atxaga, Itziar Ituño, or Mikel Erentxun.
