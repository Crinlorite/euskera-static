From paper to pixel: the lesson on **everyday technology**. Vocabulary you use a hundred times a day — now in Basque, which also boasts transparent and well-constructed words (*pasahitza* = pass word; *sakelakoa* = "the one for the pocket").

## The devices

| English | Basque |
|---|---|
| The computer | *ordenagailua* |
| The laptop | *eramangarria* |
| The mobile phone | *mugikorra / sakelakoa* |
| The tablet | *tableta* |
| The screen | *pantaila* |
| The keyboard | *teklatua* |
| The mouse | *sagua* (yes, the animal!) |
| The headphones | *entzungailuak* |

## The web and accounts

| English | Basque |
|---|---|
| The network / internet | *sarea / internet* |
| The Wi-Fi | *wifia* |
| The email | *posta elektronikoa* |
| The user | *erabiltzailea* |
| The password | *pasahitza* |
| The app | *aplikazioa* |
| The website | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — What's the Wi-Fi password?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — I've forgotten the password and now I have to create a new one. Again.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — To create an account, you need an email and a password.

## Digital verbs

| English | Basque |
|---|---|
| To turn on / to turn off | *piztu / itzali* |
| To download | *deskargatu / jaitsi* |
| To install | *instalatu* |
| To save | *gorde* |
| To delete | *ezabatu* |
| To send / to share | *bidali / partekatu* |
| To search (on the web) | *bilatu* |
| To work / to function | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — The computer is not working well; turn it off and on — the classic solution.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Have you saved the photos? Don't delete anything!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — You download the app, create the account, and you're all set.

## Dialogue: family tech support

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Note:** digital Basque is very much alive: free software and the Basque Wikipedia are powerful, and your entire phone can be set to Basque (*Ezarpenak → Hizkuntza*). Setting it is, in fact, a fantastic study hack: free daily immersion.
