You already knew how to shop from A1. This lesson is **level 2 of shopping**: trying on clothes, fighting with sizes, and — the final boss — **exchanging or returning** items without breaking a sweat. With two old friends at work: the *-egi* suffix (too) and the NOR-NORI case (*geratzen zait*).

## In the fitting room

| English | Euskera |
|---|---|
| Can I try it on? | *Probatu dezaket?* |
| The fitting room | *probalekua* |
| The size | *neurria / talla* |
| What size do you wear? | *Zein neurri erabiltzen duzu?* |
| It fits me well / badly | *Ondo / gaizki geratzen zait* |
| Too big / small | *Handiegia / txikiegia* |
| Do you have it in another color? | *Beste kolore batean baduzue?* |
| And in a bigger size? | *Eta neurri bat handiagoan?* |

> *— Praka hauek **probatu ditzaket**?*
>
> *— Noski, **probalekua** hor atzean dago.*
>
> *(bost minutu geroago)* *— Zer, **ondo geratzen zaizkizu**?*
>
> *— Ez… **txikiegiak dira**. **42an baduzue**?*

*Geratzen zait / zaizkizu* — Pure NOR-NORI: the garment (NOR) fits ME (NORI). In the plural: *geratzen zaizkit* (they fit me).

## Exchanging and returning

| English | Euskera |
|---|---|
| I want to exchange it | *Aldatu nahi dut* |
| I want to return it | *Itzuli nahi dut* |
| Will you give me my money back? | *Dirua itzuliko didazue?* |
| The receipt | *tiketa* |
| It has a defect | *Akats bat dauka* |
| It's unworn | *Erabili gabe dago* |
| The return period | *Itzultzeko epea* |

> *— Egun on. Jertse hau **itzuli nahi nuke**. **Akats bat dauka** hemen, ikusten?*
>
> *— Egia da. **Tiketa badaukazu**?*
>
> *— Bai, hemen. **Dirua itzuliko didazue** ala aldatu behar dut?*
>
> *— Nahi duzun bezala. Dirua **txartelera itzuliko dizugu**, bi-hiru egunetan.*
>
> *— Primeran, eskerrik asko.*

Notice the chained NOR-NORI-NORK: *itzuliko didazue* (you will return it to me), *itzuliko dizugu* (we will return it to you). Unit 03 working in real life.

## Sales and prices (a snappy review)

> ***Merkealdiak** daude: dena **%50ean**!* — There's a sale: everything is 50% off!
>
> *Deskontuarekin, **19,95 euro** bakarrik.* — With the discount, it's only €19.95.
>
> *Bi erosita, **hirugarrena doan**.* — Buy two, get the third one free.

## The pocket summary

1. **To try on**: *Probatu dezaket? → Ondo/gaizki geratzen zait → -egi* for sizes.
2. **To exchange**: *Aldatu nahi dut* (+ *beste neurri/kolore batean*).
3. **To return**: *Itzuli nahi dut* + *tiketa* + *dirua itzuliko didazue?*
