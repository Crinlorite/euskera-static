D'o paper a o píxel: a lección de **tecnolochía cotidiana**. Vocabulario que fas servir cient vegadas a o día — agora en basco, que antimás presume de parolas transparents y bien construyidas (*pasahitza* = parola de paso; *sakelakoa* = "o de pocha").

## Os aparatos

| Aragonés | Euskera |
|---|---|
| L'ordinador | *ordenagailua* |
| O (ordinador) portatil | *eramangarria* |
| O móbil | *mugikorra / sakelakoa* |
| A tableta | *tableta* |
| A pantalla | *pantaila* |
| O teclau | *teklatua* |
| O ratón | *sagua* (¡sí, l'animal!) |
| Os auriculars | *entzungailuak* |

## O ret y as cuentas

| Aragonés | Euskera |
|---|---|
| O ret / internet | *sarea / internet* |
| O wifi | *wifia* |
| O correu electronico | *posta elektronikoa* |
| O usuario | *erabiltzailea* |
| A clau | *pasahitza* |
| L'aplicación | *aplikazioa* |
| A pachina web | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Cuál ye a clau d'o wifi?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — He ixublidau a clau y agora he de creyar-ne una de nueva. Atra vegada.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Pa creyar a cuenta cal correu y clau.

## Os verbos dichitals

| Aragonés | Euskera |
|---|---|
| Prender / amortar | *piztu / itzali* |
| Descargar | *deskargatu / jaitsi* |
| Instalar | *instalatu* |
| Alzar | *gorde* |
| Borrar | *ezabatu* |
| Ninviar / compartir | *bidali / partekatu* |
| Buscar (en o ret) | *bilatu* |
| Funcionar | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — L'ordinador va malament; amorta-lo y prende-lo — a solución de siempre.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Has alzau as fotos? ¡No borres cosa!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Descargas l'app, creyas a cuenta y ya ye.

## Dialogo: soporte tecnico familiar

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Nota:** o basco dichital ye bien vivo: o software libre y a Wikipedia en basco son potents, y o tuyo móbil entero puet ir en basco (*Ezarpenak → Hizkuntza*). Meter-lo ye, de feito, un truco d'estudio brutal: inmersión diaria de gratis.
