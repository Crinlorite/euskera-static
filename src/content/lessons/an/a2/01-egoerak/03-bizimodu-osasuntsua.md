Parlar d'**estilo de vida** y **medio ambient** ye un bloque clasico de l'A2: se mestura vocabulario nuevo con frases d'obligación y consello (*behar dugu*, *komeni da*, *garrantzitsua da*) que ya fas servir dende l'A1.

## Habitos saludables

| Castellán | Basco |
|---|---|
| Fer esporte | *kirola egin* |
| Caminar / paseyar | *paseatu* / *ibili* |
| Correr | *korrika egin* |
| Ir en bici | *bizikletaz ibili* |
| Minchar fruita y verdura | *fruta eta barazkiak jan* |
| Beber augua | *ura edan* |
| Dormir bien | *ondo lo egin* |
| Fumar | *erre* |
| Beber alcol | *alkohola edan* |
| No abusar d'a sal | *gatzaz ez abusatu* |

> Frases tipicas:
>
> - *Kirola egiten dut astean hiru aldiz.* — Faigo esporte tres vegadas a la semana.
> - *Erretzeari utzi diot.* — He deixau de fumar.
> - *Ez dut alkoholik edaten astegunetan.* — No bebo alcol entre semana.

## Frequencia: *X aldiz*

Pa decir "X vegadas" fas servir a formula **numero + aldiz**:

| Castellán | Basco |
|---|---|
| Una vegada a o día | *Egunean behin* |
| Dos vegadas a la semana | *Astean bi aldiz* / *birritan* |
| Tres vegadas a o mes | *Hilean hiru aldiz* |
| Muitas vegadas | *Askotan* |
| A vegadas | *Batzuetan* |
| Poquetas vegadas | *Gutxitan* |
| Nunca | *Inoiz ez* |

## Os contenedors

| Color habitual | Basco | Pa qué |
|---|---|---|
| Azul | *edukiontzi urdina* | papera / papel |
| Amariello | *edukiontzi horia* | plastikoa / plastico |
| Verde | *edukiontzi berdea* | beira / veire |
| Marrón | *edukiontzi marroia* | organikoa / organico |
| Gris | *edukiontzi grisa* | hondakinak / resta |

## Frases útils pa opinar

- *Garrantzitsua da birziklatzea.* — Ye important reciclar.
- *Komeni da kirola egitea.* — Convién fer esporte.
- *Beharrezkoa da kutsadura gutxitzea.* — Ye necesario reducir a contaminación.
- *Ez dut uste plastikoa ona denik.* — No creigo que o plastico sía bueno.

> Istas estructuras (*-tzea + adjetivo + da*) son a formula A2 pa "ye important / convién / ye necesario fer X". Las treballaremos a fundo en a unidat 4.

## Vida d'o vico

| Castellán | Basco |
|---|---|
| Vico | *auzoa* |
| Vecín/a | *bizilaguna* |
| Asociación | *elkartea* |
| Voluntariau | *boluntariotza* |
| Fiestas d'o vico | *auzoko jaiak* |
| Participar | *parte hartu* |
| Reunión | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## Mini-texto modelo

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **Nota cultural:** as *auzo-elkarteak* (asociacions de vecins) son una pieza fundamental d'a vida social en muitos lugars d'Euskal Herria. Organizan fiestas, tallers de basco, salidas a o mont y campanyas medioambientals. Participar-ie ye una d'as millors maneras de practicar a luenga en o suyo uso real.
