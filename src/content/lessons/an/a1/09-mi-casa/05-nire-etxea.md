Ista lección integra tot o d'o tema 9: as habitacions, os muebles, as fainas y con qui vives. L'obchectivo ye que puedas **describir a tuya casa** en frases sencillas, como si te fuesen preguntando en clase u en una conversa informal.

## As preguntas basicas

| Pregunta | Aragonés |
|---|---|
| *Non dago zure etxea?* | An ye a tuya casa? |
| *Nolakoa da?* | Cómo ye? |
| *Zenbat gela ditu?* | Cuantas habitacions tiene? |
| *Norekin bizi zara?* | Con qui vives? |
| *Zenbatgarren solairuan bizi zara?* | En qué planta vives? |
| *Etxeak badu igogailua / balkoia / terraza?* | A casa tiene ascensor / balcón / terraza? |

## Adchectivos útils pa describir a casa

| Basco | Aragonés |
|---|---|
| *handia* | gran |
| *txikia* | chica |
| *argitsua* | luminosa |
| *iluna* | escura |
| *berria* | nueva |
| *zaharra* | viella |
| *lasaia* | tranquila |
| *zaratatsua* | rudiosa |
| *erosoa* | comoda |
| *garestia* | cara |
| *merkea* | barata |

> Recuerda o patrón **NOLAKOA da?** ya visto en atras unidaz: a respuesta leva l'adchectivo + `-a` final + verbo *izan*. Ej.: *Nire etxea **handia da**.* — A mía casa ye gran.

## Un paragrafo modelo

Aquí tienes un texto sencillo describindo una casa. Leye-lo en voz alta y para cuenta en os patrons.

> *Ni Iruñean bizi naiz, auzo lasai batean. Nire etxea ez da oso handia: hiru gela ditu — bi logela eta egongela bat — sukaldea eta komuna. Egongela argitsua da, eta balkoi bat dauka. Hirugarren solairuan dago, eta etxeak igogailua du.*
>
> *Bikotekidearekin bizi naiz. Berak bazkaria prestatzen du, eta nik ontziak garbitzen ditut. Asteburuetan biok elkarrekin egiten dugu erosketa.*

## O tuyo turno: describe a tuya casa

Construye o tuyo propio paragrafo respondendo en ista orden:

1. **Non bizi zara?** (An vives?) → *X-(e)an bizi naiz.*
2. **Nolakoa da etxea?** (Cómo ye?) → *Nire etxea handia / argitsua / lasaia da.*
3. **Zenbat gela ditu?** (Cuantas habitacions?) → *Bi / Hiru / Lau gela ditu.*
4. **Zer dago etxean?** (Qué i hai?) → *Sukaldea, egongela, bi logela eta komun bat ditu.*
5. **Norekin bizi zara?** → *Bakarrik / Gurasoekin / Lagunekin bizi naiz.*
6. **Etxeko lanak nork egiten ditu?** → *Nik egunero garbitzen dut* / *Pisukideen artean banatzen ditugu.*

## Vocabulario de cierre

| Basco | Aragonés |
|---|---|
| *etxebizitza* | vivienda |
| *etxejabea* | propietario |
| *alokairua* | loguero |
| *errenta* | renta / loguero mensual |
| *auzoa* | barrio |
| *erdigunea* | centro (d'a ciudat) |
| *aldiriak* | extrarradio / afueras |

> **Consello:** quan parles d'a tuya casa en clase, no mires de traducir cada detalle. Queda-te con frases curtas y bien feitas. *"Bi logela ditut, sukalde txiki bat eta egongela handia"* ye millor descripción que una frase larga plena d'errors.
