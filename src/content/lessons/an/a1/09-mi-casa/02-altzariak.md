Cada cambra tien o suyo moblache. A parola cheneral ta "mueble" ye **altzaria** (en plural *altzariak*). Anem a recorrer a casa por gelas.

## Egongelan — En a sala

| Euskera | Aragonés |
|---|---|
| *sofa* | sofá |
| *besaulkia* | siyón / butaca |
| *mahaia* | mesa |
| *aulkia* | cadiera |
| *kuxina* | coixín |
| *lanpara* | lampa |
| *telebista* | televisión |
| *apalategia* | estantería |

## Logelan — En a cambra

| Euskera | Aragonés |
|---|---|
| *ohea* | leito |
| *gau-mahaia* | meseta de nueit |
| *armairua* | armario |
| *iratzargailua* | espertador |
| *ordenagailua* | ordinador |
| *posterra* | póster |

## Sukaldean — En a cocina

| Euskera | Aragonés |
|---|---|
| *hozkailua* | nevera |
| *labea* | forno |
| *mikrouhina* | microondas |
| *garbigailua* | lavadora |
| *ontzi-garbigailua* | rentaplatos |
| *zartagina* | sartana |
| *edalontzia* | vaso |
| *koilara / sardexka / labana* | cullara / forqueta / cutiello |

## Komunean — En o banyo

| Euskera | Aragonés |
|---|---|
| *dutxa* | ducha |
| *bainuontzia* | banyera |
| *konketa* | lavabo |
| *ispilua* | espello |
| *eskuoihala* | toballa |
| *komuneko papera* | papel hichienico |

## Como combinar-lo en una frase

Acuerda-te de lo que ya sabes de **ukan** (tener) y aplica-lo:

- *Sukaldean hozkailu bat dut.* — En a cocina tiengo una nevera.
- *Egongelan bi besaulki ditugu.* — En a sala tenemos dos butacas.
- *Logelan ez dut posterrik.* — En a cambra no tiengo pósters. *(negación con `-rik`)*

> **Nota:** *garbigailua* (lavadora) y *ontzi-garbigailua* (rentaplatos) comparten a radiz *garbi-* (limpiar). Ye un buen eixemplo de cómo o euskera construye parolas composadas muit transparents.
