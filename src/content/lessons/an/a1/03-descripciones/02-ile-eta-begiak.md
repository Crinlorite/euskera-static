Pa describir o pelo y os uellos en basco no se fa servir **izan** ("ser") como en castellano ("soy moreno"), sino **ukan** ("tener"): *tiengo o pelo negro*, *tiengo os uellos azuls*.

## Pelo: ile

A parola pa "pelo" ye **ile** (con articlo: *ilea*). Os adchectivos van dezaga, y solo o zaguer leva a marca `-a`:

| Euskera | Aragonés |
|---|---|
| *ile beltza* | pelo negro |
| *ile horia* | pelo royo |
| *ile zuria* | pelo blanco / cano |
| *ile gorria* | pelo peliroyo |
| *ile urdina* | pelo griso |
| *ile motza* | pelo curto |
| *ile luzea* | pelo largo |
| *ile lisoa* | pelo liso |
| *ile kizkurra* | pelo rizau |

> O pelo en basco se tracta como **singular**, igual que en aragonés. Por ixo se fa servir *dut* / *du* (no *ditut* / *ditu*).

- *Ile beltza eta luzea **dut**.* — Tiengo o pelo negro y largo.
- *Maialenek ile kizkurra **du**.* — Maialen tiene o pelo rizau.

## Uellos: begiak

A diferencia d'o pelo, "os uellos" ye **plural** (*begiak*). Por tanto os adchectivos van tamién en plural (`-ak`) y se fa servir **ditut / ditu**:

| Euskera | Aragonés |
|---|---|
| *begi urdinak* | uellos azuls |
| *begi marroiak* | uellos marrons |
| *begi berdeak* | uellos verdes |
| *begi beltzak* | uellos negros |
| *begi argiak* | uellos claros |
| *begi ilunak* | uellos escuros |

- *Begi urdinak **ditut**.* — Tiengo os uellos azuls.
- *Mikelek begi marroiak **ditu**.* — Mikel tiene os uellos marrons.

## Atros rasgos: o sufixo -dun

Pa decir "que leva X" u "con X", o basco tiene un sufixo muit productivo: **-duna** (singular) / **-dunak** (plural). S'adhibe a o substantivo y a persona pasa a estar "o d'as gafas", "o d'a barba"...

| Euskera | Aragonés |
|---|---|
| *betaurrekoduna* | con gafas / o d'as gafas |
| *bizarduna* | con barba |
| *biboteduna* | con bigote |
| *burusoila* | calvo (literalment "cabeza pelada") |

Istos sí que van con **izan**, porque describen una cualidat como un adchectivo:

- *Hura biboteduna da.* — Él leva bigote.
- *Nire aitona burusoila da.* — O mío lolo ye calvo.

## Combinando-lo todo

Un retrato tipico mezcla cuantas estructuras:

> *Maialen txikia eta argala da. Ile gorria eta kizkurra du. Begi berdeak ditu. Betaurrekoduna da.*
>
> Maialen ye baixeta y delgada. Tiene o pelo peliroyo y rizau. Tiene os uellos verdes. Leva gafas.

Para cuenta en cómo se reparte: **izan** pa cualidaz chenerals (*txikia da*), **ukan** pa pelo/uellos (*ile … du*, *begi … ditu*), y *-dun*-a atra vegada con **izan** pa os accesorios.
