Ha tudsz konkrét mennyiségeket kérni, az a különbség az "egy alma" és az "egy kiló alma" között. A baszk minta nagyon szabályos, és mindig ugyanaz.

## Az alapminta

> **MENNYISÉG + TERMÉK (névelő nélkül)**

| Euskera | Magyar |
|---|---|
| *kilo bat sagar* | egy kiló alma |
| *bi kilo tomate* | két kiló paradicsom |
| *kilo erdi piper* | fél kiló paprika |
| *200 g txorizo* | 20 deka chorizo |
| *litro bat ur* | egy liter víz |
| *litro erdi esne* | fél liter tej |
| *dozena bat arrautza* | egy tucat tojás |
| *pakete bat makarroi* | egy csomag makaróni |
| *botila bat ardo* | egy üveg bor |
| *lata bat tomate* | egy doboz paradicsomkonzerv |

> **Figyelem:** a termék **névelő nélkül** áll (*sagar*, nem *sagarra*). Gyakorlással megtanulható.

## Előbb a szám, utána a termék

A sorrend fontos:

- *Bi kilo sagar* — két kiló alma (HELYES)
- ~~Sagar bi kilo~~ — így nem mondják

## Hozzávetőleges mennyiségek

| Euskera | Magyar |
|---|---|
| *gehiago* | több |
| *gutxiago* | kevesebb |
| *pixka bat* | egy kicsit |
| *asko* | sok |
| *gutxi* | kevés |
| *nahikoa* | elég |

Tipikus példák a zöldségesnél:

- *Gehiago, mesedez.* — Egy kicsit többet, kérem.
- *Hori da, nahikoa da.* — Ez az, ennyi elég.
- *Gutxiago, mesedez.* — Kevesebbet, kérem.

## Mintamondatok

- *Eman kilo bat sagar eta dozena bat arrautza, mesedez.* — Adjon egy kiló almát és egy tucat tojást, kérem.
- *Litro bat esne hartuko dut.* — Egy liter tejet viszek.
- *Bi botila ur, mesedez.* — Két üveg vizet kérek.

> **Kulturális megjegyzés:** a piacokon (azoka) és a hagyományos piactereken még mindig "szemmértékkel" mérnek: egy kiló almát kérsz (*kilo bat sagar*), és az eladó addig igazítja, amíg pontos nem lesz a súly. Gyakran hallani a *pixka bat gehiago, mesedez* kérést, miközben a mérleg nyelve emelkedik.
