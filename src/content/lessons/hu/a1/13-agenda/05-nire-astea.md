Az egység utolsó leckéje: **egy egész hetet** állítunk össze mindabból, amit megtanultunk. Napok, jövő idő, találkozók, időhatározók… a tervezés nyelve.

## Nyitott kérdés

> *Zer egingo duzu aste honetan?* — Mit csinálsz ezen a héten?

Egy természetes válasz a napot + jövő időt használná:

> *Astelehenean kiroldegira joango naiz. Asteartean euskara klasea dut. Asteazkenean bilera bat izango dut. Ostegunean lasai egongo naiz. Ostiralean lagunekin afaltzera joango gara. Asteburuan mendira joango gara.*
>
> Hétfőn edzőterembe megyek. Kedden baszkórám van. Szerdán megbeszélésem lesz. Csütörtökön pihenni fogok. Pénteken a barátokkal vacsorázni megyünk. Hétvégén a hegyekbe megyünk.

## Alapsablon

> **NAP + TEVÉKENYSÉG + JÖVŐ IDŐ**

| Nap | Példatevékenység |
|---|---|
| *Astelehenean...* | *...kiroldegira joango naiz* |
| *Asteartean...* | *...lan egingo dut* |
| *Asteazkenean...* | *...amarekin geratuko naiz* |
| *Ostegunean...* | *...filma bat ikusiko dut* |
| *Ostiralean...* | *...lagunekin aterako naiz* |
| *Larunbatean...* | *...mendira joango gara* |
| *Igandean...* | *...etxean lasai egongo naiz* |

## Hasznos igék a naptárhoz

| Ige | Jövő idejű alak | Magyar |
|---|---|---|
| joan | joango naiz/da | megyek, megy (majd) |
| etorri | etorriko naiz/da | jövök, jön (majd) |
| egon | egongo naiz | leszek (valahol/valahogy) |
| izan | izango da | lesz |
| ikusi | ikusiko dut | látni fogom |
| egin | egingo dut | megcsinálom |
| jan | jango dut | megeszem |
| lan egin | lan egingo dut | dolgozni fogok |
| atera | aterako naiz | el fogok menni (kimozdulok) |
| eraman | eramango dut | elviszem |
| erosi | erosiko dut | megveszem |

## Mini-történet: Iratxe hete

Olvasd el ezt a kitalált naptárat, és figyeld meg az időhatározókat:

> *Astelehenean lana dut goizean, eta arratsaldean kiroldegira joango naiz. Asteartean medikuarekin daukat hitzordua, hamabietan. Asteazkenean ez dut ezer berezirik, etxean afalduko dut lasai. Ostegunean Maialenekin geratuko naiz kafe bat hartzeko, sei eta erdietan. Ostiralean afari bat dugu lankideekin. Larunbatean asteburu pasa: Bilbora joango gara nire bikotekidearekin. Igandean buelta etxera, eta arratsaldean lasai-lasai filma bat ikusiko dut.*

## Rajtad a sor: három mintaválasz

**Kérdés:** *Bihar zer egingo duzu?*

> *Bihar lanera joango naiz goizean. Arratsaldean kafea hartuko dut lagun batekin, eta gauean etxean afalduko dut.*

**Kérdés:** *Datorren astean zer plan duzu?*

> *Datorren astean azterketa bat izango dut. Asko ikasiko dut. Larunbatean lasai gelditu nahi dut.*

**Kérdés:** *Asteburu honetan zer egingo duzu?*

> *Asteburu honetan mendira joango gara lagunekin. Larunbatean Aralarrera joango gara, eta igandean lasai geldituko gara etxean.*

## Kulcsmondatok a hét megszervezéséhez

- **Libre zaude X-(e)an?** — Ráérsz X-en?
- **Hamarretan ondo?** — Tízkor jó?
- **Beste egun batean izan beharko du.** — Majd egy másik napon.
- **Konforme, X-(e)an geratuko gara.** — Rendben, X-en találkozunk.

## Vizuális ismétlés

```
Múlt      →  Jelen     →  Jövő
atzo         gaur          bihar — etzi — datorren astean
joan zen     doa            joango da
ikusi dut    ikusten dut    ikusiko dut
```

> **Kulturális megjegyzés:** sok helyen látsz majd olyan plakátokat, mint *"Asteburu honetan jaiak"* vagy *"Datorren ostiralean kontzertua"*. Az olyan időhatározók, mint a *datorren* és az *asteburu honetan*, a beszélgetésben és a környék bármelyik hirdetőtábláján is előfordulnak. Ha a füled felismeri őket, sokkal könnyebb "olvasni az utcát".
