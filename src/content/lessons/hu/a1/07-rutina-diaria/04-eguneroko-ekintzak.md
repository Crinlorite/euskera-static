Ahhoz, hogy elmondd, mit csinálsz minden nap, a baszk a **szokásos cselekvés** alakját használja: veszed az igét (partizipio), hozzáteszed a **-tzen** vagy **-ten** végződést, majd az **izan** (naiz, zara, da…) vagy az **ukan** (dut, duzu, du…) segédigével kapcsolod össze.

## A szabály

| Az ige vége | Szokásos végződés | Példa |
|---|---|---|
| mássalhangzó vagy `-tu` / `-du` | **-tzen** | *esnatu* → *esnatzen* |
| `-n` | **-ten** | *jan* → *jaten*; *egin* → *egiten* |
| `-i` (rendhagyó) | **-tzen** vagy **-ten** | *etorri* → *etortzen*; *ikusi* → *ikusten* |

> A *jan* (enni) ige **nem** *janten* lesz, hanem *jaten* — a végső "n" eltűnik. Ugyanígy: *edan* → *edaten*, *egon* → *egoten*.

## Mindennapi igék

### NOR (az **izan** segédigével: naiz, zara, da…)

Ezek az **izan** igével állnak, mert tárgyatlanok — az alany tárgy nélkül éli át a cselekvést:

| Partizipioa | Szokásos alak | Jelentés |
|---|---|---|
| *esnatu* | *esnatzen naiz* | felébredek |
| *jaiki* | *jaikitzen naiz* | felkelek |
| *altxatu* | *altxatzen naiz* | felkelek (a *jaiki* változata) |
| *dutxatu* | *dutxatzen naiz* | zuhanyozom |
| *jantzi* | *janzten naiz* | felöltözöm |
| *joan* | *joaten naiz* | megyek |
| *etorri* | *etortzen naiz* | jövök |
| *oheratu* | *oheratzen naiz* | lefekszem |
| *lokartu* | *lokartzen naiz* | elalszom |

### NOR-NORK (az **ukan** segédigével: dut, duzu, du…)

Ezek az **ukan** igével állnak, mert van alanyuk és tárgyuk:

| Partizipioa | Szokásos alak | Jelentés |
|---|---|---|
| *gosaldu* | *gosaltzen dut* | reggelizem |
| *bazkaldu* | *bazkaltzen dut* | ebédelek |
| *afaldu* | *afaltzen dut* | vacsorázom |
| *jan* | *jaten dut* | eszem |
| *edan* | *edaten dut* | iszom |
| *lan egin* | *lan egiten dut* | dolgozom |
| *lo egin* | *lo egiten dut* | alszom |
| *ikusi* | *ikusten dut* | látok |
| *irakurri* | *irakurtzen dut* | olvasok |
| *erosi* | *erosten dut* | vásárolok |

> **Miért áll az egyik NAIZ, a másik DUT segédigével?** Ez a baszk kulcsfontosságú megkülönböztetése. *Esnatzen naiz* (felébredek): ez velem történik, nincs tárgya. *Jaten dut* (eszem): ennek van tárgya: *ogia jaten dut* (kenyeret eszem). Ezt a következő egységben alaposan megnézzük — egyelőre jegyezd meg az ige + segédige párokat.

## Összekapcsolt példák

> *Egunero zazpietan esnatzen naiz eta dutxatzen naiz.* — Minden nap hétkor ébredek és lezuhanyozom.
>
> *Goizean kafea hartzen dut.* — Reggel kávét iszom.
>
> *Askotan lagunekin afaltzen dut.* — Gyakran vacsorázom a barátaimmal.
>
> *Batzuetan lo-kuluxka egiten dut bazkalostean.* — Néha szundítok egyet ebéd után.

> **Megjegyzés:** a *bazkalostean* = "ebéd után" (szó szerint: "az ebéd után"). A baszk nyelvnek tömör szavai vannak a hétköznapi fogalmakra, például erre a rövid délutáni alvásra — a *lo-kuluxka* pontosan ezt jelenti.
