Euskal Herriában a társasági élet jó része a **tabernában** (a bárban) zajlik. Ha ismered baszkul az alapvető italokat és ételeket, rögtön kapuk nyílnak meg előtted: egy baráti társaság, egy látogatás egy új faluban, egy *poteo* (kocsmáról kocsmára járás). Kezdjük a szókinccsel.

## A kávé és változatai

Valószínűleg kávét fogsz a leggyakrabban rendelni. Többféle formája van:

| Euskera | Magyar |
|---|---|
| *kafea* | a kávé (általában) |
| *kafe hutsa* | fekete kávé (szó szerint: "tiszta/üres kávé") |
| *kafesnea* | tejeskávé (a *kafe* + *esne* szavakból) |
| *kafe ebakia* | kevés tejjel készült kávé (*ebaki* = "vágott") |
| *kafe deskafeinatua* | koffeinmentes kávé |
| *infusioa* | gyógytea |
| *tea* | tea |

> *Kafesne*: szó szerint "kávé-tej". A baszk sok összetett szót így képez, kötőjel nélkül, a fő szót a végére téve.

## Egyéb italok

| Euskera | Magyar |
|---|---|
| *ura* | a víz |
| *zumoa* | gyümölcslé |
| *esnea* | a tej |
| *ardoa* | bor |
| *ardo gorria* | vörösbor |
| *ardo zuria* | fehérbor |
| *garagardoa* | sör |
| *zuritoa* | kis pohár sör (jellegzetes) |
| *sagardoa* | almabor |
| *txakolina* | txakoli (baszk fehérbor) |
| *patxarana* | patxaran (kökénylikőr) |

> Három érdekes szó: **sagardo** (almabor) = *sagar* (alma) + *ardo* (bor); **garagardo** (sör) = *garagar* (árpa) + *ardo*; a **txakolina** fiatal, könnyű fehérbor, Euskadi különlegessége.

## Alapvető ételek a bárban

Amihez az italod mellé:

| Euskera | Magyar |
|---|---|
| *ogia* | a kenyér |
| *gazta* | sajt |
| *urdaiazpikoa* | sonka |
| *tortilla* | tortilla (krumplis omlett) |
| *patata frijituak* | sült krumpli |
| *gozokia* | édesség (általában) |
| *txokolatea* | csokoládé |

## Az `-a` névelő

Szinte minden ilyen szó **`-a`** végződést kap, amikor "semleges" módon szerepel egy mondatban: ez a névelő, "a/az".

- *Ardoa gustatzen zait.* — Szeretem a bort.
- *Ura nahi dut.* — Vizet kérek.

Ha "egyet" kérsz, az `-a` eltűnik, és belép a **bat** ("egy"):

- *Kafe **bat**, mesedez.* — Egy kávét kérek.
- *Garagardo **bat**.* — Egy sört.

> A 3. leckében ezt részletesen látod majd. Egyelőre jegyezd meg az `-a` végű alakokat, hogy felismerd őket a bár itallapján.
