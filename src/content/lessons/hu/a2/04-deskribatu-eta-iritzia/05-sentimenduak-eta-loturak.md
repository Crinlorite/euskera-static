Ez a lecke két nagyon termékeny A2-es blokkot kapcsol össze:

1. **Érzések** és hangulatok (az alapokat ismered az A1-ből; itt bővíted őket).
2. **Szövegkötő szavak** az érveléshez és árnyaláshoz: *gainera, hala ere, beraz, alde batetik...*

Ezzel lezárod az egységet, és eszközöket kapsz a kidolgozottabb véleményekhez.

## Érzések: a formula az *egon* + állapot

A legtöbb átmeneti érzés az *egon* igével + állapotot kifejező melléknévvel vagy határozószóval áll:

| Magyar | Euskera |
|---|---|
| Boldog | *Pozik nago* |
| Szomorú | *Triste nago* |
| Mérges | *Haserre nago* |
| Ideges | *Urduri nago* |
| Nyugodt | *Lasai nago* |
| Unatkozom | *Aspertuta nago* |
| Fáradt | *Nekatuta nago* |
| Szégyellem magam | *Lotsatuta nago* |
| Szerelmes | *Maitemindurik nago* |

> Ez ugyanaz az A1-es minta (*pozik, triste, lasai*), kibővítve az *aspertuta, nekatuta, lotsatuta, maitemindurik* szavakkal.

## Érzések az *izan* igével: *beldur naiz*

Néhány mély érzés az *izan* igével áll:

| Magyar | Euskera |
|---|---|
| Félek | *Beldur naiz* |
| Igazad van | *Arrazoia duzu* |
| Kíváncsi vagyok | *Jakin-mina dut* |
| Kedvem van | *Gogoa dut* / *Gogoz nago* |
| Nincs kedvem | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — Félek autóval menni.

## Érzések *NOR-NORI* szerkezettel: *lotsa ematen dit*

Nagyon baszkos formula: az érzés "ad neked" valamit:

| Magyar | Euskera |
|---|---|
| Szégyellem | *Lotsa ematen dit* |
| Sajnálom | *Pena ematen dit* |
| Feldühít | *Amorrua ematen dit* |
| Félelmet kelt bennem | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — Szégyellem kimondani.
>
> *Albiste horrek **pena handia ematen dit**.* — Ez a hír nagyon elszomorít.

## *Jartzen naiz / jarri naiz*

Az **állapotváltozás** kifejezésére ("ideges lesz, boldog lesz, elszomorodik"):

| Magyar | Euskera |
|---|---|
| Ideges leszek | *Urduri **jartzen naiz*** |
| Elszomorodott | *Triste **jarri zen*** |
| Megörültünk | *Pozik **jarri ginen*** |
| Mindenen felhúzza magát | *Edozergatik haserretzen da* |

## Gyakori lelkiállapotot kifejező igék

| Ige | Jelentés |
|---|---|
| *gustatu* | tetszeni |
| *maite izan* | szeretni |
| *gorrotatu* / *higuindu* | gyűlölni |
| *beldurtu* | megijedni |
| *aspertu* | unatkozni |
| *haserretu* | megharagudni |
| *lasaitu* | megnyugodni |
| *poztu* | megörülni |
| *triste jarri* / *atsekabetu* | elszomorodni |
| *kezkatu* | aggódni |

> *Asko **maite ditut** nire gurasoak.* — Nagyon szeretem a szüleimet.
>
> *Ez **kezkatu**, dena ondo aterako da.* — Ne aggódj, minden rendben lesz.

## Szövegkötő szavak

A vélemények és érvek összefűzéséhez:

### Kiegészítés

| Magyar | Euskera |
|---|---|
| Ráadásul | *gainera* |
| És szintén | *eta baita ere* / *...ere* |
| Főleg | *batez ere* |

> *Gainera, prezioa ere ona da.* — Ráadásul az ár is jó.

### Ok / következmény

| Magyar | Euskera |
|---|---|
| Tehát | *beraz* |
| Ezért | *horregatik* |
| Emiatt | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — Késő van; tehát megyek.

### Ellentét / szembeállítás

| Magyar | Euskera |
|---|---|
| Mégis | *hala ere* |
| De | *baina* |
| Másrészt | *bestetik* |
| Ezzel szemben | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — Késő van; mégis eljövök.

### A szöveg megszervezése

| Magyar | Euskera |
|---|---|
| Egyrészt… másrészt | *Alde batetik... bestetik...* |
| Először… aztán… | *Lehenengo... gero...* |
| Végül | *Azkenik* |
| Összefoglalva | *Laburbilduz* |

## A2-es mellérendelő szerkezetek

Ezek a szerkezetek minden A2-es vizsgán előfordulnak:

| Magyar | Euskera |
|---|---|
| Se… se… | *Ez... ez...* |
| Mind… mind… | *Bai... bai...* / *Hala... nola...* |
| Nemcsak… hanem… is | *Ez bakarrik..., baita ere...* |
| …is (beleértve) | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — Se Anboto, se Olatz nem jött el.
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — Délelőtt is, délután is dolgoznom kell.

## Véleményt kifejtő mini-szöveg

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## Trükk az A2-höz: a "véleményváz"

Ha az A2 szinten véleményt kérnek tőled, kövesd ezt a sablont:

> **1. Nire ustez** + téma + **-(e)la**.
>
> **2. Alde batetik**, + 1. ok + **-lako**.
>
> **3. Bestetik**, + 2. ok.
>
> **4. Hala ere**, + árnyalás.
>
> **5. Beraz**, + következtetés.

Ezzel egy teljes A2-es bekezdést építesz fel.

> **Kulturális megjegyzés:** sok hivatalos A2-es szöveg (olvasói levél, fórum, vizsgafogalmazás) ezt az érvelő szerkezetet kéri. Gyakorold hétköznapi témákon: sport, étel, közösségi média, munka, a falu ünnepei.
