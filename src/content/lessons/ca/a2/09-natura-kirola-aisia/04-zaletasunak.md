Què fas quan no fas res? Aquesta lliçó va d'**aficions** — i de la peça de gramàtica que les governa: el verb convertit en substantiu amb **-tzea** (*irakurtzea* = "el llegir").

## La peça: -t(z)ea

De l'A1 coneixes *gustatzen zait* amb coses (*kafea gustatzen zait*). Perquè t'agradi una **activitat**, el verb es fa substantiu:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| Català | Eusquera |
|---|---|
| M'agrada llegir | *Irakurtzea gustatzen zait* |
| M'encanta cuinar | *Asko gustatzen zait sukaldatzea* |
| Li agrada cantar | *Abestea gustatzen zaio* |
| Ens agrada viatjar | *Bidaiatzea gustatzen zaigu* |
| No m'agrada gens matinar | *Ez zait batere gustatzen goiz jaikitzea* |

Tot el NOR-NORI que ja saps (*zait, zaio, zaigu…*) continua manant; només canvia el "què".

## El catàleg d'aficions

| Català | Eusquera |
|---|---|
| Llegir / escriure | *irakurtzea / idaztea* |
| Escoltar música | *musika entzutea* |
| Cantar / ballar | *abestea / dantzatzea* |
| Cuinar | *sukaldatzea* |
| Fer fotos | *argazkiak ateratzea* |
| Pintar / dibuixar | *margotzea / marraztea* |
| Viatjar | *bidaiatzea* |
| Cuidar l'hort | *baratzea zaintzea* |
| Els videojocs | *bideo-jokoak* |
| Cosir / fer punt | *jostea / puntua egitea* |

## Preguntar i presumir

> ***Zer egitea gustatzen zaizu** denbora librean?* — Què t'agrada fer durant el teu temps lliure?
>
> ***Zein da zure zaletasunik gogokoena**?* — Quina és la teva afició preferida?
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — La meva afició preferida és cuinar: cada cap de setmana tasto una recepta nova.

## Tres estructures, tres matisos (repàs fi)

| Estructura | Exemple | Significa |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | m'agrada (afició) |
| **-tzen dakit** | *Margotzen dakit* | sé fer-ho (habilitat) |
| **-tzen ari naiz** | *Margotzen ari naiz* | ho estic fent (ara) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — No sé fer punt, però m'agradaria aprendre'n. (Aquest *gustatuko litzaidake* elegant el dominaràs a B1 — t'ho deixem aquí de tastet.)

## Diàleg

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*
>
> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
>
> *— **Sukaldatzea** eta gero… **jatea**, noski.*
>
> *— Hori ere zaletasuna da?*
>
> *— Nire etxean, **kirola**.* 😄
