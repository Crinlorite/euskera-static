El **condicional** (*baldintza*) en basc té diverses formes. A l'A2 ens quedem amb les **dues més útils**:

1. **Condició real (futur probable):** *si demà plou, no hi aniré*.
2. **Condició irreal (hipòtesi):** *si tingués diners, compraria una casa*.

Aquesta lliçó és una **introducció**: n'hi ha prou que reconeguis les formes i produeixis frases senzilles. La unitat B1 ho aprofundeix.

## Tipus 1: condició real — *ba-* + present

Per a hipòtesis sobre el **futur probable** o el present, el basc utilitza el prefix **ba-** sobre l'auxiliar en present.

> **ba- + present de l'auxiliar, ... + futur**

| Català | Basc |
|---|---|
| Si plou, no hi aniré | *Euria egiten **badu**, ez naiz joango* |
| Si tens temps, vine | *Astia **baduzu**, etorri* |
| Si vols, truca'm | *Nahi **baduzu**, deitu niri* |
| Si soc ric algun dia… | *Aberatsa **banaiz** noizbait...* |

### Formes amb *ba-* (present)

| Verb | Sense ba- | Amb ba- |
|---|---|---|
| *naiz* | jo soc | **banaiz** (si soc) |
| *zara* | tu ets | **bazara** (si ets) |
| *da* | és | **bada** (si és) |
| *gara* | som | **bagara** (si som) |
| *dut* | jo el tinc | **badut** (si el tinc) |
| *du* | el té (ell) | **badu** (si el té) |
| *dute* | el tenen (ells) | **badute** (si el tenen) |

> **Atenció!** *Ba-* també té un ús afirmatiu: *bai, badator* = "sí, ve". És el context el que ho desambigua: si la frase té una segona part ("...llavors..."), és condicional.

## Tipus 2: condició irreal — *banintz / banu*

Per a hipòtesis irreals o molt poc probables ("si jo fos...", "si tingués..."), el basc utilitza formes dedicades:

### Formes d'*izan* en condició irreal

| Pronom | Forma | Català |
|---|---|---|
| ni | **banintz** | si jo fos/estigués |
| zu | **bazina** | si tu fossis |
| hura | **balitz** | si fos/estigués |
| gu | **bagina** | si fóssim |
| zuek | **bazinete** | si fóssiu |
| haiek | **balira** | si fossin |

### Formes d'*ukan* en condició irreal

| Pronom | Forma | Català |
|---|---|---|
| nik | **banu** | si jo el tingués |
| zuk | **bazenu** | si tu el tinguessis |
| hark | **balu** | si ell el tingués |
| guk | **bagenu** | si nosaltres el tinguéssim |
| haiek | **balute** | si ells el tinguessin |

> **Memoritza primer aquestes sis**: *banintz, balitz, banu, balu, bagenu, balute*. Són les que apareixen en qualsevol frase condicional irreal.

## La conseqüència: *-ko/-go + nuke / nintzateke*

El "comprar**ia** / aniria / seria" es forma amb **-ko/-go** (la mateixa marca que el futur) + un auxiliar especial:

### NOR-NORK condicional ("jo ho + ria")

| Pronom | Forma | Català |
|---|---|---|
| nik | **nuke** | jo ho —ria |
| zuk | **zenuke** | tu ho —ries |
| hark | **luke** | ell ho —ria |
| guk | **genuke** | ho —ríem |
| haiek | **lukete** | ho —rien |

### NOR condicional ("jo —ria", intransitiu)

| Pronom | Forma | Català |
|---|---|---|
| ni | **nintzateke** | jo —ria |
| zu | **zinateke** | tu —ries |
| hura | **litzateke** | ell —ria / seria |
| gu | **ginateke** | —ríem |
| haiek | **lirateke** | —rien |

## Frase model

> **baldintza + ondorioa**

> *Diru asko **banu**, etxe bat **erosiko nuke**.* — Si tingués molts diners, compraria una casa.
>
> *Lurralde berri batean **bizi banintz**, beste hizkuntza bat **ikasiko nuke**.* — Si visqués en un país nou, aprendria un altre idioma.
>
> *Anboto hemen **balitz**, lasaiago **egongo ginateke**.* — Si l'Anboto fos aquí, estaríem més tranquils.
>
> *Aberatsak **balira**, mundu osoa **bisitatuko lukete**.* — Si fossin rics, visitarien el món sencer.

## Comparació dels dos tipus

| Tipus | "si" | "llavors" |
|---|---|---|
| Real (futur probable) | *ba-* + present: *baduzu, bada* | futur: *-ko/-go + naiz/dut* (joango naiz, erosiko dut) |
| Irreal (hipòtesi) | *ba-* + condicional: *banu, balitz* | condicional: *-ko/-go + nuke/nintzateke* |

## Exemples en contrast

- **Real:** *Astia **baduzu**, lagunduko **dizut**.* — Si tens temps, t'ajudaré.
- **Irreal:** *Astia **bazenu**, lagunduko **zenidake**.* — Si tinguessis temps, m'ajudaries.

## Frases fetes molt útils

| Català | Basc |
|---|---|
| Voldries…? | *Nahi **zenuke**…?* |
| M'agradaria… | *Gustatuko **litzaidake**…* |
| Seria bonic… | *Polita **litzateke**…* |
| Hi aniria de gust | *Gustura **joango nintzateke*** |
| M'ho pensaria | *Pentsatuko **nuke*** |

## Minidiàleg

> *— Olatz, **nahi zenuke** zinemara joan?*
>
> *— Bai, **gustatuko litzaidake**, baina astia **banu**... Lan asko daukat astean.*
>
> *— Lasai. Bihar **etortzen bazara**, sarrera bat **erosiko dizut**.*

> **Nota pedagògica:** la *baldintza* és un dels punts on l'A2 t'obre la porta al B1. A l'A2 oficial n'hi ha prou de **reconèixer-la** i produir frases simples del tipus *banintz... -ko nuke*. La conjugació completa del condicional es treballa al B1.
