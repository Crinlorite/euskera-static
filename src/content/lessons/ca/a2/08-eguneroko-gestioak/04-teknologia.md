Del paper al píxel: la lliçó de **tecnologia quotidiana**. Vocabulari que fas servir cent cops al dia — ara en basc, que a més presumeix de paraules transparents i ben construïdes (*pasahitza* = paraula de pas; *sakelakoa* = "el de butxaca").

## Els aparells

| Català | Basc |
|---|---|
| L'ordinador | *ordenagailua* |
| El (ordinador) portàtil | *eramangarria* |
| El mòbil | *mugikorra / sakelakoa* |
| La tauleta | *tableta* |
| La pantalla | *pantaila* |
| El teclat | *teklatua* |
| El ratolí | *sagua* (sí, l'animal!) |
| Els auriculars | *entzungailuak* |

## La xarxa i els comptes

| Català | Basc |
|---|---|
| La xarxa / internet | *sarea / internet* |
| El wifi | *wifia* |
| El correu electrònic | *posta elektronikoa* |
| L'usuari | *erabiltzailea* |
| La contrasenya | *pasahitza* |
| L'aplicació | *aplikazioa* |
| La pàgina web | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Quina és la contrasenya del wifi?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — He oblidat la contrasenya i ara n'he de crear una de nova. Un altre cop.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Per crear el compte necessites correu i contrasenya.

## Els verbs digitals

| Català | Basc |
|---|---|
| Encendre / apagar | *piztu / itzali* |
| Descarregar | *deskargatu / jaitsi* |
| Instal·lar | *instalatu* |
| Desar | *gorde* |
| Esborrar | *ezabatu* |
| Enviar / compartir | *bidali / partekatu* |
| Cercar (a la xarxa) | *bilatu* |
| Funcionar | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — L'ordinador va malament; apaga'l i encén-lo — la solució de sempre.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Has desat les fotos? No esborris res!
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Descarregues l'app, crees el compte i llestos.

## Diàleg: suport tècnic familiar

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Nota:** el basc digital és molt viu: el programari lliure i la Viquipèdia en basc són potents, i tot el teu mòbil pot anar en basc (*Ezarpenak → Hizkuntza*). Posar-l'hi és, de fet, un truc d'estudi brutal: immersió diària gratuïta.
