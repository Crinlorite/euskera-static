L'**imperatiu** (*agintera*) serveix per donar instruccions, fer peticions i donar consells. En basc és **molt més senzill del que sembla**: la forma més usada coincideix gairebé sempre amb el **participi** del verb.

## La regla bàsica: fes servir el participi

Per a moltes ordres quotidianes, el verb apareix en la seva forma de participi sense auxiliar:

| Català | Basc |
|---|---|
| Pren | *Hartu* |
| Seu | *Eseri* |
| Aixeca't | *Jaiki* |
| Escriu | *Idatzi* |
| Llegeix | *Irakurri* |
| Escolta | *Entzun* |
| Repeteix | *Errepikatu* |
| Espera | *Itxoin* |
| Tanca la porta | *Itxi atea* |
| Obre la finestra | *Ireki leihoa* |

> Aquesta és la **forma més usada** a l'aula, al carrer i en instruccions escrites. Serveix tant per a *zu* com per a *zuek*.

## Formes sintètiques (trinkoak): *zatoz*, *zoaz*

Alguns verbs molt freqüents tenen formes sintètiques específiques per a l'imperatiu. Aquestes són les que convé memoritzar:

| Verb | Tu (zu) | Vosaltres (zuek) |
|---|---|---|
| *etorri* (venir) | **Zatoz** | **Zatozte** |
| *joan* (anar) | **Zoaz** | **Zoazte** |
| *ekarri* (portar) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (endur-se) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (estar) | **Egon** / **Lasai** (tranquil!) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## Imperatiu NOR-NORI-NORK: *emadazu*, *esadazu*

Quan dónes una ordre amb doble objecte ("dona'm això", "digues-li allò"), el basc té formes compactes molt útils:

| Català | Basc |
|---|---|
| Dona'm | *Emadazu* / *Eman iezadazu* |
| Digues-me | *Esadazu* / *Esan iezadazu* |
| Dona-li | *Emaiozu* / *Eman iezaiozu* |
| Digues-li | *Esaiozu* / *Esan iezaiozu* |
| Dona'ns | *Emaguzu* |
| Doneu-me | *Emadazue* |

Aquestes formes són llargues d'aprendre; a l'A2 n'hi ha prou amb **emadazu / esadazu / emaiozu / esaiozu** i entendre que venen del verb *eman* / *esan*.

## "Si us plau" i suavitzadors

L'imperatiu en basc **no sona brusc** si hi afegeixes alguna paraula de cortesia:

- *Mesedez* — si us plau
- *Ahal baduzu* — si pots
- *Faborez* (variant col·loquial)
- *Eskerrik asko aldez aurretik* — gràcies per endavant

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## Instruccions (receptes, anuncis, aula)

L'imperatiu és la forma estàndard en:

- **Receptes:** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **Cartells:** *Itxi atea. Ez ukitu. Erabili maskara.*
- **Aula:** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **Metge:** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## Minitext

> *Sukaldari eskolan, irakasleak esaten du:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **Nota cultural:** en basc el to **manaire** de l'imperatiu s'atenua amb l'entonació i el context, no tantes vegades amb perífrasis ("podries..."). Acompanyar l'ordre amb *mesedez* o amb un somriure sol ser suficient. Si vols una cosa més cortesa, digues *eman ahal didazu...?* (em pots donar...?).
