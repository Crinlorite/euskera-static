Умение просить конкретное количество — это разница между «одним яблоком» и «килограммом яблок». Схема в баскском языке очень регулярна и всегда одна и та же.

## Основная схема

> **КОЛИЧЕСТВО + ПРОДУКТ (без артикля)**

| Баскский | Русский |
|---|---|
| *kilo bat sagar* | килограмм яблок |
| *bi kilo tomate* | два килограмма томатов |
| *kilo erdi piper* | полкило перцев |
| *200 g txorizo* | 200 граммов чоризо |
| *litro bat ur* | литр воды |
| *litro erdi esne* | пол-литра молока |
| *dozena bat arrautza* | дюжина яиц |
| *pakete bat makarroi* | пачка макарон |
| *botila bat ardo* | бутылка вина |
| *lata bat tomate* | банка томатов |

> **Внимание:** продукт используется **без артикля** (*sagar*, а не *sagarra*). Это важная особенность, которая усваивается с практикой.

## Сначала число, потом продукт

Порядок слов важен:

- *Bi kilo sagar* — два килограмма яблок (ПРАВИЛЬНО)
- ~~Sagar bi kilo~~ — так не говорят

## Приблизительное количество

| Баскский | Русский |
|---|---|
| *gehiago* | больше |
| *gutxiago* | меньше |
| *pixka bat* | немного |
| *asko* | много |
| *gutxi* | мало |
| *nahikoa* | достаточно |

Типичные примеры в овощной лавке:

- *Gehiago, mesedez.* — Ещё немного, пожалуйста.
- *Hori da, nahikoa da.* — Да, этого достаточно.
- *Gutxiago, mesedez.* — Поменьше, пожалуйста.

## Типовые фразы

- *Eman kilo bat sagar eta dozena bat arrautza, mesedez.* — Дайте, пожалуйста, килограмм яблок и дюжину яиц.
- *Litro bat esne hartuko dut.* — Я возьму литр молока.
- *Bi botila ur, mesedez.* — Две бутылки воды, пожалуйста.

> **Культурная заметка:** на рынках (azoka) и традиционных площадях всё по-прежнему взвешивают «на глаз»: вы просите *kilo bat sagar*, и продавец доводит до нужного веса. Часто можно услышать *pixka bat gehiago, mesedez*, пока стрелка весов поднимается.
