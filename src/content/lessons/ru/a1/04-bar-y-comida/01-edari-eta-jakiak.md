Большая часть социальной жизни в Стране Басков проходит в **taberna** (баре). Знание основных напитков и блюд на баскском языке сразу откроет перед вами двери: компания друзей, поездка в новый город, *poteo*. Начнём со словарного запаса.

## Кофе и его разновидности

Кофе — это, вероятно, то, что вы будете заказывать чаще всего. У него есть несколько видов:

| Euskera | Русский |
|---|---|
| *kafea* | кофе (в общем смысле) |
| *kafe hutsa* | чёрный кофе (буквально: "чистый/пустой кофе") |
| *kafesnea* | кофе с молоком (от *kafe* + *esne*) |
| *kafe ebakia* | кортадо (*ebaki* = "отрезанный") |
| *kafe deskafeinatua* | кофе без кофеина |
| *infusioa* | травяной чай / настой |
| *tea* | чай |

> *Kafesne* буквально означает "кофе-молоко". В баскском языке многие составные слова образуются таким образом, без дефиса, причём главное слово ставится в конце.

## Другие напитки

| Euskera | Русский |
|---|---|
| *ura* | вода |
| *zumoa* | сок |
| *esnea* | молоко |
| *ardoa* | вино |
| *ardo gorria* | красное вино |
| *ardo zuria* | белое вино |
| *garagardoa* | пиво |
| *zuritoa* | маленький бокал пива (типичный) |
| *sagardoa* | сидр |
| *txakolina* | чаколи (баскское белое вино) |
| *patxarana* | пачаран |

> Три любопытных слова: **sagardo** (сидр) = *sagar* (яблоко) + *ardo* (вино); **garagardo** (пиво) = *garagar* (ячмень) + *ardo*; **txakolina** — это молодое и лёгкое белое вино, визитная карточка Страны Басков.

## Простые закуски в баре

Чтобы закусить то, что вы пьёте:

| Euskera | Русский |
|---|---|
| *ogia* | хлеб |
| *gazta* | сыр |
| *urdaiazpikoa* | хамон |
| *tortilla* | тортилья (картофельная) |
| *patata frijituak* | картофель фри |
| *gozokia* | сладость (в общем смысле) |
| *txokolatea* | шоколад |

## Артикль `-a`

Почти все эти слова имеют окончание **`-a`**, когда они употребляются в предложении в "нейтральной" форме: это определённый артикль.

- *Ardoa gustatzen zait.* — Мне нравится вино.
- *Ura nahi dut.* — Я хочу воды.

Когда вы просите "один", окончание `-a` исчезает и появляется **bat** ("один/одна"):

- *Kafe **bat**, mesedez.* — Один кофе, пожалуйста.
- *Garagardo **bat**.* — Одно пиво.

> В уроке 3 вы рассмотрите это подробнее. А пока запомните формы с окончанием `-a`, чтобы узнавать их в меню бара.
