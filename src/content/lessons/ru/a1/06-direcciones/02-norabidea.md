Когда кто-то спрашивает вас, как куда-то добраться, или когда вы заблудились и спрашиваете сами, вам понадобится несколько глаголов в повелительном наклонении и наречий направления. В этом уроке мы собрали самое необходимое.

## Основные повелительные формы

В баскском языке утвердительная форма повелительного наклонения глаголов движения очень проста:

| Форма | Инфинитив | Значение |
|---|---|---|
| **Jo** | jo | ударяй / направляйся (jo ezkerrera = поверни налево) |
| **Segi** / **Jarraitu** | segitu / jarraitu | следуй, продолжай |
| **Hartu** | hartu | возьми (hartu kale hau = иди по этой улице) |
| **Igo** | igo | поднимайся |
| **Jaitsi** | jaitsi | спускайся |
| **Sartu** | sartu | входи |
| **Irten** | irten | выходи |
| **Zeharkatu** | zeharkatu | пересекай |
| **Iritsi** / **heldu** | iritsi / heldu | доходи (… arte = «до…») |

> *Jo* буквально означает «ударять», но метафорически используется в значении «направляться»: **jo ezkerrera** = «поверни налево».

## Наречия и указатели направления

| Баскский | Русский |
|---|---|
| *ezkerra* | лево |
| *eskuina* | право |
| *aurrera* | вперёд |
| *atzera* | назад |
| *zuzen* | прямо |
| *gora* | вверх |
| *behera* | вниз |

> Обратите внимание: для указания **направления** используется суффикс `-ra` (который вы подробно изучите в уроке 03): *ezkerre-ra* (налево), *aurre-ra* (вперёд), *atze-ra* (назад). То же самое для *gora* и *behera*.

## Типичные ориентиры

| Баскский | Русский |
|---|---|
| *semaforoa* | светофор |
| *bidegurutzea* | перекрёсток |
| *zebrabidea* | пешеходный переход («зебра») |
| *biribilgunea* / *errotonda* | круговое движение |
| *aldapa* | подъём, спуск |
| *eskailerak* | лестница |
| *zubia* | мост |
| *errepidea* | дорога, шоссе |
| *kalea* | улица |

## Типовые фразы

- **Jo ezkerrera bidegurutzean.** — Поверни налево на перекрёстке.
- **Segi aurrera semaforora arte.** — Иди прямо до светофора.
- **Zeharkatu zebrabidea.** — Перейди пешеходный переход.
- **Igo eskailerak eta sartu eraikinean.** — Поднимись по лестнице и войди в здание.
- **Jaitsi aldapa, eta gero jo eskuinera.** — Спустись по склону, а затем поверни направо.
- **Egin atzera; gehiegi joan zara.** — Вернись назад, ты прошёл слишком далеко.

## Как спросить и объяснить дорогу

> — *Barkatu, **non dago** udaletxea?* — Простите, где находится мэрия?
>
> — ***Segi aurrera** semaforora arte. Han **jo eskuinera** eta **zeharkatu** plaza. Udaletxea elizaren ondoan dago.* — Идите прямо до светофора. Там поверните направо и перейдите площадь. Мэрия находится рядом с церковью.
>
> — *Eta gertu **dago**?* — А это близко?
>
> — *Bai, oso gertu. Bost minutu oinez.* — Да, очень близко. Пять минут пешком.

> **Лайфхак:** многие указания строятся по одной и той же схеме: повелительное наклонение (*jo*, *segi*, *zeharkatu*) + место с суффиксом (*ezkerrera*, *semaforora*, *zebrabidea*). Если вы запомните эту схему, то сможете составлять длинные инструкции, комбинируя части.
