В баскском языке для обозначения минут используются три основные конструкции: **eta erdiak** (половина), **eta laurden** (четверть) и **gutxi** (без). Главное — знать, что и куда ставится.

## «Половина» — особый случай

В отличие от других конструкций, при использовании **eta erdiak** («половина») час тоже ставится во множественное число, как и само слово *erdiak* (букв. «половины»):

| Время | Euskera |
|---|---|
| 1:30 | **Ordu bat eta erdiak dira** |
| 2:30 | **Ordu bi eta erdiak dira** |
| 3:30 | **Hiru eta erdiak dira** |
| 4:30 | **Lau eta erdiak dira** |
| 5:30 | **Bost eta erdiak dira** |
| 7:30 | **Zazpi eta erdiak dira** |

> Обратите внимание: с *eta erdiak* числительное употребляется **без -ak** (*bost*, а не *bostak*), так как показатель множественного числа уже есть в слове *erdiak*.

## «Четверть» и минуты после часа

Когда нужно сказать, что прошло несколько минут после ровного часа, используется формула **ЧАС-ak eta МИНУТЫ**:

| Время | Euskera |
|---|---|
| 3:05 | **Hirurak eta bost dira** |
| 4:10 | **Laurak eta hamar dira** |
| 5:15 | **Bostak eta laurden dira** |
| 6:20 | **Seiak eta hogei dira** |
| 7:25 | **Zazpiak eta hogeita bost dira** |

**Laurden** означает «четверть», поэтому **eta laurden** — это «четверть» (после часа).

## «Без» — gutxi ставится после

Начиная с половины часа, мы говорим о времени относительно следующего часа, используя слово **gutxi** («без»). Порядок слов такой: **СЛЕДУЮЩИЙ ЧАС-ak + МИНУТЫ + gutxi**.

| Время | Euskera |
|---|---|
| 6:35 | **Zazpiak hogeita bost gutxi dira** |
| 7:40 | **Zortziak hogei gutxi dira** |
| 8:45 | **Bederatziak laurden gutxi dira** |
| 9:50 | **Hamarrak hamar gutxi dira** |
| 10:55 | **Hamaikak bost gutxi dira** |

> Для русскоязычных самое непривычное то, что **gutxi** ставится **после** числительного, а не перед ним. *Bederatziak laurden gutxi* дословно переводится как «девять четверть без».

## Сводная таблица

| Понятие | Ключевое слово | Положение |
|---|---|---|
| Половина | *eta erdiak* | после часа; числительное используется без -ak |
| Четверть | *eta laurden* | после часа с -ak |
| X минут после | *eta + число* | после часа с -ak |
| Без четверти | *laurden gutxi* | после следующего часа с -ak |
| Без X минут | *число + gutxi* | после следующего часа с -ak |

## Пример диалога

> *— Zer ordu da?*
>
> *— **Zazpiak eta laurden dira.*** (Четверть восьмого.)
>
> *— Eta orain?*
>
> *— **Zortziak laurden gutxi dira.*** (Без четверти восемь.)

> **Заметка о культуре:** во многих баскских деревнях церковные колокола до сих пор отбивают часы и четверти. Если остановиться и прислушаться, слух привыкнет к этому ритму раньше, чем выработается автоматизм в речи.
