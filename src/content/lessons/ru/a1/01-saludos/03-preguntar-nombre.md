Есть два одинаково правильных способа спросить имя:

- **Zein da zure izena?** — «Какое твоё имя?»
- **Zure izena zein da?** — порядок слов может меняться; оба варианта естественны.

## Структура

- **Zein** = какой / какая / какое (в вопросах с выбором)
- **izena** = имя (конечное `-a` — это артикль)
- **zure** = твой / твоё / твоя
- **da** = есть

## Как ответить

У тебя есть два варианта, оба одинаково правильные:

1. **Nire izena Egoitz da.** — «Моё имя — Egoitz».
2. **Egoitz naiz.** — «Я Egoitz». (по схеме из предыдущего урока)

> Основные притяжательные местоимения: *nire* (мой), *zure* (твой), *bere* (его/её). Ты встретишь их ещё много раз — начни привыкать к ним уже сейчас.
