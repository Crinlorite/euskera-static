В баскском языке есть два глагола «быть», в то время как в русском мы чаще всего обходимся одним. Вы уже знаете **izan** («быть» для постоянных качеств). Теперь познакомимся с **egon**, который тоже переводится как «быть» или «находиться» и используется для **временных состояний**: как кто-то себя чувствует сегодня, прямо сейчас, в данный момент.

## Парадигма egon

| Местоимение | Egon | Русский |
|---|---|---|
| ni | **nago** | (я) есть / нахожусь |
| hi | **hago** | (ты) есть / находишься (неформ., на A1 не используется) |
| zu | **zaude** | (ты) есть / находишься |
| hura | **dago** | (он/она/оно) есть / находится |
| gu | **gaude** | (мы) есть / находимся |
| zuek | **zaudete** | (вы) есть / находитесь |
| haiek | **daude** | (они) есть / находятся |

> Обратите внимание, что некоторые из этих форм вы уже видели: в *zer moduz?* естественный ответ — *ondo nago* («я в порядке» / «у меня всё хорошо»). Окончания похожи на окончания *izan* (*-zu* / *-zue* / *-de*), но корень другой (`nag-`, `daud-`).

## Типичные состояния: без -a на конце

Главная ловушка: когда прилагательное идёт с **egon**, оно **НЕ** имеет окончания `-a`. Сравните:

- **Izan** (постоянное качество): *Ni alegre soy* → *Ni alai**a** naiz.* (с `-a`)
- **Egon** (временное состояние): *Yo estoy contenta hoy* → *Ni pozik nago.* (без `-a`)

| Состояние | Русский |
|---|---|
| *pozik* | радостный, довольный |
| *triste* | грустный |
| *nekatuta* | уставший/ая |
| *haserre* | рассерженный/ая |
| *lasai* | спокойный (в данный момент) |
| *urduri* | нервный (прямо сейчас) |
| *gaixorik* | больной |
| *ondo* | хорошо |
| *gaizki* | плохо |

> Некоторые из этих слов имеют формы на `-ik` (*pozik*, *gaixorik*) или `-ta` (*nekatuta*, *ezkonduta*); другие являются наречиями (*ondo*, *gaizki*); третьи — просто неизменяемыми словами (*haserre*, *triste*). Ни одно из них не принимает типичное для прилагательных с *izan* окончание `-a`.

## Типичные фразы

- *Ni pozik **nago**.* — Я рада.
- *Maialen triste **dago**.* — Майален грустит.
- *Zu nekatuta **zaude**?* — Вы устали?
- *Gu haserre **gaude**.* — Мы рассержены.
- *Haiek gaixorik **daude**.* — Они больны.

## Как спросить о состоянии

- **Nola zaude?** — Как вы?
- **Zer moduz?** — Как дела? (самый разговорный вариант)
- **Ondo, eskerrik asko. Eta zu?** — Хорошо, спасибо. А вы?
- **Nekatuta nago.** — Я устал(а).
- **Pixka bat gaixorik nago.** — Я немного приболел(а).

## Egon также указывает на местоположение

Помимо состояний, **egon** используется, чтобы сказать, **где** кто-то или что-то находится:

- *Etxean nago.* — Я дома.
- *Maialen lanean dago.* — Майален на работе.
- *Liburuak mahaian daude.* — Книги на столе.

> Это любопытным образом пересекается с *izan*: *Ni ikaslea naiz* («я студент» = профессия, качество), но *Ni ikastetxean nago* («я в школе» = местоположение). На следующем уроке мы рассмотрим это различие подробнее.
