Когда вы уже умеете говорить «находится в Х», следующий шаг — сказать, **где именно**: наверху, внизу, рядом, сзади… В баскском языке эти положения всегда строятся по схеме **ориентир + положение**.

## Основные положения

| Euskera | Русский |
|---|---|
| *aurrean* | спереди |
| *atzean* | сзади |
| *ondoan* | рядом |
| *gainean* | на, над |
| *azpian* | под |
| *artean* | между |
| *ezkerrean* | слева |
| *eskuinean* | справа |
| *barruan* | внутри |
| *kanpoan* | снаружи |
| *erdian* | посередине, в центре |

## Как их строить: -(r)en + положение

Основная формула: **(ориентир)-(r)en + положение**. Ориентир принимает окончание родительного падежа `-(r)en` (что соответствует русскому родительному падежу «кого/чего»):

| Euskera | Русский (буквально) |
|---|---|
| **mahaiaren gainean** | на столе (букв. «стола, на») |
| **etxearen aurrean** | перед домом |
| **elizaren atzean** | за церковью |
| **parkearen ondoan** | рядом с парком |
| **kutxaren barruan** | внутри коробки |
| **bi mendien artean** | между двумя горами |

Схема: сначала ориентир, **затем** положение. Это прямо противоположно тому, как в русском языке.

## Примеры полных предложений

- **Liburua mahaiaren gainean dago.** — Книга на столе.
- **Katua aulkiaren azpian dago.** — Кошка под стулом.
- **Eliza plazaren erdian dago.** — Церковь в центре площади.
- **Botika eskolaren ondoan dago.** — Аптека рядом со школой.
- **Ni Maiteren eta Anaren artean nago.** — Я нахожусь между Maite и Ana.

## Наречия места: hemen / hor / han

Чтобы быстро указать на место, есть три наречия — и, внимание, это **три дистанции**, а не две, как в русском:

| Euskera | Русский | Когда |
|---|---|---|
| *hemen* | здесь | рядом с говорящим |
| *hor* | там | рядом со слушающим |
| *han* | вон там | далеко от обоих |

> Эти три наречия соответствуют указательным местоимениям *hau / hori / hura* и их длинным формам местного падежа *honetan / horretan / hartan* («в этом / в том / в том (дальнем)»).

Быстрые примеры:

- **Hemen** taberna bat dago. — Здесь есть бар.
- **Hor** parkea dago. — Там парк.
- **Han** dago euskaltegia. — Вон там эускальтеги.

## Мини-диалог: игра в прятки

> — *Pilota mahaiaren azpian dago?* — Мяч под столом?
>
> — *Ez, pilota ez dago mahaiaren azpian.* — Нет, мяч не под столом.
>
> — *Aulkiaren atzean dago?* — Он за стулом?
>
> — *Bai, hor dago!* — Да, он там!

> **Лайфхак:** все эти слова уже содержат в себе суффикс `-an` (*aurr-ean*, *atz-ean*, *azp-ian*…). Ничего больше добавлять не нужно.
