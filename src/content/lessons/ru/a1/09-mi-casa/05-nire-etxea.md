Этот урок объединяет всё из темы 9: комнаты, мебель, домашние дела и то, с кем вы живёте. Цель — научиться **описывать свой дом** простыми фразами, как будто вас спрашивают на занятии или в неформальной беседе.

## Основные вопросы

| Вопрос | Русский |
|---|---|
| *Non dago zure etxea?* | Где твой дом? |
| *Nolakoa da?* | Какой он? |
| *Zenbat gela ditu?* | Сколько в нём комнат? |
| *Norekin bizi zara?* | С кем ты живёшь? |
| *Zenbatgarren solairuan bizi zara?* | На каком этаже ты живёшь? |
| *Etxeak badu igogailua / balkoia / terraza?* | В доме есть лифт / балкон / терраса? |

## Полезные прилагательные для описания дома

| Баскский | Русский |
|---|---|
| *handia* | большой |
| *txikia* | маленький |
| *argitsua* | светлый |
| *iluna* | тёмный |
| *berria* | новый |
| *zaharra* | старый |
| *lasaia* | тихий |
| *zaratatsua* | шумный |
| *erosoa* | удобный |
| *garestia* | дорогой |
| *merkea* | дешёвый |

> Вспомните конструкцию **NOLAKOA da?**, которую мы уже видели в других разделах: в ответе используется прилагательное + окончание `-a` + глагол *izan*. Пример: *Nire etxea **handia da**.* — Мой дом большой.

## Пример текста

Вот простой текст с описанием дома. Прочитайте его вслух и обратите внимание на конструкции.

> *Ni Iruñean bizi naiz, auzo lasai batean. Nire etxea ez da oso handia: hiru gela ditu — bi logela eta egongela bat — sukaldea eta komuna. Egongela argitsua da, eta balkoi bat dauka. Hirugarren solairuan dago, eta etxeak igogailua du.*
>
> *Bikotekidearekin bizi naiz. Berak bazkaria prestatzen du, eta nik ontziak garbitzen ditut. Asteburuetan biok elkarrekin egiten dugu erosketa.*

## Ваша очередь: опишите свой дом

Составьте свой собственный абзац, отвечая в следующем порядке:

1. **Non bizi zara?** (Где ты живёшь?) → *X-(e)an bizi naiz.*
2. **Nolakoa da etxea?** (Какой он?) → *Nire etxea handia / argitsua / lasaia da.*
3. **Zenbat gela ditu?** (Сколько в нём комнат?) → *Bi / Hiru / Lau gela ditu.*
4. **Zer dago etxean?** (Что в нём есть?) → *Sukaldea, egongela, bi logela eta komun bat ditu.*
5. **Norekin bizi zara?** (С кем ты живёшь?) → *Bakarrik / Gurasoekin / Lagunekin bizi naiz.*
6. **Etxeko lanak nork egiten ditu?** (Кто делает работу по дому?) → *Nik egunero garbitzen dut* / *Pisukideen artean banatzen ditugu.*

## Итоговый словарь

| Баскский | Русский |
|---|---|
| *etxebizitza* | жильё |
| *etxejabea* | владелец |
| *alokairua* | аренда |
| *errenta* | арендная плата / ежемесячная плата |
| *auzoa* | район |
| *erdigunea* | центр (города) |
| *aldiriak* | окраина / пригород |

> **Совет:** когда будете рассказывать о своём доме на занятии, не пытайтесь перевести каждую деталь. Используйте короткие и правильно построенные фразы. *"Bi logela ditut, sukalde txiki bat eta egongela handia"* — это лучшее описание, чем длинное предложение с кучей ошибок.
