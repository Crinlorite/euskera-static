Один из основных вопросов, чтобы познакомиться с кем-то, это **Norekin bizi zara?** — «С кем ты живёшь?». В ответе используется суффикс **`-(r)ekin`**, который называется **социатив** и соответствует русскому предлогу «с» (в значении совместности) в баскском языке.

## Суффикс `-rekin`

Он добавляется к существительному, уже имеющему артикль:

| Существительное | + -(r)ekin | Значение |
|---|---|---|
| laguna (друг/подруга) | **lagunarekin** | с другом/подругой |
| ama (мама) | **amarekin** | с мамой |
| anaia (брат) | **anaiarekin** | с братом |
| txakurra (собака) | **txakurrarekin** | с собакой |
| bikotekidea (партнёр) | **bikotekidearekin** | с партнёром |

> С именами собственными и со словом *bat* суффикс **-(e)kin** добавляется напрямую, без артикля: *Miren + ekin → Mirenekin* (с Miren), *lagun batekin* (с (одним) другом).

## Множественное число

| Множественное число | + -ekin | Значение |
|---|---|---|
| gurasoak (родители) | **gurasoekin** | с родителями |
| lagunak (друзья) | **lagunekin** | с друзьями |
| pisukideak (соседи по квартире) | **pisukideekin** | с соседями |
| seme-alabak (дети) | **seme-alabekin** | с детьми |

## Жить одному

Если вы живёте один/одна, использовать `-rekin` не нужно:

- **Bakarrik bizi naiz.** — Я живу один/одна.
- **Bakarrik bizi naiz, baina katu batekin.** — Я живу один/одна, но с котом.

## Самые распространённые варианты совместного проживания

| Ситуация | Как сказать |
|---|---|
| Один/одна | *Bakarrik bizi naiz.* |
| С родителями | *Gurasoekin bizi naiz.* |
| С партнёром | *Bikotekidearekin bizi naiz.* |
| С мужем / женой | *Senarrarekin / Emaztearekin bizi naiz.* |
| С соседями по квартире | *Pisukideekin bizi naiz.* |
| С детьми | *Seme-alabekin bizi naiz.* |
| С другом / друзьями | *Lagun batekin / Lagunekin bizi naiz.* |

## Аренда или собственность

- **Alokairuan bizi naiz.** — Я снимаю жильё.
- **Nire pisua da.** — Это моя квартира (в собственности).
- **Errenta gora doa.** — Аренда растёт. *(разг.)*

## Типичный разговор

> — *Kaixo Maialen! Norekin bizi zara?*
>
> — *Bi pisukiderekin bizi naiz Iruñean. Eta zu?*
>
> — *Ni bakarrik, baina txakur batekin. Etxea handia da?*
>
> — *Ez, txikia. Hiru logela ditu.*

> **Примечание:** *bikotekide* — это современное и нейтральное слово, которое подходит как для женатых, так и для неженатых пар, гетеро- и гомосексуальных. Для обозначения «мужа» и «жены» по-прежнему используются **senarra** и **emaztea**.
