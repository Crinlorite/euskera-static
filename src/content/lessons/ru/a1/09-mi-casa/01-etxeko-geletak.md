Начнём с самого основного в любом жилище: **комнат**. Общее слово для «зала / комнаты» — **gela**, и большинство названий помещений образуются путём сочетания корня с `-gela`.

## Основная лексика

| Euskera | Русский |
|---|---|
| *etxea* | дом |
| *pisua* | квартира (жильё в здании) |
| *gela* | комната / зал |
| *sukaldea* | кухня |
| *logela* | спальня |
| *komuna* | ванная / туалет |
| *egongela* | гостиная |
| *sarrera* | прихожая |
| *korridorea* / *pasabidea* | коридор |
| *balkoia* | балкон |
| *terraza* | терраса |

## Как образуются некоторые названия

Баскский язык очень прозрачен в этих словах. Если вы посмотрите, как они составлены, вы их лучше запомните:

- **logela** → *lo* (сон) + *gela* (комната) = «комната для сна» → спальня
- **egongela** → *egon* (быть, находиться) + *gela* = «комната для пребывания» → гостиная
- **sukaldea** → *su* (огонь) + *aldea* (зона) = «зона огня» → кухня

> **Komuna** и **bainugela** — синонимы: *komuna* — это повседневное слово, в то время как *bainugela* (буквально «комната для купания») — более формальное.

## Здание: этаж и лифт

| Euskera | Русский |
|---|---|
| *solairua* | этаж (1-й, 2-й…) |
| *igogailua* | лифт |
| *eskailera* | лестница |
| *ataria* | подъезд |

Чтобы сказать, на каком этаже вы живёте:

- *Hirugarren solairuan bizi naiz.* — Я живу на третьем этаже.
- *Etxeak igogailua du.* — В доме есть лифт.

## Полезные вопросы

- **Zenbat gela ditu zure etxeak?** — Сколько комнат в твоём доме?
- **Zenbat logela ditu?** — Сколько в нём спален?
- **Non dago sukaldea?** — Где находится кухня?
- **Etxeak badu balkoirik?** — В доме есть балкон?

> **Культурная заметка:** в Наварре и испано-баскской зоне принято говорить *pisua* о городской квартире и *etxea* о семейном/деревенском доме. В повседневной жизни они без проблем смешиваются.
