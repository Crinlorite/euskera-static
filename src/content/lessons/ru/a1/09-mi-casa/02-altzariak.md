В каждой комнате есть своя мебель. Общее слово для "мебели" — **altzaria** (во множественном числе *altzariak*). Давайте пройдёмся по комнатам дома.

## Egongelan — В гостиной

| Euskera | Русский |
|---|---|
| *sofa* | диван |
| *besaulkia* | кресло |
| *mahaia* | стол |
| *aulkia* | стул |
| *kuxina* | подушка |
| *lanpara* | лампа |
| *telebista* | телевизор |
| *apalategia* | стеллаж |

## Как использовать это в предложении

Вспомните, что вы уже знаете о **ukan** (иметь), и примените это:

- *Sukaldean hozkailu bat dut.* — На кухне у меня есть холодильник.
- *Egongelan bi besaulki ditugu.* — В гостиной у нас есть два кресла.
- *Logelan ez dut posterrik.* — В спальне у меня нет постеров. *(отрицание с `-rik`)*

> **Примечание:** *garbigailua* (стиральная машина) и *ontzi-garbigailua* (посудомоечная машина) имеют общий корень *garbi-* (чистить). Это хороший пример того, как в баскском языке образуются очень прозрачные по значению составные слова.
