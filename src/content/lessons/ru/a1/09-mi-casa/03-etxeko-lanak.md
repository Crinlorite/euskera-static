На этом уроке ты выучишь основные глаголы, чтобы говорить о **etxeko lanak** (домашних делах). В баскском языке глаголы обычно даются в форме **причастия** (`-tu`, `-i`, `-n`), которая является «словарной» формой: *garbitu*, *prestatu*, *jaso*…

## Ключевые глаголы

| Euskera | Русский |
|---|---|
| *garbitu* | убирать / чистить |
| *prestatu* | готовить |
| *jaso* | собирать / убирать |
| *jantzi* | одевать / надевать |
| *atera* | выносить / вынимать |
| *zabaldu* | развешивать / открывать |
| *lisatu* | гладить |
| *paseatu* | гулять / выгуливать |
| *erosi* | покупать |

## Типичные дела

| Дело | Как сказать |
|---|---|
| Заправлять кровать | *ohea jantzi* |
| Мыть посуду | *ontziak garbitu* / *harrikoa egin* |
| Пылесосить | *xurgagailua pasa* |
| Развешивать бельё | *arropa zabaldu* |
| Гладить бельё | *arropa lisatu* |
| Убирать ванную | *komuna garbitu* |
| Выносить мусор | *zaborra atera* |
| Готовить еду | *bazkaria prestatu* |
| Делать покупки | *erosketak egin* |
| Выгуливать собаку | *txakurra paseatu* |

## От словарной формы к обычному настоящему времени

Когда действие повторяется регулярно (каждый день, каждую неделю…), глагол меняется на форму с `-tzen` + вспомогательный глагол **dut/duzu/du…** (который ты уже знаешь из темы *ukan*):

| Лицо | Пример | Русский |
|---|---|---|
| Nik | *Nik etxea **garbitzen dut**.* | Я убираю дом. |
| Zuk | *Zuk arropa **lisatzen duzu**.* | Ты гладишь бельё. |
| Berak | *Aitak bazkaria **prestatzen du**.* | Мой отец готовит еду. |
| Guk | *Guk erosketak **egiten ditugu**.* | Мы делаем покупки. |

> На этом уроке не нужно в совершенстве владеть спряжением. Просто запомни схему **`-tzen` + dut/du** для разговора о рутине.

## Частота

Чтобы сказать, как часто ты делаешь какое-то дело:

- **egunero** — каждый день
- **astean behin** — раз в неделю
- **astean bitan / hirutan** — два / три раза в неделю
- **noizean behin** — время от времени
- **inoiz ez** — никогда

> *Nire etxean nik **astean behin** lisatzen dut, baina **egunero** garbitzen dut sukaldea.* — У себя дома я глажу раз в неделю, но кухню убираю каждый день.

## Как спросить, кто что делает

- **Nork garbitzen ditu ontziak?** — Кто моет посуду?
- **Nor arduratzen da arropaz?** — Кто отвечает за бельё?
- **Zuri gustatzen zaizu sukaldatzea?** — Тебе нравится готовить?

> **Культурная заметка:** опросы о распределении домашних обязанностей — это классика в учебниках *euskaltegi* — и не без причины. Эта лексика очень полезна для реальных разговоров с друзьями и семьёй.
