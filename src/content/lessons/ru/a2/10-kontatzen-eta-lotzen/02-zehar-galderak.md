До сих пор ты задавал прямые вопросы: *Etorriko da?* Теперь ты научишься задавать вопросы **косвенно**: *не знаю, **придёт ли он***, *спроси его, **есть ли у него время***. Это *zehar-galderak* (косвенные вопросы), и их секрет — в одной букве: **-n**.

## Правило: вспомогательный глагол принимает -n

| Прямой вопрос | Косвенный вопрос |
|---|---|
| *Etorriko **da**?* | *Ez dakit etorriko **den*** |
| *Nor **da**?* | *Ez dakit nor **den*** |
| *Non **dago**?* | *Ez dakit non **dagoen*** |
| *Zer nahi **du**?* | *Ez dakit zer nahi **duen*** |
| *Denborarik **dauka**?* | *Galdetu ea denborarik **daukan*** |

Как присоединяется **-n**: *da → den* · *dago → dagoen* · *du → duen* · *dauka → daukan* · *gara → garen* · *dute → duten*. (Если оканчивается на гласную — -n; в остальных случаях — -en. Через пару дней ты будешь делать это на слух.)

## "Ea" — универсальное слово

Для вопросов типа «да/нет» в баскском языке добавляется ***ea*** (= «посмотрим, ... ли / ... ли»):

> *Galdetu diot **ea gurekin bazkalduko duen**.* — Я спросил(а) его, будет ли он обедать с нами.
>
> *Ikusiko dugu **ea eguraldi ona egiten duen**.* — Посмотрим, будет ли хорошая погода.
>
> ***Ea garaiz iristen garen**!* — Хоть бы мы успели вовремя!

Это последнее отдельное *ea…!* — чистый разговорный баскский: желание + интрига в одном слове.

## Глаголы, которые их требуют

| Русский | Баскский |
|---|---|
| Я не знаю, ... ли... | *Ez dakit … -(e)n* |
| Ты знаешь, ... ли...? | *Badakizu … -(e)n?* |
| Спроси его, ... ли... | *Galdetu (iezaiozu) ea … -(e)n* |
| Я не помню, ... ли... | *Ez naiz gogoratzen … -(e)n* |
| Я не уверен(а), ... ли... | *Ez nago ziur … -(e)n* |

## В действии

> *— **Badakizu zer ordutan hasten den** kontzertua?*
>
> *— Ez, baina Aneri **galdetuko diot ea dakien**.*
>
> *— Eta **ea sarrerarik geratzen den** ere galdetu, mesedez!*
>
> *— Lasai. **Ea zorte ona dugun**!*

## Контраст с -la (ложный друг)

Не путай косвенный вопрос с косвенным утверждением (урок 04):

> *Esan dit etorriko **dela**.* — Он(а) сказал(а) мне, **что** придёт. (утверждение → **-la**)
>
> *Galdetu dit **ea** etorriko **den**.* — Он(а) спросил(а) меня, придёт **ли** он/она. (вопрос → **-n**)

**Что = -la · Ли = (ea) -n.** С этой шпаргалкой урок можно считать усвоенным.
