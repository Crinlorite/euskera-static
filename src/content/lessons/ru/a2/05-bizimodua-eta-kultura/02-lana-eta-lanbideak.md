Уровень A2 открывает вам мир **работы** за рамками «я студент / я преподаватель». Теперь вы начинаете говорить о:

- Типах работы и рабочем дне.
- Собеседовании.
- Резюме и опыте.
- Составлении **описания работы**, которую вы имеете или хотите получить.

## Профессии — расширенное повторение

На уровне A1 мы рассмотрели классические профессии (*medikua, ikaslea, irakaslea, sukaldaria*). На A2 вы добавите:

| Испанский | Баскский |
|---|---|
| Журналист(ка) | *kazetaria* |
| Программист(ка) | *programatzailea* |
| Дизайнер(ка) | *diseinatzailea* |
| Инженер | *ingeniaria* |
| Архитектор | *arkitektoa* |
| Адвокат | *abokatua* |
| Нотариус | *notarioa* |
| Предприниматель(ница) | *enpresari* |
| Торговец / Коммерсант | *merkataria* |
| Водитель | *gidaria* |
| Пожарный | *suhiltzailea* |
| Госслужащий(ая) | *funtzionarioa* |
| Помощник / Ассистент | *laguntzailea* |
| Продавец / Продавщица | *saltzailea* |
| Каменщик | *igeltseroa* |
| Сантехник | *iturgina* |
| Электрик | *elektrizista* |

> **Лайфхак:** многие профессии оканчиваются на **-le**, **-tzaile** или **-ari**: *saltzaile, irakasle, gidari, sukaldari, kazetari*. Это продуктивные суффиксы.

## Суффикс -**dun** («имеющий/носящий»)

Вспомните этот суффикс с уровня A1 — он продуктивен в названиях профессий:

| Испанский | Баскский |
|---|---|
| Говорящий на баскском языке | *euskalduna* |
| Чемпион (тот, у кого есть *txapela*) | *txapelduna* |
| Дальнобойщик / Водитель грузовика | *kamioiduna* |

## Типичные фразы на собеседовании

| Испанский | Баскский |
|---|---|
| Расскажите немного о себе | *Konta iezadazu zerbait zuri buruz* |
| Почему вы хотите эту должность? | *Zergatik nahi duzu lanpostu hau?* |
| Какой у вас опыт? | *Zer esperientzia daukazu?* |
| Я говорю на баскском, испанском и английском | *Euskaraz, gaztelaniaz eta ingelesez hitz egiten dut* |
| Я свободен(на) с июня | *Ekainetik aurrera nago eskuragarri* |
| Какую зарплату вы хотите? | *Zer **soldata** nahi duzu?* |

## Относительные придаточные предложения с -**(e)n**

Чтобы описывать свою работу более сложными конструкциями, вам пригодятся **относительные придаточные**:

> **verbo conjugado + -(e)n + sustantivo**

| Испанский | Баскский |
|---|---|
| Работа, которая у меня есть | *Daukadan lana* |
| Компания, в которой я работаю | *Lan egiten dudan enpresa* |
| Коллеги, которых я знаю | *Ezagutzen ditudan lankideak* |
| Зарплата, которую я получаю | *Jasotzen dudan soldata* |
| Курс, который я прошёл(ла) | *Egin nuen ikastaroa* |

> **Как образуется:** глагол в настоящем или прошедшем времени + суффикс **-(e)n** + существительное.
>
> *dut → dudan*, *du → duen*, *zen → zen*, *zuen → zuen* (когда слово уже заканчивается на -n, ничего лишнего не добавляется).

> Это ключевой инструмент для уровня A2, который появляется в 5-м модуле в разных контекстах: на собеседовании (*duzun esperientzia*) и в презентациях (*ezagutzen dudan jendea*). На уровне B1 эта тема рассматривается глубже.

## Мини-диалог: lan-elkarrizketa

> *— Egun on. Eseri, mesedez. **Konta iezadazu** zertan **lan egin duzun** orain arte.*
>
> *— Bai. Bost urtez **lan egin dut** Bilboko diseinu-enpresa batean. Han **daukadan zeregina** bezeroentzako proiektuak diseinatzea da.*
>
> *— Ondo. Eta zergatik nahi duzu **lanpostu hau**?*
>
> *— **Iruditzen zait** zuen enpresa **interesgarriagoa dela**, eta nire trebetasunak hobeto erabili **ahal izango ditudala**. **Gainera**, **lanaldi erdiko** modalitatea **eskaintzen duzuelako**, hori asko **interesatzen zait**.*

## Мини-текст: описание работы

> *Lander **kazetari** lanetan dabil hamar urtetik hona. Bilboko egunkari batean **lan egiten du**, **lanaldi osoan**. Goizeko zortzietan hasten da eta bostetan amaitzen du. Berarentzat **garrantzitsuena** albisteak ondo **kontatzea** da. **Soldata** ez da oso handia, baina **gustatzen zaion lana** dauka, eta **lankide jatorrak** ditu.*

> **Культурная справка:** в Стране Басков во многих предложениях о работе в госсекторе (Osakidetza, Eusko Jaurlaritza, муниципалитеты) знание баскского языка оценивается по системе **«профилей»** (PL1, PL2, PL3, PL4). Изучение баскского языка — это не только культурный аспект: для многих государственных должностей это конкурентное преимущество.
