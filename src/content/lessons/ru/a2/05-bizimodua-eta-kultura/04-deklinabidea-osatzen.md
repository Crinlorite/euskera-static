Этот обобщающий урок рассматривает **четыре новых склонения**, которые уровень A2 добавляет к набору падежей A1 (NOR, NORK, NORI, NON, NOREN, NORA, NONDIK, NOREKIN). Именно они встречаются на любом экзамене уровня A2 и дополняют «розу» падежей баскского языка.

## NORENTZAT — для кого (дательный назначения)

> **-(r)entzat** с определённым существительным

| Существительное | Форма | Русский |
|---|---|---|
| niretzat | *niretzat* | для меня |
| zuretzat | *zuretzat* | для тебя |
| beretzat / harentzat | *beretzat* | для него/неё |
| guretzat | *guretzat* | для нас |
| zuentzat | *zuentzat* | для вас |
| haientzat | *haientzat* | для них |
| Lander | *Landerrentzat* | для Ландера |
| la madre | *amarentzat* | для мамы |
| los amigos | *lagunentzat* | для друзей |

> *Hau **zuretzat** da.* — Это для тебя.
>
> *Opari bat erosi dut **Garazirentzat**.* — Я купил(а) подарок для Garazi.
>
> *Liburu hau **gazte ikasleentzat** da.* — Эта книга для молодых студентов.

> **Вариант:** также существует форма **-(r)endako**, синонимичная во многих диалектах: *Garazirendako, niretzako/niretako*. Стандартной является *-rentzat*.

## NORAINO — до (предел)

> **-(r)aino** с существительным (следует правилу NORA: гласная → +raino, согласная → +eraino)

| Русский | Баскский |
|---|---|
| До горы | *mendi**raino*** |
| До Бильбао | *Bilbo**raino*** |
| Досюда | *hona**ino*** |
| Докуда | *nora**ino*** |
| До вершины | *tontorr**eraino*** |

> *Korrika egin dugu **plazaraino**.* — Мы добежали до площади.
>
> *Bilbo**raino** etorri zen eta gero itzuli.* — Он доехал до Бильбао, а потом вернулся.

## NORANTZ — к, в сторону (направление)

> **-(r)antz** с существительным (та же схема, что и у NORA)

| Русский | Баскский |
|---|---|
| К горе / В сторону горы | *mendi**rantz*** |
| К дому / В сторону дома | *etxe**rantz*** |
| На юг / В сторону юга | *hego**rantz*** |
| К тебе / В твою сторону | *zu**rantz*** |

> *Etxe**rantz** abiatu nintzen.* — Я направился к дому.
>
> *Itsaso**rantz** dago etxea.* — Дом смотрит в сторону моря.

> **Разница с NORA (-ra):** *NORA* указывает на конкретный пункт назначения («еду в Бильбао»); *NORANTZ* указывает на приблизительное направление («еду в сторону Бильбао», без гарантии, что доеду).

## ZERGATIK / NORENGATIK — из-за, по причине (каузатив)

Чтобы спросить о причине: **zergatik?** (почему?). Чтобы ответить, используя существительное: **-engatik**.

| Существительное | Форма | Русский |
|---|---|---|
| nigatik | *nigatik* | из-за меня (причина) |
| zugatik | *zugatik* | из-за тебя |
| beragatik / harengatik | *beragatik* | из-за него/неё |
| Lander | *Landerrengatik* | из-за Ландера |
| la madre | *amarengatik* | из-за мамы |
| el amor | *maitasunarengatik* | из-за любви |
| la lluvia | *euriagatik* | из-за дождя |

> *Eskerrik asko **etorri zarelako, niregatik**!* — Спасибо, что пришёл, ради меня!
>
> *Berandu iritsi nintzen **trafikoarengatik**.* — Я опоздал(а) из-за пробки.
>
> *Zergatik egin duzu hori? — **Zugatik**.* — Почему ты это сделал(а)? — Из-за тебя.

> **Примечание:** различайте *-engatik* (причина: «из-за») и *-rentzat* (получатель: «для»). В испанском «por» охватывает оба значения, но в баскском языке они различаются.

## NONGO / NOIZKO — какого места / момента

Вы уже видели *NON* (-an: в) на уровне A1. **NONGO** и **NOIZKO** превращают место или время в **определение** (атрибут):

| Русский | Баскский |
|---|---|
| Люди **из** Бильбао | *Bilbo**ko** jendea* |
| Музей **в** Доностии | *Donostia**ko** museoa* |
| **Сегодняшняя** газета | *Gaur**ko** egunkaria* |
| **Завтрашний** экзамен | *Bihar**ko** azterketa* |
| **Июльский** праздник | *Uztaileko jaia* |

> Это падеж **NONGO/NOIZKO** (-ko / -tako после согласной): «откуда» / «с какого времени» в атрибутивном значении.

| Форма | Для чего |
|---|---|
| **-ko** ед. число | *Bilboko, etxeko, gaurko* |
| **-etako** мн. число | *etxe**etako**, mendi**etako**, urte**etako*** |

> *Atzo**ko** afari**a** ona zen.* — Вчерашний ужин был вкусным.
>
> *Bilbo**ko** etxebizitzak garestiak dira.* — Жильё в Бильбао дорогое.
>
> *Mendi**etako** loreak ederrak dira.* — Горные цветы красивые.

| Падеж | Суффикс | Вопрос | Пример |
|---|---|---|---|
| NORENTZAT | -rentzat | для кого? | *Garazirentzat* |
| NORAINO | -raino | докуда? | *Bilboraino* |
| NORANTZ | -rantz | куда? / в каком направлении? | *etxerantz* |
| NORENGATIK | -engatik | из-за кого/чего? | *euriagatik* |

## Обобщающий мини-текст

> *Joan den astean **Bilboraino** joan ginen autobusez. Helmuga: hiriko **museorako** sarrera bana erostea. **Bilboko jendea** oso jatorra izan zen. Buelta hartzeko, taxi bat hartu genuen **etxerantz**: euri-jasa hain handia zen, ezen autoa **euriagatik** hondatu zen. Azkenean, ordu bat **beranduago** iritsi ginen **Donostiako geltokira**. Hori bai, etxean opari bat zegoen zain: **niretzat**, ama maitearen partez.*

## Визуальное повторение: роза падежей A2

Теперь вы владеете всеми основными падежами:

| Падеж | Вопрос | Суффикс | Пример (etxe) |
|---|---|---|---|
| NOR | кто? что? | -a | *etxea* |
| NORK | кто (совершает действие)? | -ak | *etxeak* (подлежащее) |
| NORI | кому? чему? | -ari | *etxeari* |
| NON | где? | -an | *etxean* |
| NORA | куда? | -ra | *etxera* |
| NONDIK | откуда? | -tik | *etxetik* |
| NOREKIN | с кем? с чем? | -arekin | *etxearekin* |
| NOREN | кого? чего? чей? | -aren | *etxearen* |
| NONGO | откуда (опред.)? | -ko | *etxeko* |
| NORENTZAT | для кого? | -arentzat | *etxearentzat* |
| NORAINO | докуда? | -raino | *etxeraino* |
| NORANTZ | куда? / в каком направлении? | -rantz | *etxerantz* |
| NORENGATIK | из-за кого? | -arengatik | *etxearengatik* |
| -ZAZ / -Z | инструменталис | -z | *etxez* |
| -RIK | партитив (отрицание) | -rik | *etxerik (ez dago)* |

> **Задание A2:** напишите по предложению с каждым падежом, используя существительное *Garazi*. Вы увидите, как весь механизм баскского языка работает на примере одного человека.

> **Педагогическое примечание:** эти склонения — «дверь на уровень B1»: если вы их освоите, то сможете строить предложения, богатые информацией (пункт назначения, причина, определение, направление). На уровне B1 углубляются абстрактные употребления и добавляются ещё несколько падежей (инструменталис с причинным значением, расширенный партитив).
