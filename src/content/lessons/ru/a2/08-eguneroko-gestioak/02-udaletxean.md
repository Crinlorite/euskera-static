Финальный босс взрослой жизни: **бумажная волокита**. Вдохните: десятью удачно подобранными словами (*agiria, hitzordua, bete, epea…*) вы справитесь с любым окошком — на баскском, к тому же, с улыбкой чиновника в подарок.

## Лексика для работы с документами

| Русский | Euskera |
|---|---|
| Мэрия | *udaletxea* |
| Регистрация по месту жительства / зарегистрироваться | *errolda / erroldatu* |
| Справка о регистрации по месту жительства | *errolda-agiria* |
| Документ / справка | *agiria* |
| Удостоверение личности (DNI) | *NANa* |
| Водительское удостоверение | *gidabaimena* |
| Заявление | *eskabidea* |
| Заполнять | *bete* |
| Запись, приём / очередь | *hitzordua / txanda* |
| Срок | *epea* |
| Окошко | *leihatila* |

## Запись на приём (современный ритуал)

> ***Hitzordua eskatu behar da** aurretik, webgunean edo telefonoz.* — Нужно записаться заранее, на сайте или по телефону.
>
> *Hitzordua daukat **gaurko, hamaiketan**, erroldarako.* — У меня запись на сегодня, на одиннадцать, по поводу регистрации.

## У окошка

> *— Egun on. **Errolda-agiri bat behar dut**, banketxerako.*
>
> *— **NANa**, mesedez… Momentu bat… Tori, hemen duzu. **Doan da**.*
>
> *— Eskerrik asko! Eta beste kontu bat: etxez aldatu naiz. **Erroldatzeko**, zer egin behar dut?*
>
> *— **Eskabide hau bete** eta etxebizitzaren kontratua ekarri. **Fotokopiarik ez** da behar; guk egiten dugu.*
>
> *— Bikain. **Eperik badago**?*
>
> *— Ez, lasai, edonoiz etor zaitezke. Baina **hitzordua eskatu** lehenago, e!*

## Три фразы для выживания

> ***Zer agiri ekarri behar ditut**?* — Какие документы мне нужно принести?
>
> ***Noiz arte** daukat epea?* — До какого числа у меня срок?
>
> ***Nork sinatu behar du**?* — Кто должен подписать?

> **Примечание:** *hitzordua* дословно означает «час слова» (*hitza* + *ordua*) — запись к врачу, в мэрию или романтическое свидание: всё это одно слово. Контекст (и выражение вашего лица) сделает всё остальное. 😄
