Покупать вы уже умели с уровня А1. Этот урок — **второй уровень по магазинам**: примерять одежду, бороться с размерами и — финальный босс — **обменивать или возвращать** товары без лишних усилий. Нам помогут два старых друга: суффикс *-egi* (слишком) и падежная схема NOR-NORI (*geratzen zait*).

## В примерочной

| Русский | Баскский |
|---|---|
| Можно примерить? | *Probatu dezaket?* |
| Примерочная | *probalekua* |
| Размер | *neurria / talla* |
| Какой у вас размер? | *Zein neurri erabiltzen duzu?* |
| Мне хорошо / плохо сидит | *Ondo / gaizki geratzen zait* |
| Слишком большой / маленький | *Handiegia / txikiegia* |
| У вас есть в другом цвете? | *Beste kolore batean baduzue?* |
| А на размер больше? | *Eta neurri bat handiagoan?* |

> *— Praka hauek **probatu ditzaket**?*
>
> *— Noski, **probalekua** hor atzean dago.*
>
> *(пять минут спустя)* *— Zer, **ondo geratzen zaizkizu**?*
>
> *— Ez… **txikiegiak dira**. **42an baduzue**?*

*Geratzen zait / zaizkizu* — чистый NOR-NORI: одежда (NOR) подходит МНЕ (NORI). Во множественном числе: *geratzen zaizkit* (подходят).

## Обмен и возврат

| Русский | Баскский |
|---|---|
| Я хочу обменять | *Aldatu nahi dut* |
| Я хочу вернуть | *Itzuli nahi dut* |
| Вы вернёте мне деньги? | *Dirua itzuliko didazue?* |
| Чек | *tiketa* |
| Здесь есть дефект | *Akats bat dauka* |
| Вещь новая, неношеная | *Erabili gabe dago* |
| Срок возврата | *Itzultzeko epea* |

> *— Egun on. Jertse hau **itzuli nahi nuke**. **Akats bat dauka** hemen, ikusten?*
>
> *— Egia da. **Tiketa badaukazu**?*
>
> *— Bai, hemen. **Dirua itzuliko didazue** ala aldatu behar dut?*
>
> *— Nahi duzun bezala. Dirua **txartelera itzuliko dizugu**, bi-hiru egunetan.*
>
> *— Primeran, eskerrik asko.*

Обратите внимание на цепочку NOR-NORI-NORK: *itzuliko didazue* (вы мне вернёте), *itzuliko dizugu* (мы тебе вернём). Урок 03 в действии.

## Скидки и цены (весёлое повторение)

> ***Merkealdiak** daude: dena **%50ean**!* — Распродажа: всё со скидкой 50 %!
>
> *Deskontuarekin, **19,95 euro** bakarrik.* — Со скидкой, всего 19,95 €.
>
> *Bi erosita, **hirugarrena doan**.* — При покупке двух третья вещь бесплатно.

## Карманная шпаргалка

1. **Примерить**: *Probatu dezaket? → Ondo/gaizki geratzen zait → -egi* для размеров.
2. **Обменять**: *Aldatu nahi dut* (+ *beste neurri/kolore batean*).
3. **Вернуть**: *Itzuli nahi dut* + *tiketa* + *dirua itzuliko didazue?*
