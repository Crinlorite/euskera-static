Новый раздел: **на свежем воздухе**. Начнём со сцены — горы, леса, реки и моря, — которая в Стране Басков не просто декорация: это план на воскресенье, светская религия и бесконечная тема для разговоров.

## Гора

| Русский | Баскский |
|---|---|
| Гора | *mendia* |
| Вершина | *gailurra* |
| Склон | *magala* |
| Лес | *basoa* |
| Дерево | *zuhaitza* |
| Тропа | *bidezidorra* |
| Скала / утёс | *harkaitza* |
| Долина | *harana* |

> *Bidezidorretik gora, bi ordutan **gailurrera iritsiko gara**.* — Вверх по тропе, через два часа мы доберёмся до вершины.
>
> *Basoan barrena **ibili ginen**, eta ez genuen inor ikusi. Bakea.* — Мы гуляли по лесу и никого не видели. Покой.

## Вода

| Русский | Баскский |
|---|---|
| Река | *ibaia* |
| Водохранилище / болото | *urtegia* |
| Водопад | *ur-jauzia* |
| Море | *itsasoa* |
| Пляж | *hondartza* |
| Волны | *olatuak* |
| Утёс / обрыв | *labarra* |

> *Uda honetan ibaian **bainatuko gara**, hondartzan **jende gehiegi** dago eta.* — Этим летом будем купаться в реке, потому что на пляже слишком много людей. (Суффикс *-egi* и причинный союз *eta* в действии.)

## Описание пейзажа

> *Hemendik **bista ikusgarria** dago: harana, basoa eta urrutian **itsasoa**.* — Отсюда открывается впечатляющий вид: долина, лес и вдали море.
>
> *Udazkenean basoa **kolore ederrekoa** da: horia, gorria, marroia.* — Осенью у леса прекрасные цвета: жёлтый, красный, коричневый.
>
> *Zuhaitz hori **oso zaharra da** — ehun urte baino **gehiago** ditu.* — Это дерево очень старое: ему больше ста лет. (Сравнительные степени из раздела 04.)

## Диалог: план на воскресенье

> *— Igandean **mendira joango gara**? Anbotora, adibidez.*
>
> *— Anboto? Hori **gogorra** da niretzat! **Zerbait errazagoa**, mesedez…*
>
> *— Ados: Urkiolara **igoko gara**, bidezidor lasai batetik. **Gailurrean** hamaiketakoa.*
>
> *— Hamaiketakoarekin **konbentzitu nauzu**.* 😄

> **Примечание:** *mendizaletasuna* (любовь к горам) — это часть идентичности: у каждой деревни есть своя «собственная» гора и вершина с почтовым ящиком. Слово *hamaiketakoa* — второй завтрак (в одиннадцать часов) — настоящая причина, по которой многие совершают восхождение. Только никому не говорите.
