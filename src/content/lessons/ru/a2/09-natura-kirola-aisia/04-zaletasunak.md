Что вы делаете, когда ничего не делаете? Этот урок о **хобби** — и о грамматической конструкции, которая ими управляет: глагол, превращённый в существительное с помощью **-tzea** (*irakurtzea* = «чтение»).

## Конструкция: -t(z)ea

С уровня А1 вы знаете *gustatzen zait* с предметами (*kafea gustatzen zait*). Чтобы сказать, что вам нравится какое-то **действие**, глагол нужно превратить в существительное:

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| Русский | Баскский |
|---|---|
| Мне нравится читать | *Irakurtzea gustatzen zait* |
| Я обожаю готовить | *Asko gustatzen zait sukaldatzea* |
| Ему/ей нравится петь | *Abestea gustatzen zaio* |
| Нам нравится путешествовать | *Bidaiatzea gustatzen zaigu* |
| Мне совсем не нравится рано вставать | *Ez zait batere gustatzen goiz jaikitzea* |

Вся схема NOR-NORI, которую вы уже знаете (*zait, zaio, zaigu…*), продолжает работать так же; меняется только «что».

## Каталог хобби

| Русский | Баскский |
|---|---|
| Читать / писать | *irakurtzea / idaztea* |
| Слушать музыку | *musika entzutea* |
| Петь / танцевать | *abestea / dantzatzea* |
| Готовить | *sukaldatzea* |
| Фотографировать | *argazkiak ateratzea* |
| Рисовать красками / рисовать | *margotzea / marraztea* |
| Путешествовать | *bidaiatzea* |
| Ухаживать за огородом | *baratzea zaintzea* |
| Видеоигры | *bideo-jokoak* |
| Шить / вязать | *jostea / puntua egitea* |

## Спрашивать и хвастаться

> ***Zer egitea gustatzen zaizu** denbora librean?* — Что тебе нравится делать в свободное время?
>
> ***Zein da zure zaletasunik gogokoena**?* — Какое у тебя любимое хобби?
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — Моё любимое хобби — готовить: каждые выходные я пробую новый рецепт.

## Три структуры, три оттенка (тонкости для повторения)

| Структура | Пример | Значение |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | мне нравится (хобби) |
| **-tzen dakit** | *Margotzen dakit* | я умею это делать (навык) |
| **-tzen ari naiz** | *Margotzen ari naiz* | я делаю это (сейчас) |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — Я не умею вязать, но хотел(а) бы научиться. (Этот элегантный оборот *gustatuko litzaidake* вы освоите на уровне B1 — оставляем его здесь в качестве закуски.)

## Диалог

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*
>
> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
>
> *— **Sukaldatzea** eta gero… **jatea**, noski.*
>
> *— Hori ere zaletasuna da?*
>
> *— Nire etxean, **kirola**.* 😄
