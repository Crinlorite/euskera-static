Разговоры об **образе жизни** и **окружающей среде** — это классический блок уровня А2: здесь новая лексика смешивается с фразами долженствования и совета (*behar dugu*, *komeni da*, *garrantzitsua da*), которыми вы уже владеете с уровня А1.

## Здоровые привычки

| Русский | Euskera |
|---|---|
| Заниматься спортом | *kirola egin* |
| Ходить пешком / гулять | *paseatu* / *ibili* |
| Бегать | *korrika egin* |
| Ездить на велосипеде | *bizikletaz ibili* |
| Есть фрукты и овощи | *fruta eta barazkiak jan* |
| Пить воду | *ura edan* |
| Хорошо спать | *ondo lo egin* |
| Курить | *erre* |
| Пить алкоголь | *alkohola edan* |
| Не злоупотреблять солью | *gatzaz ez abusatu* |

> Типичные фразы:
>
> - *Kirola egiten dut astean hiru aldiz.* — Я занимаюсь спортом три раза в неделю.
> - *Erretzeari utzi diot.* — Я бросил(а) курить.
> - *Ez dut alkoholik edaten astegunetan.* — Я не пью алкоголь в будние дни.

## Частота: *X aldiz*

Чтобы сказать «X раз», используется формула **число + aldiz**:

| Русский | Euskera |
|---|---|
| Один раз в день | *Egunean behin* |
| Два раза в неделю | *Astean bi aldiz* / *birritan* |
| Три раза в месяц | *Hilean hiru aldiz* |
| Часто | *Askotan* |
| Иногда | *Batzuetan* |
| Редко | *Gutxitan* |
| Никогда | *Inoiz ez* |

## Контейнеры для мусора

| Обычный цвет | Euskera | Для чего |
|---|---|---|
| Синий | *edukiontzi urdina* | papera / бумага |
| Жёлтый | *edukiontzi horia* | plastikoa / пластик |
| Зелёный | *edukiontzi berdea* | beira / стекло |
| Коричневый | *edukiontzi marroia* | organikoa / органика |
| Серый | *edukiontzi grisa* | hondakinak / прочие отходы |

## Полезные фразы для выражения мнения

- *Garrantzitsua da birziklatzea.* — Важно перерабатывать отходы.
- *Komeni da kirola egitea.* — Желательно заниматься спортом.
- *Beharrezkoa da kutsadura gutxitzea.* — Необходимо уменьшить загрязнение.
- *Ez dut uste plastikoa ona denik.* — Я не думаю, что пластик — это хорошо.

> Эти конструкции (*-tzea + прилагательное + da*) — это формула уровня А2 для выражения «важно / желательно / необходимо делать X». Мы подробно разберём их в 4-м модуле.

## Жизнь района

| Русский | Euskera |
|---|---|
| Район | *auzoa* |
| Сосед/соседка | *bizilaguna* |
| Ассоциация / объединение | *elkartea* |
| Волонтёрство | *boluntariotza* |
| Районные праздники | *auzoko jaiak* |
| Участвовать | *parte hartu* |
| Собрание | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## Пример мини-текста

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **Культурная справка:** *auzo-elkarteak* (ассоциации соседей) — это фундаментальная часть общественной жизни во многих городах и деревнях Страны Басков. Они организуют праздники, семинары по баскскому языку, походы в горы и экологические кампании. Участие в их деятельности — один из лучших способов практиковать язык в реальных ситуациях.
