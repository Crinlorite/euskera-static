Этот урок объединяет два очень продуктивных блока уровня A2:

1. **Чувства** и состояния (с базовыми вы познакомились на уровне A1; здесь вы их расширите).
2. **Слова-связки** для аргументации и уточнения: *gainera, hala ere, beraz, alde batetik...*

Этим вы завершаете раздел и получаете инструменты для выражения более сложных мнений.

## Чувства: формула с *egon* + состояние

Большинство временных чувств выражаются с помощью *egon* + прилагательное или наречие в форме состояния:

| Русский | Баскский |
|---|---|
| Радостный / довольный | *Pozik nago* |
| Грустный | *Triste nago* |
| Сердитый / злой | *Haserre nago* |
| Нервный | *Urduri nago* |
| Спокойный | *Lasai nago* |
| Скучающий | *Aspertuta nago* |
| Уставший | *Nekatuta nago* |
| Смущённый | *Lotsatuta nago* |
| Влюблённый | *Maitemindurik nago* |

> Это та же схема с уровня A1 (*pozik, triste, lasai*), дополненная словами *aspertuta, nekatuta, lotsatuta, maitemindurik*.

## Чувства с *izan*: *beldur naiz*

Некоторые глубокие чувства выражаются с помощью *izan*:

| Русский | Баскский |
|---|---|
| Я боюсь | *Beldur naiz* |
| Ты прав(а) | *Arrazoia duzu* |
| Мне любопытно | *Jakin-mina dut* |
| У меня есть желание / Я хочу | *Gogoa dut* / *Gogoz nago* |
| У меня нет желания / Я не хочу | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — Я боюсь ехать на машине.

## Чувства с *NOR-NORI*: *lotsa ematen dit*

Очень баскская формула: чувство «тебе даёт»:

| Русский | Баскский |
|---|---|
| Мне стыдно | *Lotsa ematen dit* |
| Мне жаль | *Pena ematen dit* |
| Меня злит / бесит | *Amorrua ematen dit* |
| Мне страшно | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — Мне стыдно это говорить.
>
> *Albiste horrek **pena handia ematen dit**.* — Эта новость меня очень огорчает.

## *Jartzen naiz / jarri naiz*

Для выражения **изменения состояния** («становиться нервным, радостным, грустным»):

| Русский | Баскский |
|---|---|
| Я нервничаю / становлюсь нервным | *Urduri **jartzen naiz*** |
| Он(а) загрустил(а) | *Triste **jarri zen*** |
| Мы обрадовались | *Pozik **jarri ginen*** |
| Он(а) злится по пустякам | *Edozergatik haserretzen da* |

## Часто используемые психологические глаголы

| Глагол | Значение |
|---|---|
| *gustatu* | нравиться |
| *maite izan* | любить |
| *gorrotatu* / *higuindu* | ненавидеть |
| *beldurtu* | пугаться |
| *aspertu* | скучать |
| *haserretu* | сердиться, злиться |
| *lasaitu* | успокаиваться |
| *poztu* | радоваться |
| *triste jarri* / *atsekabetu* | печалиться, грустить |
| *kezkatu* | беспокоиться |

> *Asko **maite ditut** nire gurasoak.* — Я очень люблю своих родителей.
>
> *Ez **kezkatu**, dena ondo aterako da.* — Не беспокойся, всё будет хорошо.

## Слова-связки

Чтобы связывать мнения и аргументы:

### Добавление

| Русский | Баскский |
|---|---|
| Кроме того / К тому же | *gainera* |
| А также | *eta baita ere* / *...ere* |
| Прежде всего / Особенно | *batez ere* |

> *Gainera, prezioa ere ona da.* — Кроме того, цена тоже хорошая.

### Причина / следствие

| Русский | Баскский |
|---|---|
| Поэтому / Следовательно | *beraz* |
| Поэтому | *horregatik* |
| По этой причине | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — Поздно, поэтому я ухожу.

### Противопоставление

| Русский | Баскский |
|---|---|
| Однако / Тем не менее | *hala ere* |
| Но | *baina* |
| С другой стороны | *bestetik* |
| Зато / Напротив | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — Поздно, но я всё равно приду.

### Организация речи

| Русский | Баскский |
|---|---|
| С одной стороны... с другой | *Alde batetik... bestetik...* |
| Сначала... потом... | *Lehenengo... gero...* |
| Наконец / В заключение | *Azkenik* |
| Вкратце / Подводя итог | *Laburbilduz* |

## Сочинительные конструкции A2

Это конструкции, которые встречаются на любом экзамене уровня A2:

| Русский | Баскский |
|---|---|
| Ни... ни... | *Ez... ez...* |
| Как... так и... | *Bai... bai...* / *Hala... nola...* |
| Не только... но и... | *Ez bakarrik..., baita ere...* |
| ...тоже / также (включая) | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — Ни *Anboto*, ни *Olatz* не пришли.
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — Я должен работать как утром, так и вечером.

## Мини-текст с мнением

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## Лайфхак для A2: «скелет» для выражения мнения

Когда вас попросят выразить мнение на уровне A2, следуйте этому шаблону:

> **1. Nire ustez** + тема + **-(e)la**.
>
> **2. Alde batetik**, + причина1 + **-lako**.
>
> **3. Bestetik**, + причина2.
>
> **4. Hala ere**, + уточнение.
>
> **5. Beraz**, + заключение.

С его помощью вы построите полноценный абзац уровня A2.

> **Культурная заметка:** во многих официальных текстах уровня A2 (письмо в редакцию, сообщение на форуме, экзаменационное сочинение) требуется эта аргументативная структура. Практикуйте её на повседневные темы: спорт, еда, социальные сети, работа, местные праздники.
