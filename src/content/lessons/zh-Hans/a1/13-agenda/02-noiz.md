要谈论计划，你需要掌握时间标记词。这里有表示过去-现在-未来的时间轴，以及一些最常用于不久的将来的词。

## 基本时间轴

| 巴斯克语 | 中文 |
|---|---|
| *atzo* | 昨天 |
| *gaur* | 今天 |
| *bihar* | 明天 |
| *etzi* | 后天 |
| *etziluma / etzidamu* | “大后天”（不常用） |

三个简短的词（*atzo, gaur, bihar*）和 *etzi* —— 有了它们，你几乎可以应对任何关于日期的日常对话。

## `Datorren` (即将到来的)

要说“下周”、“下个月”，我们用 **datorren** + 名词：

| 巴斯克语 | 中文 |
|---|---|
| *datorren astean* | 下周 |
| *datorren astelehenean* | 下周一 |
| *datorren hilean* | 下个月 |
| *datorren urtean* | 明年 |

`Datorren` 的意思是“即将到来的”（是动词 *etorri* “来”的关系形式）。重要的是把它作为一个整体来学习。

## “这” — `hau` / `honetan`

要说“这周”、“这个周末”：

- *aste honetan* — 这周
- *asteburu honetan* — 这个周末
- *hilabete honetan* — 这个月

## 其他关键时间标记词

| 巴斯克语 | 中文 |
|---|---|
| *orain* | 现在 |
| *gero* | 然后，之后 |
| *lehen* | 以前，之前 |
| *gaur goizean* | 今天早上 |
| *gaur arratsaldean* | 今天下午 |
| *gaur gauean* | 今天晚上 |
| *bihar goizean* | 明天早上 |

> *Goiza* = 早上（一天中的一部分）。*Bihar* = 明天（第二天）。这是两个不同的词，不要混淆！

## 提问时间

- **Noiz?** — 什么时候？
- **Noiz etorriko zara?** — 你什么时候来？
- **Noiz egingo dugu afaria?** — 我们什么时候做晚饭？

## 情景示例

- *Bihar mendira joango naiz.* — 我明天要去爬山。
- *Etzi euskara klasea dut.* — 我后天有巴斯克语课。
- *Datorren astean lan asko izango dut.* — 我下周有很多工作。
- *Asteburu honetan ez dut planik.* — 我这个周末没有计划。

> **文化小贴士：** 在巴斯克语中，作为一天中时段的“早上”是 *goiza*，而作为第二天的“明天”是 *bihar*。短语 *bihar goizean*（“明天早上”）将两者结合在一起。在初学者的对话中，很容易搞错这个细微差别，所以最好从一开始就牢牢记住。
