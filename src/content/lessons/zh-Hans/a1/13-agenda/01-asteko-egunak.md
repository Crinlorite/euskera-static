在讨论计划和日程之前，我们来复习一下星期几的说法，并学习如何将它们与日常活动联系起来。

## 一周七天

| 巴斯克语 | 中文 | 提示 |
|---|---|---|
| *astelehena* | 星期一 | aste + lehen = “一周的第一天” |
| *asteartea* | 星期二 | aste + arte = “周中” |
| *asteazkena* | 星期三 | aste + azken = “工作周的最后一天”（历史说法） |
| *osteguna* | 星期四 | egun = 天 |
| *ostirala* | 星期五 | 与 *osteguna* 共享词根 *ortzi/osti-*（天空） |
| *larunbata* | 星期六 | larun + bata |
| *igandea* | 星期日 | 历史上的假日 |

> **记忆提示：** **aste**（星期）这个词出现在工作日的开头。*Astelehen-、astear-、asteazken-* 几乎就像大声数着一周的开始、中间和结束。

## 表达“在星期一” — 后缀 `-(e)an`

要表示某事发生在某一天，可以在日期后加上 `-(e)an`：

| 日期 | “在 + 日期” |
|---|---|
| astelehena | astelehen**ean** |
| asteartea | astearte**an** |
| asteazkena | asteazken**ean** |
| osteguna | ostegun**ean** |
| ostirala | ostirale**an** |
| larunbata | larunbat**ean** |
| igandea | igande**an** |

- *Astelehenean lan egiten dut.* — 我星期一工作。
- *Larunbatean afaltzera joango gara.* — 我们星期六要去吃晚饭。

## 表达“每个X” — 后缀 `-ero`

用于表示规律性的频率：

- *astelehenero* — 每个星期一
- *larunbatero* — 每个星期六
- *egunero* — 每一天
- *astero* — 每一周
- *astebururo* — 每个周末

## 日期 + 活动：示例

| 巴斯克语 | 中文 |
|---|---|
| *Astelehenean kiroldegira noa.* | 星期一我去健身房。 |
| *Asteartean euskara klasea dut.* | 星期二我有巴斯克语课。 |
| *Ostiralean parranda egiten dugu.* | 星期五我们出去玩。 |
| *Larunbatean familiaren etxera joango naiz.* | 星期六我会去家人的家。 |
| *Igandean lasai gelditzen naiz etxean.* | 星期日我待在家里放松。 |

## Asteburua — 周末

`Asteburua`（周末）是一个非常有用的词：

- *Asteburuan zer egingo duzu?* — 你周末打算做什么？
- *Asteburu honetan mendira joango naiz.* — 这个周末我会去爬山。
- *Asteburu pasa egitea gustatzen zait.* — 我喜欢周末短途旅行。

> **文化小贴士：** 除了 *igandea*，你还会经常看到 *jaieguna*（节假日）：在公交车时刻表、商店和市政厅的告示上，*igandeak eta jaiegunak* 是一个典型的表述方式。
