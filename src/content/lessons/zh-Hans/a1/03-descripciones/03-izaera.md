描述了一个人的外貌之后，很自然地就要讲述**其内在**：他的性格、为人。在巴斯克语中，这些形容词也和描述外貌的形容词一样，用 **izan** + 形容词 + `-a` 的结构来构成。

## 基本性格词汇

这些形容词几乎总是以反义词的形式成对出现：

| 巴斯克语 | 中文意思 | 反义词 |
|---|---|---|
| *alaia* | 开朗的 | *triste* (伤心的 — 但请注意，这是一个状态) |
| *jatorra* | 友好的，亲切的 | — |
| *atsegina* | 和蔼的，令人愉快的 | — |
| *ona* | 好的 | *txarra* (坏的) |
| *isila* | 安静的 | *berritsua* (话多的) |
| *lasaia* | 冷静的 | *urduria* (紧张的) |
| *langilea* | 勤奋的 | *alferra* (懒惰的) |
| *ausarta* | 勇敢的 | *beldurtia* (胆小的) |
| *zintzoa* | 规矩的，诚实的 | *bihurria* (淘气的，调皮的) |
| *serioa* | 严肃的 | — |
| *lotsatia* | 害羞的 | — |
| *bikaina* | 优秀的，极好的 | — |

> 许多这类形容词由名词+后缀构成。例如，*langile* 来自 *lan*（“工作”）；*beldurti* 来自 *beldur*（“恐惧”）。在A1阶段，你不需要学习其内部逻辑，但这会帮助你记忆。

## 结构：与描述外貌的形容词相同

- *Maialen oso **alaia** da.* — Maialen 非常开朗。
- *Egoitz **isila eta serioa** da.* — Egoitz 安静又严肃。
- *Gu **langileak** gara.* — 我们是勤奋的人。
- *Haiek **bihurriak** dira.* — 他们很淘气。
- *Ni ez naiz oso **lotsatia**.* — 我不是很害羞。

## 连接多个形容词

介绍某人时，一种非常自然的方式是连续说出3-4个特点。巴斯克语通过在最后一个形容词前使用连词 **eta**（“和”）来实现这一点：

> *Nire arreba alaia, jatorra **eta** langilea da.*
>
> 我的姐姐开朗、友好且勤奋。

## 用 "Oso" 和 "nahiko" 来调整语气

- **oso** alaia → 非常开朗
- **nahiko** isila → 相当安静
- **ez** oso urduria → 不是很紧张
- **ez** zara batere alferra → 你一点也不懒 (*batere* 加强否定语气)

## 完整示例

> *Nire ama oso jatorra eta atsegina da. Lasaia da, baina nire aita urduria da. Anaia bihurri samarra da, baina ni zintzoa naiz!*
>
> 我的妈妈非常友好和蔼。她很冷静，但我爸爸很爱紧张。我的哥哥相当淘气，但我很规矩！
