在巴斯克语中，描述头发和眼睛时，不用像西班牙语那样使用 **izan**（“是”）（例如“soy moreno”），而是用 **ukan**（“有”）：*tengo el pelo negro*（我有黑色的头发），*tengo los ojos azules*（我有蓝色的眼睛）。

## 头发：ile

“头发”这个词是 **ile**（带冠词时是 *ilea*）。形容词跟在名词后面，并且只有最后一个形容词带有 `-a` 标记：

| 巴斯克语 | 中文意思 |
|---|---|
| *ile beltza* | 黑发 |
| *ile horia* | 金发 |
| *ile zuria* | 白发 |
| *ile gorria* | 红发 |
| *ile urdina* | 灰发 |
| *ile motza* | 短发 |
| *ile luzea* | 长发 |
| *ile lisoa* | 直发 |
| *ile kizkurra* | 卷发 |

> 在巴斯克语中，“头发”被视为**单数**，和西班牙语一样。因此使用 *dut* / *du*（而不是 *ditut* / *ditu*）。

- *Ile beltza eta luzea **dut**.* — 我有一头又黑又长的头发。
- *Maialenek ile kizkurra **du**.* — Maialen 有一头卷发。

## 眼睛：begiak

与头发不同，“眼睛”是**复数**（*begiak*）。因此形容词也用复数形式（`-ak`），并且动词要用 **ditut / ditu**：

| 巴斯克语 | 中文意思 |
|---|---|
| *begi urdinak* | 蓝色的眼睛 |
| *begi marroiak* | 棕色的眼睛 |
| *begi berdeak* | 绿色的眼睛 |
| *begi beltzak* | 黑色的眼睛 |
| *begi argiak* | 浅色的眼睛 |
| *begi ilunak* | 深色的眼睛 |

- *Begi urdinak **ditut**.* — 我有蓝色的眼睛。
- *Mikelek begi marroiak **ditu**.* — Mikel 有棕色的眼睛。

## 其他特征：后缀 -dun

要表示“带着 X 的”或“有 X 的”，巴斯克语有一个非常好用的后缀：**-duna**（单数）/ **-dunak**（复数）。它加在名词后面，用来指代人，例如“戴眼镜的人”、“有胡子的人”……

| 巴斯克语 | 中文意思 |
|---|---|
| *betaurrekoduna* | 戴眼镜的 / 戴眼镜的人 |
| *bizarduna* | 有（络腮）胡子的 |
| *biboteduna* | 有（上唇）胡子的 |
| *burusoila* | 秃头的（字面意思是“光头”） |

这些词确实要与 **izan** 搭配使用，因为它们像形容词一样描述一种特质：

- *Hura biboteduna da.* — 他有小胡子。
- *Nire aitona burusoila da.* — 我爷爷是秃头。

## 综合运用

一段典型的人物描述会混合使用多种结构：

> *Maialen txikia eta argala da. Ile gorria eta kizkurra du. Begi berdeak ditu. Betaurrekoduna da.*
>
> Maialen 又矮又瘦。她有一头红色卷发。她有绿色的眼睛。她戴着眼镜。

请注意这些结构的分配方式：**izan** 用于描述一般特征（*txikia da*），**ukan** 用于描述头发/眼睛（*ile … du*，*begi … ditu*），而带 *-dun*-a 的词则再次与 **izan** 搭配，用于描述配饰等。
