这节课涵盖了两个经常被混淆的问题：**你来自哪里** (出身) 和 **你住在哪里** (当前住所)。在巴斯克语中，它们用不同的后缀来构成。

## 出身: Nongoa zara? → ...koa naiz

询问出身，使用 **Nongoa zara?** 并用地名 + 后缀 **`-(e)ko`** (带冠词时为：`-koa`) 回答：

| 地点 | 出身 |
|---|---|
| Bilbo | Bilbo**koa** naiz (我来自毕尔巴鄂) |
| Donostia | Donostia**koa** naiz (我来自多诺斯蒂亚) |
| Iruñea | Iruñe**koa** naiz (我来自潘普洛纳) |
| Madril | Madril**goa** naiz |
| Espainia | Espainia**koa** naiz |
| Argentina | Argentina**koa** naiz |

> 在辅音后，后缀会根据拼写规则进行调整 (*Madril* → *Madrilgoa*)。熟能生巧。

## 住所: Non bizi zara? → ...n bizi naiz

询问现住址，使用 **Non bizi zara?** (“你住在哪里？”) + 地名加方位格后缀 **`-(e)n`**：

| 地点 | 住所 |
|---|---|
| Bilbo | Bilbo**n** bizi naiz |
| Donostia | Donostia**n** bizi naiz |
| Iruñea | Iruñea**n** bizi naiz |
| Madril | Madril**en** bizi naiz |

> 以固有 `-a` 结尾的词 (如 *Donostia*) 会保留 `a`。以辅音结尾的词 (如 *Madril*) 会插入 `-e-`。

## 对话中的两种用法

> — *Kaixo! Zein da zure izena?* — 你好！你叫什么名字？
>
> — *Ni Maialen naiz. Eta zu?* — 我是 Maialen。你呢？
>
> — *Egoitz naiz. **Nongoa zara?*** — 我是 Egoitz。你来自哪里？
>
> — ***Iruñekoa naiz**, baina **Bilbon bizi naiz** orain.* — 我来自潘普洛纳，但现在住在毕尔巴鄂。

## 实用词汇

- **herri** — 村庄，镇
- **hiri** — 城市
- **herrialde** — 地区 / 省
- **estatu** — 国家
- **norekin bizi zara?** — 你和谁一起住？ → *Bakarrik bizi naiz* (我一个人住) / *Gurasoekin bizi naiz* (我和父母一起住)
