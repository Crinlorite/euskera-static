在巴斯克地区，很大一部分的社交生活都围绕着 **taberna**（酒吧）进行。了解巴斯克语中的基本饮品和食物会立刻为你打开大门：结交一群朋友、探访一个新的村庄、参加一次 *poteo*（串吧喝酒）。我们从词汇开始吧。

## 咖啡及其种类

咖啡可能是你会点得最多的东西。它有几种形式：

| 巴斯克语 | 西班牙语 |
|---|---|
| *kafea* | 咖啡（泛指） |
| *kafe hutsa* | 黑咖啡（字面意思：“纯/空的咖啡”） |
| *kafesnea* | 拿铁/牛奶咖啡（来自 *kafe* + *esne*） |
| *kafe ebakia* | 玛奇朵/短浓缩咖啡 (*ebaki* = “切断的”） |
| *kafe deskafeinatua* | 无因咖啡 |
| *infusioa* | 花草茶/冲泡饮品 |
| *tea* | 茶 |

> *Kafesne* 的字面意思是“咖啡-牛奶”。巴斯克语中有很多这样构成的复合词，没有连字符，且核心词在后。

## 其他饮品

| 巴斯克语 | 西班牙语 |
|---|---|
| *ura* | 水 |
| *zumoa* | 果汁 |
| *esnea* | 牛奶 |
| *ardoa* | 葡萄酒 |
| *ardo gorria* | 红葡萄酒 |
| *ardo zuria* | 白葡萄酒 |
| *garagardoa* | 啤酒 |
| *zuritoa* | 小杯啤酒（典型的） |
| *sagardoa* | 苹果酒 |
| *txakolina* | txakoli（巴斯克白葡萄酒） |
| *patxarana* | pacharán（一种利口酒） |

> 三个有趣的词：**sagardo**（苹果酒）= *sagar*（苹果）+ *ardo*（酒）；**garagardo**（啤酒）= *garagar*（大麦）+ *ardo*；**txakolina** 是一种年轻、清淡的白葡萄酒，是巴斯克地区的招牌。

## 定冠词 `-a`

几乎所有这些词在句子中以“中性”形式出现时，词尾都会带上 **`-a`**：这是定冠词，相当于西班牙语的“el / la”。

- *Ardoa gustatzen zait.* — 我喜欢葡萄酒。
- *Ura nahi dut.* — 我想要水。

当你点“一个”时，`-a` 会消失，换成 **bat**（“一个”）：

- *Kafe **bat**, mesedez.* — 一杯咖啡，谢谢。
- *Garagardo **bat**.* — 一杯啤酒。

> 在第3课中，你会更详细地学习这一点。现在，先记住带 `-a` 的形式，以便在酒吧的菜单上认出它们。
