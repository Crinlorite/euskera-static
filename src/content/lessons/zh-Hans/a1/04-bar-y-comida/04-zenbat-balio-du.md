要在巴斯克语中询问价格并听懂结账时的话，你需要两样东西：公式 **Zenbat balio du?** 和100以内的数字。巴斯克语的数字系统是**二十进制**的（以20为一组），所以需要一点时间来适应。

## 关键问题

| 巴斯克语 | 中文 |
|---|---|
| *Zenbat balio du?* | 多少钱？ |
| *Zenbat da?* | 是多少？ |
| *Zenbat dira denera?* | 总共多少钱？ |
| *Pagatu daiteke?* | 可以付款吗？（用于结账） |

> **Zenbat** 的意思是“多少”——你已经在 *Zenbat urte dituzu?*（“你几岁了？”）中学过它。**Balio** = “价值/花费”。

## 20以内的数字（复习）

你已经在关于家庭的单元中学过1到10了。下面是11到20：

| 数字 | 巴斯克语 |
|---|---|
| 11 | *hamaika* |
| 12 | *hamabi* (hamar + bi) |
| 13 | *hamahiru* |
| 14 | *hamalau* |
| 15 | *hamabost* |
| 16 | *hamasei* |
| 17 | *hamazazpi* |
| 18 | *hemezortzi* |
| 19 | *hemeretzi* |
| 20 | *hogei* |

> 从12到17，注意看它是如何由 *hamar*（“十”）+ 个位数构成的：*hamabi* = “十-二” = 十二。*Hamaika* (11) 和 *hemezortzi*/*hemeretzi* (18, 19) 是不规则的。

## 十位数：二十进制

这是巴斯克语的惊喜之处。十位数是**以20为一组**来数的：

| 数字 | 巴斯克语 | 逻辑 |
|---|---|---|
| 20 | *hogei* | 基础 |
| 30 | *hogeita hamar* | “20加10” |
| 40 | *berrogei* | “两个20” (*ber-* = 双倍) |
| 50 | *berrogeita hamar* | “两个20加10” |
| 60 | *hirurogei* | “三个20” (*hiru* = 三) |
| 70 | *hirurogeita hamar* | “三个20加10” |
| 80 | *laurogei* | “四个20” |
| 90 | *laurogeita hamar* | “四个20加10” |
| 100 | *ehun* | 基础 |

> 对于中间的数字，遵循同样的逻辑：25 = *hogeita bost*（“20加5”），67 = *hirurogeita zazpi*（“三个20加7”）。一开始会有点难，但在酒吧里多练习几次价格的说法，自然就会了。

## 说价格

| 价格 | 巴斯克语 |
|---|---|
| 1 € | *euro bat* |
| 2 € | *bi euro* |
| 1,50 € | *euro bat eta berrogeita hamar* / *euro eta erdi* |
| 3 € | *hiru euro* |
| 25 € | *hogeita bost euro* |

> 注意，当 **euro** 前面有数字时，它不带 `-a`（就像 *bi anaia*，“两个兄弟”一样）。以欧分表示的确切金额说法和西班牙语一样：*hiru euro eta berrogeita hamar zentimo* (3.50欧元)。

## 购买多个物品

当你点不止一样东西时，记得用 **ditut** 或 **ditugu** 来代替 *dut*/*dugu*：

- *Bi kafe hartuko ditut.* — 我要两杯咖啡。
- *Hiru ogitarteko hartuko ditugu.* — 我们要三个三明治。

## 谈论价格的形容词

- **garesti** — 贵的（加冠词时为 *garestia*）
- **merke** — 便宜的（加冠词时为 *merkea*）
- **doan** — 免费的

> *Hau oso garestia da!* — 这个太贵了！
> *Bilbon kafea merkea da.* — 在毕尔巴鄂，咖啡很便宜。
