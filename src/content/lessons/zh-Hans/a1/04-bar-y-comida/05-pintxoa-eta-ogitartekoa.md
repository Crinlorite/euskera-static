伟大的巴斯克酒吧文化围绕着三种主要形式：**pintxo**（小份，吧台小吃）、**ogitarteko**（三明治）和 **plater konbinatua**（套餐）。了解如何点不同种类的食物，你就能在任何地方吃饭了。

## 三种形式

| 巴斯克语 | 西班牙语 | 份量 |
|---|---|---|
| *pintxoa* | pincho / tapa (小吃) | 小份，吧台小吃 |
| *ogitartekoa* | 三明治 | 中等份量，夹在面包里 |
| *plater konbinatua* | 套餐 | 一顿正餐 |
| *razioa* | 一份 (菜) | 供分享 |

> **Ogitarteko** 的字面意思是“面包之间的东西”：*ogi* (面包) + *arte* (之间) + *-ko*。这就是我们常吃的三明治，但用的是优质的巴斯克面包和丰富的馅料。

## 典型馅料

以下是你在酒吧黑板上会看到的最常见的馅料：

| 巴斯克语 | 西班牙语 |
|---|---|
| *tortilla* | 土豆煎蛋饼 |
| *txistorra* | txistorra (一种西班牙香肠) |
| *txorizoa* | 西班牙香肠 |
| *gazta* | 奶酪 |
| *urdaiazpikoa* | 火腿 |
| *antxoa* | 凤尾鱼 |
| *atuna* | 金枪鱼 |
| *gilda* | gilda (凤尾鱼 + 腌辣椒 + 橄榄) |

## 如何组合点餐

公式是：**描述词 + 形式 + bat (mesedez)**。描述词（馅料）放在前面。

- *Tortilla **pintxo bat**, mesedez.* — 请给我一个土豆煎蛋饼 pincho。
- *Gazta **ogitartekoa**, mesedez.* — 请给我一个奶酪三明治。
- *Txistorra **razio bat** hartuko dugu.* — 我们要一份 txistorra。
- *Ogitarteko **mistoa**, mesedez.* — 请给我一个混合三明治。

> 当你点餐是为了分享时，使用 **dugu**（“我们有/我们吃”）或 **hartuko dugu**（“我们将要吃”）。一群人一起时，为所有人点几份菜是很常见的。

## 变体与细微差别

- **handia** — 大的 / **txikia** — 小的：
  - *Garagardo handia* — 大杯啤酒
  - *Kafe txikia* — 小杯咖啡（小杯子）
- **hotza** — 凉的 / **beroa** — 热的：
  - *Ogitarteko beroa* — 热三明治（用烤盘加热）
- **eta...** — 和... (用于添加)：
  - *Tortilla pintxoa **eta** ardo gorri bat* — 一个土豆煎蛋饼 pincho 和一杯红酒

## 一桌朋友

> — *Zer hartuko dugu?* — 我们吃点什么？
>
> — *Niretzat tortilla pintxoa eta zurito bat.* — 我要一个土豆煎蛋饼 pincho 和一小杯啤酒。
>
> — *Eta zuretzat?* — 你呢？
>
> — *Nik gazta razio bat eta ardo gorri bat hartuko ditut.* — 我要一份奶酪和一杯红酒。
>
> — *Nik plater konbinatu bat: arrautzak, txorizoa eta patata frijituak.* — 我要一个套餐：鸡蛋、西班牙香肠和炸薯条。
>
> — *Bale, hiru eskaera dira.* — 好的，一共三份。

## 付款

- **Pagatzera!** — 该付钱了！
- **Niri tokatzen zait.** — 该我付了。
- **Nik gonbidatzen zaitut.** — 我请客。
- **Erdibana.** — AA制，一人一半。（分摊）

> **文化小贴士：** pintxos 是在多诺斯蒂亚、毕尔巴鄂和伊鲁尼亚等地尤为盛行的传统。每家酒吧通常都有自己的招牌菜。**poteo** 的习俗是指挨家挨户地去不同的酒吧，在每家店吃一个 pintxo、喝一杯饮料——这是一个非常具有社交性和巴斯克特色的传统。
