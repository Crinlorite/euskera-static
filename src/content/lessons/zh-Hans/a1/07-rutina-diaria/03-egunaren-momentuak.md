在巴斯克语中，表示一天中不同时段的词语主要使用两个关键后缀：**`-(e)an`**（意为“在”）和 **`-(e)ko`**（意为“的”），具体取决于你的用途。好消息是，它们与所有相关词语的组合都非常有规律。

## 基本词汇

| 巴斯克语 | 中文 |
|---|---|
| *goiza* | 早上 |
| *eguerdia* | 中午 |
| *arratsaldea* | 下午 |
| *iluntzea* | 傍晚 |
| *gaua* | 晚上 |

## “在早上/在下午”——方位格后缀 `-(e)an`

要表示某事发生的时间（在一天的哪个时段），在词根后加上 **-(e)an**：

| 时间 | 巴斯克语 |
|---|---|
| 在早上 | **goizean** |
| 在中午 | **eguerdian** |
| 在下午 | **arratsaldean** |
| 在傍晚 | **iluntzean** |
| 在晚上 | **gauean** |

> *Goizean kafea hartzen dut.* — 我早上喝咖啡。
>
> *Arratsaldean lagunekin egoten naiz.* — 我下午和朋友们待在一起。
>
> *Gauean lo egiten dut.* — 我晚上睡觉。

## “早上的/下午的”——后缀 `-ko`

要指明**一天中的具体时间**，将带有 **-ko** 的词放在小时前面：

| 确切时间 | 巴斯克语 |
|---|---|
| 早上8点 | **goizeko zortziak** |
| 中午12点 | **eguerdiko hamabiak** |
| 下午5点 | **arratsaldeko bostak** |
| 晚上9点 | **gaueko bederatziak** |

> *Goizeko zazpietan esnatzen naiz.* — 我早上七点起床。
>
> *Arratsaldeko hirurak dira.* — 现在是下午三点。

## 基本时间标记

这些词你每天都会用到：

| 巴斯克语 | 中文 |
|---|---|
| *gaur* | 今天 |
| *atzo* | 昨天 |
| *bihar* | 明天（后一天） |
| *etzi* | 后天 |
| *orain* | 现在 |
| *gero* | 然后，之后 |
| *lehen* | 以前 |

> 注意：请小心区分 **bihar**（后一天，“明天”）和 **goiza**（早上，指中午之前的时段）。在西班牙语中，这两个概念都用“mañana”一词，但在巴斯克语中则不然。

## 综合运用

> *Bihar goizean lanera joango naiz.* — 我明天早上要去上班。
>
> *Atzo arratsaldean zinemara joan ginen.* — 我们昨天下午去看电影了。
>
> *Gaur gaueko hamarretan afalduko dut.* — 我今晚十点吃晚餐。

> **文化小贴士：**巴斯克地区以其 *iluntze* 而闻名——也就是傍晚时分，朋友们（*cuadrillas*）会出门进行 *poteo*（在不同酒吧间轮流喝小杯酒）。它既不是下午也不是晚上，而是一天中一个具有独特身份的时刻。
