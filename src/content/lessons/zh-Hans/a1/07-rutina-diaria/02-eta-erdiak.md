在巴斯克语里，分钟的表达主要靠三种结构就能搞定绝大多数情况：**eta erdiak**（...点半）、**eta laurden**（过一刻）和 **gutxi**（差）。窍门在于知道每个词放在哪里。

## “...点半” —— 特殊情况

与其他情况不同，用“...点半”时，复数不在钟点上，而在“半”这个词上：数字不带 *-ak*，由 *erdiak* 来承载复数。动词仍然用复数 (*dira*)，一点半也是如此：

| 时间 | 巴斯克语 |
|---|---|
| 1:30 | **Ordu bat eta erdiak dira** |
| 2:30 | **Ordu bi eta erdiak dira** |
| 3:30 | **Hiru eta erdiak dira** |
| 4:30 | **Lau eta erdiak dira** |
| 5:30 | **Bost eta erdiak dira** |
| 7:30 | **Zazpi eta erdiak dira** |

> 请注意：用 *eta erdiak* 时，数字**不带 -ak**（是 *bost eta erdiak*，不是 *bostak eta erdiak*），因为复数只由 *erdiak* 来体现。一点和两点也一样：*ordu bat eta erdiak*、*ordu bi eta erdiak*（不是 *ordu bata…*，也不是 *ordu biak…*）。这是标准巴斯克语 (*batua*) 的形式；在北巴斯克地区 (Iparralde)，你会听到两处都用复数（*bost orenak eta erdiak*、*bostak eta erdiak*）。

## “过一刻”和分钟数

当时间已经超过整点几分钟时，使用公式 **钟点-ak eta 分钟**：

| 时间 | 巴斯克语 |
|---|---|
| 3:05 | **Hirurak eta bost dira** |
| 4:10 | **Laurak eta hamar dira** |
| 5:15 | **Bostak eta laurden dira** |
| 6:20 | **Seiak eta hogei dira** |
| 7:25 | **Zazpiak eta hogeita bost dira** |

**Laurden** 意为“一刻”，所以 **eta laurden** = “过一刻”。

## “差” —— gutxi 放在后面

从半点之后开始，我们以下一个整点为基准来说时间，用 **gutxi**（“差”）这个词。语序是：**钟点-ak + 分钟 + gutxi**。

| 时间 | 巴斯克语 |
|---|---|
| 6:35 | **Zazpiak hogeita bost gutxi dira** |
| 7:40 | **Zortziak hogei gutxi dira** |
| 8:45 | **Bederatziak laurden gutxi dira** |
| 9:50 | **Hamarrak hamar gutxi dira** |
| 10:55 | **Hamaikak bost gutxi dira** |

> 对说中文的人来说，最奇怪的地方可能是 **gutxi** 要放在数字**后面**，而不是前面。*Bederatziak laurden gutxi* 字面意思是“九点 一刻 差”。

## 小结表

| 概念 | 关键词 | 位置 |
|---|---|---|
| ...点半 | *eta erdiak* | 放在钟点之后；数字不带 -ak |
| 过一刻 | *eta laurden* | 放在带 -ak 的钟点之后 |
| 过X分钟 | *eta + 数字* | 放在带 -ak 的钟点之后 |
| 差一刻 | *laurden gutxi* | 放在带 -ak 的下一个钟点之后 |
| 差X分钟 | *数字 + gutxi* | 放在带 -ak 的下一个钟点之后 |

## 对话示例

> *— Zer ordu da?*
>
> *— **Zazpiak eta laurden dira.*** （现在是七点一刻。）
>
> *— Eta orain?*
>
> *— **Zortziak laurden gutxi dira.*** （现在是差一刻八点。）

> **文化小贴士：** 在许多巴斯克村庄，教堂的钟声仍在报时和报刻。如果你停下来听，你的耳朵会在嘴巴还没把它变成下意识反应之前，就先习惯这种节奏。
