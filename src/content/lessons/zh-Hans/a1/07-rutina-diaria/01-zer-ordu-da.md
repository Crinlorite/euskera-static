在巴斯克语中，表示时间要用动词 **izan** (是)，并且，除了“一点钟”以外，时间总是用**复数**形式。字面意思是：*“是五个点钟”*，*“是八个点钟”*。一开始听起来可能有点奇怪，但这个规律非常有规则。

## 提问

要询问时间，我们用 **Zer ordu da?** (“几点了？”)。

> *— Zer ordu da?*
>
> *— Zazpiak dira.* (七点了。)

## 整点

| 时间 | 巴斯克语 |
|---|---|
| 1:00 | **Ordu bata da** |
| 2:00 | **Ordu biak dira** |
| 3:00 | **Hirurak dira** |
| 4:00 | **Laurak dira** |
| 5:00 | **Bostak dira** |
| 6:00 | **Seiak dira** |
| 7:00 | **Zazpiak dira** |
| 8:00 | **Zortziak dira** |
| 9:00 | **Bederatziak dira** |
| 10:00 | **Hamarrak dira** |
| 11:00 | **Hamaikak dira** |
| 12:00 | **Hamabiak dira** |

## 为什么一点和两点是特殊的

- **Ordu bata** (一点) 是**单数**，所以要用 **da**：*Ordu bata da*。
- **Ordu biak** (两点) 前面会加上单词 *ordu*，因为单用 *biak* 可能会引起混淆——这是一些人为了更清晰而加上“ordu”的唯一时间点。其他时间（从三点开始）则不需要：*hirurak*、*laurak*、*bostak*……

## 后缀 `-ak`

结尾的 **-ak** 是从哪里来的呢？它是巴斯克语的复数形式（你在 *gurasoak*、*aiton-amonak* 中见过）。这里也是一样：*bost* (五) → *bostak* (“五个点钟”) + *dira* (“是”)。

> **注意：**很多人和说西班牙语时一样，使用12小时制来报时。要区分上午或下午，只需在前面加上 *goizeko* (早上的) 或 *arratsaldeko* (下午的)：*goizeko zortziak* (早上八点)。我们将在第3课学习这个内容。

## 练习

现在看看你手机上的时间，然后大声说出来。如果是十一点：*hamaikak dira*。如果是一点：*ordu bata da*。这周内，每次看表时都这样做——这是形成习惯的最佳方式。
