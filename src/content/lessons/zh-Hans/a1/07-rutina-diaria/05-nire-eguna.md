这一课整合了本单元的所有内容：时间、一天中的时段、日常动词和频率。目标是让你能用巴斯克语从头到尾讲述你完整的一天。

## 关键问题："Zer ordutan…?"

| 问题 | 西班牙语 |
|---|---|
| *Zer ordutan esnatzen zara?* | 你几点醒来？ |
| *Zer ordutan jaikitzen zara?* | 你几点起床？ |
| *Zer ordutan gosaltzen duzu?* | 你几点吃早餐？ |
| *Zer ordutan bazkaltzen duzu?* | 你几点吃午饭？ |
| *Zer ordutan ateratzen zara etxetik?* | 你几点出门？ |
| *Zer ordutan afaltzen duzu?* | 你几点吃晚餐？ |
| *Zer ordutan oheratzen zara?* | 你几点上床睡觉？ |

> 注意助动词的变化：*esnatzen **zara*** (NOR)，但 *gosaltzen **duzu*** (NOR-NORK)。你需要开始注意动词和助动词的搭配。

## “在X点”——如何表达

要回答“在（几点）”，取时间的复数形式，然后将 *-ak* 变为 **-etan** （除了已经以元音结尾的词，中间会插入 `-e-`）：

| 时间 | “在…点” |
|---|---|
| zazpiak (七点) | **zazpietan** |
| zortziak | **zortzietan** |
| hamarrak | **hamarretan** |
| hamabiak | **hamabietan** |
| ordu bata (一点) | **ordu batean** (单数，保留其形式) |
| ordu biak | **ordu bietan** |
| bost eta erdiak | **bost eta erdietan** (在五点半) |
| zortziak laurden gutxi | **zortziak laurden gutxitan** (在差一刻八点) |

## 完整的一天——范例

阅读这篇范文，注意各个部分是如何衔接的：

> *Ni goizeko zazpietan esnatzen naiz. Poliki-poliki altxatzen naiz eta komunera joaten naiz. Dutxa bat hartzen dut, arropa janzten dut eta sukaldera joaten naiz. Sukaldean gosaria prestatzen dut eta lasai-lasai gosaltzen dut. Ondoren, etxetik ateratzen naiz eta lanera joaten naiz. Eguerdiko ordu bietan bazkaltzen dut. Arratsaldean batzuetan zinemara joaten naiz, beste batzuetan lagunekin egoten naiz. Gauean, etxean afaltzen dut, telebista ikusten dut eta hamaiketan oheratzen naiz.*

大致翻译：
> *我早上七点醒来。我慢慢地起床，然后去洗手间。我洗个澡，穿上衣服，然后去厨房。在厨房里，我准备早餐，然后悠闲地吃早餐。之后，我出门去上班。中午两点我吃午饭。下午我有时去看电影，有时和朋友们待在一起。晚上，我在家吃晚饭，看电视，十一点上床睡觉。*

## 构建你自己的

用你自己的真实信息来填写这个模板。这是巩固所学知识的最好方法：

1. **你几点醒来：** *Goizeko ___etan esnatzen naiz.*
2. **起床后做什么：** *... dutxatzen naiz / gosaltzen dut / ...*
3. **怎么去上班或上学：** *... oinez / autoz / autobusez joaten naiz.*
4. **下午做什么：** *Arratsaldean ...*
5. **几点吃晚饭和睡觉：** *Gaueko ___etan afaltzen dut eta ___etan oheratzen naiz.*

## 用于衔接的常用短语

- *Lehenengo* — 首先
- *Gero / Ondoren* — 然后，之后
- *Eta gero* — 然后
- *Azkenik* — 最后
- *Egunero* — 每天
- *Batzuetan / Beste batzuetan* — 有时 / 其他时候
- *Beti* — 总是
- *Inoiz ez* — 从不

> **文化小贴士：** 在巴斯克地区，很多人在14:00到15:00之间吃午饭 (*bazkaldu*)，晚餐 (*afaldu*) 吃得相当晚，大约在21:00-22:00。*Hamaiketakoa*——上午十一点的加餐，通常是一个 *pintxo* 或三明治——是一种传统。如果你和一群朋友在一起，上午11点有人说 *hamaiketakoa egitera goaz*，你就知道该做什么了。
