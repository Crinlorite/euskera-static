为了完成本单元，我们还缺少一个部分：**你如何出行**。在西班牙语中，我们使用“en + 交通工具”（“en coche”、“en autobús”）。在巴斯克语中，我们使用后缀 **`-z`**（*工具格*），它附加在交通工具后面，而且令人惊讶的是，它也附加在表示“脚”的词后面。

## 提问

| 问题 | 西班牙语 |
|---|---|
| ***Nola* zoaz?** | 你怎么去？ |
| ***Zerez* zoaz?** | 你乘坐什么（交通工具）去？ |
| ***Nola* doa Iruñera?** | 他/她怎么去潘普洛纳？ |

这两种形式（*Nola* 和 *Zerez*）都有效且常用。*Nola* 更通用；*zerez* 直接表示“乘坐什么交通工具”。

## 交通工具

| 方式 | 带 -z 的形式 | 西班牙语 |
|---|---|---|
| oin (脚) | **oinez** | 步行 |
| kotxe / auto | **kotxez** / **autoz** | 乘汽车 |
| autobus | **autobusez** | 乘公共汽车 |
| tren | **trenez** | 乘火车 |
| metro | **metroz** | 乘地铁 |
| taxi | **taxiz** | 乘出租车 |
| bizikleta | **bizikletaz** | 骑自行车 |
| motor | **motorrez** | 骑摩托车 |
| hegazkin | **hegazkinez** | 乘飞机 |
| itsasontzi | **itsasontziz** | 乘船 |
| furgoneta | **furgonetaz** | 乘货车 |
| zaldi (马) | **zaldiz** | 骑马 |

> 后缀在元音后是 **`-z`**，在辅音后是 **`-ez`** (*autobus → autobusez*）。在实际使用中，几乎所有交通工具的名称都以元音结尾，所以基本公式是：**交通工具 + z**。

## 完整示例

- **Oinez noa lanera.** — 我步行去上班。
- **Iruñera trenez goaz.** — 我们乘火车去潘普洛纳。
- **Bilbora hegazkinez doaz.** — 他们乘飞机去毕尔巴鄂。
- **Eskolara bizikletaz dator alaba.** — 女儿骑自行车来学校。
- **Mendira oinez igotzen gara.** — 我们步行上山。

## 组合 NONDIK + NORA + NOLA

一个典型的旅行句子通常包含三个部分：**从哪里 + 到哪里 + 怎么样**。

- **Iruñetik Donostiara autobusez doa.** — 他/她乘公共汽车从潘普洛纳去多诺斯蒂亚。
- **Bilbotik Madrilera trenez gatoz.** — 我们乘火车从毕尔巴鄂来马德里。
- **Etxetik euskaltegira oinez noa.** — 我从家步行去巴斯克语学校（euskaltegi）。

## 迷你对话

> — *Aupa! Bihar Bilbora **noa**.* — 你好！我明天要去毕尔巴鄂。
>
> — *Eta **nola** zoaz?* — 那你怎么去？
>
> — *Trenez. Oso erosoa da.* — 乘火车。非常舒服。
>
> — *Ni autoz noa beti, baina garestia da gasolina.* — 我总是开车去，但是汽油很贵。

## 关于 “oinez”

乍一看，*oinez* 似乎是一个特例（“用脚”），但实际上它遵循着与其他词完全相同的模式：*oin*（脚）+ *ez*（工具格后缀）。巴斯克语将“步行”视为与其他任何交通方式一样：使用带你到达目的地的工具。

## NORA / NONDIK / NOLA 板块最终复习

| 问题 | 后缀 | 典型问题 | 典型回答 |
|---|---|---|---|
| **Nora?** | -ra | 去哪里？ | *Bilbo**ra** noa.* |
| **Nondik?** | -tik | 从哪里来？ | *Bilbo**tik** nator.* |
| **Nola? / Zerez?** | -z | 怎么去？/ 乘坐什么？ | *Tren**ez** noa.* |

> **技巧：** 这三个后缀组合在一起几乎可以构成任何旅行句子。例如：*Bilbotik Donostiara autobusez goaz, lagun bat bisitatzera*。——“我们乘公共汽车从毕尔巴鄂去多诺斯蒂亚拜访一位朋友。”如果你掌握了这三个后缀以及 *joan* 和 *etorri* 的综合形式，你就可以谈论日常生活中的任何出行活动。
