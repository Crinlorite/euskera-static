当有人问你怎么去一个地方时——或者当你迷路问路时——你需要一些祈使动词和方向副词。在本课中，我们汇集了最基本的内容。

## 基本祈使句

在巴斯克语中，表示移动的动词的肯定祈使式非常直接：

| Forma | Verbo base | Sentido |
|---|---|---|
| **Jo** | jo | 撞击 / 朝向 (jo ezkerrera = 左转) |
| **Segi** / **Jarraitu** | segitu / jarraitu | 继续，接着走 |
| **Hartu** | hartu | 走，上 (hartu kale hau = 走这条街) |
| **Igo** | igo | 上 |
| **Jaitsi** | jaitsi | 下 |
| **Sartu** | sartu | 进 |
| **Irten** | irten | 出 |
| **Zeharkatu** | zeharkatu | 穿过 |
| **Iritsi** / **heldu** | iritsi / heldu | 到达 (… arte = “直到…”) |

> *Jo* 的字面意思是“撞击”，但在这里比喻为“朝……方向去”：**jo ezkerrera** = “向左转”。

## 方向副词和参照物

| Euskera | Castellano |
|---|---|
| *ezkerra* | 左边 |
| *eskuina* | 右边 |
| *aurrera* | 向前 |
| *atzera* | 向后 |
| *zuzen* | 直行 |
| *gora* | 向上 |
| *behera* | 向下 |

> 注意：要表示**朝向某个方向**，使用后缀 `-ra`（你将在第03课深入学习）：*ezkerre-ra*（向左），*aurre-ra*（向前），*atze-ra*（向后）。*gora* 和 *behera* 也是如此。

| Euskera | Castellano |

| *semaforoa* | 红绿灯 |

## 常用短语

- **Jo ezkerrera bidegurutzean.** — 在十字路口左转。
- **Segi aurrera semaforora arte.** — 一直走到红绿灯处。
- **Zeharkatu zebrabidea.** — 穿过人行横道。
- **Igo eskailerak eta sartu eraikinean.** — 上楼梯，然后进入大楼。
- **Jaitsi aldapa, eta gero jo eskuinera.** — 下坡，然后右转。
- **Egin atzera; gehiegi joan zara.** — 往回走，你走过了。

## 问路与指路

> — *Barkatu, **non dago** udaletxea?* — 不好意思，请问市政厅在哪里？
>
> — ***Segi aurrera** semaforora arte. Han **jo eskuinera** eta **zeharkatu** plaza. Udaletxea elizaren ondoan dago.* — 一直走到红绿灯。在那里右转，穿过广场。市政厅就在教堂旁边。
>
> — *Eta gertu **dago**?* — 离得近吗？
>
> — *Bai, oso gertu. Bost minutu oinez.* — 是的，很近。走路五分钟。

> **技巧：** 很多指路说明都遵循一个固定模式：祈使动词 (*jo*, *segi*, *zeharkatu*) + 带后缀的地点 (*ezkerrera*, *semaforora*, *zebrabidea*)。如果你记住了这个模式，就可以通过组合各个部分来连接成长串的指令。
