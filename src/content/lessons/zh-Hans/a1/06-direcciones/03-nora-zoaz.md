**NORA格**（也称作*向格*）表示动作的**目的地**：你要去哪里。在西班牙语中，通常用前置词**“a”**来翻译（例如“voy *a* casa”、“*a* Bilbao”、“*al* parque”）。

## 提问：Nora?

| 问句 | 西班牙语 |
|---|---|
| ***Nora* zoaz?** | 你去哪儿？ |
| ***Nora* doa?** | 他/她/它去哪儿？ |
| ***Nora* goaz?** | 我们去哪儿？ |
| ***Nora* doaz?** | 他们/她们/它们去哪儿？ |

## 后缀：-ra

回答时，我们在目的地后面加上**`-ra`**。具体形式根据单词的结尾而变化：

| 地点的结尾 | 规则 | 例子 |
|---|---|---|
| -a（原生的，如*eskola*） | + ra | eskola → **eskolara** |
| 非-a的元音结尾（如*Bilbo*, *etxe*） | + ra | etxe → **etxera**, Bilbo → **Bilbora** |
| 辅音（如*Madril*, *Gasteiz*） | + era | Madril → **Madrilera**, Gasteiz → **Gasteizera** |

## 示例表

| 地点 | -ra 形式 | 例句 |
|---|---|---|
| etxe (家) | **etxera** | *Etxera noa.* — 我回家。 |
| eskola | **eskolara** | *Eskolara doaz.* — 他们去学校。 |
| euskaltegi | **euskaltegira** | *Euskaltegira goaz.* — 我们去巴斯克语学校。 |
| taberna | **tabernara** | *Tabernara zoaz?* — 你去酒吧吗？ |
| lan (工作) | **lanera** | *Lanera nator.* — 我来上班。（辅音后同样加-era） |
| Bilbo | **Bilbora** | *Bilbora doa.* — 他/她去毕尔巴鄂。 |
| Donostia | **Donostiara** | *Donostiara goaz asteburuan.* — 我们周末去多诺斯蒂亚。 |
| Madril | **Madrilera** | *Madrilera doaz.* — 他们去马德里。 |
| mendi (山) | **mendira** | *Mendira goaz larunbatean.* — 我们周六去爬山。 |

> **小技巧：** *non* → *nora* 的变化规则与 *kale-an* → *kale-ra* 相同。如果你知道如何构成 *Bilbon*（在毕尔巴鄂），你就知道如何构成 *Bilbora*（去毕尔巴鄂）：把 *-n* 换成 *-ra*。如果你知道如何构成 *Madrilen*，你就知道如何构成 *Madrilera*。

## Zertara? — “去干什么？”

要询问你**去干什么**（目的），使用 **Zertara zoaz?**，并用动词 + 后缀 **`-tzera`** 来回答：

| 问句 | 回答 |
|---|---|
| *Zertara zoaz tabernara?* | *Kafea hartzera.* — 去喝咖啡。 |
| *Zertara doa Kepa supermerkatura?* | *Erostera.* — 去买东西。 |
| *Zertara goaz mendira?* | *Ibiltzera.* — 去走路/散步。 |
| *Zertara doaz hondartzara?* | *Igeri egitera.* — 去游泳。 |

> **规则：** *（动词分词形式） + -t(z)era*：*erosi → erostera*，*jan → jatera*，*ikasi → ikastera*，*ikusi → ikustera*，*bisitatu → bisitatzera*。这基本上相当于西班牙语的“a + 动词不定式”。

## 小对话

> — *Nora zoaz, Maialen?* — Maialen，你去哪儿？
>
> — *Euskaltegira noa.* — 我去巴斯克语学校。
>
> — *Eta zertara?* — 去干什么？
>
> — *Klasera, noski! Euskara ikastera.* — 当然是去上课！去学巴斯克语。
>
> — *Eta gero?* — 然后呢？
>
> — *Tabernara goaz lagunekin pote bat hartzera.* — 我们和朋友们去酒吧喝一杯。

## 方向副词

指示词也有其对应的NORA格形式：

| NON (方位格) | NORA (向格) | 意思 |
|---|---|---|
| hemen | **hona** | 到这里来 |
| hor | **horra** | 到那里去 |
| han | **hara** | 到那边去 |

- **Hona zatoz?** — 你到这里来吗？
- **Hara doaz.** — 他们到那边去。

> **重要提示：** 很多人一开始会混淆：*etxean*（在家）≠ *etxera*（回家）≠ *etxetik*（从家里，第04课）。这三个词很像，因为它们都与“家”有关，但表达的信息完全不同。请记住：**NON = -an (在某处)**，**NORA = -ra (去某处)**，**NONDIK = -tik (从某处来，第4课)**。
