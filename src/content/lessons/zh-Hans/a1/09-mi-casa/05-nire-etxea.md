这节课整合了第9单元的所有内容：房间、家具、家务以及你和谁住在一起。目标是让你能用简单的句子**描述你的家**，就像在课堂上或非正式对话中被提问一样。

## 基本问题

| 问题 | 西班牙语 |
|---|---|
| *Non dago zure etxea?* | 你家在哪儿？ |
| *Nolakoa da?* | 它是什么样的？ |
| *Zenbat gela ditu?* | 它有几个房间？ |
| *Norekin bizi zara?* | 你和谁一起住？ |
| *Zenbatgarren solairuan bizi zara?* | 你住在哪一层？ |
| *Etxeak badu igogailua / balkoia / terraza?* | 房子有电梯/阳台/露台吗？ |

## 描述房子的实用形容词

| 巴斯克语 | 西班牙语 |
|---|---|
| *handia* | 大的 |
| *txikia* | 小的 |
| *argitsua* | 明亮的 |
| *iluna* | 昏暗的 |
| *berria* | 新的 |
| *zaharra* | 旧的 |
| *lasaia* | 安静的 |
| *zaratatsua* | 吵闹的 |
| *erosoa* | 舒适的 |
| *garestia* | 贵的 |
| *merkea* | 便宜的 |

> 记住在其他单元学过的 **NOLAKOA da?** 句型：回答时使用形容词 + 词尾 `-a` + 动词 *izan*。例如：*Nire etxea **handia da**.* — 我的房子是大的。

## 范文段落

这里有一个描述房子的简单文本。大声朗读并注意其中的句型。

> *Ni Iruñean bizi naiz, auzo lasai batean. Nire etxea ez da oso handia: hiru gela ditu — bi logela eta egongela bat — sukaldea eta komuna. Egongela argitsua da, eta balkoi bat dauka. Hirugarren solairuan dago, eta etxeak igogailua du.*
>
> *Bikotekidearekin bizi naiz. Berak bazkaria prestatzen du, eta nik ontziak garbitzen ditut. Asteburuetan biok elkarrekin egiten dugu erosketa.*

## 轮到你了：描述你的家

按照以下顺序回答问题，构建你自己的段落：

1. **Non bizi zara?** (你住在哪儿？) → *X-(e)an bizi naiz.*
2. **Nolakoa da etxea?** (它是什么样的？) → *Nire etxea handia / argitsua / lasaia da.*
3. **Zenbat gela ditu?** (有几个房间？) → *Bi / Hiru / Lau gela ditu.*
4. **Zer dago etxean?** (家里有什么？) → *Sukaldea, egongela, bi logela eta komun bat ditu.*
5. **Norekin bizi zara?** → *Bakarrik / Gurasoekin / Lagunekin bizi naiz.*
6. **Etxeko lanak nork egiten ditu?** → *Nik egunero garbitzen dut* / *Pisukideen artean banatzen ditugu.*

## 结尾词汇

| 巴斯克语 | 西班牙语 |
|---|---|
| *etxebizitza* | 住宅 |
| *etxejabea* | 房主 |
| *alokairua* | 租金 |
| *errenta* | 月租 |
| *auzoa* | 街区 |
| *erdigunea* | 市中心 |
| *aldiriak* | 郊区 |

> **建议：**在课堂上谈论你的家时，不要试图翻译每一个细节。坚持使用简短、正确的句子。*"Bi logela ditut, sukalde txiki bat eta egongela handia"* 是比一个充满错误的长句更好的描述。
