在这一课中，你将学习谈论**etxeko lanak**（家务活）的基本动词。在巴斯克语中，动词通常以**分词**形式（`-tu`、`-i`、`-n`）出现，也就是“词典”形式：*garbitu*、*prestatu*、*jaso*……

## 核心动词

| 巴斯克语 | 中文 |
|---|---|
| *garbitu* | 打扫 |
| *prestatu* | 准备 |
| *jaso* | 收拾 |
| *jantzi* | 穿 / 铺 |
| *atera* | 拿出 |
| *zabaldu* | 晾晒 / 打开 |
| *lisatu* | 熨烫 |
| *paseatu* | 散步 |
| *erosi* | 购买 |

## 常见的家务

| 家务 | 说法 |
|---|---|
| 铺床 | *ohea jantzi* |
| 洗碗 | *ontziak garbitu* / *harrikoa egin* |
| 吸尘 | *xurgagailua pasa* |
| 晾衣服 | *arropa zabaldu* |
| 熨衣服 | *arropa lisatu* |
| 打扫卫生间 | *komuna garbitu* |
| 倒垃圾 | *zaborra atera* |
| 准备饭菜 | *bazkaria prestatu* |
| 购物 | *erosketak egin* |
| 遛狗 | *txakurra paseatu* |

## 从词典形式到一般现在时

当一个动作习惯性地重复时（每天、每周……），动词会变为 `-tzen` + 助动词 **dut/duzu/du…**（你已经从 *ukan* 中学过）的形式：

| 人称 | 示例 | 中文 |
|---|---|---|
| Nik | *Nik etxea **garbitzen dut**.* | 我打扫房子。 |
| Zuk | *Zuk arropa **lisatzen duzu**.* | 你熨衣服。 |
| Berak | *Aitak bazkaria **prestatzen du**.* | 我爸爸准备饭菜。 |
| Guk | *Guk erosketak **egiten ditugu**.* | 我们购物。 |

> 在这一课中，你不需要掌握动词变位。只需记住 **`-tzen` + dut/du** 这个模式来谈论日常活动即可。

## 频率

要说明你做某项家务的频率：

- **egunero** — 每天
- **astean behin** — 每周一次
- **astean bitan / hirutan** — 每周两次 / 三次
- **noizean behin** — 偶尔
- **inoiz ez** — 从不

> *Nire etxean nik **astean behin** lisatzen dut, baina **egunero** garbitzen dut sukaldea.* — 在我家，我每周熨一次衣服，但每天都打扫厨房。

## 询问谁做什么

- **Nork garbitzen ditu ontziak?** — 谁洗碗？
- **Nor arduratzen da arropaz?** — 谁负责衣服的事？
- **Zuri gustatzen zaizu sukaldatzea?** — 你喜欢做饭吗？

> **文化小贴士：** 关于家务分工的调查是巴斯克语学校（euskaltegi）教材中的一个经典话题——这是有原因的。这些词汇在与朋友和家人的真实对话中非常有用。
