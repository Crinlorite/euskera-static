每个房间都有自己的家具。“家具”的一般说法是 **altzaria**（复数形式为 *altzariak*）。我们来逐个房间看看。

## Egongelan — 在客厅

| 巴斯克语 | 中文 |
|---|---|
| *sofa* | 沙发 |
| *besaulkia* | 扶手椅 |
| *mahaia* | 桌子 |
| *aulkia* | 椅子 |
| *kuxina* | 靠垫 |
| *lanpara* | 灯 |
| *telebista* | 电视 |
| *apalategia* | 置物架 |

## Logelan — 在卧室

| 巴斯克语 | 中文 |
|---|---|
| *ohea* | 床 |
| *gau-mahaia* | 床头柜 |
| *armairua* | 衣柜 |
| *iratzargailua* | 闹钟 |
| *ordenagailua* | 电脑 |
| *posterra* | 海报 |

## Sukaldean — 在厨房

| 巴斯克语 | 中文 |
|---|---|
| *hozkailua* | 冰箱 |
| *labea* | 烤箱 |
| *mikrouhina* | 微波炉 |
| *garbigailua* | 洗衣机 |
| *ontzi-garbigailua* | 洗碗机 |
| *zartagina* | 平底锅 |
| *edalontzia* | 杯子 |
| *koilara / sardexka / labana* | 勺子 / 叉子 / 刀 |

## Komunean — 在浴室

| 巴斯克语 | 中文 |
|---|---|
| *dutxa* | 淋浴 |
| *bainuontzia* | 浴缸 |
| *konketa* | 洗手池 |
| *ispilua* | 镜子 |
| *eskuoihala* | 毛巾 |
| *komuneko papera* | 卫生纸 |

## 如何在句子中组合

回顾一下你学过的 **ukan**（有），并应用它：

- *Sukaldean hozkailu bat dut.* — 我在厨房里有一台冰箱。
- *Egongelan bi besaulki ditugu.* — 我们在客厅里有两张扶手椅。
- *Logelan ez dut posterrik.* — 我卧室里没有海报。（使用 `-rik` 的否定形式）

> **注意：** *garbigailua*（洗衣机）和 *ontzi-garbigailua*（洗碗机）共享词根 *garbi-*（清洁）。这是巴斯克语如何构建非常直观的复合词的一个很好的例子。
