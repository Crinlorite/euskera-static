我们从任何住宅最基本的部分开始：**房间**。“房间/室”的一般说法是 **gela**，大多数房间的名称都是由一个词根和 `-gela` 组合而成的。

## 基础词汇

| 巴斯克语 | 中文 |
|---|---|
| *etxea* | 房子 |
| *pisua* | 公寓（楼房里的住宅） |
| *gela* | 房间 / 室 |
| *sukaldea* | 厨房 |
| *logela* | 卧室 |
| *komuna* | 卫生间 |
| *egongela* | 客厅 |
| *sarrera* | 玄关 / 入口 |
| *korridorea* / *pasabidea* | 走廊 |
| *balkoia* | 阳台 |
| *terraza* | 露台 |

## 一些名称的构成方式

巴斯克语中这些单词的构成非常直观。如果你看看它们的构成方式，就更容易记住它们：

- **logela** → *lo* (睡眠) + *gela* (房间) = “睡眠的房间” → 卧室
- **egongela** → *egon* (待着) + *gela* = “待着的房间” → 客厅
- **sukaldea** → *su* (火) + *aldea* (区域) = “火的区域” → 厨房

> **Komuna** 和 **bainugela** 是同义词：*komuna* 是日常用词，而 *bainugela*（字面意思是“浴室”）则更正式一些。

## 建筑：楼层和电梯

| 巴斯克语 | 中文 |
|---|---|
| *solairua* | 楼层（第一层，第二层…） |
| *igogailua* | 电梯 |
| *eskailera* | 楼梯 |
| *ataria* | 大门 / 门厅 |

要说你住在哪一层：

- *Hirugarren solairuan bizi naiz.* — 我住在三楼。
- *Etxeak igogailua du.* — 这栋房子有电梯。

## 实用问题

- **Zenbat gela ditu zure etxeak?** — 你家有几个房间？
- **Zenbat logela ditu?** — 有几间卧室？
- **Non dago sukaldea?** — 厨房在哪里？
- **Etxeak badu balkoirik?** — 房子有阳台吗？

> **文化小贴士：** 在纳瓦拉和巴斯克-卡斯蒂利亚地区，人们习惯用 *pisua* 指城市住宅，用 *etxea* 指家庭住宅/村里的房子。在日常生活中，这两个词可以混合使用，没有问题。
