除了父母、兄弟姐妹和子女，家庭成员还包括叔伯、堂表亲、侄甥和姻亲。以下是一些最常用的词汇。

## 叔伯与堂表亲

| 巴斯克语 | 中文 |
|---|---|
| *osaba* | 叔叔/伯伯/舅舅 |
| *izeba* | 阿姨/姑姑 |
| *lehengusu* | 堂/表兄弟 |
| *lehengusina* | 堂/表姐妹 |
| *iloba* | 侄子/女，外甥/女（在某些方言中也指“孙子/女”——需根据上下文判断） |

## 姻亲

| 巴斯克语 | 中文 |
|---|---|
| *aitaginarreba* | 岳父/公公 |
| *amaginarreba* | 岳母/婆婆 |
| *koinatu* | 内兄/弟，姐/妹夫 |
| *koinata* | 姑/姨，嫂/弟媳 |
| *errain* | 儿媳 |
| *suhi* | 女婿 |

## 用法模式

- *Nire osaba Bilbon bizi da.* — 我的叔叔住在毕尔巴鄂。
- *Bere lehengusinak hamabi urte ditu.* — 他的堂/表姐（妹）十二岁了。
- *Zure koinata euskalduna da?* — 你的弟媳是巴斯克人吗？

> 表示姻亲的词通常由现有词组合而成 (*aita-* + *ginarreba*)。无需记忆其内部逻辑，通过使用自然会掌握。
