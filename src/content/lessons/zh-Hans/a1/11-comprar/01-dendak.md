当你在 Euskal Herria 购物时，每种商品通常都有专门的商店，尤其是在村镇和社区里。学习这些名称有助于你出行，也能帮助你看懂招牌。

## 食品店

| 巴斯克语 | 西班牙语 | 售卖商品 |
|---|---|---|
| *harategia* | 肉店 | haragia (肉) |
| *okindegia* | 面包店 | ogia (面包) |
| *arrandegia* | 鱼店 | arraina (鱼) |
| *fruta-denda* | 水果店 | frutak, barazkiak |
| *supermerkatua* | 超市 | 什么都卖 |
| *hipermerkatua* | 大型超市 | 大型卖场 |
| *azoka* / *plaza* | 市场 / 广场 | 多个摊位 |

## 隐藏的线索：*-degi*

许多商店的名称以 **-degi** 结尾，这是一个古老的后缀，意思是“有……的地方”：

- *ogi* (面包) → **okindegia** (面包店)
- *haragi* (肉) → **harategia** (肉店)
- *arrain* (鱼) → **arrandegia** (鱼店)
- *gozo* (甜食) → **gozotegia** (糕点店)

> 当你发现 *-degi* 这个规律后，即使你以前没见过其他商店的名称，也能认出来。

## 其他有用的地方

| 巴斯克语 | 西班牙语 |
|---|---|
| *kutxazain automatikoa* | 自动取款机 |
| *banketxea* | 银行 |
| *postetxea* | 邮局 |
| *tabako-denda* | 烟草店 |

## 表达你要去哪里

要去某个商店，使用表示“目的地”的 **NORA** 格，其后缀为 `-ra`：

- *Okindegi**ra** noa.* — 我去面包店。
- *Harategi**ra** joango naiz.* — 我要去肉店。
- *Fruta-denda**ra** joaten naiz astero.* — 我每周都去水果店。

> **文化小贴士：**许多家庭仍然分开购物：在社区的 *arrandegia* 买鱼，在 *okindegia* 买面包，只有其他东西才去超市买。因此，经常可以听到 “*okindegira noa*” 这样的日常表达。
