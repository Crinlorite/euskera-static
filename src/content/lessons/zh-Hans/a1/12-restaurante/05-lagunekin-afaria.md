你已经掌握了所有部分：餐厅类型、菜单、点餐、付款。让我们把它们整合到一次与朋友的晚餐中：安排约会、点餐和结束夜晚。

## 1. 约晚餐

> — *Aizue, ostiralean afaltzera joango gara?* — 嘿，我们周五去吃晚饭好吗？
>
> — *Bai, ideia ona!* — 好啊，好主意！
>
> — *Nik ezin dut ostiralean. Larunbatean ondo?* — 我周五不行。周六可以吗？
>
> — *Ados. Zer ordutan geratuko gara?* — 好的。我们几点见？
>
> — *Bederatzi eta erdietan, taberna ondoan?* — 九点半，在酒吧旁边？
>
> — *Ederki!* — 太好了！

当你去不了时，用来推辞的句子：

- **Ezin dut, beste plan bat dut.** — 我去不了，我有别的安排了。
- **Ezin dut, bihar lan egin behar dut.** — 我去不了，明天得工作。
- **Beste egun batean izan beharko du.** — 只能改天了。

## 2. 预订

> — *Egun on! "Kutixi" jatetxea al da?*
>
> — *Bai, esan.*
>
> — *Erreserba egin nahi dut, larunbat gauerako.*
>
> — *Zenbat lagunentzat?*
>
> — *Lau lagun izango gara.*
>
> — *Zer ordutan?*
>
> — *Bederatzi eta erdietan.*
>
> — *Noren izenean?*
>
> — *Mikelen izenean.*
>
> — *Oso ondo. Larunbat arte!*

## 3. 在餐桌上

入座时的问候语：

- **On egin!** — 请慢用！
- **Topa!** — 干杯！(祝酒时)

点餐，用上所有学过的部分：

> — *Hasteko, niretzat entsalada mistoa, mesedez.*
>
> — *Eta niretzat arrain-zopa.*
>
> — *Bigarrenerako, niretzat legatza saltsan.*
>
> — *Niri, txuleta. Eta edateko, ardo gorria botila bat, mesedez.*

## 4. 评论食物

| 巴斯克语 | 中文 |
|---|---|
| *Oso goxoa zegoen!* | 非常好吃！ |
| *Hau betekada!* | 吃得好撑！ |
| *Beste botila bat ardo, mesedez.* | 请再来一瓶红酒。 |
| *Postrerako, izozkia hartuko dut.* | 甜点我要冰淇淋。 |
| *Nik ez dut postrerik nahi.* | 我不要甜点。 |

## 5. 结束夜晚

> — *Aizu, kobratuko al diguzu?*
>
> — *Bai, oraintxe. Berrogeita hamabi euro eta hogeita bost zentimo.*
>
> — *Txartelaz ordain dezakegu?*
>
> — *Bai, noski.*
>
> — *Eskerrik asko! Oso ondo zegoen.*
>
> — *Zuri! Hurrengora arte!*

## 可视化总结

```
1. 约见:      Etorri nahi duzu afaltzera?  →  Bai, ados!
2. 预订:     Erreserba egin nahi dut...   →  Noren izenean?
3. 点餐:       Hasteko... Bigarrenerako...  →  Postrerako...
4. 享用:   On egin! / Topa! / Goxoa zegoen!
5. 付款:       Kontua, mesedez. / Txartelaz ordain dezaket?
```

> **文化小贴士：** *On egin!* 这个说法也用于当你经过在公共场所（露台、水果店，任何地方）吃饭的人旁边时。这是一个非常典型的礼貌姿态，听到后最好回应一下：通常的回应是 *Eskerrik asko!*。
