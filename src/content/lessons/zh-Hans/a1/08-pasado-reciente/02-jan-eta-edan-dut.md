**及物动词**是带动词宾语的动词：某人吃*某物*，看*某物*，读*某物*。在巴斯克语中，这些动词使用助动词 **ukan** (dut, duzu, du…)。在最近过去时中，公式是：

> **partizipioa + dut/duzu/du/dugu/duzue/dute**

## 基本及物动词

| Partizipioa | 我 (he…) | 中文意思 |
|---|---|---|
| *jan* | **jan dut** | 我吃了 |
| *edan* | **edan dut** | 我喝了 |
| *ikusi* | **ikusi dut** | 我看了 |
| *irakurri* | **irakurri dut** | 我读了 |
| *entzun* | **entzun dut** | 我听了 |
| *erosi* | **erosi dut** | 我买了 |
| *egin* | **egin dut** | 我做了 |
| *hartu* | **hartu dut** | 我拿了 / 我吃了/喝了 |
| *ekarri* | **ekarri dut** | 我带来了 |
| *eraman* | **eraman dut** | 我带走了 |
| *ikasi* | **ikasi dut** | 我学了 / 我学习了 |
| *eskatu* | **eskatu dut** | 我点了 / 我要了 |
| *ordaindu* | **ordaindu dut** | 我付钱了 |
| *idatzi* | **idatzi dut** | 我写了 |
| *prestatu* | **prestatu dut** | 我准备了 |
| *garbitu* | **garbitu dut** | 我打扫了 |
| *gosaldu* | **gosaldu dut** | 我吃早饭了 |
| *bazkaldu* | **bazkaldu dut** | 我吃午饭了 |
| *afaldu* | **afaldu dut** | 我吃晚饭了 |
| *lan egin* | **lan egin dut** | 我工作了 |

## 一个动词的完整变位

我们以 *ikusi* (看) 为例：

| 代词 + 主语 | 形式 | 中文意思 |
|---|---|---|
| Nik | **ikusi dut** | 我看了 |
| Zuk | **ikusi duzu** | 你看了 |
| Hark | **ikusi du** | 他/她看了 |
| Guk | **ikusi dugu** | 我们看了 |
| Zuek | **ikusi duzue** | 你们看了 |
| Haiek | **ikusi dute** | 他们/她们看了 |

> 及物动词的主语带有 **NORK** 标记 (-k)：*nik, zuk, hark, guk, zuek, haiek*。你会经常看到它，尤其是在主语是名字的时候：*Mikelek* (Mikel 已经…)，*Maialenek* (Maialen 已经…)。如果这让你感到困惑，在A1阶段你可以省略代词，只保留动词：上下文就足够了。

## 典型句子

- *Gaur goizean egunkaria irakurri dut.* — 今天早上我读了报纸。
- *Bazkaltzeko arraina jan dut.* — 午饭我吃了鱼。
- *Lagunekin kafea hartu dut.* — 我和朋友们喝了咖啡。
- *Mikelek ardoa erosi du.* — Mikel 买了酒。
- *Guk pelikula bat ikusi dugu.* — 我们看了一部电影。
- *Haiek euskara ikasi dute gaur.* — 他们今天学习了巴斯克语。

## 否定

要说“我没做X”，**ez** 放在助动词前面：

> *Ez dut bazkaldu.* — 我没吃午饭。
>
> *Ez du egunkaria irakurri.* — 他/她没读报纸。
>
> *Ez dugu ardorik edan.* — 我们没喝酒。（注意 *ardorik*：在否定句中，宾语通常带有部分格 **-rik**。）

## 迷你对话

> *— Zer afaldu duzu gaur, Maialen?*
>
> *— Entsalada eta arraina jan dut, eta postrerako jogurta hartu dut. Eta zuk?*
>
> *— Nik tortilla egin dut, baina ez dut postrerik jan.*

> **图文总结：**如果动作有明确或隐含的宾语（吃某物，看某物，做某物），助动词就是 **dut**（及其变位形式）。记住这些动词-助动词组合，其余的就迎刃而解了。
