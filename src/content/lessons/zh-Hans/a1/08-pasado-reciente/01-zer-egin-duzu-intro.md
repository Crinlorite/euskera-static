在巴斯克语中，要讲述不久前——尤其是今天——做过的事情，我们会使用 **orainaldi burutua**（字面意思是“现在完成时”），它相当于西班牙语的 *he comido / he ido*。这就是所谓的**最近过去时**。

## 公式非常简单

> **Partizipioa + 助动词 (izan 或 ukan)**

与你在上一单元学过的惯常体相比，唯一的变化是动词**不带 -tzen / -ten**：

| 惯常体 | 最近过去时 | 西班牙语 |
|---|---|---|
| *gosaltzen dut* | **gosaldu dut** | 我吃早餐 → 我吃过早餐了 |
| *jaten dut* | **jan dut** | 我吃 → 我吃过了 |
| *joaten naiz* | **joan naiz** | 我去 → 我去过了 |
| *etortzen naiz* | **etorri naiz** | 我来 → 我来过了 |
| *ikusten dut* | **ikusi dut** | 我看 → 我看过了 |

> **这和西班牙语中**一般现在时和现在完成时的区别是一样的：
>
> - *Egunero euskaltegira **joaten naiz**.* — 我每天都去巴斯克语学校。
> - *Gaur goizean euskaltegira **joan naiz**.* — 今天早上我去了巴斯克语学校。

## 最自然的提问方式

> *— **Zer egin duzu gaur?*** — 你今天做了什么？
>
> *— Lan egin dut, eta gero zinera joan naiz.* — 我工作了，然后去看了电影。

注意这两种形式：**lan egin dut**（用 *dut* 是因为在巴斯克语中“工作”需要带宾语）和 **joan naiz**（用 *naiz* 是因为“去”不带宾语）。

## 两个助动词 — 快速复习

### 使用 izan (NOR) — naiz / zara / da / gara / zarete / dira

| 代词 | 助动词 | 例子 |
|---|---|---|
| ni (我) | naiz | *joan **naiz*** (我去过了) |
| zu (你) | zara | *etorri **zara*** (你来过了) |
| hura (他/她) | da | *esnatu **da*** (他/她醒了) |
| gu (我们) | gara | *joan **gara*** (我们去过了) |
| zuek (你们) | zarete | *etorri **zarete*** (你们来过了) |
| haiek (他们) | dira | *joan **dira*** (他们去过了) |

### 使用 ukan (NOR-NORK) — dut / duzu / du / dugu / duzue / dute

| 代词 | 助动词 | 例子 |
|---|---|---|
| nik (我) | dut | *jan **dut*** (我吃过了) |
| zuk (你) | duzu | *ikusi **duzu*** (你看过了) |
| hark (他/她) | du | *erosi **du*** (他/她买过了) |
| guk (我们) | dugu | *egin **dugu*** (我们做过了) |
| zuek (你们) | duzue | *jan **duzue*** (你们吃过了) |
| haiek (他们) | dute | *ikusi **dute*** (他们看过了) |

## 迷你对话

> *— Kaixo Maialen! Zer moduz?*
>
> *— Ondo. Eta zu? **Zer egin duzu gaur?***
>
> *— Lan egin dut goizean, eta arratsaldean lagun batekin kafea hartu dut.*
>
> *— Polita. Ni gaur ez naiz lanera joan, gaixo egon naiz.*

> **基本总结：**关键在于知道每个动词使用哪个助动词（我们将在接下来的两课中学习），并且保持分词形式，不加惯常体标记 *-tzen/-ten*。
