要想清楚地讲述发生过的事，你需要说明**什么时候**。这一课将教你一些与最近过去时搭配使用的时间标记，用来确定动作发生的时间。

## 基本标记

| 巴斯克语 | 中文 |
|---|---|
| *gaur* | 今天 |
| *atzo* | 昨天 |
| *bihar* | 明天 |
| *etzi* | 后天 |
| *orain* | 现在 |
| *oraintxe* | 立刻，马上 |
| *lehen* | 以前 |
| *gero* | 之后，然后 |

> 如果你注意到了，*atzo* (昨天) 和 *bihar* (明天) 这两个词很短，可以一下子就学会。*Etzi* (后天) 这个词在西班牙语里没有对应的单个词语——这是巴斯克语送给你的一个小礼物。

## 与一天中的不同时段组合

这些标记可以与上一单元学过的 *goizean*、*arratsaldean*、*gauean* 等词组合。公式是：**标记 + 一天的某个时段**。

| 巴斯克语 | 中文 |
|---|---|
| *gaur goizean* | 今天早上 |
| *gaur eguerdian* | 今天中午 |
| *gaur arratsaldean* | 今天下午 |
| *gaur gauean* | 今晚 |
| *atzo goizean* | 昨天早上 |
| *atzo arratsaldean* | 昨天下午 |
| *atzo gauean* | 昨晚 |
| *bihar goizean* | 明天早上 |

> **注意：** *gaur gauean* 是“今晚”（指即将到来或正在经历的夜晚）；*atzo gauean* 是“昨晚”。巴斯克语对此区分得非常清楚。

## 频率和次数

| 巴斯克语 | 中文 |
|---|---|
| *behin* | 一次 |
| *bi aldiz* | 两次 |
| *hiru aldiz* | 三次 |
| *askotan* | 经常，很多次 |
| *batzuetan* | 有时 |
| *inoiz ez* | 从不 |
| *gaur goizetik* | 从今天早上起 |
| *aste honetan* | 这周 |
| *hilabete honetan* | 这个月 |

## 使用最近过去时和标记的句子

> *Gaur goizean lanera joan naiz autoz.* — 今天早上我开车去上班了。
>
> *Gaur arratsaldean Mikelekin egon naiz.* — 今天下午我和 Mikel 待在一起了。
>
> *Gaur oso berandu esnatu naiz.* — 今天我起得很晚。
>
> *Gaur eguerdian etxean bazkaldu dut.* — 今天中午我在家吃的饭。
>
> *Aste honetan bi aldiz egon naiz zinean.* — 这周我去了两次电影院。

## 语序

在巴斯克语中，带时间标记的句子的典型语序是：

> **时间 + 地点 + 内容 + 动词**

> **Gaur goizean** + **euskaltegian** + **euskara** + **ikasi dut**. — 今天早上我在巴斯克语学校学习了巴斯克语。

这不是唯一的可能性——巴斯克语允许移动句子成分来强调——但如果你遵循这个顺序，就不会出错。

## 迷你对话

> *— Eta gaur zer egin duzu, Maialen?*
>
> *— **Gaur goizean** lanera joan naiz oinez. **Eguerdian** lagunekin bazkaldu dut tabernan. **Arratsaldean** etxera bueltatu naiz eta liburua irakurri dut. **Gauean** ez dut afaldu, asko jan baitut bazkarian.*

> **注：** *gaur* 指的是今天的整一天。如果你想说得更具体，可以加上具体时段 (*gaur goizean*, *gaur arratsaldean*)。在日常对话中，*Zer egin duzu gaur?* 通常被理解为“你今天一整天都做了什么？”。
