学会说“在X处”之后，下一步就是说出**确切的位置**：上面、下面、旁边、后面……在巴斯克语中，这些位置总是遵循**参照物 + 位置**的模式来构建。

## 基本位置

| Euskera | 中文 |
|---|---|
| *aurrean* | 前面 |
| *atzean* | 后面 |
| *ondoan* | 旁边 |
| *gainean* | 上面 |
| *azpian* | 下面 |
| *artean* | 在……之间 |
| *ezkerrean* | 在左边 |
| *eskuinean* | 在右边 |
| *barruan* | 里面 |
| *kanpoan* | 外面 |
| *erdian* | 在中间 |

## 如何构建：-(r)en + 位置

基本公式是**(参照物)-(r)en + 位置**。参照物使用属格`-(r)en`（相当于中文的“的”）：

| Euskera | 中文（字面意思） |
|---|---|
| **mahaiaren gainean** | 在桌子上面（字面意思：“桌子的，上面”） |
| **etxearen aurrean** | 在房子前面 |
| **elizaren atzean** | 在教堂后面 |
| **parkearen ondoan** | 在公园旁边 |
| **kutxaren barruan** | 在盒子里 |
| **bi mendien artean** | 在两山之间 |

模式：参照物在前，位置在**后**。这与中文的顺序正好相反。

## 完整例句

- **Liburua mahaiaren gainean dago.** — 书在桌子上面。
- **Katua aulkiaren azpian dago.** — 猫在椅子下面。
- **Eliza plazaren erdian dago.** — 教堂在广场中央。
- **Botika eskolaren ondoan dago.** — 药店在学校旁边。
- **Ni Maiteren eta Anaren artean nago.** — 我在Maite和Ana之间。

## 地点副词：hemen / hor / han

为了快速指明位置，有三个副词——注意，是**三个距离**，不像中文通常只区分“这里”和“那里”两个：

| Euskera | 中文 | 何时使用 |
|---|---|---|
| *hemen* | 这里 | 靠近说话者 |
| *hor* | 那儿 | 靠近听话者 |
| *han* | 那里 | 远离两人 |

> 这三个副词分别对应指示词*hau / hori / hura*及其长的方位格形式*honetan / horretan / hartan*（“在这个/在那个/在那个”）。

快速示例：

- **Hemen** taberna bat dago. — 这里有一家酒吧。
- **Hor** parkea dago. — 公园就在那儿。
- **Han** dago euskaltegia. — 巴斯克语学校在那里。

## 迷你对话：玩捉迷藏

> — *Pilota mahaiaren azpian dago?* — 球在桌子下面吗？
>
> — *Ez, pilota ez dago mahaiaren azpian.* — 不，球不在桌子下面。
>
> — *Aulkiaren atzean dago?* — 在椅子后面吗？
>
> — *Bai, hor dago!* — 是的，就在那儿！

> **技巧：**所有表示位置的词本身都已包含后缀`-an`（*aurr-ean*、*atz-ean*、*azp-ian*……）。你不需要再添加任何东西。
