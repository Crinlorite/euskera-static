本课是单元综合课，内容涵盖：地点词汇、方位格 `-(e)an`、空间位置词 (*aurrean*, *ondoan*…)，以及 **存在 / 位于** (*badago* / *dago*) 的区别。学完后，你将能够用真实的句子描述你的街区或村庄。

## 描述的结构

对街区或村庄的典型描述遵循以下顺序：

1. **这个地方怎么样**（大小、特点）：*Nire auzoa txikia eta polita da.*
2. **有什么**和没有什么：*Auzoan badago liburutegia, baina ez dago zinemarik.*
3. 每个重要的地方**在哪里**：*Liburutegia plazaren ondoan dago.*
4. **你住在哪里**以及和谁一起住：*Ni Maialenen ondoan bizi naiz, etxe txiki batean.*

## 描述性词汇

| 巴斯克语 | 中文 |
|---|---|
| *handi* | 大的 |
| *txiki* | 小的 |
| *ertain* | 中等的 |
| *polit* | 漂亮的 |
| *itsusi* | 丑的 |
| *zaharra* | 旧的 |
| *berria* | 新的 |
| *lasai* | 安静的 |
| *jendetsu* | 人多的 |
| *modernoa* | 现代的 |
| *erdigunean* | 在市中心 |
| *kanpoaldean* | 在郊区 |

> 记住：在巴斯克语中，形容词放在**名词后面**，并加上冠词 `-a`。*Auzo + handi + a* → *auzo handia*（“大街区”）；*auzo + txiki + a* → *auzo txikia*。

## 全部结合：范例

> *Ni Iruñean bizi naiz, Txantrea auzoan. Auzoa ez da oso handia, baina lasaia eta polita da. Auzoan badago supermerkatu txiki bat, bi taberna eta okindegi bat. Eskola plazaren ondoan dago, eta liburutegia eskolaren atzean. Parkea handia da, eta umeentzat oso ona. Auzoan ez dago zinemarik, baina hori ez da arazoa: zinema erdigunean dago, eta gertu dago. Nire etxea bigarren solairuan dago, kale lasai batean.*

参考译文：

> 我住在潘普洛纳的 Txantrea 街区。这个街区不是很大，但很安静、漂亮。街区里有一个小超市、两家酒吧和一家面包店。学校在广场旁边，图书馆在学校后面。公园很大，对孩子们来说非常好。街区里没有电影院，但这不是问题：电影院在市中心，而且离得近。我家在二楼，位于一条安静的街道上。

## 别人会问你的问题

| 问题 | 回答类型 |
|---|---|
| ***Non bizi zara?*** | 地点 + 方位格：*X-(e)an bizi naiz.* |
| ***Nolakoa da zure auzoa?*** | 形容词：*Polita da, txikia da…* |
| ***Zer dago zure auzoan?*** | 表示存在：*Badago…, badaude…* |
| ***Ba al dago tabernarik?*** | 是/否：*Bai, badago / Ez, ez dago tabernarik.* |
| ***Non dago liburutegia?*** | 表示位置：*Plazaren ondoan dago.* |

## 该你了

想象你的同伴不认识你的街区。请描述：

1. 它叫什么名字，在哪里。
2. 它是大是小，是旧是新。
3. **有**哪三个地方（用 *badago / badaude*）。
4. **没有**哪三样东西（用 *ez dago … rik*）。
5. 你家具体在哪里（街道、楼层、在什么旁边）。

> **文化小贴士：**许多巴斯克街区和村庄都以 **frontoia**（回力球场）和 **eliza**（教堂）为参照物，它们通常一个挨着一个，靠近主广场。如果你的街区有广场、回力球场或教堂，这就是给别人指路的最佳参照物。
