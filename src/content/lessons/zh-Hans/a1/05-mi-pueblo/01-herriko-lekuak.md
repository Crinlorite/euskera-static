在学会指路之前，你需要掌握谈论街区 (**auzoa**) 和村镇 (**herria**) 的基本词汇。在本课中，我们汇集了最典型的地方和服务。

## 商店和商业

| 巴斯克语 | 西班牙语 |
|---|---|
| *taberna* | 酒吧 |
| *kafetegia* | 咖啡馆 |
| *jatetxea* | 餐馆 |
| *okindegia* | 面包店 |
| *harategia* | 肉店 |
| *arrandegia* | 鱼店 |
| *fruta-denda* | 水果店 |
| *gozoki-denda* | 糖果店 |
| *merkatua* / *supermerkatua* | 市场 / 超市 |
| *jantzi-denda* | 服装店 |
| *liburu-denda* | 书店 |
| *loradenda* | 花店 |

> 很多单词遵循 **产品 + denda**（“……的店”）的模式：*fruta-denda*、*liburu-denda*、*jantzi-denda*。如果你知道产品是什么，你就知道这个地方是哪里。

## 后缀 -tegi 及其相关后缀

注意这些高产的后缀：它们会反复出现。

- **-tegi** → 表示“……的地方”：*euskal·tegi*（巴斯克语的地方），*ile-apain·degi*（整理头发的地方），*liburu·tegi*（书的地方）。
- **-degi / -tegi** → 意思相同的变体：*gasolin·degi*、*okin·degi*。
- **-etxe**（“房子”）→ *udal·etxe*（议会的房子），*osasun·etxe*（健康的房子），*jatetxe*（吃饭的地方）。

> **文化小贴士：**在许多巴斯克街区和村镇，**taberna**（酒吧）和 **plaza**（广场）是绝佳的聚会地点，而 **frontoia**（回力球场）通常位于教堂旁边。一个 *euskaltegi* 正是你学习这门语言的学校。
