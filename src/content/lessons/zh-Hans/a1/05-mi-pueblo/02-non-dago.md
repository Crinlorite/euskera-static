在“你住在哪里”这一课中，你已经学过后缀 **`-(e)an`** (*Bilbon bizi naiz*)。在这里，我们把它应用到街区上：说明各个东西在哪里。

## 提问：Non dago…？

要问**……在哪里？**，我们使用：

- **Non dago …?** — ……在哪里？+（单数主语）
- **Non daude …?** — ……们在哪里？+（复数主语）
- **Non zaude?** — 你在哪里？
- **Non nago?** — 我在哪里？

动词是 **egon**（“在”），你在问候语中已经见过它。记住这些形式：

| 人称 | 形式 |
|---|---|
| ni | **nago** |
| zu | **zaude** |
| hura | **dago** |
| gu | **gaude** |
| zuek | **zaudete** |
| haiek | **daude** |

## 回答：地点 + `-(e)an` + dago

要说某物**在哪里**，在地点后面加上后缀 **`-(e)an`**：

| 地点词尾 | 模式 | 例子 |
|---|---|---|
| -a（词干自带的，如 *Donostia*） | + n | Donostia → **Donostian** |
| 非-a元音结尾（*mendi*，*kale-*） | + an | mendi → **mendian** |
| 辅音（*Madril*，*lur*） | + en（专有名词）/ + ean（普通名词） | Madril → **Madrilen**; lur → **lurrean** |

> 关于像 *kale*（街道）这类词的提示：当它们带上冠词 *kalea*（“这条街道”）时，在添加后缀前要去掉冠词的 `-a`：*kalea* → *kale-an* = **kalean**（“在街上”）。

## 完整示例

- **Botika kalean dago.** — 药店在街上。
- **Liburuak mahaian daude.** — 书在桌子上。
- **Ikaslea ikasgelan dago.** — 学生在教室里。
- **Aita tabernan dago.** — 爸爸在酒吧里。
- **Ni euskaltegian nago.** — 我在巴斯克语学校。
- **Bilbo Bizkaian dago.** — 毕尔巴鄂在比斯开省。

## 迷你对话

> — *Aupa! **Non dago** liburutegia?* — 你好！图书馆在哪里？
>
> — *Liburutegia plazan dago, eskolaren ondoan.* — 图书馆在广场上，学校旁边。
>
> — *Eskerrik asko!*

> **小窍门：** *non* = 巴斯克语中的“哪里”。任何对 *non…?* 的回答都带有一个含后缀 `-(e)an` 的名词或一个地点副词（*hemen*、*hor*、*han*——你将在下一课学到它们）。
