在本课中，你将学习比较级的另外两种形式：

1. **等同级**（“和……一样……”，“和……一样多”）：*bezain*、*adina*、*beste*。
2. **最高级**（“最……”）：*-en + a*。

## 等同级：*bezain*

用于形容词或副词，表示“和……一样……”：

> **X bezain Y**

| 西班牙语 | 巴斯克语 |
|---|---|
| 和你一样高 | *Zu **bezain** altua* |
| 和多诺斯蒂亚一样美 | *Donostia **bezain** polita* |
| 和他父亲一样好 | *Aita **bezain** ona* |
| 不像我想的那么快 | *Uste nuen **bezain** azkarra ez da* |

> 完整句子：*Lander **zu bezain altua** da.* — Lander 和你一样高。

## 数量等同级：*adina / beste*

用于名词或数量，表示“和……一样多”：

| 西班牙语 | 巴斯克语 |
|---|---|
| 和你一样多 | *Zuk **adina*** / *Zuk **beste*** |
| 和我一样多的钱 | *Nik **adina** diru* |
| 和 Anboto 一样多的年份 | *Anbotok **adina** urte* |

> *Zuk adina urte ditut.* — 我的年龄和你一样大。
>
> *Garazik nik beste irakurtzen du.* — Garazi 读的书和我一样多。

> **区别：** *bezain* 用于修饰性质（形容词/副词）。*Adina/beste* 用于修饰数量（可数名词或数量名词）。有时人们会混淆——实用法则是：如果后面的词是**形容词** → *bezain*；如果是**名词或数字** → *adina/beste*。

## 方式比较：*bezala / moduan*

另一种表示等同的方式，这次是关于**方式**或**方法**：

| 西班牙语 | 巴斯克语 |
|---|---|
| 像你一样 | *Zu **bezala*** / *Zure **moduan*** |
| 我像你一样做 | *Zuk egin duzun **moduan** egiten dut* |
| 一栋像你家那样的房子 | *Zurea **bezalako** etxea* |
| 她说话像她妈妈 | *Amaren **moduan** hitz egiten du* |

> 比较：
>
> - *Zu **bezain** altua* — 和你一样高（性质）
> - *Zu **bezala** hitz egiten du* — 说话像你一样（方式）
> - *Zuk **adina** ikasten du* — 和你学得一样多（数量）

## 最高级：*-en + a*

要表示“最……”，在形容词或副词后加上 **-en** + 定冠词 **-a**：

| 形容词 | 最高级 |
|---|---|
| *handia* (大) | *handi**ena*** (最大的) |
| *txikia* (小) | *txiki**ena*** |
| *polita* (漂亮) | *polit**ena*** |
| *zaharra* (老) | *zaharr**ena*** |
| *azkarra* (快) | *azkarr**ena*** |
| *garestia* (贵) | *garesti**ena*** |
| *ona* (好) | **onena** / **hoberena** (不规则) |
| *txarra* (坏) | **txarrena** / **okerrena** |

> *Liburu hau **politena** da.* — 这本书是最漂亮的。
>
> *Donostia Euskal Herriko hiri **politena** da, askoren ustez.* — 在许多人看来，多诺斯蒂亚是巴斯克地区最美的城市。

## 最高级 + 范围：*-etan / -etako*

当你要指明**在哪个范围内**时，使用方位格或所有格：

| 西班牙语 | 巴斯克语 |
|---|---|
| 班里最高的 | *Klaseko **altuena*** |
| 世界上最快的 | *Munduko **azkarrena*** |
| 所有人中最好的 | *Denetan **onena*** / *Guztietan **onena*** |
| 日子中最糟的 | *Egunetan **txarrena*** |

> *Klaseko ikasle **azkarrena** da.* — 他是班里最快的学生。
>
> *Euskal Herriko mendi **altuena** Hiru Errege Mahaia da.* — 巴斯克地区最高的山是 Hiru Errege Mahaia（三王台）。

## *Gehien / gutxien* — 最多 / 最少

用于数量或频率的最高级对等词：

| 西班牙语 | 巴斯克语 |
|---|---|
| 我最喜欢的东西 | *Gehien gustatzen zaidana* |
| 我最少做的事 | *Gutxien egiten dudana* |
| 学习最多的人 | *Gehien ikasten duena* |

## 文化小比较

典型句子：

- *Hiru Errege Mahaia Euskal Herriko mendi **altuena** da.* — Hiru Errege Mahaia（三王台）是巴斯克地区最高的山。
- *Korrika euskararen aldeko ekintza **handiena** da.* — Korrika 是支持巴斯克语的最大型活动。
- *San Fermin festa famatuena da.* — 圣费尔明节是最著名的节日。

## 记忆技巧

| 形式 | 例子 |
|---|---|
| 比较级（比 X 更…） | *X baino Y-**agoa*** |
| 等同级（和…一样 X） | *Y bezain X* |
| 数量等同级（和…一样多） | *Yk adina X* |
| 最高级（最 X 的） | *X-**ena*** |
| 范围内的最高级 | *Z-ko / Z-etan + X-**ena*** |

## 小对话

> *— Anboto, hau bai pintxoa! Sekula jan dudan **goxoena**.*
>
> *— Bai, **zure ustez** Bilboko **onenak** non daude?*
>
> *— Plaza Berrian. Han pintxoak **garestienak** dira, baina **goxoenak** ere bai. Donostiakoak ere ez dira **gutxiago**: ia **maila berekoak** dira.*

> **文化小贴士：**在*巴斯克地区*的典型辩论中，*Donostiako pintxoak Bilbokoak baino hobeak dira*（多诺斯蒂亚的 pintxo 比毕尔巴鄂的好）是一个经典的友好争论话题。现实是：每个地区都为自己的 pintxo 辩护，而且都非常好吃。
