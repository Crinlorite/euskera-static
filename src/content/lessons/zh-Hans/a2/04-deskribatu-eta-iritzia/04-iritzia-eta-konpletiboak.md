对于A2水平来说，表达观点是**关键能力**之一。本课将为你提供：

1. 开启一个观点的句式。
2. 使用 **-ela** 的补语从句（表示“...”）。
3. 使用 **-enik** 否定观点（我不认为...）。
4. 使用 **-lako** 和 **zeren** 表达原因（因为...）。

## 开启一个观点

| 西班牙语 | Euskera |
|---|---|
| 我认为… | *Uste dut...* |
| 在我看来… | *Iruditzen zait...* |
| 依我之见 | *Nire ustez* |
| 对我来说 | *Niretzat* |
| 我知道… | *Badakit...* |
| 我同意 | *Ados nago* |
| 我不同意 | *Ez nago ados* |
| 你说得对 | *Arrazoia duzu* |
| 是真的 | *Egia da* |

## 使用-**ela**的补语从句

当观点引出另一个句子时，从句动词需要加上后缀 **-(e)la**（表示“...这回事”）。这个变化非常有规律：

| 无后缀 | 带-ela | 西班牙语 |
|---|---|---|
| *da* | *dela* | 是 / 在... |
| *naiz* | *naizela* | （我）是... |
| *zara* | *zarela* | 你是... |
| *du* | *duela* | （他/她/它）有... |
| *ditu* | *dituela* | （他/她/它）有（复数）... |
| *dut* | *dudala* | （我）有... |
| *zen* | *zela* | 曾是... |
| *nuen* | *nuela* | （我）曾有... |
| *etorriko da* | *etorriko **dela*** | 将会来... |

> *Uste dut Anboto pozik **dagoela**.* — 我认为Anboto很高兴。
>
> *Badakit gauza zailak gertatu **direla**.* — 我知道发生了一些困难的事情。
>
> *Argi dago euskaraz hobeto hitz egiten **duela**.* — 很明显，他/她的巴斯克语说得更好。

## 否定观点：-**enik**

当你说“**我不认为** + 动词”时，从句的后缀变为 **-enik**：

| 西班牙语 | Euskera |
|---|---|
| 我不认为这很好 | *Ez dut uste ona **denik*** |
| 我不认为他们会来 | *Ez dut uste etorriko **direnik*** |
| 在我看来这不是真的 | *Ez zait iruditzen egia **denik*** |

> 这是与观点动词连用时的特定否定形式。肯定句：*uste dut ona **dela***。否定句：*ez dut uste ona **denik***。

## 其他表达观点的结构

这些结构组合了形容词 + *da* + 带-ela的句子：

| 西班牙语 | Euskera |
|---|---|
| 很明显… | *Argi dago + -(e)la* |
| 重要的是… | *Garrantzitsua da + -tzea* |
| 确实… | *Egia da + -(e)la* |
| 可能… | *Posible da + -tzea* |
| 合乎逻辑的是… | *Logikoa da + -(e)la* |
| 有趣的是… | *Interesgarria da + -tzea* |

> *Argi dago ikasten ari **zarela**.* — 很明显你正在学习。
>
> *Garrantzitsua da euskaraz **hitz egitea**.* — 说巴斯克语很重要。

## 原因状语：*-lako* 和 *zeren*

要表达**原因**（“因为”），你有两种方式：

### 后缀 -**lako**（从句，最常见）

> **动词 + -lako**

| 西班牙语 | Euskera |
|---|---|
| 因为他/她来了 | *Etorri **delako*** |
| 因为我饿了 | *Goseak nagoelako* (或 *gose naizelako*) |
| 因为这很重要 | *Garrantzitsua **delako*** |
| 因为我不喜欢 | *Ez zaidalako gustatzen* |

> *Etxean nago **gaixorik nagoelako**.* — 我在家，因为我病了。
>
> *Bilbora joaten naiz lana **bertan dudalako**.* — 我去毕尔巴鄂，因为我的工作在那里。

### 连词 *zeren*（在句首）

| 西班牙语 | Euskera |
|---|---|
| 因为这很重要 | *…, **zeren** garrantzitsua baita* |
| …，因为他/她来了 | *…, **zeren** etorri baita* |

> 这是一种“罗曼语式”的表原因方式，更正式或用于新闻报道。口语中更常用 *-lako*。

## 迷你辩论

> *— Olatz, **uste dut** Bilbo Donostia baino interesgarriagoa **dela**.*
>
> *— **Ez nago ados**. Donostia askoz politagoa da, **uste dut**, itsasoa **duelako** ondoan.*
>
> *— **Egia da** itsasoa duela, baina Bilbon **museo gehiago daudela ere egia da**.*
>
> *— Bai, baina **iruditzen zait** giroa, kalea, jendea... Donostian goxoagoak **direla**. Eta Donostiako pintxoak Bilbokoak **baino hobeak direla** ere bai!*

## 实用结构列表

| 西班牙语 | Euskera |
|---|---|
| 我认为这很重要 | *Garrantzitsua **dela** uste dut* |
| 我知道他/她是对的 | *Arrazoia **duela** badakit* |
| 我不认为他们会来 | *Ez dut uste etorriko **direnik*** |
| 很明显他/她有麻烦 | *Argi dago arazoak **dituela*** |
| 因为他/她病了 | *Gaixorik **dagoelako*** |
| 因为天气冷 | *Hotz **egiten duelako*** |

## 常见陷阱

1. **不要忘记双重形式：肯定句用-ela，否定观点用-enik。**
2. **后缀-ela附加在变位动词上**，而不是分词上：*etorriko da → etorriko **dela***。
3. **如果观点非常强烈，在西班牙语中会使用虚拟式**，但在巴斯克语中没有严格的区别：*uste dut ondo dagoela*（我认为这很好）和 *zalantza dut ondo dagoenik*（我怀疑这是否好）使用不同的形式，但没有一个正式的“虚拟式”。

> **教学提示：** 公式 *Nire ustez + 句子 + -lako + 句子* 可能是A2水平表达观点和论证最有效的工具。示范例子：
>
> *Nire ustez **euskara ikastea garrantzitsua da** **gure herriaren hizkuntza delako**.*
> （“在我看来，学习巴斯克语很重要，因为它是我们民族的语言。”）
