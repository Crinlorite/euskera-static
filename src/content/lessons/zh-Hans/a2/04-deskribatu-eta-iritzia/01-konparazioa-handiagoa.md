比较是语言中最日常的行为之一：*这个比那个大*，*我比你矮*，*今天的玉米饼比昨天的好吃*。在巴斯克语中，这个句式非常有规律，一旦掌握，就能造出许多新句子。

## 公式

> **X baino Y-AGO(A)**

- **baino** 放在两个比较对象之间——相当于汉语的“比”。
- **-ago** 添加在形容词或副词后面（类似于英语的“-er”或汉语的“更”）。
- 如果后面跟的是定指名词，形容词会带上它通常的 **-a** 后缀：*altuago**a***。

| 中文含义 | 巴斯克语 |
|---|---|
| 更大 | *handi**agoa*** |
| 更小 | *txiki**agoa*** |
| 更贵 | *garesti**agoa*** |
| 更漂亮 | *polit**agoa*** |
| 更快 | *azkar**agoa*** |

## 句型示例

| 中文含义 | 巴斯克语 |
|---|---|
| Lander 比 Olatz 高 | *Lander Olatz **baino** altu**agoa** da* |
| 这栋房子比那栋大 | *Etxe hau hura **baino** handi**agoa** da* |
| 毕尔巴鄂比多诺斯蒂亚大 | *Bilbo Donostia **baino** handi**agoa** da* |
| 咖啡比茶贵 | *Kafea tea **baino** garesti**ago** dago* |
| Garazi 比我跑得快 | *Garazik nik **baino** azkarrago **egiten du korrika*** |

> **语序：**在巴斯克语中，“比” (*baino*) 位于两个比较对象之间，而不是在形容词之后。**X baino Y-agoa** 的字面意思是“X 比 Y-更”。

## 不规则形容词

有些形容词不遵循一般规则，需要记忆：

| 中文含义 | 巴斯克语 |
|---|---|
| 好 → 更好 | *ona → **hobea*** |
| 坏 → 更坏 | *txarra → **okerragoa*** |
| 多 → 更多 | *asko → **gehiago*** |
| 少 → 更少 | *gutxi → **gutxiago*** |

> *Liburu hau hura **baino hobea** da.* — 这本书比那本好。
>
> *Garazik nik **baino gehiago** ikasten du.* — Garazi 比我学得多。

## 与动词连用的比较级

当比较**动作**或**数量**时，*gehiago / gutxiago* 用作副词：

| 中文含义 | 巴斯克语 |
|---|---|
| 我比你工作得多 | *Zuk **baino gehiago** lan egiten dut* |
| 他/她学习比以前少了 | *Lehen **baino gutxiago** ikasten du* |
| 我吃水果比蔬菜多 | *Barazkiak **baino fruta gehiago** jaten dut* |

> *Gehiago* 和 *gutxiago* 位于动词或其修饰的名词**之前**，而 *baino* 仍然在两个比较对象之间。

## 与副词连用的比较级

| 副词 | 比较级 |
|---|---|
| *azkar* (快) | *azkarrago* |
| *poliki* (慢) | *polikiago* |
| *ondo* (好) | *hobeto* (不规则) |
| *gaizki* (坏) | *okerrago* |
| *berandu* (晚) | *beranduago* |
| *goiz* (早) | *goizago* |

> *Hobeto egiten duzu lan.* — 你工作得更好。
>
> *Goizago etorriko naiz bihar.* — 我明天会早点来。

## 否定形式：“比...少”

要表达“比...少”，自然的句式是 **gutxiago + baino**：

> *Lander nik baino **gutxiago** lan egiten du.* — Lander 比我工作得少。

或者使用反向比较：

> *Olatz Lander baino **txikiagoa** da.* (= Lander 比 Olatz 高，反过来说。)

## 使用 *hain* 的否定形式——“不像...那么”

一个非常有用的句式：

| 中文含义 | 巴斯克语 |
|---|---|
| 没那么贵 | *Ez da **hain** garestia* |
| 没那么快 | *Ez **hain** azkar* |
| 不像你想的那么大 | *Ez da uste zenuen **bezain** handia* |

> *Hain* 用来表示“那么”（= 如此地）。与 *ez* 结合使用可以缓和比较的语气。

## 迷你对话

> *— Anboto, etxe berria zer moduz?*
>
> *— Aurrekoa **baino handiagoa** da, eta argia ere **askoz argiagoa** da. Baina logelak **txikiagoak** dira.*
>
> *— Eta kalea?*
>
> *— Lehen baino **lasaiagoa**: ez dago **hainbeste** autorik.*

## 记忆技巧

将这个公式作为一个整体来记忆：

> **X baino Y-agoa da.**

对于不规则形式，记住：**hobea, okerragoa, gehiago, gutxiago**。这样你就掌握了 A2 级别 95% 的优级比较。

> **文化小贴士：**在日常口语中，你还会听到一些加强语气的表达：*askoz handiagoa* (大得多), *pixka bat handiagoa* (大一点), *dezente handiagoa* (大不少)。这些细微差别虽然不完全属于 A2 级别的内容，但在各种对话中都会出现。
