本课整合了两个非常有用的A2模块：

1. **情感**和情绪状态（基础内容你在A1已经学过；这里是扩展学习）。
2. **语篇连接词**，用于论证和细化观点：*gainera, hala ere, beraz, alde batetik...*

学完这些，你就完成了本单元，并掌握了表达更复杂观点的工具。

## 情感：*egon* + 状态的公式

大多数短暂的情感都使用 *egon* + 形容词或副词的形式：

| 西班牙语 | 巴斯克语 |
|---|---|
| 高兴 | *Pozik nago* |
| 伤心 | *Triste nago* |
| 生气 | *Haserre nago* |
| 紧张 | *Urduri nago* |
| 平静 | *Lasai nago* |
| 无聊 | *Aspertuta nago* |
| 疲倦 | *Nekatuta nago* |
| 害羞/尴尬 | *Lotsatuta nago* |
| 恋爱中 | *Maitemindurik nago* |

> 这与A1的模式（*pozik, triste, lasai*）相同，只是增加了 *aspertuta, nekatuta, lotsatuta, maitemindurik*。

## 使用 *izan* 表达情感：*beldur naiz*

一些深层的情感使用 *izan*：

| 西班牙语 | 巴斯克语 |
|---|---|
| 我害怕 | *Beldur naiz* |
| 你有道理 | *Arrazoia duzu* |
| 我好奇 | *Jakin-mina dut* |
| 我想做/我有兴致 | *Gogoa dut* / *Gogoz nago* |
| 我不想做/我没兴致 | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — 我害怕坐车去。

## 使用 *NOR-NORI* 表达情感：*lotsa ematen dit*

一种非常巴斯克式的表达：情感“使你感到”：

| 西班牙语 | 巴斯克语 |
|---|---|
| 让我感到羞愧/尴尬 | *Lotsa ematen dit* |
| 让我感到遗憾/可惜 | *Pena ematen dit* |
| 让我感到愤怒 | *Amorrua ematen dit* |
| 让我感到害怕 | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — 说这个让我感到羞愧。
>
> *Albiste horrek **pena handia ematen dit**.* — 那个消息让我非常难过。

## *Jartzen naiz / jarri naiz*

用于表达**状态的改变**（“变得紧张、高兴、伤心”）：

| 西班牙语 | 巴斯克语 |
|---|---|
| 我变得紧张 | *Urduri **jartzen naiz*** |
| 他/她变得伤心 | *Triste **jarri zen*** |
| 我们变得高兴 | *Pozik **jarri ginen*** |
| 他/她无缘无故就生气 | *Edozergatik haserretzen da* |

## 常见的心理动词

| 动词 | 含义 |
|---|---|
| *gustatu* | 喜欢 |
| *maite izan* | 爱 |
| *gorrotatu* / *higuindu* | 恨 |
| *beldurtu* | 害怕/受惊 |
| *aspertu* | 感到无聊 |
| *haserretu* | 生气 |
| *lasaitu* | 冷静下来 |
| *poztu* | 变得高兴 |
| *triste jarri* / *atsekabetu* | 变得伤心 |
| *kezkatu* | 担心 |

> *Asko **maite ditut** nire gurasoak.* — 我非常爱我的父母。
>
> *Ez **kezkatu**, dena ondo aterako da.* — 别担心，一切都会好起来的。

## 语篇连接词

用于组织观点和论据：

### 补充

| 西班牙语 | 巴斯克语 |
|---|---|
| 此外 | *gainera* |
| 而且/也 | *eta baita ere* / *...ere* |
| 尤其是 | *batez ere* |

> *Gainera, prezioa ere ona da.* — 此外，价格也很好。

### 因果

| 西班牙语 | 巴斯克语 |
|---|---|
| 因此 | *beraz* |
| 所以 | *horregatik* |
| 因此/由于那个原因 | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — 时间晚了；因此，我走了。

### 对比/转折

| 西班牙语 | 巴斯克语 |
|---|---|
| 然而 | *hala ere* |
| 但是 | *baina* |
| 另一方面 | *bestetik* |
| 相反 | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — 时间晚了；尽管如此，我还是会来。

### 组织语篇

| 西班牙语 | 巴斯克语 |
|---|---|
| 一方面…另一方面 | *Alde batetik... bestetik...* |
| 首先…然后… | *Lehenengo... gero...* |
| 最后 | *Azkenik* |
| 总而言之 | *Laburbilduz* |

## A2并列结构

这些是任何A2考试中都会出现的结构：

| 西班牙语 | 巴斯克语 |
|---|---|
| 既不…也不… | *Ez... ez...* |
| 既…又… | *Bai... bai...* / *Hala... nola...* |
| 不但…而且… | *Ez bakarrik..., baita ere...* |
| …也（包括在内） | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — Anboto和Olatz都没来。
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — 我上午和下午都得工作。

## 观点短文

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## A2技巧：“观点骨架”

当A2考试要求你发表观点时，请遵循这个模板：

> **1. Nire ustez** + 主题 + **-(e)la**.
>
> **2. Alde batetik**, + 理由1 + **-lako**.
>
> **3. Bestetik**, + 理由2.
>
> **4. Hala ere**, + 补充/细化.
>
> **5. Beraz**, + 结论。

这样你就能构建一个完整的A2段落了。

> **文化小贴士：** 许多官方A2文本（给编辑的信、论坛、考试作文）都要求这种论证结构。用日常话题多加练习：体育、食物、社交网络、工作、村镇节日等。
