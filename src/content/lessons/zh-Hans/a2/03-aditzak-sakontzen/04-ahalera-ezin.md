在巴斯克语中，要表达“我能 / 你能 / 我们能”，你有两种选择：一种是**正式**用法（ahalera 加特殊助动词），另一种是**口语**用法（*ahal* 加普通助动词）。在A2级别，你需要能认出这两种用法。

对于“不能”，还有一个专门的词：**ezin**。

## 选项1：口语形式 — *ahal*

这是最简单、也是你最常听到的形式：

> **partizipioa + ahal + auxiliar**

| 西班牙语 | 巴斯克语 |
|---|---|
| 你能来吗？ | *Etorri **ahal zara**?* |
| 我能进来吗？ | *Sartu **ahal naiz**?* |
| 你能帮我吗？ | *Lagundu **ahal didazu**?* |
| 我们能和你谈谈吗？ | *Hitz egin **ahal dugu** zurekin?* |

> 在书面或更正式的语境中，会出现 **ahal izan**：*etorri ahal izango da*，*jakin ahal izan dut*。在日常口语中，*ahal* + 助动词 的形式是可行的。

## 选项2：“真正的” ahalera — *dezaket / naiteke*

这是可能式的综合形式。它有两个系列，取决于动词是及物动词还是不及物动词。

### 及物动词 (NOR-NORK): *dezaket*

| 代词 | 形式 | 西班牙语 |
|---|---|---|
| nik | **dezaket** | 我能（做某事） |
| zuk | **dezakezu** | 你能（做某事） |
| hark | **dezake** | 他/她能（做某事） |
| guk | **dezakegu** | 我们能（做某事） |
| zuek | **dezakezue** | 你们能（做某事） |
| haiek | **dezakete** | 他们能（做某事） |

> **分词（不带词尾）+ dezaket**：*egin → egin dezaket*，*idatzi → idatz dezaket*，*jan → jan dezaket*。

### 不及物动词 (NOR): *naiteke*

| 代词 | 形式 | 西班牙语 |
|---|---|---|
| ni | **naiteke** | 我能 |
| zu | **zaitezke** | 你能 |
| hura | **daiteke** | 他/她能 |
| gu | **gaitezke** | 我们能 |
| zuek | **zaitezkete** | 你们能 |
| haiek | **daitezke** | 他们能 |

> *Etor naiteke?* — 我能来吗？
>
> *Joan zaitezke?* — 你能去吗？
>
> *Hori egia izan daiteke.* — 那可能是真的。

## 综合形式公式

| 类型 | 结构 | 例子 |
|---|---|---|
| 及物动词 | 分词（去掉典型的词尾）+ *dezaket* 等 | *Liburua **irakur dezakezu*** (你能读这本书) |
| 不及物动词 | 分词 + *naiteke* 等 | *Etor **zaitezke**?* (你能来吗？) |

> **拼写细节：**在 ahalera 中，一些动词的分词形式会“缩短”：*jan → jan*，*egin → egin*，*irakurri → irakur*，*ikusi → ikus*，*etorri → etor*。词尾的 -i 会脱落。这是一个典型的正式用法标记。

## *Ezin* — 不能

ahalera 的否定形式有它自己的专用词：**ezin**。

> **ezin + partizipioa + auxiliar**

| 西班牙语 | 巴斯克语 |
|---|---|
| 我不能来 | *Ezin **dut etorri*** (NOR-NORK) 或 *Ezin **naiz etorri*** (NOR) |
| 我不能去 | *Ezin naiz joan* |
| 你不能那么做 | *Ezin duzu hori egin* |
| 我无法入睡 | *Ezin nuen lo egin* |
| 无法知道 | *Ezin da jakin* |
| 我们不能等 | *Ezin dugu itxaron* |

> *Ezin* 放在主语之后，后面跟分词 + 助动词。这种用法非常普遍。

## 过去时形式：*nezakeen / nintekeen / ezin nuen*

| 形式 | 意思 |
|---|---|
| **nezakeen** | 我（那时）能（做某事）（过去可能式） |
| **zezakeen** | 他（那时）能（做某事） |
| **nintekeen** | 我（那时）能（NOR 过去时） |
| **ezin nintzen** | （那时）不能（NOR） |
| **ezin nuen** | （那时）不能（NOR-NORK） |

> *Atzo ezin nintzen joan, gaixorik nengoen.* — 昨天我不能去，因为我病了。

## 情态动词 vs 助动词：“你能做”的三种表达方式

1. **口语：** *Egin ahal duzu.* — 口语中最自然的形式。
2. **综合形式：** *Egin dezakezu.* — 比较正式或用于书面语。
3. **使用 ezin 的否定形式：** *Ezin duzu egin.* — 用于表达“你不能做”。

这三种形式并存。在A2级别，你需要会使用前两种，并能认出所有三种。

## *Ahal izan* 的其他时态

| 西班牙语 | 巴斯克语 |
|---|---|
| 我已经能够去了 | *Joan ahal izan naiz* |
| 我将能够去 | *Joan ahal izango naiz* |
| 我没能... | *Ezin izan dut* |

## 日常示例

- *Lagundu ahal didazu, mesedez?* — 你能帮我一下吗？
- *Bihar ezin naiz etorri.* — 我明天不能来。
- *Hau uler dezaket.* — 这个我能理解。
- *Ezin duzu hori egin.* — 你不能那么做。
- *Goazen lasai, denbora dugu eta.* — 我们从容点，因为我们有时间。
- *Etxea bihar eros daiteke.* — 这房子明天可以买。

## 小对话

> *— Anboto, **etor zaitezke** bihar afaltzera?*
>
> *— Tira, **ezin dut**: lan asko daukat eta berandu arte ezin naiz mugitu. Baina hurrengo astean **etor naiteke**, eta zer ekar **dezaket**?*
>
> *— **Ekar dezakezu** ardo botila bat, hori asko gustatzen zaigu.*

> **教学提示：**在A2级别，最有用的是熟练掌握用 *ezin dut/naiz* 表达“我不能”，以及用 *ahal duzu?* 进行提问。综合形式 (*dezaket, naiteke*) 你将通过阅读逐渐掌握。B1单元会对此进行深入讲解。
