**NOR-NORI** 动词指的是某事 (NOR) “发生在某人身上” (NORI) 的情况。语法主语是**事物**，而不是人——这与西班牙语中的 *gustar*（喜欢）完全一样：*me gusta el cine*（我喜欢电影，字面意思是“电影使我喜欢”）。

在 A1 级别你已经学过 *gustatzen zait*。在 A2 级别，你将把这个模式扩展到其他非常有用的动词上。

## NOR-NORI 助动词的现在时形式

当 NOR 为单数时：

| NORI | 形式 | 中文含义 |
|---|---|---|
| niri | **zait** | 我 |
| zuri | **zaizu** | 你 |
| hari | **zaio** | 他/她 |
| guri | **zaigu** | 我们 |
| zuei | **zaizue** | 你们 |
| haiei | **zaie** | 他们/她们 |

当 NOR 为**复数**时：

| NORI | 复数形式 | 中文含义 |
|---|---|---|
| niri | **zaizkit** | 我 (复数事物) |
| zuri | **zaizkizu** | 你 |
| hari | **zaizkio** | 他/她 |
| guri | **zaizkigu** | 我们 |
| zuei | **zaizkizue** | 你们 |
| haiei | **zaizkie** | 他们/她们 |

## 过去时：*zitzaidan, zitzaion*

| NORI | 过去时单数 | 过去时复数 |
|---|---|---|
| niri | **zitzaidan** | **zitzaizkidan** |
| zuri | **zitzaizun** | **zitzaizkizun** |
| hari | **zitzaion** | **zitzaizkion** |
| guri | **zitzaigun** | **zitzaizkigun** |
| haiei | **zitzaien** | **zitzaizkien** |

## 使用此模式的动词

| 动词 | 含义 | 示例 |
|---|---|---|
| *gustatu* | 喜欢 | *Filmak gustatzen zaizkit* (我喜欢这些电影) |
| *iruditu* | 觉得 | *Ondo iruditzen zait* (我觉得很好) |
| *ahaztu* | 忘记 | *Ahaztu zait izena* (我忘记名字了) |
| *erori* | 掉落 | *Erori zaizu boligrafoa* (你的圆珠笔掉了) |
| *gertatu* | 发生（在某人身上） | *Zer gertatu zaizu?* (你发生什么事了？) |
| *interesatu* | 使……感兴趣 | *Politika interesatzen zait* (我对政治感兴趣) |
| *axola izan* | 在乎，要紧 | *Ez zait axola* (我不在乎) |

## 结构：主语是事物

> **NORI + NOR + 动词 + NOR-NORI 助动词**

| 中文 | 巴斯克语 | 标记 |
|---|---|---|
| 我喜欢电影 | *Niri zinea **gustatzen zait*** | NORI + NOR sing + zait |
| 我喜欢这些电影 | *Niri filmak **gustatzen zaizkit*** | NORI + NOR pl + zaizkit |
| 你觉得很好 | *Zuri ondo **iruditzen zaizu*** | NORI + NOR + zaizu |
| 他/她掉了一本书 | *Hari liburu bat **erori zaio*** | NORI + NOR sing + zaio |
| 我忘记带钥匙了 | *Niri giltzak **ahaztu zaizkit*** | NORI + NOR pl + zaizkit |

> **技巧：** 受影响的人使用 NORI 格（-ari/-ei），并且通常出现在句首。事物是语法主语，动词与它保持一致。

## *Gustatzen zait* 的过去时 — *gustatu zitzaidan*

用于谈论过去的喜好：

> *Filma asko **gustatu zitzaidan**.* — 我非常喜欢那部电影。
>
> *Ez zitzaion gustatu opari hori.* — 他/她不喜欢那个礼物。

> 注意：*gustatu zitzaidan* (= 我喜欢过，已完成的动作) vs *gustatzen zitzaidan* (= （过去）我（一直）喜欢，习惯性动作)。

## *Iruditu* (觉得) — 个人观点

A2 级别最有用的句式之一：

| 中文 | 巴斯克语 |
|---|---|
| 我觉得很好 | *Ondo iruditzen zait* |
| 我觉得很有趣 | *Interesgarria iruditzen zait* |
| 你觉得怎么样？ | *Zer iruditzen zaizu?* |
| 我觉得很奇怪 | *Bitxia iruditzen zait* |
| 我觉得是 | *Baietz iruditzen zait* |

## *Ahaztu zait* — 我忘记了

| 中文 | 巴斯克语 |
|---|---|
| 我忘记了 | *Ahaztu zait* |
| 我忘记带钥匙了 | *Giltzak ahaztu zaizkit* |
| 他/她什么都忘 | *Dena ahazten zaio* |
| 你别忘了！ | *Ez zaizula ahaztu!* |

## 迷你对话

> *— Olatz, **zer iruditzen zaizu** Bilboko jatetxe berria?*
>
> *— Asko **gustatu zait**. Bereziki bigarren platerak: **interesgarriak iruditu zaizkit**.*
>
> *— Eta, jakin nahi nuen, **ahaztu zaizu** zer eskatu zenuen?*
>
> *— Bai, izenak ez **zaizkit gogoratzen**, baina arraina zen, ziur.*

## 常见陷阱

1. **这里没有作格主语。** 不要说 *\*Nik gustatzen dut*（这是一个非常常见的错误）：正确的说法是 *Niri gustatzen zait*。人不是动作的执行者。
2. **NOR 的一致性。** 如果事物是复数，助动词也要用复数形式：*zaizkit, zaizkio, zaizkigu...*
3. **一些地区使用其他变体**（例如在 *hitano* 口语中的 *zaidak, zaidan*），但在标准巴斯克语 (*batua*) 中，标准形式是表中的那些。

> **文化小贴士：** 说巴斯克语的人通常会（善意地）频繁使用 *iruditzen zait* 来谨慎地表达观点，例如：*interesgarria iruditzen zait*（我觉得很有趣），*bitxia iruditzen zait*（我觉得很奇怪），*ez zait ondo iruditzen*（我觉得不太好）。这相当于巴斯克语中委婉表达的“我觉得……”。
