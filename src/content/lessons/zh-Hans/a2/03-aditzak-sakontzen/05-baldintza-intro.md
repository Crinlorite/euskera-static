巴斯克语中的**条件式** (*baldintza*) 有几种形式。在A2级别，我们只学习**最有用的两种**：

1. **真实条件 (很可能发生的未来):** *如果明天下雨，我就不去*。
2. **非真实条件 (假设):** *如果我有钱，我就会买一座房子*。

本课是一个**简介**：你只需能够识别这些形式并造出简单的句子即可。B1单元会更深入地讲解。

## 类型1：真实条件 — *ba-* + 现在时

对于关于**很可能发生的未来**或现在的假设，巴斯克语在现在时助动词前使用前缀 **ba-**。

> **ba- + 现在时助动词, ... + 将来时**

| 西班牙语 | 巴斯克语 |
|---|---|
| 如果下雨，我就不去 | *Euria egiten **badu**, ez naiz joango* |
| 如果你有时间，就来吧 | *Astia **baduzu**, etorri* |
| 如果你愿意，就给我打电话 | *Nahi **baduzu**, deitu niri* |
| 如果有一天我富有了… | *Aberatsa **banaiz** noizbait...* |

### 带 *ba-* 的形式 (现在时)

| 动词 | 不带 ba- | 带 ba- |
|---|---|---|
| *naiz* | 我是 | **banaiz** (如果我是) |
| *zara* | 你是 | **bazara** (如果你是) |
| *da* | 是 | **bada** (如果是) |
| *gara* | 我们是 | **bagara** (如果我们是) |
| *dut* | 我...它 | **badut** (如果我有它) |
| *du* | 他...它 | **badu** (如果他有它) |
| *dute* | 他们...它 | **badute** (如果他们有它) |

> **¡注意！** *Ba-* 也有一个肯定的用法：*bai, badator* = “是的，他来了”。需要根据上下文来区分：如果句子有第二部分（“...那么...”），它就是条件句。

## 类型2：非真实条件 — *banintz / banu*

对于非真实的或可能性很小的假设（“如果我是...”、“如果我有...”），巴斯克语使用专门的形式：

### *izan* 的非真实条件形式

| 代词 | 形式 | 西班牙语 |
|---|---|---|
| ni | **banintz** | 如果我是/我在 |
| zu | **bazina** | 如果你是 |
| hura | **balitz** | 如果是/在 |
| gu | **bagina** | 如果我们是 |
| zuek | **bazinete** | 如果你们是 |
| haiek | **balira** | 如果他们是 |

### *ukan* 的非真实条件形式

| 代词 | 形式 | 西班牙语 |
|---|---|---|
| nik | **banu** | 如果我有它 |
| zuk | **bazenu** | 如果你有它 |
| hark | **balu** | 如果他有它 |
| guk | **bagenu** | 如果我们有它 |
| haiek | **balute** | 如果他们有它 |

> **先记住这六个**：*banintz, balitz, banu, balu, bagenu, balute*。它们会出现在任何非真实条件句中。

## 结果从句：*-ko/-go + nuke / nintzateke*

西班牙语中的“comprar**ía** / iría / sería”（我会买/我会去/我会是）由 **-ko/-go**（与将来时标记相同）+ 特殊助动词构成：

### NOR-NORK 条件式 (“我会...它”)

| 代词 | 形式 | 西班牙语 |
|---|---|---|
| nik | **nuke** | 我会...它 |
| zuk | **zenuke** | 你会...它 |
| hark | **luke** | 他会...它 |
| guk | **genuke** | 我们会...它 |
| haiek | **lukete** | 他们会...它 |

### NOR 条件式 (“我会...”，不及物)

| 代词 | 形式 | 西班牙语 |
|---|---|---|
| ni | **nintzateke** | 我会... |
| zu | **zinateke** | 你会... |
| hura | **litzateke** | 他会... / 他会是 |
| gu | **ginateke** | 我们会... |
| haiek | **lirateke** | 他们会... |

## 句型

> **baldintza + ondorioa**

> *Diru asko **banu**, etxe bat **erosiko nuke**.* — 如果我有很多钱，我就会买一座房子。
>
> *Lurralde berri batean **bizi banintz**, beste hizkuntza bat **ikasiko nuke**.* — 如果我住在一个新的国家，我就会学习另一种语言。
>
> *Anboto hemen **balitz**, lasaiago **egongo ginateke**.* — 如果Anboto在这里，我们会更安心。
>
> *Aberatsak **balira**, mundu osoa **bisitatuko lukete**.* — 如果他们是富人，他们就会环游世界。

## 两种类型的比较

| 类型 | “如果”从句 | “那么”从句 |
|---|---|---|
| 真实 (很可能发生的未来) | *ba-* + 现在时: *baduzu, bada* | 将来时: *-ko/-go + naiz/dut* (joango naiz, erosiko dut) |
| 非真实 (假设) | *ba-* + 条件式: *banu, balitz* | 条件式: *-ko/-go + nuke/nintzateke* |

## 对比示例

- **真实:** *Astia **baduzu**, lagunduko **dizut**.* — 如果你有时间，我会帮助你。
- **非真实:** *Astia **bazenu**, lagunduko **zenidake**.* — 如果你有时间，你会帮助我。

## 非常有用的常用语

| 西班牙语 | 巴斯克语 |
|---|---|
| 你想要...吗？ | *Nahi **zenuke**…?* |
| 我想要... | *Gustatuko **litzaidake**…* |
| 如果...就太好了 | *Polita **litzateke**…* |
| 我很乐意去 | *Gustura **joango nintzateke*** |
| 我会考虑一下 | *Pentsatuko **nuke*** |

## 迷你对话

> *— Olatz, **nahi zenuke** zinemara joan?*
>
> *— Bai, **gustatuko litzaidake**, baina astia **banu**... Lan asko daukat astean.*
>
> *— Lasai. Bihar **etortzen bazara**, sarrera bat **erosiko dizut**.*

> **教学笔记：** *baldintza* 是A2级别为你打开B1大门的知识点之一。在官方的A2级别中，你只需能够**识别**它并造出类似 *banintz... -ko nuke* 的简单句子即可。条件式的完整变位将在B1级别学习。
