你没事的时候做什么？这节课是关于**爱好**的 — 以及一个相关的语法点：用**-tzea**将动词名词化 (*irakurtzea* = “阅读”这件事)。

## 语法点：-t(z)ea

在A1级别，你学过用*gustatzen zait*来谈论事物 (*kafea gustatzen zait*)。要表示你喜欢某个**活动**，需要将动词名词化：

> **irakurri → irakurtzea** · **abestu → abestea** · **bidaiatu → bidaiatzea** · **sukaldatu → sukaldatzea**

| 西班牙语 | 巴斯克语 |
|---|---|
| 我喜欢阅读 | *Irakurtzea gustatzen zait* |
| 我超爱做饭 | *Asko gustatzen zait sukaldatzea* |
| 他/她喜欢唱歌 | *Abestea gustatzen zaio* |
| 我们喜欢旅行 | *Bidaiatzea gustatzen zaigu* |
| 我一点也不喜欢早起 | *Ez zait batere gustatzen goiz jaikitzea* |

所有你已经学过的NOR-NORI变位 (*zait, zaio, zaigu…*) 仍然适用；只是“什么”的部分变了。

## 爱好清单

| 西班牙语 | 巴斯克语 |
|---|---|
| 阅读 / 写作 | *irakurtzea / idaztea* |
| 听音乐 | *musika entzutea* |
| 唱歌 / 跳舞 | *abestea / dantzatzea* |
| 做饭 | *sukaldatzea* |
| 拍照 | *argazkiak ateratzea* |
| 绘画 / 素描 | *margotzea / marraztea* |
| 旅行 | *bidaiatzea* |
| 打理菜园 | *baratzea zaintzea* |
| 电子游戏 | *bideo-jokoak* |
| 缝纫 / 编织 | *jostea / puntua egitea* |

## 提问与展示

> ***Zer egitea gustatzen zaizu** denbora librean?* — 你空闲时间喜欢做什么？
>
> ***Zein da zure zaletasunik gogokoena**?* — 你最喜欢的爱好是什么？
>
> *Nire zaletasunik gogokoena **sukaldatzea** da: asteburuero **errezeta berri bat** probatzen dut.* — 我最喜欢的爱好是做饭：每个周末我都会尝试一道新菜。

## 三种结构，三种细微差别（精细复习）

| 结构 | 例子 | 含义 |
|---|---|---|
| **-tzea gustatzen zait** | *Margotzea gustatzen zait* | 我喜欢（爱好） |
| **-tzen dakit** | *Margotzen dakit* | 我会做（技能） |
| **-tzen ari naiz** | *Margotzen ari naiz* | 我正在做（现在） |

> *Puntua egiten **ez dakit**, baina ikastea **gustatuko litzaidake**.* — 我不会编织，但我想学。（这个优雅的*gustatuko litzaidake*你将在B1级别掌握——我们先把它作为开胃菜放在这里。）

## 对话

> *— Aizu, **zer egitea gustatzen zaizu** asteburuetan?*
>
> *— Niri **mendira joatea** eta **argazkiak ateratzea**. Batzuetan biak batera. 😄 Eta zuri?*
>
> *— **Sukaldatzea** eta gero… **jatea**, noski.*
>
> *— Hori ere zaletasuna da?*
>
> *— Nire etxean, **kirola**.* 😄
