从风景到居民：**动物** — 家养的、农舍的以及森林里的动物。这是一些很有用的词汇，充满了讲述故事的复合词（*basurdea* = “森林里的猪”）。

## 在家里

| 西班牙语 | 巴斯克语 |
|---|---|
| 狗 | *txakurra* |
| 猫 | *katua* |
| 鸟 | *txoria* |
| 鱼 | *arraina* |

> *Gure **txakurrak** hiru urte ditu eta **katuak** hamaika. Nagusia, katua — noski.* — 我们的狗三岁，猫十一岁。老大当然是猫了。

## 在农舍 (baserria)

| 西班牙语 | 巴斯克语 |
|---|---|
| 牛 | *behia* |
| 绵羊 / 羔羊 | *ardia / arkumea* |
| 马 | *zaldia* |
| 猪 | *txerria* |
| 母鸡 / 公鸡 | *oiloa / oilarra* |
| 驴 | *astoa* |

> *Baserrian **behiak, ardiak eta oiloak** dituzte. Goizero **esnea eta arrautzak** hartzen dituzte.* — 在农舍里，他们有牛、绵羊和鸡。每天早上他们都取牛奶和鸡蛋。

## 在森林和天空

| 西班牙语 | 巴斯克语 |
|---|---|
| 野猪 | *basurdea* |
| 狐狸 | *azeria* |
| 狼 | *otsoa* |
| 熊 | *hartza* |
| 鹿 | *oreina* |
| 秃鹫 | *putrea* |
| 松鼠 | *urtxintxa* |

> *Mendian **basurde bat ikusi genuen** — eta basurdea guri begira. Denok geldi-geldi!* — 我们在山里看到了一头野猪 —— 野猪也看着我们。大家一动不动！
>
> *Pirinioetan **hartzak** daude berriro, gutxi baina badaude.* — 比利牛斯山脉又开始有熊了：虽然数量不多，但确实有。

## 谈论你的动物

> ***Animaliarik baduzu**?* — 你有动物吗？
>
> *Bai, **txakur bat daukat**. Mendira eramaten dut **egunero**.* — 是的，我有一只狗。我每天都带它去山上。
>
> *Katuak **ez du ezer egiten**… eta hala ere, **dena da berea**.* — 猫什么都不做……但即便如此，一切都是它的。 😄

> **注意：**动物遍布整个巴斯克语：*Otsoa aipatu eta otsoa atari*（提到狼，狼就到门口了 = 说曹操，曹操到），*azeria baino azkarragoa*（比狐狸还聪明）……还有许多姓氏：Otxoa（狼）、Artzak（熊）、Azeri……动物们在这里已经生活了几个世纪，它们的名字也融入了语言中。
