本单元的第二站：**体育运动**——无论是参与还是观看。在巴斯克地区，这还包括一些你在世界其他任何地方都看不到的运动。

## 常见的运动

| 西班牙语 | 巴斯克语 |
|---|---|
| 体育运动 | *kirola* |
| 足球 | *futbola* |
| 篮球 | *saskibaloia* |
| 游泳 | *igeriketa* |
| 自行车 | *txirrindularitza* |
| 跑步 | *korrika egin* |
| 徒步 | *mendi-ibilia* |
| 健身房 | *gimnasioa* |

## 本地特色运动

| 运动 | 简介 |
|---|---|
| *pilota* | 巴斯克回力球，在 *frontoia*（回力球场）进行 |
| *arrauna* | 赛艇——*traineras*（一种传统赛艇）和“海螺旗”帆船赛 |
| *herri kirolak* | 乡村运动：*aizkora*（伐木）、*harri-jasotzea*（举石）、*soka-tira*（拔河） |

> *Herriko frontoian **pilota partida** dago larunbatean.* — 周六镇上的回力球场有回力球比赛。
>
> *Irailean **estropadak** ikusten ditugu: gure herriko traineroa animatzera!* — 九月我们去看帆船赛：为我们镇上的赛艇队加油！

## 练习：动词

> *Kirola **egiten dut**: astean bitan **entrenatzen naiz** eta igandeetan **korrika egiten dut**.* — 我做运动：我每周训练两次，周日跑步。
>
> ***Igeri badakizu**?* — 你会游泳吗？（用 *jakin* 表示技能：*igeri dakit*，*dantzan dakit*…）
>
> *Gaztetan futbolean **jokatzen nuen**; orain **ikusi** bakarrik.* 😄 — 我年轻时踢足球；现在只看了。

## 比赛

| 西班牙语 | 巴斯克语 |
|---|---|
| 球队 | *taldea* |
| 比赛 | *partida* |
| 赢 / 输 / 平局 | *irabazi / galdu / berdindu* |
| 比分 | *emaitza* |
| 进球 | *gola sartu* |
| 球场 | *zelaia* |

> *— Ikusi zenuen atzoko partida? **Zenbat** bukatu zen?*
>
> *— **2 eta 1 irabazi genuen**! Azken minutuan **gola sartu** zuten.*
>
> *— Aupa! Eta hurrengo astean **etxean jokatuko dute**?*
>
> *— Bai, igandean. **Zelaira joango gara**? Sarrera nire kontu!*

## 对话：报名参加

> *— Kirol pixka bat egin nahi dut, baina gimnasioa **aspergarria** iruditzen zait.*
>
> *— **Zergatik ez zara** herriko igerilekura **apuntatzen**? Goizeko ordutegia oso ona da.*
>
> *— Ez dakit ba… **igeri badakit**, baina gaizki.*
>
> *— Horretarako dira ikastaroak! Ni **astean bitan** joaten naiz. **Elkarrekin joango gara**?*
>
> *— Beno, ados. Baina gero **hamaiketakoa** ere elkarrekin, e?* 😄
