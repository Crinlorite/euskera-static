新单元：**户外**。我们从场景开始——山、森林、河流和大海——在 *Euskal Herria*，这些不只是装饰：它们是周日的计划、世俗的信仰和永恒的聊天话题。

## 山

| 西班牙语 | 巴斯克语 |
|---|---|
| 山 | *mendia* |
| 山顶 | *gailurra* |
| 山坡 | *magala* |
| 森林 | *basoa* |
| 树 | *zuhaitza* |
| 小径 | *bidezidorra* |
| 岩石 / 巨石 | *harkaitza* |
| 山谷 | *harana* |

> *Bidezidorretik gora, bi ordutan **gailurrera iritsiko gara**.* — 沿着小径向上，两小时内我们就能到达山顶。
>
> *Basoan barrena **ibili ginen**, eta ez genuen inor ikusi. Bakea.* — 我们穿行在森林里，没有看到任何人。一片宁静。

## 水

| 西班牙语 | 巴斯克语 |
|---|---|
| 河流 | *ibaia* |
| 水库 / 水坝 | *urtegia* |
| 瀑布 | *ur-jauzia* |
| 大海 | *itsasoa* |
| 海滩 | *hondartza* |
| 海浪 | *olatuak* |
| 悬崖 | *labarra* |

> *Uda honetan ibaian **bainatuko gara**, hondartzan **jende gehiegi** dago eta.* — 今年夏天我们要在河里游泳，因为海滩上人太多了。（后缀 *-egi* 和表示原因的 *eta* 在这里派上了用场。）

## 描述风景

> *Hemendik **bista ikusgarria** dago: harana, basoa eta urrutian **itsasoa**.* — 从这里看，景色令人惊叹：山谷、森林，远处还有大海。
>
> *Udazkenean basoa **kolore ederrekoa** da: horia, gorria, marroia.* — 秋天，森林的颜色非常美丽。
>
> *Zuhaitz hori **oso zaharra da** — ehun urte baino **gehiago** ditu.* — 那棵树很老了：超过一百年了。（第04单元的比较级。）

## 对话：周日的计划

> *— Igandean **mendira joango gara**? Anbotora, adibidez.*
>
> *— Anboto? Hori **gogorra** da niretzat! **Zerbait errazagoa**, mesedez…*
>
> *— Ados: Urkiolara **igoko gara**, bidezidor lasai batetik. **Gailurrean** hamaiketakoa.*
>
> *— Hamaiketakoarekin **konbentzitu nauzu**.* 😄

> **注意：** *mendizaletasuna*（对登山的热爱）是纯粹的身份认同：每个村庄都有自己“专属”的山，山顶上还有一个信箱。*hamaiketakoa* 这个词——十一点的午餐——是许多人登山的真正原因。别太大声说出来。
