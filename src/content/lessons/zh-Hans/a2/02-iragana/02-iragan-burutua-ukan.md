本课将过去时扩展到 **NOR-NORK** 动词（及物动词：我...它，你...它，他...它）。这是叙述所有带宾语的动作的基础：*我吃了，我看了，我做了，我说了，我买了，我叫了...*

## 公式

> **partizipioa + nuen / zenuen / zuen / genuen / zenuten / zuten**

| 人称代词 | *dut* 的过去时 | 含义 |
|---|---|---|
| nik | **nuen** | 我...它 |
| zuk | **zenuen** | 你...它 |
| hark | **zuen** | 他/她...它 |
| guk | **genuen** | 我们...它 |
| zuek | **zenuten** | 你们...它 |
| haiek | **zuten** | 他们...它 |

> 这些形式**总是以 -n 结尾**，首字母是人称标记：**n-** (我)，**z-** (你/你们/他们)，**g-** (我们)。

## 复数宾语 — *nituen*

如果宾语是**复数**（书本、门票、啤酒），助动词会变为 **-itu-** 系列：

| 人称代词 | 复数助动词 | 含义 |
|---|---|---|
| nik | **nituen** | 我...它们 |
| zuk | **zenituen** | 你...它们 |
| hark | **zituen** | 他/她...它们 |
| guk | **genituen** | 我们...它们 |
| zuek | **zenituzten** | 你们...它们 |
| haiek | **zituzten** | 他们...它们 |

## 示例

| 中文 | 巴斯克语 |
|---|---|
| 我吃了 pintxos | *Pintxoak jan **nituen*** |
| 我看了一部电影 | *Film bat ikusi **nuen*** |
| 他们做了晚餐 | *Afaria egin **zuten*** |
| 他/她说了什么？ | *Zer esan **zuen**?* |
| 我们买了面包 | *Ogia erosi **genuen*** |
| 他/她卖了两辆摩托车 | *Bi motoak saldu **zituen*** |

## 综合动词：*eduki* 和 *jakin*

有两个非常常见的动词在过去时中保持**综合**形式，就像在现在时中一样 (*daukat, dakit*)：

### *Eduki* (拥有，所有)

| 人称代词 | 形式 | 含义 |
|---|---|---|
| ni | **neukan** | 我曾有 |
| zu | **zeneukan** | 你曾有 |
| hura | **zeukan** | 他/她曾有 |
| gu | **geneukan** | 我们曾有 |
| zuek | **zeneukaten** | 你们曾有 |
| haiek | **zeukaten** | 他们曾有 |

### *Jakin* (知道)

| 人称代词 | 形式 | 含义 |
|---|---|---|
| ni | **nekien** | 我（当时）知道 |
| zu | **zenekien** | 你（当时）知道 |
| hura | **zekien** | 他/她（当时）知道 |
| gu | **genekien** | 我们（当时）知道 |
| zuek | **zenekiten** | 你们（当时）知道 |
| haiek | **zekiten** | 他们（当时）知道 |

> *Anbotok bizikleta gorri bat **zeukan** umetan.* — Anboto 小时候有一辆红色的自行车。
>
> *Ez **zekien** non bizi ginen.* — 他/她不知道我们住在哪里。

## NOR-NORK 过去时的两个关键细节

**1. 主语上的 -k 标记。** 和现在时一样，执行动作的主语使用作格：

> *Garazi**k** afaria egin **zuen**.* — Garazi 做了晚餐。
>
> *Lander**rek** sarrerak erosi **zituen**.* — Lander 买了门票。

**2. 与宾语保持一致。** 如果宾语是单数 → *nuen / zuen*；如果是复数 → *nituen / zituen*。这和现在时的规则一样。

## 否定

> *Atzo ez nuen filmik ikusi.* — 昨天我一部电影也没看。
>
> *Ainarak ez zuen ezer esan.* — Ainara 什么也没说。
>
> *Ez genituen sarrerak erosi.* — 我们没有买门票。

> 当宾语被否定时，通常使用部分格：*filmik, ezer, txikirik*。这和你在 A1 级别学过的 *-rik* 是一样的。

## 小故事

> *Aurreko larunbatean Olatz eta Lander itsasora **joan ziren** (NOR). Hondartzan egun osoa **eman zuten**: igeri **egin zuten**, eguzkitan etzanda **egon ziren** eta liburu bat **irakurri zuten**. Iluntzean afari bat **prestatu zuten** eta lagunekin **afaldu zuten**.*

注意 NOR 形式 (*joan ziren, egon ziren*) 和 NOR-NORK 形式 (*eman zuten, irakurri zuten, prestatu zuten*) 是如何混合使用的。这两课的内容结合起来就可以用来叙事了。

> **注意：** 在下一课中，你将学习**过去时的综合动词** (*nindoan, nentorren, nenbilen*)，它们是 NOR 过去时的补充。
