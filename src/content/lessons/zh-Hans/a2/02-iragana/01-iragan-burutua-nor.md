你已经在A1级别学过**最近过去时** (*joan naiz*, *jan dut*)。在A2级别，你将迈出决定性的一步：学习**完成过去时** (*iragan burutua*)。它相当于中文里的“曾是/曾在/做过/说过”等，用于叙述已经结束、遥远或久远的事情。

这第一课的重点是 NOR 类动词：**izan** 和 **egon** 的过去时形式。

## *izan* 的过去时 (是)

| 代词 | 过去时 | 中文 |
|---|---|---|
| ni | **nintzen** | 我曾是 |
| zu | **zinen** | 你曾是 |
| hura | **zen** | 他/她曾是 |
| gu | **ginen** | 我们曾是 |
| zuek | **zineten** | 你们曾是 |
| haiek | **ziren** | 他们曾是 |

> 技巧：所有形式的词尾都有 **n** (n**intzen**, zi**nen**, ze**n**, gi**nen**, zi**ne**ten, zir**en**)。这是巴斯克语中过去时的经典标志。

## *egon* 的过去时 (在) — 综合形式

*Egon* 在过去时有综合形式，与现在时的 *nago/zaude/dago...* 相对应：

| 代词 | 过去时 | 中文 |
|---|---|---|
| ni | **nengoen** | 我曾在 |
| zu | **zeunden** | 你曾在 |
| hura | **zegoen** | 他/她曾在 |
| gu | **geunden** | 我们曾在 |
| zuek | **zeundeten** | 你们曾在 |
| haiek | **zeuden** | 他们曾在 |

> 在日常口语中，使用助动词的 **egon nintzen / egon zen** 等形式也是可以的。综合形式听起来更讲究或更书面化，但你也会经常听到。

## 区别：过去时的 *izan* vs 过去时的 *egon*

和现在时一样，在过去时中，你也需要区分：

- **性质 / 身份** → *izan*: *Egoitz medikua zen* (Egoitz 曾是医生)。
- **短暂状态 / 位置** → *egon*: *Egoitz pozik zegoen* (Egoitz 当时很高兴) / *Egoitz Bilbon zegoen* (Egoitz 当时在毕尔巴鄂)。

## 完成过去时的时间标记

为了让句子听起来表示一个已经结束的过去动作，巴斯克语会使用一些时间标记：

| 中文 | 巴斯克语 |
|---|---|
| 昨天 | *Atzo* |
| 昨晚 | *Bart* |
| 前天 | *Herenegun* |
| 上周 | *Joan den astean* / *Aurreko astean* |
| 上个月 | *Joan den hilean* |
| 去年 | *Joan den urtean* / *Iaz* |
| 两年前 | *Duela bi urte* |
| 很久以前 | *Aspaldian* / *Duela urte asko* |
| 那时 | *Orduan* |
| 在2010年 | *2010ean* |

## 典型句式

> *Atzo ni etxean **nintzen** goiz osoan.* — 昨天我整个上午都在家。
>
> *Joan den urtean Garazi Frantzian **zegoen**.* — 去年 Garazi 在法国。
>
> *Duela hamar urte ikaskideak **ginen**.* — 十年前我们是同学。
>
> *Bart kalean jende asko **zegoen**.* — 昨晚街上有很多人。
>
> *Haurrak gu **ginen**, eta orain helduak gara.* — 我们曾经是孩子，现在是成年人了。

## 否定形式

和现在时一样：在动词前加 **ez**。

> *Atzo ez nintzen lanean egon.* — 昨天我没在上班。
>
> *Ainara ez zegoen pozik orduan.* — 那时 Ainara 不高兴。
>
> *Gu ez ginen ikaskideak.* — 我们不是同学。

## 小短文

> *Duela hamar urte Anboto Bartzelonan **bizi zen**. Han ikaslea **zen** eta unibertsitateko logelan **zegoen**. Pozik **zegoen** baina urruti **zegoen** familiatik. Astebururo telefonoz hitz egiten zuen amarekin.*

> **注意：**在这段文字中，*zen* (曾是) 和 *zegoen* (曾在) 与我们将在接下来几课中学习的其他形式并存。这就是第二单元的核心：将各种过去时形式串联起来进行叙述。
