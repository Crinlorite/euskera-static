巴斯克语的**未完成过去时** (*iragan ez burutua*) 大致对应于西班牙语的“comía / vivía / iba / trabajaba”（我过去常吃/住/去/工作）。它用于描述：

- **过去的习惯**（你通常做的事情）。
- **描述**（它是什么样的，你住在哪里，你拥有什么）。
- **进行中的动作**，作为另一个特定动作的背景。

## 公式

> **动词以 -tzen / -ten 结尾 + 过去时助动词**

现在时与未完成过去时对比：

| 现在时（今天的习惯） | 未完成过去时（过去的习惯） |
|---|---|
| *Lan egiten dut* (我工作) | *Lan egiten **nuen*** (我过去常工作) |
| *Bilbon bizi naiz* (我住在毕尔巴鄂) | *Bilbon bizi **nintzen*** (我过去住在毕尔巴鄂) |
| *Filmak ikusten ditut* (我看电影) | *Filmak ikusten **nituen*** (我过去常看电影) |
| *Egunero joaten naiz* (我每天都去) | *Egunero **joaten nintzen*** (我过去每天都去) |

> 主动词使用其**习惯体**形式（-tzen / -ten — 与 A1 级别中的形式相同），而助动词则使用**过去时**形式（第1课和第2课中的形式）。

## 使用助动词 NOR 的变位（不及物动词）

| 代词 | 未完成过去时 | 中文含义 |
|---|---|---|
| ni | *…tzen* **nintzen** | 我过去常去/是/住 |
| zu | *…tzen* **zinen** | 你过去常去 |
| hura | *…tzen* **zen** | 他/她/它过去常去/是 |
| gu | *…tzen* **ginen** | 我们过去常去/是 |
| zuek | *…tzen* **zineten** | 你们过去常去 |
| haiek | *…tzen* **ziren** | 他们过去常去 |

> *Garai hartan Donostian **bizi nintzen**.* — 那个时候我住在圣塞瓦斯蒂安。

## 使用助动词 NOR-NORK 的变位（及物动词）

| 代词 | 未完成过去时 | 中文含义 |
|---|---|---|
| nik | *…tzen* **nuen** | 我过去常做（它） |
| zuk | *…tzen* **zenuen** | 你过去常做（它） |
| hark | *…tzen* **zuen** | 他/她过去常做（它） |
| guk | *…tzen* **genuen** | 我们过去常做（它） |
| zuek | *…tzen* **zenuten** | 你们过去常做（它） |
| haiek | *…tzen* **zuten** | 他们过去常做（它） |

> *Aitak afari berezia **prestatzen zuen** igandero.* — 父亲每个星期天都会准备一顿特别的晚餐。

## Burutua vs ez burutua：关键区别

| 类型 | 形式 | 含义 |
|---|---|---|
| Burutua (完成) | partizipioa + 过去时助动词 | 一次性的、已结束的动作 |
| Ez burutua (未完成) | -tzen + 过去时助动词 | 习惯或进行中的动作 |

对比：

| 西班牙语 | 巴斯克语 |
|---|---|
| 昨天我去了公司 | *Atzo lanera **joan nintzen*** |
| 以前我骑自行车去公司 | *Lehen lanera bizikletaz **joaten nintzen*** |
| 周六我看了一部电影 | *Larunbatean film bat **ikusi nuen*** |
| 我以前每个周六都看电影 | *Larunbatero filmak **ikusten nituen*** |

## 进行体：*ari nintzen*

要表达“我当时正在做某事”，你需要使用带 **ari** 的句型：

> **-tzen + ari + izan 过去时** (NOR)

| 西班牙语 | 巴斯克语 |
|---|---|
| 我当时正在吃饭 | *Jaten **ari nintzen*** |
| 我们当时正在工作 | *Lanean **ari ginen*** |
| 当时正在下雨 | *Euria **ari zuen*** |
| 你当时在做什么？ | *Zer **ari zinen** egiten?* |

> 就像现在时的 *ari naiz* 一样，过去时用 *ari nintzen*。它用来表示动作在某个特定时刻**正在进行中**。

## 引导未完成过去时的标记词

这些标记词通常引导句子使用未完成过去时/表示习惯：

| 西班牙语 | 巴斯克语 |
|---|---|
| 小时候 | *Txikitan* |
| 年轻时 | *Gaztea nintzenean* |
| 在那个时代 | *Garai hartan* |
| 以前 / 过去 | *Lehen* / *Lehenago* |
| 总是 | *Beti* |
| 每天 | *Egunero* |
| 经常 | *Sarri* / *Askotan* |

## 对比短文

> **Burutua:** *Atzo Iratiren etxera **joan nintzen**, kafea **hartu nuen**, eta hamabietan **itzuli nintzen**.* — 昨天我去了 Irati 家，喝了杯咖啡，十二点回来了。
>
> **Ez burutua:** *Lehen Iratiren etxera **joaten nintzen** astero. Han kafea **hartzen genuen** eta luze **hitz egiten genuen**.* — 以前我每周都去 Irati 家。我们在那里喝咖啡，聊了很久。
>
> **Progresivoa:** *Atzo, kafea **hartzen ari ginela**, telefonoa jo zuen.* — 昨天，我们正在喝咖啡的时候，电话响了。

## 常见陷阱

1. **规则动词 + -tzen** 几乎总是适用的。注意：*jan → jaten* (不是 *jantzen*), *edan → edaten*, *egin → egiten*。这些在 A1 级别需要记住。
2. **不要直译“estaba siendo”（当时是）**：在巴斯克语中，未完成过去时已经涵盖了大部分描述性过去时的用法，无需添加 *ari*。
3. **助动词**与分词形式 (*partizipio*) 使用的**相同** (*nintzen, nuen*)；唯一改变的是主动词的形式。

> **实用总结：**如果句子回答的是“发生了什么？” → *partizipio + 助动词* (burutua)。如果回答的是“你通常做什么？”或“它是什么样的？” → *-tzen + 过去时助动词* (ez burutua)。如果回答的是“那一刻你正在做什么？” → *-tzen ari + izan 过去时* (puntukaria)。
