这节课是**综合性**的：它结合了完成过去时、未完成过去时和进行体，让你学会如何使用巴斯克语中时态的编排方式来**讲述一段经历**。

你已掌握的内容：

- *Iragan burutua*（第1和第2课）：一次性事件。
- *Iragan ez burutua*（第4课）：习惯或描述。
- 过去时的综合动词（第3课）：描述进行中的场景。
- 过去的时间标记（atzo, joan den astean, duela...）。

现在你将学习如何**将它们串联起来**。

## 叙事编排

一个典型的过去时叙述会根据功能混合使用不同的时态：

| 功能 | 时态 | 示例 |
|---|---|---|
| 时间和空间背景 | 未完成时 | *Garai hartan Bilbon **bizi ginen*** |
| 当时是什么样的/处于什么状态 | 未完成时 | *Iluna **zen** kalea* |
| 发生了什么（一次性） | burutua | *Bat-batean atea **jo zuten*** |
| 进行中的动作 | ari nintzen / 综合动词 | *Afaria **prestatzen ari nintzen*** |
| 结果 | burutua | *Eta gauza guztiak **gertatu ziren*** |

## 时间连接词

用于串联发生的事情：

| 西班牙语 | 巴斯克语 |
|---|---|
| 首先 / 一开始 | *Lehenengo* / *Hasieran* |
| 接下来 | *Ondoren* |
| 然后 | *Gero* |
| 之后 | *Geroago* |
| 稍后 | *Beranduago* |
| 与此同时 | *Bitartean* |
| 突然 | *Bat-batean* |
| 那时 | *Orduan* |
| 最后 / 最终 | *Azkenean* |

这些结构会出现在任何传记或个人叙述中：

| 西班牙语 | 巴斯克语 |
|---|---|
| 我出生于1990年 | *1990ean **jaio nintzen*** |

## 范文：一篇小传记

> *Garazi 1992an Iruñean **jaio zen**. Txikitan auzo lasai batean **bizi zen**, eta bere familia oso handia **zen**: lau anai-arreba **zituen** eta amona ondoan **zegoen**. Eskolan euskaraz **ikasten zuen**, eta hamabost urterekin musika tresnak **ikasten hasi zen**.*
>
> *Hemezortzi urterekin Donostiara **joan zen** unibertsitatera. Han Lander **ezagutu zuen**, kafetegi batean **lan egiten** **zuen** **bitartean**. **Maitemindu ziren** azkar, eta urtebete geroago **bizitzen hasi ziren** elkarrekin.*
>
> *Duela bost urte, **erabaki zuten** Bilbora itzultzea. Han etxe txiki bat **erosi zuten**, eta orain bertan **bizi dira** alaba batekin.*

注意时态的编排：

- *jaio zen, joan zen, ezagutu zuen, maitemindu ziren, hasi ziren, erabaki zuten, erosi zuten* → **burutua**（一次性动作）。
- *bizi zen, zituen, zegoen, ikasten zuen, lan egiten zuen* → **ez burutua**（场景、背景、习惯）。

## 如何构建你自己的叙述

给A2水平学习者的实用方法：

1. **时间背景**：用一个时间标记开始（*Duela X urte... / X-ean...*）。
2. **场景**：用未完成时描述当时的一切（*bizi nintzen, lan egiten nuen, urruti nengoen...*）。
3. **关键事件**：用burutua串联故事的要点（*ezagutu nuen, joan ginen, hasi nintzen...*）。
4. **连接词**：点缀使用 *lehenengo, gero, ondoren, bitartean, azkenean* 使叙述流畅。
5. **结尾**：用现在时结尾，与当前联系起来（*eta orain... bizi naiz / ari naiz / nago*）。

## 采访他人时可以问的问题

| 西班牙语 | 巴斯克语 |
|---|---|
| 你在哪里出生？ | *Non jaio zinen?* |
| 你什么时候开始工作的？ | *Noiz hasi zinen lanean?* |
| 你小时候做什么？ | *Zer egiten zenuen txikitan?* |
| 你先认识的是Lander还是Anboto？ | *Lehenengo nor ezagutu zenuen, Lander ala Anboto?* |
| 你的家乡是什么样的？ | *Nolakoa zen zure herria?* |
| 你为什么搬家？ | *Zergatik aldatu zinen etxez?* |

> **A2挑战：** 用五句话写一篇你自己的迷你传记，混合使用burutua和ez burutua。以*jaio nintzen*开始，接着描述你童年的场景（*bizi ginen, etxean...*），串联三个关键事件，并用现在时结尾。

> **文化小贴士：** 传记和*bizipen-kontaketak*（经历叙述）是成人巴斯克语学习中非常常见的体裁。几乎所有的A2教材都包含对长者、作家、运动员的采访。这是巩固过去时态的最佳方式，同时也能发现像Bernardo Atxaga、Itziar Ituño或Mikel Erentxun这样的文化名人。
