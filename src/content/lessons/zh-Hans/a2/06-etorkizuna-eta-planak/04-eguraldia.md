在一个早上就可能出太阳、下雨、再出太阳的国家，**谈论天气是一项全民运动**。而且这还有双重好处：*eguraldia* 的词汇是练习你刚学的将来时的绝佳领域，因为天气预报总是用 *geroaldia* 来表达。

## 基础词汇

| 西班牙语 | 巴斯克语 |
|---|---|
| 天气 | *eguraldia* |
| 太阳 | *eguzkia* |
| 雨 | *euria* |
| 雪 | *elurra* |
| 风 | *haizea* |
| 雾 | *lainoa* |
| 云 | *hodeiak* |
| 阵雨 | *zaparrada* |
| 温度 | *tenperatura* |
| 度 | *graduak* |
| 预报 | *iragarpena* |

## 三个核心句式

| 时间点 | 句式 | 例子 |
|---|---|---|
| **现在** | 现象 + ***ari du*** | *Euria **ari du**.* — 正在下雨。 |
| **通常 / 今天** | 现象 + ***egiten du*** | *Hotz handia **egiten du**.* — 天气很冷。 |
| **预报（将来）** | 现象 + ***egingo du*** | *Bihar euria **egingo du**.* — 明天会下雨。 |

其他有自己动词的说法：

> *Eguzkia **atera da** / **aterako da**.* — 太阳出来了 / 将会出来。
>
> *Haizea **dabil**.* — 正在刮风（风在“走”）。
>
> ***Hodeitsu / eguzkitsu dago**.* — 天气多云 / 晴朗。

> **请注意：**在巴斯克语中，天气是用动词 *egin* 和助动词 **du** 来“做”事情的（没有可见的主语）：*euria egingo du*，*bero handia egiten du*。这和西班牙语的 «hace calor»（天气热）几乎一样——只是雨也是被“做”出来的。

## 如何提问

> ***Zer eguraldi egiten du** zure herrian?* — 你家乡天气怎么样？
>
> ***Zer dio iragarpenak** biharko?* — 明天的天气预报怎么说？
>
> ***Zenbat gradu daude** kanpoan?* — 外面多少度？

## 一段真实的天气预报（电视上那种）

> *«Gaur, goizean **lainoa** izango dugu kostaldean, baina eguerdirako **eguzkia aterako da**. Arratsaldean **hodeiak** iritsiko dira mendebaldetik eta gauean **euria egingo du**, batez ere Bizkaian. Tenperaturak **behera egingo du**: 22 gradutik 16ra. Bihar, **haizea ibiliko da** eta **zaparradak** izango ditugu han-hemenka.»*

（早上沿海有雾，中午出太阳，下午云从西边来，夜间有雨，气温下降，明天有风和零星阵雨——经典的大西洋套餐。😄）

## 对话：计划看天定

> *— Bihar mendira **joango gara**?*
>
> *— Ez dakit… **zer dio iragarpenak**?*
>
> *— Goizean **eguzkitsu**, baina arratsaldean **euria egingo du**.*
>
> *— Orduan goiz **aterako gara**. **Zaparrada** harrapatzen bagaitu, hurrengoan ez naiz zurekin inora joango!* 😄
