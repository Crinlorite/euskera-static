本单元的最后一课 — 也为一个重要阶段画上句号：既然你已经掌握了将来时，**你就掌握了全部三种时态**。这节课是锦上添花（*ohi*，巴斯克语中的“通常”），并且会让你练习用过去时、现在习惯时和将来时表达同一个想法。这正是A2考试的考官想听到的内容。

## "Ohi" — 巴斯克语中的“通常”

> **过去分词 + ohi + 助动词**

| 西班牙语 | 巴斯克语 |
|---|---|
| 我通常骑自行车上班 | *Lanera bizikletaz joan **ohi** naiz* |
| 我们通常在奶奶家吃饭 | *Amonaren etxean bazkaldu **ohi** dugu* |
| 他/她通常来得很晚 | *Berandu etorri **ohi** da* |
| 我过去常常抽烟（现在不抽了） | *Erre **ohi** nuen* |

两点说明：

1. **位置是固定的**：在过去分词和助动词之间。*Joan ohi naiz* ✓ — 绝不是 *ohi joan naiz*。
2. 当**助动词为过去时**时，就得到“过去常常”的意思：*joan ohi nintzen* (过去常常去)。它和你已经学过的未完成时（*joaten nintzen*）非常相似 — *ohi* 更加强调习惯性。

> **不用 "ohi" 可以吗？** 现在习惯时（*joaten naiz*）本身就表达习惯。*Ohi* 是一种更优雅的强调方式，常见于书面语和考试中。当你想让表达听起来更地道时，可以使用它：*Igandeetan hondartzara joan ohi gara.*

## 与习惯搭配的副词

| 西班牙语 | 巴斯克语 |
|---|---|
| 通常 | *normalean* |
| 大多数时候 | *gehienetan* |
| 几乎总是 | *ia beti* |
| 有时 | *batzuetan* |
| 几乎从不 | *ia inoiz ez* |
| 每天早上 / 每年 | *goizero / urtero* |
| 每周日 | *igandeetan* |

## 完整时态图（你的终极备忘单）

| 概念 | 巴斯克语 | 时态 |
|---|---|---|
| 我去（习惯） | *joaten naiz* / *joan ohi naiz* | 现在习惯时 |
| 我正在去 | *joaten ari naiz* | 现在进行时 |
| 我（今天）去过了 | *joan naiz* | 最近过去时 |
| 我（某天）去了 | *joan nintzen* | 简单过去时 |
| 我过去常去 / 过去常常去 | *joaten nintzen* / *joan ohi nintzen* | 过去习惯时 |
| 我将要去 | ***joango naiz*** | **将来时** |

六个格子。一个动词。**你全都掌握了。**

## 小短文：过去、现在和未来

> *Lehen, lanera autoz joan **ohi nintzen**: ordu erdi trafikoan, egunero. Orain bizikletaz **joaten naiz** — hamar minutu, eta gainera kirola **egiten dut**. Datorren urtean etxetik gertuago **biziko naiz**, eta orduan oinez **joango naiz**. Nire medikua pozik **egongo da**!* 😄

## 复习对话（三种时态的实际应用）

> *— Zer egin **ohi duzu** igandeetan?*
>
> *— Normalean berandu jaiki eta familiarekin bazkaldu **ohi dut**. Baina datorren igandean ezberdina **izango da**: Behobia-Donostia lasterketa **korrituko dut**!*
>
> *— Ederki! Entrenatu **ohi zara**?*
>
> *— Bai, gaztetan asko korritzen **nuen**, gero utzi **egin nion**… eta aurten berriro **hasi naiz**. Bihar azken entrenamendua **egingo dut**.*
>
> *— Ba, zorte on! Helmugan **egongo naiz**, animatzen.* 💪
