从纸张到像素：**日常科技**课程。你每天使用一百次的词汇 — 现在用巴斯克语来学习，巴斯克语还以其结构清晰、易于理解的词汇而自豪 (*pasahitza* = 通行词；*sakelakoa* = “口袋里的东西”)。

## 设备

| 西班牙语 | 巴斯克语 |
|---|---|
| 电脑 | *ordenagailua* |
| 笔记本电脑 | *eramangarria* |
| 手机 | *mugikorra / sakelakoa* |
| 平板电脑 | *tableta* |
| 屏幕 | *pantaila* |
| 键盘 | *teklatua* |
| 鼠标 | *sagua* (对，就是那种动物！) |
| 耳机 | *entzungailuak* |

## 网络和账户

| 西班牙语 | 巴斯克语 |
|---|---|
| 网络 / 互联网 | *sarea / internet* |
| 无线网络 (wifi) | *wifia* |
| 电子邮件 | *posta elektronikoa* |
| 用户 | *erabiltzailea* |
| 密码 | *pasahitza* |
| 应用程序 (App) | *aplikazioa* |
| 网页 | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Wifi 密码是什么？
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — 我忘了密码，现在得创建一个新的。又来一次。
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — 创建账户需要电子邮件和密码。

## 数字动词

| 西班牙语 | 巴斯克语 |
|---|---|
| 开机 / 关机 | *piztu / itzali* |
| 下载 | *deskargatu / jaitsi* |
| 安装 | *instalatu* |
| 保存 | *gorde* |
| 删除 | *ezabatu* |
| 发送 / 分享 | *bidali / partekatu* |
| 搜索 (在网上) | *bilatu* |
| 运行 | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — 电脑出问题了；关机再开机——老办法了。
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — 你保存照片了吗？什么都别删！
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — 下载应用，创建账户，搞定。

## 对话：家庭技术支持

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **注：**数字领域的巴斯克语非常有活力：自由软件和巴斯克语维基百科都非常强大，而且你的整部手机都可以设置为巴斯克语 (*Ezarpenak → Hizkuntza*)。事实上，这样做是一个绝佳的学习技巧：免费的日常沉浸式学习。
