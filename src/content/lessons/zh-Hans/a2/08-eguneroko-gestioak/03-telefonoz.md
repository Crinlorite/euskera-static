用另一种语言打电话可能会让人感到紧张——你看不见对方的脸，也没有手势。因此，本课是**纯粹的现成句式**：从正式电话到WhatsApp语音，这些固定短语总是管用。

## 接电话与询问

| 西班牙语 | 巴斯克语 |
|---|---|
| 喂？请讲？ | *Bai, esan?* |
| 请问是哪位？ | *Nor da?* |
| Ane在吗？ | *Ane dago?* |
| 我是Mikel | *Mikel naiz* |
| 请稍等，他马上就来 | *Une batez, orain jarriko da* |
| 他现在不在 | *Orain ez dago* |

## 当对方无法接电话时

> *— Kaixo, **Ane dago**?*
>
> *— Ez, **orain ez dago**. Zerbait **esan behar diot**?*
>
> *— Bai, mesedez: bilera **bihar dela**, ez gaur. Edo hobeto: **deituko didala**, libre dagoenean.*
>
> *— Ederki, **esango diot**. Nor zarela esango diot?*
>
> *— **Mikel naiz**, lanekoa. Eskerrik asko!*

请注意：*esan behar diot* (我得告诉他/她), *esango diot* (我会告诉他/她), *deituko didala* (叫他/她打给我) ——第03单元的NOR-NORI-NORK格在电话中起主导作用。打电话是 *deitu* + NORI格：*deitu diot* (我打过电话给他/她), *deituko dizut* (我会打给你)。

## 技术问题（经典场景）

| 西班牙语 | 巴斯克语 |
|---|---|
| 正在占线 | *Komunikatzen ari da* |
| 没有信号 | *Estaldurarik ez dago* |
| 我手机没电了 | *Bateria gabe geratu naiz* |
| 听不清楚 | *Gaizki entzuten da* |
| 电话断了 | *Deia moztu da* |
| 打错号码了 | *Okerreko zenbakia* |

> *Barkatu, **gaizki entzuten da**. Igogailuan nago — **gero deituko dizut**!* — 抱歉，听不太清楚。我在电梯里——待会儿打给你！

## 短信 (gaur egungo bizitza)

> ***Mezu bat bidali dizut** WhatsAppez.* — 我通过WhatsApp给你发了一条消息。
>
> ***Audioa entzun duzu**?* — 你听那条语音了吗？
>
> *Deitu beharrean, **idatzi**, mesedez: bileran nago.* — 请不要打电话，发消息给我，谢谢：我正在开会。

## 电话答录机/语音留言

> *«Kaixo! Orain ezin dut telefonoa hartu. **Utzi mezua** seinalearen ondoren, eta **lehenbailehen deituko dizut**. Eskerrik asko!»* — 你好！我现在无法接听电话。请在提示音后留言，我会尽快回电。谢谢！

*Lehenbailehen* = 尽快。一个能让你的水平听起来提高两分的优雅词汇。😄
