成年人生活中的终极大佬：**办手续**。深呼吸：只要选对十个词（*agiria, hitzordua, bete, epea…*），你就能在任何窗口生存下来——而且还是用巴斯克语，并附赠公务员的微笑。

## 办手续词汇

| 西班牙语 | 巴斯克语 |
|---|---|
| 市政厅 | *udaletxea* |
| 户籍 / 登记户口 | *errolda / erroldatu* |
| 户籍证明 | *errolda-agiria* |
| 文件 / 证明 | *agiria* |
| 身份证 | *NANa* |
| 驾照 | *gidabaimena* |
| 申请表 | *eskabidea* |
| 填写 | *bete* |
| 预约 / 号 | *hitzordua / txanda* |
| 期限 | *epea* |
| 窗口 | *leihatila* |

## 预约（现代仪式）

> ***Hitzordua eskatu behar da** aurretik, webgunean edo telefonoz.* — 需要提前在网站或通过电话预约。
>
> *Hitzordua daukat **gaurko, hamaiketan**, erroldarako.* — 我今天十一点有个户籍登记的预约。

## 在窗口

> *— Egun on. **Errolda-agiri bat behar dut**, banketxerako.*
>
> *— **NANa**, mesedez… Momentu bat… Tori, hemen duzu. **Doan da**.*
>
> *— Eskerrik asko! Eta beste kontu bat: etxez aldatu naiz. **Erroldatzeko**, zer egin behar dut?*
>
> *— **Eskabide hau bete** eta etxebizitzaren kontratua ekarri. **Fotokopiarik ez** da behar; guk egiten dugu.*
>
> *— Bikain. **Eperik badago**?*
>
> *— Ez, lasai, edonoiz etor zaitezke. Baina **hitzordua eskatu** lehenago, e!*

## 三句生存必备短语

> ***Zer agiri ekarri behar ditut**?* — 我需要带什么文件？
>
> ***Noiz arte** daukat epea?* — 我的期限到什么时候？
>
> ***Nork sinatu behar du**?* — 谁需要签字？

> **注意：** *hitzordua* 的字面意思是“话语的时间” (*hitza* + *ordua*)——无论是看医生、去市政厅办事还是浪漫约会，都可以用这一个词。具体是哪种，就看上下文（和你脸上的表情）了。😄
