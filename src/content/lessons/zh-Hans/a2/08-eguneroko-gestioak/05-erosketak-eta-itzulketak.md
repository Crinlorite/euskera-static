从A1级别起你就已经会购物了。这节课是**商店购物的第二级**：试穿衣服、跟尺码作斗争，以及——最终大boss——轻松**换货或退货**。有两个老朋友在帮忙：后缀*-egi*（太……）和NOR-NORI格（*geratzen zait*）。

## 在试衣间

| 西班牙语 | 巴斯克语 |
|---|---|
| 我可以试穿一下吗？ | *Probatu dezaket?* |
| 试衣间 | *probalekua* |
| 尺码 | *neurria / talla* |
| 你穿什么尺码？ | *Zein neurri erabiltzen duzu?* |
| 我穿着合适 / 不合适 | *Ondo / gaizki geratzen zait* |
| 太大 / 太小 | *Handiegia / txikiegia* |
| 你们有其他颜色的吗？ | *Beste kolore batean baduzue?* |
| 那有大一码的吗？ | *Eta neurri bat handiagoan?* |

> *— Praka hauek **probatu ditzaket**?*
>
> *— Noski, **probalekua** hor atzean dago.*
>
> *（五分钟后）* *— Zer, **ondo geratzen zaizkizu**?*
>
> *— Ez… **txikiegiak dira**. **42an baduzue**?*

*Geratzen zait / zaizkizu* — 纯粹的NOR-NORI格：衣服（NOR）对我（NORI）来说很合身。复数形式是 *geratzen zaizkit*（它们对我来说很合身）。

## 换货与退货

| 西班牙语 | 巴斯克语 |
|---|---|
| 我想换货 | *Aldatu nahi dut* |
| 我想退货 | *Itzuli nahi dut* |
| 可以退款给我吗？ | *Dirua itzuliko didazue?* |
| 小票 | *tiketa* |
| 它有瑕疵 | *Akats bat dauka* |
| 还没穿过 | *Erabili gabe dago* |
| 退货期限 | *Itzultzeko epea* |

> *— Egun on. Jertse hau **itzuli nahi nuke**. **Akats bat dauka** hemen, ikusten?*
>
> *— Egia da. **Tiketa badaukazu**?*
>
> *— Bai, hemen. **Dirua itzuliko didazue** ala aldatu behar dut?*
>
> *— Nahi duzun bezala. Dirua **txartelera itzuliko dizugu**, bi-hiru egunetan.*
>
> *— Primeran, eskerrik asko.*

注意这个连锁的NOR-NORI-NORK格：*itzuliko didazue*（你们将把它退给我），*itzuliko dizugu*（我们将把它退给你）。第03单元在现实生活中的应用。

## 折扣与价格（趣味复习）

> ***Merkealdiak** daude: dena **%50ean**!* — 正在打折：所有商品5折！
>
> *Deskontuarekin, **19,95 euro** bakarrik.* — 折后仅需19.95欧元。
>
> *Bi erosita, **hirugarrena doan**.* — 买二送一。

## 口袋总结

1. **试穿**：*Probatu dezaket? → Ondo/gaizki geratzen zait → -egi* 用于尺码。
2. **换货**：*Aldatu nahi dut* (+ *beste neurri/kolore batean*）。
3. **退货**：*Itzuli nahi dut* + *tiketa* + *dirua itzuliko didazue?*
