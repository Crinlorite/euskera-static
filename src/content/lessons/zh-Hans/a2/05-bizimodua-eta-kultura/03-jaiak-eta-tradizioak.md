本课将为你提供谈论**节日和习俗**以及**比较时代和地点**（“以前……现在”、“在X和Y都……”）的工具。这是A2级别任何文化对话中必不可少的词汇。

## 巴斯克节日：核心词汇

| 日期 | 节日 | 西班牙语简介 |
|---|---|---|
| 6月23日 | *San Juan sua* | 圣胡安篝火 |
| 12月31日 | *Urtezahar* | 除夕 |
| 12月24日 | *Olentzero* | 送礼物的烧炭工角色 |
| 2月/3月 | *Inauteriak / Aratusteak* | 狂欢节 |
| 2月5日 | *Santa Ageda* | 挨家挨户唱传统歌曲 |
| 每两年一次 | *Korrika* | 支持巴斯克语的民众长跑 |
| 8月 | *Aste Nagusia* | 毕尔巴鄂大周节 |
| 地方性（各村镇） | *Herriko jaiak* | 村镇节日 |

## 巴斯克文化中的人物和元素

| 西班牙语 | 巴斯克语 |
|---|---|
| Bertsolari（即兴诗人） | *bertsolaria* |
| Trikitilari（手风琴手） | *trikitilaria* |
| Txistulari（传统笛手） | *txistularia* |
| Dantzari（舞者） | *dantzaria* |
| Pelotari（回力球手） | *pilotaria* |
| Aizkolari（伐木手） | *aizkolaria* |
| Harrijasotzaile（举石手） | *harrijasotzaileak* |

> **文化小贴士：***kirol-jaiak*（乡村运动）是节日的典型活动：举石、用斧头砍木、划艇比赛、*soka-tira*（拔河）。它们是巴斯克身份的标志，出现在任何村镇的节日活动中。

## 比较过去和现在：*lehen / orain*

文化比较会用到这两个词：

| 西班牙语 | 巴斯克语 |
|---|---|
| 以前 | *lehen* |
| 现在 | *orain* |
| 过去，古时候 | *garai batean* / *aspaldian* |
| 如今 | *gaur egun* |
| 以前……现在…… | *Lehen... orain...* |
| 几年前 | *Duela urte batzuk* |

> *Lehen baserrian **bizi ginen**, orain hirian **bizi gara**.* — 以前我们住在农舍里，现在我们住在城市里。
>
> *Garai batean **dena euskaraz egiten zen**; gaur egun, **erdaraz ere asko** egiten da.* — 过去一切都用巴斯克语进行；如今，很多也用西班牙语进行。

## 比较地点：*bai... bai...*, *baita... ere*

| 西班牙语 | 巴斯克语 |
|---|---|
| 在X和Y都 | *Bai X-(e)an, bai Y-(e)an* |
| 在X也 | *X-(e)an ere bai* |
| 在X和Y都不 | *Ez X-(e)an, ez Y-(e)an* |
| 不仅X，也Y | *Ez **bakarrik** X, **baita** Y **ere*** |

> *San Juan sua **bai** Donostian, **bai** Bilbon ospatzen da.* — 圣胡安篝火节在多诺斯蒂亚和毕尔巴鄂都会庆祝。
>
> *Korrika **bai** Hego Euskal Herrian, **bai** Iparraldean egiten da.* — *Korrika* 在南巴斯克地区和北巴斯克地区都会举行。

## 如何描述一个节日

实用结构：

> **节日 + 时间 + 地点 + 活动内容 + 特别之处**

> *San Juan sua **ekainaren 23an** ospatzen da. Herri askotan **plaza nagusian** egur pila bat egiten da, eta gauean **sua pizten dute**. Jendeak **suaren gainetik salto egiten du**, eta **dantzan eta kantuan** aritzen da gauerdi arte. Familia eta lagun arteko ospakizuna da, eta **udaren hasiera** ospatzen du.*

## 对比小短文

> *Lehen, herriko **jaiak** ohikoak ziren udazkenean. Familia osoa elkartzen zen plaza nagusian, **bertsolariak** eta **trikitilariak** entzuten zituen, eta **dantzan** ari zen gauerdi arte. **Gaur egun**, jaiak antolatzea zailagoa da: jendea sakabanatuta dago, gazteek bestelako gustuak dituzte, eta **lehen baino** diru **gutxiago** dago. Hala ere, **tradizioa** mantentzen ahalegintzen dira: **bai herri txikietan, bai hiri handietan**, urtero programa **politak** prestatzen dituzte.*

## 对话：比较习俗

> *— Anboto, zer ospatzen da zure herrian?*
>
> *— Ba, klasikoak: **San Juan**, **herriko jaiak** abuztuan, **Olentzero** Eguberrian. **Korrika** ere bai bi urtero, oso garrantzitsua hori.*
>
> *— Eta Olentzero, oraindik etxez etxe ibiltzen da?*
>
> *— **Lehen ohitura zen** etxez etxe ibili eta umeentzako opariak banatzea. **Orain**, herri txikietan oraindik egiten da, baina hirietan ekitaldi nagusi bat plazan egin ohi da, **bertsolariekin eta musikarekin**.*

## 用于文化比较的实用句式

| 西班牙语 | 巴斯克语 |
|---|---|
| 相反，在这里…… | *Hemen, aldiz, ...* |
| 和在X一样 | *X-(e)n bezala* |
| 和X不同 | *X ez bezala* |
| 与……相似 | *Antzekoa da* |
| 非常不同 | *Oso ezberdina da* |

> **文化小贴士：**巴斯克节日是官方考试和实际对话中A2级别最常出现的话题之一。用五句话**描述一个你自己最喜欢的节日**：时间、地点、活动内容、你喜欢什么，并将其与另一个节日进行比较。这是一个完美的综合练习。
