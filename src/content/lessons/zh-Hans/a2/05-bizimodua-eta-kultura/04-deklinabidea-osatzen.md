这节综合课复习A2级别在A1级别（NOR, NORK, NORI, NON, NOREN, NORA, NONDIK, NOREKIN）的基础上新增的**四个新变格**。它们会出现在任何A2级别的考试中，并补全了巴斯克语的“变格玫瑰图”。

## NORENTZAT — 为谁 (表目的)

> **-(r)entzat** 加在限定名词后

| 名词 | 形式 | 中文 |
|---|---|---|
| niretzat | *niretzat* | 为我 |
| zuretzat | *zuretzat* | 为你 |
| beretzat / harentzat | *beretzat* | 为他/她 |
| guretzat | *guretzat* | 为我们 |
| zuentzat | *zuentzat* | 为你们 |
| haientzat | *haientzat* | 为他们 |
| Lander | *Landerrentzat* | 为Lander |
| la madre | *amarentzat* | 为妈妈 |
| los amigos | *lagunentzat* | 为朋友们 |

> *Hau **zuretzat** da.* — 这是给你的。
>
> *Opari bat erosi dut **Garazirentzat**.* — 我给Garazi买了一件礼物。
>
> *Liburu hau **gazte ikasleentzat** da.* — 这本书是给年轻学生的。

> **变体：** 也有 **-(r)endako** 这种形式，在许多方言中是同义词：*Garazirendako, niretzako/niretako*。标准形式是 *-rentzat*。

## NORAINO — 直到 (表终点)

> **-(r)aino** 加在名词后 (遵循NORA格的规则：元音 → +raino，辅音 → +eraino)

| 中文 | 巴斯克语 |
|---|---|
| 直到山 | *mendi**raino*** |
| 直到毕尔巴鄂 | *Bilbo**raino*** |
| 直到这里 | *hona**ino*** |
| 直到哪里 | *nora**ino*** |
| 直到顶峰 | *tontorr**eraino*** |

> *Korrika egin dugu **plazaraino**.* — 我们一直跑到广场。
>
> *Bilbo**raino** etorri zen eta gero itzuli.* — 他一直来到毕尔巴鄂，然后又回去了。

## NORANTZ — 朝向 (表方向)

> **-(r)antz** 加在名词后 (与NORA格的模式相同)

| 中文 | 巴斯克语 |
|---|---|
| 朝向山 | *mendi**rantz*** |
| 朝向家 | *etxe**rantz*** |
| 朝向南方 | *hego**rantz*** |
| 朝向你 | *zu**rantz*** |

> *Etxe**rantz** abiatu nintzen.* — 我朝家的方向走去。
>
> *Itsaso**rantz** dago etxea.* — 房子朝向大海。

> **与NORA (-ra)的区别：** *NORA* 表示具体目的地（“我去毕尔巴鄂”）；*NORANTZ* 表示大致方向（“我朝毕尔巴鄂方向去”，不保证一定会到达）。

## ZERGATIK / NORENGATIK — 因为 (表原因)

提问原因时用：**zergatik?** (为什么？)。用名词回答时用：**-engatik**。

| 名词 | 形式 | 中文 |
|---|---|---|
| nigatik | *nigatik* | 因为我 |
| zugatik | *zugatik* | 因为你 |
| beragatik / harengatik | *beragatik* | 因为他/她 |
| Lander | *Landerrengatik* | 因为Lander |
| la madre | *amarengatik* | 因为妈妈 |
| el amor | *maitasunarengatik* | 因为爱 |
| la lluvia | *euriagatik* | 因为下雨 |

> *Eskerrik asko **etorri zarelako, niregatik**!* — 谢谢你为我而来！
>
> *Berandu iritsi nintzen **trafikoarengatik**.* — 我因为堵车迟到了。
>
> *Zergatik egin duzu hori? — **Zugatik**.* — 你为什么这么做？ — 因为你。

> **注意：** 区分 *-engatik* (原因：“因为……的缘故”) 和 *-rentzat* (接收者：“为了”)。在西班牙语中，“por”可以涵盖这两种意思，但在巴斯克语中它们是不同的。

## NONGO / NOIZKO — 来自何处/何时

你在A1级别已经学过 *NON* (-an: 在)。**NONGO** 和 **NOIZKO** 将一个地点或时间转换为**修饰语**（定语）：

| 中文 | 巴斯克语 |
|---|---|
| 毕尔巴鄂**的**人 | *Bilbo**ko** jendea* |
| 多诺斯蒂亚**的**博物馆 | *Donostia**ko** museoa* |
| 今天**的**报纸 | *Gaur**ko** egunkaria* |
| 明天**的**考试 | *Bihar**ko** azterketa* |
| 七月**的**节日 | *Uztaileko jaia* |

> 这就是 **NONGO/NOIZKO** 格 (-ko / -tako 辅音后)：“哪里的”/“什么时候的”的定语意义。

| 形式 | 用途 |
|---|---|
| **-ko** 单数 | *Bilboko, etxeko, gaurko* |
| **-etako** 复数 | *etxe**etako**, mendi**etako**, urte**etako*** |

> *Atzo**ko** afari**a** ona zen.* — 昨天的晚餐很好吃。
>
> *Bilbo**ko** etxebizitzak garestiak dira.* — 毕尔巴鄂的住房很贵。
>
> *Mendi**etako** loreak ederrak dira.* — 山上的花很漂亮。

## 迷你总结表

| 格 | 后缀 | 疑问词 | 例子 |
|---|---|---|---|
| NORENTZAT | -rentzat | 为谁？ | *Garazirentzat* |
| NORAINO | -raino | 直到哪里？ | *Bilboraino* |
| NORANTZ | -rantz | 朝向哪里？ | *etxerantz* |
| NORENGATIK | -engatik | 因为谁/什么？ | *euriagatik* |
| NONGO | -ko | 哪里的（定语）？ | *Donostiako* |
| NOIZKO | -ko / -tako | 什么时候的？ | *gaurko, atzoko* |

## 迷你综合短文

> *Joan den astean **Bilboraino** joan ginen autobusez. Helmuga: hiriko **museorako** sarrera bana erostea. **Bilboko jendea** oso jatorra izan zen. Buelta hartzeko, taxi bat hartu genuen **etxerantz**: euri-jasa hain handia zen, ezen autoa **euriagatik** hondatu zen. Azkenean, ordu bat **beranduago** iritsi ginen **Donostiako geltokira**. Hori bai, etxean opari bat zegoen zain: **niretzat**, ama maitearen partez.*

## A2级别变格玫瑰图：视觉复习

现在你已经掌握了所有基础格：

| 格 | 疑问词 | 后缀 | 例子 (etxe) |
|---|---|---|---|
| NOR | 谁？ | -a | *etxea* |
| NORK | 谁做？ | -ak | *etxeak* (sujeto) |
| NORI | 给谁？ | -ari | *etxeari* |
| NON | 在哪里？ | -an | *etxean* |
| NORA | 去哪里？ | -ra | *etxera* |
| NONDIK | 从哪里？ | -tik | *etxetik* |
| NOREKIN | 和谁？ | -arekin | *etxearekin* |
| NOREN | 谁的？ | -aren | *etxearen* |
| NONGO | 哪里的（定语）？ | -ko | *etxeko* |
| NORENTZAT | 为谁？ | -arentzat | *etxearentzat* |
| NORAINO | 直到哪里？ | -raino | *etxeraino* |
| NORANTZ | 朝向哪里？ | -rantz | *etxerantz* |
| NORENGATIK | 因为谁？ | -arengatik | *etxearengatik* |
| -ZAZ / -Z | 工具格 | -z | *etxez* |
| -RIK | 部分格（否定） | -rik | *etxerik (ez dago)* |

> **A2挑战：** 用名词 *Garazi* 对每个格各造一个句子。你会看到巴斯克语的整个机制如何在一个词上运作。

> **教学提示：** 这些变格是“通往B1的大门”：如果你掌握了它们，你就能构建包含丰富信息（目的地、原因、定语、方向）的句子。在B1级别，你将深化学习它们的抽象用法，并会增加一些新的格（具有原因价值的工具格，扩展的部分格）。
