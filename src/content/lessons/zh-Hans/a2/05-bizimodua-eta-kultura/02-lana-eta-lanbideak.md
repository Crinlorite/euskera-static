A2为你打开了**工作**的世界，超越了“我是学生/我是老师”的范畴。现在你将开始谈论：

- 工作类型和工时。
- 求职面试。
- 简历和经验。
- **描述**你现有或想要从事的**工作**。

## 职业 — 扩展复习

A1级别涵盖了常见的职业（*medikua, ikaslea, irakaslea, sukaldaria*）。在A2级别，你将学习更多：

| 西班牙语 | 巴斯克语 |
|---|---|
| 记者 | *kazetaria* |
| 程序员 | *programatzailea* |
| 设计师 | *diseinatzailea* |
| 工程师 | *ingeniaria* |
| 建筑师 | *arkitektoa* |
| 律师 | *abokatua* |
| 公证员 | *notarioa* |
| 企业家 | *enpresari* |
| 商人 | *merkataria* |
| 司机 | *gidaria* |
| 消防员 | *suhiltzailea* |
| 公务员 | *funtzionarioa* |
| 助理 | *laguntzailea* |
| 销售员 | *saltzailea* |
| 泥瓦匠 | *igeltseroa* |
| 管道工 | *iturgina* |
| 电工 | *elektrizista* |

> **技巧：**许多职业以 **-le**、**-tzaile** 或 **-ari** 结尾：*saltzaile, irakasle, gidari, sukaldari, kazetari*。这些是能产新词的后缀。

## 后缀 -**dun**（“拥有/带有……”）

回顾一下A1级别学过的这个后缀——在职业词汇中很常用：

| 西班牙语 | 巴斯克语 |
|---|---|
| 说巴斯克语的人 | *euskalduna* |
| 冠军（戴着txapela的人） | *txapelduna* |
| 卡车司机 | *kamioiduna* |

## 面试常用语

| 西班牙语 | 巴斯克语 |
|---|---|
| 介绍一下你自己 | *Konta iezadazu zerbait zuri buruz* |
| 你为什么想得到这个职位？ | *Zergatik nahi duzu lanpostu hau?* |
| 你有什么经验？ | *Zer esperientzia daukazu?* |
| 我会说巴斯克语、西班牙语和英语 | *Euskaraz, gaztelaniaz eta ingelesez hitz egiten dut* |
| 我从六月起可以入职 | *Ekainetik aurrera nago eskuragarri* |
| 你的期望薪资是多少？ | *Zer **soldata** nahi duzu?* |

## 使用 -**(e)n** 的关系从句

要更复杂地描述你的工作，使用**关系从句**会很方便：

> **变位动词 + -(e)n + 名词**

| 西班牙语 | 巴斯克语 |
|---|---|
| 我有的工作 | *Daukadan lana* |
| 我工作的公司 | *Lan egiten dudan enpresa* |
| 我认识的同事 | *Ezagutzen ditudan lankideak* |
| 我领的薪水 | *Jasotzen dudan soldata* |
| 我上过的课程 | *Egin nuen ikastaroa* |

> **构成方式：**现在时或过去时动词 + 后缀 **-(e)n** + 名词。
>
> *dut → dudan*, *du → duen*, *zen → zen*, *zuen → zuen*（如果动词已经以 -n 结尾，则不添加额外的字母）。

> 这是A2级别的一个关键知识点，在第5单元中有多种用法：在面试中（*duzun esperientzia*）和在介绍中（*ezagutzen dudan jendea*）。B1级别会更深入地学习。

## 迷你对话：lan-elkarrizketa

> *— Egun on. Eseri, mesedez. **Konta iezadazu** zertan **lan egin duzun** orain arte.*
>
> *— Bai. Bost urtez **lan egin dut** Bilboko diseinu-enpresa batean. Han **daukadan zeregina** bezeroentzako proiektuak diseinatzea da.*
>
> *— Ondo. Eta zergatik nahi duzu **lanpostu hau**?*
>
> *— **Iruditzen zait** zuen enpresa **interesgarriagoa dela**, eta nire trebetasunak hobeto erabili **ahal izango ditudala**. **Gainera**, **lanaldi erdiko** modalitatea **eskaintzen duzuelako**, hori asko **interesatzen zait**.*

## 迷你短文：工作描述

> *Lander **kazetari** lanetan dabil hamar urtetik hona. Bilboko egunkari batean **lan egiten du**, **lanaldi osoan**. Goizeko zortzietan hasten da eta bostetan amaitzen du. Berarentzat **garrantzitsuena** albisteak ondo **kontatzea** da. **Soldata** ez da oso handia, baina **gustatzen zaion lana** dauka, eta **lankide jatorrak** ditu.*

> **文化小贴士：**在巴斯克地区，许多公共部门的招聘（如Osakidetza、Eusko Jaurlaritza、市政厅）会通过一个**“等级”**（PL1, PL2, PL3, PL4）系统来为巴斯克语知识加分。学习巴斯克语不仅是为了文化：对于许多公共职位来说，它是一项竞争优势。
