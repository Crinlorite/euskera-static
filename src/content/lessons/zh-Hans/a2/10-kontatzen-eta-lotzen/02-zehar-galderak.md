到目前为止，你都是直接提问：*Etorriko da?* 现在你将学习如何**间接地**提问：*我不知道**他/她是否会来***，*问问他/她**是否有时间***。这些就是 *zehar-galderak*（间接问句），其诀窍只有一个字母：**-n**。

## 规则：助动词加上 -n

| 直接 | 间接 |
|---|---|
| *Etorriko **da**?* | *Ez dakit etorriko **den*** |
| *Nor **da**?* | *Ez dakit nor **den*** |
| *Non **dago**?* | *Ez dakit non **dagoen*** |
| *Zer nahi **du**?* | *Ez dakit zer nahi **duen*** |
| *Denborarik **dauka**?* | *Galdetu ea denborarik **daukan*** |

如何附加 **-n**：*da → den* · *dago → dagoen* · *du → duen* · *dauka → daukan* · *gara → garen* · *dute → duten*。（如果以元音结尾，加 -n；否则加 -en。两天后你的耳朵就会习惯了。）

## "Ea" — 万能词

对于“是/否”问句，巴斯克语会加上 ***ea***（=“看看是否/是否”）：

> *Galdetu diot **ea gurekin bazkalduko duen**.* — 我问了他/她是否会和我们一起吃午饭。
>
> *Ikusiko dugu **ea eguraldi ona egiten duen**.* — 我们看看天气会不会好。
>
> ***Ea garaiz iristen garen**!* — 希望能准时到！

最后这个单独的 *ea…!* 是纯正的巴斯克口语：一个词就表达了愿望和悬念。

## 需要使用间接问句的动词

| 西班牙语 | 巴斯克语 |
|---|---|
| 我不知道是否… | *Ez dakit … -(e)n* |
| 你知道是否…？ | *Badakizu … -(e)n?* |
| 问问他/她是否… | *Galdetu (iezaiozu) ea … -(e)n* |
| 我不记得是否… | *Ez naiz gogoratzen … -(e)n* |
| 我不确定是否… | *Ez nago ziur … -(e)n* |

## 实战演练

> *— **Badakizu zer ordutan hasten den** kontzertua?*
>
> *— Ez, baina Aneri **galdetuko diot ea dakien**.*
>
> *— Eta **ea sarrerarik geratzen den** ere galdetu, mesedez!*
>
> *— Lasai. **Ea zorte ona dugun**!*

## 与 -la 的对比（易混淆点）

不要将间接问句与间接陈述句（第04单元）混淆：

> *Esan dit etorriko **dela**.* — 他/她告诉我他/她**会**来。（陈述 → **-la**）
>
> *Galdetu dit **ea** etorriko **den**.* — 他/她问我我**是否**会来。（疑问 → **-n**）

**Que = -la · Si = (ea) -n.** 记住这个口诀，这一课你就掌握了。
