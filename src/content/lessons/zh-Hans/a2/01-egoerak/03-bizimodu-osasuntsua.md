谈论**生活方式**和**环境**是A2级别的经典模块：它将新词汇与你从A1级就已掌握的表示义务和建议的短语（*behar dugu*、*komeni da*、*garrantzitsua da*）结合起来。

## 健康习惯

| 西班牙语 | 巴斯克语 |
|---|---|
| 做运动 | *kirola egin* |
| 走路 / 散步 | *paseatu* / *ibili* |
| 跑步 | *korrika egin* |
| 骑自行车 | *bizikletaz ibili* |
| 吃水果和蔬菜 | *fruta eta barazkiak jan* |
| 喝水 | *ura edan* |
| 睡好觉 | *ondo lo egin* |
| 吸烟 | *erre* |
| 喝酒 | *alkohola edan* |
| 不要摄入过多的盐 | *gatzaz ez abusatu* |

> 典型句子：
>
> - *Kirola egiten dut astean hiru aldiz.* — 我每周运动三次。
> - *Erretzeari utzi diot.* — 我已经戒烟了。
> - *Ez dut alkoholik edaten astegunetan.* — 我工作日不喝酒。

## 频率：*X aldiz*

要表达“X次”，使用公式 **数字 + aldiz**：

| 西班牙语 | 巴斯克语 |
|---|---|
| 一天一次 | *Egunean behin* |
| 一周两次 | *Astean bi aldiz* / *birritan* |
| 一月三次 | *Hilean hiru aldiz* |
| 很多次 | *Askotan* |
| 有时 | *Batzuetan* |
| 很少次 | *Gutxitan* |
| 从不 | *Inoiz ez* |

## 环境 — *ingurumena*

| 西班牙语 | 巴斯克语 |
|---|---|
| 环境 | *ingurumena* |
| 自然 | *natura* |
| 污染 | *kutsadura* |
| 垃圾 | *zaborra* |

## 垃圾箱

| 常见颜色 | 巴斯克语 | 用途 |
|---|---|---|
| 蓝色 | *edukiontzi urdina* | papera / 纸张 |
| 黄色 | *edukiontzi horia* | plastikoa / 塑料 |
| 绿色 | *edukiontzi berdea* | beira / 玻璃 |
| 棕色 | *edukiontzi marroia* | organikoa / 有机物 |
| 灰色 | *edukiontzi grisa* | hondakinak / 其他垃圾 |

## 用于发表意见的实用短语

- *Garrantzitsua da birziklatzea.* — 回收很重要。
- *Komeni da kirola egitea.* — 做运动是件好事。
- *Beharrezkoa da kutsadura gutxitzea.* — 减少污染是必要的。
- *Ez dut uste plastikoa ona denik.* — 我不认为塑料是好东西。

> 这些结构（*-tzea + 形容词 + da*）是A2级别用来表达“做某事是重要的/适宜的/必要的”的公式。我们将在第4单元深入学习它们。

## 社区生活

| 西班牙语 | 巴斯克语 |
|---|---|
| 社区 | *auzoa* |
| 邻居 | *bizilaguna* |
| 协会 | *elkartea* |
| 志愿服务 | *boluntariotza* |
| 社区节日 | *auzoko jaiak* |
| 参加 | *parte hartu* |
| 会议 | *bilera* |

> *Gure auzoan jaiak antolatzeko bilera dago ostegunean. Ainarak parte hartzen du beti.*

## 小范文

> *Lander auzo-elkarteko kidea da. Astean bi aldiz **bilerak** antolatzen ditu. Auzoko **jaiak** prestatzen dituzte, baita **boluntariotza-egitasmoak** ere: zaborrak biltzeko ekintzak, **birziklatzeari** buruzko hitzaldiak, eta abar. Berarentzat **garrantzitsua da auzoaren bizitza zaintzea**.*

> **文化小贴士：** *auzo-elkarteak*（邻里协会）是 Euskal Herria 许多城镇社会生活的基本组成部分。它们组织节日活动、巴斯克语工作坊、登山郊游和环保运动。参与其中是在实际生活中练习这门语言的最佳方式之一。
