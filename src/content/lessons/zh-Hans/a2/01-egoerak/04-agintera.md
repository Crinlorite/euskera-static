**祈使句** (*agintera*) 用于发出指令、提出请求和给予建议。在巴斯克语中，它**比看起来要简单得多**：最常用的形式几乎总是与动词的**分词**形式相同。

## 基本规则：使用分词

对于许多日常命令，动词以其分词形式出现，无需助动词：

| 西班牙语 | 巴斯克语 |
|---|---|
| 拿 | *Hartu* |
| 坐下 | *Eseri* |
| 起来 | *Jaiki* |
| 写 | *Idatzi* |
| 读 | *Irakurri* |
| 听 | *Entzun* |
| 重复 | *Errepikatu* |
| 等一下 | *Itxoin* |
| 关门 | *Itxi atea* |
| 开窗 | *Ireki leihoa* |

> 这是在课堂上、街头和书面说明中**最常用的形式**。它既适用于 *zu*，也适用于 *zuek*。

## 综合形式 (trinkoak): *zatoz*, *zoaz*

一些非常常见的动词有特定的祈使句综合形式。以下是需要记住的：

| 动词 | 你 (zu) | 你们 (zuek) |
|---|---|---|
| *etorri* (来) | **Zatoz** | **Zatozte** |
| *joan* (去) | **Zoaz** | **Zoazte** |
| *ekarri* (带来) | **Ekarri** / **Ekar ezazu** | **Ekar ezazue** |
| *eraman* (带走) | **Eraman** / **Eramazu** | **Eramazue** |
| *egon* (在/待) | **Egon** / **Lasai** (冷静！) | **Egon** |

> *— **Zatoz** hona, mesedez.*
> *— **Zoazte** lehenbailehen.*

## NOR-NORI-NORK 祈使句: *emadazu*, *esadazu*

当你发出带有双重宾语的命令时（“给我这个”、“告诉他那个”），巴斯克语有一些非常有用的紧凑形式：

| 西班牙语 | 巴斯克语 |
|---|---|
| 给我 | *Emadazu* / *Eman iezadazu* |
| 告诉我 | *Esadazu* / *Esan iezadazu* |
| 给他/她 | *Emaiozu* / *Eman iezaiozu* |
| 告诉他/她 | *Esaiozu* / *Esan iezaiozu* |
| 给我们 | *Emaguzu* |
| （你们）给我 | *Emadazue* |

这些形式学起来比较长；在A2级别，只需掌握 **emadazu / esadazu / emaiozu / esaiozu** 并理解它们来自 *eman* / *esan* 这两个动词就足够了。

## “请”和缓和语气的词

在巴斯克语中，如果你加上一些礼貌用语，祈使句听起来**并不会很生硬**：

- *Mesedez* — 请
- *Ahal baduzu* — 如果可以的话
- *Faborez* (口语变体)
- *Eskerrik asko aldez aurretik* — 提前感谢

> *Emadazu ogia, **mesedez**.*
> *Itxoin pixka bat, **ahal baduzu**.*

## 说明（食谱、公告、课堂）

祈使句是以下场景中的标准形式：

- **食谱：** *Moztu tipula. Bota olioa zartaginera. Frijitu bost minutuz.*
- **标牌：** *Itxi atea. Ez ukitu. Erabili maskara.*
- **课堂：** *Ireki liburua. Idatzi koadernoan. Errepikatu nirekin.*
- **医生：** *Hartu pilula bat. Edan ur asko. Hartu atseden.*

## 小短文

> *Sukaldari eskolan, irakasleak esaten du:*
>
> *— **Hartu** patata bat. **Garbitu** ondo. **Kendu** azala. **Moztu** zatitan eta **bota** ur irakinera. **Itxoin** hogei minutu. Eta **probatu** ondoren.*

> **文化小贴士：**在巴斯克语中，祈使句的**命令式**语气是通过语调和上下文来缓和的，而不是经常使用委婉说法（“你是否可以……”）。在命令后加上 *mesedez* 或一个微笑通常就足够了。如果你想更礼貌一些，可以说 *eman ahal didazu...?* (你能给我……吗？)
