A2为你打开了谈论身体感受的大门：什么时候生病，哪里疼痛，以及医生开了什么药。你在A1学过的基本结构 (*mina daukat*) 将会得到扩展，增加更多具体词汇、医护专业人员和就诊对话。

## 如何说“我生病了”

在巴斯克语中，有两种常见说法：

- **Gaixorik nago.** — 我生病了。（表示当前状态，使用 *egon*）
- **Ez nago ondo.** — 我感觉不舒服。
- **Min hartu dut.** — 我受伤了。
- **Gaixotu egin naiz.** — 我病倒了（不及物动词，使用 *naiz*）。

> **语法提示：** *gaixorik* 带有后缀 -**rik**（表示状态），与 *pozik*（高兴）、*nekatuta*、*triste* 类似。记住：状态 = *egon*。

## 症状 — 万能公式 X **daukat**

和A1中学到的一样，症状用 *eduki*（有）来表达：

| 西班牙语 | 巴斯克语 |
|---|---|
| 我发烧了 | *Sukarra **daukat*** |
| 我咳嗽 | *Eztula **daukat*** |
| 我感冒了 | *Katarroa **daukat*** |
| 我得了流感 | *Gripea **daukat*** |
| 我头晕 | *Zorabiatuta nago* |
| 我想吐 | *Goragalea **daukat*** |

## 疼痛：*mina*

在巴斯克语中，**疼痛** (*mina*) 是一个名词，它与表示身体部位的 **NONGO (-ko)** 形式连用，作为“哪种疼痛”的补充说明：

> **身体部位 + -ko + mina + daukat**

| 西班牙语 | 巴斯克语 |
|---|---|
| 我头疼 | *Buruko mina daukat* |
| 我喉咙疼 | *Eztarriko mina daukat* |
| 我肚子疼 | *Sabeleko mina daukat* |
| 我牙疼 | *Hortzeko mina daukat* |
| 我背疼 | *Bizkarreko mina daukat* |
| 我脚疼 | *Oinetako mina daukat* |

另一种非常常见的说法，尤其是在描述“当下”的疼痛时：

- *Buruak min ematen dit.* — 头让我疼。

## 在诊所

| 西班牙语 | 巴斯克语 |
|---|---|
| 你怎么了？/ 你有什么症状？ | *Zer duzu?* / *Zer gertatzen zaizu?* |
| 从什么时候开始的？ | *Noiztik?* |
| 疼吗？ | *Min ematen dizu?* |
| 每八小时吃一片药 | *Hartu pilula bat zortzi orduro* |
| 休息 | *Hartu atseden* |
| 一周后复诊 | *Itzuli astebete barru* |

## 迷你对话

> *— Egun on. **Zer duzu**?*
>
> *— **Sukarra daukat** atzotik, eta **buruko mina** ere bai.*
>
> *— Eztulik?*
>
> *— Bai, baina ez asko.*
>
> *— Ondo. **Hartu** pilula hauek **zortzi orduro**, eta **edan** ur asko. Hobeto ez bazaude, bihar etorri berriro.*

> **文化小贴士：** 在巴斯克地区，*"botikaria"*（药剂师）在许多小村镇里，仍然是处理轻微问题（如感冒、蚊虫叮咬、头晕）的第一道咨询关口。药店在家庭医生之前起到了一个过滤作用。
