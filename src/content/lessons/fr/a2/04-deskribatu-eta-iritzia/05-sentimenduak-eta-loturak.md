Cette leçon intègre deux blocs A2 très productifs :

1. **Sentiments** et états d'âme (tu connais les bases du niveau A1 ; ici, tu approfondis).
2. **Connecteurs discursifs** pour argumenter et nuancer : *gainera, hala ere, beraz, alde batetik...*

Avec cela, tu termines l'unité et obtiens des outils pour formuler des opinions plus élaborées.

## Sentiments : la formule avec *egon* + état

La plupart des sentiments passagers se construisent avec *egon* + adjectif ou adverbe d'état :

| Français | Basque |
|---|---|
| Content | *Pozik nago* |
| Triste | *Triste nago* |
| Fâché | *Haserre nago* |
| Nerveux | *Urduri nago* |
| Tranquille | *Lasai nago* |
| Ennuyé | *Aspertuta nago* |
| Fatigué | *Nekatuta nago* |
| Honteux | *Lotsatuta nago* |
| Amoureux | *Maitemindurik nago* |

> C'est le même modèle que pour le A1 (*pozik, triste, lasai*) élargi avec *aspertuta, nekatuta, lotsatuta, maitemindurik*.

## Sentiments avec *izan* : *beldur naiz*

Certains sentiments profonds se construisent avec *izan* :

| Français | Basque |
|---|---|
| J'ai peur | *Beldur naiz* |
| Tu as raison | *Arrazoia duzu* |
| Je suis curieux | *Jakin-mina dut* |
| J'ai envie | *Gogoa dut* / *Gogoz nago* |
| Je n'ai pas envie | *Gogorik ez dut* |

> *Beldur naiz autoz joateko.* — J'ai peur d'y aller en voiture.

## Sentiments avec *NOR-NORI* : *lotsa ematen dit*

Une formule très basque : le sentiment "te donne" :

| Français | Basque |
|---|---|
| J'ai honte | *Lotsa ematen dit* |
| Ça me fait de la peine | *Pena ematen dit* |
| Ça me met en rage | *Amorrua ematen dit* |
| Ça me fait peur | *Beldurra ematen dit* |

> *Hori esateak **lotsa ematen dit**.* — J'ai honte de le dire.
>
> *Albiste horrek **pena handia ematen dit**.* — Cette nouvelle me fait beaucoup de peine.

## *Jartzen naiz / jarri naiz*

Pour exprimer le **changement d'état** ("devenir nerveux, content, triste") :

| Français | Basque |
|---|---|
| Je deviens nerveux | *Urduri **jartzen naiz*** |
| Il/Elle est devenu(e) triste | *Triste **jarri zen*** |
| Nous sommes devenus contents | *Pozik **jarri ginen*** |
| Il/Elle se fâche pour un rien | *Edozergatik haserretzen da* |

## Verbes psychologiques fréquents

| Verbe | Signification |
|---|---|
| *gustatu* | aimer / plaire |
| *maite izan* | aimer |
| *gorrotatu* / *higuindu* | détester / haïr |
| *beldurtu* | prendre peur / s'effrayer |
| *aspertu* | s'ennuyer |
| *haserretu* | se fâcher |
| *lasaitu* | se calmer |
| *poztu* | se réjouir |
| *triste jarri* / *atsekabetu* | devenir triste / s'attrister |
| *kezkatu* | s'inquiéter |

> *Asko **maite ditut** nire gurasoak.* — J'aime beaucoup mes parents.
>
> *Ez **kezkatu**, dena ondo aterako da.* — Ne t'inquiète pas, tout ira bien.

## Connecteurs discursifs

Pour lier des opinions et des arguments :

### Addition

| Français | Basque |
|---|---|
| De plus | *gainera* |
| Et aussi | *eta baita ere* / *...ere* |
| Surtout | *batez ere* |

> *Gainera, prezioa ere ona da.* — De plus, le prix est bon aussi.

### Cause / conséquence

| Français | Basque |
|---|---|
| Donc | *beraz* |
| C'est pourquoi | *horregatik* |
| Pour cette raison | *arrazoi horregatik* |

> *Berandu da; **beraz**, joango naiz.* — Il est tard ; donc, je m'en vais.

### Contraste / opposition

| Français | Basque |
|---|---|
| Cependant | *hala ere* |
| Mais | *baina* |
| D'un autre côté | *bestetik* |
| En revanche | *aldiz* / *berriz* |

> *Berandu da; **hala ere**, etorriko naiz.* — Il est tard ; cependant, je viendrai.

### Organiser le discours

| Français | Basque |
|---|---|
| D'un côté... de l'autre... | *Alde batetik... bestetik...* |
| D'abord... ensuite... | *Lehenengo... gero...* |
| Enfin | *Azkenik* |
| En résumé | *Laburbilduz* |

## Structures coordonnées A2

Ce sont des constructions qui apparaissent dans n'importe quel examen A2 :

| Français | Basque |
|---|---|
| Ni... ni... | *Ez... ez...* |
| Aussi bien... que... | *Bai... bai...* / *Hala... nola...* |
| Non seulement... mais aussi... | *Ez bakarrik..., baita ere...* |
| ...aussi (inclus) | *...ere bai* |

> *Ez Anboto, ez Olatz ez dira etorri.* — Ni Anboto ni Olatz ne sont venus.
>
> *Bai goizean, bai arratsaldean, lan egin behar dut.* — Aussi bien le matin que l'après-midi, je dois travailler.

## Mini-texte d'opinion

> *Niretzat **garrantzitsua** da gauean ondo lo egitea. **Alde batetik**, lasaitu egiten gara. **Bestetik**, hurrengo egunean indartsuago **gaude**. **Gainera**, osasunarentzat ezinbestekoa da: zazpi-zortzi ordu lo egiten ez **baditugu**, gaixotzeko probabilitate **handiagoa** dugu. **Hala ere**, ez da beti erraza izaten: askotan ezin dut lo hartu **kezkatuta nagoelako**. **Beraz**, lo egiten lagunduko didan errutina bat behar dut.*

## Astuce pour le A2 : le "squelette d'opinion"

Quand on te demande de donner ton opinion au niveau A2, suis ce modèle :

> **1. Nire ustez** + thème + **-(e)la**.
>
> **2. Alde batetik**, + raison 1 + **-lako**.
>
> **3. Bestetik**, + raison 2.
>
> **4. Hala ere**, + nuance.
>
> **5. Beraz**, + conclusion.

Avec ça, tu construis un paragraphe complet de niveau A2.

> **Note culturelle :** de nombreux textes officiels de niveau A2 (lettre à l'éditeur, forum, rédaction d'examen) demandent cette structure argumentative. Entraîne-toi avec des sujets quotidiens : le sport, la nourriture, les réseaux sociaux, le travail, les fêtes de village.
