Le **conditionnel** (*baldintza*) en basque a plusieurs formes. Au niveau A2, nous nous concentrerons sur les **deux plus utiles** :

1. **Condition réelle (futur probable) :** *s'il pleut demain, je n'irai pas*.
2. **Condition irréelle (hypothèse) :** *si j'avais de l'argent, j'achèterais une maison*.

Cette leçon est une **introduction** : il te suffit de reconnaître les formes et de produire des phrases simples. L'unité B1 approfondit ce sujet.

## Type 1 : condition réelle — *ba-* + présent

Pour les hypothèses sur le **futur probable** ou le présent, le basque utilise le préfixe **ba-** sur l'auxiliaire au présent.

> **ba- + présent de l'auxiliaire, ... + futur**

| Français | Euskera |
|---|---|
| S'il pleut, je n'irai pas | *Euria egiten **badu**, ez naiz joango* |
| Si tu as le temps, viens | *Astia **baduzu**, etorri* |
| Si tu veux, appelle-moi | *Nahi **baduzu**, deitu niri* |
| Si je suis riche un jour… | *Aberatsa **banaiz** noizbait...* |

### Formes avec *ba-* (présent)

| Verbe | Sans ba- | Avec ba- |
|---|---|---|
| *naiz* | je suis | **banaiz** (si je suis) |
| *zara* | tu es | **bazara** (si tu es) |
| *da* | il/elle est | **bada** (s'il/elle est) |
| *gara* | nous sommes | **bagara** (si nous sommes) |
| *dut* | je l'ai | **badut** (si je l'ai) |
| *du* | il/elle l'a | **badu** (s'il/elle l'a) |
| *dute* | ils/elles l'ont | **badute** (s'ils/elles l'ont) |

> **Attention !** *Ba-* a aussi un usage affirmatif : *bai, badator* = "oui, il/elle vient". C'est le contexte qui lève l'ambiguïté : si la phrase a une deuxième partie ("...alors..."), c'est un conditionnel.

## Type 2 : condition irréelle — *banintz / banu*

Pour les hypothèses irréelles ou très peu probables ("si j'étais...", "si j'avais..."), le basque utilise des formes dédiées :

### Formes de *izan* au conditionnel irréel

| Pronom | Forme | Français |
|---|---|---|
| ni | **banintz** | si j'étais |
| zu | **bazina** | si tu étais |
| hura | **balitz** | s'il/elle était |
| gu | **bagina** | si nous étions |
| zuek | **bazinete** | si vous étiez |
| haiek | **balira** | s'ils/elles étaient |

### Formes de *ukan* au conditionnel irréel

| Pronom | Forme | Français |
|---|---|---|
| nik | **banu** | si je l'avais |
| zuk | **bazenu** | si tu l'avais |
| hark | **balu** | s'il/elle l'avait |
| guk | **bagenu** | si nous l'avions |
| haiek | **balute** | s'ils/elles l'avaient |

> **Mémorise d'abord ces six formes** : *banintz, balitz, banu, balu, bagenu, balute*. Ce sont celles qui apparaissent dans n'importe quelle phrase au conditionnel irréel.

## La conséquence : *-ko/-go + nuke / nintzateke*

Le "j'achèter**ais** / j'irais / je serais" se forme avec **-ko/-go** (la même marque que le futur) + un auxiliaire spécial :

### NOR-NORK conditionnel ("je le + rais")

| Pronom | Forme | Français |
|---|---|---|
| nik | **nuke** | je le —rais |
| zuk | **zenuke** | tu le —rais |
| hark | **luke** | il/elle le —rait |
| guk | **genuke** | nous le —rions |
| haiek | **lukete** | ils/elles le —raient |

### NOR conditionnel ("je —rais", intransitif)

| Pronom | Forme | Français |
|---|---|---|
| ni | **nintzateke** | je —rais |
| zu | **zinateke** | tu —rais |
| hura | **litzateke** | il/elle —rait / serait |
| gu | **ginateke** | nous —rions |
| haiek | **lirateke** | ils/elles —raient |

## Phrase modèle

> **baldintza + ondorioa**

> *Diru asko **banu**, etxe bat **erosiko nuke**.* — Si j'avais beaucoup d'argent, j'achèterais une maison.
>
> *Lurralde berri batean **bizi banintz**, beste hizkuntza bat **ikasiko nuke**.* — Si je vivais dans un nouveau pays, j'apprendrais une autre langue.
>
> *Anboto hemen **balitz**, lasaiago **egongo ginateke**.* — Si Anboto était ici, nous serions plus tranquilles.
>
> *Aberatsak **balira**, mundu osoa **bisitatuko lukete**.* — S'ils étaient riches, ils visiteraient le monde entier.

## Comparaison des deux types

| Type | "si" | "alors" |
|---|---|---|
| Réel (futur probable) | *ba-* + présent : *baduzu, bada* | futur : *-ko/-go + naiz/dut* (joango naiz, erosiko dut) |
| Irréel (hypothèse) | *ba-* + conditionnel : *banu, balitz* | conditionnel : *-ko/-go + nuke/nintzateke* |

## Exemples en contraste

- **Réel :** *Astia **baduzu**, lagunduko **dizut**.* — Si tu as le temps, je t'aiderai.
- **Irréel :** *Astia **bazenu**, lagunduko **zenidake**.* — Si tu avais le temps, tu m'aiderais.

## Expressions très utiles

| Français | Euskera |
|---|---|
| Voudrais-tu… ? | *Nahi **zenuke**…?* |
| J'aimerais… | *Gustatuko **litzaidake**…* |
| Ce serait joli… | *Polita **litzateke**…* |
| J'irais avec plaisir | *Gustura **joango nintzateke*** |
| J'y réfléchirais | *Pentsatuko **nuke*** |

## Mini-dialogue

> *— Olatz, **nahi zenuke** zinemara joan?*
>
> *— Bai, **gustatuko litzaidake**, baina astia **banu**... Lan asko daukat astean.*
>
> *— Lasai. Bihar **etortzen bazara**, sarrera bat **erosiko dizut**.*

> **Note pédagogique :** la *baldintza* est l'un des points où le niveau A2 t'ouvre la porte du B1. Au niveau A2 officiel, il suffit de la **reconnaître** et de produire des phrases simples du type *banintz... -ko nuke*. La conjugaison complète du conditionnel est travaillée en B1.
