Jusqu'à aujourd'hui, tu posais des questions directes : *Etorriko da?* Maintenant, tu vas apprendre à poser des questions **indirectes** : *je ne sais pas **s'il viendra***, *demande-lui **s'il a le temps***. Ce sont les *zehar-galderak* (questions indirectes), et leur astuce tient en une seule lettre : **-n**.

## La règle : l'auxiliaire prend -n

| Directe | Indirecte |
|---|---|
| *Etorriko **da**?* | *Ez dakit etorriko **den*** |
| *Nor **da**?* | *Ez dakit nor **den*** |
| *Non **dago**?* | *Ez dakit non **dagoen*** |
| *Zer nahi **du**?* | *Ez dakit zer nahi **duen*** |
| *Denborarik **dauka**?* | *Galdetu ea denborarik **daukan*** |

Comment s'ajoute le **-n** : *da → den* · *dago → dagoen* · *du → duen* · *dauka → daukan* · *gara → garen* · *dute → duten*. (S'il finit par une voyelle, -n ; sinon, -en. Ton oreille s'y fera toute seule en deux jours.)

## "Ea" — le mot passe-partout

Pour les questions oui/non, le basque ajoute ***ea*** (= "pour voir si / si") :

> *Galdetu diot **ea gurekin bazkalduko duen**.* — Je lui ai demandé s'il mangera avec nous.
>
> *Ikusiko dugu **ea eguraldi ona egiten duen**.* — On verra s'il fait beau.
>
> ***Ea garaiz iristen garen**!* — Pourvu qu'on arrive à l'heure !

Ce dernier *ea…!* utilisé seul est du pur basque parlé : un souhait + du suspense en un seul mot.

## Les verbes qui les requièrent

| Français | Basque |
|---|---|
| Je ne sais pas si… | *Ez dakit … -(e)n* |
| Sais-tu si… ? | *Badakizu … -(e)n?* |
| Demande-lui si… | *Galdetu (iezaiozu) ea … -(e)n* |
| Je ne me souviens pas si… | *Ez naiz gogoratzen … -(e)n* |
| Je ne suis pas sûr(e) si… | *Ez nago ziur … -(e)n* |

## En action

> *— **Badakizu zer ordutan hasten den** kontzertua?*
>
> *— Ez, baina Aneri **galdetuko diot ea dakien**.*
>
> *— Eta **ea sarrerarik geratzen den** ere galdetu, mesedez!*
>
> *— Lasai. **Ea zorte ona dugun**!*

## Le contraste avec -la (le faux ami)

Ne confonds pas la question indirecte avec l'affirmation indirecte (unité 04) :

> *Esan dit etorriko **dela**.* — Il/Elle m'a dit **qu'**il/elle viendra. (affirmation → **-la**)
>
> *Galdetu dit **ea** etorriko **den**.* — Il/Elle m'a demandé **si** il/elle viendra. (question → **-n**)

**Que = -la · Si = (ea) -n.** Avec cette antisèche, la leçon est dans la poche.
