Cette leçon étend le passé aux verbes **NOR-NORK** (transitifs : je le, tu le, il le). C'est la base pour raconter toutes les actions qui ont un objet : *j'ai mangé, j'ai vu, j'ai fait, j'ai dit, j'ai acheté, j'ai appelé...*

## La formule

> **partizipioa + nuen / zenuen / zuen / genuen / zenuten / zuten**

| Pronom | Passé de *dut* | Français |
|---|---|---|
| nik | **nuen** | je le |
| zuk | **zenuen** | tu le |
| hark | **zuen** | il/elle le |
| guk | **genuen** | nous le |
| zuek | **zenuten** | vous le |
| haiek | **zuten** | ils/elles le |

> Les formes se terminent **toujours par -n**, et la première lettre est la marque de la personne : **n-** (je), **z-** (tu/vous/ils), **g-** (nous).

## Objet pluriel — *nituen*

Si l'objet est **pluriel** (les livres, les billets, les bières), l'auxiliaire passe à la série en **-itu-** :

| Pronom | Auxiliaire pluriel | Français |
|---|---|---|
| nik | **nituen** | je les |
| zuk | **zenituen** | tu les |
| hark | **zituen** | il/elle les |
| guk | **genituen** | nous les |
| zuek | **zenituzten** | vous les |
| haiek | **zituzten** | ils/elles les |

## Exemples

| Français | Basque |
|---|---|
| J'ai mangé des pintxos | *Pintxoak jan **nituen*** |
| J'ai vu un film | *Film bat ikusi **nuen*** |
| Ils/Elles ont préparé le dîner | *Afaria egin **zuten*** |
| Qu'a-t-il/elle dit ? | *Zer esan **zuen**?* |
| Nous avons acheté du pain | *Ogia erosi **genuen*** |
| Il/Elle a vendu les deux motos | *Bi motoak saldu **zituen*** |

## Verbes synthétiques : *eduki* et *jakin*

Deux verbes très fréquents conservent une forme **synthétique** au passé, tout comme au présent (*daukat, dakit*) :

### *Eduki* (avoir, possession)

| Pronom | Forme | Français |
|---|---|---|
| ni | **neukan** | j'avais |
| zu | **zeneukan** | tu avais |
| hura | **zeukan** | il/elle avait |
| gu | **geneukan** | nous avions |
| zuek | **zeneukaten** | vous aviez |
| haiek | **zeukaten** | ils/elles avaient |

### *Jakin* (savoir)

| Pronom | Forme | Français |
|---|---|---|
| ni | **nekien** | je savais |
| zu | **zenekien** | tu savais |
| hura | **zekien** | il/elle savait |
| gu | **genekien** | nous savions |
| zuek | **zenekiten** | vous saviez |
| haiek | **zekiten** | ils/elles savaient |

> *Anbotok bizikleta gorri bat **zeukan** umetan.* — Anboto avait un vélo rouge quand il était enfant.
>
> *Ez **zekien** non bizi ginen.* — Il/Elle ne savait pas où nous vivions.

## Deux détails clés du NOR-NORK au passé

**1. La marque -k sur le sujet.** Comme au présent, le sujet qui agit porte le cas ergatif :

> *Garazi**k** afaria egin **zuen**.* — Garazi a préparé le dîner.
>
> *Lander**rek** sarrerak erosi **zituen**.* — Lander a acheté les billets.

**2. L'accord avec l'objet.** Si l'objet est singulier → *nuen / zuen* ; s'il est pluriel → *nituen / zituen*. C'est la même règle qu'au présent.

## Négation

> *Atzo ez nuen filmik ikusi.* — Hier, je n'ai vu aucun film.
>
> *Ainarak ez zuen ezer esan.* — Ainara n'a rien dit.
>
> *Ez genituen sarrerak erosi.* — Nous n'avons pas acheté les billets.

> Quand l'objet est nié, il apparaît généralement au partitif : *filmik, ezer, txikirik*. C'est le même *-rik* que tu as vu en A1.

## Mini-récit

> *Aurreko larunbatean Olatz eta Lander itsasora **joan ziren** (NOR). Hondartzan egun osoa **eman zuten**: igeri **egin zuten**, eguzkitan etzanda **egon ziren** eta liburu bat **irakurri zuten**. Iluntzean afari bat **prestatu zuten** eta lagunekin **afaldu zuten**.*

Remarque comment les formes NOR (*joan ziren, egon ziren*) et NOR-NORK (*eman zuten, irakurri zuten, prestatu zuten*) se mélangent. Les deux leçons se combinent pour raconter une histoire.

> **Note :** dans la prochaine leçon, tu verras les **verbes synthétiques au passé** (*nindoan, nentorren, nenbilen*) qui complètent le passé NOR.
