Du papier au pixel : la leçon de **technologie quotidienne**. Du vocabulaire que tu utilises cent fois par jour — maintenant en basque, qui, de plus, se targue de mots transparents et bien construits (*pasahitza* = mot de passe ; *sakelakoa* = "celui de poche").

## Les appareils

| Français | Euskera |
|---|---|
| L'ordinateur | *ordenagailua* |
| L'ordinateur portable | *eramangarria* |
| Le portable / Le mobile | *mugikorra / sakelakoa* |
| La tablette | *tableta* |
| L'écran | *pantaila* |
| Le clavier | *teklatua* |
| La souris | *sagua* (oui, l'animal !) |
| Les écouteurs | *entzungailuak* |

## Le web et les comptes

| Français | Euskera |
|---|---|
| Le réseau / internet | *sarea / internet* |
| Le wifi | *wifia* |
| Le courrier électronique | *posta elektronikoa* |
| L'utilisateur | *erabiltzailea* |
| Le mot de passe | *pasahitza* |
| L'application | *aplikazioa* |
| La page web | *webgunea* |

> ***Zein da wifiaren pasahitza**?* — Quel est le mot de passe du wifi ?
>
> ***Pasahitza ahaztu dut** eta orain berri bat sortu behar dut. Berriro.* — J'ai oublié le mot de passe et maintenant je dois en créer un nouveau. Encore une fois.
>
> *Kontua sortzeko, **posta elektronikoa eta pasahitza** behar dituzu.* — Pour créer le compte, tu as besoin d'une adresse e-mail et d'un mot de passe.

## Les verbes numériques

| Français | Euskera |
|---|---|
| Allumer / éteindre | *piztu / itzali* |
| Télécharger | *deskargatu / jaitsi* |
| Installer | *instalatu* |
| Enregistrer | *gorde* |
| Effacer | *ezabatu* |
| Envoyer / partager | *bidali / partekatu* |
| Chercher (sur le web) | *bilatu* |
| Fonctionner / Marcher | *ibili / funtzionatu* |

> *Ordenagailua **gaizki dabil**; **itzali eta piztu** — betiko konponbidea.* — L'ordinateur ne marche pas bien ; éteins-le et rallume-le — la solution de toujours.
>
> *Argazkiak **gorde dituzu**? Ez **ezabatu** ezer!* — Tu as enregistré les photos ? N'efface rien !
>
> *Aplikazioa **deskargatu**, kontua **sortu** eta listo.* — Tu télécharges l'appli, tu crées le compte et c'est tout.

## Dialogue : support technique familial

> *— Aizu, laguntza behar dut. Aplikazio hau **ez dabil**.*
>
> *— Ea… **Wifira konektatuta zaude**?*
>
> *— Baietz uste dut… A, ez. **Pasahitza eskatzen dit**.*
>
> *— Router-aren azpian dago idatzita. Bai, **denok egiten dugu** hori.* 😄
>
> *— Eginda! Orain bai. **Eskerrik asko**, teknikari!*
>
> *— **Hurrengoan kobratu egingo dizut**.* 😄

> **Remarque :** le basque numérique est très vivant : les logiciels libres et Wikipédia en basque sont très développés, et ton portable tout entier peut être en basque (*Ezarpenak → Hizkuntza*). Le configurer ainsi est, en fait, une excellente astuce d'étude : une immersion quotidienne gratuite.
