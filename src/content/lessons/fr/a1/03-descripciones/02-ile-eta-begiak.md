Pour décrire les cheveux et les yeux en basque, on n'utilise pas **izan** (« être ») comme en français (« je suis brun »), mais **ukan** (« avoir ») : *j'ai les cheveux noirs*, *j'ai les yeux bleus*.

## Cheveux : ile

Le mot pour « cheveux » est **ile** (avec l'article : *ilea*). Les adjectifs se placent après, et seul le dernier porte la marque `-a` :

| Basque | Français |
|---|---|
| *ile beltza* | cheveux noirs |
| *ile horia* | cheveux blonds |
| *ile zuria* | cheveux blancs / grisonnants |
| *ile gorria* | cheveux roux |
| *ile urdina* | cheveux gris |
| *ile motza* | cheveux courts |
| *ile luzea* | cheveux longs |
| *ile lisoa* | cheveux lisses |
| *ile kizkurra* | cheveux bouclés |

> En basque, le mot pour « cheveux » est au **singulier**, contrairement au français. C'est pourquoi on utilise *dut* / *du* (et non *ditut* / *ditu*).

- *Ile beltza eta luzea **dut**.* — J'ai les cheveux noirs et longs.
- *Maialenek ile kizkurra **du**.* — Maialen a les cheveux bouclés.

## Yeux : begiak

À la différence de *ile* (cheveux), le mot pour « yeux » est au **pluriel** (*begiak*). Les adjectifs sont donc aussi au pluriel (`-ak`) et on utilise **ditut / ditu** :

| Basque | Français |
|---|---|
| *begi urdinak* | yeux bleus |
| *begi marroiak* | yeux marron |
| *begi berdeak* | yeux verts |
| *begi beltzak* | yeux noirs |
| *begi argiak* | yeux clairs |
| *begi ilunak* | yeux foncés |

- *Begi urdinak **ditut**.* — J'ai les yeux bleus.
- *Mikelek begi marroiak **ditu**.* — Mikel a les yeux marron.

## Autres traits : le suffixe -dun

Pour dire « qui porte X » ou « avec X », le basque a un suffixe très productif : **-duna** (singulier) / **-dunak** (pluriel). On l'ajoute au nom et la personne devient « celui avec les lunettes », « celui avec la barbe »...

| Basque | Français |
|---|---|
| *betaurrekoduna* | avec des lunettes / celui qui a des lunettes |
| *bizarduna* | barbu / avec une barbe |
| *biboteduna* | moustachu / avec une moustache |
| *burusoila* | chauve (littéralement « tête pelée ») |

Ceux-ci s'utilisent avec **izan**, car ils décrivent une qualité, comme un adjectif :

- *Hura biboteduna da.* — Il est moustachu.
- *Nire aitona burusoila da.* — Mon grand-père est chauve.

## En combinant le tout

Un portrait type mélange plusieurs structures :

> *Maialen txikia eta argala da. Ile gorria eta kizkurra du. Begi berdeak ditu. Betaurrekoduna da.*
>
> Maialen est petite et mince. Elle a les cheveux roux et bouclés. Elle a les yeux verts. Elle porte des lunettes.

Remarquez comment cela se répartit : **izan** pour les qualités générales (*txikia da*), **ukan** pour les cheveux/yeux (*ile … du*, *begi … ditu*), et *-dun*-a de nouveau avec **izan** pour les accessoires.
