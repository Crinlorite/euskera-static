Cette leçon intègre tout le contenu du thème 9 : les pièces, les meubles, les tâches ménagères et les personnes avec qui tu vis. L'objectif est que tu puisses **décrire ta maison** en phrases simples, comme si on te posait la question en classe ou dans une conversation informelle.

## Les questions de base

| Question | Français |
|---|---|
| *Non dago zure etxea?* | Où est ta maison ? |
| *Nolakoa da?* | Comment est-elle ? |
| *Zenbat gela ditu?* | Combien de pièces a-t-elle ? |
| *Norekin bizi zara?* | Avec qui vis-tu ? |
| *Zenbatgarren solairuan bizi zara?* | À quel étage vis-tu ? |
| *Etxeak badu igogailua / balkoia / terraza?* | La maison a-t-elle un ascenseur / un balcon / une terrasse ? |

## Adjectifs utiles pour décrire la maison

| Euskera | Français |
|---|---|
| *handia* | grande |
| *txikia* | petite |
| *argitsua* | lumineuse |
| *iluna* | sombre |
| *berria* | neuve |
| *zaharra* | vieille |
| *lasaia* | calme |
| *zaratatsua* | bruyante |
| *erosoa* | confortable |
| *garestia* | chère |
| *merkea* | bon marché |

> Souviens-toi du modèle **NOLAKOA da?** déjà vu dans d'autres unités : la réponse se construit avec l'adjectif + `-a` final + le verbe *izan*. Ex. : *Nire etxea **handia da**.* — Ma maison est grande.

## Un paragraphe modèle

Voici un texte simple qui décrit une maison. Lis-le à voix haute et fais attention aux structures.

> *Ni Iruñean bizi naiz, auzo lasai batean. Nire etxea ez da oso handia: hiru gela ditu — bi logela eta egongela bat — sukaldea eta komuna. Egongela argitsua da, eta balkoi bat dauka. Hirugarren solairuan dago, eta etxeak igogailua du.*
>
> *Bikotekidearekin bizi naiz. Berak bazkaria prestatzen du, eta nik ontziak garbitzen ditut. Asteburuetan biok elkarrekin egiten dugu erosketa.*

## À ton tour : décris ta maison

Construis ton propre paragraphe en répondant dans cet ordre :

1. **Non bizi zara?** (Où vis-tu ?) → *X-(e)an bizi naiz.*
2. **Nolakoa da etxea?** (Comment est la maison ?) → *Nire etxea handia / argitsua / lasaia da.*
3. **Zenbat gela ditu?** (Combien de pièces a-t-elle ?) → *Bi / Hiru / Lau gela ditu.*
4. **Zer dago etxean?** (Qu'y a-t-il dans la maison ?) → *Sukaldea, egongela, bi logela eta komun bat ditu.*
5. **Norekin bizi zara?** → *Bakarrik / Gurasoekin / Lagunekin bizi naiz.*
6. **Etxeko lanak nork egiten ditu?** (Qui fait les tâches ménagères ?) → *Nik egunero garbitzen dut* / *Pisukideen artean banatzen ditugu.*

|---|---|

| *erdigunea* | centre-ville |

> **Conseil :** quand tu parles de ta maison en classe, n'essaie pas de traduire chaque détail. Tiens-t'en à des phrases courtes et bien construites. *"Bi logela ditut, sukalde txiki bat eta egongela handia"* est une meilleure description qu'une longue phrase pleine de fautes.
