Commençons par la base de tout logement : les **pièces**. Le mot général pour « salle / pièce » est **gela**, et la plupart des noms de pièces se construisent en combinant une racine avec `-gela`.

## Vocabulaire de base

| Basque | Français |
|---|---|
| *etxea* | la maison |
| *pisua* | l'appartement (logement dans un immeuble) |
| *gela* | pièce / salle |
| *sukaldea* | la cuisine |
| *logela* | la chambre |
| *komuna* | la salle de bain |
| *egongela* | le salon |
| *sarrera* | l'entrée |
| *korridorea* / *pasabidea* | le couloir |
| *balkoia* | le balcon |
| *terraza* | la terrasse |

## Comment se forment certains noms

Le basque est très transparent avec ces mots. Si tu regardes comment ils sont composés, tu les retiendras mieux :

- **logela** → *lo* (sommeil) + *gela* (salle) = « salle du sommeil » → chambre
- **egongela** → *egon* (être/rester) + *gela* (salle) = « salle de séjour » → salon
- **sukaldea** → *su* (feu) + *aldea* (zone) = « zone du feu » → cuisine

> **Komuna** et **bainugela** sont synonymes : *komuna* est le mot courant, tandis que *bainugela* (littéralement « salle de bain ») est un peu plus formel.

## Immeuble : étage et ascenseur

| Basque | Français |
|---|---|
| *solairua* | étage (1er, 2e…) |
| *igogailua* | l'ascenseur |
| *eskailera* | l'escalier |
| *ataria* | le hall d'entrée |

Pour dire à quel étage tu habites :

- *Hirugarren solairuan bizi naiz.* — J'habite au troisième étage.
- *Etxeak igogailua du.* — La maison a un ascenseur.

## Questions utiles

- **Zenbat gela ditu zure etxeak?** — Combien de pièces a ta maison ?
- **Zenbat logela ditu?** — Combien de chambres a-t-elle ?
- **Non dago sukaldea?** — Où est la cuisine ?
- **Etxeak badu balkoirik?** — Est-ce que la maison a un balcon ?

> **Note culturelle :** en Navarre et dans la zone basco-espagnole, il est courant de dire *pisua* pour un logement en ville et *etxea* pour la maison familiale/de village. Au quotidien, les deux se mélangent sans problème.
