Pour parler de projets, il faut maîtriser les marqueurs temporels. Voici ceux de l'axe passé-présent-futur et les plus utilisés pour le futur proche.

## L'axe de base

| Basque | Français |
|---|---|
| *atzo* | hier |
| *gaur* | aujourd'hui |
| *bihar* | demain |
| *etzi* | après-demain |
| *etziluma / etzidamu* | "le surlendemain" (peu utilisé) |

Trois mots courts (*atzo, gaur, bihar*) et *etzi* — avec ça, tu peux te débrouiller dans presque n'importe quelle conversation quotidienne sur les dates.

## `Datorren` (qui vient)

Pour dire "la semaine prochaine", "le mois prochain", on utilise **datorren** + nom :

| Basque | Français |
|---|---|
| *datorren astean* | la semaine prochaine |
| *datorren astelehenean* | lundi prochain |
| *datorren hilean* | le mois prochain |
| *datorren urtean* | l'année prochaine |

`Datorren` signifie "qui vient" (c'est la forme relative du verbe *etorri*, venir). L'important est de l'apprendre comme un bloc.

## "Ce/cette" — `hau` / `honetan`

Pour dire "cette semaine", "ce week-end" :

- *aste honetan* — cette semaine
- *asteburu honetan* — ce week-end
- *hilabete honetan* — ce mois-ci

## Autres marqueurs clés

| Basque | Français |
|---|---|
| *orain* | maintenant |
| *gero* | plus tard, après |
| *lehen* | avant |
| *gaur goizean* | ce matin |
| *gaur arratsaldean* | cet après-midi |
| *gaur gauean* | ce soir |
| *bihar goizean* | demain matin |

> *Goiza* = matin (partie de la journée). *Bihar* = demain (jour suivant). Ce sont deux mots différents, ne les confonds pas !

## Poser des questions sur le temps

- **Noiz?** — Quand ?
- **Noiz etorriko zara?** — Quand viendras-tu ?
- **Noiz egingo dugu afaria?** — Quand préparerons-nous le dîner ?

## Exemples en contexte

- *Bihar mendira joango naiz.* — Demain, j'irai à la montagne.
- *Etzi euskara klasea dut.* — Après-demain, j'ai cours de basque.
- *Datorren astean lan asko izango dut.* — La semaine prochaine, j'aurai beaucoup de travail.
- *Asteburu honetan ez dut planik.* — Ce week-end, je n'ai pas de programme.

> **Note culturelle :** en basque, "matin" en tant que moment de la journée se dit *goiza* et "demain" en tant que jour suivant se dit *bihar*. L'expression *bihar goizean* ("demain matin") combine les deux. Dans les premières conversations, il est très fréquent de se tromper sur cette nuance, il est donc conseillé de bien la retenir dès le début.
