Vous connaissez déjà le suffixe **`-(e)an`** de la leçon « Où habites-tu ? » (*Bilbon bizi naiz*). Ici, nous l'appliquons au quartier : où se trouve chaque chose.

## La question : Non dago…?

Pour demander **où est... ?**, on utilise :

- **Non dago …?** — Où est + (sujet singulier) ?
- **Non daude …?** — Où sont + (sujet pluriel) ?
- **Non zaude?** — Où es-tu ?
- **Non nago?** — Où suis-je ?

Le verbe est **egon** (« être », pour la localisation), que vous avez déjà vu dans les salutations. Rappelez-vous des formes :

| Personne | Forme |
|---|---|
| ni | **nago** |
| zu | **zaude** |
| hura | **dago** |
| gu | **gaude** |
| zuek | **zaudete** |
| haiek | **daude** |

## La réponse : lieu + `-(e)an` + dago

Pour dire **où se trouve** quelque chose, ajoutez le suffixe **`-(e)an`** au lieu :

| Terminaison du lieu | Modèle | Exemple |
|---|---|---|
| -a (organique, comme *Donostia*) | + n | Donostia → **Donostian** |
| Voyelle sans -a final (*mendi*, *kale-*) | + an | mendi → **mendian** |
| Consonne (*Madril*, *lur*) | + en (noms propres) / + ean (noms communs) | Madril → **Madrilen**; lur → **lurrean** |

> Remarque sur les mots comme *kale* (rue) : lorsqu'ils portent l'article *kalea* (« la rue »), on retire le `-a` de l'article avant d'ajouter le suffixe : *kalea* → *kale-an* = **kalean** (« dans la rue »).

## Exemples complets

- **Botika kalean dago.** — La pharmacie est dans la rue.
- **Liburuak mahaian daude.** — Les livres sont sur la table.
- **Ikaslea ikasgelan dago.** — L'élève est dans la salle de classe.
- **Aita tabernan dago.** — Papa est au bar.
- **Ni euskaltegian nago.** — Je suis à l'euskaltegi.
- **Bilbo Bizkaian dago.** — Bilbao est en Bizkaia.

## Mini-dialogue

> — *Aupa! **Non dago** liburutegia?* — Salut ! Où est la bibliothèque ?
>
> — *Liburutegia plazan dago, eskolaren ondoan.* — La bibliothèque est sur la place, à côté de l'école.
>
> — *Eskerrik asko!*

> **Astuce :** *non* = « où » en basque. Toute réponse à *non...?* contient un nom avec le suffixe `-(e)an` ou un adverbe de lieu (*hemen*, *hor*, *han* — vous les verrez dans la prochaine leçon).
